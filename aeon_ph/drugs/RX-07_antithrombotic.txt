================================================================
アスピリン（aspirin）— 低用量
================================================================
商品名: バイアスピリン錠100mg — 先発品（長収載品）
カテゴリ: RX-07 抗血栓薬
剤型・規格: 腸溶錠 100mg
薬価: 5.90円
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 抗血小板薬（低用量アスピリン）
- シクロオキシゲナーゼ-1（COX-1）を不可逆的に阻害
- トロンボキサンA2（TXA2）産生を抑制 → 血小板凝集を阻害
- 血小板は核を持たないためCOX-1を再合成できない → 血小板寿命（7〜10日）の間効果持続
- 腸溶錠のため胃内では溶解せず腸で吸収 → 胃粘膜への直接的刺激を軽減

【適応】
- 狭心症（慢性安定狭心症、不安定狭心症）
- 心筋梗塞
- 虚血性脳血管障害（脳梗塞、一過性脳虚血発作）
- 冠動脈バイパス術（CABG）あるいは経皮経管冠動脈形成術（PCI）施行後の血栓・塞栓形成の抑制
- 川崎病（冠動脈障害を含む）

【用法用量】
- 成人: 1回100mg 1日1回
- 腎機能低下時: 出血リスクに注意するが用量調整は不要
- 肝機能低下時: 慎重投与

【禁忌・注意】
- 禁忌: 本剤過敏症、消化性潰瘍、出血傾向、アスピリン喘息
- 慎重投与: 消化性潰瘍の既往（PPI併用を考慮）、手術前（5〜7日前に中止を検討）
- 相互作用:
  - 他のNSAIDs → 消化管出血リスク増大
  - ワルファリン、DOAC → 出血リスク増大
  - メトトレキサート → 排泄遅延による毒性増強
  - イブプロフェン → アスピリンの抗血小板作用を競合的に阻害する可能性（投与順序に注意）
- 妊婦: 出産予定日12週以内は禁忌（分娩遅延・出血のリスク）
- 副作用:
  - 頻度高: 消化器症状（胃部不快感、悪心）、出血傾向
  - 重大: 消化管出血、脳出血、ショック（アスピリン喘息）

【処方のポイント】
- 動脈硬化性疾患の二次予防の基本薬
- 消化管出血リスクが高い場合 → タケルダ配合錠（アスピリン100mg + ランソプラゾール15mg）が便利
- PCI後のDAPT（アスピリン + クロピドグレル）の一方として使用
- 手術前の中止時期: 待機手術では5〜7日前に中止（血小板寿命を考慮）
- 一次予防としての使用は推奨されなくなっている（出血リスクとのバランス）

【CureStation テンプレートとの関連】
- 090-AP-03（急性冠症候群）、090-AP-04（脳梗塞二次予防）

【調剤薬局での採用状況】
- 採用: あり（バイアスピリン錠100mg）

【採用がない場合の代替案】
- 同効代替薬: クロピドグレル（在庫あり）→ アスピリン不耐の場合の代替
- 配合剤: タケルダ配合錠（在庫あり）→ PPI併用が必要な場合


================================================================
クロピドグレル（clopidogrel）
================================================================
商品名: プラビックス / 後発: クロピドグレル錠「サワイ」他
カテゴリ: RX-07 抗血栓薬
剤型・規格: 錠 75mg
薬価: 31.90円（後発錠75mg）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- チエノピリジン系抗血小板薬
- ADP受容体P2Y12を選択的かつ非可逆的に遮断 → 血小板凝集を阻害
- プロドラッグ: 肝臓でCYP2C19等により活性代謝物に変換
- CYP2C19の遺伝子多型により効果に個人差（PM: poor metabolizerでは効果減弱）
- T1/2（活性代謝物）: 約7〜8時間だが、血小板への作用は不可逆的のため持続

【適応】
- 虚血性脳血管障害（脳梗塞）後の再発抑制
- PCI後の血栓予防（アスピリンとのDAPT）
- 末梢動脈疾患に伴う血栓・塞栓形成の抑制

【用法用量】
- 成人: 1回75mg 1日1回
- PCI時: ローディングドーズ300mgを投与後、75mg/日で維持
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 慎重投与

【禁忌・注意】
- 禁忌: 出血している患者、本剤過敏症
- 慎重投与: 出血リスクの高い患者、手術前（5〜7日前に中止を検討）
- 相互作用:
  - CYP2C19阻害薬（オメプラゾール等）→ 活性化が阻害され抗血小板効果減弱の可能性
  - PPIとの併用: ラベプラゾールはCYP2C19への影響が少ない → 併用PPIとして好ましい
  - ワルファリン、DOAC → 出血リスク増大
- 妊婦: 有益性投与
- 副作用:
  - 頻度高: 出血（皮下出血、鼻出血等）、消化器症状
  - 重大: 重篤な出血（頭蓋内出血等）、血栓性血小板減少性紫斑病（TTP）、肝機能障害

【処方のポイント】
- アスピリンとのDAPT: PCI後の標準療法。期間は病態に応じて3〜12ヶ月
- CYP2C19 PMでは効果が不十分 → 代替薬（プラスグレル: 調剤薬局非採用）を検討
- PPIが必要な場合: ラベプラゾール（在庫あり）を優先的に選択
- アスピリン不耐の場合: クロピドグレル単剤での抗血小板療法

【CureStation テンプレートとの関連】
- 090-AP-03（急性冠症候群：DAPT）、090-AP-04（脳梗塞二次予防）

【調剤薬局での採用状況】
- 採用: あり（後発 クロピドグレル錠75mg「サワイ」）
- 備考: なし

【採用がない場合の代替案】
- 同効代替薬: アスピリン（在庫あり）→ ただしP2Y12阻害ではない
- 薬局での取り寄せ: 翌日入荷可能


================================================================
アピキサバン（apixaban）
================================================================
商品名: エリキュース
カテゴリ: RX-07 抗血栓薬
剤型・規格: 錠 2.5mg / 5mg
薬価: 114.70円（2.5mg）、207.00円（5mg）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 直接経口抗凝固薬（DOAC）
- 活性化血液凝固第Xa因子を選択的かつ可逆的に阻害
- バイオアベイラビリティ約50%
- T1/2 約12時間 → 1日2回投与
- 腎排泄27%、肝代謝（CYP3A4、P-gp基質）
- 食事の影響を受けない

【適応】
- 非弁膜症性心房細動における虚血性脳卒中・全身性塞栓症の発症抑制
- 静脈血栓塞栓症（DVT/PE）の治療・再発抑制

【用法用量】
- 心房細動: 1回5mg 1日2回
- 減量基準（以下のうち2項目以上に該当）: 80歳以上、体重60kg以下、血清Cr 1.5mg/dL以上 → 1回2.5mg 1日2回
- DVT/PE初期治療: 1回10mg 1日2回（7日間）、その後1回5mg 1日2回
- 腎機能低下時: CrCl 15〜29で慎重投与（減量基準に該当する場合が多い）。CrCl <15は慎重投与（十分なデータなし、原則使用を避ける）
- 高齢者: 減量基準に該当することが多い

【禁忌・注意】
- 禁忌: 出血、重度肝障害（凝固因子産生異常を伴う）
- 相互作用:
  - CYP3A4阻害薬 + P-gp阻害薬（ケトコナゾール、イトラコナゾール等）→ 併用禁忌
  - アゾール系抗真菌薬、HIVプロテアーゼ阻害薬 → 血中濃度上昇
  - CYP3A4誘導薬（リファンピシン、カルバマゼピン等）→ 血中濃度低下
  - 抗血小板薬 → 出血リスク増大
- 妊婦: 禁忌（動物実験で有害作用）。授乳婦: 投与を避ける
- 副作用:
  - 頻度高: 出血（鼻出血、皮下出血、血尿等）
  - 重大: 重篤な出血（頭蓋内出血、消化管出血）

【処方のポイント】
- ARISTOTLE試験: ワルファリンと比較して脳卒中・全身性塞栓症、大出血、死亡率のいずれも低下
- DOACの中で最も出血リスクが低いとされる → 高齢者・出血リスクの高い患者に好ましい
- 減量基準を正確に適用することが重要（不適切な減量は効果不十分に）
- 拮抗薬: アンデキサネットアルファ（病院での使用）
- 腎排泄の割合が低い（27%）→ 軽〜中等度腎機能低下でも使いやすい

【CureStation テンプレートとの関連】
- 090-AP-05（心房細動）、090-AP-06（深部静脈血栓症/肺塞栓症）

【調剤薬局での採用状況】
- 採用: あり（先発 エリキュース錠2.5mg、5mg）
- 備考: 後発品なし（先発のみ）

【採用がない場合の代替案】
- 同一成分別規格: 2.5mg / 5mg いずれも在庫あり
- 同効代替薬: エドキサバン（在庫あり）、リバーロキサバン（在庫あり）

エドキサバン（edoxaban）
================================================================
商品名: リクシアナ
カテゴリ: RX-07 抗血栓薬
剤型・規格: OD錠 30mg / 60mg
薬価: 411.30円（OD錠30mg）、416.80円（OD錠60mg）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 直接経口抗凝固薬（DOAC）
- 活性化第Xa因子を選択的かつ可逆的に阻害
- T1/2 約10〜14時間 → 1日1回投与
- 腎排泄約50%（DOACの中で腎排泄の割合が比較的高い）
- P-gp基質

【適応】
- 非弁膜症性心房細動における虚血性脳卒中・全身性塞栓症の発症抑制
- 静脈血栓塞栓症（DVT/PE）の治療・再発抑制

【用法用量】
- 心房細動: 1回60mg 1日1回
- 減量基準（以下のいずれかに該当）: 体重60kg以下、CrCl 15〜50mL/min、P-gp阻害薬併用 → 1回30mg 1日1回
- DVT/PE: 親薬（ヘパリン等）投与後に1回60mg 1日1回
- 腎機能低下時: CrCl 15〜50で30mgに減量。CrCl <15は禁忌
- 高齢者: 減量基準に該当する場合が多い

【禁忌・注意】
- 禁忌: 出血、重度肝障害、CrCl <15
- 相互作用:
  - P-gp阻害薬（キニジン、ベラパミル、シクロスポリン等）→ 減量基準に該当
  - 抗血小板薬 → 出血リスク増大
- 妊婦: 禁忌（動物実験で有害作用）
- 副作用:
  - 頻度高: 出血（鼻出血、皮下出血等）
  - 重大: 重篤な出血（頭蓋内出血、消化管出血）、肝機能障害

【処方のポイント】
- 1日1回投与 → 服薬アドヒアランスが最も良いDOAC
- OD錠 → 嚥下困難な高齢者に使いやすい
- 減量基準がシンプル（体重60kg以下 or CrCl 15〜50 or P-gp阻害薬）
- 腎排泄の割合が比較的高い → 高度腎機能低下時にはアピキサバンが好ましい場合あり
- ENGAGE AF-TIMI 48試験: ワルファリンと比較して非劣性（脳卒中予防）、大出血は有意に低下

【CureStation テンプレートとの関連】
- 090-AP-05（心房細動）、090-AP-06（DVT/PE）

【調剤薬局での採用状況】
- 採用: あり（先発 リクシアナOD錠30mg、60mg）
- 備考: 後発品なし（先発のみ）

【採用がない場合の代替案】
- 同一成分別規格: 30mg / 60mg いずれも在庫あり
- 同効代替薬: アピキサバン（在庫あり）、リバーロキサバン（在庫あり）

リバーロキサバン（rivaroxaban）
================================================================
商品名: イグザレルト / 後発: リバーロキサバンOD錠「サワイ」他
カテゴリ: RX-07 抗血栓薬
剤型・規格: 錠 10mg / OD錠 15mg
薬価: 331.60円（先発錠10mg）、226.70円（後発OD錠15mg）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 直接経口抗凝固薬（DOAC）
- 活性化第Xa因子を直接的かつ選択的に阻害
- バイオアベイラビリティ: 15mg錠は食後投与で約80%（食事の影響あり → 食後投与が必要）
- T1/2 約5〜9時間（若年者）、約11〜13時間（高齢者）
- 腎排泄約36%、肝代謝（CYP3A4/CYP2J2）、P-gp基質

【適応】
- 非弁膜症性心房細動における虚血性脳卒中・全身性塞栓症の発症抑制
- 深部静脈血栓症（DVT）・肺血栓塞栓症（PE）の治療および再発抑制

【用法用量】
- 心房細動: 1回15mg 1日1回 食後
- 腎機能低下例（CrCl 15〜49mL/min）: 1回10mg 1日1回
- DVT/PE: 初期治療15mg 1日2回 3週間、その後15mg 1日1回。再発抑制10〜15mg 1日1回
- CrCl <15は禁忌

【禁忌・注意】
- 禁忌: 出血、重度肝障害、CrCl <15
- 相互作用:
  - CYP3A4阻害薬 + P-gp阻害薬 → 血中濃度上昇（アゾール系抗真菌薬、HIVプロテアーゼ阻害薬）
  - CYP3A4誘導薬 → 血中濃度低下
  - 抗血小板薬 → 出血リスク増大
- 妊婦: 禁忌（動物実験で有害作用）
- 副作用:
  - 頻度高: 出血（鼻出血、歯肉出血等）
  - 重大: 重篤な出血、肝機能障害

【処方のポイント】
- 1日1回投与だが食後投与が必要（食事による吸収促進がないとバイオアベイラビリティ低下）
- 後発OD錠15mgが在庫あり → DOACの中では最も安価な選択肢
- DVT/PE: 初期から経口投与が可能（他のDOACはヘパリンからの切替が必要な場合あり）
- ROCKET AF試験: ワルファリンと比較して非劣性
- 食事を十分にとれない患者にはアピキサバンやエドキサバンが好ましい

【CureStation テンプレートとの関連】
- 090-AP-05（心房細動）、090-AP-06（DVT/PE）

【調剤薬局での採用状況】
- 採用: あり（先発 イグザレルト錠10mg、後発 リバーロキサバンOD錠15mg「サワイ」）
- 備考: 後発OD錠は15mgのみ

【採用がない場合の代替案】
- 同効代替薬: アピキサバン（在庫あり）、エドキサバン（在庫あり）


================================================================
ワルファリン（warfarin）
================================================================
商品名: ワーファリン
カテゴリ: RX-07 抗血栓薬
剤型・規格: 錠 0.5mg / 1mg
薬価: 10.40円（各規格）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- ビタミンK拮抗薬（経口抗凝固薬）
- 肝臓でのビタミンK依存性凝固因子（II, VII, IX, X）の合成を阻害
- 作用発現まで2〜5日（既存の凝固因子が消費されるまでの時間が必要）
- T1/2 約36〜42時間
- 肝代謝（CYP2C9, CYP3A4, CYP1A2）
- 治療域が狭い → PT-INRによるモニタリングが必須

【適応】
- 血栓塞栓症の治療・予防
  - 心房細動に伴う血栓塞栓症
  - 人工弁置換術後
  - 深部静脈血栓症・肺塞栓症
  - その他の血栓塞栓症

【用法用量】
- 成人: 初回1日1〜5mg
- PT-INRを指標に維持量を決定。通常維持量1日1〜5mg
- 目標PT-INR: 心房細動（非弁膜症性）2.0〜3.0（70歳以上は1.6〜2.6）
- 腎機能低下時: INRを指標に調整
- 高齢者: 感受性が高い → 低用量から開始

【禁忌・注意】
- 禁忌: 出血、重篤な肝・腎障害、妊婦（催奇形性: ワルファリン胎芽病）
- 相互作用（非常に多い）:
  - 効果増強: アゾール系抗真菌薬、マクロライド系抗菌薬、ST合剤、アミオダロン、フィブラート系
  - 効果減弱: リファンピシン、カルバマゼピン、St. John's Wort
  - ビタミンK含有食品（納豆、クロレラ、ブロッコリー大量摂取等）→ 効果減弱
  - NSAIDs、抗血小板薬 → 出血リスク増大
- 妊婦: 禁忌（催奇形性）
- 副作用:
  - 頻度高: 出血（皮下出血、鼻出血、血尿、消化管出血）
  - 重大: 頭蓋内出血、後腹膜出血、皮膚壊死（稀）

【処方のポイント】
- DOACの登場により使用頻度は減少しているが、以下の場合には依然として第一選択:
  - 機械弁置換術後
  - 僧帽弁狭窄症に伴う心房細動
  - 抗リン脂質抗体症候群
- PT-INRの定期的モニタリングが必須 → 服薬コンプライアンスと通院頻度が問題
- ビタミンK含有食品の制限が患者のQOLに影響 → 食事指導が重要
- 拮抗薬: ビタミンK（メナテトレノン）→ 緊急時の出血対応
- 0.5mgと1mgの2規格が在庫あり → きめ細かい用量調節が可能

【CureStation テンプレートとの関連】
- 090-AP-05（心房細動）、090-AP-06（DVT/PE）

【調剤薬局での採用状況】
- 採用: あり（先発 ワーファリン錠0.5mg、1mg）
- 備考: なし

【採用がない場合の代替案】

タケルダ配合錠（アスピリン + ランソプラゾール）
================================================================
商品名: タケルダ配合錠
カテゴリ: RX-07 抗血栓薬（配合剤）
剤型・規格: 配合錠（アスピリン100mg + ランソプラゾール15mg）
薬価: 19.40円
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 低用量アスピリン（抗血小板薬）+ PPI（プロトンポンプ阻害薬）の配合錠
- アスピリン100mg: COX-1阻害による抗血小板作用
- ランソプラゾール15mg: 胃酸分泌抑制 → アスピリンによる胃潰瘍リスクを低減
- 抗血小板作用を維持しつつ消化管保護を同時に行う

【適応】
- 血栓・塞栓形成の抑制を要し、胃潰瘍または十二指腸潰瘍の既往がある患者
  （下記の疾患: 狭心症、心筋梗塞、虚血性脳血管障害、CABG後、PCI後）

【用法用量】
- 成人: 1回1錠 1日1回
- 腎機能低下時: 出血リスクに注意
- 高齢者: 通常量で使用可

【禁忌・注意】
- 禁忌: アスピリンの禁忌に準ずる（消化性潰瘍の活動期、出血傾向、アスピリン喘息）
- 禁忌: ランソプラゾールの禁忌（アタザナビル・リルピビリン投与中）
- 相互作用:
  - アスピリンの相互作用に準ずる
  - クロピドグレル: ランソプラゾールがCYP2C19を介してクロピドグレルの活性化を阻害する可能性
- 副作用: アスピリン + ランソプラゾール各成分の副作用に準ずる

【処方のポイント】
- 消化管出血既往があり低用量アスピリンを継続する必要がある患者に最適
- 単剤2錠（アスピリン + PPI別々）より配合錠1錠で服薬負担軽減
- DAPT時（アスピリン + クロピドグレル）にタケルダを使用する場合、ランソプラゾールのCYP2C19阻害に注意 → 必要ならPPIをラベプラゾールに変更
- 消化管出血リスクのない患者にはバイアスピリン単剤で十分

- 090-AP-03（急性冠症候群）、090-AP-04（脳梗塞二次予防）
