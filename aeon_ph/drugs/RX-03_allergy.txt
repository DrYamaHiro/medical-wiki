フェキソフェナジン塩酸塩（fexofenadine）
================================================================
商品名: アレグラ / 後発: フェキソフェナジン塩酸塩錠「杏林」他
カテゴリ: RX-03 アレルギー・免疫
剤型・規格:
  - 錠 30mg / 60mg
  - シロップ用（DS）5%（0.6g/包）
薬価: 10.40円（後発錠30mg・60mg）/ 29.10円（後発DS5%）/ 26.10円（先発アレグラ60mg）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 第2世代抗ヒスタミン薬
- H1受容体を選択的に遮断し、アレルギー反応を抑制
- 脳内H1受容体占拠率が極めて低い → 眠気が少ない（自動車運転制限なし）
- ケミカルメディエーター遊離抑制作用も有する
- T1/2 約14時間
- 肝代謝はほぼなし（未変化体のまま主に糞便中排泄）→ CYP相互作用が少ない

【適応】
- アレルギー性鼻炎
- 蕁麻疹
- 皮膚疾患に伴うそう痒（湿疹・皮膚炎、アトピー性皮膚炎等）

【用法用量】
- 成人: 1回60mg 1日2回 投与
- 小児（7-11歳）: 1回30mg 1日2回
- 小児（12歳以上）: 成人量
- 小児（2-6歳）: DS使用。1回30mg 1日2回
- 腎機能低下時: 重度腎障害では1回60mg 1日1回に減量（添付文書を参照）
- 高齢者: 腎機能に応じて減量を考慮

【禁忌・注意】
- 禁忌: 本剤成分に過敏症の既往
- 相互作用:
  - エリスロマイシン → フェキソフェナジン血中濃度上昇（P-gp阻害）
  - 制酸薬（Al・Mg含有）→ フェキソフェナジン吸収低下（同時服用を避ける）
  - グレープフルーツジュース → OATP阻害による吸収低下
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 添付文書を参照
- 副作用:
  - 頻度高: 頭痛（稀）、眠気（プラセボと同等）
  - 重大: ショック・アナフィラキシー（極めて稀）、肝機能障害、無顆粒球症

【処方のポイント】
- 眠気が最も少ない抗ヒスタミン薬の一つ（ビラスチンと並ぶ）
- 運転制限なし → ドライバー、精密作業者に適する
- 効果が穏やかなため、重症例にはオロパタジンやレボセチリジンが適する場合あり
- 花粉症シーズン前からの予防的投与が有効
- OTC版（アレグラFX）との重複に注意
- DS製剤は小児への用量調整に有用

【CureStation テンプレートとの関連】
- 020-AP-01（アレルギー性鼻炎）
- 200-AP-01〜02（蕁麻疹・アトピー性皮膚炎）

【調剤薬局での採用状況】
- 採用:
  - アレグラ錠60mg（先発）: 在庫200
  - フェキソフェナジン塩酸塩錠30mg「杏林」（後発 ○）: 在庫200
  - フェキソフェナジン塩酸塩錠60mg「杏林」（後発 ○）: 在庫1,000
  - フェキソフェナジン塩酸塩DS5%「トーワ」（後発 ○）: 在庫120
- 備考: 後発60mg錠は大量在庫あり

【採用がない場合の代替案】
- 同一成分別規格: 30mg / 60mg / DS いずれも在庫あり
- 同効代替薬: ビラスチン錠20mg（在庫あり）。同様に眠気が少ない

ビラスチン（bilastine）
================================================================
商品名: ビラノア / ビラノアOD錠
カテゴリ: RX-03 アレルギー・免疫
剤型・規格: 錠 20mg / OD錠 20mg
薬価: 48.70円（先発ビラノア錠）/ 49.10円（先発ビラノアOD錠）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 第2世代抗ヒスタミン薬（新規）
- H1受容体を選択的に遮断
- 脳内H1受容体占拠率が極めて低い → 眠気がほぼない
- 肝代謝をほとんど受けない → CYP相互作用が少ない
- T1/2 約14.5時間
- P-gp基質

【適応】
- アレルギー性鼻炎
- 蕁麻疹
- 皮膚疾患に伴うそう痒

【用法用量】
- 成人: 1回20mg 1日1回 空腹時に投与
- 小児: 適応なし（日本では成人のみ承認）
- 腎機能低下時: 中等度以上の腎障害では血中濃度上昇。慎重投与
- 高齢者: 通常量で使用可

【禁忌・注意】
- 禁忌: 本剤成分に過敏症の既往
- 重要: 食事の影響を受ける → 必ず空腹時に服用（食後投与で吸収が約40%低下）
- 相互作用:
  - P-gp阻害薬（エリスロマイシン、シクロスポリン等）→ ビラスチン血中濃度上昇
  - グレープフルーツジュース → OATP阻害による吸収低下
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 有益性投与（乳汁移行の報告あり）
- 副作用:
  - 頻度高: 頭痛（稀）
  - 重大: ショック・アナフィラキシー（極めて稀）

【処方のポイント】
- フェキソフェナジンと並び眠気が最も少ない抗ヒスタミン薬
- 運転制限なし
- 空腹時服用が必須（起床時に服用 → 30分後に朝食が理想）→ アドヒアランスに注意
- OD錠は水なしで服用可能。嚥下困難な患者に有用
- 1日1回投与で服薬簡便

【CureStation テンプレートとの関連】
- 020-AP-01（アレルギー性鼻炎）
- 200-AP-01〜02（蕁麻疹・アトピー性皮膚炎）

【調剤薬局での採用状況】
- 採用:
  - ビラノア錠20mg（先発）: 在庫200
  - ビラノアOD錠20mg（先発）: 在庫200
- 備考: 後発品は未発売（2026年3月現在）

【採用がない場合の代替案】
- 同効代替薬: フェキソフェナジン錠60mg（在庫あり）。同様に眠気が少ないが1日2回投与

レボセチリジン塩酸塩（levocetirizine）
================================================================
商品名: ザイザル / 後発: レボセチリジン塩酸塩錠「サワイ」「YD」他
カテゴリ: RX-03 アレルギー・免疫
剤型・規格:
  - 錠 2.5mg / 5mg
  - シロップ 0.05%
  - シロップ用（DS）0.5%（0.25g/包）
薬価: 12.10円（後発錠2.5mg）/ 14.60円（後発錠5mg）/ 41.10円（先発ザイザル5mg）/ 6.90円（後発シロップ）/ 46.70円（後発DS）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 第2世代抗ヒスタミン薬
- セチリジンの光学活性体（R-エナンチオマー）でH1受容体選択性が高い
- 抗ヒスタミン作用が強力（セチリジンより少量で同等効果）
- ケミカルメディエーター遊離抑制作用も有する
- T1/2 約7-10時間
- 腎排泄が主体（約85%が未変化体で尿中排泄）→ 腎機能低下時は減量

【適応】
- アレルギー性鼻炎
- 蕁麻疹
- 皮膚疾患に伴う掻痒

【用法用量】
- 成人: 1回5mg 1日1回 就寝前
- 小児（7歳以上15歳未満）: 1回2.5mg 1日2回（朝食後・就寝前）
- 小児（2歳以上7歳未満）: シロップ 1回2.5mL（1.25mg）1日2回（朝食後・就寝前）
- 小児（7歳以上）シロップ: 1回5mL（2.5mg）1日2回
- 腎機能低下時: 中等度（CrCl 30-50）は2.5mg 1日1回、重度では隔日投与（添付文書を参照）
- 高齢者: 腎機能に応じて減量

【禁忌・注意】
- 禁忌: 本剤・セチリジン・ヒドロキシジン・ピペラジン誘導体に過敏症、重度腎障害（CrCl<10）
- 注意: 眠気が生じることがある → 自動車運転等の注意（添付文書に記載あり）
- 相互作用: 臨床上問題となるものは少ない。腎排泄型のためCYP相互作用は少ない
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 有益性投与（乳汁移行の報告あり）
- 副作用:
  - 頻度高: 眠気（フェキソフェナジンより多いがオロパタジンより少ない）、口渇、倦怠感
  - 重大: ショック・アナフィラキシー（極めて稀）、肝機能障害、痙攣

【処方のポイント】
- 効果と眠気のバランスが良い抗ヒスタミン薬
- 1日1回就寝前投与 → アドヒアランス良好、眠気を夜間に利用
- 蕁麻疹には増量処方（5mg 1日2回、保険適応外）が有効な場合あり
- 小児用剤型（シロップ、DS）が充実 → 小児のアレルギー管理に有用
- 腎機能低下患者では減量が必要（腎排泄型）

【CureStation テンプレートとの関連】
- 020-AP-01（アレルギー性鼻炎）
- 200-AP-01〜02（蕁麻疹・アトピー性皮膚炎）

【調剤薬局での採用状況】
- 採用:
  - ザイザル錠5mg（先発）: 在庫100
  - レボセチリジン塩酸塩錠2.5mg「YD」（後発 ○）: 在庫200
  - レボセチリジン塩酸塩錠5mg「サワイ」（後発 ○）: 在庫300
  - ザイザルシロップ0.05%（先発）: 在庫400
  - レボセチリジン塩酸塩シロップ0.05%「トーワ」（後発 ○）: 在庫400
  - レボセチリジン塩酸塩DS0.5%「タカタ」（後発 ○）: 在庫200
- 備考: 全剤型豊富に在庫あり

【採用がない場合の代替案】
- 同一成分別規格: 全規格在庫あり → 規格切れの心配は低い
- 同効代替薬: オロパタジン錠5mg（在庫あり）。効果は同等だが1日2回投与

オロパタジン塩酸塩（olopatadine）
================================================================
商品名: アレロック / 後発: オロパタジン塩酸塩錠「日医工」他
カテゴリ: RX-03 アレルギー・免疫
剤型・規格:
  - 錠 5mg
  - OD錠 2.5mg / 5mg
  - 顆粒 0.5%（0.5g/包）
  - 点眼液 0.1%（5mL/瓶）
薬価: 10.40円（後発錠5mg・OD錠2.5mg）/ 20.70円（先発アレロックOD錠5mg・顆粒）/ 34.90円（後発点眼液）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 第二世代抗ヒスタミン薬
- H1受容体拮抗作用に加え、ケミカルメディエーター遊離抑制作用を有する
- 抗ヒスタミン作用が強力（第2世代の中でも上位）
- T1/2 約8-12時間
- 肝代謝（一部CYP3A4）、腎排泄

【適応】
- アレルギー性鼻炎
- 蕁麻疹
- 皮膚疾患に伴う瘙痒（湿疹・皮膚炎、アトピー性皮膚炎等）
- 点眼液: アレルギー性結膜炎

【用法用量】
- 成人: 1回5mg 1日2回（朝・就寝前）
- 小児（7歳以上）: 1回5mg 1日2回
- 小児（2-6歳）: 顆粒 1回0.5g（2.5mg）1日2回
- 点眼: 1回1滴 1日4回
- 腎機能低下時: 添付文書を参照。腎排泄の寄与があるため慎重投与
- 高齢者: 通常量で使用可。眠気に注意

【禁忌・注意】
- 禁忌: 本剤成分に過敏症の既往
- 注意: 眠気が生じることがある → 自動車運転等に注意（添付文書に記載あり）
- 相互作用: 中枢抑制薬、アルコール → 眠気増強
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 有益性投与（乳汁移行の報告あり）
- 副作用:
  - 頻度高: 眠気（約7%）、倦怠感
  - 重大: 肝機能障害（稀）

【処方のポイント】
- 効果が強力で掻痒の強いアトピー性皮膚炎、蕁麻疹に適する
- 眠気はフェキソフェナジン・ビラスチンより多い → 就寝前投与の配慮
- 顆粒は小児（2歳から使用可）の用量調整に有用
- 点眼液は抗アレルギー作用と抗ヒスタミン作用を併せ持つ → 花粉症の結膜炎に有効
- OD錠は嚥下困難な患者に有用

【CureStation テンプレートとの関連】
- 020-AP-01（アレルギー性鼻炎）
- 200-AP-01〜02（蕁麻疹・アトピー性皮膚炎）

【調剤薬局での採用状況】
- 採用:
  - アレロック錠5mg（先発）: 在庫100 / アレロックOD錠5mg（先発）: 在庫100
  - オロパタジン塩酸塩OD錠2.5mg「サワイ」（後発 ○）: 在庫100
  - オロパタジン塩酸塩錠5mg「日医工」（後発 ○）: 在庫1,000
  - アレロック顆粒0.5%（先発）: 在庫200 / オロパタジン塩酸塩顆粒「トーワ」（後発 ○）: 在庫200
  - オロパタジン点眼液0.1%「ニットー」（後発 ○）: 在庫100
- 備考: 後発錠5mgは大量在庫あり

【採用がない場合の代替案】
- 同効代替薬: レボセチリジン錠5mg（在庫あり）。効果は同等、1日1回投与

d-クロルフェニラミンマレイン酸塩（d-chlorpheniramine）
================================================================
商品名: ポララミン
カテゴリ: RX-03 アレルギー・免疫
剤型・規格: 錠 2mg
薬価: 5.90円
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 第一世代抗ヒスタミン薬
- H1受容体を拮抗しアレルギー反応を抑制
- 脳内H1受容体占拠率が高い → 強い眠気・鎮静作用
- 抗コリン作用あり → 鼻汁・くしゃみの抑制に寄与するが、口渇・排尿困難等の副作用
- T1/2 約12-43時間（添付文書参照、個人差が大きい）

【適応】
- 蕁麻疹
- アレルギー性鼻炎
- 皮膚疾患に伴う掻痒

【用法用量】
- 成人: 1回2mg 1日1-4回 投与
- 小児: 年齢に応じて減量（添付文書を参照）
- 腎機能低下時: 添付文書を参照
- 高齢者: 抗コリン作用による認知機能低下・せん妄のリスク。Beers criteriaで不適切薬に該当

【禁忌・注意】
- 禁忌: 本剤成分に過敏症、緑内障、前立腺肥大による排尿障害、低出生体重児・新生児
- 注意: 強い眠気 → 自動車運転禁止（添付文書に記載）
- 相互作用:
  - 中枢抑制薬、アルコール → 鎮静増強
  - 抗コリン薬 → 抗コリン作用増強（口渇、便秘、排尿困難）
  - MAO阻害薬 → 作用増強
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 有益性投与（乳汁移行の報告あり）
- 副作用:
  - 頻度高: 眠気（高頻度）、口渇、便秘、排尿困難
  - 重大: 痙攣（小児、過量投与時）

【処方のポイント】
- 第一世代のため原則として第二世代抗ヒスタミン薬を優先
- 主な使用場面:
  - 重症蕁麻疹のレスキュー（注射剤がない外来で経口追加）
  - 鎮静が必要な場面（掻痒による不眠時の就寝前投与）
  - 急性上気道炎の鼻漏（抗コリン作用で鼻汁を抑制）
- 高齢者への漫然とした投与は避ける（Beers criteria該当）
- 小児への長期投与は学習能力低下の懸念

【CureStation テンプレートとの関連】
- 010-AP-01〜03（急性上気道炎: 鼻漏が強い場合）
- 200-AP-01（蕁麻疹: 重症時の追加薬）

【調剤薬局での採用状況】
- 採用: あり（ポララミン錠2mg: 在庫2,000）
- 備考: 大量在庫あり

【採用がない場合の代替案】
- 同効代替薬: 第二世代抗ヒスタミン薬（オロパタジン、レボセチリジン等、全て在庫あり）への切替が推奨

モメタゾン点鼻液（mometasone nasal）
================================================================
商品名: ナゾネックス / 後発: モメタゾン点鼻液「トーワ」
カテゴリ: RX-03 アレルギー・免疫（点鼻ステロイド）
剤型・規格: 点鼻液 50μg（56噴霧用 / 112噴霧用）
薬価: 401.10円（後発56噴霧）/ 922.70円（後発112噴霧）/ 1,417.20円（先発ナゾネックス112噴霧）
薬品区分: 普通薬
----------------------------------------------------------------

【薬理】
- 鼻噴霧用合成副腎皮質ステロイド薬
- 鼻粘膜局所で強力な抗炎症作用を発揮（好酸球浸潤抑制、サイトカイン産生抑制）
- 糖質コルチコイド受容体への結合親和性が高い
- 全身バイオアベイラビリティが極めて低い（約0.1%以下）→ 点鼻ステロイドの中で最も全身移行が少ない
- 肝初回通過効果が高く、吸収された微量成分も速やかに不活化
- 薬物動態: 局所作用が主体。全身吸収はほぼないためCYP相互作用も臨床的に無視できる

【適応】
- アレルギー性鼻炎（通年性・季節性）
- 小児: 3歳以上で適応あり（添付文書を参照）

【用法用量】
- 成人: 各鼻腔に2噴霧ずつ（計4噴霧 = 200μg）1日1回
- 小児（3歳以上12歳未満）: 各鼻腔に1噴霧ずつ（計2噴霧 = 100μg）1日1回
- 小児（12歳以上）: 成人量
- 腎機能低下時: 用量調整不要（全身吸収はほぼなし）
- 肝機能低下時: 用量調整不要（局所作用が主体）
- 高齢者: 通常量で使用可

【禁忌・注意】
- 禁忌: 本剤成分に過敏症の既往、有効な抗菌薬のない感染症、全身真菌症
- 慎重投与: 鼻中隔潰瘍の既往、鼻腔手術後、結核性疾患
- 相互作用: 局所投与のため臨床上問題となる全身性の相互作用はほぼない
- 妊婦: 治療上の有益性が危険性を上回る場合に投与（全身吸収は極めて少ないが、ステロイドのため念のため注意）
- 授乳婦: 使用可（全身吸収はほぼなし）
- 副作用:
  - 頻度高: 鼻出血（5-10%）、咽頭不快感、鼻内乾燥感
  - 重大: 鼻中隔穿孔（極めて稀）、アナフィラキシー（極めて稀）

【処方のポイント】
- アラミスト（フルチカゾンフランカルボン酸）と同等の点鼻ステロイド
- 全身バイオアベイラビリティが約0.1%以下で、点鼻ステロイドの中で最も低い → 全身性副作用の懸念が最も少ない
- アラミストとの使い分け: 効果は同等。デバイスの使いやすさ・薬価で選択
- 小児: 3歳以上で使用可能（アラミストは2歳以上）
- 花粉症には飛散開始1-2週間前からの投与開始が望ましい
- 1日1回投与でアドヒアランス良好
- 56噴霧用は約2週間分（成人）、112噴霧用は約1ヶ月分

【CureStation テンプレートとの関連】
- 020-AP-01（アレルギー性鼻炎）: 点鼻ステロイドRx
- 030-AP-01（急性副鼻腔炎）: 鼻閉改善の補助

【調剤薬局での採用状況】
- 採用:
  - ナゾネックス点鼻液50μg 112噴霧用（先発）: 在庫10
  - モメタゾン点鼻液50μg「トーワ」112噴霧用（後発 ○）: 在庫10
  - モメタゾン点鼻液50μg「トーワ」56噴霧用（後発 ○）: 在庫10
- 備考: 先発・後発ともに在庫あり

【採用がない場合の代替案】
- 同効代替薬: フルチカゾンフランカルボン酸点鼻液（在庫あり）。同等の効果・安全性
- ベクロメタゾン点鼻は調剤薬局非採用
