[Z11.3] 性感染症スクリーニング (STD Screening)

<A: 評価>:
    ・STD一括スクリーニング結果:
      - クラミジア（尿/咽頭/膣 NAAT）: 陰性 / 陽性
      - 淋菌（尿/咽頭/膣 NAAT）: 陰性 / 陽性
      - 梅毒（RPR + TP抗体）: 陰性 / 陽性（RPR定量: ＿倍）
      - HIV（第4世代抗原抗体）: 陰性 / 陽性 ※検査前同意取得要
      - B型肝炎（HBs抗原）: 陰性 / 陽性
    ・ウインドウ期:
      - HIV: 4週
      - 梅毒: 4-6週
      - クラミジア/淋菌: 2-3週
    ・全項目陰性の場合: 「現時点でSTDは検出されませんでした。ウインドウ期を考慮し、心配な行為から＿週間後に再検をお勧めします」

<P: 方針>:
    ・陽性項目があれば該当疾患のテンプレートへ移行して治療開始。
    ・全陰性なら結果説明 + ウインドウ期再検の案内。
    ・注: Z11.3（STDスクリーニング）は保険診療では単独算定不可。保険請求時は『クラミジア感染症の疑い[A56.2]』『淋菌感染症の疑い[A54.9]』等の疑い病名を併記すること。自費診療の場合はZ11.3のみで可。

    ▼ 処方・アクション ▼
    【スクリーニング検査セット】
    [ID: Rx-Uro-STDScr-CT] クラミジアNAAT
    ・尿（男性: 初尿）/ 膣擦過（女性）/ 咽頭擦過 ；部位は行為内容に応じて選択
    [ID: Rx-Uro-STDScr-GC] 淋菌NAAT
    ・尿（男性: 初尿）/ 膣擦過（女性）/ 咽頭擦過 ；部位は行為内容に応じて選択
    [ID: Rx-Uro-STDScr-Syp] 梅毒検査
    ・RPR定量 + TP抗体（TPHA or CLIA）
    [ID: Rx-Uro-STDScr-HIV] HIV検査
    ・第4世代抗原抗体検査 ※検査前に同意を取得すること
    [ID: Rx-Uro-STDScr-HBV] B型肝炎検査
    ・HBs抗原
    [ID: Rx-Uro-STDScr-HCV] C型肝炎検査
    ・C型肝炎（HCV抗体）: 未検 / 陰性 / 陽性 ※特にMSMではHCV同時検査を強く推奨

    【陽性時の治療テンプレート参照先】
    ・クラミジア陽性 → 255-AP-02.txt（性器）/ 255-AP-05.txt（咽頭）
    ・淋菌陽性 → 255-AP-03.txt（性器）/ 255-AP-05.txt（咽頭）
    ・梅毒陽性 → 255-AP-06.txt〜255-AP-09.txt（病期別）
    ・HIV陽性 → 専門施設紹介
    ・HBV陽性 → 消化器内科紹介

    ▼ 指導・計画 ▼
    ・ウインドウ期の説明: リスク行為から検査までの期間が短い場合、偽陰性の可能性を説明。
    ・全陰性でもウインドウ期を考慮した再検を案内。
    ・再診目安: ウインドウ期経過後（リスク行為から4-6週後）。


▶ Dr.Advice [ウインドウ期]: 「昨日リスク行為があった」という患者にすぐ検査しても意味がない。各検査のウインドウ期を説明し、適切な時期に再検を案内せよ。
▶ Dr.Advice [HIV]: HIV検査は検査前に同意を取得すること。結果は対面で伝えることが望ましい。電話での結果通知は避けよ。
▶ Dr.Advice [網羅的に]: 「クラミジアだけ調べて」と言われても、淋菌・梅毒・HIVの同時検査を勧めよ。STDは重複感染が多い。1つ見つかれば他も調べるのが原則。
