[STD] 性感染症 (再診)

<S: 主訴・ROS>:
    症状の変化: ( 消失 / 改善 / 残存 )
    服薬状況: ( 飲みきった / 中断[理由: ＿] / 副作用なし )
    パートナーの状況: ( 受診済・治療完了 / 受診済・治療中 / 未受診 )
    性交渉: ( 治療中は禁止を遵守 / 遵守できず )

<O: 所見・検査>:
    【前回検査結果の確認と説明】
    CT/NG NAAT結果: クラミジア( 陰性 / 陽性 ) 淋菌( 陰性 / 陽性 )
    TV/MG NAAT結果: トリコモナス( 陰性 / 陽性 ) M.genitalium( 陰性 / 陽性 )
    梅毒: RPR( ＿倍 ) TP抗体( 陰性 / 陽性 )
    HIV: ( 陰性 / 陽性 → 専門施設紹介 )
    HBV/HCV: ( 陰性 / 陽性 → 消化器内科紹介 )
    【治癒確認検査（該当時）】
    NAAT再検（治療終了3週間後）: ( 陰性[治癒] / 陽性[治療失敗] )
    梅毒RPR定量フォロー: ( 低下傾向 / 横ばい / 上昇 )

▶ Dr.Advice [治癒確認]: 淋菌・クラミジア・M.genitaliumは治療後3週間以降にNAAT再検で治癒確認を行え。2週間以内の再検はDead DNA偽陽性のリスクがあり信頼性に欠ける。咽頭感染は特に治癒率が低いため再検は必須。
▶ Dr.Advice [CT/NG陰性後のTV/MG]: 初回にCT/NG NAATのみ提出した場合、結果陰性で症状が残存する場合はTV/MG NAAT検査を別日で追加提出せよ。
▶ Dr.Advice [梅毒フォロー]: RPR定量は治療効果の指標。治療後6ヶ月でRPRが4倍以上低下しない場合は治療失敗または再感染を疑え。TP抗体は既感染の指標であり治療効果判定には使えない。
▶ Dr.Advice [パートナー]: パートナーが未受診の場合は再度受診を強く勧めよ。ピンポン感染の防止が治癒の鍵。
