[Z25.9] ワクチン接種記録 (Vaccination Record)

<A: 評価>:
    ・ワクチン名: インフルエンザ / 肺炎球菌(ニューモバックス) / 肺炎球菌(バクニュバンス/PCV15) / 肺炎球菌(プレベナー20/PCV20) / 帯状疱疹(シングリックス) / HPV(シルガード9) / COVID-19 / B型肝炎 / 破傷風トキソイド / MR / 水痘 / おたふく / その他
    ・ロット番号: ＿
    ・接種部位: 左上腕三角筋 / 右上腕三角筋 / 左大腿外側 / 右大腿外側
    ・接種量: 0.25mL / 0.5mL / 1.0mL
    ・体温: ＿℃（37.5℃未満を確認）
    ・問診確認: 副反応・アナフィラキシーの既往なし、体調良好、妊娠なし
    ・同意: 予診票に基づき問診を行い、接種の効果と副反応について十分説明の上、書面による同意を得て接種を実施した。
    ・接種後観察: 接種後15分（アナフィラキシー既往者は30分）院内で経過観察し、異常なきことを確認。

<P: 方針>:
    ・次回接種予定があれば予約。接種証明書の発行。

    ▼ 処方・アクション ▼
    【接種実施】
    [ID: Rx-Vac-Influenza] インフルエンザワクチン
    ・インフルエンザHAワクチン 0.5mL 皮下注射
    [ID: Rx-Vac-PPSV23] 肺炎球菌ワクチン（ニューモバックス）
    ・ニューモバックスNP 0.5mL 皮下注射
    [ID: Rx-Vac-PCV15] 肺炎球菌ワクチン（バクニュバンス/PCV15）
    ・バクニュバンス水性懸濁注シリンジ 0.5mL 筋肉注射 ；PCV15
    [ID: Rx-Vac-PCV20] 肺炎球菌ワクチン（プレベナー20/PCV20）
    ・プレベナー20水性懸濁注シリンジ 0.5mL 筋肉注射 ；PCV20
    [ID: Rx-Vac-Shingrix] 帯状疱疹ワクチン（シングリックス）
    ・シングリックス筋注用 0.5mL 筋肉注射 ；2回接種（2ヶ月間隔）
    [ID: Rx-Vac-HPV9] HPVワクチン（シルガード9）
    ・シルガード9 0.5mL 筋肉注射 ；3回接種（0-2-6ヶ月）
    [ID: Rx-Vac-COVID] COVID-19ワクチン
    ・COVID-19ワクチン 最新推奨に準拠
    [ID: Rx-Vac-HepB] B型肝炎ワクチン
    ・ビームゲン 0.5mL 皮下注射 ；3回接種（0-1-6ヶ月）
    [ID: Rx-Vac-Tetanus] 破傷風トキソイド
    ・沈降破傷風トキソイド 0.5mL 皮下注射
    【緊急時対応】
    [ID: Rx-Emerg-Epi] アドレナリン筋注（アナフィラキシー対応）
    ・アドレナリン0.3mg 大腿外側に筋注 ；接種前に必ず準備

    ▼ 指導・計画 ▼
    ・再診目安: 次回接種スケジュールに応じて予約。
    ・接種記録をお薬手帳・接種記録カードに記載。
    ・接種後の副反応（発熱、局所腫脹等）について説明。重篤な副反応出現時は速やかに受診するよう指導。
    ・接種証明書が必要な場合は発行する。


▶ Dr.Advice [アナフィラキシー準備]: ワクチン接種時はアドレナリン0.3mg筋注の準備を必ず行え。
▶ Dr.Advice [シングリックス]: 50歳以上に推奨。2回接種（2ヶ月間隔）。帯状疱疹予防効果90%以上。
▶ Dr.Advice [肺炎球菌]: 65歳以上にニューモバックス。PCV15→1年以上後にPPSV23、またはPCV20単独投与を推奨（2024年度より定期接種化）。詳細は最新の厚労省通知を確認。
