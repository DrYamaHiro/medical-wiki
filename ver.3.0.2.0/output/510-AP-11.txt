[Z13.9] ヘルスメンテナンス（スクリーニング）(Health Maintenance Screening)

<A: 評価>:
    ・慢性疾患管理中の患者に対する包括的予防医療チェックリスト。

    ▼ がん検診 ▼
    ・大腸がん: 便潜血（年1回、40歳以上）→ 実施済 / 未 / 該当なし
    ・胃がん: 内視鏡 or X線（2年に1回、50歳以上）→ 実施済 / 未
    ・肺がん: 胸部X線（年1回）± 喀痰細胞診（BI 600以上）→ 実施済 / 未
    ・乳がん（女性）: マンモグラフィ（2年に1回、40歳以上）→ 実施済 / 未
    ・子宮頸がん（女性）: 細胞診（2年に1回、20歳以上）→ 実施済 / 未

    ▼ 骨密度 ▼
    ・骨密度検査: 閉経後女性、ステロイド使用者、骨折リスク因子あり → 実施済 / 未

    ▼ 感染症スクリーニング ▼
    ・B型肝炎（HBs抗原）: 未検 / 陰性 / 陽性
    ・C型肝炎（HCV抗体）: 未検 / 陰性 / 陽性
    ・梅毒（RPR/TP）: 未検 / 陰性 / 陽性
    ・HIV（同意取得の上）: 未検 / 陰性 / 陽性

    ▼ ワクチン接種状況 ▼
    ・インフルエンザ: 本年度 接種済 / 未
    ・肺炎球菌（65歳以上）: ニューモバックス 接種済 / 未
    ・帯状疱疹（50歳以上）: シングリックス 1回目 / 2回目 / 未
    ・COVID-19: 最終接種 ＿年＿月

    ▼ 生活習慣 ▼
    ・喫煙: 現喫煙 / 禁煙済 / 非喫煙 → TDS 5点以上なら禁煙治療推奨
    ・飲酒: AUDIT-C ＿点 → 高リスクなら減酒指導

<P: 方針>:
    ・チェックリストで不足分を抽出し、次回以降の検査計画を立てる。

    ▼ 処方・アクション ▼
    【がん検診オーダー】
    [ID: Rx-HC-HM-FOBT] 便潜血検査
    ・便潜血2日法 ；大腸がん検診（年1回、40歳以上）
    [ID: Rx-HC-HM-CXR] 胸部X線
    ・胸部X線（正面）；肺がん検診（年1回）
    [ID: Rx-HC-HM-Sputum] 喀痰細胞診
    ・喀痰細胞診 ；BI 600以上の喫煙者
    【感染症スクリーニング】
    [ID: Rx-HC-HM-HBsAg] HBs抗原
    ・HBs抗原（定性）；B型肝炎スクリーニング
    [ID: Rx-HC-HM-HCV] HCV抗体
    ・HCV抗体（定性）；C型肝炎スクリーニング
    [ID: Rx-HC-HM-Syphilis] 梅毒検査
    ・RPR定量, TP抗体 ；梅毒スクリーニング
    [ID: Rx-HC-HM-HIV] HIV検査
    ・HIV-1/2抗体（同意取得後）；HIVスクリーニング

    ▼ 指導・計画 ▼
    ・不足している検診項目を患者に説明し、受診勧奨。
    ・がん検診は自治体の助成制度を利用可能な場合がある旨を説明。
    ・ワクチン接種歴を確認し、未接種のものは接種計画を立てる。
    ・喫煙者: TDS 5点以上なら禁煙外来の適応。禁煙治療の説明を行う。
    ・飲酒: AUDIT-C高リスクなら減酒指導。必要に応じて肝機能検査を追加。
    ・再診目安: 次回定期受診時にチェックリストを更新。


▶ Dr.Advice [便潜血]: 大腸がん検診で最もエビデンスレベルの高い検診。受診率が低いため積極的に勧奨せよ。
▶ Dr.Advice [骨密度]: ステロイド5mg/日以上を3ヶ月以上使用する患者は必ず骨密度を測定せよ。
▶ Dr.Advice [B/C肝]: 一生に一度はスクリーニングを受けるべきとされている。特にC型肝炎はDAA治療でSVR 97%以上が見込める。
