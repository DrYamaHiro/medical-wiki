■ 2. CS Drug Reference（800: Drug Reference）新設・整備
================================================================

wiki内にコンテナ800として薬学辞書コンテンツを新設。
イオン薬局リーフシティ市川の採用薬580品目を基盤に、
18カテゴリ・325薬剤エントリを作成。

カテゴリ:
  RX-01 感染症治療薬      RX-02 解熱鎮痛薬
  RX-03 アレルギー        RX-04 呼吸器系
  RX-05 消化器系          RX-06 循環器系
  RX-07 抗血栓薬          RX-08 脂質・代謝
  RX-09 糖尿病治療薬      RX-10 内分泌
  RX-11 神経・精神科      RX-12 泌尿器
  RX-13 皮膚科            RX-14 眼科・耳鼻科
  RX-15 漢方薬            RX-16 ビタミン
  RX-17 ワクチン          RX-18 その他

各薬剤エントリの構成:
  - 見出し: 商品名（後発品名）/ 一般名（英語名）
  - 【薬理】作用機序・薬物動態
  - 【適応】保険適応・適応外使用
  - 【用法用量】成人/小児/腎機能/肝機能/高齢者
  - 【禁忌・注意】禁忌/慎重投与/相互作用/妊婦・授乳婦/副作用
  - 【処方のポイント】同効薬との使い分け等
  - 【CureStation テンプレートとの関連】正しいAP番号
  - 【調剤薬局での採用状況】
  - 【採用がない場合の代替案】

監査: 3ラウンド実施（CRITICAL 0 / MAJOR 0 / MINOR 0）

  - メトホルミンeGFR段階別制限の追記
  - トリプタン禁忌リスト追加
  - エムガルティ初回240mg修正
  - PCV13→PCV15/PCV20ワクチン更新
  - バルプロ酸催奇形性リスク（主要奇形6-11%）
  - 咳喘息にテリルジー追加
  - A-DROPスコア1/2分離、Wells DVT 2段階分類追加
