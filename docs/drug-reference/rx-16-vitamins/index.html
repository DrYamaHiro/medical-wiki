ビタミン・栄養素

CS Drug Reference

各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。

シナール（シーピー配合顆粒「東和」）/ アスコルビン酸・パントテン酸Ca配合錠/顆粒（ascorbic acid/calcium pantothenate）

商品名: シナール配合錠 / 後発: シーピー配合顆粒「東和」 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 錠剤 / 顆粒 1g/包 薬価: 6.40〜6.50円 薬品区分: 普通薬

薬理

  • ビタミンC（アスコルビン酸）＋ビタミンB5（パントテン酸Ca）配合剤
  • アスコルビン酸: コラーゲン合成促進・抗酸化・メラニン生成抑制
  • パントテン酸Ca: 補酵素CoAの構成成分、糖・脂質・蛋白質代謝に関与

適応

  • ビタミンC欠乏症の予防・治療
  • 炎症後色素沈着
  • 適応外: しみ・そばかすの改善

用法用量

  • 成人: 錠剤: 1回1〜3錠、1日1〜3回経口投与
  • 顆粒: 1回1包（1g）、1日1〜3回経口投与

禁忌・注意

  • 禁忌: 特になし
  • 副作用: 稀に胃部不快感、下痢（大量投与時）

処方のポイント

  • 色素沈着やしみに対して広く処方される
  • トラネキサム酸との併用が美白目的で一般的
  • ビタミンCは大量投与しても余剰分は尿中排泄される

CureStation テンプレートとの関連

  • 該当テンプレートなし（しみ・色素沈着の補助療法として使用）

調剤薬局での採用状況

  • 採用: あり（先発 シナール配合錠 + 後発 シーピー配合顆粒「東和」1g/包）
  • 備考: なし

採用がない場合の代替案

  • 汎用品のため在庫切れの可能性は低い。薬局での取り寄せ: 翌日入荷可能
ユベラN（トコフェロールニコチン酸エステルカプセル「サワイ」等）/ トコフェロールニコチン酸エステル（tocopherol nicotinate）

商品名: ユベラNカプセル / 後発: トコフェロールニコチン酸エステルカプセル「サワイ」/ ユベラNソフトカプセル カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: カプセル 100mg / 200mg 薬価: 6.10〜7.50円 薬品区分: 普通薬

薬理

  • ビタミンE誘導体（血行改善薬）
  • 末梢血管を拡張し血流を改善
  • 脂質代謝を改善
  • 抗酸化作用

適応

  • 高脂血症
  • 閉塞性動脈硬化症に伴う末梢循環障害

用法用量

  • 成人: 1回100〜200mgを1日3回経口投与

禁忌・注意

  • 禁忌: 特になし
  • 副作用: 稀に胃部不快感

処方のポイント

  • しもやけ（凍瘡）、末梢循環障害に使用
  • しみ・そばかすにはシナール＋トラネキサム酸との併用も

CureStation テンプレートとの関連

  • 該当テンプレートなし（末梢循環障害の補助療法として使用）

調剤薬局での採用状況

  • 採用: あり（先発 ユベラNカプセル100mg + ユベラNソフトカプセル200mg + 後発200mg「サワイ」）
  • 備考: なし

採用がない場合の代替案

  • 汎用品のため在庫切れの可能性は低い。薬局での取り寄せ: 翌日入荷可能
メチコバール（メコバラミン錠「トーワ」）/ メコバラミン（mecobalamin）

商品名: メチコバール錠 / 後発: メコバラミン錠「トーワ」 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 錠剤 0.25mg / 0.5mg 薬価: 5.90〜10.40円 薬品区分: 普通薬

薬理

  • 活性型ビタミンB12製剤
  • メチル基転移反応の補酵素として核酸・蛋白・脂質代謝に関与
  • 傷害された末梢神経の修復を促進

適応

  • 末梢性神経障害（糖尿病性神経障害、帯状疱疹後神経痛等）

用法用量

  • 成人: 1回0.5mg（0.5mg錠1錠又は0.25mg錠2錠）、1日3回 毎食後経口投与

禁忌・注意

  • 禁忌: 特になし
  • 副作用: 稀に発疹、食欲不振

処方のポイント

  • 末梢神経障害に対する基本的なビタミン補充療法
  • 即効性はなく、長期投与で効果を判定
  • ビタメジン配合カプセル（B1+B6+B12）としても処方可能

CureStation テンプレートとの関連

  • 100-AP-06（糖尿病性神経障害）
  • 210-AP-01（帯状疱疹）: 帯状疱疹後神経痛

調剤薬局での採用状況

  • 採用: あり（先発 メチコバール錠250μg/500μg + 後発 メコバラミン錠500「トーワ」）
  • 備考: 0.5mg錠は在庫潤沢

採用がない場合の代替案

  • 同効代替薬: ビタメジン配合カプセルB50（在庫あり）。B1+B6+B12を一度に補充できる
フォリアミン / 葉酸（folic acid）

商品名: フォリアミン錠 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 錠剤 5mg 薬価: 10.10円 薬品区分: 普通薬

薬理

  • ビタミンB群（葉酸製剤）
  • DNA合成に必要な補酵素として造血を促進

適応

  • 葉酸欠乏症（巨赤芽球性貧血等）
  • 葉酸の需要増大（妊婦、悪性腫瘍）
  • MTX投与時の副作用軽減（レスキュー）

用法用量

  • 成人: 1日5〜20mgを2〜3回に分割経口投与
  • MTX療法のレスキュー: 投与スケジュールに従う

禁忌・注意

  • 禁忌: 特になし
  • 副作用: 稀に食欲不振、悪心

処方のポイント

  • MTX（メトトレキサート）投与時の葉酸補充として最も多く処方される
  • 関節リウマチのMTX療法ではMTX投与翌日〜2日後に葉酸5mgを補充するのが一般的
  • 妊娠計画中の女性への葉酸補充（先天性神経管閉鎖障害の予防）

CureStation テンプレートとの関連

  • 140-AP-01（関節リウマチ）

調剤薬局での採用状況

  • 採用: あり（フォリアミン錠5mg）
  • 備考: なし

採用がない場合の代替案

  • 薬局での取り寄せ: 汎用品のため翌日入荷可能
フェロミア（クエン酸第一鉄Na錠「サワイ」）/ クエン酸第一鉄ナトリウム錠（sodium ferrous citrate）

商品名: フェロミア錠 / 後発: クエン酸第一鉄Na錠「サワイ」 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 錠剤 50mg（鉄として） 薬価: 6.10〜6.20円 薬品区分: 普通薬

薬理

  • 鉄欠乏性貧血治療薬
  • 二価鉄（Fe2+）として消化管から吸収され、ヘモグロビン合成に利用

適応

  • 鉄欠乏性貧血

用法用量

  • 成人: 1回100〜200mg（鉄として）、1日1〜2回に分割、食後に経口投与（1日2〜4錠）

禁忌・注意

  • 禁忌: 鉄欠乏状態にない患者
  • 注意: テトラサイクリン系・ニューキノロン系抗菌薬とは2時間以上間隔をあける（キレート形成）
  • 副作用: 悪心、嘔吐、食欲不振、便秘・下痢、便の黒色化

処方のポイント

  • 鉄欠乏性貧血の標準治療。Hb回復後も貯蔵鉄を補充するため3〜6ヶ月継続
  • 消化器症状が問題の場合はインクレミンシロップ（溶性ピロリン酸第二鉄）に変更
  • ビタミンC（シナール等）との併用で鉄の吸収率が向上

CureStation テンプレートとの関連

  • 320-AP-01（鉄欠乏性貧血）

調剤薬局での採用状況

  • 採用: あり（先発 フェロミア錠50mg + 後発 クエン酸第一鉄Na錠50mg「サワイ」）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: インクレミンシロップ5%（在庫あり、特に小児に適する）
インクレミン / 溶性ピロリン酸第二鉄シロップ（ferric pyrophosphate）

商品名: インクレミンシロップ カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: シロップ 5%（調剤用250mL） 薬価: 6.40円/mL 薬品区分: 普通薬

薬理

  • 鉄欠乏性貧血治療薬（経口鉄剤・シロップ製剤）
  • 2価鉄として消化管から吸収されヘモグロビン合成に利用

適応

  • 鉄欠乏性貧血

用法用量

  • 成人: 1日12〜24mL（鉄として72〜144mg）を2〜3回に分割、食後に経口投与
  • 小児: 体重に応じて適宜減量

禁忌・注意

  • 禁忌: 鉄欠乏状態にない患者
  • 注意: テトラサイクリン系・ニューキノロン系抗菌薬とは2時間以上間隔をあける（キレート形成による吸収低下）
  • 制酸薬（PPI等）との併用で鉄の吸収が低下する可能性
  • 副作用: 悪心、嘔吐、食欲不振、便の黒色化

処方のポイント

  • 小児にも使いやすい液剤
  • 錠剤（フェロミア等）で消化器症状が強い場合の代替
  • シロップのため用量調節が容易

CureStation テンプレートとの関連

  • 320-AP-01（鉄欠乏性貧血）

調剤薬局での採用状況

  • 採用: あり（後発 インクレミンシロップ5% 調剤用250mL）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: フェロミア錠50mg（在庫あり）。錠剤が服用可能であれば代替可
ハイチオール / L-システイン（L-cysteine）

商品名: ハイチオール錠80 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 錠剤 80mg 薬価: 5.90円（後発） 薬品区分: 普通薬

薬理

  • アミノ酸製剤
  • 皮膚の代謝を正常化し、メラニン色素の生成を抑制・排出を促進

適応

  • 湿疹、蕁麻疹、薬疹、中毒疹、尋常性ざ瘡、多形滲出性紅斑

禁忌・注意

  • 禁忌: 特になし
  • 副作用: 稀に悪心、下痢

処方のポイント

  • しみ治療でシナール（VitC）・トラネキサム酸との3剤併用が多い
  • 二日酔い（アセトアルデヒド代謝促進）にも有効

  • 備考: なし

採用がない場合の代替案

  • 薬局での取り寄せ: 翌日入荷可能
  • しみ治療目的であればシナール＋トラネキサム酸の2剤でも対応可

ビタメジン / ベンフォチアミン・B6・B12配合カプセル（benfotiamine/B6/B12）

商品名: ビタメジン配合カプセルB50 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: カプセル 薬価: 6.10円 薬品区分: 普通薬

薬理

  • ビタミンB群配合剤
  • ベンフォチアミン（活性型B1）・ピリドキシン（B6）・シアノコバラミン（B12）を配合

適応

  • ビタミンB群欠乏に伴う神経障害、筋肉痛、関節痛、末梢神経炎、眼精疲労等

用法用量

  • 成人: 1回1カプセル、1日1〜3回経口投与

禁忌・注意

  • 禁忌: 特になし
  • 相互作用: ピリドキシン（B6）含有のためレボドパの作用を減弱させる（DCI非併用時）。レボドパ単剤服用中の患者には使用を避ける（レボドパ/DCI配合剤との併用は問題なし）
  • 副作用: 稀に発疹、悪心

処方のポイント

  • B1+B6+B12の3種を一度に補充できる簡便性
  • 末梢神経障害にメコバラミン単剤で不十分な場合に選択

CureStation テンプレートとの関連

  • 100-AP-06（糖尿病性神経障害）

調剤薬局での採用状況

  • 採用: あり（ビタメジン配合カプセルB50）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: メコバラミン錠（在庫あり）+ アリナミンF錠（在庫あり）で個別補充可
ピリドキサール（ピリドキサール錠「ツルハラ」）/ ピリドキサールリン酸エステル錠（pyridoxal phosphate）

商品名: ピリドキサール錠 / 後発: ピリドキサール錠「ツルハラ」 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 錠剤 30mg 薬価: 5.90円（後発） 薬品区分: 普通薬

薬理

  • 活性型ビタミンB6製剤
  • 補酵素としてアミノ酸代謝に関与

適応

  • ビタミンB6欠乏症
  • ビタミンB6の需要増大（口内炎、湿疹等）

用法用量

  • 成人: 1日60〜120mgを2〜3回に分割経口投与

禁忌・注意

  • 禁忌: 特になし
  • 相互作用: B6含有のためレボドパの作用を減弱させる（DCI非併用時）。レボドパ単剤服用中の患者には使用を避ける（レボドパ/DCI配合剤との併用は問題なし）
  • 副作用: 稀に悪心、食欲不振

処方のポイント

  • 口内炎・口角炎・湿疹に対するビタミンB6補充
  • ビフロキシン配合錠（B2+B6）との使い分け

CureStation テンプレートとの関連

  • 該当テンプレートなし（口内炎・皮膚炎の補助療法として使用）

調剤薬局での採用状況

  • 採用: あり（後発 ピリドキサール錠30mg「ツルハラ」）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: ビフロキシン配合錠（在庫あり）。B2+B6配合で口内炎にも有効
ビフロキシン / リボフラビン・ピリドキシン配合錠（riboflavin/pyridoxine）

商品名: ビフロキシン配合錠 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: 配合錠 薬価: 6.10円 薬品区分: 普通薬

薬理

  • ビタミンB2（リボフラビン）＋B6（ピリドキシン）配合剤
  • B2: 脂質代謝、皮膚・粘膜の健康維持
  • B6: アミノ酸代謝

適応

  • B2・B6需要が増大し食事からの摂取が不十分な場合の補給
  • 湿疹、口角炎、口内炎、舌炎、脂漏性皮膚炎等

用法用量

  • 成人: 1回1〜2錠、1日1〜3回経口投与

禁忌・注意

  • 禁忌: 特になし
  • 相互作用: ピリドキシン（B6）含有のためレボドパの作用を減弱させる（DCI非併用時）。レボドパ単剤服用中の患者には使用を避ける
  • 副作用: 稀に悪心、食欲不振

処方のポイント

  • 口角炎・口内炎の基本的ビタミン補充
  • 尿が黄色くなることを患者に説明（B2の色）

CureStation テンプレートとの関連

  • 該当テンプレートなし（口内炎・皮膚炎の補助療法として使用）

  • 備考: なし

  • 同効代替薬: ピリドキサール錠（在庫あり）でB6を単独補充可。B2が必要な場合は薬局での取り寄せ: 翌日入荷可能
デノタス / 沈降炭酸カルシウム・コレカルシフェロール・炭酸マグネシウム配合錠（Ca/VitD3/Mg）

商品名: デノタスチュアブル配合錠 カテゴリ: RX-16 ビタミン・栄養素 剤型・規格: チュアブル錠 薬価: 11.30円 薬品区分: 普通薬

薬理

  • カルシウム・ビタミンD3・マグネシウム配合製剤
  • デノスマブ（プラリア）等の骨吸収抑制薬投与時の低Ca血症予防

適応

  • 骨粗鬆症治療薬使用時のCa・VitD・Mg補充

用法用量

  • 成人: 1日2錠を1日1回又は2回に分割経口投与
  • 噛み砕くか口中で溶かして服用

禁忌・注意

  • 禁忌: 高Ca血症、腎性骨異栄養症を伴わない重篤な腎不全
  • 相互作用: ジギタリス製剤（ジゴキシン等）→ Ca補充により高Ca血症を来すとジギタリスの作用増強・不整脈リスク
  • テトラサイクリン系・NQ系抗菌薬 → Caとのキレート形成（2時間以上間隔をあける）
  • 副作用: 便秘、高Ca血症（長期大量投与時）

処方のポイント

  • デノスマブ（プラリア）やゾレドロン酸使用時に必須の補充薬
  • チュアブル錠で服用しやすい
  • Ca単独のアスパラCa等とは異なり、VitD3・Mgも配合

CureStation テンプレートとの関連

  • 140-AP-05（骨粗鬆症）

調剤薬局での採用状況

  • 採用: あり（デノタスチュアブル配合錠）
  • 備考: なし

採用がない場合の代替案

  • 薬局での取り寄せ: 翌日入荷可能
