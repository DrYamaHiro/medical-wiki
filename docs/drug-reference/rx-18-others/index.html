CS Drug Reference

各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。

グリセリン浣腸液「ケンエー」/ グリセリン浣腸液（glycerin enema）

商品名: グリセリン浣腸液50%「ケンエー」 カテゴリ: RX-18 その他 剤型・規格: 浣腸液 50% 30mL / 60mL 薬価: 110.10円（30mL）/ 131.70円（60mL） 薬品区分: 普通薬

薬理

  • 浸透圧性下剤（浣腸）
  • 腸管内に水分を引き込み腸蠕動を促進して排便を誘発
  • 直腸粘膜への刺激作用も排便反射を惹起

適応

  • 便秘症、腸疾患時の排便、術前処置等

用法用量

  • 成人: 1回30〜60mLを直腸内に注入
  • 小児: 1回10〜30mL
  • 体温程度に温めて使用

禁忌・注意

  • 禁忌: 腸管穿孔のおそれのある患者、全身衰弱の強い患者
  • 注意: 頻回使用で直腸粘膜刺激 → 習慣性に注意
  • 副作用: 腹痛、不快感

処方のポイント

  • 便秘の緊急対応（頓用）
  • 習慣的使用は避け、経口下剤の調整が基本
  • 高齢者では迷走神経反射による徐脈・血圧低下に注意

CureStation テンプレートとの関連

  • 050-AP-05（便秘症）

  • 採用: あり（グリセリン浣腸液50%「ケンエー」30mL + 60mL）
  • 備考: なし

採用がない場合の代替案

  • 汎用品のため在庫切れの可能性は低い。薬局での取り寄せ: 翌日入荷可能

商品名: 消毒用エタノール「マルイシ」 カテゴリ: RX-18 その他 剤型・規格: 外用液（調剤用1,000mL） 薬価: 1.87円/mL 薬品区分: 普通薬

薬理

  • 外用殺菌消毒薬

  • 注意: 損傷皮膚・粘膜への使用は避ける（刺激が強い）。引火性あり

  • 創傷面への消毒にはポビドンヨードの方が適する場合もある

炭酸水素ナトリウム「VTRS」/ 炭酸水素ナトリウム（sodium bicarbonate）

商品名: 炭酸水素ナトリウム「VTRS」原末 カテゴリ: RX-18 その他 剤型・規格: 原末（バラ500g） 薬価: 0.77円/g 薬品区分: 普通薬

薬理

  • 制酸薬・アルカリ化薬
  • 胃酸を中和し制酸作用を示す
  • 尿のアルカリ化により痛風等で尿酸結石を予防

適応

  • 胃・十二指腸潰瘍の制酸
  • アシドーシスの補正
  • 尿酸排泄促進

用法用量

  • 成人: 制酸薬として1回1〜2gを1日数回経口投与

禁忌・注意

  • 注意: 大量投与でアルカローシス。Na負荷（心不全、高血圧、腎不全に注意）
  • 副作用: 膨満感（CO2発生）、高Na血症

処方のポイント

  • 制酸薬としてはPPI/P-CABが主流であり、使用頻度は低い
  • 尿アルカリ化にはクエンメット配合錠の方が使いやすい

クレメジン（球形吸着炭細粒分包「日医工」）/ 球形吸着炭細粒（spherical carbon adsorbent）

商品名: クレメジン細粒分包 / 後発: 球形吸着炭細粒分包「日医工」 カテゴリ: RX-18 その他 剤型・規格: 細粒分包 2g/包 薬価: 74.90円/包 薬品区分: 普通薬

薬理

  • 経口吸着薬
  • 消化管内で尿毒症毒素（インドール等の前駆物質）を吸着し便中に排泄

適応

  • 慢性腎不全（進行性）における尿毒症症状の改善及び透析導入の遅延

用法用量

  • 成人: 1日6g（2g x 3包）を3回に分割、食間に経口投与
  • 他の薬剤と同時服用を避ける（吸着して効果を減弱させる）

禁忌・注意

  • 禁忌: 消化管通過障害
  • 注意: 便秘（炭による）、他剤との同時投与を避ける（2時間以上間隔をあける）
  • 副作用: 便秘、食欲不振

処方のポイント

  • CKD（慢性腎臓病）の保存的治療薬
  • 他の薬剤との服用間隔（2時間以上）の確保が重要
  • 便の黒色化は正常

CureStation テンプレートとの関連

プロマック（ポラプレジンクOD錠「サワイ」）/ ポラプレジンク錠/顆粒（polaprezinc）

商品名: プロマック顆粒 / 後発: ポラプレジンクOD錠「サワイ」 カテゴリ: RX-18 その他 剤型・規格: OD錠 75mg / 顆粒 15% 0.5g/包 薬価: 14.30〜30.00円 薬品区分: 普通薬

薬理

  • 亜鉛含有胃潰瘍治療薬
  • 亜鉛とL-カルノシンのキレート化合物
  • 胃粘膜保護・抗酸化作用・創傷治癒促進作用
  • 亜鉛含有量: 75mg中 亜鉛約17mg（1日150mg中 約34mg）

適応

  • 胃潰瘍
  • 適応外: 低亜鉛血症の治療にも使用される場合がある

  • 成人: 1回75mg、1日2回 朝食後・就寝前経口投与

禁忌・注意

  • 注意: 銅欠乏症（長期亜鉛投与で銅の吸収が阻害される）
  • 副作用: 稀に便秘、腹部膨満感

処方のポイント

  • 胃潰瘍治療薬だが、亜鉛補充目的でも使用される
  • 低亜鉛血症にはノベルジンが正式適応だが、ソースデータにノベルジンの記載なし
  • 味覚障害（亜鉛欠乏による）にも処方されることがある

CureStation テンプレートとの関連

調剤薬局での採用状況

  • 採用: あり（先発 プロマック顆粒15% 0.5g/包 + 後発 ポラプレジンクOD錠75mg「サワイ」）
  • 備考: ノベルジン（酢酸亜鉛）はソースデータに記載なし

採用がない場合の代替案

  • 薬局での取り寄せ: 翌日入荷可能
ポララミン / d-クロルフェニラミンマレイン酸塩錠（d-chlorpheniramine）

商品名: ポララミン錠 カテゴリ: RX-18 その他 剤型・規格: 錠剤 2mg 薬価: 5.90円 薬品区分: 普通薬

薬理

  • 第一世代抗ヒスタミン薬
  • H1受容体を拮抗しアレルギー反応を抑制
  • 中枢移行性が高く眠気が強い

適応

  • 蕁麻疹、アレルギー性鼻炎、皮膚疾患に伴う掻痒

用法用量

  • 成人: 1回2mg、1日1〜4回経口投与
  • 小児: 年齢に応じ減量。眠気が強いため就寝前投与も有用

禁忌・注意

  • 禁忌: 緑内障、前立腺肥大による排尿障害、下部尿路閉塞性疾患
  • 注意: 中枢抑制作用が強い → 自動車の運転等危険を伴う機械の操作に従事させないこと（運転禁止）
  • 相互作用: 中枢神経抑制薬（睡眠薬、抗不安薬等）、MAO阻害薬、アルコール → 相互に作用増強
  • 副作用: 眠気（高頻度）、口渇、排尿困難

処方のポイント

  • 第二世代抗ヒスタミン薬が主流だが、即効性の抗ヒスタミン作用が必要な場合に使用
  • 鎮静作用を利用して掻痒による不眠に就寝前投与
  • PL配合顆粒に含まれるプロメタジンと同系統

CureStation テンプレートとの関連

  • 040-AP-01（花粉症）
  • 200-AP-03（蕁麻疹）

調剤薬局での採用状況

  • 採用: あり（ポララミン錠2mg）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: 第二世代抗ヒスタミン薬（ロラタジン、フェキソフェナジン等、在庫あり）への変更を検討。ただし即効性・鎮静作用が必要な場合はPL配合顆粒（在庫あり）で代替可
PL配合顆粒（non-pyrin cold remedy）

商品名: PL配合顆粒 カテゴリ: RX-18 その他 剤型・規格: 顆粒 1g/包 薬価: 6.70円/包 薬品区分: 普通薬

薬理

  • 非ピリン系総合感冒薬
  • サリチルアミド＋アセトアミノフェン（解熱鎮痛）
  • プロメタジン（抗ヒスタミン・鎮静）
  • カフェイン（鎮痛補助）の4成分配合

適応

  • 感冒の諸症状（鼻汁、鼻閉、咽頭痛、頭痛、発熱等）の緩和

用法用量

  • 成人: 1回1g、1日4回 毎食後および就寝前経口投与

禁忌・注意

  • 禁忌: サリチル酸系過敏症、消化性潰瘍
  • 注意: 眠気が強い（プロメタジン含有）→ 運転禁止
  • 副作用: 眠気、口渇

処方のポイント

  • 風邪の対症療法として広く処方される
  • 眠気が強いため就寝前の投与が適する
  • インフルエンザの小児にはサリチルアミド含有のため避ける（Reye症候群のリスク）

CureStation テンプレートとの関連

  • 010-AP-01〜03（急性上気道炎）

調剤薬局での採用状況

  • 採用: あり（PL配合顆粒1g/包）
  • 備考: なし

採用がない場合の代替案

  • 汎用品のため在庫切れの可能性は低い。薬局での取り寄せ: 翌日入荷可能
