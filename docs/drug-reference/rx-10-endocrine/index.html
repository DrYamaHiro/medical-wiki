チラーヂンS（後発品なし）/ レボチロキシン（levothyroxine）

商品名: チラーヂンS カテゴリ: RX-10 内分泌・甲状腺 剤型・規格: 錠 25μg / 50μg 薬価: 10.40円（25μg / 50μg いずれも同額） 薬品区分: 劇薬

薬理

  • 合成甲状腺ホルモン（T4）製剤
  • 体内でT3に変換され、甲状腺ホルモンとしての作用を発揮する
  • 基礎代謝の亢進、蛋白合成促進、成長発育の促進
  • 経口投与後の生体利用率: 約50-80%（空腹時に高い）
  • T1/2 約7日（長い）→ 定常状態到達に4-6週間

適応

  • 甲状腺機能低下症
  • 粘液水腫
  • クレチン症
  • 甲状腺腫

用法用量

  • 成人: 1日25-100μgから開始、1日1回 朝食前（空腹時）に経口投与
  • 維持量: 1日100-150μg（TSH正常化を目標に用量調整）
  • 高齢者・虚血性心疾患合併: 12.5-25μgから開始し、4-6週ごとに漸増
  • 小児（クレチン症）: 初期量は年齢・体重により異なる（添付文書を参照）
  • 腎機能低下時: 用量調整不要

禁忌・注意

  • 禁忌: 新鮮な心筋梗塞（相対的禁忌、心臓に対する負荷増大）
  • 慎重投与: 虚血性心疾患、副腎不全（コルチゾール補充なしにレボチロキシンを開始すると副腎クリーゼを誘発する恐れ）、糖尿病
  • 相互作用:
    • 鉄剤、カルシウム製剤、制酸薬 → レボチロキシン吸収低下（4時間以上間隔をあける）
    • ワルファリン → 抗凝固作用増強
    • リファンピシン → レボチロキシン代謝促進
    • コレスチラミン → レボチロキシン吸収阻害
  • 妊婦: 投与継続（甲状腺機能低下は胎児に有害。妊娠中はTSH目標値がやや低め）
  • 授乳婦: 使用可
  • 副作用:
    • 過量投与: 動悸、頻脈、発汗、体重減少、振戦（甲状腺中毒症状）
    • 適切な用量では副作用はほぼない

処方のポイント

  • 甲状腺機能低下症の標準治療薬
  • TSHを4-6週ごとにモニタリングし用量調整（目標TSH: 0.5-2.5 mU/L が一般的）
  • 空腹時服用が吸収に最適（起床時、朝食30分前）
  • 鉄剤・Ca剤との同時服用を避ける指導が重要
  • 安定後は6-12ヶ月ごとのTSHチェックで十分
  • 副腎不全合併が疑われる場合は、コルチゾール補充を先行させてからレボチロキシンを開始

メルカゾール（後発品なし）/ チアマゾール（thiamazole）

商品名: メルカゾール カテゴリ: RX-10 内分泌・甲状腺 剤型・規格: 錠 5mg 薬価: 10.10円 薬品区分: 普通薬

薬理

  • 抗甲状腺薬（チオアミド系）
  • 甲状腺ペルオキシダーゼを阻害しヨウ素の有機化・カップリング反応を抑制して甲状腺ホルモン合成を減少させる
  • 既存の甲状腺ホルモンの放出には影響しない → 効果発現に2-4週間
  • 肝代謝、T1/2 約4-6時間（ただし甲状腺内での作用は持続的）

適応

  • 甲状腺機能亢進症（バセドウ病）

用法用量

  • 初期量: 1日15-30mg 3-4回に分割経口投与
  • 症状安定後: 1日5-10mgに漸減し維持
  • 維持量決定後は分1でも可
  • 小児: 初期量0.5mg/kg/日、維持量0.25mg/kg/日（添付文書を参照）
  • 腎機能低下時: 用量調整不要
  • 妊婦: 妊娠初期はプロピルチオウラシル（PTU）への切替が推奨（チアマゾール初期奇形のリスク）。妊娠中期以降はチアマゾールに戻すことが多い

禁忌・注意

  • 禁忌: 本剤過敏症
  • 慎重投与: 肝障害、白血球減少傾向
  • 妊婦: 妊娠初期はPTUへ切替推奨（チアマゾール胎芽病リスク: 頭皮欠損症、後鼻孔閉鎖、食道閉鎖等の初期奇形）。妊娠中期以降はチアマゾールに戻すことが多い
  • 相互作用:
    • ワルファリン → 甲状腺機能改善に伴い抗凝固作用が変動
    • ジゴキシン → 甲状腺機能改善に伴い血中濃度が変動
  • 副作用:
    • 重大: 無顆粒球症（0.2-0.5%、投与開始2-3ヶ月以内に多い → 定期的血液検査。咽頭痛・発熱時は直ちに受診するよう指導）、重篤な肝障害、ANCA関連血管炎（長期投与時）
    • 頻度高: 皮疹（5-10%）、関節痛、消化器症状

処方のポイント

  • バセドウ病の薬物療法の第一選択
  • 無顆粒球症の早期発見: 投与開始後3ヶ月間は2週ごとの白血球分画検査を推奨
  • 患者指導: 発熱・咽頭痛があれば直ちに受診（無顆粒球症のサイン）
  • 寛解率: 長期投与（1.5-2年）後に約30-50%が寛解
  • PTUと比較: チアマゾールの方が効力が強く、副作用（特に肝障害）が少ない → 第一選択

プロパジール / プロピルチオウラシル〔PTU〕（propylthiouracil）【ソースリスト非採用】

商品名: プロパジール、チウラジール カテゴリ: RX-10 内分泌・甲状腺 剤型・規格: 錠 50mg 薬価: 添付文書を参照 薬品区分: 普通薬

薬理

  • 抗甲状腺薬（チオアミド系）
  • 甲状腺ペルオキシダーゼを阻害し甲状腺ホルモン合成を抑制
  • チアマゾールと異なり、末梢でのT4→T3変換も阻害する
  • チアマゾールの約1/10の効力
  • T1/2 約1-2時間（短い）→ 1日3回投与が必要

適応

  • 甲状腺機能亢進症

用法用量

  • 成人: 初期量1日300mg 3回に分割経口投与。維持量1日50-100mg
  • 妊婦: 妊娠初期のバセドウ病ではPTUが推奨される（チアマゾール初期奇形回避）
  • 腎機能低下時: 添付文書を参照
  • 小児: 添付文書を参照

禁忌・注意

  • 禁忌: 本剤過敏症
  • 慎重投与: 肝障害
  • 相互作用: チアマゾールと同様
  • 授乳婦: 使用可（乳汁移行は少量。授乳中の甲状腺機能亢進症にはPTUが推奨される）
  • 副作用:
    • 重大: 無顆粒球症、重篤な肝障害（チアマゾールより肝障害リスクが高い）、ANCA関連血管炎
    • 頻度高: 皮疹、関節痛

処方のポイント

  • チアマゾールの副作用（皮疹等）で継続困難な場合の代替薬
  • 妊娠初期のバセドウ病: PTUが推奨（チアマゾールの頭皮欠損症等の初期奇形リスク）
  • 甲状腺クリーゼ: T4→T3変換阻害作用があるため急性期に有利

フォサマック（アレンドロン酸錠「サワイ」等）/ アレンドロン酸（alendronate）

商品名: フォサマック、ボナロン / 後発: アレンドロン酸錠「サワイ」 カテゴリ: RX-10 骨粗鬆症 剤型・規格: 錠 35mg（週1回製剤） 薬価: 99.20円（後発35mg） 薬品区分: 劇薬

薬理

  • ビスホスホネート系骨粗鬆症治療薬
  • 骨のハイドロキシアパタイトに結合し、破骨細胞のファルネシルピロリン酸合成酵素を阻害して骨吸収を抑制する
  • 週1回製剤で服薬コンプライアンス向上
  • 経口生体利用率: 約0.7%（極めて低い）→ 空腹時・十分な水での服用が必須
  • 骨中T1/2: 約10年

適応

  • 骨粗鬆症

用法用量

  • 成人: 1回35mg 週1回 起床時に十分量（約180mL）の水で経口投与
  • 服用後少なくとも30分は横にならず、飲食および他の薬剤の服用も避ける（食道刺激予防・吸収阻害防止）
  • 腎機能低下時: 重度腎障害（CCr < 35）では推奨されない
  • 小児: 適応なし

禁忌・注意

  • 禁忌: 食道狭窄等の食道通過障害、起立不能（30分以上坐位を保てない）、低Ca血症、本剤過敏症
  • 慎重投与: 上部消化管障害の既往、腎障害
  • 相互作用:
    • カルシウム剤・制酸薬・鉄剤 → 吸収低下（同時服用を避ける。少なくとも30分以上の間隔）
    • NSAIDs → 消化管障害リスク増大
  • 副作用:
    • 重大: 食道炎・食道潰瘍（服薬方法を守らない場合）、顎骨壊死（ONJ、長期使用時・歯科処置後）、非定型大腿骨骨折（長期使用時）
    • 頻度高: 消化器症状（腹痛、悪心、便秘）、筋骨格痛

処方のポイント

  • 骨粗鬆症治療の第一選択薬クラス（ビスホスホネート）
  • 服薬方法が厳密: 起床時・空腹・十分な水・30分間坐位/立位 → 患者指導が極めて重要
  • 歯科処置前の休薬: 侵襲的歯科処置予定の3ヶ月前から休薬を推奨するガイドラインあり
  • 治療期間: 3-5年で休薬検討（drug holiday）。高リスク例は継続
  • ビタミンD・Ca補充を併用（デノタスチュアブル配合錠等）

    • NSAIDs → 消化管潰瘍リスク増大
    • リファンピシン、フェニトイン等のCYP3A4誘導薬 → ステロイド代謝促進
    • ワルファリン → 作用増強の可能性
    • 糖尿病治療薬 → 血糖上昇による効果減弱
  • 副作用（長期投与時）:
    • 重大: 感染症増悪、消化管穿孔、副腎不全（急な中止時）
    • 頻度高: 満月様顔貌、体重増加、骨粗鬆症、糖尿病、高血圧、白内障、緑内障、不眠、易感染性、皮膚萎縮

処方のポイント

  • 副腎不全の補充療法: ヒドロコルチゾンが生理的だが、プレドニゾロン5mg（≒ヒドロコルチゾン20mg）で代用可
  • 漸減プロトコル: 長期投与後の急な中止は副腎クリーゼを誘発 → 漸減が必須
  • ステロイド性骨粗鬆症予防: PSL 5mg/日以上を3ヶ月以上使用する場合はビスホスホネート開始を推奨（ACR/日本骨粗鬆症学会ガイドライン）
  • 朝投与が生理的リズムに合致（副腎抑制を最小限にする）
  • 1mg錠は微量調整（漸減時）に有用

CureStation テンプレートとの関連

  • 110-AP-05（副腎不全）: Rx-Adrenal-PSL
  • 多数のテンプレートで使用

調剤薬局での採用状況

  • 採用: あり（プレドニゾロン錠1mg（旭化成）、プレドニン錠5mg）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: デキサメタゾン、ベタメタゾン等（本薬局の採用状況を確認）
デノタスチュアブル配合錠（後発品なし）/ 沈降炭酸Ca・コレカルシフェロール・炭酸Mg（Ca / cholecalciferol / Mg）

商品名: デノタスチュアブル配合錠 カテゴリ: RX-10 骨粗鬆症・カルシウム製剤 剤型・規格: 配合錠（沈降炭酸Ca 762.5mg〔Ca 305mg〕+ コレカルシフェロール 200IU + 炭酸Mg 30mg） 薬価: 11.30円 薬品区分: 普通薬

薬理

  • Ca・ビタミンD3・Mg配合製剤
  • デノスマブ（プラリア）等の骨吸収抑制薬投与時の低Ca血症予防のため、カルシウム・ビタミンD・マグネシウムを補充する
  • ビタミンD3（コレカルシフェロール）は腸管からのCa吸収を促進

適応

  • 骨粗鬆症治療薬使用時の補助（低Ca血症予防）

用法用量

  • 成人: 1日2錠 1日1回又は2回に分割し経口投与
  • 噛み砕くか口中で溶かして服用（チュアブル錠）
  • 腎機能低下時: 高Ca血症・高Mg血症に注意

禁忌・注意

  • 禁忌: 高Ca血症
  • 慎重投与: 腎障害、高Ca尿症
  • 相互作用:
    • テトラサイクリン系・ニューキノロン系抗菌薬 → Ca がキレート形成し吸収低下
    • レボチロキシン → Ca がレボチロキシンの吸収を阻害（4時間以上間隔をあける）
    • 活性型ビタミンD製剤（アルファカルシドール等）→ 高Ca血症リスク増大に注意
  • 副作用:
    • 頻度高: 便秘、消化器症状

処方のポイント

  • デノスマブ使用時には必ず併用する（低Ca血症予防）
  • ビスホスホネート使用時にもCa・VitD補充として使用可
  • レボチロキシンやキノロン系との服用間隔に注意（少なくとも4時間）
  • チュアブル錠のため嚥下困難な高齢者にも使いやすい

CureStation テンプレートとの関連

  • 240-AP-01（骨粗鬆症）: デノスマブ投与時に必須併用

調剤薬局での採用状況

  • 採用: あり（デノタスチュアブル配合錠）
  • 備考: なし

採用がない場合の代替案

  • 同一成分別規格: 該当なし
  • 同効代替: Ca製剤（L-アスパラギン酸カルシウム等）+ ビタミンD製剤の個別投与で対応可能だが、一包化のメリットが失われる
