タケプロン（ランソプラゾールOD錠「トーワ」等）/ ランソプラゾール（lansoprazole）

商品名: タケプロン / 後発: ランソプラゾールOD錠「トーワ」他 カテゴリ: RX-05 消化器系 剤型・規格: OD錠 15mg / 30mg 薬価: 添付文書を参照（後発品） 薬品区分: 普通薬

薬理

  • プロトンポンプ阻害薬（PPI）
  • 胃壁細胞のH+/K+-ATPaseを不可逆的に阻害し、強力に胃酸分泌を抑制
  • T1/2 約1.5時間だが、酵素への結合は不可逆的のため酸分泌抑制は24時間以上持続
  • 肝代謝（CYP2C19, CYP3A4）。CYP2C19の遺伝子多型により代謝速度に個人差あり

適応

  • 胃潰瘍、十二指腸潰瘍
  • 逆流性食道炎
  • Zollinger-Ellison症候群
  • NSAIDs潰瘍の治療・予防（低用量アスピリン投与時の潰瘍再発抑制、NSAIDs投与時の潰瘍再発抑制）
  • H. pylori除菌補助（アモキシシリン+クラリスロマイシンと3剤併用）

用法用量

  • 胃潰瘍: 1回30mg 1日1回（8週間まで）
  • 十二指腸潰瘍: 1回30mg 1日1回（6週間まで）
  • 逆流性食道炎: 1回30mg 1日1回（治療）、1回15mg 1日1回（維持療法）
  • 低用量アスピリン投与時の潰瘍予防: 1回15mg 1日1回
  • 腎機能低下時: 用量調整不要
  • 肝機能低下時: 慎重投与（代謝遅延の可能性）

禁忌・注意

  • 禁忌: アタザナビル・リルピビリン投与中（吸収低下）、本剤過敏症
  • 慎重投与: 肝障害
  • 相互作用:
    • CYP2C19基質（ジアゼパム、フェニトイン等）の代謝を阻害 → 血中濃度上昇
    • クロピドグレルの活性化を阻害する可能性（臨床的意義は議論あり）
    • タクロリムス → 血中濃度上昇
  • 妊婦: 有益性投与。授乳婦: 動物で乳汁移行あり
  • 副作用:
    • 頻度高: 下痢、腹部膨満感
    • 重大: 汎血球減少、間質性肺炎、肝機能障害（稀）
    • 長期投与: 骨折リスク上昇、低Mg血症、Clostridioides difficile感染症リスク、腎障害（間質性腎炎）、ビタミンB12吸収低下

処方のポイント

  • タケルダ配合錠（アスピリン100mg+ランソプラゾール15mg）として低用量アスピリンとの配合剤あり
  • PPIの中ではCYP2C19多型の影響を比較的受けやすい
  • 長期投与時は漫然投与を避け、適宜PPIの必要性を再評価
  • OD錠は経管投与にも対応

ネキシウム（エソメプラゾールカプセル「サワイ」等）/ エソメプラゾール（esomeprazole）

商品名: ネキシウム / 後発: エソメプラゾールカプセル「サワイ」「トーワ」他 カテゴリ: RX-05 消化器系 剤型・規格: カプセル 10mg / 20mg 薬価: 21.70円（後発カプセル10mg）、37.80円（後発カプセル20mg） 薬品区分: 普通薬

薬理

  • プロトンポンプ阻害薬（PPI）
  • オメプラゾールのS-エナンチオマー。安定したバイオアベイラビリティ
  • 胃壁細胞のH+/K+-ATPaseを不可逆的に阻害し、強力に胃酸分泌を抑制
  • 肝代謝（CYP2C19, CYP3A4）。R体と比べCYP2C19多型の影響を受けにくい

適応

  • 胃潰瘍、十二指腸潰瘍
  • 逆流性食道炎（治療・維持療法）
  • NSAIDs潰瘍の予防（再発抑制）
  • H. pylori除菌補助

用法用量

  • 逆流性食道炎治療: 1回20mg 1日1回（8週間まで）
  • 逆流性食道炎維持療法: 1回10〜20mg 1日1回
  • NSAIDs潰瘍予防: 1回20mg 1日1回
  • H. pylori除菌: 1回20mg 1日2回（7日間、抗菌薬と併用）
  • 腎機能低下時: 用量調整不要
  • 肝機能低下時: 重度肝障害では20mg/日を超えない

禁忌・注意

  • 禁忌: アタザナビル・リルピビリン投与中、本剤過敏症
  • 相互作用:
    • クロピドグレルの活性化を阻害する可能性（ランソプラゾールと同様）
    • ジアゼパム、フェニトイン等のCYP2C19基質 → 血中濃度上昇
  • 妊婦: 有益性投与。授乳婦: 乳汁移行あり
  • 副作用:
    • 頻度高: 下痢、頭痛
    • 重大: アナフィラキシー、汎血球減少（稀）
    • 長期投与: 骨折リスク上昇、低Mg血症、Clostridioides difficile感染症リスク、腎障害、ビタミンB12吸収低下

処方のポイント

  • CYP2C19多型の影響がランソプラゾールより少なく、安定した効果が期待できる
  • 10mgカプセルは維持療法に適した低用量
  • PPIの第一選択として使いやすい

パリエット（ラベプラゾールNa錠「トーワ」）/ ラベプラゾール（rabeprazole）

商品名: パリエット / 後発: ラベプラゾールNa錠「トーワ」他 カテゴリ: RX-05 消化器系 剤型・規格: 錠 10mg（※20mg規格も存在するが調剤薬局では採用なし。逆流性食道炎で20mg/日が必要な場合は10mg×2錠で対応） 薬価: 24.00円（後発錠10mg）、35.80円（先発パリエット錠10mg） 薬品区分: 普通薬

薬理

  • プロトンポンプ阻害薬（PPI）
  • H+/K+-ATPaseを不可逆的に阻害し胃酸分泌を抑制
  • PPIの中で最もpKaが高く（約5.0）、活性化が速い → 速やかな酸分泌抑制効果
  • 肝代謝（CYP2C19の関与が他のPPIより小さく、CYP2C19多型の影響を受けにくい）
  • 非酵素的代謝経路（チオエーテル化）も有する

適応

  • 胃潰瘍、十二指腸潰瘍
  • 逆流性食道炎
  • Zollinger-Ellison症候群
  • NSAIDs潰瘍
  • H. pylori除菌補助

用法用量

  • 胃潰瘍: 1回10mg 1日1回（8週間まで）
  • 十二指腸潰瘍: 1回10mg 1日1回（6週間まで）
  • 逆流性食道炎: 1回10〜20mg 1日1回
  • H. pylori除菌: 1回10mg 1日2回（7日間）
  • 腎機能低下時: 用量調整不要

禁忌・注意

  • 禁忌: アタザナビル・リルピビリン投与中、本剤過敏症
  • 相互作用: CYP2C19への影響が他のPPIより小さい → クロピドグレルとの併用時に選択しやすい
  • 妊婦: 有益性投与
  • 副作用:
    • 頻度高: 下痢、肝機能障害（稀）
    • 長期投与: 骨折リスク上昇、低Mg血症、Clostridioides difficile感染症リスク、腎障害、ビタミンB12吸収低下

処方のポイント

  • CYP2C19多型の影響を最も受けにくいPPI
  • クロピドグレル併用時のPPI選択としてラベプラゾールが好まれることがある

タケキャブ / ボノプラザン（vonoprazan）

商品名: タケキャブ カテゴリ: RX-05 消化器系 剤型・規格: 錠 10mg / 20mg 薬価: 94.30円（10mg）、141.00円（20mg） 薬品区分: 普通薬

薬理

  • カリウムイオン競合型アシッドブロッカー（P-CAB）
  • 壁細胞のH+,K+-ATPaseをK+と競合的に阻害
  • PPIと異なり酸による活性化が不要 → 投与初日から強力かつ速やかな酸分泌抑制
  • PPIと異なり可逆的阻害だが、解離が遅いため持続的な効果
  • 肝代謝（CYP3A4主体）。CYP2C19多型の影響をほとんど受けない
  • T1/2 約7.7時間

適応

  • 逆流性食道炎（治療・維持療法）
  • 胃潰瘍、十二指腸潰瘍
  • H. pylori除菌補助（ボノサップパックとして3剤パック製剤あり）
  • NSAIDs潰瘍
  • 低用量アスピリン投与時の潰瘍予防

用法用量

  • 逆流性食道炎治療: 1回20mg 1日1回（4週間まで。重症は8週間）
  • 逆流性食道炎維持療法: 1回10mg 1日1回
  • 胃潰瘍: 1回20mg 1日1回
  • H. pylori除菌: 1回20mg 1日2回（7日間、抗菌薬と併用）
  • 低用量アスピリン投与時: 1回10mg 1日1回
  • 腎機能低下時: 用量調整不要
  • 肝機能低下時: 慎重投与

禁忌・注意

  • 禁忌: アタザナビル・リルピビリン投与中、本剤過敏症
  • 相互作用:
    • CYP3A4阻害薬（クラリスロマイシン等）→ 血中濃度上昇の可能性
    • pH上昇により吸収が低下する薬剤（イトラコナゾール等）
  • 妊婦: 有益性投与
  • 副作用:
    • 頻度高: 下痢、便秘
    • 重大: 肝機能障害（稀）
    • 高ガストリン血症（胃酸抑制が強力なため）
    • 長期投与: 胃底腺ポリープ、骨折リスク、Clostridioides difficile感染症リスク

処方のポイント

  • PPIで効果不十分な逆流性食道炎に有効（初日からの強力な酸分泌抑制）
  • H. pylori除菌成功率がPPIベースの除菌より高い（P-CABベースの除菌率90%以上）
  • 除菌療法に便利
  • 薬価がPPIより高いため、維持療法ではコスト面も考慮
  • CYP2C19多型の影響を受けない → 遺伝子型に関わらず安定した効果

  • 050-AP-10（H.pylori）

採用がない場合の代替案

  • 同効代替薬: エソメプラゾール、ラベプラゾール。ただしP-CABの酸分泌抑制力には劣る
ガスター（ファモチジンOD錠「トーワ」等）/ ファモチジン（famotidine）

商品名: ガスター / 後発: ファモチジンOD錠「トーワ」他 カテゴリ: RX-05 消化器系 剤型・規格: OD錠 10mg / 20mg 薬価: 10.40円（後発OD錠10mg / 20mg）、13.40円（先発ガスターD錠20mg） 薬品区分: 普通薬

薬理

  • H2受容体拮抗薬（H2RA）
  • 胃壁細胞のH2受容体を遮断し胃酸分泌を抑制
  • PPIほど強力ではないが、夜間の基礎酸分泌抑制に優れる
  • 腎排泄が主（約70%）→ 腎機能低下時は減量が必要
  • T1/2 約2.5〜3.5時間

適応

  • 胃潰瘍、十二指腸潰瘍
  • 逆流性食道炎
  • 上部消化管出血
  • Zollinger-Ellison症候群

    • ビスホスホネート → 同上
    • セフジニル → キレート形成により吸収低下（2時間以上あける）
    • 活性型ビタミンD3製剤 → 高Ca・高Mg血症のリスク
  • 妊婦: 使用可（妊娠中の便秘に頻用）
  • 副作用:
    • 頻度高: 下痢（用量依存）
    • 重大: 高Mg血症（腎機能低下時、嘔吐・徐脈・血圧低下・意識障害）

処方のポイント

  • 便秘症の第一選択薬の一つ。安価で安全性が高い
  • 腎機能低下時の高Mg血症を必ずチェック → 定期的にMg値を測定
  • 他の下剤との併用も可能

CureStation テンプレートとの関連

  • 060-AP-01（便秘）

調剤薬局での採用状況

  • 採用: あり（酸化マグネシウム錠250mg・330mg・500mg「ケンエー」、重質酸化マグネシウム原末）

採用がない場合の代替案

  • 規格切れの心配は低い
  • 同効代替薬: ルビプロストン、リナクロチド
プルゼニド（センノシド錠「サワイ」等）/ センノシド（sennoside）

商品名: プルゼニド / 後発: センノシド錠「サワイ」他 カテゴリ: RX-05 消化器系 剤型・規格: 錠 12mg 薬価: 5.30円（後発錠12mg） 薬品区分: 普通薬

薬理

  • 大腸刺激性下剤（アントラキノン系）
  • 大腸細菌叢によりレインアンスロンに変換され大腸粘膜を刺激し蠕動を亢進
  • 就寝前投与で翌朝の排便を期待

適応

  • 便秘症

用法用量

  • 成人: 1回1〜2錠（12〜24mg）1日1回 就寝前
  • 小児: 適宜減量
  • 腎機能低下時: 調整不要

禁忌・注意

  • 禁忌: 急性腹症が疑われる場合、痙攣性便秘、重症の硬結便
  • 相互作用: 臨床上重要なものは少ない
  • 妊婦: 子宮収縮を誘発する可能性あり。妊婦には投与しないことが望ましい
  • 副作用:
    • 頻度高: 腹痛、下痢
    • 長期連用: 大腸メラノーシス、耐性（用量漸増が必要になる）

処方のポイント

  • 酸化マグネシウムで効果不十分な場合の追加薬として使用
  • 長期連用は耐性を生じるため頓用的使用が望ましい
  • センナ・センナ実配合顆粒（ピムロ顆粒）も同系統

CureStation テンプレートとの関連

  • 060-AP-01（便秘）

調剤薬局での採用状況

  • 採用: あり（後発 センノシド錠12mg「サワイ」）

採用がない場合の代替案

  • 同効代替薬: ピコスルファートNa液
アミティーザ / ルビプロストン（lubiprostone）

商品名: アミティーザ カテゴリ: RX-05 消化器系 剤型・規格: カプセル 12μg / 24μg 薬価: 48.20円（12μg）、96.90円（24μg） 薬品区分: 普通薬

薬理

  • クロライドチャネルアクチベーター
  • 小腸上皮のClC-2クロライドチャネルを活性化 → 腸管内への水分分泌を促進
  • 便を軟化させ腸管輸送を促進
  • 習慣性がなく長期投与に適する

適応

  • 慢性便秘症（器質的疾患による便秘を除く）

用法用量

  • 成人: 1回24μg 1日2回 朝食後・夕食後
  • 症状により1回12μgに減量
  • 小児: 適応なし
  • 腎機能低下時: 添付文書を参照
  • 高齢者: 低用量（12μg）から開始を考慮

禁忌・注意

  • 禁忌: 妊婦（動物実験で流産の報告）、腸閉塞の疑い
  • 授乳婦: 乳汁移行の有無は不明。授乳中は投与を避けるか授乳を中止
  • 相互作用: 臨床上重要なものは少ない
  • 副作用:
    • 頻度高: 悪心（初期に多い、食後投与で軽減）、下痢
    • 重大: 特になし

処方のポイント

  • 酸化マグネシウムで効果不十分な慢性便秘に有効
  • 悪心が投与初期に多い → 食後投与と低用量開始で軽減
  • 妊婦には禁忌 → 妊娠可能な女性には注意
  • 腎機能低下時でも使用しやすい（酸化Mgの代替として）

CureStation テンプレートとの関連

  • 060-AP-01（便秘）

調剤薬局での採用状況

  • 採用: あり（アミティーザカプセル12μg、24μg）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: リナクロチド（リンゼス）、エロビキシバット（非採用）
リンゼス / リナクロチド（linaclotide）

商品名: リンゼス カテゴリ: RX-05 消化器系 剤型・規格: 錠 0.25mg 薬価: 64.50円 薬品区分: 普通薬

薬理

  • グアニル酸シクラーゼC（GC-C）受容体作動薬
  • 腸管上皮細胞のGC-C受容体を活性化 → cGMPを介して腸液分泌促進・腸管輸送能促進
  • 内臓痛覚過敏の改善作用も有する（IBS-Cの腹痛にも効果あり）
  • 全身吸収はほぼない → 全身性の副作用が少ない

適応

  • 便秘型過敏性腸症候群（IBS-C）
  • 慢性便秘症

用法用量

  • 便秘型過敏性腸症候群（IBS-C）: 1回0.5mg 1日1回 食前（症状により0.25mgに減量）
  • 慢性便秘症: 1回0.25mg 1日1回 食前（症状により0.5mgに増量）
  • 小児: 適応なし
  • 腎機能低下時: 調整不要（全身吸収はほぼない）

禁忌・注意

  • 禁忌: 機械的消化管閉塞、6歳未満の小児
  • 相互作用: 臨床上重要なものは少ない
  • 妊婦: 有益性投与
  • 副作用:
    • 頻度高: 下痢（用量依存性、高度なら減量）
    • 重大: 重度の下痢（脱水に注意）

処方のポイント

  • IBS-C（便秘型過敏性腸症候群）の腹痛・便秘に対する第一選択薬の一つ
  • 食前投与が重要（食後では下痢のリスクが高まる）
  • 慢性便秘にも適応があるが、IBS-Cの腹痛改善がルビプロストンとの最大の差別化ポイント

CureStation テンプレートとの関連

  • 060-AP-08（IBS）: 便秘型
  • 060-AP-01（便秘）

調剤薬局での採用状況

  • 採用: あり（リンゼス錠0.25mg）
  • 備考: 0.5mg錠は非採用（0.25mg×2錠で対応）

採用がない場合の代替案

  • 同効代替薬: ルビプロストン
グーフィス / エロビキシバット（elobixibat）

商品名: グーフィス カテゴリ: RX-05 消化器系 剤型・規格: 錠 5mg 薬価: 添付文書を参照 薬品区分: 普通薬

薬理

  • 回腸末端の胆汁酸トランスポーター（IBAT）阻害薬
  • 回腸での胆汁酸再吸収を阻害 → 大腸に流入する胆汁酸量が増加
  • 胆汁酸が大腸粘膜を刺激 → 水分分泌促進・蠕動亢進
  • 新しい作用機序の便秘治療薬

適応

  • 慢性便秘症

用法用量

  • 成人: 1回10mg 1日1回 食前
  • 症状により1回5mgに減量（最大15mg）
  • 小児: 適応なし
  • 腎機能低下時: 添付文書を参照
  • 肝機能低下時: 慎重投与（重度肝障害では禁忌）

禁忌・注意

  • 禁忌: 重篤な肝障害、胆道完全閉塞
  • 相互作用:
    • 胆汁酸製剤（ウルソデオキシコール酸等）→ 効果減弱の可能性
    • コレスチラミン → エロビキシバットの効果を減弱
  • 妊婦: 有益性投与
  • 副作用:
    • 頻度高: 腹痛、下痢
    • 重大: 重度の下痢

処方のポイント

  • 酸化Mg、ルビプロストン、リナクロチドとは異なる作用機序 → 既存薬で効果不十分な場合に有用
  • 食前投与が必要
  • 下痢が強い場合は減量

CureStation テンプレートとの関連

  • 060-AP-01（便秘）

調剤薬局での採用状況

  • 採用: なし
  • 備考: 胆汁酸トランスポーター阻害薬は調剤薬局非採用

採用がない場合の代替案

  • 同効代替薬: ルビプロストン、リナクロチド
  • 薬局での取り寄せ: 翌日〜数日で入荷可能
ロペミン（ロペラミド塩酸塩カプセル「NIG」等）/ ロペラミド（loperamide）

商品名: ロペミン / 後発: ロペラミド塩酸塩カプセル「NIG」他 カテゴリ: RX-05 消化器系 剤型・規格: カプセル 1mg 薬価: 6.10円（後発カプセル1mg） 薬品区分: 普通薬

薬理

  • 止瀉薬（腸管運動抑制薬）
  • 腸管壁のオピオイドμ受容体に作用 → 腸管蠕動を抑制
  • 水分・電解質の吸収を促進
  • 中枢に移行しにくいため鎮痛・依存性のリスクは低い

適応

  • 急性・慢性下痢症

用法用量

  • 成人: 1日1〜2mg 分1〜2
  • 最大1日4mg
  • 小児: 添付文書を参照（低年齢児には慎重）
  • 腎機能低下時: 添付文書を参照

禁忌・注意

  • 禁忌: 出血性大腸炎、細菌性腸炎（起炎菌の排出が遅延）、偽膜性大腸炎、2歳未満の小児（中枢性副作用のリスクが高い）
  • 慎重投与: 感染性下痢（起炎菌の排出を遅らせるリスク）
  • 相互作用: 臨床上重要なものは少ない
  • 妊婦: 有益性投与
  • 副作用:
    • 頻度高: 便秘、腹部膨満
    • 重大: イレウス（過量投与時）、中毒性巨大結腸（稀）

処方のポイント

  • 感染性下痢には原則使用しない（菌の排出を遅らせる）
  • 非感染性の下痢（IBS-D、機能性下痢等）に使用
  • 止瀉作用は強力だが、原因治療ではない
  • 短期間の使用に留める

CureStation テンプレートとの関連

  • 060-AP-08（IBS）: 下痢型
  • 050-AP-01（感染性胃腸炎）: ※感染性には慎重

調剤薬局での採用状況

  • 採用: あり（後発 ロペラミド塩酸塩カプセル1mg「NIG」）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: リーダイ配合錠（ベルベリン・ゲンノショウコ配合）→ 止瀉作用は弱い
ツムラ43番 六君子湯 / 六君子湯（りっくんしとう）

商品名: ツムラ六君子湯エキス顆粒（医療用）【ツムラ43番】 カテゴリ: RX-05 消化器系（漢方薬） 剤型・規格: エキス顆粒 2.5g/包 薬価: 18.00円/包 薬品区分: 普通薬

構成生薬

  • 蒼朮（ソウジュツ）4.0g、茯苓（ブクリョウ）4.0g、人参（ニンジン）4.0g
  • 半夏（ハンゲ）4.0g、陳皮（チンピ）2.0g、大棗（タイソウ）2.0g
  • 甘草（カンゾウ）1.0g、生姜（ショウキョウ）0.5g
  • ※甘草含有（1.0g/日）→ 偽アルドステロン症に注意（量は少ない）

薬理

  • 補気健脾の代表処方
  • 胃腸機能を高め食欲不振・消化不良を改善する
  • グレリン分泌促進作用が報告されており、食欲増進効果の機序の一つと考えられている
  • 胃適応性弛緩の改善作用

適応

  • 保険適応: 胃腸虚弱、胃下垂、消化不良、食欲不振、慢性胃炎
  • 臨床での主な使用場面:
    • 機能性ディスペプシア（FD）→ エビデンスあり
    • GERD（PPI効果不十分例への上乗せ）
    • 癌化学療法時の食欲不振（シスプラチン等による）
    • 高齢者の食欲低下

用法用量

  • 成人: 1日7.5g（2.5g x 3包）分2〜3 食前または食間
  • 小児: 年齢に応じて適宜減量
  • 腎機能低下時: 調整不要
  • 高齢者: 通常量で使用可

禁忌・注意

  • 禁忌: アルドステロン症、ミオパチー、低K血症（甘草含有のため）
  • 相互作用:
    • 甘草含有製剤との併用 → 偽アルドステロン症リスク（甘草1.0g/日と少量だがチェック必要）
    • 利尿薬 → 低K血症リスク
  • 妊婦: 有益性が危険性を上回る場合に投与
  • 副作用:
    • 重大: 偽アルドステロン症（甘草由来、頻度は低い）、肝機能障害、間質性肺炎（稀）
    • 頻度高: 食欲不振の一過性悪化（開始初期）

処方のポイント

  • FD（機能性ディスペプシア）の食後愁訴症候群（PDS）にエビデンスあり
  • アコチアミドとの使い分け: 六君子湯は食欲不振・倦怠感も伴う虚証の患者に適する
  • Tatsuta M, et al.: グレリン分泌促進を介した食欲改善効果の報告
  • 化学療法時の悪心・食欲不振にも補助的に使用される
  • 甘草含有量が1.0g/日と少ないが、他の甘草含有漢方薬との併用には注意

CureStation テンプレートとの関連

  • 050-AP-06（FD）
  • 050-AP-05（GERD）: 補助

調剤薬局での採用状況

  • 採用: あり（ツムラ六君子湯エキス顆粒 2.5g/包）
  • 備考: なし

採用がない場合の代替案

  • 同一成分別規格: 該当なし
  • 同効代替薬: アコチアミド（アコファイド）→ FDの適応あり。ただし漢方的な証が異なる
  • その他: クラシエ等の他社六君子湯は非採用
