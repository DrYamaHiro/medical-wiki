リンデロン-V（ベタメタゾン吉草酸エステル軟膏「イワキ」等）/ ベタメタゾン吉草酸エステル（betamethasone valerate）

商品名: リンデロン-V軟膏/クリーム/ローション / 後発: ベタメタゾン吉草酸エステル軟膏「イワキ」他 カテゴリ: RX-13 皮膚科 剤型・規格: 軟膏 0.12% / クリーム 0.12% / ローション 0.12%（各5g/本, 10mL/瓶等） 薬価: 8.50円/g（後発軟膏）〜16.90円/g（先発） 薬品区分: 普通薬

薬理

  • ストロング（strong/III群）クラスの副腎皮質ステロイド外用薬
  • 炎症細胞浸潤の抑制、血管透過性亢進・浮腫の改善
  • 全身吸収はほぼなし（広範囲・長期使用・密封法では注意）

適応

  • 湿疹・皮膚炎群（接触皮膚炎、アトピー性皮膚炎等）
  • 乾癬、痒疹群
  • 虫さされ

用法用量

  • 成人: 1日1〜数回、患部に適量を塗布
  • 小児: 同様（ただし長期・広範囲の使用は避ける）
  • 軟膏: 乾燥・苔癬化した病変に適する。クリーム: 浸出液を伴う病変に。ローション: 頭皮等の有毛部に

禁忌・注意

  • 禁忌: 細菌・真菌・ウイルス性皮膚感染症（単独使用）、潰瘍面、本剤過敏症
  • 注意: 顔面への長期使用は避ける（酒さ様皮膚炎）、眼周囲（緑内障リスク）
  • 相互作用: 外用薬のため臨床上問題となるものはない
  • 妊婦・授乳婦: 大量・長期使用を避ける。有益性が危険性を上回る場合に使用
  • 副作用: 皮膚萎縮、毛細血管拡張、ステロイド座瘡、接触性皮膚炎（稀）

処方のポイント

  • ステロイド外用薬ランク分類: ストロング（strong/III群）
  • 皮膚科外用ステロイドの中で最も汎用されるランクの一つ
  • 体幹・四肢の中等症湿疹に適する
  • 顔面・陰部にはミディアム以下（ロコイド等）を選択
  • VG（ゲンタマイシン配合）は感染を伴う場合に使用するが、長期連用は耐性菌の懸念あり

  • 取り寄せ: 翌日入荷可能
ザーネ / ビタミンA油軟膏（retinol）

商品名: ザーネ軟膏 カテゴリ: RX-13 皮膚科 剤型・規格: 軟膏 0.5%（5,000単位、調剤用500g） 薬価: 1.90円/g 薬品区分: 普通薬

プロスタンディン / プロスタンディン軟膏（alprostadil alfadex）

商品名: プロスタンディン軟膏 カテゴリ: RX-13 皮膚科 剤型・規格: 軟膏 0.003%（10g/本） 薬価: 34.30円/g 薬品区分: 劇薬

  • 血流改善と創傷治癒促進

  • 褥瘡・皮膚潰瘍

ユーパスタ / 精製白糖・ポビドンヨード配合軟膏（sucrose/povidone-iodine）

商品名: ユーパスタ軟膏 カテゴリ: RX-13 皮膚科 剤型・規格: 軟膏（調剤用100g） 薬価: 11.40円/g 薬品区分: 普通薬

商品名: ヨクイニンエキス錠「コタロー」 カテゴリ: RX-13 皮膚科 剤型・規格: 錠剤（バラ） 薬価: 6.50円/錠 薬品区分: 普通薬
