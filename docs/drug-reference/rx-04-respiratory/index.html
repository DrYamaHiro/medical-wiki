フルタイド / フルチカゾンプロピオン酸エステル吸入剤（fluticasone propionate inhaler）

商品名: フルタイドディスカス カテゴリ: RX-04 呼吸器系（吸入ステロイド・ICS単剤） 剤型・規格: ディスカス（DPI）100μg 60ブリスター / 200μg 60ブリスター（※50μg規格も存在するが調剤薬局では採用なし） 薬価: 950.00円（100μg 60ブリスター）/ 1,247.60円（200μg 60ブリスター） 薬品区分: 普通薬

薬理

  • 吸入ステロイド薬（ICS）
  • 気道の炎症を強力に抑制（好酸球浸潤、サイトカイン産生、粘液分泌を抑制）
  • 全身バイオアベイラビリティが低い → 全身性副作用が少ない
  • DPI（ドライパウダー吸入器）タイプ

適応

  • 気管支喘息の長期管理（コントローラー）

用法用量

  • 成人: 1回100-200μg 1日2回吸入。症状に応じて適宜増減（最大800μg/日）
  • 小児: 1回50-100μg 1日2回吸入（添付文書を参照）
  • 腎機能低下時: 調整不要（全身吸収は少ない）
  • 高齢者: 通常量で使用可。吸入手技の確認が重要

禁忌・注意

  • 禁忌: 本剤成分に過敏症の既往
  • 注意: 急性喘息発作には無効（発作時はSABAを使用）
  • 副作用:
    • 頻度高: 口腔カンジダ症、嗄声（吸入後のうがいで予防）
    • 重大: アナフィラキシー（極めて稀）

処方のポイント

  • ICS単剤はGINA Step 1-2の軽症喘息に使用
  • ステップアップ時はICS/LABA配合剤（アドエア、レルベア等）へ変更
  • 吸入後の含嗽（うがい）を必ず指導 → 口腔カンジダ症・嗄声の予防
  • ディスカスは吸入手技が比較的簡単（カウンター付き）

  • 全身バイオアベイラビリティが低い

適応

  • 気管支喘息の長期管理（コントローラー）

アドエア / サルメテロール・フルチカゾン配合吸入剤（salmeterol/fluticasone: SFC）

商品名: アドエアディスカス カテゴリ: RX-04 呼吸器系（ICS/LABA配合） 剤型・規格:

  • ディスカス 100（サルメテロール50μg/フルチカゾン100μg）60ブリスター
  • ディスカス 250（サルメテロール50μg/フルチカゾン250μg）28ブリスター / 60ブリスター
  • ディスカス 500（サルメテロール50μg/フルチカゾン500μg）60ブリスター 薬価: 3,111.10円（100/60）/ 1,865.80円（250/28）/ 3,625.30円（250/60）/ 3,952.10円（500/60） 薬品区分: 普通薬

薬理

  • ICS（フルチカゾンプロピオン酸）+ LABA（サルメテロール）配合吸入剤
  • フルチカゾン: 気道の炎症を抑制
  • サルメテロール: 気管支平滑筋のβ2受容体を刺激し長時間（12時間以上）気管支を拡張
  • ICSとLABAの相乗効果（ICSがβ2受容体発現を維持、LABAがGR核内移行を促進）

適応

  • 気管支喘息
  • COPD（250ディスカス60ブリスターのみ）

用法用量

  • 成人: 1回1吸入 1日2回（朝・夕）
  • 用量選択:
    • 100ディスカス: 低用量ICS相当
    • 250ディスカス: 中用量ICS相当（最も汎用）
    • 500ディスカス: 高用量ICS相当（重症例）
  • 小児: 100ディスカスを使用（添付文書を参照）
  • 腎機能低下時: 調整不要
  • 高齢者: 通常量で使用可。吸入手技の確認が重要

禁忌・注意

  • 禁忌: 本剤成分に過敏症の既往、有効な抗菌薬のない感染症
  • 注意: 急性喘息発作には無効。発作時はSABAを使用
  • 相互作用:
    • CYP3A4阻害薬（リトナビル等）→ フルチカゾン血中濃度上昇 → 副腎抑制リスク
    • β遮断薬 → サルメテロールの気管支拡張効果を減弱
  • 副作用:
    • 頻度高: 口腔カンジダ症、嗄声（うがいで予防）
    • 重大: アナフィラキシー（稀）、心房細動（稀）

処方のポイント

  • GINA Step 3-4の喘息管理の標準治療
  • ディスカスは吸入手技が比較的簡単（DPI）
  • 28ブリスター製剤は約2週間分、60ブリスターは約1ヶ月分
  • SMART療法（維持+頓用）には使用不可（サルメテロールの効果発現が遅い → ホルモテロール含有製剤を使用）

シムビコート（ブデホル吸入粉末剤「JG」）/ ブデソニド・ホルモテロール配合吸入粉末剤（budesonide/formoterol: BFC）

商品名: シムビコート / 後発: ブデホル吸入粉末剤「JG」 カテゴリ: RX-04 呼吸器系（ICS/LABA配合） 剤型・規格: 吸入粉末剤（タービュヘイラー型）30吸入 / 60吸入 薬価: 682.80円（後発30吸入）/ 1,223.00円（後発60吸入） 薬品区分: 普通薬

薬理

  • ICS（ブデソニド）+ LABA（ホルモテロール）配合吸入剤
  • ホルモテロール: 効果発現が速い（約1-3分）+ 長時間作用（12時間以上）
  • ブデソニド: 気道の抗炎症作用
  • SMART療法（維持+頓用）が可能な唯一のICS/LABA（ホルモテロールの速効性による）

適応

  • 気管支喘息
  • COPD

用法用量

  • 維持療法: 1回1-2吸入 1日2回
  • SMART療法: 維持1回1-2吸入 1日2回 + 発作時追加1吸入（維持含め1日合計8吸入まで。一時的に12吸入まで増量可）
  • 小児: 添付文書を参照
  • 腎機能低下時: 調整不要

禁忌・注意

  • 禁忌: 本剤成分に過敏症の既往
  • 注意:
    • SMART療法の最大吸入回数（維持含め1日合計8吸入、一時的に12吸入まで）を超えないよう指導
    • 頓用が頻回になる場合はステップアップを検討
  • 相互作用:
    • CYP3A4阻害薬 → ブデソニド血中濃度上昇
    • β遮断薬 → ホルモテロールの効果減弱
  • 副作用: 口腔カンジダ症、嗄声、動悸・頻脈（ホルモテロールによる）、振戦

処方のポイント

  • SMART療法が最大の特徴 → 維持と発作時レスキューを1つの吸入器で管理
  • SYGMA study: SMART療法は低用量ICS/LABA定期投与と同等の喘息コントロール
  • 後発品（ブデホル「JG」）が使用可能 → コストメリット大
  • タービュヘイラー型は吸入力がやや必要 → 高齢者・小児では吸入手技を確認
  • COPDへの適応もあり（アドエア・レルベアは喘息のみ）

  • 禁忌: アルドステロン症、ミオパチー、低K血症
  • 相互作用:
    • 甘草含有製剤との併用 → 偽アルドステロン症リスク増大
    • グリチルリチン → 同上
    • 利尿薬 → 低K血症リスク増大
  • 妊婦: 有益性投与（半夏含有だが臨床的使用経験あり）
  • 副作用:
    • 重大: 偽アルドステロン症（低K血症、血圧上昇、浮腫）、間質性肺炎（稀）、肝機能障害
    • 頻度高: 食欲不振（稀）

処方のポイント

  • 感冒後の遷延性咳嗽（乾性咳嗽、咽頭乾燥感）に最適
  • 西洋薬の鎮咳薬と併用可能
  • 特に「咳き込むと止まらない」タイプの咳嗽に有効
  • ACE阻害薬による咳嗽にも有効との報告あり
  • 甘草含有量2.0g/日は中程度。他の甘草含有漢方薬との重複に注意
  • 湿性咳嗽（痰が多い）には不適 → カルボシステイン等の去痰薬を優先

  • 010-AP-01（急性上気道炎）: 遷延性咳嗽
  • 030-AP-06（咳喘息）: 乾性咳嗽

ムコダイン（カルボシステイン錠「杏林」等）/ カルボシステイン（carbocisteine）

商品名: ムコダイン / 後発: カルボシステイン錠「杏林」等 カテゴリ: RX-04 呼吸器系（去痰薬） 剤型・規格:

薬理

  • 気道粘液調整薬・粘膜正常化薬
  • 喀痰中のムチンのシアル酸/フコース比を正常化し、痰の粘度を低下させる
  • 粘膜上皮の繊毛機能を正常化し、痰の排出を促進

  • 妊婦: 治療上の有益性が危険性を上回る場合に投与

処方のポイント

  • 日本で最も汎用される去痰薬
  • 上気道炎・気管支炎の去痰に第一選択

ホクナリンテープ（ツロブテロールテープ「トーワ」）/ ツロブテロールテープ（tulobuterol tape）

商品名: ホクナリンテープ / 後発: ツロブテロールテープ「トーワ」 カテゴリ: RX-04 呼吸器系（気管支拡張薬・経皮吸収型） 剤型・規格: テープ 0.5mg / 1mg / 2mg 薬価: 14.90円（後発0.5mg）/ 20.80円（後発1mg）/ 29.00円（後発2mg） 薬品区分: 普通薬

薬理

  • β2刺激薬（経皮吸収型気管支拡張薬）
  • 気管支平滑筋のβ2受容体を刺激し気管支を拡張
  • 貼付により24時間持続的に薬物が経皮吸収される
  • T1/2 添付文書を参照

適応

  • 気管支喘息
  • 急性気管支炎
  • COPD

  • 0.5-3歳: 0.5mg 1日1回 胸部・背部・上腕部に貼付
  • 3-9歳: 1mg 1日1回

  • 禁忌: 本剤成分に過敏症の既往

    • 気管支拡張薬であり、抗炎症作用はない → ICSの代替にはならない
  • 相互作用: β遮断薬 → 効果減弱
  • 副作用:
    • 頻度高: 貼付部位の紅斑・掻痒、動悸・振戦（β2刺激作用）
    • 重大: アナフィラキシー（極めて稀）、低K血症（β2刺激作用による細胞内K取り込み増加）

  • 効果不十分時はICS追加を検討
