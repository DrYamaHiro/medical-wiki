脂質異常症・代謝

CS Drug Reference

各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。

リピトール（アトルバスタチン錠「Me」等）/ アトルバスタチン（atorvastatin）

商品名: リピトール / 後発: アトルバスタチン錠「Me」 カテゴリ: RX-08 脂質異常症・代謝 剤型・規格: 錠 5mg / 10mg 薬価: 10.40円（後発5mg）、13.90円（後発10mg） 薬品区分: 普通薬

薬理

  • HMG-CoA還元酵素阻害薬（ストロングスタチン）
  • 肝臓でのコレステロール合成を阻害し、LDL受容体を増加させてLDL-Cを低下させる
  • LDL-C低下率: 5mg で約35%、10mg で約40%（添付文書を参照）
  • 肝代謝（CYP3A4）、T1/2 約14時間
  • TG低下作用・HDL-C上昇作用も有する

適応

  • 高コレステロール血症
  • 家族性高コレステロール血症

用法用量

  • 成人: 1回10mg 1日1回。効果不十分時は最大20mgまで増量可（FHホモ接合体では最大40mg/日）
  • 開始用量: 5mgから開始することが多い
  • 小児（10歳以上FH）: 添付文書を参照
  • 腎機能低下時: 用量調整不要
  • 肝機能低下時: 禁忌（活動性肝疾患）

禁忌・注意

  • 禁忌: 活動性肝疾患、妊婦・授乳婦、本剤過敏症
  • 慎重投与: 腎障害、甲状腺機能低下症（横紋筋融解症リスク増大）
  • 相互作用:
    • CYP3A4阻害薬（イトラコナゾール、クラリスロマイシン等）→ 血中濃度上昇
    • フィブラート系（フェノフィブラート等）→ 横紋筋融解症リスク増大
    • グレープフルーツジュース → 血中濃度上昇
  • 副作用:
    • 重大: 横紋筋融解症（CK上昇、筋痛、褐色尿）、肝機能障害
    • 頻度高: 消化器症状、CK上昇（無症候性）

処方のポイント

  • 日本で最も処方されるストロングスタチンの一つ
  • ACS二次予防: 高用量（10-20mg）を推奨するガイドラインあり
  • アムロジピンとの配合剤（アマルエット）が利用可能 → 高血圧＋脂質異常症合併例に有用
  • ロスバスタチンと比較: CYP3A4代謝のため相互作用に留意が必要

CureStation テンプレートとの関連

  • 120-AP-01（脂質異常症）: Rx-DL-Statin-Ator

調剤薬局での採用状況

  • 採用: あり（後発 アトルバスタチン錠「Me」5mg / 10mg、先発 リピトール錠5mg）
  • 備考: なし

採用がない場合の代替案

  • 同一成分別規格: 5mg / 10mg いずれも在庫あり
  • 同効代替薬: ロスバスタチン錠（在庫あり）、ピタバスタチン錠（在庫あり）。力価が異なるため換算が必要
  • 配合剤で代替: アマルエット配合錠1番/3番（在庫あり）
クレストール（ロスバスタチン錠「杏林」等）/ ロスバスタチン（rosuvastatin）

商品名: クレストール / 後発: ロスバスタチン錠「杏林」 カテゴリ: RX-08 脂質異常症・代謝 剤型・規格: 錠 2.5mg / 5mg 薬価: 10.40円（後発2.5mg / 5mg いずれも同額） 薬品区分: 普通薬

薬理

  • HMG-CoA還元酵素阻害薬（ストロングスタチン）
  • 肝臓でのコレステロール合成を阻害しLDL受容体発現を増加させてLDL-Cを低下させる
  • スタチンの中で最も強力なLDL-C低下作用: 2.5mg で約38%、5mg で約45%（添付文書を参照）
  • CYP代謝の寄与が小さく（主にCYP2C9、一部CYP2C19）、薬物相互作用が少ない
  • T1/2 約20時間

適応

  • 高コレステロール血症
  • 家族性高コレステロール血症

用法用量

  • 成人: 1回2.5mg 1日1回から開始。効果不十分時は5mg、最大20mgまで増量可
  • 小児: 添付文書を参照
  • 腎機能低下時: 重度腎障害では慎重投与（AUC上昇）
  • 肝機能低下時: 禁忌（活動性肝疾患）

禁忌・注意

  • 禁忌: 活動性肝疾患、妊婦・授乳婦、シクロスポリン併用
  • 慎重投与: 腎障害、甲状腺機能低下症
  • 相互作用:
    • シクロスポリン → 禁忌（血中濃度著明上昇）
    • フィブラート系 → 横紋筋融解症リスク増大
    • ワルファリン → INR上昇の可能性
    • CYP3A4阻害薬との相互作用は少ない（アトルバスタチンとの差異）
  • 副作用:
    • 重大: 横紋筋融解症、肝機能障害、免疫介在性壊死性ミオパチー（稀）
    • 頻度高: CK上昇、消化器症状

処方のポイント

  • CYP3A4阻害薬との相互作用が少なく、多剤併用患者に適する
  • エゼチミブとの配合剤（エゼロス配合錠HD / ロスーゼット配合錠HD）が利用可能
  • 2.5mgでも十分なLDL-C低下が得られることが多く、低用量から開始しやすい
  • LDL-Cが非常に高い場合（FH等）: エゼチミブ併用で追加15-20%低下

CureStation テンプレートとの関連

  • 120-AP-01（脂質異常症）: Rx-DL-Statin-Ros

調剤薬局での採用状況

  • 採用: あり（後発 ロスバスタチン錠「杏林」2.5mg / 5mg）
  • 備考: 先発クレストールは非採用

採用がない場合の代替案

  • 同一成分別規格: 2.5mg / 5mg いずれも在庫あり
  • 同効代替薬: アトルバスタチン錠（在庫あり）、ピタバスタチン錠（在庫あり）。力価換算が必要
  • 配合剤で代替: エゼロス配合錠HD（ロスバスタチン5mg+エゼチミブ10mg、在庫あり）
リバロ（ピタバスタチンCa錠「日医工」等）/ ピタバスタチン（pitavastatin）

商品名: リバロ / 後発: ピタバスタチンCa錠「日医工」、ピタバスタチンCa・OD錠「トーワ」 カテゴリ: RX-08 脂質異常症・代謝 剤型・規格: 錠 1mg / 2mg、OD錠 1mg / 2mg 薬価: 10.40円（後発錠1mg）、12.90円（後発錠2mg）、10.40円（後発OD錠1mg）、15.80円（後発OD錠2mg） 薬品区分: 普通薬

薬理

  • HMG-CoA還元酵素阻害薬（ストロングスタチン）
  • 肝臓でのコレステロール合成を阻害しLDL-Cを低下させる
  • CYP2C9による代謝は極めて少なく、主にUGT（グルクロン酸抱合）で代謝される。CYPを介した薬物相互作用がほとんどない
  • シクロスポリンとの併用は禁忌だが、CYP3A4阻害薬の影響を受けにくい
  • T1/2 約11時間

適応

  • 高コレステロール血症
  • 家族性高コレステロール血症

用法用量

  • 成人: 1回1-2mg 1日1回。最大4mg/日
  • 小児: 添付文書を参照
  • 腎機能低下時: 用量調整を考慮（添付文書を参照）
  • 肝機能低下時: 禁忌（活動性肝疾患）

禁忌・注意

  • 禁忌: 活動性肝疾患、妊婦・授乳婦、シクロスポリン併用
  • 慎重投与: 腎障害、甲状腺機能低下症
  • 相互作用:
    • シクロスポリン → 禁忌
    • フィブラート系 → 横紋筋融解症リスク増大
    • エリスロマイシン → 血中濃度上昇（CYP非依存的機序）
  • 副作用:
    • 重大: 横紋筋融解症、肝機能障害
    • 頻度高: CK上昇、消化器症状

処方のポイント

  • CYPをほとんど介さないため薬物相互作用が最も少ないスタチン
  • HIV治療薬（プロテアーゼ阻害薬）との併用が可能（他のスタチンは困難なことが多い）
  • OD錠があり嚥下困難な高齢者に有用
  • 糖代謝への影響が最も少ないスタチンとの報告あり（LIVES study）

CureStation テンプレートとの関連

  • 120-AP-01（脂質異常症）: Rx-DL-Statin-Pita

調剤薬局での採用状況

  • 採用: あり（後発 ピタバスタチンカルシウム錠「日医工」1mg / 2mg、OD錠「トーワ」1mg / 2mg、先発 リバロ錠1mg）
  • 備考: OD錠と普通錠の両方を採用

採用がない場合の代替案

  • 同一成分別規格: 1mg / 2mg / OD錠 いずれも在庫あり
  • 同効代替薬: ロスバスタチン錠（在庫あり）、アトルバスタチン錠（在庫あり）。力価換算が必要
リピディル（フェノフィブラート錠「武田テバ」等）/ フェノフィブラート（fenofibrate）

商品名: リピディル、トライコア / 後発: フェノフィブラート錠「武田テバ」 カテゴリ: RX-08 脂質異常症・代謝 剤型・規格: 錠 53.3mg / 80mg 薬価: 8.80円（後発53.3mg）、10.40円（後発80mg） 薬品区分: 普通薬

薬理

  • フィブラート系脂質異常症治療薬
  • PPARαを活性化し、TG低下・HDL-C上昇作用を示す
  • リポ蛋白リパーゼ活性を亢進させ、VLDL・TGの異化を促進
  • TG低下率: 約30-50%、HDL-C上昇率: 約10-20%（添付文書を参照）
  • 肝代謝（エステラーゼによる加水分解後、グルクロン酸抱合）、腎排泄

適応

  • 高脂血症（高TG血症を含む）

用法用量

  • 成人: 1回106.6-160mg 1日1回 食後に経口投与
    • 53.3mg錠 2-3錠 または 80mg錠 2錠が一般的
  • 小児: 適応なし
  • 腎機能低下時: 禁忌（血中クレアチニン値2.5mg/dL以上、添付文書記載基準）。軽度腎障害では減量を考慮
  • 肝機能低下時: 重篤な肝障害には禁忌

禁忌・注意

  • 禁忌: 重篤な肝・腎障害、胆石症、妊婦・授乳婦
  • 慎重投与: 腎障害、胆道疾患の既往
  • 相互作用:
    • スタチン → 横紋筋融解症リスク増大（慎重併用）
    • ワルファリン → 抗凝固作用増強（PT-INR上昇）
    • スルホニルウレア薬 → 低血糖リスク増大
  • 副作用:
    • 重大: 横紋筋融解症、肝機能障害、膵炎
    • 頻度高: 消化器症状（腹痛、悪心）、CK上昇、肝酵素上昇

処方のポイント

  • 高TG血症の第一選択薬（TG ≧ 500mg/dL では急性膵炎予防の観点からも重要）
  • スタチンとの併用は可能だが横紋筋融解症に注意（ペマフィブラートの方が安全性データが良好）
  • 尿酸低下作用も有する（URAT1を介した排泄促進）
  • 腎機能に注意: Cr上昇を認めることがあり、定期的な腎機能モニタリングが必要

CureStation テンプレートとの関連

  • 120-AP-01（脂質異常症）: Rx-DL-Fibrate

調剤薬局での採用状況

  • 採用: あり（後発 フェノフィブラート錠「武田テバ」53.3mg / 80mg）
  • 備考: なし

採用がない場合の代替案

  • 同一成分別規格: 53.3mg / 80mg いずれも在庫あり
  • 同効代替薬: ペマフィブラート徐放錠（パルモディアXR、在庫あり）。SPPARMαでより選択的
パルモディアXR（後発品なし）/ ペマフィブラート（pemafibrate）

商品名: パルモディアXR カテゴリ: RX-08 脂質異常症・代謝 剤型・規格: 徐放錠 0.2mg 薬価: 60.00円 薬品区分: 普通薬

薬理

  • 選択的PPARαモジュレーター（SPPARMα）
  • PPARαを選択的に活性化しTG低下・HDL-C上昇作用を示す
  • 従来のフィブラート系（フェノフィブラート等）より副作用軽減が期待される
  • 肝代謝が主（グルクロン酸抱合、CYP関与は少ない）、腎排泄の寄与が少ない
  • T1/2: 添付文書を参照

適応

  • 高脂血症

用法用量

  • 成人: 1回0.2mg 1日1回 経口投与（徐放錠のため1日1回）
  • 小児: 適応なし
  • 腎機能低下時: フェノフィブラートと異なり腎排泄の寄与が少なく、中等度腎障害までは使用可能（添付文書を参照）
  • 肝機能低下時: 重篤な肝障害には慎重投与

禁忌・注意

  • 禁忌: 重篤な肝障害、本剤過敏症
  • 慎重投与: 胆石症の既往、肝障害
  • 相互作用:
    • シクロスポリン → 血中濃度上昇の可能性
    • リファンピシン → 血中濃度低下の可能性
    • スタチン併用: フェノフィブラートより横紋筋融解症リスクが低いとされるが、注意は必要
  • 副作用:
    • 重大: 横紋筋融解症（頻度不明）、胆石症
    • 頻度高: CK上昇、肝酵素上昇

処方のポイント

  • フェノフィブラートが腎機能障害で使用困難な場合の代替として有用
  • PROMINENT試験: 2型糖尿病患者でのCV event抑制は示されなかったが、TG低下効果は確認
  • 1日1回の徐放錠でアドヒアランス良好
  • スタチン併用時の安全性はフェノフィブラートより良好と考えられている

CureStation テンプレートとの関連

  • 120-AP-01（脂質異常症）: Rx-DL-SPPARMa

調剤薬局での採用状況

  • 採用: あり（パルモディアXR錠0.2mg）
  • 備考: なし

採用がない場合の代替案

  • 同一成分別規格: 該当なし（0.2mgのみ）

ユリノーム（ベンズブロマロン錠「トーワ」等）/ ベンズブロマロン（benzbromarone）

商品名: ユリノーム / 後発: ベンズブロマロン錠「トーワ」 カテゴリ: RX-08 脂質異常症・代謝（尿酸降下薬） 剤型・規格: 錠 50mg 薬価: 6.10円（後発50mg） 薬品区分: 劇薬

薬理

  • 尿酸排泄促進薬
  • 近位尿細管のURAT1を阻害し尿酸の再吸収を抑制して尿酸排泄を促進する
  • 尿酸排泄低下型の高尿酸血症に特に適する
  • 肝代謝、T1/2: 添付文書を参照

適応

  • 痛風
  • 高尿酸血症

用法用量

  • 成人: 1回25mgから開始、1日1-3回 経口投与。維持量1日50mg。最大1日150mg
  • 小児: 適応なし
  • 腎機能低下時: 腎結石のリスクがあるため十分な水分摂取・尿アルカリ化を行う。重度腎障害では効果減弱
  • 肝機能低下時: 禁忌（重篤な肝障害例あり）

禁忌・注意

  • 禁忌: 重篤な肝障害、腎結石を有する患者
  • 慎重投与: 肝障害、消化性潰瘍
  • 相互作用:
    • ワルファリン → 抗凝固作用増強
    • アスピリン → 尿酸排泄促進効果の減弱
  • 副作用:
    • 重大: 劇症肝炎、重篤な肝障害（投与開始6ヶ月以内に多い → 定期的肝機能検査が必須）
    • 頻度高: 消化器症状、肝酵素上昇

処方のポイント

  • 痛風発作予防: 開始時はコルヒチンカバーを考慮（0.5mg/日、3-6ヶ月間）
  • 尿酸排泄低下型に適するが、肝障害リスクが最大の懸念
  • 投与開始後少なくとも6ヶ月間は月1回の肝機能検査が必須
  • 尿路結石予防: 十分な飲水（1日2L以上）＋尿アルカリ化薬（炭酸水素Na等）
  • 近年はドチヌラド（ユリス）が選択的URAT1阻害薬として安全性の面で注目されている

ユリス（後発品なし）/ ドチヌラド（dotinurad）

商品名: ユリス カテゴリ: RX-08 脂質異常症・代謝（尿酸降下薬） 剤型・規格: 錠 1mg 薬価: 42.40円 薬品区分: 普通薬

薬理

  • 選択的尿酸再吸収阻害薬（SURI: Selective Urate Reabsorption Inhibitor）
  • 近位尿細管のURAT1を選択的に阻害し尿酸の再吸収を抑制して尿酸排泄を促進する
  • ベンズブロマロンと比較しURAT1への選択性が高く、他のトランスポーターへの影響が少ない
  • 肝代謝（グルクロン酸抱合）、T1/2: 添付文書を参照

適応

  • 痛風
  • 高尿酸血症

用法用量

  • 成人: 1回0.5mg 1日1回から開始。維持量2mg（1mg錠×2錠）。最大4mg/日
  • 小児: 適応なし
  • 腎機能低下時: 添付文書を参照（中等度までは使用可能）
  • 肝機能低下時: 重度肝障害は慎重投与（ベンズブロマロンより安全性は良好）

禁忌・注意

  • 禁忌: 重篤な腎障害（eGFR 30未満）
  • 慎重投与: 腎結石の既往、肝障害
  • 相互作用:
    • アスピリン → 尿酸排泄促進効果の減弱
    • NSAID → 尿酸排泄に影響の可能性
  • 副作用:
    • 重大: 肝機能障害（ベンズブロマロンより頻度低い）
    • 頻度高: 痛風関節炎（治療初期）、肝酵素上昇

処方のポイント

  • 痛風発作予防: 開始時はコルヒチンカバーを考慮（0.5mg/日、3-6ヶ月間）
  • ベンズブロマロンの重篤な肝障害リスクを回避できる新世代の尿酸排泄促進薬
  • 尿路結石予防: 十分な飲水＋尿アルカリ化（ベンズブロマロンと同様の注意）
  • 漸増が必要（急激な尿酸低下による痛風発作予防）
  • 1日1回投与でアドヒアランス良好
