サワシリン（アモキシシリンカプセル「日医工」等）/ アモキシシリン（amoxicillin）

商品名: サワシリン / 後発: アモキシシリンカプセル「日医工」, ワイドシリン細粒 カテゴリ: RX-01 感染症治療薬（ペニシリン系） 剤型・規格: カプセル250mg / 細粒10%（サワシリン）/ 細粒20%（ワイドシリン） 薬価: 10.40円（後発カプセル250mg）/ 7.20円/g（細粒10%）/ 11.80円/g（後発細粒20%） 薬品区分: 普通薬

薬理

  • ペニシリン系抗菌薬（広域アミノペニシリン）
  • 細菌の細胞壁合成（PBP: ペニシリン結合蛋白）を阻害し殺菌的に作用
  • グラム陽性菌（溶連菌、肺炎球菌等）を中心に広い抗菌スペクトル
  • 経口吸収率が高い（約80%）
  • 腎排泄型 → 腎機能低下時は用量調整を考慮
  • T1/2 約1-1.5時間（添付文書を参照）

適応

  • 咽頭・扁桃炎（溶連菌性）、中耳炎、副鼻腔炎
  • 肺炎（肺炎球菌性）
  • 尿路感染症
  • H. pylori除菌（PPI/P-CAB + CAMとの3剤併用）
  • 皮膚軟部組織感染症
  • 歯性感染症
  • 適応外（参考）: 感染性心内膜炎予防（歯科処置前）

用法用量

  • 成人: 1回250mg 1日3-4回 経口投与
  • H. pylori除菌: 1回750mg 1日2回（PPI/P-CAB + CAMと併用、7日間）
  • 小児: 体重1kgあたり20-40mg（力価）を1日3-4回に分割 経口投与
  • 腎機能低下時: GFR 10-30の場合は投与間隔延長を検討（添付文書を参照）

禁忌・注意

  • 禁忌: ペニシリン系薬剤に対する過敏症の既往
  • 慎重投与: セフェム系アレルギーの既往（交差アレルギー1-2%）、伝染性単核症（発疹誘発）
  • 相互作用:
    • ワルファリン → PT-INR上昇の可能性
    • メトトレキサート → 排泄遅延による毒性増強
  • 妊婦: 使用可（FDA旧分類B相当、臨床使用実績豊富）
  • 授乳婦: 使用可（乳汁移行あるが少量）
  • 副作用:
    • 頻度高: 下痢・軟便（5-10%）、発疹
    • 重大: アナフィラキシー（稀）、偽膜性大腸炎（稀）

処方のポイント

  • 溶連菌性咽頭炎の第一選択薬（10日間投与）
  • 急性中耳炎ガイドラインでも第一選択
  • 経口ペニシリンとして最も汎用性が高い
  • 耐性菌（β-ラクタマーゼ産生菌）にはCVA/AMPC（クラバモックス）で対応
  • 抗菌薬投与時は耐性乳酸菌（ビオフェルミンR等）の併用を検討
  • 細粒10%と20%の使い分け: 20%（ワイドシリン）は少量で同等量投与可能

  • 250-AP-01（急性膀胱炎）
  • 050-AP-10（H.pylori）: 除菌レジメン構成薬
  • 330-AP-01（小児感冒）: 溶連菌合併時

  • 採用: あり
  • 備考: カプセルは後発品の記載なし。細粒は先発（サワシリン10%）と後発（ワイドシリン20%）の2種あり

採用がない場合の代替案

  • 剤型変更で対応可能
  • 同効代替薬: CVA/AMPC配合剤（クラバモックス）は上位互換だが適応が異なる
  • 注意: AMPCからセフェム系への変更時はスペクトルの違いに留意
クラバモックス / クラブラン酸・アモキシシリン配合（CVA/AMPC）

商品名: クラバモックス小児用配合ドライシロップ カテゴリ: RX-01 感染症治療薬（ペニシリン系 + β-ラクタマーゼ阻害薬） 剤型・規格: 配合ドライシロップ 636.5mg/包（0.505g/包, 1.01g/包） 薬価: 107.40円/g 薬品区分: 普通薬

薬理

  • β-ラクタマーゼ阻害薬（クラブラン酸）+ ペニシリン系抗菌薬（アモキシシリン）の配合剤
  • クラブラン酸がβ-ラクタマーゼを不可逆的に阻害し、AMPCの分解を防ぐ
  • AMPC耐性のβ-ラクタマーゼ産生菌にも有効
  • 小児用ドライシロップ製剤のみ（成人用経口剤は国内未発売）

適応

  • β-ラクタマーゼ産生菌を含む広範囲の細菌感染症
  • 特に: AMPC単剤で無効の中耳炎、副鼻腔炎
  • 小児: 適応あり（本剤は小児用製剤）

用法用量

  • 小児: AMPC高用量として96.4mg/kg/日、1日2回 食前に経口投与
  • 体重20kg未満: 約1包（0.505g）/10kg/回を目安に処方（体重別の包数で調整）
  • 成人: 適応なし（小児用製剤のため）

禁忌・注意

  • 禁忌: ペニシリン系過敏症の既往
  • 慎重投与: セフェム系アレルギーの既往（交差アレルギー）、伝染性単核症（発疹誘発）
  • 相互作用: AMPC単剤と同様（ワルファリン、メトトレキサート等）
  • 腎機能低下時: AMPCに準じる。高度腎障害時は投与間隔延長を検討（添付文書を参照）
  • 妊婦: AMPCに準じ使用可（FDA旧分類B相当）。ただし本剤は小児用製剤のため成人（妊婦）への処方は適応外
  • 授乳婦: AMPC単剤と同様に使用可（乳汁移行あるが少量）
  • 副作用:
    • 頻度高: 下痢・軟便（クラブラン酸による消化管刺激でAMPC単剤より下痢が多い、約10-20%）、発疹
    • 重大: アナフィラキシー（稀）、偽膜性大腸炎（稀）

処方のポイント

  • AMPC単剤で効果不十分な小児中耳炎・副鼻腔炎に使用
  • 食前投与（吸収率改善）
  • 下痢が多いため、耐性乳酸菌の併用を推奨
  • 成人への使用は適応外（成人にはオーグメンチン配合錠が一般的だが調剤薬局では非採用）

CureStation テンプレートとの関連

  • 280-AP-07（急性中耳炎）: AMPC無効時の二次選択
  • 040-AP-06（急性副鼻腔炎）

調剤薬局での採用状況

  • 採用: あり

採用がない場合の代替案

  • 同効代替薬: AMPC高用量（ワイドシリン細粒）で対応可。ただしβ-ラクタマーゼ産生菌にはカバー不十分
  • 薬局での取り寄せ: 翌営業日入荷可能
ジスロマック / アジスロマイシン（azithromycin）

商品名: ジスロマック カテゴリ: RX-01 感染症治療薬（マクロライド系） 剤型・規格: 錠剤 250mg 薬価: 145.40円（先発ジスロマック錠250mg） 薬品区分: 普通薬

薬理

  • 15員環マクロライド系抗菌薬
  • 細菌リボソーム50Sサブユニットに結合し蛋白合成を阻害（静菌的）
  • 組織移行性が極めて高く、組織内濃度は血中の10-100倍に達する
  • 3日間投与で7日間効果が持続（組織内貯留による）
  • 肝代謝（CYP3A4への影響はクラリスロマイシンより弱い）
  • T1/2 約68時間（添付文書を参照）

適応

  • 呼吸器感染症（肺炎、気管支炎）
  • マイコプラズマ肺炎
  • 皮膚・軟部組織感染症
  • クラミジア感染症（尿道炎、子宮頸管炎）
  • 副鼻腔炎
  • 歯周組織炎、歯冠周囲炎
  • 小児: 適応あり（錠剤が服用可能な場合）

用法用量

  • 成人: 1回500mg（2錠）1日1回 3日間 経口投与
  • 尿道炎・子宮頸管炎: 1回1000mg（4錠）単回投与

禁忌・注意

  • 禁忌: 本剤・他のマクロライド系薬に対する過敏症
  • 慎重投与: 肝障害、心疾患（QT延長リスク）
  • 相互作用:
    • ワルファリン → PT-INR上昇の可能性
    • ジゴキシン → 血中濃度上昇
    • CYP3A4関連の相互作用はクラリスロマイシンより少ない
  • 妊婦: 治療上の有益性が危険性を上回る場合に投与
  • 授乳婦: 使用可（乳汁移行量は少量、AAP compatible）
  • 副作用:
    • 頻度高: 下痢・軟便（10-15%）、悪心、腹痛
    • 重大: アナフィラキシー、QT延長、肝機能障害、偽膜性大腸炎（いずれも稀）

処方のポイント

  • 3日間投与で治療完結するためアドヒアランスに優れる
  • マイコプラズマ肺炎にはペニシリン系無効のため本剤が第一選択
  • クラミジア感染症には単回投与で治療完結
  • CYP3A4阻害作用がクラリスロマイシンより弱く、薬物相互作用が少ない
  • 下痢の頻度が高い → 耐性乳酸菌の併用を検討
  • 耐性化が問題：不必要な処方を避ける

CureStation テンプレートとの関連

  • 020-AP-03（マイコプラズマ肺炎）: 第一選択
  • 020-AP-05（急性気管支炎）: 非定型菌カバー
  • 020-AP-01（細菌性肺炎）: 非定型肺炎カバー

調剤薬局での採用状況

  • 採用: あり（先発 ジスロマック錠250mg）
  • 備考: 後発品は非採用。小児用ドライシロップは非採用

採用がない場合の代替案

  • 同効代替薬: クラリスロマイシン錠200mg。ただし投与日数が長い（7-14日間）、CYP3A4阻害が強い点に注意
  • 小児でシロップが必要な場合: クラリスロマイシンDSで代替
クラリス（クラリスロマイシン錠「大正」等）/ クラリスロマイシン（clarithromycin）

商品名: クラリス / 後発: クラリスロマイシン錠「大正」, クラリスロマイシンDS「タカタ」 カテゴリ: RX-01 感染症治療薬（マクロライド系） 剤型・規格: 錠200mg / 小児用錠50mg / DS10%（小児用） 薬価: 24.90円（先発錠200mg）/ 11.90円（後発小児用錠50mg）/ 85.30円/g（先発DS）/ 57.90円/g（後発DS） 薬品区分: 普通薬

薬理

  • 14員環マクロライド系抗菌薬
  • 細菌リボソーム50Sサブユニットに結合し蛋白合成を阻害（静菌的）
  • 抗菌作用に加え、マクロライド少量長期療法としての抗炎症・免疫調節作用あり
  • 肝代謝（CYP3A4の強い阻害薬）→ 多くの薬物相互作用に注意
  • T1/2 約3-4時間（添付文書を参照）

適応

  • 呼吸器感染症（肺炎、気管支炎、副鼻腔炎）
  • マイコプラズマ肺炎
  • 耳鼻科感染症（中耳炎等）
  • H. pylori除菌（PPI/P-CAB + AMPCとの3剤併用）
  • 非結核性抗酸菌症（MAC症）
  • 適応外（参考）: 副鼻腔炎に対するマクロライド少量長期療法

用法用量

  • 成人: 1回200mg 1日2回 経口投与
  • H. pylori除菌: 1回200-400mg 1日2回（PPI/P-CAB + AMPCと併用、7日間）
  • 小児: 体重1kgあたり10-15mg（力価）を1日2-3回に分割 経口投与

禁忌・注意

イナビル / ラニナミビル（laninamivir）

商品名: イナビル カテゴリ: RX-01 感染症治療薬（抗インフルエンザウイルス薬） 剤型・規格: 吸入粉末剤 20mg 薬価: 2,098.10円/セット 薬品区分: 普通薬

  • 予防:

ボノサップパック400 / H. pylori一次除菌パック

商品名: ボノサップパック400 カテゴリ: RX-01 感染症治療薬（H. pylori除菌レジメン配合剤） 剤型・規格: パック（ボノプラザン20mg + AMPC750mg + CAM400mg のシート） 薬価: 464.60円/シート 薬品区分: 普通薬

薬理

  • H. pylori一次除菌用3剤パック製剤
    • ボノプラザン（P-CAB）: H+,K+-ATPaseをK+と競合的に阻害し強力に胃酸分泌抑制
    • アモキシシリン（AMPC）: ペニシリン系抗菌薬、H. pyloriの細胞壁合成阻害
    • クラリスロマイシン（CAM）: マクロライド系抗菌薬、蛋白合成阻害
  • ボノプラザンベースの除菌はPPIベースより除菌成功率が高い（90%以上）

適応

  • H. pylori感染胃炎
  • 胃潰瘍、十二指腸潰瘍におけるH. pylori除菌
  • 小児: 適応なし

用法用量

  • 1回1シート分（ボノプラザン20mg + AMPC750mg + CAM 1回200mg（1日2回、CAM計400mg/日））
  • 1日2回 朝夕食後 7日間 経口投与

禁忌・注意

  • 禁忌: 各構成薬剤の禁忌に準じる（ペニシリン系過敏症、アタザナビル・リルピビリン併用等）
  • 相互作用: クラリスロマイシンのCYP3A4阻害に基づく相互作用（詳細はCAMの項を参照）
  • 副作用: 下痢、味覚異常（CAM由来の苦味）、発疹

処方のポイント

  • H. pylori一次除菌の標準レジメン
  • 7日間の確実な服薬が除菌成功の鍵 → パック製剤で服薬を簡便化
  • 除菌判定は治療終了4週間以降に尿素呼気試験等で実施

CureStation テンプレートとの関連

  • 050-AP-10（H.pylori）

調剤薬局での採用状況

  • 採用: あり（先発 ボノサップパック400）
  • 備考: 1症例で1パック（7シート）を使用

採用がない場合の代替案

  • パック製剤がない場合: ボノプラザン錠20mg+ AMPC+ CAMを個別処方で代替可能
  • 注意: パック製剤は服薬簡便化のための製剤であり、構成薬は個別にも処方可能
クレナフィン / エフィナコナゾール外用液（efinaconazole）

商品名: クレナフィン カテゴリ: RX-01 感染症治療薬（抗真菌薬・外用） 剤型・規格: 爪外用液 10%（3.56g/瓶） 薬価: 1,396.80円/瓶 薬品区分: 普通薬

薬理

  • トリアゾール系抗真菌薬（外用・爪白癬専用）
  • 真菌細胞膜のエルゴステロール生合成（CYP51）を阻害
  • 爪甲への浸透性が高く、爪白癬の原因菌（皮膚糸状菌 Trichophyton rubrum等）に有効
  • 全身吸収はほぼない

適応

  • 爪白癬
  • 小児: 適応なし（使用経験が限られる）

用法用量

  • 1日1回 罹患爪全体に塗布
  • 治療期間: 約48週間（爪の生え替わりに要する期間）

禁忌・注意

  • 禁忌: 本剤に対する過敏症
  • 外用薬のため全身性の薬物相互作用はほぼない
  • 副作用: 爪囲の皮膚炎、紅斑（接触性）

処方のポイント

  • 経口抗真菌薬（イトラコナゾール、テルビナフィン）が使用できない場合の爪白癬治療
  • 肝機能障害・薬物相互作用で経口薬を避けたい患者に適する
  • 治療期間が約1年と長い → アドヒアランス維持が課題
  • ルコナック爪外用液5%（ルリコナゾール）と同効だが薬価が高い
  • 爪表面だけでなく爪と皮膚の境界部にも塗布するよう指導

採用がない場合の代替案

  • 同効代替薬: ルコナック爪外用液5%（ルリコナゾール）。同じ外用爪白癬治療薬。薬価はルコナックの方が安価（663.60円/瓶）
ルリコン（ルリコナゾール軟膏「イワキ」等）/ ルリコナゾール（luliconazole）

商品名: ルリコン / 後発: ルリコナゾール軟膏「イワキ」/ ルコナック爪外用液 カテゴリ: RX-01 感染症治療薬（抗真菌薬・外用） 剤型・規格: クリーム1%（10g/本）/ 軟膏1%（10g/本）/ 爪外用液5%（3.5g/瓶） 薬価: 28.80円/g（先発クリーム）/ 16.40円/g（後発軟膏）/ 663.60円/瓶（爪外用液） 薬品区分: 普通薬

  • イミダゾール系の中で最も強い抗真菌活性を持つとされる
  • 全身吸収はほぼない（外用）

適応

  • 白癬（足白癬、体部白癬、股部白癬）: クリーム・軟膏

  • 1日1回塗布でアドヒアランス良好

  • 足白癬: 病変部だけでなく足底全体に塗布するよう指導（再発予防）

ビオフェルミンR / 耐性乳酸菌製剤（ビオフェルミンR等）

商品名: ビオフェルミンR散 / レベニン散 / ビオフェルミンR錠 カテゴリ: RX-01（併用補助薬） 剤型・規格: 散0.6%（ビオフェルミンR）/ 散1.8%（レベニン）/ 錠6mg（ビオフェルミンR錠） 薬価: 6.50円/g（散）/ 6.10円/錠 薬品区分: 普通薬

薬理

  • 耐性乳酸菌製剤（Streptococcus faecalis等を含む）
  • ペニシリン系、セフェム系、マクロライド系等の抗菌薬に耐性を持つ乳酸菌
  • 抗菌薬による腸内菌叢の乱れを軽減し、下痢・軟便を予防
  • 抗菌薬と同時投与が可能（耐性を有するため抗菌薬存在下でも増殖可能）
  • 薬物動態: 腸管内で作用するため全身吸収はほぼない

適応

  • 抗菌薬投与時の腸内菌叢異常に伴う下痢・軟便
  • 適応外（参考）: 抗菌薬投与に伴うClostridium difficile感染症の予防（エビデンスは限定的）

用法用量

  • 成人: 1日3g（散）を3回に分割、食後に経口投与
  • 錠剤: 1回2錠 1日3回 食後
  • 小児: 年齢に応じて適宜減量（添付文書を参照）
  • 腎機能低下時: 用量調整不要（全身吸収はほぼなし）
  • 高齢者: 通常量で使用可

禁忌・注意

  • 禁忌: 本剤成分に過敏症の既往（極めて稀）
  • 相互作用: 臨床上問題となるものはない（抗菌薬との同時投与を目的とした製剤）
  • 妊婦: 使用可（全身吸収はほぼなし）
  • 授乳婦: 使用可
  • 副作用: 腹部膨満感（稀）。重篤な副作用の報告はほぼない
  • 注意: ビオフェルミンRは主にペニシリン系・セフェム系・マクロライド系に耐性。キノロン系への耐性は製剤により異なる → レベニンはキノロン系にも耐性あり

処方のポイント

  • 抗菌薬処方時のルーチン併用を検討
  • 製剤選択のポイント:
    • ビオフェルミンR: ペニシリン系・セフェム系・マクロライド系に耐性
    • レベニン: 上記に加えキノロン系にも耐性 → キノロン系処方時はレベニンが適する
  • ミヤBM（宮入菌）も抗菌薬耐性あり→ 酪酸菌製剤で腸管バリア機能を強化
  • 抗菌薬の投与期間と同期間の併用が一般的
  • 散剤と錠剤で効果に差はないが、散剤は小児への用量調整に適する

CureStation テンプレートとの関連

  • 各種抗菌薬処方テンプレートで併用薬として使用

調剤薬局での採用状況

  • 採用: あり

採用がない場合の代替案

  • 同効代替薬: ミヤBM細粒・錠（宮入菌製剤）。抗菌薬耐性あり
  • 注意: 一般の整腸剤（ビオフェルミン配合散等）は抗菌薬耐性がないため代替にならない
