解熱鎮痛薬・抗炎症薬

CS Drug Reference

各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。

カロナール（カロナール錠「あゆみ」等）/ アセトアミノフェン（acetaminophen）

商品名: カロナール / 後発: カロナール錠「あゆみ」他 カテゴリ: RX-02 解熱鎮痛薬・抗炎症薬 剤型・規格:

  • 錠 200mg / 300mg / 500mg
  • 細粒 20%（1g/包）
  • シロップ 2%
  • 坐剤 100mg / 200mg 薬価: 6.70円（後発錠200mg）/ 7.00円（300mg）/ 11.30円（500mg）/ 12.20円（細粒20%）/ 4.90円（シロップ2%）/ 20.90円（坐剤100mg・200mg） 薬品区分: 劇薬（錠500mg・細粒）/ 普通薬（錠200mg・300mg）

薬理

  • 非ピリン系解熱鎮痛薬
  • 中枢神経系のシクロオキシゲナーゼ阻害と視床下部の体温調節中枢に作用し、解熱・鎮痛効果を発揮
  • NSAIDsと異なり末梢での抗炎症作用は弱い → 胃粘膜障害・腎障害のリスクが低い
  • 肝代謝（グルクロン酸抱合、硫酸抱合、CYP2E1によるNAPQI生成）
  • T1/2 約2-3時間
  • 過量投与時はNAPQI蓄積による肝壊死 → N-アセチルシステイン（NAC）が解毒薬

適応

  • 各種疾患・症状に伴う疼痛
  • 発熱（感冒、急性上気道炎等）
  • 小児の解熱鎮痛（第一選択）
  • 変形性関節症、腰痛症

用法用量

  • 成人: 1回300-1000mg 4-6時間以上あけて投与。1日総量4000mgまで
  • 小児: 体重1kgあたり10-15mg/回。1日総量60mg/kgまで
  • 腎機能低下時: 重度腎障害では投与間隔を延長（添付文書を参照）
  • 肝機能低下時: 肝障害・肝硬変では減量。アルコール常飲者は肝毒性リスク増大
  • 高齢者: 通常量で使用可。肝機能に注意

禁忌・注意

  • 禁忌: 重篤な肝障害、本剤成分に過敏症の既往、アスピリン喘息（ただし添付文書上禁忌だが少量(300mg以下)で使用可とする見解あり（専門医判断））
  • 慎重投与: 肝障害、腎障害、心機能異常、アルコール多量常飲者、G6PD欠損
  • 相互作用:
    • ワルファリン → INR上昇（長期併用時）
    • カルバマゼピン、フェノバルビタール等（CYP2E1誘導）→ NAPQI産生増加、肝毒性リスク増大
    • アルコール → CYP2E1誘導による肝毒性リスク増大
  • 妊婦: 使用可（妊娠中の鎮痛薬として第一選択）。ただし妊娠後期の長期大量投与は動脈管早期閉鎖のリスク
  • 授乳婦: 使用可（乳汁移行量は少量）
  • 副作用:
    • 重大: 肝機能障害（過量投与時）、中毒性表皮壊死融解症・皮膚粘膜眼症候群（極めて稀）
    • 頻度高: 悪心（稀）

処方のポイント

  • 小児・妊婦の解熱鎮痛に第一選択
  • NSAIDsが使用できない患者（胃潰瘍既往、腎機能障害、アスピリン喘息）に有用
  • 鎮痛効果はNSAIDsに劣るが、安全性プロファイルが優れる
  • 1日4000mg上限を患者に明示。OTC薬との重複に注意（総合感冒薬にAAP含有）
  • 坐剤は経口摂取困難時（嘔吐時、小児の発熱）に有用。吸収がやや遅い
  • シロップは乳幼児の用量微調整に適する
  • 細粒は錠剤嚥下困難な患者や体重に応じた用量調整に有用

  • 010-AP-03（インフルB）: 解熱鎮痛
  • 010-AP-04（COVID-19）: 解熱鎮痛

調剤薬局での採用状況

  • 採用:
    • カロナール錠200（後発 ○）: 在庫200
    • カロナール錠300（後発 ○）: 在庫200
    • カロナール錠500（劇薬）: 在庫200
    • カロナール細粒20%（1g/包）（劇薬）: 在庫360（分包）+ 100（バラ）
    • カロナールシロップ2%（後発 ○）: 在庫500
    • アセトアミノフェン坐剤100mg「JG」（後発 ○）: 在庫100 / アンヒバ坐剤100mg: 在庫50
    • アセトアミノフェン坐剤200mg「JG」（後発 ○）: 在庫100 / アンヒバ坐剤200mg: 在庫50
  • 備考: 全剤型が揃っており供給安定

採用がない場合の代替案

  • 同一成分別規格: 全規格在庫あり → 規格切れの心配は低い
  • 同効代替薬: イブプロフェン錠200mg（在庫あり）。ただしNSAIDsのため適応・禁忌が異なる
  • 坐剤の代替: 100mg・200mgいずれも在庫あり。先発・後発両方対応可
ロキソニン（ロキソプロフェン錠「EMEC」等）/ ロキソプロフェンNa（loxoprofen sodium）

商品名: ロキソニン / 後発: ロキソプロフェン錠60mg「EMEC」他 カテゴリ: RX-02 解熱鎮痛薬・抗炎症薬 剤型・規格:

  • 錠 60mg
  • テープ 50mg（7×10cm）/ 100mg（10×14cm）
  • パップ 100mg（10×14cm 非温） 薬価: 10.10円（後発錠60mg）/ 12.70円（テープ50mg）/ 17.60円（テープ100mg・パップ100mg） 薬品区分: 普通薬

薬理

  • プロドラッグ型非ステロイド性抗炎症薬（NSAID）
  • 消化管で吸収後、肝臓で活性体（trans-OH体）に変換されてCOXを阻害
  • プロスタグランジン合成を抑制し、抗炎症・鎮痛・解熱作用を発揮
  • プロドラッグ型のため消化管障害が比較的少ない（他のNSAIDsと比較して）
  • T1/2 約1.3時間（活性代謝物）
  • 肝代謝、腎排泄

適応

  • 関節リウマチ、変形性関節症、腰痛症、肩関節周囲炎、頸肩腕症候群
  • 歯痛、術後疼痛、外傷後疼痛
  • 急性上気道炎の解熱・鎮痛
  • 外用剤: 変形性関節症、筋肉痛、外傷後の腫脹・疼痛

用法用量

  • 成人（経口）: 1回60mg 1日3回 食後に投与。頓用の場合は1回60mg（症状に応じ2錠まで可、1日総量180mg以内）
  • 外用テープ: 1日1回 患部に貼付
  • 外用パップ: 1日1回 患部に貼付
  • 小児: 適応なし（小児にはアセトアミノフェンを使用）
  • 腎機能低下時: 重篤な腎障害では禁忌。中等度では慎重投与
  • 高齢者: 副作用が出やすい。低用量・短期間使用を心がける

禁忌・注意

  • 禁忌: 消化性潰瘍、重篤な血液異常・肝障害・腎障害・心機能不全、アスピリン喘息、妊娠末期
  • 慎重投与: 消化性潰瘍既往、血液異常、肝障害、腎障害、心機能異常、高齢者、SLE
  • 相互作用:
    • ワルファリン → 抗凝固作用増強
    • メトトレキサート → MTX血中濃度上昇（腎排泄競合）
    • リチウム → Li血中濃度上昇
    • 降圧薬（ACE阻害薬、ARB、利尿薬）→ 降圧効果減弱、腎機能悪化
    • ニューキノロン系 → 痙攣誘発リスク
  • 妊婦: 妊娠末期は禁忌（動脈管早期閉鎖）。妊娠初期〜中期も可能な限り避ける
  • 授乳婦: 短期使用は可。添付文書を参照
  • 副作用:
    • 頻度高: 胃部不快感、腹痛、食欲不振、浮腫
    • 重大: 消化管出血・穿孔、ショック・アナフィラキシー、腎障害、肝障害、無顆粒球症
    • 外用剤: 貼付部位の紅斑、掻痒、接触性皮膚炎

処方のポイント

  • 日本で最も汎用されるNSAIDs。プロドラッグ型で消化管障害が比較的少ない
  • 頓用としての使い勝手が良い（効果発現が比較的速い）
  • 長期使用時はPPI併用を検討（特に高齢者、潰瘍既往）
  • テープ剤は湿布剤より密着性が高く剥がれにくい。パップ剤は冷却効果がある
  • 外用剤は全身性副作用が少ないが、大面積・長期使用では血中移行に注意
  • 腎機能低下患者ではアセトアミノフェンへの切替を検討

CureStation テンプレートとの関連

  • 010-AP-01（急性上気道炎）: 解熱鎮痛
  • 010-AP-06（急性扁桃炎）: 咽頭痛

調剤薬局での採用状況

  • 採用:
    • ロキソニン錠60mg（先発）: 在庫100
    • ロキソプロフェン錠60mg「EMEC」（後発 ○）: 在庫200
    • ロキソニンテープ100mg（先発）: 在庫210 / ロキソプロフェンNaテープ100mg「ユートク」（後発 ○）: 在庫210
    • ロキソニンテープ50mg（先発）: 在庫210 / ロキソプロフェンNaテープ50mg「ユートク」（後発 ○）: 在庫210
    • ロキソニンパップ100mg（先発）: 在庫140 / ロキソプロフェンNaパップ100mg「日医工」（後発 ○）: 在庫140
  • 備考: 先発・後発ともに全剤型在庫あり

採用がない場合の代替案

  • 同一成分別規格: テープ50mg/100mg、パップ100mg いずれも在庫あり
  • 同効代替薬: セレコキシブ錠（在庫あり）。COX-2選択的で消化管障害リスクが低い
  • 外用の代替: ジクロフェナクNa点眼液は眼科用のみ在庫
セレコックス（セレコキシブ錠「サワイ」）/ セレコキシブ（celecoxib）

商品名: セレコックス / 後発: セレコキシブ錠「サワイ」 カテゴリ: RX-02 解熱鎮痛薬・抗炎症薬 剤型・規格: 錠 100mg / 200mg 薬価: 9.30円（後発錠100mg）/ 13.80円（後発錠200mg） 薬品区分: 劇薬

薬理

  • COX-2選択的阻害型非ステロイド性抗炎症薬（NSAIDs）
  • COX-2を選択的に阻害しプロスタグランジン産生を抑制
  • COX-1への影響が少ない → 胃粘膜保護作用のPGE2を維持し、消化管障害リスクが低い
  • T1/2 約6-12時間
  • 肝代謝（CYP2C9）、腎排泄
  • スルホンアミド骨格を有する → サルファ剤アレルギーとの交差反応に注意

適応

  • 関節リウマチ、変形性関節症
  • 腰痛症、肩関節周囲炎、頸肩腕症候群
  • 手術後・外傷後・抜歯後の消炎・鎮痛

用法用量

  • 成人: 1回100-200mg 1日2回 朝夕食後に投与。最大1日400mgを超えない
  • 小児: 適応なし
  • 腎機能低下時: 重篤な腎障害では禁忌。中等度では慎重投与
  • 肝機能低下時: 重度肝障害では禁忌。中等度では減量を考慮
  • 高齢者: 低用量から開始。腎機能・消化管出血に注意

禁忌・注意

  • 禁忌: 消化性潰瘍、重篤な肝障害・腎障害・心機能不全、アスピリン喘息、冠動脈バイパス術周術期、スルホンアミド過敏症、妊娠末期
  • 慎重投与: 消化性潰瘍既往、血液異常、肝障害、腎障害、心機能異常、高血圧、高齢者
  • 相互作用:
    • ワルファリン → 抗凝固作用増強
    • リチウム → Li血中濃度上昇
    • フルコナゾール（CYP2C9阻害）→ セレコキシブ血中濃度上昇
    • ACE阻害薬・ARB → 降圧効果減弱、腎機能悪化
  • 妊婦: 妊娠末期は禁忌。それ以外の時期も可能な限り避ける
  • 副作用:
    • 頻度高: 腹痛、下痢、浮腫
    • 重大: 消化管出血・穿孔（従来型NSAIDsより頻度低い）、心血管イベント（長期高用量で注意）、肝障害、腎障害
    • 皮膚粘膜眼症候群（スルホンアミド骨格に関連）

処方のポイント

  • 消化管障害リスクが高い患者（高齢者、潰瘍既往、抗凝固薬併用）に適する
  • CLASS study: 従来型NSAIDsと比較して消化管障害が有意に少ない
  • 心血管リスクの高い患者への長期投与は注意（COX-2選択的阻害薬に共通の懸念）
  • ロキソプロフェンと異なりプロドラッグではないため、効果発現がやや遅い（定時投与向き）
  • 頓用にはロキソプロフェンが適する場合が多い

CureStation テンプレートとの関連

  • 整形外科系テンプレート（現行テンプレート対象外）

調剤薬局での採用状況

  • 採用: あり（後発 セレコキシブ錠「サワイ」100mg: 在庫200 / 200mg: 在庫100）
  • 備考: 先発セレコックスは非採用

採用がない場合の代替案

  • 同一成分別規格: 100mg / 200mg いずれも在庫あり
  • 同効代替薬: ロキソプロフェン錠60mg（在庫あり）。ただしCOX-2選択性なし、消化管障害リスクが高い
ブルフェン（イブプロフェン錠「NIG」）/ イブプロフェン（ibuprofen）

商品名: ブルフェン / 後発: イブプロフェン錠200mg「NIG」 カテゴリ: RX-02 解熱鎮痛薬・抗炎症薬 剤型・規格: 錠 200mg 薬価: 8.90円（後発錠200mg） 薬品区分: 普通薬

薬理

  • 非ステロイド性抗炎症薬（NSAID）
  • シクロオキシゲナーゼ（COX）を阻害しプロスタグランジン合成を抑制

  • アセトアミノフェン: 中枢性の解熱鎮痛作用
  • 2つの作用機序で相加的鎮痛効果

    • 中枢抑制薬（BZD、睡眠薬）→ 呼吸抑制・鎮静増強

    • 頻度高: 悪心・嘔吐（投与初期、約20-30%）、便秘、めまい、傾眠

  • 依存性は強オピオイドより低いが、長期使用では精神的依存に注意

プレドニン（プレドニゾロン錠「旭化成」）/ プレドニゾロン（prednisolone）

商品名: プレドニン / 後発: プレドニゾロン錠「旭化成」 カテゴリ: RX-02 解熱鎮痛薬・抗炎症薬（ステロイド内服） 剤型・規格: 錠 1mg / 5mg 薬価: 8.60円（1mg）/ 10.10円（先発プレドニン5mg） 薬品区分: 普通薬

  • 膠原病（SLE、関節リウマチ等）

  • 自己免疫疾患
  • ネフローゼ症候群
  • 血液疾患（ITP等）
  • 適応外（参考）: COVID-19中等症以上、痛風発作（NSAIDsが使えない場合）

  • 成人: 1日5-60mg 1-4回に分割経口投与（疾患・重症度により大幅に異なる）

  • 高齢者: 副作用（骨粗鬆症、感染症、糖尿病）のリスクが高い。最小有効量を使用

  • 禁忌: 本剤成分に過敏症の既往

  • 妊婦: 治療上の有益性が危険性を上回る場合に投与。口蓋裂リスクの報告あり（低リスク）

  • 血糖値モニタリング（特に糖尿病リスクのある患者）
