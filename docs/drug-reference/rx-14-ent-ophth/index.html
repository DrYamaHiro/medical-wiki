眼科・耳鼻科

CS Drug Reference

各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。

クラビット（レボフロキサシン点眼液「ニットー」「杏林」）/ レボフロキサシン点眼液（levofloxacin ophthalmic）

商品名: クラビット点眼液 / 後発: レボフロキサシン点眼液「ニットー」「杏林」 カテゴリ: RX-14 眼科・耳鼻科 剤型・規格: 点眼液 0.5%（5mL/瓶）/ 1.5%（5mL/瓶） 薬価: 23.50〜24.20円/mL（後発） 薬品区分: 普通薬

薬理

  • ニューキノロン系抗菌点眼薬
  • 細菌のDNAジャイレースおよびトポイソメラーゼIVを阻害し殺菌的に作用
  • 広範な抗菌スペクトル
  • 全身吸収はほぼなし

適応

  • 眼瞼炎、結膜炎、角膜炎、麦粒腫等の眼感染症

用法用量

  • 0.5%: 1回1滴、1日3回点眼
  • 1.5%: 1回1滴、1日3回点眼。重症例では1日5回以上の頻回点眼も考慮
  • 小児: 同様

禁忌・注意

  • 禁忌: 本剤過敏症
  • 妊婦・授乳婦: 有益性投与（点眼薬のため全身移行は極めて少ない）
  • 副作用: 刺激感（稀）

処方のポイント

  • 眼科感染症で最も汎用される抗菌点眼薬
  • 1.5%製剤は0.5%より高濃度で、重症例やコンプライアンス重視の場合に選択
  • 術前予防としても使用される
  • 防腐剤: BAK含有。ソフトCL装用中は外して点眼、5分以上後に再装用

CureStation テンプレートとの関連

調剤薬局での採用状況

  • 採用: あり（後発 0.5%「ニットー」5mL/瓶 + 1.5%「杏林」5mL/瓶）

採用がない場合の代替案

  • 同効代替薬: オフロキサシン点眼液（在庫あり）、トスフロキサシン点眼液（オゼックス、在庫あり）

  • 同効代替薬: ベンゼトニウム塩化物含嗽液（ネオステリングリーン、在庫あり）。殺菌目的なら代替可だが、口内炎・粘膜保護目的には不適
ネオステリングリーン / ベンゼトニウム塩化物含嗽液（benzethonium chloride gargle）

商品名: ネオステリングリーンうがい液 カテゴリ: RX-14 眼科・耳鼻科 剤型・規格: うがい液 0.2%（56mL/瓶） 薬価: 5.40円/mL 薬品区分: 普通薬

薬理

  • 陽イオン界面活性剤型殺菌消毒薬
  • 口腔内の細菌に対し殺菌作用
  • 全身吸収はほぼなし

適応

  • 口腔内の消毒、抜歯創を含む口腔創傷の感染予防、口内炎の補助的治療

用法用量

  • 本剤を水で約10〜50倍に希釈し、1日数回含嗽

処方のポイント

  • アズノール（抗炎症・創傷治癒）とは異なり殺菌目的
  • イソジンガーグルと同じ殺菌カテゴリだが、ヨードフリーでヨードアレルギーにも使用可
  • 歯科領域で多く使用される

禁忌・注意

  • 禁忌: 本剤成分に過敏症の既往
  • 副作用: 稀に口腔内刺激感

CureStation テンプレートとの関連

  • 010-AP-01〜03（急性上気道炎、口腔内消毒として）

調剤薬局での採用状況

  • 採用: あり（ネオステリングリーンうがい液0.2% 56mL/瓶）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: アズノールうがい液4%（在庫あり）。殺菌ではなく抗炎症目的だが咽頭痛には有効
SPトローチ / デカリニウム塩化物トローチ（dequalinium chloride）

商品名: SPトローチ「明治」 カテゴリ: RX-14 眼科・耳鼻科 剤型・規格: トローチ 0.25mg 薬価: 5.90円/錠 薬品区分: 普通薬

薬理

  • 殺菌消毒薬（第四級アンモニウム塩）
  • 口腔内細菌の細胞膜を破壊し殺菌作用
  • 全身吸収はほぼなし

適応

  • 咽頭炎、扁桃炎、口内炎における口腔内の殺菌・消毒

用法用量

  • 1回1錠、1日6回、口腔内で徐々に溶解させて使用

処方のポイント

  • 咽頭痛の対症療法
  • 噛んで飲み込まないよう患者指導
  • トラネキサム酸内服との併用が一般的

禁忌・注意

  • 禁忌: 本剤成分に過敏症の既往
  • 副作用: 稀に口腔内刺激感

CureStation テンプレートとの関連

  • 010-AP-01〜03（急性上気道炎、咽頭痛の対症療法として）

調剤薬局での採用状況

  • 採用: あり（後発 SPトローチ0.25mg「明治」）
  • 備考: なし

採用がない場合の代替案

  • 薬局での取り寄せ: 翌日入荷可能
  • 咽頭痛の代替対症療法: アズノールうがい液4%（在庫あり）、トラネキサム酸内服（在庫あり）
ケナログ（オルテクサー口腔用軟膏）/ トリアムシノロンアセトニド口腔用軟膏（triamcinolone acetonide oral）

商品名: ケナログ / 後発: オルテクサー口腔用軟膏 カテゴリ: RX-14 眼科・耳鼻科 剤型・規格: 口腔用軟膏 0.1%（5g/本） 薬価: 63.20円/g（後発） 薬品区分: 普通薬

薬理

  • 口腔粘膜用ステロイド軟膏（中程度）
  • 口腔粘膜に付着し局所の炎症を抑制
  • 全身吸収はほぼなし

適応

  • 口内炎（アフタ性、びらん性）、舌炎

用法用量

  • 1日1〜数回、適量を患部に塗布。口腔粘膜に密着させる

処方のポイント

  • 口内炎治療の標準的外用薬
  • 粘着性基剤で口腔内に付着し薬効を持続
  • 口内炎が2週間以上持続する場合は悪性疾患の鑑別が必要

禁忌・注意

  • 禁忌: 口腔内に感染を伴う患者（ウイルス性・真菌性・結核性）
  • 副作用: 稀に口腔内刺激感。長期連用で口腔カンジダ症のリスク

CureStation テンプレートとの関連

  • 該当テンプレートなし（口内炎の対症療法として使用）

調剤薬局での採用状況

  • 採用: あり（後発 オルテクサー口腔用軟膏0.1% 5g/本）
  • 備考: 在庫少量

採用がない場合の代替案

  • 薬局での取り寄せ: 翌日入荷可能
