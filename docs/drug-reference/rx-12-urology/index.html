ハルナール（タムスロシン塩酸塩OD錠「サワイ」等）/ タムスロシン（tamsulosin）

商品名: ハルナール / 後発: タムスロシン塩酸塩OD錠「サワイ」 カテゴリ: RX-12 泌尿器・腎臓（α1遮断薬） 剤型・規格: OD錠 0.1mg / 0.2mg 薬価: 18.50円（後発OD錠0.2mg）, 25.30円（先発D錠0.2mg） 薬品区分: 劇薬

薬理

  • 選択的α1A受容体遮断薬
  • 前立腺・尿道平滑筋のα1A受容体を選択的に遮断し、尿道内圧を低下させて排尿障害を改善
  • α1A選択性が高く、血管平滑筋のα1B受容体への影響が少ない → 起立性低血圧が比較的少ない
  • 肝代謝（CYP3A4, CYP2D6）
  • T1/2 添付文書を参照（OD錠で持続的な薬効）

適応

  • 前立腺肥大症に伴う排尿障害

用法用量

  • 成人: 1回0.2mgを1日1回 食後に経口投与
  • 小児: 適応なし
  • 腎機能低下時: 軽度-中等度では用量調整不要。重度腎障害では添付文書を参照
  • 肝機能低下時: 重篤な肝障害では慎重投与（血中濃度上昇の可能性）
  • 高齢者: 通常量で開始可

禁忌・注意

  • 禁忌: 本剤成分に過敏症
  • 慎重投与: 起立性低血圧のある患者、重篤な肝障害
  • 相互作用:
    • 他のα遮断薬（降圧薬として使用）→ 過度の血圧低下
    • PDE5阻害薬（シルデナフィル等）→ 降圧作用の増強
    • CYP3A4阻害薬 → 血中濃度上昇の可能性
  • 妊婦・授乳婦: 該当なし（男性への投与）
  • 副作用:
    • 頻度高: めまい・立ちくらみ、射精障害（逆行性射精）、鼻閉
    • 重大: 起立性低血圧、失神（稀）、肝機能障害
    • 眼科関連: 術中虹彩緊張低下症候群（IFIS）→ 白内障手術前に眼科医に服用歴を申告

処方のポイント

  • 前立腺肥大症に伴う排尿障害の第一選択薬（α1遮断薬の中で最も使用実績が豊富）
  • シロドシンに比べ起立性低血圧が少ないが、射精障害はいずれも起こりうる
  • 白内障手術予定がある場合は事前に休薬を検討（眼科医と相談）
  • OD錠は嚥下困難な高齢者に有用
  • 効果発現は比較的速い（数日〜1週間で排尿症状の改善）
  • デュタステリドとの併用（α遮断薬+5ARI）は大きな前立腺肥大に有効

調剤薬局での採用状況

  • 採用: あり（後発 タムスロシン塩酸塩OD錠0.2mg「サワイ」、先発 ハルナールD錠0.2mg）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: シロドシン。α1A選択性がより高いが射精障害がやや多い
ユリーフ（シロドシンOD錠「サワイ」等）/ シロドシン（silodosin）

商品名: ユリーフ / 後発: シロドシンOD錠「サワイ」, シロドシン錠「ニプロ」 カテゴリ: RX-12 泌尿器・腎臓（α1遮断薬） 剤型・規格: OD錠 4mg, 錠 4mg 薬価: 10.40円（後発OD錠4mg）, 10.40円（後発錠4mg） 薬品区分: 劇薬

薬理

  • 選択的α1A受容体遮断薬（タムスロシンよりもα1A選択性が高い）
  • 前立腺・尿道平滑筋のα1A受容体を高選択的に遮断し排尿障害を改善
  • 血管平滑筋への影響がさらに少ない
  • 肝代謝（CYP3A4, UGT2B7）
  • T1/2 添付文書を参照

適応

  • 前立腺肥大症に伴う排尿障害

用法用量

  • 成人: 1回4mgを1日2回、朝夕食後に経口投与
  • 小児: 適応なし
  • 腎機能低下時: 重度腎障害（CLcr<30）では慎重投与。血中濃度上昇の可能性
  • 肝機能低下時: 重篤な肝機能障害は禁忌
  • 高齢者: 通常量で開始可

禁忌・注意

  • 禁忌: 本剤成分に過敏症、重篤な肝機能障害
  • 慎重投与: 起立性低血圧、肝障害
  • 相互作用:
    • CYP3A4阻害薬 → 血中濃度上昇
    • 他のα遮断薬 → 過度の血圧低下
    • PDE5阻害薬 → 降圧作用の増強
  • 妊婦・授乳婦: 該当なし（男性への投与）
  • 副作用:
    • 頻度高: 射精障害（逆行性射精、20-30%と高頻度 → タムスロシンより多い）、口渇、鼻閉
    • 重大: 肝機能障害、起立性低血圧
    • 術中虹彩緊張低下症候群（IFIS）→ 白内障手術前に申告

処方のポイント

  • α1A選択性がα遮断薬中最も高く、排尿障害改善効果が強い
  • 射精障害が高頻度（20-30%）→ 性活動を重視する患者にはタムスロシンを優先
  • 1日2回投与が必要（タムスロシンは1日1回）→ アドヒアランス面でやや不利
  • OD錠は嚥下困難な高齢者に有用
  • 白内障手術前のIFISリスクはタムスロシンと同様に注意

フリバス（後発品なし）/ ナフトピジル（naftopidil）

商品名: フリバス カテゴリ: RX-12 泌尿器・腎臓（α1遮断薬） 剤型・規格: 錠 25mg / 50mg / 75mg, OD錠 薬価: 添付文書を参照 薬品区分: 普通薬

薬理

  • α1D受容体選択性の高いα1受容体遮断薬
  • 膀胱三角部・膀胱頸部のα1D受容体を遮断し、蓄尿症状（頻尿、尿意切迫感）の改善に寄与
  • タムスロシン・シロドシンのα1A選択性とは異なるサブタイプ選択性
  • 肝代謝（CYP3A4, CYP2C9）
  • T1/2 添付文書を参照

適応

  • 前立腺肥大症に伴う排尿障害

用法用量

  • 成人: 1日25mgから開始、1-2週後に50-75mgへ増量。1日1回 食後に経口投与
  • 小児: 適応なし
  • 腎機能低下時: 添付文書を参照
  • 肝機能低下時: 慎重投与
  • 高齢者: 低用量から開始

禁忌・注意

  • 禁忌: 本剤成分に過敏症
  • 慎重投与: 起立性低血圧、肝障害
  • 相互作用:
    • 降圧薬 → 降圧作用の増強
    • PDE5阻害薬 → 血圧低下リスク
  • 妊婦・授乳婦: 該当なし（男性への投与）
  • 副作用:
    • 頻度高: めまい、立ちくらみ、胃腸障害
    • 重大: 起立性低血圧、肝機能障害（稀）
    • 射精障害はタムスロシン・シロドシンより少ない

処方のポイント

  • 蓄尿症状（頻尿・尿意切迫感）が主訴の場合に選択されることがある
  • 射精障害がα1A遮断薬より少ない → 性活動を重視する患者に有利
  • 排尿症状（尿勢低下等）への効果はタムスロシン・シロドシンにやや劣るとの報告
  • 降圧作用がやや強い → 高血圧合併例には一石二鳥、低血圧例には注意

アボルブ（デュタステリドカプセル「日医工」等）/ デュタステリド（dutasteride）

商品名: アボルブ / 後発: デュタステリドカプセル「日医工」 カテゴリ: RX-12 泌尿器・腎臓（5α還元酵素阻害薬 / 5ARI） 剤型・規格: カプセル 0.5mg 薬価: 22.90円（後発0.5mg AV） 薬品区分: 劇薬

薬理

  • 5α還元酵素阻害薬（Ⅰ型・Ⅱ型のデュアル阻害）
  • テストステロンからジヒドロテストステロン（DHT）への変換を阻害
  • 前立腺を縮小させ、排尿障害を改善
  • フィナステリド（Ⅱ型のみ阻害）よりDHT抑制が強力
  • T1/2 約3-5週間（非常に長い）→ 効果持続が長いが中止後も長期間影響が残る
  • 肝代謝（CYP3A4）

適応

  • 前立腺肥大症

用法用量

  • 成人: 1回0.5mgを1日1回経口投与
  • 食事の影響: 食事に関係なく投与可
  • 小児: 禁忌
  • 腎機能低下時: 用量調整不要
  • 肝機能低下時: 重篤な肝機能障害は禁忌。軽度-中等度では慎重投与
  • 高齢者: 用量調整不要

禁忌・注意

  • 禁忌: 女性（特に妊婦・妊娠している可能性のある女性 → カプセルに触れることも禁忌。皮膚からDHTが吸収され男性胎児の外性器異常を起こす可能性）、小児、重篤な肝機能障害
  • 慎重投与: 肝機能障害
  • 相互作用:
    • CYP3A4阻害薬 → 血中濃度上昇の可能性（臨床的に問題になることは稀）
  • 副作用:
    • 頻度高: 性機能障害（リビドー低下、勃起不全、射精障害）、乳房障害（女性化乳房、乳房圧痛）
    • 重大: 肝機能障害
    • PSA値を約50%低下させる → 前立腺癌スクリーニング時にPSA値を2倍して評価する必要がある

処方のポイント

  • 前立腺体積が30mL以上の大きな前立腺肥大に特に有効
  • 効果発現に3-6ヶ月かかる → 患者に説明し早期の中止を防ぐ
  • α遮断薬との併用（タムスロシン+デュタステリド）が大きな前立腺肥大の標準治療
  • PSA低下作用に注意: 前立腺癌スクリーニング時はPSA値を2倍にして解釈
  • T1/2が非常に長い → 中止後も6ヶ月間は効果・副作用が持続する可能性
  • 女性・小児が触れないよう患者指導（カプセルが破損した場合の皮膚吸収リスク）
  • 献血制限: 投与中止後6ヶ月間は献血不可

ザルティア（後発品なし）/ タダラフィル（tadalafil）

商品名: ザルティア（前立腺肥大症用） カテゴリ: RX-12 泌尿器・腎臓（PDE5阻害薬） 剤型・規格: 錠 2.5mg / 5mg 薬価: 添付文書を参照 薬品区分: 劇薬

薬理

  • ホスホジエステラーゼ5（PDE5）阻害薬
  • PDE5を阻害しcGMP分解を抑制 → 前立腺・尿道・膀胱頸部の平滑筋弛緩
  • 前立腺・膀胱の血流改善効果も関与
  • T1/2 約17.5時間（長い）→ 1日1回投与で24時間効果持続
  • 肝代謝（CYP3A4）

適応

  • 前立腺肥大症に伴う排尿障害（ザルティア）
  • ※EDに対するシアリスとは製剤名・適応が異なる

用法用量

  • 成人: 1回2.5mgを1日1回から開始。1-2週後に5mgへ増量。1日1回経口投与
  • 腎機能低下時: CLcr<30では2.5mgから開始し慎重に
  • 肝機能低下時: 軽度-中等度では慎重投与。重度では使用回避

  • 禁忌: 消化管・尿路の器質的閉塞、迷走神経緊張症、脱分極性筋弛緩薬投与中
  • 最重要注意: コリン作動性クリーゼ（過量投与時に致死的）
    • 症状: 縮瞳、徐脈、唾液分泌過多、呼吸困難、筋攣縮
    • 拮抗薬: アトロピン
  • 慎重投与: 気管支喘息、消化性潰瘍、甲状腺機能亢進症、パーキンソン病
  • 相互作用:
    • 他のChE阻害薬 → コリン作動性クリーゼのリスク増大
    • β遮断薬 → 徐脈の増強
  • 妊婦・授乳婦: 妊婦は有益性投与。授乳婦は添付文書を参照
  • 副作用:
    • 頻度高: 腹痛、下痢、悪心、唾液分泌過多
    • 重大: コリン作動性クリーゼ（重篤: 徐脈、呼吸抑制、意識障害）

処方のポイント

  • 低活動膀胱（排尿筋低活動）による排尿困難に使用
  • コリン作動性クリーゼのリスクがあり、投与量と症状の定期的な評価が必須
  • 高齢者では特に慎重に（徐脈、消化器症状のリスク）
  • 抗コリン薬（OAB治療薬等）とは作用が正反対 → 併用は通常行わない
  • 排尿困難の原因が前立腺肥大による閉塞の場合はα遮断薬が第一選択（ジスチグミンは排尿筋低活動の場合）

ブラダロン（後発品なし）/ フラボキサート（flavoxate）

商品名: ブラダロン カテゴリ: RX-12 泌尿器・腎臓（排尿障害治療薬） 剤型・規格: 錠 200mg 薬価: 添付文書を参照 薬品区分: 普通薬

薬理

  • 泌尿器科用鎮痙薬
  • 膀胱平滑筋に直接作用し、排尿筋の異常収縮を抑制
  • ホスホジエステラーゼ阻害作用およびCa拮抗作用による平滑筋弛緩
  • 抗コリン作用は弱い → 口渇・便秘が少ない
  • 肝代謝
  • T1/2 添付文書を参照

適応

  • 頻尿、残尿感、排尿痛等の膀胱刺激症状
  • 尿路結石・膀胱炎等に伴う膀胱刺激症状

用法用量

  • 成人: 1回200mgを1日3回経口投与
  • 小児: 添付文書を参照
  • 腎機能低下時: 添付文書を参照
  • 肝機能低下時: 添付文書を参照
  • 高齢者: 通常量で開始可

禁忌・注意

  • 禁忌: 幽門・十二指腸閉塞、消化管出血、閉塞隅角緑内障
  • 慎重投与: 前立腺肥大症（排尿困難悪化の可能性）
  • 相互作用: 臨床的に重要なものは少ない
  • 妊婦・授乳婦: 妊婦は有益性投与。授乳婦は添付文書を参照
  • 副作用:
    • 頻度高: 悪心、食欲不振、腹部膨満感
    • 重大: 特記すべきものなし

処方のポイント

  • 膀胱炎・尿路結石に伴う膀胱刺激症状（頻尿、排尿痛）の対症療法に使用
  • 抗コリン薬に比べ口渇・便秘が少なく忍容性が高い
  • OABに対する効果は抗コリン薬やβ3作動薬に劣る → OABにはビベグロン等を優先
  • 尿路感染症の膀胱刺激症状には抗菌薬と併用
  • 1日3回投与が必要 → アドヒアランス面でやや不利

セルニルトン（後発品なし）/ セルニチンポーレンエキス（cernitin pollen extract）

商品名: セルニルトン カテゴリ: RX-12 泌尿器・腎臓（前立腺炎治療薬） 剤型・規格: 錠 薬価: 19.00円（先発） 薬品区分: 普通薬

薬理

  • 花粉由来植物エキス製剤
  • 前立腺の炎症・浮腫を改善し、排尿障害を軽減する
  • 抗炎症作用、抗浮腫作用、膀胱平滑筋弛緩作用
  • 正確な薬理機序は完全には解明されていない

適応

  • 慢性前立腺炎に伴う排尿困難、残尿感、頻尿

用法用量

  • 成人: 1回2錠を1日2-3回経口投与
  • 小児: 適応なし
  • 腎機能低下時: 添付文書を参照
  • 肝機能低下時: 添付文書を参照
  • 高齢者: 通常量で開始可

禁忌・注意

  • 禁忌: 本剤成分に過敏症（花粉アレルギーとの交差反応は稀だが注意）
  • 相互作用: 臨床的に問題となるものは報告されていない
  • 妊婦・授乳婦: 該当なし（男性への投与が主）
  • 副作用:
    • 頻度高: 胃腸障害（少ない）
    • 重大: 特記すべきものなし

処方のポイント

  • 慢性前立腺炎/慢性骨盤痛症候群（CP/CPPS）の補助療法
  • 副作用が極めて少なく長期投与に適する
  • 効果はマイルドで、単独では不十分な場合が多い → α遮断薬やNSAIDsとの併用
  • 花粉エキスだが、花粉症との交差反応は通常問題にならない
