ツムラ葛根湯（1番）/ 葛根湯（かっこんとう）

商品名: ツムラ葛根湯エキス顆粒（医療用）【ツムラ1番】 カテゴリ: RX-15 漢方薬 剤型・規格: エキス顆粒 2.5g/包 薬価: 13.40円/g 薬品区分: 普通薬

構成生薬

  • 葛根（カッコン）4.0g、麻黄（マオウ）3.0g、桂皮（ケイヒ）2.0g
  • 芍薬（シャクヤク）2.0g、甘草（カンゾウ）2.0g
  • 大棗（タイソウ）3.0g、生姜（ショウキョウ）2.0g
  • ※甘草含有（2.0g/日）→ 偽アルドステロン症に注意
  • ※麻黄含有 → エフェドリン含有のため交感神経刺激作用に注意

薬理

  • 発汗解表作用で風邪の初期症状を改善
  • 麻黄のエフェドリン: 交感神経刺激による気管支拡張・発汗促進
  • 葛根: 解熱・鎮痙作用

適応

  • 感冒の初期（汗をかいていないもの）
  • 肩こり、筋肉痛、頭痛
  • 証: 比較的体力のある人（実証〜中間証）

用法用量

  • 成人: 1日7.5g（2.5g x 3包）分2〜3 食前又は食間
  • 小児: 年齢に応じて適宜減量

禁忌・注意

  • 禁忌: アルドステロン症、ミオパチー、低K血症
  • 慎重投与: 高血圧、心疾患、甲状腺機能亢進症（麻黄含有のため）、前立腺肥大（排尿困難悪化の可能性）
  • 相互作用: 甘草含有製剤との併用 → 偽アルドステロン症リスク、MAO阻害薬（麻黄のエフェドリンとの相互作用）
  • 副作用: 発汗過多、動悸（麻黄による）、偽アルドステロン症

処方のポイント

  • 風邪の初期で「寒気があり汗をかいていない」状態に使用
  • 汗をかいている場合は桂枝湯（ツムラ45番）が適する
  • 発症48時間以内の投与が効果的
  • 高齢者や虚弱者には麻黄附子細辛湯を検討
  • 肩こりにも有効（葛根の筋弛緩作用）

調剤薬局での採用状況

  • 採用: あり（ツムラ葛根湯エキス顆粒 2.5g/包）
  • 備考: なし

採用がない場合の代替案

  • 同効代替薬: 麻黄湯（ツムラ27番、在庫あり）。ただし発汗作用がより強いため虚弱者には注意
  • 肩こり目的の場合: 桂枝茯苓丸（ツムラ25番、在庫あり）を検討
