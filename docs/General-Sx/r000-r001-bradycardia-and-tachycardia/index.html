[R00.0/R00.1] 徐脈・頻脈 / Bradycardia and Tachycardia

📋 主訴・所見・診察前対応

主訴・ROS

全身症状

発熱: なし / 微熱 / 高熱 / 弛張熱, 期間: ＿週間 倦怠感: なし / 朝強い / 夕方強い / 一日中 / 活動後増悪 体重変化: なし / 減少: ＿kg[＿ヶ月で] ；意図しない減少はRedFlag その他: 寝汗 / 関節痛 / 皮疹

💡 Dr.Advice

[Red Flags] 「意図しない体重減少」「寝汗（結核・リンパ腫）」「鎖骨上窩リンパ節腫脹（Virchow転移）」「側頭動脈の圧痛（巨細胞性動脈炎）」は危険信号。徹底的な精査が必要。

[設備制約] 当院にはCT・エコーがないため、深部リンパ節、膿瘍、固形腫瘍の評価はできない。Red Flagsがある場合や、初期スクリーニングで原因不明の場合は、抱え込まずに総合病院へ紹介せよ。

評価

  • 徐脈（HR 60未満）:
  • 洞性徐脈（生理的: アスリート、睡眠時）
  • 薬剤性（β遮断薬、Ca拮抗薬、ジゴキシン）
  • 甲状腺機能低下症
  • 房室ブロック: 1度/2度Mobitz I → 経過観察可 vs 2度Mobitz II/3度 → ペースメーカー適応、循環器紹介
  • 洞不全症候群
  • 頻脈（HR 100以上）:
  • 洞性頻脈（発熱、脱水、貧血、甲状腺機能亢進症、心不全、疼痛、不安）
  • 上室性頻拍（PSVT/AVNRT）: 突然発症・突然停止が特徴
  • 心房細動/粗動
  • 心室頻拍（Wide QRS → 緊急）
  • 検査: 12誘導心電図（全例必須）、TSH/FT4、CBC、BNP。持続性の場合Holter心電図。

方針・処方

  • 【洞性徐脈（無症候性）】経過観察。
  • 【薬剤性徐脈】被疑薬の減量・中止。
  • 【高度房室ブロック（2度Mobitz II/3度）】循環器紹介（ペースメーカー評価）。
  • 【洞性頻脈】原因治療: 脱水 → 補液、貧血 → 鉄剤、甲状腺機能亢進症 → 抗甲状腺薬。
  • 【PSVT】迷走神経刺激（バルサルバ手技、顔面冷水浸漬）→ 無効ならATP急速静注6mg → 循環器紹介。
  • 【Wide QRS頻拍】VTとして対応 → 循環器緊急コンサルト。

処方・アクション​

PSVT停止

[Rx-Gen-PSVT-ATP] ATP急速静注（PSVT停止用）
  • アデノシン三リン酸ナトリウム（ATP）6mg 急速静注（ボーラス）→ 直後に生食20mLフラッシュ

※最も末梢の静脈ルートから投与。無効時12mgで再投与可 ※除細動器・モニターを必ず準備の上で投与すること

検査セット

[Rx-Gen-Brady-Lab] 徐脈・頻脈精査セット
  • 12誘導心電図
  • TSH、FT4
  • CBC（貧血評価）
  • BNP（心不全評価） [Rx-Gen-Brady-Holter] Holter心電図（持続性・発作性不整脈の場合）
  • 24時間Holter心電図

指導・計画​

  • 薬剤性徐脈: 被疑薬リストを確認し、処方医と連携して減量・中止を検討。
  • PSVT: 発作時の迷走神経刺激法（バルサルバ手技）を患者に指導。
  • 再診目安: 心電図結果に応じて1-2週後。循環器紹介の場合は紹介先受診後にフォロー。

💡 Dr.Advice

[Wide QRS] Wide QRS（0.12秒以上）の頻拍はVTとして扱え。SVTとの鑑別に迷ったらVTとして対応するのが安全。

[薬剤性] 徐脈の最多原因は薬剤性。処方歴を必ず確認せよ。β遮断薬+非DHP系Ca拮抗薬の併用は特に危険。

[ATP] ATP急速静注は「アデホス-Lコーワ」ではなく「アデノシン三リン酸ナトリウム（ATP）」として準備。半減期が極めて短いため最も末梢の静脈ルートから急速（ボーラス）投与し直後にフラッシュ。

📖 詳細解説​

徐脈（HR 60回/分未満）と頻脈（HR 100回/分以上）は、プライマリケアで遭遇頻度の高いバイタルサイン異常である。多くは生理的反応や薬剤性であるが、致死的不整脈の初期徴候であることもあり、12誘導心電図による鑑別が必須である。

病態生理​

刺激伝導系の基本

  • 洞結節（SA node）→ 心房 → 房室結節（AV node）→ His束 → 右脚/左脚 → プルキンエ線維 → 心室筋
  • 洞結節の固有調律: 60-100回/分
  • 房室結節の固有調律: 40-60回/分
  • 心室固有調律: 20-40回/分

徐脈の病態

  • 洞性徐脈: 洞結節からの興奮発生が低下。生理的（アスリート心臓、睡眠時、迷走神経緊張）または病的（洞不全症候群、甲状腺機能低下症、低体温、薬剤性）。
  • 洞不全症候群（SSS）: 洞結節の器質的障害。Rubenstein分類 -- I型: 持続性洞性徐脈、II型: 洞停止・洞房ブロック、III型: 徐脈頻脈症候群（bradycardia-tachycardia syndrome）。
  • 房室ブロック:
分類心電図所見臨床的意義
1度PR間隔延長（0.20秒超）、全P波が伝導通常無害、経過観察
2度 Mobitz I型（Wenckebach）PR間隔が漸次延長し1拍脱落AV node内のブロック、予後良好
2度 Mobitz II型PR間隔一定で突然脱落His束以下のブロック、完全房室ブロックへ進行リスク高い
3度（完全房室ブロック）P波とQRS波が完全に独立補充調律に依存、Adams-Stokes発作のリスク
  • 薬剤性徐脈（最多原因）: β遮断薬、非DHP系Ca拮抗薬（ベラパミル、ジルチアゼム）、ジゴキシン、アミオダロン。β遮断薬 + 非DHP系Ca拮抗薬の併用は特に危険。

頻脈の病態

  • 洞性頻脈: 生理的反応（発熱、脱水、貧血、疼痛、不安、運動）または病的状態（甲状腺機能亢進症、心不全、肺塞栓症、敗血症）の反映。原因の検索と治療が本質。
  • 発作性上室性頻拍（PSVT）:
    • AVNRT（房室結節リエントリー性頻拍）: 最多（約60%）。房室結節内の二重伝導路を介するリエントリー。
    • AVRT（房室回帰性頻拍）: WPW症候群に伴う。副伝導路を介するリエントリー。
    • 特徴: 突然発症・突然停止（on-off現象）、HR 150-250回/分、narrow QRS。
  • 心房細動（AF）: 心房の無秩序な興奮。絶対性不整脈（RR間隔不整）。脳梗塞リスクの評価（CHADS2スコア）と抗凝固療法の検討が必要。
  • 心室頻拍（VT）: 心室起源の頻拍。Wide QRS（0.12秒以上）。心室細動（VF）へ移行するリスクがあり、最も危険な不整脈の一つ。

診断基準・鑑別疾患​

12誘導心電図による鑑別（全例必須）

Narrow QRS頻拍（0.12秒未満）の鑑別

不整脈特徴
洞性頻脈P波正常、HR通常150未満、徐々に変化
PSVT（AVNRT）HR 150-250、P波不明瞭（QRS内に埋没）、RR整
心房細動RR絶対不整、f波、P波なし
心房粗動鋸歯状F波（特にII/III/aVF）、HR 150前後（2:1伝導）

Wide QRS頻拍（0.12秒以上）の鑑別

  • 原則: Wide QRS頻拍はVTとして対応する -- これが最も安全な臨床ルール
  • VTを否定できる根拠がない限り、SVTの変行伝導と判断してはならない
  • Brugada基準等の鑑別アルゴリズムがあるが、迷った場合はVTとして扱う

徐脈の鑑別

評価項目確認内容
薬剤歴β遮断薬、Ca拮抗薬、ジゴキシン、アミオダロン
甲状腺機能TSH、FT4（甲状腺機能低下症の除外）
電解質高カリウム血症（徐脈+tent-T）
心電図PR間隔、P-QRS関係、QRS幅
症状の有無失神、めまい、息切れ、倦怠感

エビデンス・ガイドライン推奨​

徐脈の管理（日本循環器学会 不整脈治療ガイドライン準拠）

  • 無症候性洞性徐脈: 経過観察。アスリート心臓では安静時HR 40台でも正常。
  • 薬剤性徐脈: 被疑薬の減量・中止が第一。急性期で血行動態不安定な場合はアトロピン0.5mg静注（最大3mgまで反復可）。
  • 2度Mobitz II型/3度房室ブロック: ペースメーカー植込みの適応 → 循環器専門医への紹介が必須。

ペースメーカーの適応（クラスI: 強く推奨）

  • 症候性の3度房室ブロック
  • 症候性の2度Mobitz II型房室ブロック
  • 徐脈に伴う失神（Adams-Stokes発作）
  • 症候性洞不全症候群（SSS）

洞性頻脈の管理

  • 洞性頻脈そのものは治療対象ではなく、原因の検索と治療が本質
  • 必須の原因検索: 発熱、脱水、貧血（CBC）、甲状腺機能亢進症（TSH/FT4）、心不全（BNP）、肺塞栓症（D-dimer）、敗血症

PSVTの急性期管理

  1. 迷走神経刺激法（第一選択）:
    • Modified Valsalva法: 仰臥位で45度挙上、息こらえ15秒後に仰臥位に戻し両下肢を45度挙上して15秒保持。成功率43%（通常Valsalvaの17%より優れる）。
    • 顔面冷水浸漬（diving reflex）: 氷水に顔を10-15秒間浸す。小児で特に有効。
    • 頸動脈洞マッサージ: 高齢者では脳梗塞リスクがあり慎重に（頸動脈雑音がないことを確認）。
  2. ATP急速静注（迷走神経刺激無効時）:
    • アデノシン三リン酸ナトリウム（ATP）10mg 急速静注（ボーラス）
    • 直後に生食20mLでフラッシュ（半減期が極めて短い: 10秒未満）
    • 最も末梢の静脈ルートから投与
    • 無効時: 20mgで再投与可（日本のATP製剤の用量。海外のアデノシン6mg/12mgとは等価ではない）
    • 一過性の洞停止・胸部不快感が出現するが通常数秒で消失
    • 禁忌: 喘息（気管支攣縮誘発）、2度以上の房室ブロック、WPW+AF（VF誘発リスク）
    • 必ず除細動器・モニターを準備の上で投与
  3. 停止しない場合: 循環器専門医へコンサルト。ベラパミル5mg緩徐静注等を検討。

Wide QRS頻拍（VTとして対応）

  • 血行動態不安定（意識障害、ショック）: 即座に電気的除細動（同期カルディオバージョン）
  • 血行動態安定: 循環器緊急コンサルト。アミオダロン静注等を検討。
  • ベラパミルの静注はWide QRS頻拍には禁忌（VTの場合に血行動態が破綻する）
