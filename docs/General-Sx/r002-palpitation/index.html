[R00.2] 動悸 / Palpitation

📋 主訴・所見・診察前対応

💡 Dr.Advice

[Red Flags] 「意図しない体重減少」「寝汗（結核・リンパ腫）」「鎖骨上窩リンパ節腫脹（Virchow転移）」「側頭動脈の圧痛（巨細胞性動脈炎）」は危険信号。徹底的な精査が必要。

[設備制約] 当院にはCT・エコーがないため、深部リンパ節、膿瘍、固形腫瘍の評価はできない。Red Flagsがある場合や、初期スクリーニングで原因不明の場合は、抱え込まずに総合病院へ紹介せよ。

評価

  • 鑑別診断:
  1. 不整脈: 心房細動、期外収縮（上室性/心室性）、PSVT、WPW症候群。
  2. 頻脈性（二次性）: 甲状腺機能亢進症、貧血、脱水、発熱。
  3. 心因性: パニック障害、全般性不安障害。
  4. 薬剤性: β刺激薬、カフェイン、テオフィリン。
  • 精査: 12誘導心電図、Holter心電図、甲状腺機能（TSH, FT4）、CBC、BNP。

方針・処方

  • 心電図で不整脈を確認し、該当疾患の治療へ移行。
  • 器質的心疾患除外のため心エコー検討（当院不可 → 循環器へ紹介）。
  • 頻脈性は原因治療を優先（甲状腺、貧血、脱水等）。
  • 心因性の場合は安心保証 + 必要に応じて精神科紹介。

処方・アクション​

検査セット

[Rx-Gen-Palp-ECG] 12誘導心電図（安静時）
  • 全例に施行 [Rx-Gen-Palp-Holter] Holter心電図
  • 非発作時の12誘導心電図が正常の場合、24時間記録で不整脈を捕捉 [Rx-Gen-Palp-Lab] 血液検査
  • TSH, FT4, CBC, BNP ；二次性頻脈の除外

紹介

[Doc-Gen-Referral] 診療情報提供書（循環器内科へ: 心エコー精査、不整脈精査）

指導・計画​

  • Holter装着時の指導: 「動悸を感じたらイベントボタンを押す」よう説明。
  • カフェイン・アルコール・睡眠不足の確認と生活指導。
  • 再診目安: 検査結果返却時（1-2週間後）。

💡 Dr.Advice

[Red Flag] 失神を伴う動悸、労作時の動悸＋胸痛、持続する頻脈（HR 150以上）は致死性不整脈の可能性がある。速やかに循環器へ紹介せよ。

[Holter] 非発作時の12誘導心電図では異常を捉えられないことが多い。「動悸を感じたらイベントボタンを押す」よう指導してHolter検査を施行せよ。

[カフェイン] 動悸の訴えでまず確認すべきはカフェイン摂取量。エナジードリンク多飲は若年者の動悸の主因。問診で必ず確認せよ。

📖 詳細解説​

動悸（palpitation）は「心臓の拍動を不快に自覚する症状」と定義される。プライマリケア外来における頻度の高い主訴であり、原因は不整脈性と非不整脈性に大別される。大多数は良性であるが、致死性不整脈の除外が最優先課題である。

病態生理​

動悸の病態は大きく2つに分類される。

1. 不整脈性動悸（心臓自体のリズム異常）

  • 心房細動（AF）: 心房の無秩序な電気的興奮により不規則な心室応答が生じる。有病率は加齢とともに上昇し、80歳以上で約10%。脳塞栓のリスクがあり、CHADS2スコアによるリスク層別化が必要。
  • 発作性上室性頻拍（PSVT）: 房室結節リエントリー頻拍（AVNRT）が最多（約60%）。突然発症・突然停止する規則的な頻拍（HR 150-250 bpm）が特徴。迷走神経刺激（Valsalva法、頸動脈洞マッサージ）で停止することがある。
  • 心室期外収縮（PVC）: 最も頻度が高い不整脈。健常者の50-75%にHolterで検出される。単発・無症候性であれば基本的に良性だが、頻発（総心拍の10%以上）では心機能低下をきたす可能性がある。
  • WPW症候群: 副伝導路（Kent束）を介した頻拍。delta波が心電図上の特徴。AFを合併するとVFに移行するリスクがある。

2. 非不整脈性動悸（心臓外の原因による洞性頻脈・拍動増強）

  • 甲状腺機能亢進症: 甲状腺ホルモン過剰により心拍数増加、心拍出量増大。バセドウ病では約10%にAFを合併。
  • 貧血: Hb低下による代償性の心拍数増加・1回拍出量増加。Hb 7g/dL未満で症状が顕在化しやすい。
  • 脱水: 循環血液量減少に伴う反射性頻脈。
  • カフェイン: アデノシン受容体拮抗によるカテコラミン放出促進。エナジードリンク1本にカフェイン80-300mg含有。
  • パニック障害: 自律神経系の過活動による動悸・発汗・振戦。動悸を主訴に循環器を受診する患者の約15-30%に認める。

診断基準・鑑別疾患​

診断アプローチ

検査目的備考
12誘導心電図不整脈の検出、QT延長、WPW、Brugada型の確認全例必須。発作時に記録できれば診断率が飛躍的に向上
Holter心電図（24時間）非発作時の心電図が正常な場合に不整脈を捕捉症状が毎日ある場合に有用。週1回以下の頻度ならイベントレコーダーを検討
血液検査TSH、FT4（甲状腺）、CBC（貧血）、BNP（心不全）、電解質二次性頻脈の除外
心エコー器質的心疾患（弁膜症、心筋症）の評価心雑音あり、BNP高値、心電図異常の場合に施行

鑑別のポイント

  • 突然発症・突然停止 → PSVT（AVNRT、AVRT）
  • 不規則な動悸 → AF、多発PVC
  • 脈が飛ぶ感じ → PVC（代償性休止期に「ドキッ」と感じる）
  • 持続的な頻脈+体重減少・手指振戦 → 甲状腺機能亢進症
  • 労作時動悸+息切れ → 貧血、心不全、弁膜症
  • 動悸+過呼吸+しびれ+恐怖感 → パニック障害

Red Flags（緊急対応が必要）

  • 失神を伴う動悸 → 致死性不整脈（VT/VF）、大動脈弁狭窄症
  • 労作時の動悸+胸痛 → 虚血性心疾患、肥大型心筋症
  • 持続する頻脈（HR 150 bpm以上）→ AF with rapid ventricular response、SVT
  • 突然死の家族歴+動悸 → Brugada症候群、QT延長症候群、ARVC

エビデンス・ガイドライン推奨​

  • 日本循環器学会「不整脈薬物治療ガイドライン（2020年改訂版）」: 動悸の初期評価として12誘導心電図を全例に施行（推奨クラスI）。症状と心電図所見の相関が得られない場合、Holter心電図またはイベントレコーダーの使用を推奨。
  • AF検出: 2020年ESCガイドラインでは、65歳以上の患者で脈拍の自己検脈またはデバイスによるスクリーニングを推奨（クラスI）。日本では脳卒中予防の観点からCHADS2スコア1点以上でDOAC開始を推奨。
  • PSVT: 迷走神経刺激法（Modified Valsalva法: 40mmHgの呼気努力後に仰臥位で下肢挙上）は通常のValsalvaより停止率が有意に高い（43% vs 17%, REVERT trial, Lancet 2015）。
  • 良性PVC: 器質的心疾患がなく、PVC burden 10%未満であれば経過観察可。症状が強い場合はβ遮断薬（ビソプロロール2.5-5mg/日等）が第一選択。
  • パニック障害の鑑別: 動悸を主訴に受診した患者の約15-30%がパニック障害との報告がある。器質的疾患の除外後、PHQ（Patient Health Questionnaire）等のスクリーニングツールが有用。
