[K70] アルコール性肝障害 / Alcoholic Liver Disease

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 検診異常 / 右季肋部痛 / 心窩部痛 / 背部痛 / 黄疸 / 倦怠感

消化器・肝胆膵

腹痛: なし / 右季肋部 / 心窩部 / 背部, 性状: 鈍痛 / 疝痛 / 持続的 自覚症状: 皮膚掻痒感 / 尿の色が濃い / 悪心 / 食欲不振

リスク・背景

飲酒歴: なし / あり: ＿ ml × ＿ 日/週 [種類: ビール/日本酒/焼酎] 体重変化: なし / 増加 / 減少 ＿kg 既往歴: 輸血歴 / タトゥー / 胆石 / 糖尿病 / 脂質異常症

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃ 身体計測: 身長 ＿cm, 体重 ＿kg, BMI ＿

腹部

肝・脾: 触知せず / 肝腫大 / 脾腫 圧痛: なし / 右季肋部 / 心窩部, Murphy徴候: 陰性 / 陽性

皮膚・眼

黄疸: なし / 眼球結膜 / 皮膚 肝硬変徴候: 手掌紅斑 / クモ状血管腫 / 腹壁静脈怒張 / なし

検査 (外注)

肝臓詳細セット (AST/ALT/γGTP/Bil/ALP/Alb/PT/Plt/ウイルス) 腫瘍マーカーセット (AFP/PIVKA-II/CEA/CA19-9)

診察前対応

検査 (外注)

[Lab-Hep-Full] 肝臓詳細セット[Lab-Hep-Tumor] 腫瘍マーカーセット

💡 Dr.Advice

[設備制約] 当院には腹部エコーおよびCTがない。肝臓の形状評価、胆石の有無、胆管拡張の確認ができないため、身体所見で異常（黄疸、Murphy徴候、腫瘤）があれば、迷わず画像診断可能な施設へ紹介せよ。

[FIB-4 Index] 脂肪肝を見たら必ずFIB-4 indexを算出せよ。スコア2.67以上の場合は肝硬変への進展リスクが高いため、肝臓専門医へ紹介すること。

評価

  • 診断根拠: 過剰なアルコール摂取歴（純エタノール60g/日以上）。γGTP優位の上昇。AST>ALTパターン。
  • 禁酒意思: あり / なし

方針・処方

  • 治療戦略: 断酒・節酒指導が治療の全てである。
  • 肝庇護薬の投与、重症例（肝不全徴候あり）は専門医紹介。

処方・処置 (選択)​

肝庇護薬

[Rx-Hep-Urs] ウルソ(肝庇護)
  • ウルソ錠100mg 1回1錠 1日3回 毎食後 28日分

注射 (AST/ALT著高時)

[Inj-Hep-Pro] 強力ネオミノファーゲンシー
  • 強力ネオミノファーゲンシー静注20mL 1管 静脈内注射

指導・計画 (必須)​

  • 患者指導: 断酒の必要性を説明。
  • 再診目安: 2-4週間後。

💡 Dr.Advice

[説得] 「肝臓が悲鳴を上げている」と数値を具体的に示して警告せよ。γGTPは断酒により速やかに改善するため、モチベーション維持の指標にしやすい。

📖 詳細解説​

病態生理​

  • 定義: 長期間の過剰飲酒（エタノール換算 男性60g/日以上、女性40g/日以上）に起因する肝障害
  • スペクトラム: アルコール性脂肪肝 → アルコール性肝炎 → アルコール性肝線維症 → アルコール性肝硬変
  • アルコール性肝炎: 大量飲酒後の急性発症。重症型は致死率30-50%
  • 病態: アセトアルデヒドによる直接毒性、酸化ストレス、腸内細菌叢の変化、内毒素血症

飲酒量とリスクの関係​

純エタノール換算量の目安（飲酒量 = 飲酒量mL x アルコール度数 x 0.8）:

飲料1単位の目安純エタノール量
ビール（5%）中瓶500mL 1本約20g
日本酒（15%）1合180mL約22g
焼酎（25%）0.6合110mL約22g
ウイスキー（40%）ダブル60mL約19g
ワイン（12%）グラス2杯240mL約23g
  • 低リスク飲酒: 純エタノール 20g/日以下（日本の健康日本21基準）
  • 危険飲酒: 男性 40g/日以上、女性 20g/日以上で肝障害リスク上昇
  • 肝硬変リスク: 80g/日以上を10-15年以上継続で肝硬変リスクが著明に上昇
  • 女性は感受性が高い: 男性の2/3の飲酒量で同等の肝障害が生じる

AUDIT-Cスコア（簡易スクリーニング）​

AUDIT全10項目の短縮版。プライマリケアでの問題飲酒スクリーニングに有用:

質問0点1点2点3点4点
Q1: どのくらいの頻度で飲酒するか飲まない月1回以下月2-4回週2-3回週4回以上
Q2: 飲酒日の飲酒量（ドリンク数）1-2杯3-4杯5-6杯7-9杯10杯以上
Q3: 1度に6杯以上飲む頻度ない月1回未満月1回週1回毎日or殆ど毎日
  • カットオフ: 男性 5点以上、女性 4点以上で問題飲酒を疑う。**AUDIT-C計算ツール**で簡便に評価可能
  • 感度: 問題飲酒の検出に対し86%、特異度72%
  • 臨床的意義: 外来で30秒で実施可能。陽性例にはAUDIT全10項目やCAGE質問票で精査

診断基準・鑑別疾患​

  • 診断: 飲酒歴 + AST優位のトランスアミナーゼ上昇（AST/ALT比 2以上が特徴）+ gamma-GTP上昇
  • 鑑別: MASLD、薬剤性肝障害、自己免疫性肝炎、ウイルス性肝炎

Maddrey判別関数（Discriminant Function: DF）​

重症アルコール性肝炎の予後予測と治療適応決定に使用:

  • 計算式: DF = 4.6 x（患者PT秒 - 対照PT秒）+ 総ビリルビン（mg/dL）
  • 解釈:
    • DF 32未満: 軽症〜中等症。支持療法で対応。1ヶ月死亡率 約10%
    • DF 32以上: 重症アルコール性肝炎 → ステロイド療法の適応。1ヶ月死亡率 30-50%
  • ステロイド療法: プレドニゾロン 40mg/日を4週間投与、その後4週間で漸減
  • Lilleモデル: ステロイド開始7日後にビリルビンの変化で治療反応を評価。Lilleスコア 0.45以上はステロイド非反応例（中止を検討）
  • ステロイド禁忌例: 活動性消化管出血、コントロール不良の感染症、肝腎症候群、多臓器不全
  • MELD（Model for End-Stage Liver Disease）スコア: 21以上も重症の指標となる

エビデンス・ガイドライン推奨​

  • 断酒: 唯一の根本治療。断酒により脂肪肝は数週間で改善、線維化も改善しうる
  • 重症アルコール性肝炎: プレドニゾロン40mg/日 4週間（DF 32以上で適応）
  • 栄養療法: アルコール性肝障害患者は栄養不良が多い。高蛋白食・BCAA補充。1日35-40kcal/kg、蛋白1.2-1.5g/kgを目標
  • 肝硬変進展時: 肝硬変の一般管理に準じる（食道静脈瘤スクリーニング、肝癌サーベイランス）
  • アルコール依存症の治療: ナルメフェン（セリンクロ）10mg 飲酒1-2時間前に頓用（頓用薬であり連日服用ではない。最大1日1回まで）、アカンプロサート（レグテクト）333mg 1日3回。精神科・依存症専門医との連携
  • ブリーフインターベンション: 10-15分の短時間介入で飲酒量を有意に減少させるエビデンスあり。FRAMES（Feedback, Responsibility, Advice, Menu, Empathy, Self-efficacy）に基づく動機づけ面接
