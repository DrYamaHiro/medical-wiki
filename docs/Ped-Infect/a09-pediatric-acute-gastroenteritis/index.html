[A09] 小児急性胃腸炎 / Pediatric Acute Gastroenteritis

📋 主訴・所見・診察前対応

主訴・ROS

発熱: あり ＿℃ / なし 機嫌・活気: 良い / 悪い / あやすと笑う / ぐったり / 視線が合わない 食欲・哺乳: 良好 / 低下 / 全く飲めない 排尿: 良好 / 半日以上なし・濃い ；脱水評価

呼吸器

咳: 乾性 / 湿性 / 犬吠様, 鼻汁: 水様 / 膿性 喘鳴: なし / ヒューヒュー / ゼロゼロ

消化器

嘔吐: なし / あり, 下痢: なし / あり

接触歴

周囲の流行: RS / ヒトメタ / 手足口 / アデノ / インフル / コロナ / 溶連菌 / マイコ 保育園・学校での流行: なし / あり

所見・検査

バイタル: BT ＿℃, SpO2 ＿%, HR ＿ bpm, RR ＿ /min

全身

顔色: 紅潮 / 蒼白 / チアノーゼ, 皮膚ツルゴール: 正常 / 低下 大泉門: 平坦 / 陥凹 / 膨隆, CRT: <2秒 / 延長

呼吸

呼吸様式: 正常 / 陥没呼吸 / 鼻翼呼吸 / シーソー呼吸 聴診: 清明 / Wheeze / Rhonchi / Crackles

頭頸部・皮膚

咽頭: 発赤 / 扁桃腫大 / 白苔・膿栓, 中耳炎所見: なし / あり 発疹: なし / 水疱 / 紅斑 / 紫斑, BCG痕: 正常 / 発赤

迅速検査

RSウイルス 陽性 / 陰性 アデノウイルス 陽性 / 陰性 ヒトメタニューモ 陽性 / 陰性 溶連菌 陽性 / 陰性 インフルエンザ 陽性 / 陰性 COVID-19 陽性 / 陰性

診察前対応

迅速検査

[Lab-Ped-RSV] RSウイルス[Lab-Ped-Adeno] アデノウイルス[Lab-Ped-hMPV] ヒトメタニューモ[Lab-Gen-Strep] 溶連菌[Lab-Gen-Influenza] インフルエンザ[Lab-Gen-COVID] COVID-19

💡 Dr.Advice

[トリアージの要点] ①即時対応 (重症感あり): SpO2<95%、チアノーゼ、意識障害（ぐったり）、大泉門膨隆、紫斑（髄膜炎菌疑い）→ 緊急対応。 ②要注意 (ハイリスク): 生後3ヶ月未満の発熱、3日以上続く高熱、水分が全く取れない → 早急に検査・方針決定。 ③機嫌・活気が最重要: 体温の高さよりも「あやすと笑う・視線が合う」かどうかが重症度判定の核心である。 ④ハイリスク回避: 「親の直感」（「いつもと違う」）は有力な情報である。親の不安が強い場合は確認検査を行うことで受診の安心につながる。

評価

  • 小児の急性胃腸炎。ウイルス性が大半（ロタウイルス、ノロウイルス、アデノウイルス）。
  • 脱水評価が最重要: 軽度（3-5%体重減）: 口渇、尿量やや減少 中等度（6-9%体重減）: 皮膚ツルゴール低下、CRT延長、眼窩陥凹 重度（10%以上体重減）: ショック徴候（頻脈、血圧低下、意識障害）

方針・処方

  • 【軽度〜中等度脱水】ORS（経口補水液）による経口補水療法（ORT）が第一選択（点滴より有効: Cochrane 2006）。
  • ORS投与量: 軽度 50mL/kg/4時間、中等度 100mL/kg/4時間をスプーンで少量ずつ。
  • 嘔吐がある場合: 嘔吐後5分待ってからスプーン1杯ずつ再開（嘔吐はORTの禁忌ではない）。
  • 制吐薬: ナウゼリン坐剤（体重10-15kg: 10mg、15-30kg: 30mg）→ 嘔吐コントロール後にORT。
  • 【重度脱水・経口摂取不能】点滴（生理食塩水20mL/kg急速 → 維持輸液）。
  • 止痢薬: ロペミンは5歳未満禁忌。整腸剤（ビオフェルミンR等）は可。
  • 食事: 早期からの食事再開が推奨（絶食不要）。乳児は母乳/ミルク継続。

処方・アクション​

制吐薬

[Rx-Ped-GE-Dompe] ナウゼリン坐剤（嘔吐時）
  • ナウゼリン坐剤10mg（体重10-15kg）/ 30mg（体重15-30kg）1個 嘔吐時挿肛

整腸剤

[Rx-Ped-GE-Probio] ビオフェルミンR散
  • ビオフェルミンR散 1回0.5-1g 1日3回 毎食後 5日分

輸液（重度脱水時）

[Rx-Ped-GE-NS] 生理食塩水（初期急速輸液）
  • 生理食塩水 20mL/kg 急速点滴 → 改善評価後、維持輸液へ移行

指導・計画​

  • ORS（OS-1等）をスプーン1杯ずつ、5分ごとに与える方法を保護者に指導。
  • 食事は制限せず、本人が食べられるものを少量ずつ再開。
  • 便の回数・性状、尿の有無を記録するよう指導。
  • 再診目安: 翌日（脱水悪化がないか確認）。Red Flag出現時は直ちに受診。

💡 Dr.Advice

[脱水評価] 小児の脱水は「体重減少率」が最も正確な指標。直近の体重と比較せよ。

[ORT] 「吐いているのに飲ませるのか」と保護者は不安がる。「スプーン1杯ずつなら吐かないことが多い。点滴より体に優しく、効果も同等」と説明せよ。

[Red Flag] 6時間以上排尿なし、泣いても涙が出ない、ぐったりしている、血便 → 直ちに入院精査。

[抗菌薬] ウイルス性胃腸炎に抗菌薬は不要。細菌性を疑う場合（血便、高熱遷延、渡航歴）のみ便培養提出。

📖 詳細解説​

小児急性胃腸炎は小児の最も頻度の高い感染症の一つであり、5歳未満の小児は年間1-2回罹患する。先進国では死亡はまれであるが、脱水による入院は依然として多い。原因の80%以上はウイルス性であり、抗菌薬は通常不要。治療の柱は脱水の評価と経口補水療法（ORT）である。

病態生理​

主要な原因微生物

病原体特徴好発年齢・季節
ロタウイルス最も重症化しやすいウイルス性胃腸炎。白色水様便が特徴。ワクチン導入後は入院例が激減（約80%減少）6ヶ月-2歳、冬季
ノロウイルス突然の噴射状嘔吐で発症。家族内・施設内での集団発生が多い。10-100個の少量ウイルスで感染成立全年齢、冬季
アデノウイルス（40/41型）下痢が7-14日間と長引く。嘔吐は軽度2歳未満、通年
サポウイルスノロウイルスに類似した症状。集団発生もある小児、通年
細菌性（カンピロバクター、サルモネラ等）血便、高熱を伴うことが多い。鶏肉・卵・生食の摂食歴夏季に多い

下痢の機序

  • 浸透圧性下痢: ロタウイルスが小腸絨毛上皮を破壊し、二糖類分解酵素（ラクターゼ等）が低下。未消化の糖が腸管内に貯留し浸透圧上昇。
  • 分泌性下痢: ウイルスのNSP4（ロタウイルスのエンテロトキシン）がCl-チャネルを活性化し、腸管内への水分分泌が亢進。

脱水の評価（体重減少率が最も正確）

重症度体重減少率臨床所見
脱水なし/軽度3-5%口渇、やや不機嫌、尿量やや減少
中等度6-9%皮膚ツルゴール低下、眼窩陥凹、CRT 2-3秒、涙減少、口腔粘膜乾燥
重度10%以上ショック徴候（頻脈、血圧低下）、意識障害、無尿、CRT 3秒以上

診断基準・鑑別疾患​

診断は臨床的に行う（検査は通常不要）

  • 典型的な病歴（急性発症の嘔吐+下痢+発熱、周囲の流行）で診断可能
  • 便培養の適応: 血便、高熱の遷延（5日以上）、渡航後下痢、免疫不全
  • 迅速抗原検査（ロタ、ノロ、アデノ）は確定診断に有用だが治療方針を変えることは少ない

鑑別すべき疾患

  • 腸重積: 間欠的な激しい啼泣（腹痛）+嘔吐+イチゴジャム状血便。2歳未満に好発。超音波でtarget sign。
  • 虫垂炎: 心窩部痛から右下腹部痛への移動（小児では非典型的なことが多い）。
  • 溶血性尿毒症症候群（HUS）: O157等の腸管出血性大腸菌感染後5-7日で発症。血便後の貧血+血小板減少+腎機能障害。
  • 糖尿病性ケトアシドーシス（DKA）: 嘔吐+脱水+意識障害。尿糖・血糖を確認。
  • 代謝異常: 先天性副腎過形成、先天性代謝異常（特に乳児期）

エビデンス・ガイドライン推奨​

経口補水療法（ORT）が第一選択

  • Cochrane systematic review（Hartling L, et al. 2006; updated 2013）: 軽度-中等度脱水の小児において、ORTはIV（静脈内）補液と同等の有効性を示し、入院期間の短縮、合併症の減少が確認された。ORTの失敗率は約4%のみ。
  • WHO/UNICEF、ESPGHAN、日本小児救急医学会のいずれもORTを第一選択として推奨。

ORS投与量

脱水程度ORS量投与方法
軽度50 mL/kg を4時間かけてスプーンまたはシリンジで5分ごとに少量ずつ
中等度100 mL/kg を4時間かけて同上。4時間後に再評価
  • 維持: 下痢1回につき10 mL/kg、嘔吐1回につき2 mL/kgを追加

嘔吐がある場合の対応

  • 嘔吐はORTの禁忌ではない。嘔吐後5分待ってからスプーン1杯（5mL）ずつ再開。
  • 頻回嘔吐でORT不能の場合: ドンペリドン坐剤で制吐後にORT再試行。
  • オンダンセトロン（制吐薬）: ESPGHAN 2014ガイドラインでは、頻回嘔吐でORT不能例にオンダンセトロン単回経口投与を推奨（NNT=5）。日本では小児適応外だが、海外では広く使用。

早期食事再開

  • 脱水補正後（4時間のORT後）は速やかに通常の食事を再開する。「お粥→うどん→普通食」のような段階的食事制限はエビデンスなし。
  • 乳児: 母乳は中断しない（脱水補正中も母乳は継続可）。ミルクの希釈は不要。
  • 乳糖除去ミルクへの変更: ロタウイルス等による遷延性下痢（7日以上）で乳糖不耐が疑われる場合のみ検討。

止痢薬・その他

  • ロペラミド: 5歳未満は禁忌（イレウス、中枢神経抑制のリスク）。
  • 整腸剤（プロバイオティクス）: Lactobacillus rhamnosus GGやSaccharomyces boulardiiは下痢期間を約1日短縮するエビデンスがある（ESPGHAN推奨）。ビオフェルミン等は使用可。
  • 抗菌薬: ウイルス性には不要。細菌性でも軽症であれば不要（カンピロバクターは自然治癒が多い）。適応は重症細菌性腸炎、菌血症リスクのある乳児、免疫不全患者に限る。
