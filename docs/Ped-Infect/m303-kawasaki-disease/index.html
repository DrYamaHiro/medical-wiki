[M30.3] 川崎病 / Kawasaki Disease

📋 主訴・所見・診察前対応

主訴・ROS

発熱: あり ＿℃ / なし 機嫌・活気: 良い / 悪い / あやすと笑う / ぐったり / 視線が合わない 食欲・哺乳: 良好 / 低下 / 全く飲めない 排尿: 良好 / 半日以上なし・濃い ；脱水評価

呼吸器

咳: 乾性 / 湿性 / 犬吠様, 鼻汁: 水様 / 膿性 喘鳴: なし / ヒューヒュー / ゼロゼロ

消化器

嘔吐: なし / あり, 下痢: なし / あり

接触歴

周囲の流行: RS / ヒトメタ / 手足口 / アデノ / インフル / コロナ / 溶連菌 / マイコ 保育園・学校での流行: なし / あり

所見・検査

バイタル: BT ＿℃, SpO2 ＿%, HR ＿ bpm, RR ＿ /min

全身

顔色: 紅潮 / 蒼白 / チアノーゼ, 皮膚ツルゴール: 正常 / 低下 大泉門: 平坦 / 陥凹 / 膨隆, CRT: <2秒 / 延長

呼吸

呼吸様式: 正常 / 陥没呼吸 / 鼻翼呼吸 / シーソー呼吸 聴診: 清明 / Wheeze / Rhonchi / Crackles

頭頸部・皮膚

咽頭: 発赤 / 扁桃腫大 / 白苔・膿栓, 中耳炎所見: なし / あり 発疹: なし / 水疱 / 紅斑 / 紫斑, BCG痕: 正常 / 発赤

迅速検査

RSウイルス 陽性 / 陰性 アデノウイルス 陽性 / 陰性 ヒトメタニューモ 陽性 / 陰性 溶連菌 陽性 / 陰性 インフルエンザ 陽性 / 陰性 COVID-19 陽性 / 陰性

診察前対応

迅速検査

[Lab-Ped-RSV] RSウイルス[Lab-Ped-Adeno] アデノウイルス[Lab-Ped-hMPV] ヒトメタニューモ[Lab-Gen-Strep] 溶連菌[Lab-Gen-Influenza] インフルエンザ[Lab-Gen-COVID] COVID-19

💡 Dr.Advice

[トリアージの要点] ①即時対応 (重症感あり): SpO2<95%、チアノーゼ、意識障害（ぐったり）、大泉門膨隆、紫斑（髄膜炎菌疑い）→ 緊急対応。 ②要注意 (ハイリスク): 生後3ヶ月未満の発熱、3日以上続く高熱、水分が全く取れない → 早急に検査・方針決定。 ③機嫌・活気が最重要: 体温の高さよりも「あやすと笑う・視線が合う」かどうかが重症度判定の核心である。 ④ハイリスク回避: 「親の直感」（「いつもと違う」）は有力な情報である。親の不安が強い場合は確認検査を行うことで受診の安心につながる。

評価

  • 診断根拠: 主要6症状（(1)発熱5日以上 (2)両側結膜充血 (3)口唇紅潮・苺舌 (4)不定形発疹 (5)四肢末端変化 (6)頸部リンパ節腫脹≧1.5cm）のうち5項目以上で確定。4項目+冠動脈病変でも確定。 不全型: 5項目に満たなくても他疾患除外+冠動脈病変確認で不全型として治療対象。
  • 重症度: 確定型 / 不全型
  • 鑑別: アデノウイルス感染症、溶連菌感染症、麻疹、EBウイルス感染症、Stevens-Johnson症候群。

方針・処方

  • 即日紹介が必須。入院精査（心エコー、血液検査: CRP・ESR・WBC・Plt・ALB・AST/ALT・Na）。
  • 紹介先への情報提供: 発熱日数、満たす主要症状数、BCG接種部位発赤の有無。
  • 発症10日以内のIVIG（免疫グロブリン大量療法 2g/kg単回投与+ASA 30-50mg/kg/日）開始が冠動脈瘤予防の鍵。

処方・アクション​

紹介・搬送

[Ref-Ped-Kawasaki] 小児科紹介（入院対応可能施設）※電話連絡必須
  • 診療情報提供書作成: 発熱日数、主要症状の詳細、BCG接種部位所見を記載
  • 紹介状チェックリスト: 発熱開始日（第何病日）、各症状出現日、BCG接種部位発赤の有無、体重（IVIG算出用）、使用解熱薬

検査・アクション​

紹介前検査（可能であれば）

[Lab-Ped-KD-CBC] CBC+分画[Lab-Ped-KD-CRP] CRP・ESR[Lab-Ped-KD-Bio] AST/ALT・ALB・Na

指導・計画​

  • 再診目安: 紹介先受診後、退院後のフォローアップ。

💡 Dr.Advice

[RedFlag] 冠動脈瘤は発症7-10日が最も危険。BCG接種部位の発赤は有用な早期サイン（感度50-80%）。不全型でも紹介を躊躇しないこと。

[プライマリの役割] プライマリケアの役割は早期発見と迅速紹介である。「不全型かもしれないが念のため」の紹介姿勢が冠動脈瘤を防ぐ。

📖 詳細解説​

川崎病（Kawasaki disease）は主に5歳未満の乳幼児に好発する急性の全身性血管炎であり、中型動脈（特に冠動脈）を主標的とする。年間罹患数は日本で約15,000-17,000人（2020年全国調査）と世界最多であり、小児後天性心疾患の最大の原因である。未治療での冠動脈瘤合併率は約25%に達するが、適切なIVIG投与により3-5%に低下する。

病態生理​

原因と発症メカニズム

  • 原因は未だ不明だが、遺伝的素因を持つ小児において何らかの感染性トリガー（ウイルスまたは細菌の超抗原）が免疫系を過剰活性化し、全身性の血管炎を引き起こすと考えられている。
  • 日本人に好発（年間罹患率: 日本は人口10万人あたり約300、米国は約25）であり、遺伝的因子（ITPKC、CASP3、ORAI1遺伝子多型等）の関与が示唆されている。

血管炎の進行

  1. 急性期（第1-2病週）: 冠動脈を含む中型動脈の全層性血管炎。内膜・中膜の浮腫、好中球・マクロファージの浸潤。
  2. 亜急性期（第2-4病週）: 中膜の弾性線維・平滑筋が破壊され、動脈壁が脆弱化。この時期に冠動脈瘤が形成される。血小板増多によりリスクが最大。
  3. 慢性期: 小さな瘤は退縮することが多いが（約50%が1-2年で退縮）、巨大瘤（内径8mm以上）は永続し、血栓形成・狭窄・石灰化のリスクがある。

冠動脈瘤のリスク因子

  • IVIG不応例
  • 発症年齢1歳未満
  • 男児
  • CRP高値・ALB低値・Na低値
  • 治療開始の遅れ（第10病日以降）

診断基準・鑑別疾患​

主要症状6項目（日本川崎病学会）

番号症状詳細
1発熱5日以上持続（抗菌薬に不応）
2両側眼球結膜充血滲出物を伴わない非化膿性充血
3口唇・口腔所見口唇紅潮・亀裂、苺舌、口腔咽頭粘膜のびまん性発赤
4不定形発疹多形紅斑様、蕁麻疹様等。水疱・痂皮は通常なし
5四肢末端の変化急性期: 手足の硬性浮腫・掌蹠紅斑 / 回復期: 指先からの膜様落屑
6非化膿性頸部リンパ節腫脹1.5cm以上、多くは片側性

確定診断: 6項目中5項目以上を満たす場合。または4項目+心エコーで冠動脈病変を認める場合。

不全型川崎病（incomplete Kawasaki disease）

  • 主要症状が3-4項目しか満たさないが、他疾患が除外され、補助的検査所見が川崎病を支持する場合に診断。
  • 補助的検査所見: CRP 3.0 mg/dL以上、ESR 40mm/hr以上、ALB 3.0 g/dL未満、肝酵素上昇、WBC 15,000/mcL以上、尿中白血球10/HPF以上、血小板45万/mcL以上（7日以降）
  • 不全型は全川崎病の約15-20%を占める。 1歳未満の乳児に多く、冠動脈瘤のリスクは確定型と同等であるため、疑えば積極的に紹介する。
  • BCG接種部位の発赤は早期診断の有用な所見（感度50-80%、特異度高い）。日本特有のサイン。

鑑別疾患

  • アデノウイルス感染症（咽頭結膜熱）: 滲出性結膜炎、咽頭炎
  • 溶連菌感染症（猩紅熱）: 迅速検査で鑑別
  • 麻疹: コプリック斑、ワクチン接種歴
  • EBウイルス感染症（伝染性単核症）: 異型リンパ球、脾腫
  • Stevens-Johnson症候群: 薬剤歴、粘膜びらん、水疱
  • 若年性特発性関節炎（全身型）: 弛張熱、サーモンピンク疹

エビデンス・ガイドライン推奨​

初期治療（日本川崎病学会ガイドライン）

IVIG療法（免疫グロブリン大量療法）

  • 用量: 2 g/kg 単回投与（12-24時間かけて点滴静注）
  • 有効性: 冠動脈瘤合併率を25%から3-5%に低下させる（Newburger JW, et al. NEJM 1991; Terai M, et al.）
  • 投与時期: 第5-10病日の早期投与が最も有効。第10病日以降でも有効性は残るが、冠動脈瘤予防効果は減弱。

アスピリン（ASA）併用

  • 急性期: ASA 30-50 mg/kg/日 分3（抗炎症量）-- 解熱後48-72時間まで
  • 回復期: ASA 3-5 mg/kg/日 分1（抗血小板量）-- CRP正常化・血小板正常化まで（通常6-8週間）
  • 冠動脈瘤合併例: ASA低用量を長期継続（瘤の大きさに応じて抗凝固療法を追加）

IVIG不応例の治療（初回IVIG後36時間以内に解熱しない場合）

IVIG不応は全症例の約10-20%に認める。以下の治療を段階的に検討:

治療内容エビデンス
追加IVIG2 g/kg 単回投与（2回目）約60-70%が反応
ステロイドパルスメチルプレドニゾロン30 mg/kg（1-3日間）RAISE study（2012）: 初回IVIG+PSL併用で冠動脈瘤有意減少
インフリキシマブ5 mg/kg 単回投与TNF-α阻害薬。IVIG+ステロイド不応例に使用。冠動脈瘤退縮効果の報告あり。※川崎病への保険適応外使用
シクロスポリンA5 mg/kg/日 経口（5日間）KAICA trial（2019）: IVIG不応予測例への初期併用で冠動脈瘤減少。※川崎病への保険適応外使用

IVIG不応リスク予測（久留米スコア等）

  • 日齢、CRP、血小板数、AST、Na、好中球%等から不応リスクを予測するスコアリングシステムが複数開発されている。
  • 高リスク例では初回IVIG+ステロイド併用療法を検討（RAISE studyのプロトコル）。

長期フォローアップ

  • 冠動脈瘤なし: 発症後5年間は年1回の心エコーフォローを推奨（日本川崎病学会）
  • 小冠動脈瘤（4-6mm）: 低用量ASA継続、6-12ヶ月ごとの心エコー
  • 中等度冠動脈瘤（6-8mm）: ASA+ワルファリンまたはDOAC、定期的な負荷試験
  • 巨大冠動脈瘤（8mm以上）: ASA+ワルファリン（PT-INR 2.0-2.5）、冠動脈造影による定期評価、運動制限
