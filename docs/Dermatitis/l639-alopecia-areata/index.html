[L63.9] 円形脱毛症 / Alopecia Areata

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 発疹 / 痒み / 疼痛 / 腫瘤 / 脱毛 ＿日前から出現 経過: 急速拡大 / 再発 / 慢性 / 徐々に拡大 自覚症状: 激痒 / 軽度痒み / 痛み / 無症状 / 赤み / ブツブツ / 水疱 部位: 顔面 / 手指 / 体幹 / 下肢 / 全身

誘因・背景

接触歴: 植物 / 金属 / 化粧品 / 虫 / 動物 / 新しい薬 / 新しい洗剤・柔軟剤 / 庭仕事 / ペット 既往歴: アトピー / 蕁麻疹 / 糖尿病 / 喘息 / 鼻炎 / 花粉症

所見・検査

皮疹性状

原発疹: 紅斑 / 丘疹 / 水疱 / 膿疱 / 結節 / 膨疹 続発疹: 痂皮 / 鱗屑 / びらん / 潰瘍 / 苔癬化 / 掻破痕 / 色素沈着 / 乾燥 配列・分布: 左右対称 / 片側性 / 帯状 / 孤立 / 集簇 / 汎発 / デルマトーム / 接触部位 / 脂漏部位

その他

爪: 混濁 / 肥厚 / 変形, 毛髪: 脱毛 / 牽引痛

検査

真菌鏡検(KOH): 外注提出 / 未実施 / 陽性 / 陰性 ※外注 真菌鏡検(KOH法) ダーモスコピー: 実施 / 未実施

診察前対応

検査

[Lab-Der-KOH] 真菌鏡検(KOH法)

💡 Dr.Advice

[KOH即日不可の対応] 当院ではKOH（真菌検査）が外注となるため、その場での白癬確定診断ができない。典型的な湿疹に見えても、ステロイドを塗って悪化する場合は白癬の可能性がある。「もし薬を塗って赤みや痒みが増したら、すぐに中止して再診してください」と必ず伏線を張れ。疑わしければ、初回は抗真菌薬もステロイドも使わず、保湿剤や非ステロイド系（スタデルム等）で検査結果を待つのも賢明な戦略である。

[FTU (Finger Tip Unit)] 外用薬の効果が出ない最大の理由は「塗布量不足」である。チューブから「人差し指の先から第一関節まで（約0.5g）」出した量が、「大人の手のひら2枚分」の面積を塗る適量である。「ティッシュが張り付くくらい」たっぷり塗るよう指導せよ。

評価

  • 診断根拠: 円形〜楕円形の境界明瞭な脱毛斑。感嘆符毛（!型短毛）が活動期の指標。pull testで容易に抜ける毛髪。
  • 病型: 単発型 / 多発型 / 蛇行型 / 全頭型 / 汎発型
  • 病態: 自己免疫性（T細胞による毛包攻撃）。甲状腺疾患・白斑の合併スクリーニングを考慮。
  • 鑑別: トリコチロマニア（抜毛症）、頭部白癬、膠原病による脱毛、AGA/FAGA（全く異なる病態）

方針・処方

  • 単発小型（3cm未満）: ステロイド外用で経過観察。自然治癒率は約80%。
  • 4週間で効果不十分時: strongest（デルモベート）へステップアップ。
  • 多発型: ステロイド局所注射。
  • 広範囲（全頭型・汎発型）: 皮膚科専門医紹介。

処方・アクション​

単発型セット

[Rx-Der-AA-Topi] アンテベートローション（第一選択）
  • アンテベートローション0.05% 1本 1日1-2回 脱毛部に塗布 28日分 — 単発型円形脱毛症 [Rx-Der-AA-Topi2] デルモベートスカルプローション（ステップアップ）
  • デルモベートスカルプローション0.05% 1本 1日1-2回 脱毛部に塗布 28日分 — 4週間で効果不十分時 [Rx-Der-AA-Frost] フロジン液（補助）
  • フロジン外用液5% 1本 1日2-3回 脱毛部に塗布 28日分 — 血行促進

多発型セット（皮膚科で施行）

[Rx-Der-AA-Inject] ケナコルト-A局注
  • トリアムシノロンアセトニド（ケナコルト-A）局注 2.5-5mg/mL 脱毛部皮内注射 4週間ごと ；多発型

※1回あたり最大20mg、4週間ごと

検査・アクション​

合併症スクリーニング

[Lab-Der-AA-Thy] 甲状腺機能（TSH, FT4）[Lab-Der-AA-ANA] 抗核抗体

指導・計画​

  • 患者指導: 単発型は自然治癒率が高い旨を説明（不安軽減）。
  • ステロイド外用の長期使用注意: 皮膚萎縮・毛細血管拡張のリスクあり。4週間ごとに皮膚の状態を確認し、改善傾向があれば減量・中止を検討。
  • 再診目安: 4-6週間後。多発・拡大傾向があれば皮膚科紹介。

💡 Dr.Advice

[病態理解] 700-PrivateのAGA/FAGAとは全く異なる病態。ストレスが誘因になりうるが自己免疫が本態であることを患者に説明。

[専門医紹介] 多発型・全頭型は皮膚科専門医へ紹介。JAK阻害薬が使える時代になった（局所免疫療法と合わせて専門医が判断）。

📖 詳細解説​

円形脱毛症（alopecia areata: AA）は、毛包に対する臓器特異的自己免疫疾患である。日本での有病率は約1〜2%、生涯罹患率は約2%とされる。あらゆる年齢で発症するが、20〜30歳代にピークがあり、患者の約40%は20歳未満で初発する。

病態生理​

  • 毛包の免疫特権（immune privilege）の崩壊: 正常な毛包の毛球部はMHCクラスI分子の発現が抑制されており、免疫系から「隠された」状態にある（免疫特権）。円形脱毛症ではこの免疫特権が崩壊し、毛球部のMHCクラスI発現が亢進する。
  • CD8陽性T細胞による毛包攻撃: NKG2D陽性CD8陽性T細胞が毛球部に浸潤し、成長期毛包を選択的に攻撃する。これにより毛包は成長期から退行期・休止期へ強制移行し、脱毛が生じる。
  • IFN-gamma/JAK-STAT経路: IFN-gammaシグナルがJAK1/JAK2-STAT1経路を介してMHCクラスI発現を誘導する。この経路がJAK阻害薬の治療標的である。
  • 遺伝的背景: HLA-DQB1*03等との関連が報告されている。一卵性双生児の一致率は約55%。
  • 合併疾患: 甲状腺疾患（橋本病・バセドウ病）約8〜28%、白斑約4%、アトピー性皮膚炎約40%が合併する。

診断基準・鑑別疾患​

病型分類

病型特徴予後
単発型1箇所の脱毛斑約80%が1年以内に自然治癒
多発型2箇所以上の脱毛斑自然治癒率は低下
蛇行型（ophiasis）後頭部〜側頭部の帯状脱毛難治性
全頭型（totalis）頭部全体の脱毛難治性、治療反応不良
汎発型（universalis）全身の体毛が脱落最も難治

診断のポイント

  • 感嘆符毛（exclamation mark hairs）: 脱毛斑辺縁に見られる根元が細く先端が太い短毛（!の形状）。活動期の重要な指標
  • Pull test: 脱毛斑辺縁で毛髪を軽く牽引すると容易に抜ける（活動期）
  • ダーモスコピー所見: 黒点（black dots）、感嘆符毛、黄色点（yellow dots: 毛包開口部の角栓）、短い軟毛（vellus hairs: 回復期の指標）
  • 爪所見: 約10〜20%に爪甲の点状陥凹（pitting）、粗造、横溝を認める

鑑別疾患

鑑別疾患鑑別ポイント
抜毛症（トリコチロマニア）不規則な脱毛斑、様々な長さの毛髪残存、ダーモスコピーで黒点なし
頭部白癬KOH陽性。鱗屑・膿痂疹を伴う。小児に多い
牽引性脱毛ポニーテール等の習慣的牽引部位に一致
膠原病による脱毛SLEのびまん性脱毛、DLEの瘢痕性脱毛
AGA/FAGA徐々に進行するびまん性の軟毛化。境界明瞭な脱毛斑は形成しない

エビデンス・ガイドライン推奨​

日本皮膚科学会 円形脱毛症診療ガイドライン（2017年版。2024年改訂版を適宜参照）

単発型・少数多発型（脱毛面積 25%未満）

  • ステロイド外用（推奨度B）: ベリーストロング〜ストロンゲスト。第一選択。3〜6ヶ月継続
  • ステロイド局所注射（推奨度B）: トリアムシノロンアセトニド 2.5〜5mg/mL 脱毛部皮内注射。4週間ごと。局所の皮膚萎縮に注意
  • カルプロニウム塩化物（フロジン液）外用（推奨度C1）: 血行促進作用。補助療法として
  • 冷却療法（推奨度C1）: ドライアイスやスプレーによる局所刺激

多発型・広範囲（脱毛面積 25〜50%以上）

  • 局所免疫療法（SADBE/DPCP）（推奨度B）: 感作後に低濃度で接触皮膚炎を繰り返し惹起し、毛包周囲のT細胞を置換する。最も有効なエビデンスを持つ治療法の一つ。有効率は約60〜70%だが、かぶれ・リンパ節腫脹を伴う
  • ステロイドパルス療法（推奨度C1）: メチルプレドニゾロン 500mg/日 3日間点滴。急速進行型で発症6ヶ月以内に有効性が高い
  • ステロイド内服（推奨度C1）: 長期投与は副作用のため推奨されない

JAK阻害薬（2022年〜）

  • バリシチニブ（オルミエント）: JAK1/JAK2阻害薬。2022年6月に円形脱毛症に対する適応を日本で取得（世界初の経口JAK阻害薬承認）
  • 適応: 既存治療で効果不十分な脱毛面積50%以上の重症円形脱毛症（全頭型・汎発型含む）
  • 用量: 4mg 1日1回 経口（効果発現後2mgへ減量可）
  • BRAVE-AA1/AA2試験: 36週時点でSALT 20以下（頭髪80%以上回復）達成率はバリシチニブ4mg群で約35〜39%（プラセボ群 約5〜6%）
  • 副作用: 感染症（帯状疱疹含む）、脂質異常、血栓塞栓症リスク。投与前にスクリーニング検査（結核、肝炎ウイルス、血算、脂質、肝機能）が必須
  • 専門医による管理が必要
