[L40.3] 掌蹠膿疱症 / Palmoplantar Pustulosis

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 発疹 / 痒み / 疼痛 / 腫瘤 / 脱毛 ＿日前から出現 経過: 急速拡大 / 再発 / 慢性 / 徐々に拡大 自覚症状: 激痒 / 軽度痒み / 痛み / 無症状 / 赤み / ブツブツ / 水疱 部位: 顔面 / 手指 / 体幹 / 下肢 / 全身

誘因・背景

接触歴: 植物 / 金属 / 化粧品 / 虫 / 動物 / 新しい薬 / 新しい洗剤・柔軟剤 / 庭仕事 / ペット 既往歴: アトピー / 蕁麻疹 / 糖尿病 / 喘息 / 鼻炎 / 花粉症

所見・検査

皮疹性状

原発疹: 紅斑 / 丘疹 / 水疱 / 膿疱 / 結節 / 膨疹 続発疹: 痂皮 / 鱗屑 / びらん / 潰瘍 / 苔癬化 / 掻破痕 / 色素沈着 / 乾燥 配列・分布: 左右対称 / 片側性 / 帯状 / 孤立 / 集簇 / 汎発 / デルマトーム / 接触部位 / 脂漏部位

その他

爪: 混濁 / 肥厚 / 変形, 毛髪: 脱毛 / 牽引痛

検査

真菌鏡検(KOH): 外注提出 / 未実施 / 陽性 / 陰性 ※外注 真菌鏡検(KOH法) ダーモスコピー: 実施 / 未実施

診察前対応

検査

[Lab-Der-KOH] 真菌鏡検(KOH法)

💡 Dr.Advice

[KOH即日不可の対応] 当院ではKOH（真菌検査）が外注となるため、その場での白癬確定診断ができない。典型的な湿疹に見えても、ステロイドを塗って悪化する場合は白癬の可能性がある。「もし薬を塗って赤みや痒みが増したら、すぐに中止して再診してください」と必ず伏線を張れ。疑わしければ、初回は抗真菌薬もステロイドも使わず、保湿剤や非ステロイド系（スタデルム等）で検査結果を待つのも賢明な戦略である。

[FTU (Finger Tip Unit)] 外用薬の効果が出ない最大の理由は「塗布量不足」である。チューブから「人差し指の先から第一関節まで（約0.5g）」出した量が、「大人の手のひら2枚分」の面積を塗る適量である。「ティッシュが張り付くくらい」たっぷり塗るよう指導せよ。

評価

  • 手掌・足底に無菌性膿疱が反復出現。周囲に紅斑・鱗屑を伴う。
  • 鑑別: 足白癬（KOH検査で真菌陰性を確認）、汗疱（異汗性湿疹）、膿疱性乾癬。
  • 関連因子: 喫煙（80%以上が喫煙者）、歯科金属アレルギー（ニッケル・コバルト）、扁桃病巣感染。
  • 合併症: 掌蹠膿疱症性骨関節炎（PAO）の有無（鎖骨・胸肋関節の疼痛・腫脹）。

方針・処方

  • 全例皮膚科紹介が望ましい。当院ではKOH検査による水虫除外と初期治療を担当する。
  • 禁煙指導（禁煙だけで著明改善する例あり）。
  • 歯科受診推奨（歯科金属除去で改善する報告あり）。

処方・アクション​

ステロイド外用

[Rx-Der-PPP-Str] ステロイド外用（ストロング～ベリーストロング）
  • アンテベート軟膏0.05% 1日2回 患部に塗布 — 手掌・足底はベリーストロングまで使用可

※手掌・足底は角層が厚く吸収率が低いため強めのランクを選択

ビタミンD3外用

[Rx-Der-PPP-VitD] ドボネックス軟膏
  • ドボネックス軟膏50μg/g 1日2回 患部に塗布 — ステロイドとの併用

※ステロイドと交互塗布またはシークエンシャル療法

紹介

[Doc-Gen-Referral] 診療情報提供書（皮膚科へ紹介: エトレチナート・シクロスポリン・グセルクマブ等の全身療法検討）

指導・計画​

  • 禁煙指導: 喫煙は最大の増悪因子。禁煙外来の案内を行う。
  • 歯科受診: 歯科金属パッチテストを推奨。
  • 再診目安: 4週後に効果判定。改善乏しい場合は皮膚科紹介。

💡 Dr.Advice

[鑑別] KOH検査で真菌を必ず除外せよ。膿疱の見た目は水虫と酷似する。

[喫煙] 掌蹠膿疱症患者の80%以上が喫煙者。禁煙だけで著明改善する例あり。禁煙指導を最優先せよ。

[歯科] 歯科金属（特にニッケル、コバルト）除去で改善する報告あり。歯科受診を推奨せよ。

[設備制約] 生物学的製剤（グセルクマブ等）は当院では対応不可。皮膚科専門医へ紹介せよ。

📖 詳細解説​

掌蹠膿疱症（palmoplantar pustulosis: PPP）は、手掌・足底に無菌性膿疱が反復出現する慢性炎症性皮膚疾患である。日本での有病率は欧米より高く、30〜50歳代の女性に好発する。喫煙との強い関連が特徴的であり、患者の80〜90%が喫煙者である。

病態生理​

  • 病態の本質: エクリン汗管周囲の免疫異常が中心的役割を果たす。汗管上皮に対する自己免疫反応により好中球が汗管内に集簇し、無菌性膿疱を形成する。
  • 免疫学的機序: IL-8（CXCL8）をはじめとするケモカインによる好中球遊走、TNF-alpha・IL-17・IL-23経路の活性化が病態に関与する。乾癬との類似点があるが、独立した疾患と位置づけられている。
  • 喫煙の影響: ニコチンはエクリン汗腺のニコチン性アセチルコリン受容体に結合し、汗管上皮の角化異常・炎症を惹起する。喫煙は最大の増悪因子であり、禁煙により著明改善する症例がある。
  • 病巣感染: 扁桃病巣感染（慢性扁桃炎）および歯性感染症（歯周病・根尖病巣・歯科金属アレルギー）が病態を修飾する。扁桃摘出や歯科金属除去により改善する報告が多数ある。
  • ビオチン代謝異常: 喫煙者ではビオチン（ビタミンB7）の血中濃度が低下しており、ビオチン欠乏が脂肪酸代謝異常を介して皮膚バリア障害を引き起こすとされる。
  • 掌蹠膿疱症性骨関節炎（PAO）: 約10〜30%に合併。胸肋鎖骨関節を中心に疼痛・腫脹を生じる。SAPHO症候群（Synovitis, Acne, Pustulosis, Hyperostosis, Osteitis）の一型として認識される。前胸部痛を訴える患者ではCTや骨シンチグラフィーで評価する。

診断基準・鑑別疾患​

診断ポイント

  • 手掌・足底（特に母指球・小指球・土踏まず）に周期的に出現する無菌性膿疱
  • 膿疱は数日で乾燥して褐色の痂皮・落屑となり、新旧の膿疱が混在する
  • KOH検査で真菌陰性を確認することが必須（水虫との鑑別の要）

鑑別疾患

鑑別疾患鑑別ポイント
足白癬（水虫）KOH陽性。趾間型は鱗屑・浸軟、小水疱型は足縁に好発
汗疱（異汗性湿疹）手指側面の小水疱が主体。膿疱は伴わない
膿疱性乾癬全身に膿疱が波及。発熱・全身症状を伴う
接触皮膚炎原因物質への接触歴。パッチテストで同定
掌蹠角化症角化が主体で膿疱を伴わない

エビデンス・ガイドライン推奨​

外用療法（第一選択）

  • ステロイド外用: ベリーストロング〜ストロンゲスト（手掌・足底は角層が厚く吸収率が低いため強めのランクが必要）
  • 活性型ビタミンD3外用（カルシポトリオール等）: ステロイドとの併用・交互塗布で効果増強。日本皮膚科学会ガイドラインで推奨度B

全身療法（外用療法抵抗例）

  • ビオチン療法: ビオチン 9mg/日 + ミヤBM（酪酸菌）の併用。保険適用あり。エビデンスは限定的だが、安全性が高く試みる価値あり
  • エトレチナート（チガソン）: 0.3〜0.5mg/kg/日。催奇形性があり、女性は投与中止後2年間避妊が必要
  • シクロスポリン: 3〜5mg/kg/日。腎機能・血圧モニタリング必須
  • 禁煙: エビデンスレベルは観察研究が主だが、最も費用対効果の高い介入。禁煙後3〜6ヶ月で改善傾向
  • 扁桃摘出: 扁桃病巣感染が疑われる場合（ASO高値、扁桃誘発試験陽性）。摘出後の改善率は約70〜90%
  • 歯科金属除去: 金属パッチテスト陽性の場合に考慮。改善率は約50〜70%

生物学的製剤

  • グセルクマブ（トレムフィア）: 抗IL-23p19抗体。2018年に掌蹠膿疱症に対して日本で世界初の適応取得。100mg 皮下注 0, 4週後、以後8週毎。第III相試験でPPPASI 50達成率は有意にプラセボを上回った
  • 他の生物学的製剤（抗TNF-alpha抗体等）は掌蹠膿疱症への効果が一定しない
