[R03.0] 白衣高血圧 / White Coat Hypertension

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 検診異常 / 自宅血圧高値 / 頭痛 / 肩こり / めまい / 動悸 随伴症状: 胸部圧迫感 / 息切れ / なし

生活習慣

塩分摂取: 多 / 適 / 少, 外食頻度: ＿ 回/週 運動習慣: なし / 週＿回, 喫煙: なし / あり ＿本/日 睡眠: 良好 / 不眠 / いびき・無呼吸 ストレス: 有 / 無, 飲酒: なし / あり: ＿ 家族歴: 高血圧 / 脳卒中 / 心筋梗塞, 発症年齢: ＿歳頃

所見・検査

身体計測: 身長 ＿cm, 体重 ＿kg, BMI ＿ 診察室血圧: ＿/＿ mmHg (左右差: 有 / 無) 自宅平均血圧: ＿/＿ mmHg

診察

心雑音: 有 / 無, 頸動脈雑音: 有 / 無 下肢浮腫: 有 / 無, 足背動脈触知: 良好 / 減弱 / 消失

スクリーニング

尿検査: 蛋白(＿) 糖(＿) 心電図: 正常 / 左室肥大 / ST-T変化 採血(外注): Cre, eGFR, K, 血糖, 脂質

診察前対応

（データなし）

💡 Dr.Advice

[白衣高血圧] 診察室血圧のみ高い場合は「白衣高血圧」の可能性がある。薬物治療開始の前に、必ず「家庭血圧」を測定させ、その平均値で判断せよ。

[眼底検査] 当院では眼底検査ができないため、高血圧性変化や糖尿病網膜症の評価が必要な場合（特に尿蛋白陽性例や視力低下例）は、眼科へ対診依頼 [ID: Doc-Gen-Referral] を行え。

[二次性高血圧] 若年発症（35歳以下）、重症高血圧、低カリウム血症を認める場合は、原発性アルドステロン症などの二次性高血圧を疑いホルモン検査（外注）を行え。

[オンライン初診処方制限] オンライン診療において、お薬手帳、健診結果、紹介状等で基礎疾患が把握できない初診患者の場合、処方は「7日分を上限」とせよ。

評価

  • 診断根拠: 診察室血圧は高値(>140/90)だが、家庭血圧は正常(<135/85)。
  • 臓器障害: なし。

方針・処方

  • 直ちには投薬せず、家庭血圧測定を継続し経過観察。
  • 生活習慣指導（減塩等）は行う。
  • 3～6ヶ月毎に再評価。

処方・処置 (選択)​

オーダー

💡 Dr.Advice

[過降圧注意] 診察室の数値だけで薬を出すと、自宅や職場で低血圧（ふらつき・転倒）を起こす危険がある。「お家での血圧を信じます」と伝え、測定を習慣化させよ。

📖 詳細解説​

病態生理​

  • 定義: 診察室血圧は140/90mmHg以上だが、家庭血圧は135/85mmHg未満
  • 有病率: 高血圧疑い患者の15-30%
  • 病態: 医療環境での精神的緊張（交感神経活性化）→ 一過性の血圧上昇
  • 臨床的意義: 正常血圧と比較してやや心血管リスクが高い（将来の持続性高血圧への移行リスクあり）

ABPM（24時間自由行動下血圧測定）基準値​

白衣高血圧の確定診断および仮面高血圧の除外に最も信頼性が高い検査:

指標高血圧基準白衣高血圧の条件
24時間平均130/80 mmHg以上130/80 mmHg未満
日中（覚醒時）平均135/85 mmHg以上135/85 mmHg未満
夜間（睡眠時）平均120/70 mmHg以上120/70 mmHg未満
  • 白衣高血圧の診断: 診察室血圧 140/90以上 + ABPM日中平均 135/85未満（かつ24時間平均 130/80未満）
  • ABPMの追加的評価:
    • 夜間血圧パターン: dipper（正常: 夜間10-20%低下）、non-dipper（10%未満の低下: 臓器障害リスク上昇）、riser（夜間上昇: 最も予後不良）、extreme dipper（20%以上の低下: 脳虚血リスク）
    • モーニングサージ: 早朝の急激な血圧上昇（脳卒中・心筋梗塞の発症時間帯と一致）
  • 家庭血圧で代替する場合: 最低5-7日間の朝・晩2回ずつの測定平均値（初日は除外）で判定

持続性高血圧への移行率​

  • 年間移行率: 白衣高血圧患者の約2-5%/年が持続性高血圧に移行
  • メタアナリシス: 白衣高血圧の約28-40%が10年以内に持続性高血圧に移行
  • 移行リスク因子:
    • 診察室収縮期血圧が高い（160mmHg以上ではリスクが高い）
    • BMI 25以上
    • 家庭血圧が高めの正常域（130-134/80-84 mmHg）
    • 年齢が高い
    • メタボリックシンドロームの合併
    • 糖尿病の合併
  • 心血管リスク: 白衣高血圧は正常血圧と比較して心血管イベントリスクが約1.3-1.5倍（持続性高血圧の約2-3倍よりは低い）
  • 臓器障害: 白衣高血圧でもLVH、頸動脈内膜中膜肥厚、微量アルブミン尿などの臓器障害を有する例がある → 臓器障害スクリーニングが重要

診断基準・鑑別疾患​

  • 診断: 複数回の診察室血圧が高値 + 家庭血圧が正常範囲 + ABPMで日中平均135/85未満
  • 仮面高血圧の除外: 逆パターン（診察室正常、家庭高値）は仮面高血圧で予後が悪い → 家庭血圧測定が重要
  • 白衣効果: 既に降圧薬治療中の患者でも診察室血圧が家庭血圧より著しく高い場合を「白衣効果」と呼ぶ（白衣高血圧とは区別）

エビデンス・ガイドライン推奨​

  • JSH2024の推奨: 臓器障害なし → 降圧薬は不要。生活習慣修正 + 定期的な家庭血圧モニタリング
  • フォロー: 3-6ヶ月ごとに家庭血圧を確認。持続性高血圧への移行を監視
  • 臓器障害ありの場合: 降圧薬治療を検討（特にLVH、微量アルブミン尿、頸動脈IMT肥厚を認める場合）
  • 家庭血圧測定の指導: 朝（起床後1時間以内、排尿後、食前、服薬前）と就寝前に各2回測定。上腕式血圧計を使用（手首式は不正確）
  • 生活習慣修正: 減塩（6g/日未満）、減量、有酸素運動（週150分以上）、節酒、禁煙は全例に推奨
