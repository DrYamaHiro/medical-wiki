[A05.9] 細菌性食中毒 / Bacterial Gastroenteritis

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 腹痛 / 悪心・嘔吐 / 下痢 / 便秘 / 血便 / 吐血 / 心窩部不快感

消化器系

腹痛部位: 心窩部 / 右季肋部 / 臍周囲 / 右下腹部 / 左下腹部 / 全体 腹痛性状: 鈍痛 / 鋭痛 / 波がある / 持続的 便性状: 水様 / 泥状 / 粘血便 / 黒色便 / 兎糞状, 回数: ＿ 回/日 食事関連: 食前 / 食後 / 空腹時 / 夜間

全身・背景

発熱: 有 / 無, 倦怠感: 有 / 無 食事摂取: 可能 / 不可: 水分のみ / 絶食中 生食歴: 牡蠣 / 鶏肉 / 焼肉 / 刺身 / なし ＿日前 周囲の流行: 家族 / 職場 / 学校 ストレス: 有 / 無, アルコール: 多飲 / 機会飲酒 内服薬: NSAIDs / ステロイド / 抗血小板薬

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

全身

脱水所見: 口腔乾燥 有 / 無, ツルゴール 正常 / 低下 眼瞼結膜: 貧血なし / 蒼白

腹部

視診: 平坦 / 膨満 聴診: 腸雑音 正常 / 亢進 / 減弱 / 消失 / 金属音 触診: 軟 / 筋性防御 / 板状硬, 腫瘤 有 / 無 圧痛点: 心窩部 / McBurney / Murphy / 全体 / なし 反跳痛: 有 / 無, CVA叩打痛: 有 / 無

直腸診（必要な場合）

タール便 有 / 無

除外項目(Negative ROS)

板状硬無, 反跳痛無, 拍動性腫瘤無

診察前対応

（データなし）

💡 Dr.Advice

[設備制約] 当院にはCT、エコー、上部消化管内視鏡がない。吐血、黒色便、激しい腹痛、腹膜刺激症状がある場合は、診断がつかなくても直ちに専門病院へ紹介せよ。

[トリアージ] 高齢者の心窩部痛はACS（心筋梗塞）の可能性があるため、必ず心電図を確認せよ。

評価

  • 診断根拠: 汚染食品摂取後の急激な嘔吐・下痢・腹痛・発熱。
  • 原因菌: サルモネラ（卵・肉）、腸炎ビブリオ（魚介）、黄色ブドウ球菌（おにぎり・弁当）。

方針・処方

  • 原則は対症療法（排菌を促すため止痢薬は避ける）。
  • 重症例（高熱、血便）では抗菌薬投与を検討するが、ニューキノロン（レボフロキサシン）の使用は慎重に。

処方・アクション​

対症療法

[Rx-Gen-GI-BioR] ビオフェルミンR(耐性乳酸菌)
  • ビオフェルミンR錠 1回1錠 1日3回 毎食後 5日分 [Rx-Gen-Pain-Ace] アセトアミノフェン単剤(定期)
  • アセトアミノフェン錠500mg 1回1錠 1日3回 毎食後 5日分

💡 Dr.Advice

[止痢薬禁忌] 感染性胃腸炎に対し、強力な下痢止め（ロペミン等）を使用すると、毒素が腸内に貯留し重症化する恐れがあるため、原則使用禁止とせよ。

[抗菌薬の害] サルモネラ腸炎に抗菌薬を投与すると、排菌期間が延びる（保菌者化）リスクがある。免疫不全や菌血症リスクがない限り、漫然と投与しないこと。

📖 詳細解説​

病態生理​

  • 分類:
    • 毒素型（嘔吐型）: 黄色ブドウ球菌（1-6時間）、セレウス菌嘔吐型（1-6時間）。食品中の毒素摂取
    • 感染型（下痢型）: サルモネラ（8-48時間）、カンピロバクター（2-5日）、腸炎ビブリオ（8-24時間）
    • 毒素産生型: 腸管出血性大腸菌O157（3-8日）、ウェルシュ菌（8-16時間）
  • 原因食品: 鶏肉（カンピロバクター）、鶏卵（サルモネラ）、刺身・魚介（腸炎ビブリオ）、おにぎり・弁当（黄色ブドウ球菌）、焼肉・生レバー（O157）

診断基準・鑑別疾患​

  • 食中毒を疑う根拠: 同一食品摂取者に複数の発症者（集団発生）
  • 検査: 便培養（起炎菌同定）、血便があればO157検査（ベロ毒素検査）
  • HUS（溶血性尿毒症症候群）: O157感染後5-10日に血小板減少・溶血性貧血・急性腎障害。小児・高齢者で発症リスク高い

エビデンス・ガイドライン推奨​

  • 毒素型: 自然軽快（24時間以内）。補液のみ
  • 感染型: 多くは自然軽快。重症・免疫不全では抗菌薬（起炎菌に応じた選択）
  • O157: 抗菌薬投与の是非は議論あり（毒素放出を助長する可能性）。FOSFOMYCIN 2-3g/日が日本では使用されることが多い。止瀉薬は禁忌
  • 食中毒届出: 医師は食中毒と診断（疑いを含む）した場合、直ちに保健所に届出義務（食品衛生法）
