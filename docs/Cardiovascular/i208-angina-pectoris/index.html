[I20.8] 労作性狭心症 / Angina Pectoris

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 労作時息切れ / 動悸 / 胸痛 / 浮腫 / 下肢痛

心臓症状

動悸: 脈が飛ぶ / 突然始まる / 常に速い / ドンとする 胸痛: 圧迫感 / 絞扼感 / 鋭痛 / 放散痛:肩・顎 呼吸困難: 労作時 / 安静時 / 夜間発作性 / 起坐呼吸

末梢血管・下肢

間欠性跛行: なし / あり: ＿mで出現 下肢症状: 冷感 / 色調変化 / 血管怒張 / 左右差あり 浮腫: なし / 下肢 / 顔面 / 片側 / 両側 / 急激

リスク・背景

既往歴: 心筋梗塞 / 弁膜症 / 高血圧 / 糖尿病 / 喫煙 内服薬: 抗凝固薬 / 抗血小板薬 / 利尿薬

所見・検査

バイタル: BP ＿/＿ (左右差: 有 / 無), HR ＿ (整/不整), SpO2 ＿%

胸部

頸静脈怒張: 有 / 無 心音: 整 / 不整 / 雑音: 収縮期・拡張期 / III音・IV音 呼吸音: 清明 / 湿性ラ音 / 喘鳴

末梢・下肢

下肢浮腫: なし / Pitting / Non-pitting 動脈拍動(足背・後脛骨): 良好 / 減弱 / 消失 Homan's徴候: 陰性 / 陽性、皮膚: 色素沈着 / 潰瘍 / 静脈瘤

検査

心電図: 正常洞調律 / ST変化 / 異常Q波 / 不整脈 / LVH 胸部X線: CTR ＿%, 肺鬱血 / 胸水 / 異常なし 採血(外注): BNP, Dダイマー, 电解質, 腎機能

診察前対応

（データなし）

💡 Dr.Advice

[設備制約] 当院には心エコー、ホルター心電図、ABI測定機器がない。心雑音、不整脈、脈拍欠損、重症心不全を認めた場合は、詳細評価のため循環器専門医へ紹介せよ。

[BNP解釈] 息切れの鑑別にはBNPが有用だが、外注のため結果は後日となる。急性期のトリアージは身体所見とSpO2、X線で行え。

評価

  • 診断根拠: 労作時の胸部圧迫感、安静で軽快。関連痛（肩・顎）。
  • 心電図: ST低下 / 正常

方針・処方

  • カテーテル検査の要否検討のため、循環器内科へ紹介。
  • 抗血小板薬、発作時ニトロの処方（紹介までのつなぎ）。

処方・処置 (選択)​

虚血性心疾患セット

[Rx-IHD-AntiPlt-Asp] バイアスピリン
  • バイアスピリン錠100mg 1回1錠 1日1回 朝食後 28日分 — 抗血小板 [Rx-IHD-Nitro-Spr] ミオコールスプレー
  • ミオコールスプレー0.3mg 1本 発作時1回1噴霧 — 発作時 [Rx-IHD-Nitro-Tab] ニトロペン
  • ニトロペン舌下錠0.3mg 1回1錠 発作時舌下 10回分 — 発作時

💡 Dr.Advice

[ニトロ指導] 「胸が痛くなったら迷わず使う」「座って使う（起立性低血圧注意）」「5分おきに3回使っても治まらなければ救急車」の3点を徹底指導せよ。

📖 詳細解説​

病態生理​

  • 定義: 冠動脈の動脈硬化による狭窄で、心筋酸素需要増大時に心筋虚血をきたす状態
  • 病態: 冠動脈のプラーク形成 → 内腔狭窄（通常75%以上で症状出現）→ 労作時に心筋酸素需要が供給を上回る → 胸痛
  • 安定狭心症 vs 不安定狭心症: 安定型は労作で誘発され安静で軽快。不安定型はプラーク破裂を伴い急性冠症候群（ACS）に分類
  • 微小血管狭心症: 冠動脈造影で有意狭窄がないにもかかわらず虚血症状を呈する。女性に多い

CCS（Canadian Cardiovascular Society）狭心症分類​

クラス定義具体的活動制限
Class I通常の身体活動では症状なし。激しい or 持続的な運動で胸痛階段を急いで上る、重い荷物を運ぶなど
Class II通常の活動が軽度に制限される急いで歩く、坂道を上る、食後・寒冷時・情動時の歩行で胸痛
Class III通常の活動が著明に制限される平地の1-2ブロック歩行、階段1階分で胸痛
Class IVいかなる身体活動でも胸痛。安静時にも胸痛が出現しうる安静時狭心症 → ACSの可能性を考慮
  • 臨床的意義: Class III以上は積極的な冠動脈評価（冠動脈CT or 造影）の適応。Class IVは不安定狭心症/ACSの可能性を考え緊急対応

冠動脈CTの診断精度​

指標値備考
感度95-99%有意狭窄（50%以上）の検出に対し極めて高い陰性適中率
特異度64-83%石灰化病変では特異度が低下（偽陽性が増える）
陰性適中率97-99%冠動脈CTが陰性なら有意冠動脈疾患をほぼ除外可能
陽性適中率64-91%陽性の場合は冠動脈造影で確認が必要な場合がある
  • 最適な適応: 検査前確率が中等度（15-50%）の胸痛患者。低リスク（15%未満）には過剰検査、高リスク（50%以上）には直接冠動脈造影が適切
  • FFRCT: CTデータから非侵襲的にFFR（冠血流予備量比）を推定。機能的虚血の評価が可能

ISCHEMIA試験​

安定冠動脈疾患における侵襲的戦略 vs 保存的戦略を比較した大規模RCT:

  • 対象: 中等度以上の虚血を有する安定冠動脈疾患患者5,179例（左主幹部病変は除外）
  • 主要結果:
    • 3.2年の中央値追跡で、侵襲的戦略（PCI/CABG + OMT）と保存的戦略（OMT単独）で主要心血管イベントに有意差なし
    • 侵襲的戦略は自然発症心筋梗塞を減少させたが、手技関連心筋梗塞が増加
    • 狭心症症状・QOLは侵襲的戦略群で有意に改善
  • 臨床的意義: 安定狭心症では最適薬物治療（OMT）が基盤。症状改善目的でのPCIは有効だが、予後改善のエビデンスは限定的
  • 例外: 左主幹部病変、3枝病変（特にEF低下例）、薬物治療抵抗性の症状は侵襲的治療の適応が強い

診断基準・鑑別疾患​

  • 典型的胸痛: 前胸部の圧迫感・絞扼感、労作で誘発、安静またはニトロで5分以内に軽快
  • 検査: 12誘導心電図（発作時ST低下）、運動負荷心電図、心臓超音波、冠動脈CT、冠動脈造影
  • 鑑別: GERD、肋間神経痛、パニック障害、肺塞栓、大動脈解離、心膜炎

エビデンス・ガイドライン推奨​

  • 発作時: ニトログリセリン舌下錠0.3mg（5分間隔で最大3回。無効ならACS疑いで救急搬送）
  • 二次予防: 抗血小板薬（アスピリン100mg/日）、スタチン（LDL 70mg/dL未満を目標）、beta遮断薬、ACE-I/ARB
  • 冠血行再建: 薬物治療でコントロール不良、3枝病変、左主幹部病変ではPCI（ステント）orCABGの適応
  • リスク因子管理: 高血圧、脂質異常症、糖尿病、禁煙が最重要
