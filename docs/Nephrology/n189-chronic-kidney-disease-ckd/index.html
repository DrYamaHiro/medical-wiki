[N18.9] 慢性腎臓病 / Chronic Kidney Disease / CKD

📋 主訴・所見・診察前対応

主訴・ROS

検診異常: 蛋白尿 / 潜血 / eGFR低下 / クレアチニン上昇

自覚症状

浮腫: なし / 下肢 / 眼瞼 / 夕方に増悪 尿異常: 泡立ち / 夜間頻尿 全身症状: なし / 全身倦怠感 / 掻痒感 / 食欲不振 ；尿毒症症状

リスク因子

既往歴: 糖尿病 / 高血圧 / 脂質異常症 / 痛風 / なし 家族歴: 透析患者 / 多発性嚢胞腎 / なし 内服歴: なし / NSAIDs長期連用

所見・検査

バイタル: BP ＿/＿ mmHg 身体所見: 浮腫 なし / 下肢pitting / 全身, 眼瞼結膜 正常 / 蒼白

院内迅速検査

尿検査

  • 蛋白(＿) 潜血(＿) 糖(＿)

外注検査 (結果は後日)

  • 尿沈渣、尿蛋白/Cr比(随時)
  • 血液: Cre, eGFR, BUN, K, P, Ca, Alb, Hb
  • 画像: 当院では腎エコー・CT不可

診察前対応

院内迅速検査

[Lab-Gen-Urine] 尿定性

💡 Dr.Advice

[設備制約] 当院にはエコーがないため、腎後性腎不全（水腎症）や腎萎縮の評価ができない。前立腺肥大症の既往がある男性や、急激なeGFR低下例は、閉塞機転の除外のため一度は画像診断可能な施設へ紹介せよ。

[検査タイムラグ] 血液検査（Cre, K）の結果は「後日」となる。「今日現在の腎機能」は分からないため、著しい体調不良（尿毒症疑い）や乏尿がある場合は、結果を待たずに総合病院へ送る判断が必要。

評価

  • 診断根拠: eGFR<60 または 尿異常(蛋白尿等)が3ヶ月以上持続。
  • ステージ: G1 / 2 / 3a / 3b / 4 / 5
  • 原因: 糖尿病性 / 腎硬化症 / 慢性糸球体腎炎 / 不明
  • 尿蛋白区分: A1:正常 / 2:軽度 / 3:高度

方針・処方

  • 治療戦略: 血圧管理(130/80未満・RAAS阻害薬)。腎保護(SGLT2阻害薬導入)。合併症管理(腎性貧血・高K血症・アシドーシス)。減塩指導(6g/日未満)。

処方・処置​

腎保護薬 (併用推奨)

[Rx-DM-SGLT2-Dap] フォシーガ
  • フォシーガ錠10mg 1回1錠 1日1回 朝食後 28日分 — 第一選択 [Rx-HT-ARB-Tel40] テルミサルタン
  • テルミサルタン錠40mg 1回1錠 1日1回 朝食後 28日分 — 尿蛋白抑制

腎性貧血 (内服のみ)

[Rx-Nep-Ane-Duv] ダーブロック
  • ダーブロック錠2mg 1回1錠 1日1回 朝食後 28日分 — HIF-PH阻害薬 [Rx-Nep-Ane-Evr] エベレンゾ
  • エベレンゾ錠50mg 1回1錠 週3回(月水金など) 28日分

高カリウム血症 (K>5.5)

[Rx-Nep-K-Lok] ロケルマ
  • ロケルマ懸濁用散剤5g 1回1包 1日1回 (水に懸濁) 28日分 — 即効性 [Rx-Nep-K-Kal] カリメート
  • カリメート経口液20% 1包 1日2回～3回 食後 28日分 — 標準

代謝性アシドーシス

[Rx-Nep-Acid-Bic] 炭酸水素ナトリウム
  • 炭酸水素ナトリウム錠500mg 1回2錠 1日3回 毎食後 28日分

紹介

[Doc-Gen-Referral] 診療情報提供書 (腎臓内科へ紹介：尿蛋白≧0.5g/gCr、eGFR<45等)

指導・計画​

  • 再診目安: 4週間後。

💡 Dr.Advice

[注射不可] 当院ではESA注射（ネスプ等）の採用がないため、腎性貧血治療は内服のHIF-PH阻害薬で行う。HIF-PH阻害薬の使用が難しい場合（悪性腫瘍合併等）は、ESA投与のために他院へ紹介する必要がある。

[SGLT2阻害薬] RAS阻害薬に次ぐCKD治療の基本薬。投与初期にeGFRが10～20%低下すること（Initial Dip）があるが、中止せず継続することで長期的には腎保護に働く。

[高K血症薬の使い分け] ロケルマは即効性があり味が良いが、Naと交換するため「浮腫・心不全」に注意。カリメートは標準的だが「便秘・腸管穿孔」リスクがある。心機能低下例にはカリメート、それ以外はロケルマが第一選択となりつつある。

📖 詳細解説​

慢性腎臓病（CKD）は腎機能の慢性的な低下または腎障害の持続を示す概念で、心血管疾患のリスク因子でもある。

病態生理​

  • 定義（KDIGO 2012）: 以下のいずれかが3ヶ月以上持続
    • GFR 60 mL/min/1.73m2 未満
    • 腎障害の存在（蛋白尿、血尿、画像異常、病理異常）
  • 日本の疫学: 成人の約13%（約1,330万人）がCKD
  • 原因疾患（日本）: 糖尿病性腎症（第1位、約40%）、慢性糸球体腎炎（第2位）、腎硬化症（第3位、増加中）
  • 進行機序: 原疾患による糸球体障害 → ネフロン減少 → 残存ネフロンの過剰濾過 → 糸球体硬化 → さらなるネフロン喪失（悪循環）
  • CKD-MBD: 腎機能低下に伴うCa-P代謝異常、二次性副甲状腺機能亢進症、骨病変

診断基準・鑑別疾患​

  • CKDステージ分類（GFR区分）:
    • G1: 90以上（正常/高値）、G2: 60-89、G3a: 45-59、G3b: 30-44
    • G4: 15-29、G5: 15未満（末期腎不全）
  • 蛋白尿区分: A1: 正常（30mg/gCr未満）、A2: 微量アルブミン尿（30-299）、A3: 顕性蛋白尿（300以上）
  • CGA分類: 原因（Cause）+ GFR + 蛋白尿で重症度をヒートマップ分類
  • 腎機能推算: eGFR（日本人係数使用）でステージ分類を行う。なお、薬剤投与量の調整にはeGFRではなく**Ccr（Cockcroft-Gault式）**が用いられることが多い
  • 鑑別（原疾患の検索）:
    • 糖尿病性腎症: 糖尿病歴、網膜症合併、徐々に蛋白尿増加
    • IgA腎症: 血尿 + 蛋白尿、上気道感染後の肉眼的血尿
    • 腎硬化症: 高血圧、高齢、蛋白尿軽度
    • 多発性嚢胞腎: 画像で両側多発嚢胞

エビデンス・ガイドライン推奨​

  • CKD診療ガイドライン2024（日本腎臓学会）:
    • 血圧管理: 蛋白尿あり: 130/80mmHg未満、蛋白尿なし: 140/90mmHg未満
    • RAS阻害薬: ACE阻害薬/ARBが蛋白尿抑制・腎保護に第一選択
    • SGLT2阻害薬: CKD G2-4（eGFR 20以上）で腎保護効果あり（DAPA-CKD, EMPA-KIDNEY）→ 糖尿病の有無を問わず推奨
    • フィネレノン（ケレンディア）: 2型糖尿病合併CKDで腎・心血管イベント抑制
    • 食事療法: 蛋白制限（G3以降: 0.6-0.8g/kg/日）、塩分制限（6g/日未満）、カリウム制限（G4以降）
  • 腎臓専門医紹介基準: eGFR 45未満、蛋白尿0.5g/gCr以上、急速なeGFR低下（年5以上）、血尿+蛋白尿
  • 透析導入: eGFR 5-8程度で症状を考慮して開始
