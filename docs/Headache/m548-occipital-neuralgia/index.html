[M54.8] 後頭神経痛 / Occipital Neuralgia

📋 主訴・所見・診察前対応

主訴・ROS

頭痛 (OPQRST)

発症様式: 突然[雷鳴] / 急性 / 徐々 / いつもの頭痛 増悪・寛解: 体動 / 入浴 / アルコール / 光・音 / 安静 性状: ズキズキ / 締め付けられる / 殴られたような / 電撃的 部位: 片側 / 両側 / 後頭部 / 目の奥 / 全体 強度: NRS ＿/10 生活に支障あり / 寝込む 経過: ＿時間/日 持続、頻度 ＿回/月

随伴症状

悪心・嘔吐、閃輝暗点、流涙・鼻汁、肩こり しびれ、麻痺、言葉が出にくい、発熱

てんかん・発作

意識消失 有 / 無、痙攣 全身 / 一部、前兆 目撃情報: 白目 / 泡を吹く / 硬直 / 脱力

背景

既往歴: 片頭痛 / 高血圧 / 癌 / 副鼻腔炎 / 脳卒中 市販薬使用: なし / あり: ＿錠/月 ；MOHリスク評価

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

神経学的所見

意識レベル: 清明 / JCS ＿ / GCS ＿ 髄膜刺激症状: 項部硬直 有 / 無、Kernig徴候 有 / 無 局所徴候: 麻痺 有 / 無、Barre徴候 有 / 無 脳神経: 眼瞼下垂 有 / 無、瞳孔不同 有 / 無 小脳症状: 指鼻試験 正常 / 測定障害

局所

側頭動脈: 正常 / 怒張 / 圧痛 ；GCA疑い 圧痛点: 副鼻腔叩打痛 有 / 無、大後頭神経圧痛 有 / 無

除外項目(Negative ROS)

雷鳴頭痛の否定、神経脱落症状なし、項部硬直なし

診察前対応

（データなし）

💡 Dr.Advice

[SNOOP4 (Red Flags)] 以下のサインは二次性頭痛（危険）を示唆する。一つでもあれば、当院で抱えずCT/MRIのある施設へ紹介せよ。

[雷鳴頭痛の定義] 「突然」とは「何時何分」と言えるレベルの急激さであり、「バットで殴られたような」と表現される。痛みのピークが1分以内に完成する場合は、CTが正常でもルンバール（髄液検査）が必要なSAHの可能性がある。

[緑内障発作] 「頭が痛い」と言って来院しても、実は「眼圧上昇（緑内障発作）」であることがある。特に高齢女性の「片頭痛＋吐き気＋眼痛＋充血」は要注意。ペンライトで瞳孔を確認し、散瞳・対光反射消失があれば即眼科へ。

評価

  • 診断根拠: 片側（稀に両側）の後頭部～頭頂部の電撃的・突き刺すような痛み。
  • 圧痛点: 大後頭神経出口（Arnold's point）に強い圧痛。
  • 感覚障害: 支配領域のピリピリ感（アロディニア）。
  • 除外: 帯状疱疹（皮疹なし）、椎骨動脈解離（持続痛・突然発症）。

方針・処方

  • 治療戦略: 保存療法（局所安静、温熱、NSAIDs、ビタミンB12）。
  • 難治例には神経ブロック（局所麻酔薬注射）。

処方・処置 (選択)​

内服治療

[Rx-Gen-Pain-Lox-Set-14] ロキソニン・レバミピドセット(定期)
  • ロキソニン錠60mg 1回1錠 1日3回 毎食後 14日分
  • レバミピド錠100mg 1回1錠 1日3回 毎食後 14日分 [Rx-Der-HZ-Mir-10] タリージェ
  • タリージェ錠5mg 1回1錠 1日2回 朝夕食後 14日分 — 7日以上かけて効果をみながら増量 [Rx-Neuro-Vit-Met] メチコバール
  • メチコバール錠500μg 1回1錠 1日3回 毎食後 14日分

神経ブロック

[Inj-Gen-Block] キシロカイン(局麻)
  • キシロカイン注射液1% 5mL 1本 圧痛点に局所注射

💡 Dr.Advice

[帯状疱疹の先行痛] 後頭神経痛と診断した数日後に、同部位に水疱が出現し「帯状疱疹」だったケースが多い。初診時に「もし赤いブツブツが出たら、すぐに再診してください（抗ウイルス薬が必要です）」と必ず伝えておくこと。これがリスクマネジメントである。

[椎骨動脈解離] 「美容院でのシャンプー後」「カイロプラクティック後」などに発症した急激な後頸部痛は、椎骨動脈解離を疑う。痛み止めで様子を見ず、MRI(MRA)を考慮せよ。

📖 詳細解説​

病態生理​

  • 後頭神経痛は大後頭神経（C2）、小後頭神経（C2-3）、第3後頭神経（C3）の領域に生じる発作性疼痛
  • 原因: 後頭部の筋緊張による神経絞扼（僧帽筋・頭半棘筋の緊張）、頸椎変性（C2-3）、外傷後、帯状疱疹後
  • 大後頭神経の走行: C2神経根→頭半棘筋を貫通→僧帽筋腱膜を貫通→後頭部皮下。この貫通部で絞扼されやすい
  • 長時間のデスクワーク、スマートフォン使用（下向き姿勢）が誘因となりやすい

診断基準・鑑別疾患​

  • 後頭神経痛の診断（ICHD-3）:
    • 大後頭神経、小後頭神経、第3後頭神経のいずれかの支配領域の疼痛
    • 発作性の刺すような痛み（数秒〜数分）、うずくような持続痛を伴うこともある
    • 罹患神経の圧痛（Tinel様徴候: 神経走行部の叩打で放散痛）
    • 後頭神経ブロックで一時的に疼痛消失（診断的ブロック）
  • 鑑別疾患:
    • 緊張型頭痛: 両側性の締め付け感。後頭神経の圧痛は限定的
    • 頸原性頭痛: 頸椎の運動で増悪、頸部の可動域制限
    • 片頭痛（後頭部型）: 拍動性、嘔気、光過敏
    • 帯状疱疹/帯状疱疹後神経痛: 水疱・皮疹の既往
    • くも膜下出血: 突然の激しい後頭部痛。必ず除外

エビデンス・ガイドライン推奨​

  • 後頭神経ブロック:
    • 診断的かつ治療的。大後頭神経ブロックが最も一般的
    • 手技: 後頭隆起と乳様突起を結ぶ線の内側1/3の点で、1%リドカイン2-3mL+デキサメタゾン2mg を後頭動脈拍動の内側に注射
    • 約60-80%で即効性の疼痛改善。効果持続は数日〜数週間
  • 薬物療法:
    • NSAIDs: ロキソプロフェン、セレコキシブ等で対症療法
    • 筋弛緩薬: チザニジン（テルネリン）1-6mg/日
    • 神経障害性疼痛薬: プレガバリン75-150mg/日、ミロガバリン
    • 抗うつ薬: アミトリプチリン10-25mg就寝前（慢性化例）
  • 非薬物療法:
    • 姿勢改善指導（頸椎の前弯維持）、ストレッチ、温熱療法
    • 理学療法: 後頸部の筋のリラクゼーション
  • 難治例: 後頭神経パルス高周波療法、ボツリヌス毒素注射（off-label）
