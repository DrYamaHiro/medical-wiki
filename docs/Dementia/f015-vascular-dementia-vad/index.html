[F01.5] 血管性認知症 / Vascular Dementia / VaD

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 家族の勧め / もの忘れ外来希望 / 区の検診 / 介護保険申請のため

中核症状 (認知機能)

  • 短期記憶: 同じことを何度も聞く / 置き忘れ / 約束を忘れる
  • 見当識: 日付が不明 / 道に迷う / 季節感がない
  • 実行機能: 料理の手順が悪くなった / 家電が使えない / 釣銭計算ができない

周辺症状 (BPSD)

  • 精神系: 幻視・幻聴 / 物盗られ妄想 / 嫉妬妄想 / 易怒性・暴言 / 徘徊 / 夜間せん妄 / 睡眠障害 / 介護抵抗

生活機能 (DASC-21等)

  • ADL: 自立 / 一部介助 / 全介助
  • IADL: 買い物 / 服薬管理 / 金銭管理

背景・ROS

  • 全身症状: 体重変化 なし / 増加 / 減少 ＿kg, 食欲 良好 / 低下 / 過食 / 異食
  • 精神・神経: 物忘れ 有, 呂律難 有 / 無, 歩行障害 有 / 無, 睡眠 良好 / 不眠
  • 学歴・職歴: ＿
  • 嗜好品: 飲酒 なし / 機会飲酒 / 多飲 ；アルコール性除外
  • 家族歴: 認知症 / 脳卒中

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

神経学的所見

  • 麻痺: 有 / 無
  • 歩行障害: 小刻み / すくみ / ワイドベース / なし
  • 不随意運動: 固縮 / 振戦 / ミオクローヌス / なし

神経心理検査

  • HDS-R: ＿/30点, MMSE: ＿/30点
  • 時計描画試験(CDT): 正常 / 異常

院内迅速

  • 血糖: ＿ mg/dL, HbA1c: ＿ %

除外診断用採血 (外注)

  • 甲状腺機能(TSH/FT4), ビタミンB1/B12/葉酸, 電解質, 肝腎機能

診察前対応

（データなし）

💡 Dr.Advice

[Treatable Dementiaの除外] 「治る認知症」を見逃さないこと。1. 慢性硬膜下血腫(CT依頼), 2. 正常圧水頭症(iNPH)(CT依頼), 3. 甲状腺機能低下症, 4. ビタミン欠乏症(B1, B12, 葉酸)の除外はプライマリケア医の責務である。

[聴取テクニック] 本人に「今日は何を食べましたか？」と聞き、答えられても安心せず家族に確認せよ。「取り繕い反応」に騙されないことが診断の第一歩。

[自動車運転] 診断がついた時点で道路交通法に基づき運転は「禁止」となる。「法律で決まっている」「事故を起こしてからでは遅い」と明確に引導を渡すこと。

評価

  • 診断根拠: 脳卒中発作後の階段状悪化、感情失禁、意欲低下(アパシー)、局所神経徴候。
  • 画像所見: 梗塞巣・白質病変（他院情報）。
  • 分類: まだら認知症。

方針・処方

  • 治療戦略: 脳血管リスクの厳格管理による再発予防（最優先）。抗血小板療法。

処方・処置 (選択)​

再発予防・意欲改善

[Rx-IHD-AntiPlt-Cil] プレタールOD錠100mg 1回2錠 1日2回 朝夕食後 28日分 ；アパシー改善期待[Rx-IHD-AntiPlt-Asp] バイアスピリン錠100mg 1回1錠 1日1回 朝食後 28日分[Rx-Neuro-Cir-Ife] イフェンプロジル酒石酸塩錠20mg 1回1錠 1日3回 毎食後 28日分 ；意欲改善

指導・計画 (必須)​

  • 生活指導: 血圧管理、禁煙の徹底。脳梗塞再発防止が最大の治療であると説明。
  • 再診目安: 4週間後

💡 Dr.Advice

[アパシー] 「うつ」と間違われやすいが悲哀感はない。抗うつ薬は効きにくく、シロスタゾールやサアミオン等が有効な場合がある。

📖 詳細解説​

病態生理​

  • **血管性認知症（VaD）**は脳血管障害に起因する認知症。認知症の約15-20%
  • 病型: 多発梗塞性認知症、戦略的部位の単一梗塞（視床、角回等）、小血管病変（Binswanger型白質脳症）、脳出血後
  • 臨床的特徴: 階段状の進行（脳卒中発症ごとに悪化）、まだら認知症（保たれる機能と障害される機能が混在）、実行機能障害が前景、感情失禁

診断基準・鑑別疾患​

  • NINDS-AIREN基準（National Institute of Neurological Disorders and Stroke - Association Internationale pour la Recherche et l'Enseignement en Neurosciences）:
    • Probable VaD: (1)認知症の存在（記憶障害+2つ以上の認知領域の障害でADL低下）(2)脳血管疾患の存在（局所神経徴候+画像上の脳血管病変）(3)両者の関連（脳卒中発症後3ヶ月以内の認知症発症 or 突然の認知機能悪化 or 段階的・動揺性の経過）
    • Possible VaD: 認知症+局所神経徴候があるが、画像確認不能 or 時間的関連が不明確
    • Definite VaD: Probable VaDの臨床基準 + 病理学的確認
  • VaDのサブタイプ分類:
    • 多発梗塞性認知症: 複数の中・大梗塞の蓄積による。階段状悪化が典型的
    • 戦略的部位の単一梗塞: 視床（前核・背内側核）、角回、帯状回、尾状核頭部など。小さな梗塞でも急性に認知症を発症
    • 小血管病変型（Binswanger型白質脳症/皮質下血管性認知症）: びまん性白質病変（ラクナ梗塞多発）。緩徐進行でADとの鑑別が困難。実行機能障害・処理速度低下が前景
    • 低灌流型: 心停止後、重度低血圧後の分水嶺梗塞
    • 脳出血後: 出血部位に依存した認知機能障害
  • 鑑別: AD（記憶障害が前景、緩徐進行）、AD+VaDの混合型（最も多いパターン、剖検例の約30-40%）
  • 画像: MRIで多発梗塞、広範な白質病変（Fazekas分類Grade 2-3）、戦略的部位の梗塞

エビデンス・ガイドライン推奨​

  • 脳血管リスク管理が最重要: 血圧管理130/80未満、脂質管理、血糖管理、抗血小板療法
  • ChEI（コリンエステラーゼ阻害薬）のエビデンス:
    • Donepezil 308 study（Blackら 2003, Stroke）: VaD患者603名を対象とした24週間RCT。ドネペジル5mg群・10mg群 vs プラセボ。ADAS-cog改善: 5mg群 -1.65点、10mg群 -2.09点（いずれもプラセボ比有意差あり p値 0.01未満）。CIBIC-plus（全般的臨床印象）でも有意な改善
    • Donepezil 307 study（Wilkinsonら 2003）: 同様のデザインで616名。認知機能・全般的改善を確認
    • ガランタミン: GAL-INT-6試験で軽度改善を示すが効果はADより限定的
    • 日本では: VaD単独へのChEI保険適応なし。AD合併が証明される混合型に対してドネペジルを使用可能
  • BPSD: 抑うつにSSRI、意欲低下（アパシー）にシロスタゾール（脳血流改善+抗血小板作用）
  • 再発予防: 脳梗塞の二次予防に準じた治療が認知機能のさらなる低下を防ぐ最善策。SPS3試験ではラクナ梗塞後のBP目標 130mmHg未満でICH減少
