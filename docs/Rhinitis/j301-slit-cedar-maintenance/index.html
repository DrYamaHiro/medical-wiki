[J30.1] スギ花粉症 / 舌下免疫療法・維持 / SLIT - Cedar Maintenance

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 鼻汁 / 鼻閉 / くしゃみ / 鼻内掻痒感 / 後鼻漏 / 嗅覚障害 / 鼻出血

鼻症状詳細

鼻汁: 水様 / 粘性 / 膿性 / 血性 鼻閉: 片側 / 両側 / 交代性 嗅覚障害: 有 / 無

背景

発症時期・季節性: ＿ アレルゲン曝露: ハウスダスト / ペット / 花粉 出血 (鼻出血時): 左 / 右, 止血にかかった時間: ＿分 市販点鼻薬の使用: なし / あり: 長期連用

所見・検査

前鼻鏡

粘膜: 蒼白浮腫 / 発赤腫脹 / 乾燥 / びらん 鼻汁: 水様 / 膿性 / 粘液性 鼻中隔: 弯曲なし / 右凸 / 左凸, 穿孔 有 / 無 キーゼルバッハ部位: 出血点あり / 痂皮 / 血管怒張

検査

副鼻腔圧痛: 有 / 無 単純X線 (Waters法): 上顎洞透過性低下 / ニボー像 / 正常

診察前対応

（データなし）

💡 Dr.Advice

[点鼻薬性鼻炎] 市販の血管収縮薬入り点鼻薬（ナザール等）を長期連用していないか必ず確認せよ。これが原因で鼻閉が悪化している場合、使用中止させなければ治らない。

[設備制約] 当院にはCTおよびファイバースコープがないため、X線で診断困難な副鼻腔炎や、上咽頭・深部の観察が必要な場合は耳鼻咽喉科へ紹介せよ。

[オンライン初診処方制限] オンライン診療において、お薬手帳、健診結果、紹介状等で基礎疾患が把握できない初診患者の場合、処方は「7日分を上限」とせよ。

評価

  • 治療経過: シダキュア5,000JAUによる維持療法中。
  • アドヒアランス: 毎日服用 / 週に数回忘れ / 中断気味
  • 副作用: なし / 口腔内違和感 / 腹痛 / 喘息発作
  • 効果実感: 症状軽減 / 薬が減った / まだ不明

方針・処方

  • 維持量（5,000JAU）の継続処方。
  • 生活指導（服用後2時間は激しい運動・入浴・飲酒を避ける）。
  • 治療期間（3～5年推奨）の再確認とモチベーション維持。

処方・アクション (選択)​

維持期処方セット

[Rx-Ent-SLIT-Cida5000] シダキュア5000(維持)
  • シダキュアースギ花粉舌下錠5,000JAU 1回1錠 1日1回 舌下 28日分 [Rx-Gen-Ent-Bil] ビラノア
  • ビラノア錠20mg 1回1錠 1日1回 空腹時 28日分 — 飛散期・症状ある時

💡 Dr.Advice

[前後2時間のルール] 服用直後の血行促進（運動・入浴・飲酒）は、アレルゲンの吸収を早め、アナフィラキシーのリスクを高めるため避けるよう毎回指導せよ。

[抜歯・口内炎] 抜歯後や口内炎がひどい時は、傷口からアレルゲンが直接血中に入る恐れがあるため、治るまで休薬させること。

[飲み忘れ対応] 「昨日の分を飲み忘れたからといって、今日2回分まとめて飲む」のは副作用リスクが高まるため厳禁である。「忘れた分は飛ばして、今日1回分だけ飲む」よう指導せよ。

[長期中断のリスク] 数日の飲み忘れならそのまま再開可能だが、1ヶ月以上中断した後にいきなり維持量(5,000JAU)を再開するとアナフィラキシーを起こす危険がある。長期中断例は必ず受診させ、場合によっては導入(2,000JAU)からやり直す判断が必要。

[モチベーション維持] 症状がない時期（夏～冬）に毎日薬を飲むことは苦痛である。「今の頑張りが来年の春に報われる」「3年頑張れば、一生楽になるかもしれない」と、長期的なメリットを繰り返し伝えて励ませ。

[喘息発作時] 風邪などを契機に喘息発作（咳・喘鳴・呼吸困難）が出現した場合は、シダキュアを「直ちに中止」し、喘息治療を優先すること。喘息が完全に落ち着くまで再開してはならない。

📖 詳細解説​

病態生理​

  • 維持期の免疫変化: 継続投与により制御性T細胞が安定的に誘導され、免疫寛容が確立
  • 効果の経時変化: 1シーズン目から効果を実感する患者もいるが、2-3シーズン目に最大効果。3年以上の継続で中止後も長期的効果持続（少なくとも3年間）
  • 併用薬の調整: SLIT開始後も花粉シーズンには抗ヒスタミン薬・点鼻ステロイドの併用が必要なことが多い。シーズンごとに使用量減少が期待できる

診断基準・鑑別疾患​

  • 効果判定のポイント:
    • 花粉シーズン中の症状スコア（くしゃみ、鼻漏、鼻閉の日誌記録）
    • レスキュー薬の使用頻度
    • QOLの改善度
    • 1年目で全く効果なしなら、診断の再確認・服用遵守の確認
  • 継続の障害: 毎日の服用忘れ（アドヒアランス低下が最大の問題）、副作用による自己中断

エビデンス・ガイドライン推奨​

  • 維持療法: シダキュア5,000JAU 1日1回を毎日継続（花粉シーズン中も含む通年投与）
  • 3年間の長期エビデンス: 国内長期試験では、3年間継続投与群は2年間投与群と比較して中止後の効果持続期間が長い。3年間継続後の中止では、少なくとも2-3シーズンは効果が持続することが示されている。欧州のSLITエビデンスでも3年間投与後の効果持続が7-8年以上にわたることが報告されている
  • 治療継続率: 国内市販後データでは、1年後の継続率は約70-75%、2年後は約55-60%、3年後は約40-50%。脱落の主因はアドヒアランス低下（飲み忘れ）と効果実感の乏しさであり、副作用による中止は約5-10%
  • 服用忘れの対処: 1日忘れた場合は翌日に通常量を服用。2週間以上の中断は医師に相談（再導入が必要な場合あり）
  • 花粉シーズンの併用療法: 必要に応じて抗ヒスタミン薬・点鼻ステロイドを追加
  • 治療期間と終了判断:
    • 推奨: 3-5年間の継続（最低3年が効果持続に必要）
    • 2シーズン経過で全く効果なし → 中止を検討
    • 3年以上継続で十分な効果 → 中止して経過観察（効果は数年持続）
    • 中止後再燃時 → 再導入可能
  • フォローアップ: 最初の1年は1-3ヶ月ごと、安定後は3-6ヶ月ごとの受診
