[H61.2] 耳垢塞栓 / Impacted Cerumen

📋 主訴・所見・診察前対応

主訴・ROS

眼症状

充血: 右 / 左 / 両眼, 眼脂: 膿性 / 水様 / 粘液性 自覚症状: 掻痒感 / 異物感 / 乾燥感 / 流涙 視力・視野: 低下なし / 急激な視力低下 / 霧視 / 視野欠損 眼痛: なし / 表面 / 奥 / 動かすと痛い

耳症状

耳痛: なし / あり, 耳漏: なし / 膿性 / 血性 難聴: なし / 急激 / 徐々 / 低音が聞こえにくい その他: 耳閉感 / 耳鳴り

経過・背景

発症時期: ＿ コンタクトレンズ使用: 有 / 無 既往歴: 緑内障 / 白内障 / 中耳炎 / アレルギー

所見・検査

眼

結膜充血: 有 / 無, 眼瞼腫脹: 有 / 無 角膜・瞳孔: 角膜混濁 / 瞳孔不同 / 対光反射迅速 / 対光反射消失

耳

外耳道: 発赤 / 耳垢栓塞 / 異常なし 鼓膜所見: 正常 / 発赤 / 混濁 / 液貯留 / 穿孔 耳介牽引痛: 有 / 無 ；外耳炎サイン

検査

標準純音聴力検査

  • 結果: 実施せず / 正常 / 感音難聴 / 伝音難聴

診察前対応

検査

[Phy-Ent-Audio] 標準純音聴力検査

💡 Dr.Advice

[RedFlag - 眼] 「急激な視力低下」「激しい眼痛（緑内障発作疑い）」「視野欠損」「眼球打撲」は専門医による緊急対応が必要。処方で粘らず即日紹介せよ。

[RedFlag - 耳] 「突然聞こえなくなった（突発性難聴）」は時間との勝負（Time is Hearing）。ステロイド治療のゴールデンタイムを逃さないため、即座に聴力検査を行い、異常があれば直ちに専門医へ送れ。

[ステロイド点眼の禁忌] 角膜ヘルペスや真菌感染にステロイドを点眼すると、劇的に悪化し失明のリスクがある。細隙灯で角膜を確認できない環境では、安易にステロイド点眼処方は避けるべきである。

評価

  • 診断根拠: 耳閉感、難聴、耳鳴り。外耳道を閉塞する耳垢塊。
  • 誘因: 入浴・プールでの膨張、耳かきでの押し込み。

方針・処方

  • 治療戦略: 耳垢除去。固着して除去困難な場合は軟化剤処方し後日除去。無理な操作は避ける。

処方・処置​

処置 (院内)

[Tx-Ent-Earwax] 耳垢栓塞除去

軟化剤 (除去困難時)

[Rx-Ent-Ear-Dewax] 耳垢水
  • ジオクチルソジウムスルホサクシネート耳科用液5% 10mL 1日3回 2日分 — 耳浴

指導・計画​

  • 患者指導: 耳垢水は点耳後5～10分耳浴し、その後洗浄する。耳かき（綿棒）で奥まで掃除しないよう指導。
  • 再診目安: 軟化後（2-3日後）。

📖 詳細解説​

最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。

病態生理​

  • 定義: 耳垢が外耳道を閉塞し、難聴・耳閉感等の症状を引き起こす状態
  • 耳垢の種類: 乾性耳垢（日本人の約85%）、湿性耳垢（約15%）
  • 原因: 外耳道の自浄作用の低下（高齢者、外耳道狭窄）、綿棒による耳垢の圧入
  • 症状: 伝音性難聴、耳閉感、耳鳴、めまい（まれ）

診断基準・鑑別疾患​

  • 診断: 耳鏡検査で外耳道の耳垢充満を確認
  • 鑑別: 外耳道異物、外耳道腫瘍、外耳道真珠腫

高齢者における耳垢塞栓の有病率と臨床的意義​

  • 有病率データ:
    • 一般成人: 約5%
    • 65歳以上の在宅高齢者: 約30-35%
    • 介護施設入所高齢者: 約50-65%（Mahoneyら 1992）
    • 認知症患者: 約60-70%（自浄作用低下+ケア困難）
  • 臨床的影響:
    • 耳垢塞栓による伝音難聴は5-40dBの聴力低下を来す
    • 高齢者の認知機能・QOLに影響（難聴はLancet Commission 2024でも認知症リスク因子第1位）
    • 耳垢除去により聴力改善だけでなく認知機能テストのスコアが改善するとの報告あり
    • 補聴器使用者では耳垢によるフィードバック不良・故障の原因となる
  • 高齢者での定期管理: 6ヶ月-1年ごとの耳鏡検査と耳垢除去が推奨（AAO-HNS Clinical Practice Guideline 2017）

エビデンス・ガイドライン推奨​

  • 除去方法:
    • 耳用鑷子（ピンセット）: 乾性耳垢に有効
    • 耳垢鉤: 大きな塊の除去
    • 耳洗浄（温水）: 硬い耳垢の軟化後に施行（鼓膜穿孔がないことを確認）
    • 耳垢水（グリセリン・重曹液）: 硬い耳垢を軟化させてから除去
  • 注意: 鼓膜穿孔、中耳手術歴がある場合は洗浄禁忌
  • 患者指導: 綿棒での耳掃除は外耳道入口部のみ、奥に押し込まない
  • 高齢者: 定期的な耳垢除去が推奨（難聴の可逆的原因として重要）
