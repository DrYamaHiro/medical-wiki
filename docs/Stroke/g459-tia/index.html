[G45.9] 一過性脳虚血発作 / TIA

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 麻痺 / しびれ / 脱力 / 言語障害 / めまい / 激しい頭痛

神経症状

麻痺部位: 右 / 左 / 上肢 / 下肢 / 顔面 言語: 呂律が回らない / 言葉が出ない / 理解できない 嚥下: 飲み込みにくい / ムセる その他: めまい / ふらつき / 視野欠損 / 複視 / 意識消失

発症状況 (OPQRST)

発症様式: 突然 / 徐々に / 朝起きたら[Wake-up stroke] 発症時刻: ＿時＿分 最終健常確認時刻

リスク・背景

既往歴: 高血圧 / 糖尿病 / 脂質異常症 / 喫煙 / 心房細動 / 脳卒中既往 内服薬: 抗凝固薬 / 抗血小板薬 / なし

所見・検査

バイタル: BP: ＿/＿, HR: ＿ (整/不整), SpO2: ＿%, GCS: ＿ (JCS ＿)

神経所見 (FAST)

Face (顔面麻痺): 有 / 無 Arm (上肢麻痺): Barre徴候 下垂あり / なし Speech (構語障害): 有 / 無 Time (発症時刻): ＿

その他

眼症状: 共同偏視 / 瞳孔不同 / 対光反射消失 小脳症状: 指鼻試験 正常 / 拙劣, 継ぎ足歩行 可能 / 不可 髄膜刺激症状: 項部硬直 有 / 無 ；SAH疑い 心電図: 正常洞調律 / 心房細動 / その他不整脈

診察前対応

（データなし）

💡 Dr.Advice

[設備制約・絶対搬送] 当院にはCT/MRIがないため、脳梗塞か脳出血かの鑑別は不可能である。脳卒中を疑う所見があれば、ルート確保等は行わず、直ちに救急要請または専門病院へ紹介せよ。

[禁忌] 画像診断なしにバイアスピリン等の抗血小板薬を投与することは、脳出血であった場合に増悪させるため「絶対禁忌」である。何も飲ませずに送ること。

評価

  • 診断根拠: 脳局所症状が出現し、24時間以内（多くは1時間以内）に完全に消失したもの。
  • ABCD2スコア: ＿点 (Age, BP, Clinical features, Duration, Diabetes)
  • リスク: 発症後48時間以内の脳梗塞移行リスク極めて大。

方針・処方

  • 治療戦略: 【緊急】当院では画像評価ができないため、症状が消失していても「脳梗塞の前兆」として直ちに専門病院へ紹介する。
  • 帰宅させてはならない。

アクション​

紹介・搬送

[Doc-Gen-Referral] 診療情報提供書
  • 紹介先: 脳神経外科・救急外来
  • 抗血小板薬の投与は、出血の除外ができないため行わない。

💡 Dr.Advice

[症状消失] 「治ったから大丈夫」ではない。TIAは不安定なプラークが存在する証明であり、いつ本発作（脳梗塞）が起きてもおかしくない状態である。必ず専門医へ送れ。

📖 詳細解説​

病態生理​

  • **TIA（一過性脳虚血発作）**は脳の一過性虚血により局所神経症状が出現し、典型的には1時間以内（定義上24時間以内）に完全回復する病態
  • 機序:
    • artery-to-artery embolism: 頸動脈や大動脈弓の不安定プラークからの微小塞栓が最多
    • 血行力学性: 高度狭窄部位の灌流低下（起立時や血圧低下時に発症）
    • 心原性: 心房細動に伴う微小塞栓（症状が短時間で回復）
    • 穿通枝病変: Branch atheromatous disease（BAD）
  • TIAは「脳梗塞の超急性前駆症状」:
    • TIA後48時間以内の脳梗塞発症率: 約5%
    • 90日以内の脳梗塞発症率: 約10-15%（未治療の場合）
    • 不安定プラーク・高度狭窄が存在する証拠であり、脳卒中の最大の警告サイン

診断基準・鑑別疾患​

  • TIAの診断:
    • 突然発症の局所神経症状（片麻痺、構音障害、失語、単眼性視力障害など）
    • 症状は完全に消失（診察時に無症状のことが多い）
    • 組織ベースの定義（2009年AHA/ASA）: DWIで梗塞巣がなければTIA、あれば「脳梗塞」
  • ABCD2スコア（TIA後の脳梗塞リスク評価）:
    • Age 60歳以上: 1点
    • BP 収縮期140以上 and/or 拡張期90以上: 1点
    • Clinical features: 片側脱力2点 / 脱力を伴わない言語障害1点
    • Duration: 60分以上2点 / 10-59分1点
    • Diabetes: 1点
    • 合計4点以上は高リスク（48時間以内の脳梗塞発症率約8%）
  • 鑑別疾患:
    • てんかん（Todd麻痺）: 痙攣の既往、陽性症状先行
    • 片頭痛（前兆を伴う）: 若年者、陽性症状が進展、頭痛後続
    • 末梢性めまい（BPPV、メニエール病）: 聴覚症状、体位変換で誘発
    • 低血糖: 糖尿病治療中、血糖測定で確認
    • 過換気症候群: 両側性のしびれ、不安・呼吸困難

エビデンス・ガイドライン推奨​

  • 緊急評価・治療の重要性:
    • EXPRESS研究（2007）: TIA後の緊急評価・即日治療開始により90日以内の脳卒中リスクが80%減少
    • SOS-TIA研究（2007）: 24時間体制のTIA専門外来で90日脳卒中率1.24%（予測値5.96%）
  • 急性期抗血小板療法:
    • アスピリン160-300mg即日投与を推奨（脳卒中治療ガイドライン2021、推奨度A）
    • 発症24時間以内: アスピリン+クロピドグレルのDAPT 21日間が有効（CHANCE試験: HR 0.68）
    • ただし出血の除外が必須であり、画像診断施設のない当院では投与せず専門病院へ送る
  • 頸動脈狭窄の評価:
    • 症候性頸動脈狭窄70%以上: 頸動脈内膜剥離術（CEA）が推奨（NASCET、推奨度A）
    • 50-69%狭窄: CEAの有効性あり（推奨度B）
  • 心房細動スクリーニング:
    • TIA患者の最大25%で心房細動が検出される。心房細動を認めた場合は**CHA₂DS₂-VAScスコア**で抗凝固療法の適応を評価
    • 12誘導心電図、24時間ホルター、必要に応じて長時間心電図モニタリング
