[E60] 亜鉛欠乏症 / Zinc Deficiency

📋 主訴・所見・診察前対応

主訴・ROS

貧血症状

自覚症状: 労作時息切れ / 動悸 / めまい / 立ちくらみ / 易疲労感 / 耳鳴り 特異的症状: 氷食症[Pica] / 爪の変形 / 舌痛 / 味覚障害 神経症状: なし / 手足のしびれ / 歩行時のふらつき ；B12欠乏疑い

出血・栄養歴

月経: 順調 / 過多月経 / 凝血塊あり / 期間延長 消化管: なし / 黒色便 / 血便 / 胃切除歴 食事・嗜好: 偏食 / ベジタリアン / アルコール多飲

所見・検査

眼瞼結膜: 正常 / 蒼白 口腔: 舌乳頭萎縮 / 平滑舌 / 口角炎 爪: 正常 / 扁平 / 匙状爪[Koilonychia]

循環器・神経

脈拍: ＿ bpm, 心雑音: なし / 収縮期駆出性雑音 神経所見: 異常なし / 振動覚低下 / Romberg徴候陽性

院内迅速検査

末梢血一般(CBC)

  • Hb ＿ g/dL, MCV ＿ fL, Plt ＿ x10^4/μL
  • 判定: 小球性<80 / 正球性80-100 / 大球性>100

外注検査

貧血・鉄代謝

  • 血清鉄(Fe), UIBC, フェリチン ビタミン欠乏性貧血
  • ビタミンB12, 葉酸 ；大球性の場合 網状赤血球数

診察前対応

院内迅速検査

[Lab-Gen-CBC_CRP] 末梢血一般(CBC)

外注検査

[Lab-Hem-Iron] 貧血・鉄代謝[Lab-Hem-Vit] ビタミン欠乏性貧血

💡 Dr.Advice

[貧血は症状] 「貧血」は病名ではなく「状態」である。鉄剤を出して終わりにしてはならない。閉経後女性や男性の貧血は、消化管癌（胃癌・大腸癌）のサインである可能性が極めて高いため、必ず内視鏡検査を強く推奨せよ。

[異食症] 「氷をガリガリ食べるのが止められない」は鉄欠乏性貧血に特異的な症状である。鉄剤投与で劇的に消失する。

[MCVの鑑別]

  • 小球性低色素性貧血 (MCV<80): ①鉄欠乏性貧血（最多）②サラセミア③慢性疾患（ただし正球性が多い）の順で考えよ。「フェリチン低値」が鉄欠乏の決め手となる。
  • 正球性正色素性貧血 (MCV 80-100): ①急性出血②慢性疾患性貧血③溶血性貧血④再生不良性貧血を考える。
  • 大球性貧血 (MCV>100): ①ビタミンB12欠乏②葉酸欠乏③アルコール性が三大原因。神経症状（サブコンバイン）はB12欠乏に特異的。

評価

  • 診断根拠: 診断3要素 — (1)臨床症状（味覚障害・皮膚炎・貧血・食欲不振等）+(2)血清亜鉛値（60μg/dL未満で確定、60-80μg/dLで潜在性欠乏）+(3)亜鉛補充による改善。
  • 重症度: 味覚障害・皮膚症状（口囲や四肢末端の皮膚炎）・食欲不振・貧血の有無で評価。
  • 鑑別: 味覚障害・皮膚炎・貧血・食欲不振の原因として亜鉛欠乏を鑑別に挙げる。ペラグラ（ナイアシン欠乏）、ビオチン欠乏、腸性肢端皮膚炎も除外。

方針・処方

  • 亜鉛補充療法を開始し、3ヶ月で効果判定。
  • 血清亜鉛・ALP・血清銅を定期フォロー（銅欠乏に注意）。
  • 原因検索: PPI長期内服、利尿薬、肝硬変、炎症性腸疾患、腎不全等。

処方・アクション​

亜鉛補充セット

[Rx-Hem-Zn-Nov] ノベルジン
  • ノベルジン錠25mg 1回1錠 1日2回 朝夕食後 28日分 — 低亜鉛血症 [Rx-Hem-Zn-Ace] 酢酸亜鉛（増量時）
  • 酢酸亜鉛錠25mg 1回1錠 1日3回 毎食後 28日分 — 低亜鉛血症

※初期は25mg 1日2回で開始。効果不十分時に25mg 1日3回へ増量（最大150mg/日）。 ※ポラプレジンク（プロマック）は亜鉛欠乏症に対し適応外使用となるため注意。

検査・アクション​

フォローアップ検査

[Lab-Hem-Zn] 血清亜鉛[Lab-Hem-Cu] 血清銅[Lab-Hem-ALP] ALP

指導・計画​

  • 再診目安: 4週後に血清亜鉛再検。3ヶ月で症状改善を評価。

💡 Dr.Advice

[見落とし注意] 亜鉛欠乏は非特異的症状のため見落とされやすい。原因不明の味覚障害・貧血・皮膚炎では必ず血清亜鉛を測定すること。

[原因検索] PPI長期内服、サイアザイド系利尿薬、肝硬変、腎不全、炎症性腸疾患が主な原因。原因除去が根本治療となる。

[銅欠乏] 亜鉛長期補充により銅の吸収が阻害される。血清銅を定期的にモニタリングすること。

📖 詳細解説​

亜鉛は生体内に約2g存在し、300種以上の酵素の活性中心として機能する必須微量元素である。DNAポリメラーゼ、RNA合成酵素、アルカリホスファターゼ等に不可欠であり、欠乏すると細胞分裂が盛んな組織（味蕾、皮膚、血球、精子）から障害が現れる。日本人の推定有病率は高齢者の約20-30%と報告されており、見過ごされやすい栄養障害である。

病態生理​

亜鉛の体内動態

  • 1日必要量: 成人男性11mg、成人女性8mg（日本人の食事摂取基準2020）
  • 吸収部位: 十二指腸~空腸（吸収率約30%）
  • 体内分布: 骨格筋60%、骨25%、皮膚8%、肝臓5%。血清中には0.1%のみ存在
  • 排泄: 主に消化管（膵液・胆汁）、一部腎から

欠乏の原因

機序具体例
摂取不足高齢者の低栄養、偏食、長期経腸栄養（亜鉛非添加製剤）、アルコール多飲
吸収障害PPI長期内服（胃酸低下による吸収低下）、炎症性腸疾患（クローン病）、短腸症候群
排泄亢進肝硬変（尿中排泄増加）、腎不全・透析、サイアザイド系利尿薬
需要増大妊娠・授乳、小児の成長期、広範囲熱傷、褥瘡
薬剤性キレート作用: ペニシラミン、EDTA

欠乏による症状の機序

  • 味覚障害: 味蕾細胞のターンオーバー（10-14日）が障害される。味覚障害患者の約30%に亜鉛欠乏が関与。
  • 皮膚炎: 表皮基底細胞の分裂障害。口囲・四肢末端に好発（腸性肢端皮膚炎様の分布）。
  • 脱毛: 毛母細胞の分裂障害。びまん性脱毛を呈する。
  • 創傷治癒遅延: 線維芽細胞の増殖・コラーゲン合成障害。術後や褥瘡の治癒遅延の一因。
  • 貧血: 赤血球膜の安定性低下+エリスロポエチン産生低下による軽度の正球性貧血。鉄欠乏性貧血に合併していることも多い。
  • 免疫機能低下: T細胞機能低下、NK細胞活性低下。高齢者の易感染性の一因。
  • 性腺機能低下: 精子形成障害、テストステロン産生低下。

診断基準・鑑別疾患​

日本臨床栄養学会の診断基準（2018年）

以下の3要素で診断する:

  1. 臨床症状: 味覚障害、皮膚炎、口内炎、脱毛、褥瘡（難治性）、食欲低下、貧血、成長障害（小児）、性腺機能低下
  2. 血清亜鉛値:
    • 60 mcg/dL未満: 亜鉛欠乏症（確定）
    • 60-80 mcg/dL: 潜在性亜鉛欠乏（症状があれば治療対象）
    • 80 mcg/dL以上: 正常
  3. 亜鉛補充による症状改善: 診断的治療としても有用

検査上の注意点

  • 血清亜鉛は早朝空腹時に採血（日内変動があり、午前中が高値）
  • 溶血検体では偽高値となる（赤血球内亜鉛が流出）
  • ALPは亜鉛依存性酵素であり、亜鉛欠乏で低値を示す（ALPの変動が治療効果の指標にもなる）

鑑別疾患

  • 味覚障害の鑑別: 薬剤性（ACE阻害薬、抗甲状腺薬、メトホルミン等）、口腔乾燥症（シェーグレン症候群）、舌の真菌感染、加齢性
  • 皮膚炎の鑑別: ペラグラ（ナイアシン欠乏: 光線過敏＋下痢＋認知症の3D）、ビオチン欠乏、腸性肢端皮膚炎（先天性亜鉛吸収障害）、カンジダ症
  • 貧血の鑑別: 鉄欠乏性貧血（最も多い合併）、慢性疾患性貧血、ビタミンB12/葉酸欠乏

エビデンス・ガイドライン推奨​

治療薬

薬剤用法保険適応備考
ノベルジン（酢酸亜鉛）25-50mg 1日2-3回 食後低亜鉛血症（2017年追加）第一選択。亜鉛含有量が明確で用量調整しやすい。最大150mg/日
ポラプレジンク（プロマック）75mg 1日2回胃潰瘍のみ（亜鉛欠乏は適応外）1錠あたり亜鉛17mg含有。安価。適応外使用であることに注意

治療のポイント

  • 初期投与量: ノベルジン25mg 1日2回で開始
  • 効果発現: 味覚障害は2-4週で改善開始（完全回復に3-6ヶ月）、皮膚症状は1-2週で改善
  • 血清亜鉛は4週後に再検し、80 mcg/dL以上を目標
  • 銅欠乏に注意: 亜鉛は腸管での銅吸収を競合阻害する。長期投与（3ヶ月以上）では血清銅を定期モニタリング。銅欠乏は汎血球減少、脊髄変性を引き起こす
  • 3ヶ月間の治療で症状改善がなければ診断を再考

ハイリスク群（積極的スクリーニング対象）

  • 高齢者（特に施設入所者、低栄養）
  • PPI長期使用者
  • 肝硬変患者
  • 透析患者
  • 長期経腸栄養患者
  • 褥瘡・難治性創傷を有する患者
