[J11] インフルエンザB型 / Influenza B

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 発熱 / 咽頭痛 / 咳嗽 / 鼻汁 / 喀痰 / 頭痛 / 倦怠感 / 関節痛 / 悪寒 / 呼吸困難

呼吸器系

咳嗽: 乾性 / 湿性 / 犬吠様, 喀痰: 粘液性 / 膿性 / 血痰 / なし 呼吸困難: なし / あり: 安静時・労作時, 喘鳴: なし / あり

耳鼻・その他

鼻汁: 水様 / 膿性, 咽頭痛: 嚥下痛 / 自発痛

背景

発症時期: ＿ 周囲の感染状況: 家族 / 職場 / 学校 に インフル / コロナ / 感冒 あり ワクチン接種歴: インフル 済 / 未, コロナ 済 / 未

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃, SpO2: ＿% (Room Air)

頭頸部

咽頭: 発赤 / 扁桃肥大 / 膿栓・白苔 / 口蓋垂偏位 頸部リンパ節: 腫脹なし / あり: 圧痛

胸部

呼吸音: 清明 / 喘鳴 / Crackles / Rhonchi / 減弱 心音: 整 / 雑音なし

皮膚

発疹: 有 / 無

迅速検査

インフルエンザ抗原検査 A陽性 / B陽性 / 陰性 新型コロナウイルス抗原検査 陽性 / 陰性 A群ベータ溶連菌抗原検査 陽性 / 陰性 アデノウイルス抗原検査 陽性 / 陰性

画像 (必要時)

胸部単純X線検査 所見: 異常なし / 浸潤影 / 気管支壁肥厚 AI解析結果: 異常なし / 異常所見あり: ＿

診察前対応

⚠ 注意: 流涎・含み声・吸気性喘鳴など喉頭蓋炎を疑う場合、舌圧子での咽頭観察は厳禁（喉頭痙攣→完全気道閉塞の危険）。無理な観察をせず直ちに医師へ報告。

迅速検査

[Lab-Gen-Influenza] インフルエンザ抗原精密測定[Lab-Gen-COVID] 新型コロナウイルス抗原精密測定[Lab-Gen-Strep] A群ベータ溶連菌抗原定性[Lab-Ped-Adeno] アデノウイルス抗原精密測定

画像 (必要時)

[Img-Gen-ChestXP] 胸部単純X線撮影

💡 Dr.Advice

[RedFlag] 喉頭蓋炎の兆候（流涎、含み声、呼吸困難、吸気性喘鳴）がある場合は直ちに高次医療機関へ搬送せよ。

[鑑別] Centor Criteria（発熱・咳なし・前頸部リンパ節圧痛・扁桃白苔）を確認し、細菌性（溶連菌）の可能性を見極めよ。

[設備制約] 当院にはCTおよびファイバースコープがないため、喉頭蓋炎や深頸部膿瘍が疑われる場合は、身体所見のみでトリアージし、早期に専門医へ紹介せよ。

評価

  • 診断根拠: 発熱、消化器症状（腹痛・下痢・嘔気）、関節痛。迅速抗原検査 B型陽性。
  • 特徴: A型と比較し消化器症状が強く出やすい。

方針・処方

  • 抗インフルエンザ薬の投与。
  • 消化器症状に対する整腸剤の併用。

処方・アクション​

抗ウイルス薬選択

[Rx-Inf-Tamiflu] タミフル
  • オセルタミビルカプセル75mg 1回1カプセル 1日2回 朝夕食後 5日分 [Rx-Inf-Xofluza] ゾフルーザ
  • ゾフルーザ錠20mg 2錠 1回服用 (体重80kg未満)

感冒薬セット(4剤)

[Rx-Gen-Cold-4Meds] 感冒薬セット(4剤)
  • カロナール錠500mg 1回1錠 1日3回 毎食後 5日分
  • ムコダイン錠500mg 1回1錠 1日3回 毎食後 5日分
  • メジコン錠15mg 1回2錠 1日3回 毎食後 5日分
  • トランサミン錠250mg 1回2錠 1日3回 毎食後 5日分

腹部症状用・整腸剤

[Rx-Gen-GI-Bio] ビオフェルミン
  • ビオフェルミン錠 1回1錠 1日3回 毎食後 5日分

💡 Dr.Advice

[薬剤特徴と使い分け]

  • タミフル（オセルタミビル）【基本のキ】: 最もエビデンス豊富。1日2回×5日間。腎機能で調節必要。B型への反応はA型よりやや劣るが臨床的には有効。
  • ゾフルーザ（バロキサビル）【一撃必殺】: 1回飲むだけで終了。ウイルス排出停止が早い。家族内感染を防ぐ意味で強力。
  • イナビル（ラニナミビル）【吸入一回】: 1回吸入で終了。喘息などで吸入が上手な人向け。
  • リレンザ（ザナミビル）【吸入5日間】: 吸入薬だが5日間必要。妊婦や授乳婦への安全性が高い。
  • ラピアクタ（ペラミビル）【点滴】: 経口・吸入が不可能な患者（嘔吐、意識障害）用。

[B型特徴] B型は消化器症状を伴うことが多く、脱水になりやすいため水分摂取をより強く指導せよ。脱水が著しい場合は、ラクテックによる補液を検討せよ。

📖 詳細解説​

病態生理​

ウイルス学的特徴

  • B型インフルエンザウイルスはヒトのみを自然宿主とし、動物リザーバーを持たないためパンデミックの原因とはならない
  • 抗原ドリフトの速度はA型より遅い
  • Victoria系統とYamagata系統の2系統が存在したが、B/Yamagata系統は2020年3月以降世界的に検出されなくなった
  • WHOは2025-2026シーズン以降のワクチンからYamagata系統を除外し、3価ワクチンへの移行を勧告

A型との臨床的差異

  • 消化器症状（嘔吐・腹痛・下痢）の頻度がA型より高い（特に小児）
  • 小児でB型感染後の急性筋炎（良性急性小児筋炎）のリスクがA型より有意に高い：腓腹筋の筋痛・歩行困難で発症
  • M2イオンチャネル構造がA型と異なるため、アマンタジン・リマンタジンは無効

診断基準・鑑別疾患​

  • 臨床像はA型とほぼ同様（突然の高熱＋全身症状＋気道症状）だが、消化器症状がより多い
  • 迅速抗原検査：A型・B型を同時判定可能。B型はA型より感度がやや低い傾向（A型60-70%前後〔高感度検査では80-90%〕に対しB型70〜80%）
  • 発症後12〜48時間で検出率最高
  • 急性筋炎を呈する場合：CK高値を確認し、横紋筋融解症への進展に注意

鑑別疾患

  • インフルエンザA型（迅速検査で鑑別）、COVID-19、RSウイルス、アデノウイルス、溶連菌性咽頭炎

エビデンス・ガイドライン推奨​

抗インフルエンザ薬のB型への有効性

  • オセルタミビル：B型にも有効だが、B型ではA型よりやや効果が劣るとされる（A型での約16〜17時間短縮に対し、B型では有意な短縮が示されない報告もある）
  • バロキサビル：B型ではI38T耐性出現率がA/H3N2より低い
  • ザナミビル（リレンザ）：B型NAへの阻害活性はオセルタミビルと同等以上のin vitroデータあり
  • ラニナミビル・ペラミビル：B型にも有効
  • アマンタジン：B型には無効

小児での注意点

  • 急性筋炎は学童期男児に多く、多くは自然軽快するがCK著明高値の場合は横紋筋融解症に注意
  • インフルエンザ脳症はA型に多いがB型でも報告あり
  • 解熱薬はアセトアミノフェン限定。アスピリン・ジクロフェナク・メフェナム酸は禁忌（脳症・Reye症候群リスク）
  • 異常行動はA型・B型とも抗ウイルス薬の種類を問わず報告：発熱後少なくとも2日間は小児・未成年者を一人にしない

ワクチン

  • 2025-2026シーズンよりYamagata系統除外の3価ワクチンへ移行が進行中
  • B型に対する有効率はシーズンにより変動するが概ね40〜60%
