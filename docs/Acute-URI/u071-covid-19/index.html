[U07.1] 新型コロナウイルス感染症 / COVID-19

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 発熱 / 咽頭痛 / 咳嗽 / 鼻汁 / 喀痰 / 頭痛 / 倦怠感 / 関節痛 / 悪寒 / 呼吸困難

呼吸器系

咳嗽: 乾性 / 湿性 / 犬吠様, 喀痰: 粘液性 / 膿性 / 血痰 / なし 呼吸困難: なし / あり: 安静時・労作時, 喘鳴: なし / あり

耳鼻・その他

鼻汁: 水様 / 膿性, 咽頭痛: 嚥下痛 / 自発痛

背景

発症時期: ＿ 周囲の感染状況: 家族 / 職場 / 学校 に インフル / コロナ / 感冒 あり ワクチン接種歴: インフル 済 / 未, コロナ 済 / 未

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃, SpO2: ＿% (Room Air)

頭頸部

咽頭: 発赤 / 扁桃肥大 / 膿栓・白苔 / 口蓋垂偏位 頸部リンパ節: 腫脹なし / あり: 圧痛

胸部

呼吸音: 清明 / 喘鳴 / Crackles / Rhonchi / 減弱 心音: 整 / 雑音なし

皮膚

発疹: 有 / 無

迅速検査

インフルエンザ抗原検査 A陽性 / B陽性 / 陰性 新型コロナウイルス抗原検査 陽性 / 陰性 A群ベータ溶連菌抗原検査 陽性 / 陰性 アデノウイルス抗原検査 陽性 / 陰性

画像 (必要時)

胸部単純X線検査 所見: 異常なし / 浸潤影 / 気管支壁肥厚 AI解析結果: 異常なし / 異常所見あり: ＿

診察前対応

⚠ 注意: 流涎・含み声・吸気性喘鳴など喉頭蓋炎を疑う場合、舌圧子での咽頭観察は厳禁（喉頭痙攣→完全気道閉塞の危険）。無理な観察をせず直ちに医師へ報告。

迅速検査

[Lab-Gen-Influenza] インフルエンザ抗原精密測定[Lab-Gen-COVID] 新型コロナウイルス抗原精密測定[Lab-Gen-Strep] A群ベータ溶連菌抗原定性[Lab-Ped-Adeno] アデノウイルス抗原精密測定

画像 (必要時)

[Img-Gen-ChestXP] 胸部単純X線撮影

💡 Dr.Advice

[RedFlag] 喉頭蓋炎の兆候（流涎、含み声、呼吸困難、吸気性喘鳴）がある場合は直ちに高次医療機関へ搬送せよ。

[鑑別] Centor Criteria（発熱・咳なし・前頸部リンパ節圧痛・扁桃白苔）を確認し、細菌性（溶連菌）の可能性を見極めよ。

[設備制約] 当院にはCTおよびファイバースコープがないため、喉頭蓋炎や深頸部膿瘍が疑われる場合は、身体所見のみでトリアージし、早期に専門医へ紹介せよ。

評価

  • 診断根拠: 発熱、咽頭痛、咳嗽。迅速抗原検査 陽性。
  • 重症度: 軽症 / 中等症I / 中等症II / 重症
  • リスク因子: 高齢、肥満、基礎疾患、ワクチン未接種。

方針・処方

  • 感染対策の徹底と自宅療養指導。
  • 重症化リスクに応じた抗ウイルス薬の検討。

処方・アクション​

重症化リスクあり・抗ウイルス薬

[Rx-Cov-Xocova] ゾコーバ
  • ゾコーバ錠125mg 初日3錠 2日目以降1錠 1日1回 5日分 (併用禁忌確認必須)

※主な併用禁忌（CYP3A関連）: Ca拮抗薬（一部）、シンバスタチン、アトルバスタチン、リバーロキサバン、エドキサバン、カルバマゼピン、フェニトイン、イトラコナゾール、タクロリムス、PDE5阻害薬 → 最新の添付文書を参照 [Rx-Cov-Lagevrio] ラゲブリオ

💡 Dr.Advice

[併用禁忌] ゾコーバはCYP3Aを強く阻害するため併用禁忌薬が極めて多い。Ca拮抗薬・スタチン・DOAC・抗てんかん薬・免疫抑制薬など広範囲に影響する。必ずお薬手帳を確認し、不明な場合は薬剤師にダブルチェックを依頼せよ。妊婦には禁忌。

[RedFlag] SpO2 93%以下、呼吸困難、持続する胸痛は入院適応を考慮し直ちに連携病院へ相談せよ。当院にはCTがないため、肺病変の評価は胸部X線に限定される。

📖 詳細解説​

病態生理​

ウイルス学

  • 原因ウイルス: SARS-CoV-2（一本鎖(+)RNAウイルス、コロナウイルス科ベータコロナウイルス属）
  • スパイク(S)タンパク質がヒト細胞表面の ACE2受容体 に結合し、TMPRSS2（膜貫通型セリンプロテアーゼ）による切断を介して細胞内に侵入
  • 主な感染経路: 飛沫感染・エアロゾル感染、接触感染
  • 潜伏期: オミクロン系統では 2〜3日（デルタ株以前は4〜5日）

変異株の動向（2024〜2025年）

  • オミクロン系統の亜系統（XBB → EG.5 → JN.1 → KP.2/KP.3 → XEC系統等）が主流
  • 免疫回避能の向上と上気道親和性の増加が特徴
  • 重症化率はワクチン普及・既感染による集団免疫で低下傾向だが、高齢者・免疫不全者では依然リスクあり

病態の進展

  1. ウイルス増殖期（発症〜7日）: 上気道でのウイルス複製 → 発熱・咽頭痛・咳嗽
  2. 宿主免疫応答期（7〜14日）: 過剰な免疫応答 → サイトカインストーム（IL-6、TNF-α、IL-1β等の過剰産生）→ 肺胞障害・ARDS・多臓器不全
  3. 血管内皮障害: ACE2は血管内皮にも発現 → 微小血栓形成（D-dimer上昇）・血栓塞栓症

重症化リスク因子

  • 65歳以上
  • BMI 30以上
  • 糖尿病（HbA1c管理不良）
  • 慢性腎臓病（eGFR 30未満で特にハイリスク）
  • 慢性肺疾患（COPD、重症喘息）
  • 心血管疾患
  • 免疫抑制状態（臓器移植後、悪性腫瘍治療中、HIV/AIDS）
  • 妊娠後期
  • ワクチン未接種・未完了

診断基準・鑑別疾患​

検査法と特性

検査感度特異度備考
抗原定性検査（迅速）50〜80%97〜99%発症後1〜9日目で感度良好。発症直後（24h以内）は偽陰性多い
抗原定量検査70〜90%95〜99%定性より感度やや良好
RT-PCR（核酸検出）90〜95%99%以上ゴールドスタンダード。感染早期から検出可。結果まで数時間

検査のタイミング

  • 抗原検査は 発症後12〜48時間 での実施が最も感度が高い
  • 発症当日の抗原検査陰性でも、翌日再検で陽転することがある
  • 無症状スクリーニングには抗原検査の感度は不十分 → PCRが望ましい

重症度分類（日本の基準）

重症度基準
軽症SpO2 96%以上、呼吸困難なし
中等症I（呼吸不全なし）SpO2 93〜95%、息切れ・肺炎所見あり
中等症II（呼吸不全あり）SpO2 93%以下、酸素投与が必要
重症ICU入室、人工呼吸器管理が必要

鑑別疾患

  • インフルエンザ（迅速検査で鑑別、同時流行に注意）
  • RSウイルス感染症（高齢者・乳幼児）
  • 溶連菌性咽頭炎（咽頭所見・迅速検査）
  • マイコプラズマ肺炎（若年者の遷延する乾性咳嗽）
  • 細菌性肺炎（膿性痰・白血球上昇・CRP高値）
  • アレルギー性鼻炎・気管支喘息の増悪

エビデンス・ガイドライン推奨​

抗ウイルス薬（5類移行後・外来処方、2024〜2025年時点）

いずれも 発症5日以内 の投与開始が原則。重症化リスクのある患者が主な適応。

薬剤用法・用量特徴・注意点
エンシトレルビル（ゾコーバ）初日375mg、2〜5日目125mg 1日1回 計5日間3CLプロテアーゼ阻害薬。CYP3A基質との併用禁忌多数（Ca拮抗薬、スタチン系等）。妊婦禁忌。重症化リスクの有無を問わず使用可（症状軽減効果）。日本発の薬剤
ニルマトレルビル/リトナビル（パキロビッド）ニルマトレルビル300mg+リトナビル100mg 1日2回 5日間重症化予防効果が最も高い（入院・死亡リスク約89%低下: EPIC-HR試験）。腎機能で用量調整（eGFR 30〜60: 半量）。eGFR 30未満は使用を推奨しない（投与経験不十分）。リトナビルによる薬物相互作用に注意
モルヌピラビル（ラゲブリオ）800mg 1日2回 5日間RNAポリメラーゼ阻害薬（変異誘発型）。重症化リスクを約30%低下（MOVe-OUT試験）。薬物相互作用が少なく使いやすい。妊婦禁忌。18歳未満の安全性未確立

薬剤選択の実践的指針

  • 重症化リスクが高い場合: パキロビッドを第一選択（エビデンスレベル最高）→ 相互作用で使用不可ならラゲブリオ
  • 重症化リスクが低い・軽症の場合: ゾコーバ（症状持続期間を約1日短縮）または対症療法
  • いずれの抗ウイルス薬も 自己負担（2024年4月以降、公費支援終了）

重症例の治療（入院管理）

  • レムデシビル（ベクルリー）点滴静注: 入院患者の標準治療
  • デキサメタゾン 6mg/日（酸素投与を要する中等症II以上）
  • バリシチニブ（オルミエント）: JAK阻害薬、重症例でデキサメタゾンと併用
  • トシリズマブ（アクテムラ）: IL-6受容体抗体、サイトカインストーム制御

ワクチン

  • 2024年度以降は 定期接種（B類）: 65歳以上・60〜64歳の特定基礎疾患保有者が対象（秋冬に年1回）
  • 任意接種として全年齢で接種可能（自己負担）
  • XBB.1.5対応、JN.1対応ワクチン等、流行株に合わせた更新型

Long COVID（罹患後症状）

  • 罹患後症状の定義は統一されていない。概ね発症から 4週間以上 持続する症状を指し（NICE定義）、WHOは感染後3ヶ月以内に発症し少なくとも2ヶ月持続する症状と定義している
  • 主な症状: 倦怠感、ブレインフォグ（認知機能障害）、息切れ、動悸、脱毛、嗅覚・味覚障害、抑うつ・不安
  • リスク因子: 女性、肥満、重症例、ワクチン未接種
  • 治療: 確立された特異的治療法はなく、各症状に対する対症療法とリハビリテーションが中心
  • 罹患後症状は外来診療加算の対象（診療報酬上）

5類移行後の対応（2023年5月8日〜）

  • 届出不要（全数把握 → 定点把握へ移行）
  • 外出自粛は法的義務なし（発症後5日間・解熱後24時間は外出を控えることを推奨）
  • 医療費は通常の保険診療（1〜3割負担）
  • 入院勧告・就業制限なし
