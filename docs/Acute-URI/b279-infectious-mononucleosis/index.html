[B27.9] 伝染性単核球症 / Infectious Mononucleosis

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 発熱 / 咽頭痛 / 咳嗽 / 鼻汁 / 喀痰 / 頭痛 / 倦怠感 / 関節痛 / 悪寒 / 呼吸困難

呼吸器系

咳嗽: 乾性 / 湿性 / 犬吠様, 喀痰: 粘液性 / 膿性 / 血痰 / なし 呼吸困難: なし / あり: 安静時・労作時, 喘鳴: なし / あり

耳鼻・その他

鼻汁: 水様 / 膿性, 咽頭痛: 嚥下痛 / 自発痛

背景

発症時期: ＿ 周囲の感染状況: 家族 / 職場 / 学校 に インフル / コロナ / 感冒 あり ワクチン接種歴: インフル 済 / 未, コロナ 済 / 未

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃, SpO2: ＿% (Room Air)

頭頸部

咽頭: 発赤 / 扁桃肥大 / 膿栓・白苔 / 口蓋垂偏位 頸部リンパ節: 腫脹なし / あり: 圧痛

胸部

呼吸音: 清明 / 喘鳴 / Crackles / Rhonchi / 減弱 心音: 整 / 雑音なし

皮膚

発疹: 有 / 無

迅速検査

インフルエンザ抗原検査 A陽性 / B陽性 / 陰性 新型コロナウイルス抗原検査 陽性 / 陰性 A群ベータ溶連菌抗原検査 陽性 / 陰性 アデノウイルス抗原検査 陽性 / 陰性

画像 (必要時)

胸部単純X線検査 所見: 異常なし / 浸潤影 / 気管支壁肥厚 AI解析結果: 異常なし / 異常所見あり: ＿

診察前対応

⚠ 注意: 流涎・含み声・吸気性喘鳴など喉頭蓋炎を疑う場合、舌圧子での咽頭観察は厳禁（喉頭痙攣→完全気道閉塞の危険）。無理な観察をせず直ちに医師へ報告。

迅速検査

[Lab-Gen-Influenza] インフルエンザ抗原精密測定[Lab-Gen-COVID] 新型コロナウイルス抗原精密測定[Lab-Gen-Strep] A群ベータ溶連菌抗原定性[Lab-Ped-Adeno] アデノウイルス抗原精密測定

画像 (必要時)

[Img-Gen-ChestXP] 胸部単純X線撮影

💡 Dr.Advice

[RedFlag] 喉頭蓋炎の兆候（流涎、含み声、呼吸困難、吸気性喘鳴）がある場合は直ちに高次医療機関へ搬送せよ。

[鑑別] Centor Criteria（発熱・咳なし・前頸部リンパ節圧痛・扁桃白苔）を確認し、細菌性（溶連菌）の可能性を見極めよ。

[設備制約] 当院にはCTおよびファイバースコープがないため、喉頭蓋炎や深頸部膿瘍が疑われる場合は、身体所見のみでトリアージし、早期に専門医へ紹介せよ。

評価

  • 診断根拠: 発熱、咽頭痛、頸部リンパ節腫脹、肝脾腫。
  • 検査: 異型リンパ球、肝酵素上昇は外注結果待ちとなる。

方針・処方

  • 対症療法のみ。安静が必要。

処方・アクション​

対症療法

[Rx-Gen-Pain-Ace] アセトアミノフェン単剤(定期)
  • アセトアミノフェン錠500mg 1回1錠 1日3回 毎食後 7日分 [Rx-Gen-GI-Muc] レバミピド
  • レバミピド錠100mg 1回1錠 1日3回 毎食後 7日分

💡 Dr.Advice

[処方注意] アミノペニシリン系抗菌薬（ABPC/AMPC等）の投与は高率に薬疹を誘発する（添付文書上、ABPCは禁忌、AMPCは慎重投与）。いずれも投与を避けること。EBV否定できない溶連菌疑いにはセファレキシンを代替選択する。

[生活指導] 脾腫による脾破裂リスクあり。発症から最低4週間は接触性スポーツを禁止する（脾腫が確認された場合はエコーで縮小確認まで延長）。

📖 詳細解説​

病態生理​

原因ウイルスと感染経路

伝染性単核球症（IM）の約90%以上はEpstein-Barrウイルス（EBV; HHV-4）が原因である。残りの約5-7%はサイトメガロウイルス（CMV）、その他まれにHIV急性感染、HHV-6、トキソプラズマなどが原因となる。

EBVは主に唾液を介して伝播し（"kissing disease"）、潜伏期間は30-50日（小児ではより短い）である。

免疫学的機序

  1. EBVは咽頭上皮細胞で初期増殖した後、**B細胞表面のCD21（CR2）**に結合して感染する
  2. 感染B細胞は不死化（immortalization）し、多クローン性に活性化・増殖する
  3. これに対し、宿主の**CD8陽性細胞傷害性T細胞（CTL）**が強力に反応し、感染B細胞を排除する
  4. 末梢血で認められる異型リンパ球（atypical lymphocyte）は、このEBV特異的な反応性CD8+ T細胞であり、EBV感染B細胞そのものではない
  5. 異型リンパ球はリンパ球の10%以上を占め、大型で細胞質が豊富、核は偏在し、形態的に多様である

この強力な細胞性免疫反応が、発熱・リンパ節腫脹・脾腫・肝機能障害といった臨床症状の主因となる。EBVは排除後もB細胞にメモリーB細胞として潜伏感染し、生涯持続する。

脾腫と脾破裂リスク

脾腫はIM患者の約50-60%に認められる（触診では約15-25%だが、超音波検査では約50-60%）。脾破裂は発症後2-3週目に最も多く、頻度は約0.1-0.5%とまれだが致死的となりうる。接触性スポーツ（コンタクトスポーツ）は最低3-4週間、超音波で脾サイズ正常化を確認するまで禁止する。一般的には発症後4週間以上の運動制限が推奨される（UpToDate, 米国小児科学会）。

診断基準・鑑別疾患​

Hoagland基準（臨床診断基準）

以下の3項目すべてを満たすとき、臨床的にIMと診断する：

項目内容
1リンパ球50%以上（かつ異型リンパ球10%以上）
2発熱、咽頭炎、リンパ節腫脹のうち少なくとも1つ
3異好抗体（heterophile antibody）陽性

異好抗体検査（Paul-Bunnell反応）

  • EBV感染B細胞から産生される多クローン性IgM抗体が、ヒツジ・ウマ赤血球を凝集する性質を利用した検査
  • 迅速検査キット（Monospot test）として普及している
  • 感度は成人で約85%、小児（4歳未満）では約25-50%と低い
  • 通常、発症1週目以降に陽性化し、数ヶ月持続する
  • 偽陰性：発症早期（1週以内）、小児、高齢者
  • 偽陽性：HIV、SLE、リンパ腫、風疹など

EBV特異抗体パネルの解釈

抗体急性感染既感染（回復期）既感染（潜伏）感染なし
VCA-IgM陽性陰性陰性陰性
VCA-IgG陽性陽性陽性陰性
EA-D (Early Antigen)陽性（約70-80%）陰性-陽性通常陰性陰性
EBNA-IgG陰性陽性陽性陰性
  • VCA-IgM陽性 + EBNA-IgG陰性 = 急性EBV感染を強く示唆
  • EBNA抗体は感染後6-12週で出現するため、急性期には陰性である点が鑑別の鍵
  • VCA-IgG + EBNA-IgG両方陽性で VCA-IgM陰性なら、既感染（過去の感染）を意味する

臨床検査所見

  • 白血球増多（10,000-20,000/μL）、リンパ球優位
  • 異型リンパ球10%以上（診断的価値が高い）
  • 肝酵素上昇（AST/ALT）：約80-90%に認められる（通常、正常上限の2-3倍程度）
  • 血小板減少（軽度）：約25-50%

鑑別疾患

  • CMV単核球症：異好抗体陰性のIM（heterophile-negative IM）の最多原因。咽頭炎・頸部リンパ節腫脹がEBVより軽度で、肝機能障害が目立つことがある。CMV-IgMまたはCMV-PCRで確認
  • HIV急性感染：発熱、リンパ節腫脹、咽頭炎、皮疹を呈し、IM様症候群と呼ばれる。リスク行動歴があれば必ずHIV RNA PCRまたはp24抗原を確認
  • 溶連菌性咽頭炎：扁桃白苔・咽頭発赤が類似。迅速抗原検査で鑑別
  • 成人Still病：弛張熱、サーモンピンク疹、関節痛、フェリチン著増
  • 悪性リンパ腫：持続するリンパ節腫脹では生検を考慮

アモキシシリン（AMPC）による薬疹

  • IM患者にAMPCを投与すると、約30〜100%（古典的報告では70-100%とされたが、近年の前向き研究では30-40%との報告もある）に斑状丘疹状の全身性薬疹が出現する（Pullen H, Lancet 1967）
  • 機序：EBV感染に伴う免疫系の一過性異常活性化（多クローン性B細胞活性化によるIgM抗体の異常産生やT細胞反応の変調）が、薬剤に対する遅延型過敏反応を惹起すると考えられている
  • この薬疹はペニシリンに対する真のアレルギーを意味しない。IM回復後にペニシリン系を再投与しても薬疹が出ないことが多い
  • IMが疑われる咽頭炎にはAMPC/ペニシリン系の処方を避けることが原則

臨床上の実践的注意点

  • 溶連菌迅速検査陽性であっても、扁桃腫大・頸部リンパ節腫脹が著明な場合はEBVとの合併・混在を常に考慮する
  • EBVを否定できない溶連菌疑い例には、AMPCではなくセファレキシンを代替選択する（セフェム系ではEBV関連薬疹の頻度がペニシリン系と比較して明らかに低いが、完全にはリスクを否定できないため経過観察は行う）
  • EBV+AMPC皮疹は癒合する汎発性紅斑を呈し、麻疹に酷似することがある。渡航歴・ワクチン歴とともにお薬手帳でのAMPC処方歴確認が鑑別の鍵となる。麻疹を否定できない場合は感染症法に基づく届出義務がある（五類・全数・直ちに届出）
  • 真のペニシリンアレルギーではIgE上昇・好酸球増多を認めることがあるが、EBV関連薬疹（T細胞介在性）では通常認めない。ただし鑑別精度は限定的であり、抗EBV抗体検査（VCA-IgM/VCA-IgG/EBNA-IgG、必要に応じてEA-IgG）を優先すべきである
  • 鑑別: CMV感染（異好抗体陰性IM）、HHV-6感染、HIV急性感染、成人Still病も同様の臨床像を呈しうる

エビデンス・ガイドライン推奨​

治療方針：特異的抗ウイルス治療なし（支持療法が基本）

  • アシクロビルはEBVの口腔内排出を一時的に減少させるが、臨床症状の改善には寄与しない（Torre D, J Med Virol 1999; RCTメタアナリシス）
  • ステロイド：気道閉塞を伴う重度の扁桃肥大、自己免疫性溶血性貧血、血小板減少性紫斑病など重篤な合併症がある場合にのみ使用を考慮。ルーチン使用は推奨されない
  • 支持療法として十分な水分摂取、安静、解熱鎮痛薬（アセトアミノフェン推奨、NSAIDsも可だが血小板減少に注意）

運動制限のエビデンス

  • 脾破裂の大部分は発症後3週間以内に発生する
  • 2014年の米国スポーツ医学会（AMSSM）のポジションステートメントでは、IMと診断された場合は最低3週間の運動制限を推奨し、復帰前に脾腫の改善を確認することを勧めている
  • 超音波検査による脾サイズの経時的評価が理想的だが、必須ではない

予後

  • 大多数は2-4週間で自然回復する。倦怠感は数ヶ月持続することがある
  • まれな重篤合併症：脾破裂、気道閉塞、脳炎・髄膜炎、ギラン・バレー症候群、自己免疫性溶血性貧血、血球貪食症候群（HLH）
  • EBVは潜伏感染としてB細胞に生涯残存し、バーキットリンパ腫、上咽頭癌、ホジキンリンパ腫、移植後リンパ増殖性疾患（PTLD）などの悪性腫瘍との関連が知られる
