[J36] 扁桃周囲膿瘍 / Peritonsillar Abscess

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 発熱 / 咽頭痛 / 咳嗽 / 鼻汁 / 喀痰 / 頭痛 / 倦怠感 / 関節痛 / 悪寒 / 呼吸困難

呼吸器系

咳嗽: 乾性 / 湿性 / 犬吠様, 喀痰: 粘液性 / 膿性 / 血痰 / なし 呼吸困難: なし / あり: 安静時・労作時, 喘鳴: なし / あり

耳鼻・その他

鼻汁: 水様 / 膿性, 咽頭痛: 嚥下痛 / 自発痛

背景

発症時期: ＿ 周囲の感染状況: 家族 / 職場 / 学校 に インフル / コロナ / 感冒 あり ワクチン接種歴: インフル 済 / 未, コロナ 済 / 未

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃, SpO2: ＿% (Room Air)

頭頸部

咽頭: 発赤 / 扁桃肥大 / 膿栓・白苔 / 口蓋垂偏位 頸部リンパ節: 腫脹なし / あり: 圧痛

胸部

呼吸音: 清明 / 喘鳴 / Crackles / Rhonchi / 減弱 心音: 整 / 雑音なし

皮膚

発疹: 有 / 無

迅速検査

インフルエンザ抗原検査 A陽性 / B陽性 / 陰性 新型コロナウイルス抗原検査 陽性 / 陰性 A群ベータ溶連菌抗原検査 陽性 / 陰性 アデノウイルス抗原検査 陽性 / 陰性

画像 (必要時)

胸部単純X線検査 所見: 異常なし / 浸潤影 / 気管支壁肥厚 AI解析結果: 異常なし / 異常所見あり: ＿

診察前対応

⚠ 注意: 流涎・含み声・吸気性喘鳴など喉頭蓋炎を疑う場合、舌圧子での咽頭観察は厳禁（喉頭痙攣→完全気道閉塞の危険）。無理な観察をせず直ちに医師へ報告。

迅速検査

[Lab-Gen-Influenza] インフルエンザ抗原精密測定[Lab-Gen-COVID] 新型コロナウイルス抗原精密測定[Lab-Gen-Strep] A群ベータ溶連菌抗原定性[Lab-Ped-Adeno] アデノウイルス抗原精密測定

画像 (必要時)

[Img-Gen-ChestXP] 胸部単純X線撮影

💡 Dr.Advice

[RedFlag] 喉頭蓋炎の兆候（流涎、含み声、呼吸困難、吸気性喘鳴）がある場合は直ちに高次医療機関へ搬送せよ。

[鑑別] Centor Criteria（発熱・咳なし・前頸部リンパ節圧痛・扁桃白苔）を確認し、細菌性（溶連菌）の可能性を見極めよ。

[設備制約] 当院にはCTおよびファイバースコープがないため、喉頭蓋炎や深頸部膿瘍が疑われる場合は、身体所見のみでトリアージし、早期に専門医へ紹介せよ。

評価

  • 診断根拠: 激しい咽頭痛（片側性）、開口障害、口蓋垂の健側偏位、含み声。

方針・処方

  • 原則として耳鼻咽喉科へ即時紹介。

処方・アクション​

疼痛時

[Rx-Gen-Pain-Lox-T-Set] ロキソニン・レバミピドセット(頓用)
  • ロキソニン錠60mg 1回1錠 (疼痛時) 10回分
  • レバミピド錠100mg 1回1錠 (疼痛時) 10回分

紹介

[Doc-Gen-Referral] 診療情報提供書
  • 紹介先: 耳鼻咽喉科

💡 Dr.Advice

[処置] 当院での穿刺は行わず、速やかに専門医へ送ること。

📖 詳細解説​

病態生理​

扁桃周囲膿瘍（peritonsillar abscess; PTA）は、急性扁桃炎の最も多い合併症であり、深頸部感染症の中で最も頻度が高い。好発年齢は20〜40歳代で、小児では稀である。

進展機序

  1. 急性扁桃炎（主にウイルス性 → 細菌性二次感染）が口蓋扁桃の被膜外に波及
  2. 扁桃上極の Weber 腺（小唾液腺）領域に感染が波及し、扁桃被膜と上咽頭収縮筋の間の疎性結合組織（扁桃周囲間隙）に膿瘍を形成
  3. 膿瘍は多くの場合、扁桃上極（supratonsillar fossa）に好発する

起因菌

  • 好気性菌と嫌気性菌の混合感染が典型的である
  • 好気性菌: A群溶血性レンサ球菌（GAS; Streptococcus pyogenes）が最多。その他、S. anginosus group（S. milleri group）、黄色ブドウ球菌
  • 嫌気性菌: Fusobacterium necrophorum、Prevotella spp.、Peptostreptococcus spp.
  • F. necrophorum は若年成人の扁桃炎・PTAで重要な起因菌であり、内頸静脈の敗血症性血栓性静脈炎（Lemierre症候群）の原因菌として特に注意を要する

合併症への進展リスク

扁桃周囲間隙 → 傍咽頭間隙（parapharyngeal space） → 後咽頭間隙（retropharyngeal space）→ 縦隔への進展により、深頸部膿瘍・降下性壊死性縦隔炎へ至りうる。致死率は高く、早期診断・治療介入が必須である。

診断基準・鑑別疾患​

臨床診断（身体所見による）

PTAの診断は基本的に臨床診断であり、以下の三徴が特徴的である:

所見詳細
Trismus（開口障害）内側翼突筋の炎症性攣縮による。指2横指以下の開口制限
口蓋垂の健側偏位患側の軟口蓋・前口蓋弓の膨隆に伴い口蓋垂が対側へ偏位
Hot potato voice（含み声）口腔内容積の変化による共鳴異常

その他の臨床所見

  • 高熱（38℃以上）、激しい片側性咽頭痛、嚥下困難（odynophagia）
  • 患側頸部リンパ節腫脹・圧痛
  • 流涎（嚥下困難による）
  • 患側への頸部傾斜（torticollis）

CT撮影の適応

造影CT（頸部〜上縦隔）は以下の場合に施行する:

  • 身体所見のみでは膿瘍と蜂窩織炎の鑑別が困難な場合
  • 深頸部膿瘍（傍咽頭間隙・後咽頭間隙膿瘍）への進展が疑われる場合
  • 穿刺排膿で膿汁が得られない場合
  • 気道狭窄の評価が必要な場合
  • CT所見: 扁桃周囲のリング状造影効果（rim enhancement）を伴う低吸収域

鑑別疾患

疾患鑑別ポイント
扁桃周囲蜂窩織炎膿瘍形成前の段階。抗菌薬のみで改善しうる。CTで被包化した膿瘍腔なし
深頸部膿瘍（傍咽頭間隙膿瘍）頸部腫脹が高度、全身状態不良。CTで扁桃外側〜傍咽頭間隙に膿瘍形成。外切開ドレナージの適応
後咽頭間隙膿瘍小児に多い。頸部の伸展制限、側面X線で後咽頭軟部組織腫脹
Lemierre症候群F. necrophorum による内頸静脈の敗血症性血栓性静脈炎。扁桃炎に続き、高熱の遷延・敗血症症状・多発性敗血症性肺塞栓を呈する。造影CTで内頸静脈内血栓を確認。致死率は適切な治療下で約5%前後（診断・治療遅延で上昇）
急性喉頭蓋炎吸気性喘鳴、流涎、sniffing position。喉頭ファイバーで確認
伝染性単核球症両側扁桃腫大・白苔、頸部リンパ節腫脹、肝脾腫。異型リンパ球増多。AMPCで薬疹誘発

エビデンス・ガイドライン推奨​

1. 抗菌薬治療

GAS＋嫌気性菌の混合感染をカバーする広域抗菌薬を選択する。

レジメン用法・用量備考
ABPC/SBT（ユナシン-S）3g q6-8h 点滴静注第一選択。GAS・嫌気性菌をカバー。日本の臨床現場で最も汎用
CTRX + MNZCTRX 2g q24h + MNZ 500mg q8h 点滴静注ABPC/SBTアレルギー時の代替
CLDM（クリンダマイシン）600mg q8h 点滴静注ペニシリンアレルギー時。嫌気性菌カバー良好
  • 内服step-down: オーグメンチン配合錠250RS 1回1錠 + アモキシシリン錠250mg 1回1錠 1日3回（いわゆるオグサワ処方）、計10〜14日間
  • 抗菌薬単独で排膿処置を行わない場合の治癒率は低く（約50%）、排膿処置との併用が原則である

2. 排膿処置の選択

手技適応・エビデンス
穿刺吸引排膿（needle aspiration）初回治療として推奨。局所麻酔下に18G針で患側扁桃上極を穿刺。成功率は90%前後。Cochrane Review（2017）では穿刺吸引と切開排膿の間に治癒率の有意差なし。穿刺は低侵襲で外来施行可能
切開排膿（incision and drainage）穿刺吸引で改善しない場合、または膿瘍が大きい場合に施行。扁桃上極の前口蓋弓付近を1〜2cm切開しペアン鉗子で膿瘍腔を開放
即時扁桃摘出術（quinsy tonsillectomy）高度な気道閉塞、排膿不成功例、反復例。根治的だが全身麻酔が必要。出血リスクがやや高いが、再発率は最も低い

3. Interval tonsillectomy（待機的扁桃摘出術）の適応

  • PTA既往が2回以上の再発例、または扁桃炎の反復既往（Paradise criteria該当）がある場合に推奨
  • 初回PTAに対するroutineのinterval tonsillectomyは推奨されない（再発率は約10〜15%にとどまる）
  • Burton MJ, et al. Cochrane Database Syst Rev (2014): 初回PTA後のroutine tonsillectomyを支持するエビデンスは不十分
  • 施行時期は急性炎症消退後4〜6週間が一般的

4. 入院適応

  • 経口摂取不能（脱水リスク）
  • 気道狭窄の懸念
  • 深頸部膿瘍への進展が疑われる場合
  • 敗血症徴候（qSOFA 2点以上）
  • 排膿処置後の経過観察が必要な場合

5. Lemierre症候群が疑われる場合の追加対応

  • 造影CTで内頸静脈血栓の評価
  • 血液培養（嫌気性菌培養を含む）を必ず採取
  • 抗菌薬: MNZ追加またはカルバペネム系への変更を考慮
  • 抗凝固療法の適応は議論があり、症例ごとに判断（現時点でRCTなし）
