[M35.3] リウマチ性多発筋痛症 / Polymyalgia Rheumatica / PMR

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 関節痛 / 関節の腫れ / 朝のこわばり / 発熱 / 倦怠感

筋・骨格系

部位: 手指 / 手首 / 肘 / 肩 / 膝 / 足趾 / 全身 左右差: 対称性 / 非対称性 / 移動性 朝のこわばり: なし / あり: ＿分間 ；30分以上は有意 疼痛性状: 安静時痛 / 運動時痛 / 温めると軽快

全身・皮膚

発熱: なし / 微熱 / 高熱, 倦怠感: なし / あり, 体重減少: なし / あり レイノー現象: なし / あり, 皮疹: なし / 紅斑 / 紫斑 粘膜症状: なし / 口内炎 / ドライアイ / ドライマウス

背景

家族歴: 関節リウマチ / 膠原病 / なし

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

関節所見

腫脹: なし / あり, 圧痛: なし / あり, 熱感: なし / あり 罹患関節数: 小関節 ＿ 箇所, 大関節 ＿ 箇所

皮膚・その他

蝶形紅斑: なし / あり, ゴットロン徴候: なし / あり 爪郭部出血点: なし / あり, リンパ節腫脹: なし / あり

スクリーニング検査 (外注)

リウマチ・膠原病スクリーニング

  • RF, 抗CCP抗体, MMP-3, 抗核抗体(ANA), CRP, ESR

診察前対応

スクリーニング検査 (外注)

[Lab-Rheum-Screen] リウマチ・膠原病スクリーニング

💡 Dr.Advice

[炎症性 vs 機械性] 炎症性(RA等)は安静時も痛い、朝のこわばりが長い(>30分)、動かすと少し楽になる。機械性(変形性関節症)は動かすと痛い、安静で治まる、こわばりは短い(<15分)。この区別が鑑別の第一歩である。

[設備制約] 当院には関節エコーがないため、滑膜炎の早期検出（グレースケール・パワードプラ）ができない。「腫れているか微妙」な場合や、RF/CCP陰性だが痛みが続く場合は、見逃しを防ぐためにエコー可能な専門医へ紹介するのが安全である。

評価

  • 診断根拠: 50歳以上、急激な発症。両側の肩甲帯・骨盤帯（頸、肩、腰、大腿）の疼痛・こわばり。CRP/ESRの著明上昇。
  • 鑑別・除外: RA(小関節炎なし)、多発性筋炎(筋力低下・CK上昇なし)、悪性腫瘍。
  • リスク因子: 巨細胞性動脈炎(GCA)の合併（側頭部痛・視力障害）。

方針・処方

  • 治療戦略: ステロイド(PSL 15mg/日)による診断的治療。反応良好なら2-4週ごとに慎重に漸減。

処方・処置​

PMR治療セット(導入)

[Rx-Gen-Steroid-PSL-15x7] プレドニン15mg(3錠)
  • プレドニン錠5mg 1回3錠 1日1回 朝食後 7日分 — 14日分処方 [Rx-Gen-GI-Tak-10] タケキャブ10mg(維持)
  • タケキャブ錠10mg 1回1錠 1日1回 朝食後 28日分 — 潰瘍予防 [Rx-Ost-Bis-Ale] アレンドロン酸
  • アレンドロン酸錠35mg 1回1錠 週1回 起床時 4週分 — 骨粗鬆症予防

指導・計画​

  • 患者指導: 側頭部痛や視野異常が出現した場合は、失明のリスクがあるため直ちに受診するよう指示。
  • 再診目安: 2週間後。

💡 Dr.Advice

[15mgの魔法] PMRであれば、PSL 15mg投与翌日～数日で「嘘のように痛みが消える」。もし1週間飲んでも効果不十分なら、PMRではなく「高齢発症RA」や「悪性腫瘍」を疑い、診断をやり直せ。

[GCA合併] 頭痛や視覚異常（巨細胞性動脈炎）を伴う場合は、PSL 15mgでは足りず失明の危険がある。直ちに大量ステロイド（40-60mg）が必要なため、当院で手を出さず即日総合病院へ送れ。

病態生理​

  • **PMR（リウマチ性多発筋痛症）**は50歳以上に発症する近位筋の疼痛・こわばりを特徴とする炎症性疾患。平均発症年齢70歳代
  • 滑液包炎・腱鞘炎が本態。筋自体の炎症ではない。巨細胞性動脈炎（GCA）の約15-20%に合併

診断基準・鑑別疾患​

  • 2012 ACR/EULAR暫定分類基準: 50歳以上+両肩の疼痛+CRP/ESR上昇+以下のスコア化項目（朝のこわばり45分以上、股関節痛、RF/抗CCP抗体陰性、エコーで肩/股関節の滑液包炎）
  • 鑑別（重要）: 関節リウマチ（小関節、抗CCP陽性）、筋炎（CK上昇）、感染症、悪性腫瘍、甲状腺機能低下症
  • GCA合併の評価: 側頭部痛、顎跛行、視力障害があればGCAを疑い速やかにステロイド増量+側頭動脈生検

エビデンス・ガイドライン推奨​

  • プレドニゾロン: 12.5-25mg/日で開始。劇的に改善（24-72時間以内）が特徴的。改善なければ診断を再考
  • 漸減: 4-6週ごとに1-2.5mgずつ慎重に減量。再燃が多い（約50%）
  • 治療期間: 通常1-2年。長期ステロイド副作用（骨粗鬆症、糖尿病、感染）への対策が必須
  • ステロイド減量困難例: メトトレキサート7.5-10mg/週の併用。トシリズマブもGCA合併例で有効
  • 骨粗鬆症予防: ステロイド使用全例でビスホスホネート+ビタミンD+カルシウム
