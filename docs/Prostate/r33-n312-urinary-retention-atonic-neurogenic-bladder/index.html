[R33/N31.2] 尿閉・弛緩性神経因性膀胱 / Urinary Retention / Atonic Neurogenic Bladder

📋 主訴・所見・診察前対応

主訴・ROS

排尿症状 (IPSS/OABSS)

頻尿: なし / 昼間 ＿回 / 夜間 ＿回, 尿勢: 良好 / 低下 / 途切れる / 腹圧排尿 切迫感: なし / あり: 我慢できない / 漏れる, 残尿感: なし / あり

疼痛・不快感

部位: 会陰部 / 睾丸 / 下腹部 / 鼠径部 / 射精時, 排尿時痛: なし / あり

男性機能・全身

勃起不全: なし / あり, 性欲: あり / 低下 全身症状: 意欲低下 / 不眠 / イライラ / ほてり

既往・背景

既往歴: 糖尿病 / 脳卒中 / 脊椎疾患 / 尿路結石 / なし 内服薬: 抗コリン薬 / 睡眠薬 / 抗血小板薬 / なし

所見・検査

腹部: 膀胱充満 なし / あり

直腸診 (DRE)

前立腺: 正常大 / 腫大: 鶏卵大 / 鵞卵大 / テニスボール大 硬度: 弾性軟 / 弾性硬 / 石様硬, 圧痛: なし / あり, 表面: 平滑 / 結節あり, 正中溝: 触知可 / 消失

検査

尿検査・尿沈渣

  • 定性: 蛋白(＿) 糖(＿) 潜血(＿) 白血球(＿)
  • 沈渣: RBC(＿) WBC(＿) ；感染・血尿除外 腫瘍マーカーセット(PSA含む)
  • PSA: ＿ ng/mL (外注) スコア評価: IPSS ＿点 (QOL ＿点), OABSS ＿点

診察前対応

検査

[Lab-Gen-Urine] 尿定性・尿沈渣[Lab-Hep-Tumor] 腫瘍マーカーセット(PSA含む)

💡 Dr.Advice

[設備制約] 当院にはエコーがないため、正確な前立腺体積や残尿量の測定はできない。DRE（デジタル直腸診）による推定と、問診（IPSS）による重症度判定で治療方針を決定する。

[PSA解釈] 4.0ng/mL以上は専門医紹介の目安だが、前立腺肥大症や前立腺炎、射精直後でも上昇する。「癌のマーカーですが、良性の病気でも上がります」と事前に説明し、不安を煽りすぎないよう配慮せよ。

[残尿リスク] 頻尿を訴える高齢男性に、安易に抗コリン薬（頻尿止め）を出すと、隠れていた残尿が増加し「尿閉」に至ることがある。エコーで残尿確認ができない当院では、男性への抗コリン薬投与は原則として泌尿器科紹介後、あるいは慎重に行うべきである。

評価

  • 診断根拠: 尿閉（急性 vs 慢性）。残尿100mL以上。超音波で膀胱容量・残尿を測定。
  • 重症度: 急性尿閉は緊急対応。慢性は腎後性腎不全（水腎症）の有無を確認。
  • 鑑別: BPH（前立腺肥大症）、神経因性膀胱（糖尿病性自律神経障害、脊髄疾患）、薬剤性（抗コリン薬、抗ヒスタミン薬、三環系抗うつ薬）。

方針・処方

  • 急性尿閉→バルーンカテーテル留置（12-14Fr）で導尿。原因検索後に抜去試験。
  • 慢性尿閉→清潔間欠自己導尿（CIC）4-6回/日の導入を検討。
  • 薬物療法: 排尿筋収縮促進にウブレチド5mg 1日1回。効果不十分な場合は泌尿器科コンサルト。
  • BPH関連尿閉: α1遮断薬（タムスロシン0.2mg 1日1回）をバルーン抜去3-7日前から開始。
  • BPH確定時にはウブレチドは禁忌（残尿増悪のリスク）。

処方・アクション​

排尿促進セット

[Rx-Uro-Ub] ウブレチド
  • ウブレチド錠5mg 1回1錠 1日1回 朝食後 28日分 — 低活動膀胱・神経因性膀胱

※禁忌: 消化管・尿路の器質的閉塞、迷走神経緊張症。5mg/日を超えない。投与開始後2週間は特に注意。 ※5mg 1日1回で効果不十分な場合は泌尿器科コンサルト（自己判断での増量不可） [Rx-Uro-Tam] タムスロシン（BPH関連尿閉用）

  • タムスロシン錠0.2mg 1回1錠 1日1回 朝食後 28日分 — 前立腺肥大症に伴う排尿障害

※高齢者は起立性低血圧・転倒リスクに注意

処置・アクション​

導尿

  • 急性尿閉: バルーンカテーテル挿入（12-14Fr）
  • 慢性: 清潔間欠自己導尿（CIC）指導 4-6回/日

指導・計画​

  • 再診目安: バルーン留置後1-2週で抜去試験。CIC導入後は残尿量を評価し回数調整。
  • 排尿日誌（最低3日間）の記載を依頼。

💡 Dr.Advice

[コリン作動性クリーゼ（厚労省警告）] 縮瞳・徐脈・発汗・流涎・腹痛・下痢が出現したら直ちに中止。アトロピン0.5-1mg静注で拮抗（厚労省安全性速報2011年）。

[鑑別のポイント] BPHによる急性尿閉と神経因性膀胱の鑑別が重要。糖尿病歴・脊髄疾患歴・薬剤歴を必ず確認。直腸診で前立腺サイズも評価。

[CIC導入] 清潔間欠自己導尿（CIC）の導入は泌尿器科と連携して行う。患者の手指巧緻性・認知機能を事前に評価すること。

📖 詳細解説​

尿閉は膀胱内に貯留した尿を排出できない状態であり、急性尿閉と慢性尿閉に大別される。原因は閉塞性（BPH、尿道狭窄）、機能性（神経因性膀胱、薬剤性）、またはその混合型に分類される。神経因性膀胱は排尿に関わる神経系の障害による膀胱機能異常の総称であり、蓄尿障害型と排出障害型（低活動膀胱/弛緩性膀胱）がある。

病態生理​

正常排尿のメカニズム

  • 蓄尿期: 膀胱排尿筋が弛緩（交感神経 β3受容体）、内尿道括約筋が収縮（交感神経 α1受容体）
  • 排尿期: 排尿筋が収縮（副交感神経 M3受容体）、尿道括約筋が弛緩
  • 排尿中枢: 橋排尿中枢（Barrington核）が排尿筋収縮と括約筋弛緩を協調的に制御

急性尿閉

  • 突然の排尿不能、下腹部膨満・激痛を伴う
  • 主な原因: BPH（最多、男性高齢者）、薬剤性、便秘・糞便塊による圧迫、術後（麻酔による一過性排尿障害）
  • 緊急対応が必要（膀胱破裂のリスクは極めて稀だが、腎後性腎不全のリスクあり）

慢性尿閉（慢性尿貯留）

  • 徐々に残尿が増加、自覚症状に乏しいことがある
  • 膀胱が過伸展し排尿筋のコンプライアンスが低下
  • 溢流性尿失禁（overflow incontinence）として発見されることがある
  • 放置すると水腎症・腎後性腎不全に至る

神経因性膀胱の分類

障害レベル病態代表疾患
大脳（核上型）排尿筋過活動脳卒中、パーキンソン病、認知症
脊髄（核上型）排尿筋括約筋協調不全（DSD）脊髄損傷、多発性硬化症
末梢神経（核・核下型）低活動膀胱（排尿筋低収縮）糖尿病性自律神経障害、腰部脊柱管狭窄症、骨盤内手術後

薬剤性尿閉の主な原因薬

  • 抗コリン薬（オキシブチニン、プロピベリン等の過活動膀胱治療薬）
  • 抗ヒスタミン薬（第一世代: 抗コリン作用）
  • 三環系抗うつ薬（アミトリプチリン等）
  • α1刺激薬（含有される総合感冒薬）
  • オピオイド鎮痛薬
  • 抗パーキンソン病薬（トリヘキシフェニジル等）

診断基準・鑑別疾患​

残尿測定

  • 残尿100mL以上で臨床的に有意と判定
  • 残尿50-100mL: グレーゾーン、経過観察
  • 残尿200mL以上: 治療介入を積極的に検討
  • 残尿500mL以上: 高度尿貯留、導尿が必要
  • 測定法: 超音波検査（非侵襲的、第一選択）、導尿による直接測定

急性尿閉の診断

  • 8時間以上排尿がない + 下腹部膨満 + 膀胱部の打診で濁音
  • 超音波で膀胱内に300mL以上の尿貯留を確認
  • 導尿で400mL以上排出された場合は急性尿閉と確定

鑑別のための評価

評価項目目的
直腸診（DRE）前立腺サイズ・硬度（BPHvs前立腺癌）
薬剤歴薬剤性尿閉の除外
神経学的診察会陰部知覚、肛門括約筋トーヌス、球海綿体反射
糖尿病歴糖尿病性自律神経障害
脊椎疾患歴馬尾症候群、脊柱管狭窄症
PSA前立腺癌のスクリーニング
腎機能（Cr、BUN）腎後性腎不全の評価
超音波検査水腎症の有無、膀胱壁肥厚（慢性閉塞の指標）

エビデンス・ガイドライン推奨​

急性尿閉の管理（日本泌尿器科学会ガイドライン準拠）

  • 即座にバルーンカテーテル留置（12-14Fr）で導尿
  • 一度に1000mL以上の排尿は避ける（急激な膀胱減圧による血尿リスク: ex vacuo hematuria）
  • 原因検索を並行して実施
  • BPH関連: α1遮断薬（タムスロシン0.2mg）をカテーテル抜去3-7日前から開始し、抜去試験（TWOC: Trial Without Catheter）を施行。TWOC成功率は約60-70%。

清潔間欠自己導尿（CIC）

  • 慢性尿閉・神経因性低活動膀胱の標準治療
  • 1日4-6回、1回導尿量は400mL以下を目標
  • 無菌操作ではなく清潔操作で施行（clean technique）
  • 尿路感染のリスクは留置カテーテルより大幅に低い
  • 導入時は患者の手指巧緻性・認知機能・視力を評価
  • 泌尿器科と連携した導入・指導が望ましい

ウブレチド（ジスチグミン）の使用

  • 適応: 低活動膀胱・神経因性膀胱（排尿筋低収縮型）
  • 用法: 5mg 1日1回（増量不可）
  • 作用機序: コリンエステラーゼ阻害薬。アセチルコリン分解を抑制し、排尿筋収縮力を増強。
  • BPHによる尿閉には禁忌: 閉塞性病変に対して排尿筋収縮を促進すると膀胱内圧上昇による合併症リスク
  • 重大な副作用: コリン作動性クリーゼ -- 縮瞳・徐脈・発汗・流涎・腹痛・下痢・呼吸困難。致死的となりうる。2011年厚労省安全性速報で注意喚起。
  • 拮抗薬: アトロピン0.5-1mg 静注
  • 投与開始後2週間は特に注意深い観察が必要
  • 禁忌: 消化管・尿路の器質的閉塞、迷走神経緊張症、脱分極性筋弛緩薬投与中

α1遮断薬

  • タムスロシン0.2mg 1日1回: 前立腺部尿道の平滑筋弛緩により排尿抵抗を軽減
  • BPHに伴う排尿障害の第一選択
  • 副作用: 起立性低血圧（特に高齢者で転倒リスク）、射精障害
