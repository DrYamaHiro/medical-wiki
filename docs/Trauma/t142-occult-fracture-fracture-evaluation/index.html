[T14.2] 不顕性骨折・骨折評価 / Occult Fracture / Fracture Evaluation

📋 主訴・所見・診察前対応

主訴・ROS

受傷機転: 転倒 / 切創[ナイフ・ガラス] / 打撲 / 咬傷 / 刺傷 受傷場所: 屋内 / 屋外[土砂・錆] / 水中 ；汚染リスク評価 受傷日時: ＿ ゴールデンタイム6-8時間以内か 破傷風ワクチン接種歴: 10年以内 / 不明・未接種 / 小児期のみ

症状

疼痛スケール(NRS): ＿/10, 出血: 止血済 / 持続中 神経症状: なし / しびれ / 感覚脱失 ；神経損傷疑い 運動障害: なし / あり ；腱断裂・骨折疑い

背景

内服薬: なし / 抗凝固薬・抗血小板薬 アレルギー: なし / 麻酔薬 / 抗菌薬 / ラテックス

所見・検査

創傷評価

部位: ＿, 長さ ＿cm 深さ: 表皮 / 真皮 / 皮下 / 筋層 / 骨露出 汚染: 軽度 / 中等度 / 高度, 異物: なし / あり 血流: 良好 / 不良, 活動性出血: なし / あり

神経・腱・血管

2点識別覚(2PD): 正常 / 異常, 自動運動: 可能 / 不可

画像

単純X線 (※部位によりオーダー変更)

  • 所見: 骨折なし / 骨折疑い / 異物陰影あり

※当院にはCT/MRI/エコーがない。

診察前対応

画像

[Img-Gen-ChestXP] 単純X線

💡 Dr.Advice

[洗浄の鉄則] 消毒薬（イソジン等）は組織毒性があり治癒を遅らせる。「大量の水道水または生食」で物理的に菌と汚れを洗い流すことが感染予防の全てである。

[縫合不可] 当院には「縫合セット（針・糸）」がない。顔面、手指、関節部、および真皮縫合が必要な深い傷は、テープ固定で寄せるか、形成外科へ紹介せよ。

[神経損傷] 指の側面の切創は、浅く見えても指神経が切れていることが多い。局所麻酔を打つ前に必ず「触覚検査」を行え。麻酔後は評価不能となる。

評価

  • 診断根拠: 受傷機転あり、限局性の圧痛・腫脹があるが、X線で骨折線が見えない。
  • 好発部位: 手舟状骨、肋骨、大腿骨頸部（嵌合骨折）、足趾。

方針・処方

  • 治療戦略: 【臨床的骨折として扱う】「折れていない」と断定せず、シーネやサポーター等で固定する。1週間後に再X線（仮骨確認）、またはMRI可能な施設へ紹介。

処方・処置​

固定・外用

  • ロキソニンパップ100mg 7枚入 2袋 1日1回 貼付

鎮痛セット

[Rx-Gen-Pain-Lox-Set-5] ロキソニン・レバミピドセット(定期)
  • ロキソニン錠60mg 1回1錠 1日3回 毎食後 5日分
  • レバミピド錠100mg 1回1錠 1日3回 毎食後 5日分

紹介

[Doc-Gen-Referral] 診療情報提供書 (整形外科へ紹介：MRI精査・ギプス固定依頼)

指導・計画​

  • 再診目安: 1週間後。

💡 Dr.Advice

[見えない骨折] ①舟状骨骨折: 解剖学的嗅ぎタバコ入れ部の圧痛。初期X線で映らないことが多く、見逃すと偽関節になる。「疑ったらMRI」が原則。 ②肋骨骨折: X線での骨折線描出率は低い。「受傷機転＋限局性圧痛」があれば、X線正常でも骨折として扱う。 ③大腿骨頸部骨折（嵌合型）: 歩行可能な場合でも骨折している。「転倒後の股関節痛・鼠径部痛」はMRIまで骨折除外不可能である。

📖 詳細解説​

不顕性骨折（occult fracture）とは、受傷機転と臨床所見（限局性圧痛・腫脹・荷重困難）から骨折が強く疑われるにもかかわらず、初回の単純X線で骨折線が描出されない状態をいう。X線の骨折検出感度は部位により大きく異なり（肋骨50%、舟状骨70%、大腿骨頸部嵌合骨折80-90%）、「X線で折れていない」は「骨折がない」を意味しない。

病態生理​

不顕性骨折が生じる機序

  • 不完全骨折: 骨皮質の片側のみに亀裂が入り、X線上の骨折線が不明瞭。小児のbuckle fracture（膨隆骨折）やgreenstick fracture（若木骨折）が典型。
  • 嵌合骨折: 骨端が互いに食い込み、外形が保たれるためX線上の転位が見えない。大腿骨頸部の嵌合骨折は歩行可能なことがある。
  • 疲労骨折（stress fracture）: 正常骨に反復する微小外力が加わり、骨のリモデリング能力を超えて骨折に至る。ランナーの中足骨、脛骨が好発部位。初期にはX線正常で、2-4週後に骨膜反応や仮骨形成として描出される。
  • 脆弱性骨折（insufficiency fracture）: 骨粗鬆症等で脆弱化した骨に日常的な外力で骨折。仙骨、恥骨、椎体に好発。

X線で見えない理由

  • 骨折線の幅が0.5mm未満の場合、通常のX線では検出困難
  • 骨折部位が他の骨と重なる（舟状骨、肋骨前面）
  • 撮影方向が骨折線に対して平行の場合、描出されない

診断基準・鑑別疾患​

部位別の臨床的Decision Rule

1. 足関節 -- Ottawa Ankle Rules（OAR）

X線撮影の適応を判断するルール。以下のいずれかを満たす場合にX線撮影を行う:

  • 内果または外果の後縁6cmの骨圧痛
  • 第5中足骨基部の圧痛
  • 舟状骨（足）の圧痛
  • 受傷直後に4歩以上歩行不能

感度98-100%（骨折をほぼ見逃さない）、特異度約40%。不要なX線撮影を30-40%削減できる。足関節捻挫の大半はX線不要である。

2. 手舟状骨骨折

  • 解剖学的嗅ぎタバコ入れ（anatomical snuffbox）の圧痛: 感度90%、特異度40%。
  • 舟状骨結節の圧痛および**軸方向圧迫痛（thumb compression test）**を併用して感度向上。
  • 初回X線の感度は約70%。臨床的に疑う場合はシーネ固定（thumb spica）して2週後に再X線、または**MRI（感度ほぼ100%）**を施行。
  • 見逃した場合、血行が乏しい近位部から無腐性壊死（AVN）や偽関節に至るリスクがある。

3. 肋骨骨折

  • X線の感度は約50%（前面・軟骨部はさらに低い）。
  • 「受傷機転+限局性の圧痛+前後圧迫痛/側方圧迫痛」があればX線正常でも肋骨骨折として扱う。
  • 合併症の除外が重要: 気胸（呼吸音左右差、SpO2低下）、血胸、肺挫傷。
  • フレイルチェスト（連続3本以上の肋骨が各2カ所で骨折）は生命に関わる。

4. 大腿骨頸部骨折（嵌合型）

  • 高齢者の転倒後の鼠径部痛。歩行可能な場合でも嵌合型骨折の可能性あり。
  • X線で骨折線が不明瞭な場合、MRIが gold standard（感度100%、特異度100%）。
  • MRIが使えない場合はCTを施行（感度93%）。

5. 疲労骨折

  • ランナー、新入隊員、ダンサー等に好発。中足骨（第2-3）、脛骨近位が好発部位。
  • 初期X線は正常。2-4週後に骨膜反応・仮骨として描出される。
  • 早期診断にはMRIが最も有用（感度98%）。骨シンチも高感度だが特異度に劣る。

2週後再X線 / MRIの適応

  • 初回X線正常だが臨床的に骨折を強く疑う場合
  • シーネ固定後も疼痛が改善しない場合
  • 舟状骨・大腿骨頸部・疲労骨折が疑われる場合はMRI優先

エビデンス・ガイドライン推奨​

  • Ottawa Ankle Rules: 1992年にStiellらが開発。複数のメタアナリシスで感度98-100%が確認されている（Bachmann LM, et al. BMJ 2003）。5歳未満の小児には適用しない。
  • 舟状骨骨折の早期MRI: 臨床的に舟状骨骨折が疑われる場合、2週間の固定後再X線よりも早期MRI施行が費用対効果に優れるとの報告がある（Defined early MRI strategy, Eur Radiol 2019）。ただし日本ではMRIアクセスの制約があり、まずシーネ固定+2週後再評価が現実的な戦略。
  • 肋骨骨折: 日本外傷学会の外傷初期診療ガイドライン（JATEC）では、肋骨骨折そのものよりも合併症（気胸、血胸、肺挫傷）の検索を優先することを推奨。3本以上の骨折や高エネルギー外傷ではCT撮影を推奨。
  • 大腿骨頸部骨折: 日本整形外科学会のガイドラインでは、X線で明確な骨折線が描出されない場合でも臨床的に骨折が疑われればMRIを施行することを推奨（推奨度A）。
  • 疲労骨折の安静期間: 低リスク部位（中足骨骨幹部、腓骨）は4-8週の活動制限で治癒。高リスク部位（第5中足骨基部Jones骨折、脛骨前面、大腿骨頸部内側）は遷延治癒・偽関節のリスクがあり専門医紹介が必要。
