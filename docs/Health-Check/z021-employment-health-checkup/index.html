[Z02.1] 雇用時健診 / Employment Health Checkup

📋 主訴・所見・診察前対応

主訴・ROS

目的: 特定健診 / 雇用時健診 / 診断書作成 / 抗体検査 / 予防接種相談 提出先: 会社 / 学校 / 保健所 / 保険会社 / 警察署[銃砲] 期限: ＿月＿日までに必要 気になる症状: 特になし / ＿ 既往歴: ＿

生活習慣

喫煙: なし / あり ＿本/日 × ＿年 飲酒: なし / ＿合/日 運動: なし / 週2回以上

所見・検査

身長: ＿cm, 体重: ＿kg, BMI: ＿, 腹囲: ＿cm 血圧: ＿/＿ mmHg, 脈拍: ＿ bpm 視力: 右 ＿ / 左 ＿ 矯正 / 裸眼 聴力(1000Hz): 右 ＿ / 左 ＿, (4000Hz): 右 ＿ / 左 ＿

診察

心音・呼吸音: 異常なし、貧血: 無 / 有

検査実施

胸部X線: 異常なし / ＿ 心電図: 正常洞調律 / ＿ 尿検査: 蛋白(＿) 糖(＿) 潜血(＿) 採血: 実施済 / 項目確認 ；結果は後日

診察前対応

（データなし）

💡 Dr.Advice

[結果渡し] 当院の血液検査は外注（SRL）であるため、診断書や健診結果の即日発行は不可能である。「結果が出るまで数日かかります」と受付段階で必ず説明し、トラブルを回避せよ。

[健診の意義] 健診は「異常を見つける」だけでなく、「自分の体を知り、生活習慣を見直すきっかけ」であることを伝え、結果説明の受診を促せ。

評価

  • 労働安全衛生規則第43条に基づく雇入時健康診断。
  • 指定用紙: 有 / 無
  • 色覚検査: 必要 / 不要 ；石原式のみ対応可

方針・処方

  • 法定必須項目（胸部X線、心電図、聴力を含む）の実施。
  • 省略不可項目（35歳・40歳以上等の年齢ルールに関わらず、雇入時は全項目必須）。
  • 結果渡し：後日来院 / 郵送

雇用時健診セット

[Tx-Check-Employ] 雇入時健康診断[Img-Gen-ChestXP] 胸部単純X線撮影[Phy-Gen-ECG] 心電図（12誘導）[Lab-Check-Employ] 雇用時血液検査セット
  • CBC, AST, ALT, γGTP, LDL, HDL, TG, 血糖, HbA1c [Lab-Gen-Urine] 尿定性・尿沈渣

💡 Dr.Advice

[視力・聴力] 雇用時健診では視力・聴力（1000Hz/4000Hz）が必須項目である。オージオメーターを使用し、省略せずに実施すること。

[胸部X線] 妊娠中または妊娠の可能性がある女性には原則実施しない。雇用主にその旨を記載して提出する。

📖 詳細解説​

最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。

病態生理​

  • 法的根拠: 労働安全衛生規則第43条（雇入時の健康診断）
  • 対象: 常時使用する労働者を雇い入れる際に実施
  • 必須項目（11項目）: 既往歴・業務歴、自覚症状・他覚症状、身長・体重・BMI・腹囲、視力・聴力、胸部X線、血圧、尿検査（蛋白・糖）、血液検査（貧血、肝機能、脂質、血糖）、心電図

異常値判定基準（労働安全衛生法に基づく判定区分）​

判定区分意味対応
A（異常なし）全項目正常範囲内次回定期健診まで経過観察
B（軽度異常）正常範囲をわずかに逸脱生活習慣改善の指導。次回定期健診でフォロー
C（要経過観察）生活習慣改善+経過観察が必要6ヶ月-1年後の再検査を推奨
D1（要治療）医療機関での治療が必要速やかに受診勧奨。就業上の措置を検討
D2（要精密検査）精密検査が必要二次検査の受診勧奨
E（治療中）既に治療中主治医と連携し就業上の配慮を検討
  • 就業上の措置が必要な場合: 産業医（嘱託含む）の意見を聴取し、就業制限（残業制限、配置転換等）を事業者に意見具申

エビデンス・ガイドライン推奨​

  • 実務上の注意:
    • 3ヶ月以内の健診結果を提出可能（同等の項目がある場合）
    • 結果は5年間保存義務
    • 異常所見がある場合、医師の意見を聴取し就業上の措置を検討
  • 費用負担: 事業者負担が原則
