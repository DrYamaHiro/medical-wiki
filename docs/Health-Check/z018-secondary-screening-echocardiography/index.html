[Z01.8] 二次健診・心エコー所見記載 / Secondary Screening - Echocardiography

📋 主訴・所見・診察前対応

主訴・ROS

目的: 特定健診 / 雇用時健診 / 診断書作成 / 抗体検査 / 予防接種相談 提出先: 会社 / 学校 / 保健所 / 保険会社 / 警察署[銃砲] 期限: ＿月＿日までに必要 気になる症状: 特になし / ＿ 既往歴: ＿

生活習慣

喫煙: なし / あり ＿本/日 × ＿年 飲酒: なし / ＿合/日 運動: なし / 週2回以上

所見・検査

身長: ＿cm, 体重: ＿kg, BMI: ＿, 腹囲: ＿cm 血圧: ＿/＿ mmHg, 脈拍: ＿ bpm 視力: 右 ＿ / 左 ＿ 矯正 / 裸眼 聴力(1000Hz): 右 ＿ / 左 ＿, (4000Hz): 右 ＿ / 左 ＿

診察

心音・呼吸音: 異常なし、貧血: 無 / 有

検査実施

胸部X線: 異常なし / ＿ 心電図: 正常洞調律 / ＿ 尿検査: 蛋白(＿) 糖(＿) 潜血(＿) 採血: 実施済 / 項目確認 ；結果は後日

診察前対応

（データなし）

💡 Dr.Advice

[結果渡し] 当院の血液検査は外注（SRL）であるため、診断書や健診結果の即日発行は不可能である。「結果が出るまで数日かかります」と受付段階で必ず説明し、トラブルを回避せよ。

[健診の意義] 健診は「異常を見つける」だけでなく、「自分の体を知り、生活習慣を見直すきっかけ」であることを伝え、結果説明の受診を促せ。

評価

  • LVDd: ＿ mm（基準 36-52mm）/ LVDs: ＿ mm
  • IVSTd: ＿ mm / PWTd: ＿ mm（壁肥厚: 11mm以上）
  • LVEF: ＿%（基準 55%以上 / 40-54%軽度低下 / 40%未満低下）
  • 弁膜症: AR / MR / TR（なし / trivial / mild / moderate / severe）
  • 壁運動異常: なし / あり（部位: ＿）
  • 心嚢液: なし / あり（少量 / 中等量 / 大量）
  • 大動脈弁石灰化: なし / あり
  • E/A: ＿（拡張能評価: 正常 / 弛緩障害 / 偽正常化 / 拘束型）
  • 判定: 異常なし / 要経過観察 / 要精査・要治療

方針・処方

  • 異常所見に応じた対応を記載。

処方・アクション​

壁運動異常・冠動脈疾患疑い

[Ref-Cardio-WMA] 循環器専門医紹介
  • 壁運動異常あり → 無症候性冠動脈疾患の精査目的で循環器紹介

LVEF低下

[Ref-Cardio-HF] 心不全精査・循環器紹介
  • LVEF 40%未満 → 速やかに循環器専門医へ紹介

弁膜症 moderate以上

[Ref-Cardio-Valve] 弁膜症精査・循環器紹介
  • 弁膜症moderate以上 → 循環器専門医でフォロー

指導・計画​

  • 再診目安: 異常なしの場合は健診スケジュールに準じる。異常ありの場合は循環器紹介後のフォロー。
  • 軽度異常（trivial MR/TR等）は経過観察可。1-2年ごとの心エコーフォローを検討。
  • 心嚢液中等量以上は原因精査（感染、悪性腫瘍、膠原病等）が必要。

💡 Dr.Advice

[壁運動異常] 壁運動異常は無症候性の冠動脈疾患を示唆する。循環器専門医への紹介を検討せよ。

[LVEF低下] LVEF 40%未満は心不全の精査・治療が必要。速やかに循環器へ紹介せよ。

📖 詳細解説​

概要​

心エコー（経胸壁心エコー: TTE）は心機能・弁膜症・心室肥大・壁運動異常を非侵襲的に評価する検査であり、健診で心雑音や心電図異常を指摘された患者の二次精査として最も重要な検査のひとつである。

主要計測項目と正常値

パラメータ正常値臨床的意義
LVEF（左室駆出率）55%以上収縮機能の指標。40-54%で軽度低下、40%未満で低下（HFrEF）
LVDd（左室拡張末期径）36-52mm（男性）、36-48mm（女性）左室拡大の評価
LVDs（左室収縮末期径）24-36mm収縮機能の補助指標
IVSTd（心室中隔壁厚）6-10mm11mm以上で肥大
PWTd（後壁厚）6-10mm11mm以上で肥大
LVMi（左室心筋重量係数）男性 115 g/m2未満、女性 95 g/m2未満左室肥大の定量評価
LAD（左房径）40mm以下拡大は心房細動・僧帽弁疾患を示唆

評価基準​

左室収縮機能（LVEF）

LVEF分類対応
55%以上正常経過観察
40-54%軽度低下（HFmrEF）原因精査、循環器フォロー
40%未満低下（HFrEF）心不全治療開始、循環器紹介必須

拡張能評価

パラメータ基準解釈
E/A比0.8未満弛緩障害（Grade I拡張障害）
E/A比0.8-2.0偽正常化の可能性あり→E/e'で評価
E/A比2.0以上拘束型（Grade III拡張障害）
E/e'（中隔側）15以上左室充満圧上昇を示唆
E/e'（中隔側）8未満左室充満圧正常
E/e'（中隔側）8-15グレーゾーン（他の指標と総合判断）

壁運動異常の記載

  • 16分画モデル（ASE推奨）で部位を同定
  • 記載: normokinesis（正常）、hypokinesis（低収縮）、akinesis（無収縮）、dyskinesis（奇異性運動）
  • 壁運動異常の冠動脈支配領域: 前壁・中隔→LAD、下壁→RCA、側壁→LCx

所見記載テンプレート

  • LVDd/LVDs: ＿mm / ＿mm
  • IVSTd/PWTd: ＿mm / ＿mm
  • LVEF: ＿%（Teichholz法/Simpson法）
  • 壁運動: 正常 / 異常あり（部位: ＿）
  • 弁膜症: AR ＿度、MR ＿度、TR ＿度、AS ＿度
  • 拡張能: E/A ＿、E/e' ＿

  • 大動脈弁石灰化: なし / あり

エビデンス・ガイドライン推奨​

弁膜症治療ガイドライン2020年改訂版（日本循環器学会）

  • 高度AS（症候性）: 早期の弁置換術/TAVI推奨（クラスI）
  • 無症候性高度AS: LVEF 50%未満、運動負荷で症状出現時は手術考慮
  • 高度MR（器質性）: 症候性または LVEF 60%未満/LVDs 40mm以上で手術推奨
  • Moderate以上の弁膜症は循環器専門医でのフォローを推奨

心不全診療ガイドライン2021年改訂版（日本循環器学会）

  • HFrEF（LVEF 40%未満）: ACE阻害薬/ARB、beta遮断薬、MRA、SGLT2阻害薬の4剤併用（Fantastic Four）
  • HFpEF（LVEF 50%以上）: SGLT2阻害薬の有効性が示されている（EMPEROR-Preserved、DELIVER試験）
  • 健診で偶発的にLVEF低下が見つかった場合は心不全ステージBとして早期介入

ASE/EACVI 心エコー計測推奨（2015年改訂）

  • LVEFはSimpson法（biplane法）が推奨。Teichholz法は局所壁運動異常がない場合のみ使用
  • 拡張能評価は2016年ASE/EACVIアルゴリズムに基づき、E/e'、TR velocity、LAVi、E/A比の4指標で総合判定
