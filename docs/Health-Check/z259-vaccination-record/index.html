[Z25.9] ワクチン接種記録 / Vaccination Record

📋 主訴・所見・診察前対応

主訴・ROS

目的: 特定健診 / 雇用時健診 / 診断書作成 / 抗体検査 / 予防接種相談 提出先: 会社 / 学校 / 保健所 / 保険会社 / 警察署[銃砲] 期限: ＿月＿日までに必要 気になる症状: 特になし / ＿ 既往歴: ＿

生活習慣

喫煙: なし / あり ＿本/日 × ＿年 飲酒: なし / ＿合/日 運動: なし / 週2回以上

所見・検査

身長: ＿cm, 体重: ＿kg, BMI: ＿, 腹囲: ＿cm 血圧: ＿/＿ mmHg, 脈拍: ＿ bpm 視力: 右 ＿ / 左 ＿ 矯正 / 裸眼 聴力(1000Hz): 右 ＿ / 左 ＿, (4000Hz): 右 ＿ / 左 ＿

診察

心音・呼吸音: 異常なし、貧血: 無 / 有

検査実施

胸部X線: 異常なし / ＿ 心電図: 正常洞調律 / ＿ 尿検査: 蛋白(＿) 糖(＿) 潜血(＿) 採血: 実施済 / 項目確認 ；結果は後日

診察前対応

（データなし）

💡 Dr.Advice

[結果渡し] 当院の血液検査は外注（SRL）であるため、診断書や健診結果の即日発行は不可能である。「結果が出るまで数日かかります」と受付段階で必ず説明し、トラブルを回避せよ。

[健診の意義] 健診は「異常を見つける」だけでなく、「自分の体を知り、生活習慣を見直すきっかけ」であることを伝え、結果説明の受診を促せ。

評価

  • ワクチン名: インフルエンザ / 肺炎球菌(ニューモバックス) / 肺炎球菌(バクニュバンス/PCV15) / 肺炎球菌(プレベナー20/PCV20) / 帯状疱疹(シングリックス) / HPV(シルガード9) / COVID-19 / B型肝炎 / 破傷風トキソイド / MR / 水痘 / おたふく / その他
  • ロット番号: ＿
  • 接種部位: 左上腕三角筋 / 右上腕三角筋 / 左大腿外側 / 右大腿外側
  • 接種量: 0.25mL / 0.5mL / 1.0mL
  • 体温: ＿℃（37.5℃未満を確認）
  • 問診確認: 副反応・アナフィラキシーの既往なし、体調良好、妊娠なし
  • 同意: 予診票に基づき問診を行い、接種の効果と副反応について十分説明の上、書面による同意を得て接種を実施した。
  • 接種後観察: 接種後15分（アナフィラキシー既往者は30分）院内で経過観察し、異常なきことを確認。

方針・処方

  • 次回接種予定があれば予約。接種証明書の発行。

処方・アクション​

接種実施

[Rx-Vac-Influenza] インフルエンザワクチン
  • インフルエンザHAワクチン 0.5mL 皮下注射 [Rx-Vac-PPSV23] 肺炎球菌ワクチン（ニューモバックス）
  • ニューモバックスNP 0.5mL 皮下注射 [Rx-Vac-PCV15] 肺炎球菌ワクチン（バクニュバンス/PCV15）
  • バクニュバンス水性懸濁注シリンジ 0.5mL 筋肉注射 ；PCV15 [Rx-Vac-PCV20] 肺炎球菌ワクチン（プレベナー20/PCV20）
  • プレベナー20水性懸濁注シリンジ 0.5mL 筋肉注射 ；PCV20 [Rx-Vac-Shingrix] 帯状疱疹ワクチン（シングリックス）
  • シングリックス筋注用 0.5mL 筋肉注射 ；2回接種（2ヶ月間隔） [Rx-Vac-HPV9] HPVワクチン（シルガード9）
  • シルガード9 0.5mL 筋肉注射 ；3回接種（0-2-6ヶ月） [Rx-Vac-COVID] COVID-19ワクチン
  • COVID-19ワクチン 最新推奨に準拠 [Rx-Vac-HepB] B型肝炎ワクチン
  • ビームゲン 0.5mL 皮下注射 — 3回接種（0-1-6ヶ月） [Rx-Vac-Tetanus] 破傷風トキソイド
  • 沈降破傷風トキソイド 0.5mL 皮下注射

緊急時対応

[Rx-Emerg-Epi] アドレナリン筋注（アナフィラキシー対応）
  • アドレナリン0.3mg 大腿外側に筋注 ；接種前に必ず準備

指導・計画​

  • 再診目安: 次回接種スケジュールに応じて予約。
  • 接種記録をお薬手帳・接種記録カードに記載。
  • 接種後の副反応（発熱、局所腫脹等）について説明。重篤な副反応出現時は速やかに受診するよう指導。
  • 接種証明書が必要な場合は発行する。

💡 Dr.Advice

[アナフィラキシー準備] ワクチン接種時はアドレナリン0.3mg筋注の準備を必ず行え。

[シングリックス] 50歳以上に推奨。2回接種（2ヶ月間隔）。帯状疱疹予防効果90%以上。

[肺炎球菌] 65歳以上にニューモバックス。PCV15→1年以上後にPPSV23、またはPCV20単独投与を推奨（2024年度より定期接種化）。詳細は最新の厚労省通知を確認。

📖 詳細解説​

概要​

ワクチン接種は感染症予防の最も効果的な手段であり、成人においても定期接種と任意接種の双方が重要である。2020年10月のワクチン接種間隔ルール改定により、異なるワクチン間の接種間隔制限が大幅に緩和された。

評価基準​

定期接種（成人・高齢者）

ワクチン対象接種回数費用備考
インフルエンザ（従来型）65歳以上、60-64歳で基礎疾患あり年1回一部公費10-12月に接種。予防効果40-60%
肺炎球菌（PPSV23）65歳1回公費（定期接種対象年齢）経過措置で70,75,80,...歳も対象（段階的終了）
肺炎球菌（PCV15/PCV20）65歳以上1回2024年度より定期接種対象PCV15接種後1年以上でPPSV23追加、またはPCV20単独

任意接種（成人で推奨されるもの）

ワクチン対象接種スケジュール有効性費用目安
エフルエルダ（高用量インフルエンザ）65歳以上年1回従来型比24.2%の発症減少（NEJM 2014）自費。各株HA 60μg（従来型の4倍量）
フルミスト（経鼻インフルエンザ）2歳以上19歳未満年1回小児で従来型と同等〜やや優自費（約8,000-9,000円）。注射不要。生ワクチン
帯状疱疹（シングリックス）50歳以上2回（0, 2ヶ月）50歳以上で97%、70歳以上で90%約22,000円/回（自費）
帯状疱疹（ビケン: 生ワクチン）50歳以上1回約50%（経年で低下）約8,000円（自費）
HPV（シルガード9）9-45歳3回（0, 2, 6ヶ月）HPV 6/11/16/18/31/33/45/52/58型に90%以上定期接種対象は公費
B型肝炎医療従事者、HBVキャリア家族等3回（0, 1, 6ヶ月）抗体獲得率95%以上約5,000-7,000円/回
破傷風トキソイド全成人（10年ごと）基礎免疫3回+追加10年ごとほぼ100%約3,000-4,000円/回
MR（麻疹・風疹）抗体価不十分な成人1-2回95%以上約10,000円/回

HPVワクチン キャッチアップ接種

  • 対象: 1997年4月2日-2008年4月1日生まれの女性（積極的勧奨差し控え期間に定期接種の機会を逃した世代）
  • 期間: 公費キャッチアップ接種は2025年3月に終了した。以降は任意接種（自費）
  • 接種スケジュール: シルガード9を3回（0-2-6ヶ月）。15歳未満開始の場合は2回でも可

接種間隔ルール（2020年10月改定）

2020年10月1日以降、接種間隔の制限は以下のように緩和された:

組み合わせ接種間隔備考
注射生ワクチン同士27日以上あける例: MR→水痘は27日以上間隔
注射生ワクチン→不活化ワクチン制限なし同日接種も可（別部位）
不活化ワクチン→注射生ワクチン制限なし同日接種も可（別部位）
不活化ワクチン同士制限なし同日接種も可（別部位）
経口生ワクチン（ロタ等）制限なし他のワクチンとの間隔制限なし

注: 同一ワクチンの接種間隔（例: シングリックス1回目→2回目は2ヶ月）は従来通り各ワクチンの規定に従う。

注射生ワクチンの例: BCG、MR（麻疹風疹混合）、水痘、おたふくかぜ、帯状疱疹（ビケン）

経鼻生ワクチン: フルミスト（経鼻弱毒生インフルエンザワクチン）。経鼻投与だが生ワクチンであるため、他の注射生ワクチンとの接種間隔は27日以上あける必要がある。不活化ワクチンとの間隔制限はなし

不活化ワクチンの例: インフルエンザ（従来型）、エフルエルダ（高用量インフルエンザ）、肺炎球菌（PPSV23、PCV）、B型肝炎、HPV、破傷風、日本脳炎、帯状疱疹（シングリックス）

エビデンス・ガイドライン推奨​

予防接種法に基づく定期接種

  • A類疾病: 集団予防を目的。接種勧奨あり、努力義務あり（小児の定期接種が中心）
  • B類疾病: 個人予防を目的。接種勧奨なし、努力義務なし。インフルエンザ（65歳以上）と肺炎球菌（65歳以上）が該当

接種記録の法的保存義務

  • 予防接種法第24条: 市町村長は予防接種の記録を保存しなければならない
  • 予診票は5年間保存（予防接種法施行規則）
  • 医療機関側のカルテ記録: 医師法第24条に基づき5年間保存義務
  • 被接種者への記録交付: 母子健康手帳（小児）、予防接種済証、接種記録書
  • 副反応疑い報告: 予防接種法第12条に基づき医療機関は副反応報告義務あり（PMDA経由）

シングリックスのエビデンス

  • ZOE-50試験（N Engl J Med 2015）: 50歳以上で帯状疱疹予防効果97.2%
  • ZOE-70試験（N Engl J Med 2016）: 70歳以上で帯状疱疹予防効果89.8%、帯状疱疹後神経痛予防効果88.8%
  • 効果持続: 接種後10年時点でも80%以上の予防効果が持続（長期追跡データ）
  • 免疫抑制患者にも使用可能（不活化ワクチンのため）

肺炎球菌ワクチンの推奨

  • PPSV23: 23種の莢膜多糖体に対する抗体産生。T細胞非依存性のため免疫記憶は限定的
  • PCV（結合型）: T細胞依存性で免疫記憶を誘導。2024年より65歳以上にPCV15またはPCV20が定期接種化
  • 推奨順序（ACIP/日本）: PCV15→1年以上後にPPSV23、またはPCV20単独

HPVワクチンのエビデンス

  • シルガード9は子宮頸がんの原因となるHPV型の約90%をカバー
  • スウェーデンの大規模コホート研究（N Engl J Med 2020）: 17歳未満の接種で子宮頸がんリスク88%減少
  • 日本では2013年の積極的勧奨差し控え後、2022年4月に勧奨再開
