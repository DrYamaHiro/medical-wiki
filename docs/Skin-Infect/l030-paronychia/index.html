[L03.0] 爪囲炎 / Paronychia

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 痒み / 痛み / 水疱 / 膿疱 / しこり / イボ 部位: 足指 / 爪 / 口唇 / 体幹 / 陰部 / ＿ 経過: ＿日前から出現, 急速に拡大 / 繰り返している / 再発

皮膚・アレルギー

自覚症状: 激痒 / 軽度痒み / 痛み / 無症状 既往・背景: 糖尿病 / アトピー / 免疫抑制 / 帯状疱疹 / なし 接触歴: 家族に水虫 / プール / ジム / 性交渉 / 動物 / なし

所見・検査

皮疹性状

原発疹: 趾間浸軟 / 小水疱 / 角化 / 膿疱 / 結節 / 膨疹 続発疹: 痂皮 / びらん / 潰瘍 / 鱗屑 分布・配列: 帯状配列 / 集簇性 / 左右対称 / 孤立 / 汎発 局所所見: 圧痛あり / 波動あり / 中心臍窩あり

検査

真菌鏡検(KOH法) (外注提出) ；当院即日不可 細菌培養同定・感受性 (外注提出) 単純ヘルペスウイルス抗原検査 (迅速) 水痘帯状疱疹ウイルス抗原検査 (迅速)

診察前対応

検査

[Lab-Der-KOH] 真菌鏡検(KOH法)[Lab-Der-Culture] 細菌培養同定・感受性[Lab-Der-Rapid-HSV] 単純ヘルペスウイルス抗原定性[Lab-Der-Rapid-VZV] 水痘帯状疱疹ウイルス抗原定性

💡 Dr.Advice

[KOH即日不可の対応] 当院ではKOH（真菌検査）が外注となるため、その場での白癬確定診断ができない。典型的な湿疹に見えても、ステロイドを塗って悪化する場合は白癬の可能性がある。「もし薬を塗って赤みや痒みが増したら、すぐに中止して再診してください」と必ず伏線を張れ。疑わしければ、初回は抗真菌薬もステロイドも使わず、保湿剤や非ステロイド系（スタデルム等）で検査結果を待つのも賢明な戦略である。

[細菌培養の重要性] 蜂窩織炎や化膿性粉瘤では、切開排膿時や抗生剤開始前に必ず培養を採取せよ。経験的治療が無効だった場合、この培養結果が「次の手（耐性菌対応）」を決める命綱となる。

評価

  • 診断根拠: 爪周囲の発赤・腫脹・疼痛。膿瘍形成の有無を確認。
  • 分類: 急性: 黄色ブドウ球菌（ささくれ・陥入爪から侵入） / 慢性: カンジダ（水仕事が多い職種）
  • 鑑別: ヘルペス性ひょうそ（Herpetic whitlow）、爪白癬、悪性腫瘍（メラノーマの爪下型）

方針・処方

  • 急性・軽症: 抗菌薬内服。
  • 急性・膿瘍形成: 切開排膿（18G針で穿刺 or 11番メスで小切開）。
  • 慢性: 原因除去（水仕事時の手袋着用）+抗真菌外用。
  • 陥入爪が原因の反復例は根本治療を検討。

処方・アクション​

急性爪囲炎セット

[Rx-Skin-Paro-Ceph] ケフレックス
  • ケフレックスカプセル500mg 1回1カプセル 1日3回 毎食後 5日分 — 急性爪囲炎 [Rx-Skin-Paro-Aug] オーグメンチン配合錠（咬傷・嫌気性菌混合感染時の代替）
  • オーグメンチン配合錠250RS 1回1錠 1日3-4回 毎食後（・就寝前） 5日分 — 咬傷・嫌気性菌混合感染

※MRSA疑い時は排膿検体の培養・感受性検査を提出 [Rx-Skin-Paro-MRSA] ST合剤（MRSA対応）

  • バクタ配合錠 1回2錠 1日2回 朝夕食後 5日分 — 反復例・入院歴ありでMRSAリスクがある場合に検討

※皮膚軟部組織感染症は添付文書上の適応外。審査情報提供が必要な場合あり

慢性爪囲炎セット

[Rx-Skin-Paro-Luli] ルリコナゾール
  • ルリコンクリーム1% 1本 1日1回 患部に塗布 28日分 — カンジダ性慢性爪囲炎

切開排膿（膿瘍形成時）

[Proc-Skin-Paro-ID] 切開排膿
  • 局所麻酔（指ブロック: 1%リドカイン）→18G針穿刺 or 11番メスで小切開→排膿→洗浄→ガーゼドレナージ

指導・計画​

  • 患者指導: 爪の適切なケア（深爪回避、角を丸く切らない）。慢性例は水仕事時の手袋着用。
  • 再診目安: 切開排膿後2-3日、内服のみは1週間後。

💡 Dr.Advice

[反復例] 陥入爪が原因の反復性爪囲炎は根本治療（ワイヤー矯正、フェノール法等）を検討。形成外科紹介。

[ヘルペス注意] 水疱を伴う場合はヘルペス性ひょうそを鑑別。切開は禁忌（ウイルス播種のリスク）。

📖 詳細解説​

病態生理​

爪囲炎（paronychia）は爪郭（爪の周囲の皮膚）に生じる感染症・炎症性疾患であり、急性と慢性に大別される。

急性爪囲炎

  • 主な起因菌は黄色ブドウ球菌（Staphylococcus aureus）で、全体の約50%以上を占める
  • ささくれ（爪周囲の小さな裂傷）、深爪、陥入爪、爪噛み癖、マニキュア処置などによる微小外傷が侵入門戸となる
  • 爪郭の発赤・腫脹・疼痛が急速に進行し、24-48時間以内に膿瘍を形成することがある
  • 咬傷による場合はEikenella corrodens、Pasteurellaなどの嫌気性菌混合感染を考慮する

慢性爪囲炎

  • 6週間以上持続する爪囲の炎症と定義される
  • カンジダ（Candida albicans）が関与することが多いが、単純な感染症ではなく刺激性接触皮膚炎が基盤にある
  • 水仕事が多い職種（調理師、美容師、清掃業、医療従事者）に好発
  • 反復する湿潤環境への曝露により爪上皮（cuticle）のバリアが破壊され、刺激物質やカンジダが爪郭に侵入する
  • 爪母への慢性的な炎症波及により、爪甲の変形（横溝、波状変形）を伴うことがある

診断基準・鑑別疾患​

臨床診断のポイント

  • 急性: 爪郭の発赤・腫脹・圧痛、波動触知（膿瘍形成）。発症から数日以内
  • 慢性: 爪郭の腫脹・硬化・発赤が数週間-数ヶ月持続。爪上皮の消失、爪甲変形を伴う

切開排膿の適応

  • 膿瘍形成（波動触知陽性）を認める場合は切開排膿が必須
  • 18G針による穿刺または11番メスによる小切開で排膿
  • 排膿後は洗浄し、ガーゼドレナージを留置。翌日-2日後に再診

鑑別疾患

疾患特徴
ヘルペス性ひょうそ（Herpetic whitlow）小水疱の集簇、激痛、切開禁忌（ウイルス播種のリスク）
爪白癬爪甲の肥厚・混濁・変形、KOH法で菌糸確認
爪下メラノーマ爪甲の黒色縦線（Hutchinson徴候）、爪郭への色素沈着
乾癬による爪変化点状陥凹（pitting）、油滴徴候、他部位の乾癬病変
グロムス腫瘍爪下の激痛（特に冷水で増悪）、小結節

エビデンス・ガイドライン推奨​

急性爪囲炎の治療

  • 軽症（膿瘍なし）: 温水浸漬（1日3-4回、15-20分）で自然排膿を促す。改善なければ抗菌薬内服
  • 抗菌薬: セファレキシン（ケフレックス）500mg 1日3回 5日間が第一選択。ペニシリンアレルギー時はクリンダマイシン300mg 1日3回
  • 膿瘍形成: 切開排膿が治療の根幹。抗菌薬単独では不十分。指ブロック（1%リドカイン）下で施行
  • MRSA疑い: 入院歴、反復例、培養でMRSA既往がある場合はST合剤（バクタ配合錠）2錠 1日2回を考慮

慢性爪囲炎の治療

  • 原因除去が最重要: 水仕事時のゴム手袋（綿手袋のインナー）着用、刺激物の回避
  • 外用療法: ステロイド外用（betamethasone valerate等のmedium potency）を爪郭に塗布。炎症の基盤が刺激性接触皮膚炎であるため、抗真菌薬単独より効果的
  • 抗真菌外用: カンジダの関与が明らかな場合はルリコナゾール（ルリコン）等のアゾール系外用を併用
  • 難治例: タクロリムス外用、局所ステロイド注射を検討

予防（手荒れ対策）

  • ゴム手袋の下に綿手袋を着用し、直接的な湿潤環境を回避
  • 保湿剤によるスキンケア（ワセリン、ヘパリン類似物質）
  • 深爪回避、爪の角を丸く切りすぎない
  • ささくれは無理に引きちぎらず、清潔なニッパーで根元から切除
