[R94.2] スパイロメトリー所見記載 / Spirometry Documentation

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 咳嗽 / 喀痰 / 喘鳴 / 呼吸困難

呼吸器系

咳嗽: 乾性 / 湿性, 喀痰: 有 / 無 喘鳴: ヒューヒュー / ゼーゼー / なし 呼吸困難: 労作時 / 安静時 / 夜間 / 明け方 症状の変動: 夜間に悪化 / 季節性あり / 運動・冷気で誘発

背景

喫煙歴: ＿ 本/日 × ＿ 年 現在: 喫煙中 / 禁煙済 既往歴: アレルギー性鼻炎、アトピー、小児喘息

所見・検査

バイタル: SpO2: ＿% (Room Air)

胸部聴診

呼吸音: 強制呼気時喘鳴 / 呼吸音減弱 / 正常 / 肺胞呼吸音

呼吸機能検査 (スパイロ)

呼吸機能検査（スパイロメトリー） FEV1: ＿L, %FEV1: ＿% FEV1/FVC: ＿% <70%で閉塞性障害 フローボリューム曲線: 下に凸 / 正常

画像

胸部単純X線検査 所見: 異常なし / 透過性亢進 / 浸潤影なし AI解析結果: 異常なし / 異常所見あり: ＿

診察前対応

呼吸機能検査 (スパイロ)

[Phy-Gen-Spiro] 呼吸機能検査（スパイロメトリー）

画像

[Img-Gen-ChestXP] 胸部単純X線撮影

💡 Dr.Advice

[診断の鍵] 当院には呼気NO(FeNO)がないため、診断は「詳細な問診（変動性）」と「スパイロメトリー（可逆性・閉塞性）」、および「治療的診断（吸入薬で良くなるか）」が主軸となる。

[RedFlag] 会話が途切れるほどの呼吸苦、SpO2<90%、呼吸補助筋の使用は発作重積状態の可能性あり。直ちに吸入・ステロイド全身投与・搬送を考慮せよ。

評価

  • 肺活量(VC): ＿ L（予測値 ＿ L、%VC: ＿%）
  • 努力肺活量(FVC): ＿ L
  • 1秒量(FEV1): ＿ L（予測値 ＿ L、%FEV1: ＿%）
  • 1秒率(FEV1%): ＿%
  • 判定: 正常 / 閉塞性障害 / 拘束性障害 / 混合性障害
  • 閉塞性: FEV1% 70%未満 → COPD、喘息等を精査
  • 拘束性: %VC 80%未満 → 間質性肺疾患、神経筋疾患等を精査
  • フローボリューム曲線: 正常型 / 閉塞型（下に凸）/ 拘束型（全体縮小）

方針・処方

  • 判定に応じた精査計画を記載。

処方・アクション​

閉塞性障害精査セット

[Rx-Resp-BDR] 気管支拡張薬吸入後再検（気道可逆性試験）
  • サルブタモール200-400μg吸入後15-20分で再検 ；COPD vs 喘息の鑑別 [Rx-Resp-FeNO] 呼気NO検査
  • 呼気一酸化窒素(FeNO)測定 ；好酸球性気道炎症の評価

拘束性障害精査セット

[Img-Resp-HRCT] 胸部HRCT
  • 胸部高分解能CT ；間質性肺疾患の評価

指導・計画​

  • 再診目安: 精査結果に応じて1-4週後。
  • 閉塞性障害確認時は禁煙指導を併せて実施。
  • 拘束性障害確認時は呼吸器専門医への紹介を検討。

💡 Dr.Advice

[手技] 最低3回の測定で再現性を確認（FVCとFEV1の最大値の差が150mL以内）。

[COPD] FEV1% 70%未満のみではCOPD確定できない。気管支拡張薬吸入後の再検が必要。

[喘息] 喘息が疑われる場合は気道可逆性試験（β2刺激薬吸入前後のFEV1 12%以上かつ200mL以上の改善）を実施せよ。

📖 詳細解説​

病態生理​

  • スパイロメトリーの原理: 最大吸気位から最大努力で呼出させ、呼出量と時間の関係から肺機能を評価する
  • 主要パラメータ:
    • 肺活量（VC）: 最大吸気位から最大呼気位までゆっくり呼出した量
    • 努力性肺活量（FVC）: 最大吸気位から最大努力で一気に呼出した量。正常ではVC≒FVCだが、閉塞性障害ではFVC低下（air trapping）
    • 1秒量（FEV1）: 努力呼気開始から1秒間に呼出された量。最も再現性が高く臨床的に重要な指標
    • 1秒率（FEV1/FVC）: 閉塞性障害の指標。70%未満で閉塞性パターン
    • %肺活量（%VC）: 実測VC/予測VC x 100。80%未満で拘束性パターン
    • %FEV1: 実測FEV1/予測FEV1 x 100。重症度評価に使用
  • フローボリューム曲線: 横軸に肺気量、縦軸に呼気流速をプロットした曲線
    • 正常: 呼気開始直後にピークフロー（PEF）に達し、直線的に減少
    • 閉塞性: PEF低下、下に凸のカーブ（末梢気道閉塞を反映）
    • 拘束性: 全体が縮小するが形は正常に近い
    • 上気道閉塞: 吸気側・呼気側のプラトー形成（固定性）、または吸気のみ/呼気のみ制限（変動性）
  • 予測値: 日本人の基準値はJRS 2014（日本呼吸器学会LMS基準値）を使用。性別・年齢・身長から算出

診断基準・鑑別疾患​

換気障害の分類

パターンFEV1/FVC%VC代表疾患
正常70%以上80%以上-
閉塞性障害70%未満80%以上COPD、喘息、DPB
拘束性障害70%以上80%未満間質性肺疾患、神経筋疾患、胸郭変形
混合性障害70%未満80%未満進行COPD+合併症、塵肺

COPD重症度分類（GOLD/JRS準拠、気管支拡張薬吸入後FEV1/FVC 70%未満を確認後）

病期%FEV1
I（軽症）80%以上
II（中等症）50-80%
III（重症）30-50%
IV（最重症）30%未満

気道可逆性試験（BDR）

  • SABA（サルブタモール200-400μg）吸入後15-20分で再検
  • 陽性基準: FEV1が 12%以上かつ200mL以上 改善 → 喘息を強く示唆
  • COPDでも部分的可逆性を示すことがあり、1回の試験で喘息/COPDを完全に区別することは困難

品質評価（ATS/ERS 2019基準）

  • 許容基準（acceptability）:
    • 立ち上がりの鋭さ: 逆外挿体積（BEV）が0.15L以下またはFVCの5%以下
    • 最大努力の呼気: プラトー到達（1秒間の呼出量変化25mL以下）、または呼気時間15秒以上
    • コフ・グリッチス・早期終了がない
  • 再現性基準（repeatability）:
    • 最大FEVと2番目のFEV1の差が 150mL以内
    • 最大FVCと2番目のFVCの差が 150mL以内
  • 最低3回の許容可能な努力が必要。最大8回まで
  • グレードA（3回以上許容、再現性150mL以内）が理想

エビデンス・ガイドライン推奨​

  • COPD診断: 気管支拡張薬吸入後のFEV1/FVC 70%未満がGOLD基準。ただしLLN（正常下限値）を用いるべきとの議論もある（特に高齢者で過剰診断を避けるため）
  • 喘息のスパイロ所見: 変動性の気流制限が特徴。PEFの日内変動率20%以上、経時的なFEV1変動が12%かつ200mL以上
  • スクリーニング: 40歳以上の喫煙者にはスパイロメトリーによるCOPDスクリーニングが推奨（JRS COPD GL 2022）
  • 検査前の注意:
    • SABA: 4時間以上前に中止
    • LABA: 12時間以上前に中止（可逆性試験の場合）
    • 禁煙: 検査1時間前から
    • 食事: 検査2時間前から大食を避ける
  • 禁忌: 1ヶ月以内の心筋梗塞、気胸、大量喀血、未治療の大動脈瘤、網膜剥離術後
