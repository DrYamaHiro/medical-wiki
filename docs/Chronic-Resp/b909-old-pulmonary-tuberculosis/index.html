[B90.9] 陳旧性肺結核 / Old Pulmonary Tuberculosis

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 咳嗽 / 喀痰 / 喘鳴 / 呼吸困難

呼吸器系

咳嗽: 乾性 / 湿性, 喀痰: 有 / 無 喘鳴: ヒューヒュー / ゼーゼー / なし 呼吸困難: 労作時 / 安静時 / 夜間 / 明け方 症状の変動: 夜間に悪化 / 季節性あり / 運動・冷気で誘発

背景

喫煙歴: ＿ 本/日 × ＿ 年 現在: 喫煙中 / 禁煙済 既往歴: アレルギー性鼻炎、アトピー、小児喘息

所見・検査

バイタル: SpO2: ＿% (Room Air)

胸部聴診

呼吸音: 強制呼気時喘鳴 / 呼吸音減弱 / 正常 / 肺胞呼吸音

呼吸機能検査 (スパイロ)

呼吸機能検査（スパイロメトリー） FEV1: ＿L, %FEV1: ＿% FEV1/FVC: ＿% <70%で閉塞性障害 フローボリューム曲線: 下に凸 / 正常

画像

胸部単純X線検査 所見: 異常なし / 透過性亢進 / 浸潤影なし AI解析結果: 異常なし / 異常所見あり: ＿

診察前対応

呼吸機能検査 (スパイロ)

[Phy-Gen-Spiro] 呼吸機能検査（スパイロメトリー）

画像

[Img-Gen-ChestXP] 胸部単純X線撮影

💡 Dr.Advice

[診断の鍵] 当院には呼気NO(FeNO)がないため、診断は「詳細な問診（変動性）」と「スパイロメトリー（可逆性・閉塞性）」、および「治療的診断（吸入薬で良くなるか）」が主軸となる。

[RedFlag] 会話が途切れるほどの呼吸苦、SpO2<90%、呼吸補助筋の使用は発作重積状態の可能性あり。直ちに吸入・ステロイド全身投与・搬送を考慮せよ。

評価

  • 診断根拠: 過去の結核既往、胸部X線での石灰化・線維化陰影。
  • 活動性: なし / 疑いあり: 陰影の拡大、空洞形成

方針・処方

  • 年1回の胸部X線フォローアップ。
  • 自覚症状（血痰、咳増悪）出現時は、喀痰抗酸菌検査（外注）を行い、活動性結核が否定できなければ専門医へ紹介。

検査・アクション​

フォローアップ検査

[Img-Gen-ChestXP] 胸部単純X線撮影[Lab-Resp-AFB] 結核・抗酸菌検査
  • 喀痰抗酸菌塗抹・培養・同定・PCR (外注)

💡 Dr.Advice

[再燃] 高齢化や糖尿病、ステロイド投与を契機に数十年後に再燃することがある。常に「結核かもしれない」という視点を持つこと。

📖 詳細解説​

病態生理​

  • 定義: 過去の肺結核の治癒後に残存する非活動性の肺病変
  • 病態:
    • 結核菌感染 → 肉芽腫形成 → 乾酪壊死 → 線維化・石灰化して治癒
    • 残存所見: 石灰化結節、線維索状影、胸膜肥厚、気管支拡張、肺容量減少
    • 結核菌は完全に死滅していることもあるが、休眠状態で残存していることもある
  • 臨床的意義:
    • 健診胸部X線で異常所見として発見される最多の原因の一つ
    • 免疫抑制時（ステロイド、生物学的製剤、加齢）に再活性化のリスクあり
    • NTM症の好発因子（気管支拡張を基盤に定着）
    • 肺機能低下（広範な場合は拘束性障害）

診断基準・鑑別疾患​

  • 診断のポイント:
    • 胸部X線: 上肺野の石灰化影、線維索状影、胸膜肥厚、肺門の牽引
    • 既往歴: 過去の結核治療歴、BCG接種歴
    • 活動性結核の除外が最重要:
      • 症状（咳嗽2週間以上、微熱、盗汗、体重減少）の有無
      • 喀痰抗酸菌検査（塗抹・培養・PCR）: 活動性が少しでも疑われれば必須
      • IGRA（QFT or T-SPOT）: 感染の有無は示すが活動性の判断には不十分
  • 活動性を疑うサイン:
    • 過去のX線と比較して陰影の変化（拡大、空洞出現）
    • 新たな症状出現（咳嗽、微熱、血痰）
    • 免疫抑制状態の出現（糖尿病悪化、ステロイド開始、HIV）
  • 鑑別疾患: 肺癌（結節影との鑑別）、NTM症、肺アスペルギルス症（既存空洞への菌球形成）、サルコイドーシス

エビデンス・ガイドライン推奨​

  • 経過観察:
    • 安定した陳旧性病変: 年1回の胸部X線で十分
    • 広範な病変・気管支拡張合併: 6ヶ月ごとのフォロー
    • NTM合併のスクリーニング: 新たな痰の出現時に抗酸菌検査
  • 生物学的製剤・免疫抑制薬使用前のスクリーニング:
    • TNF-alpha阻害薬（インフリキシマブ等）開始前: IGRA + 胸部X線が必須
    • IGRA陽性 or 陳旧性結核の画像所見あり → 潜在性結核感染症（LTBI）として予防内服
    • LTBI治療: INH 300mg/日 6-9ヶ月 or INH + RFP 3ヶ月
  • 潜在性結核感染症（LTBI）の治療適応:
    • 生物学的製剤・免疫抑制薬使用予定
    • HIV感染
    • 最近の感染（接触者検診で判明）
    • 臓器移植前後
  • 健診異常への対応: 過去のX線との比較が最重要。変化なければ経過観察、変化あれば精査
