[N61] 乳腺炎 / Mastitis

📋 主訴・所見・診察前対応

主訴・ROS

主訴: ホットフラッシュ / のぼせ / 多汗 / 不眠 / イライラ / 下腹部痛 / 腰痛 / 不正出血 / 帯下異常 / 外陰部痒み / 乳房しこり

更年期症状

のぼせ・発汗: 有 / 無, 動悸: なし / あり, 関節痛・手指こわばり: なし / あり 精神: 安定 / 不安 / 抑うつ / 易怒性 睡眠: 良好 / 入眠障害 / 中途覚醒 / 早朝覚醒

婦人科症状

下腹部痛: なし / あり, 腰痛: なし / あり, 不正出血: なし / あり 帯下: 増量 / 酒粕状 / 悪臭 / 黄色 / 血性, 外陰部掻痒感: 有 / 無

乳房

しこり: なし / あり, 疼痛・発赤・熱感: なし / あり, 授乳中: はい / いいえ

月経歴・背景

最終月経: ＿月＿日 順調 / 不順 / 閉経 ＿歳 周期: ＿日, 日数: ＿日, 量: 多 / 普通 / 少 妊娠の可能性: なし / あり / 不明 既往歴: 子宮筋腫 / 内膜症 / 乳癌 / 血栓症

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

腹部診察

視診: 平坦 / 膨満, 触診: 軟 / 筋性防御 / 腫瘤触知 圧痛: なし / 下腹部正中 / 左右付属器領域 CVA叩打痛: 有 / 無 ；腎盂腎炎除外

乳房視触診

皮膚所見: 正常 / 発赤 / 熱感, 腫瘤: なし / あり, 腋窩リンパ節: 腫脹なし / あり

検査

女性ホルモンセット(E2, FSH, LH, PRL) 貧血・鉄代謝(Hb, Ferritin) 甲状腺スクリーニング(TSH, FT4) ；更年期との鑑別

診察前対応

検査

[Lab-Gyn-Hormone] 女性ホルモンセット(E2, FSH, LH, PRL)[Lab-Hem-Iron] 貧血・鉄代謝(Hb, Ferritin)[Lab-Endo-Thy-Screen] 甲状腺スクリーニング(TSH, FT4)

💡 Dr.Advice

[妊娠の絶対除外] 閉経前の女性の「腹痛」「吐き気」「不正出血」を見たら、本人が否定しても医学的には「妊娠（特に異所性妊娠）」を常に疑う必要がある。当院では尿中hCGキットの常備がないため、疑わしければ問診で強く確認するか、近隣薬局で検査薬を購入して確認するよう促す、あるいは直ちに婦人科へ紹介するフローを徹底せよ。

[内診・エコー不可の限界] 当院には内診台および経腟エコーがないため、子宮筋腫、卵巣嚢腫、子宮体癌などの器質的疾患の診断は不可能である。「薬で様子を見る」のは、あくまで機能性疾患（更年期・PMS等）と推定される場合に限り、不正出血が続く場合や腹痛が強い場合は、必ず婦人科専門医へ紹介せよ。

評価

  • 診断根拠: 乳房の局所的な発赤・腫脹・疼痛。発熱(38℃以上)。
  • 状態・分類: うっ滞性 / 化膿性 / 膿瘍形成疑い

方針・処方

  • 治療戦略: 排乳（授乳継続）を基本とし、細菌性を疑う場合は抗菌薬を投与。

処方・アクション (選択)​

抗菌薬・鎮痛

[Rx-Uro-Inf-Cef] ケフレックス錠250mg 1回1錠 1日4回 5日分[Rx-Gen-Pain-Ace-T] カロナール錠500mg 1回1錠 疼痛時頓用 ；授乳中安全[Rx-Kampo-001] 葛根湯(1) 2.5g 1回1包 1日3回 食前 5日分 ；うっ滞期

紹介

[Doc-Gen-Referral] 診療情報提供書
  • 紹介先: 乳腺外科（膿瘍形成時・切開排膿依頼）

指導・計画 (必須)​

  • 患者指導: 授乳を中断せず、排乳を促すことが重要。改善しない「しこり」は専門医へ。
  • 再診目安: 3日後（改善なき場合は紹介）。

💡 Dr.Advice

[授乳は止めない] 「薬を飲むから授乳を止める」と、うっ滞が悪化して逆効果になる。ケフレックスやカロナールは授乳中でも安全性が高い。「痛くない角度で赤ちゃんに飲んでもらうのが一番の治療」と指導せよ。

[炎症性乳癌] 抗菌薬で改善しない、あるいは「しこりが硬い」「皮膚がミカンの皮のよう」な場合は、炎症性乳癌の可能性がある。漫然と治療せず、改善なければ直ちに専門医へ。

📖 詳細解説​

病態生理​

  • 乳腺炎は授乳期に好発する乳腺の炎症。うっ滞性乳腺炎（乳汁うっ滞）と化膿性乳腺炎（細菌感染）に分類
  • 授乳婦の約10-20%が経験。産後2-3週間に多い。起因菌はS. aureus（黄色ブドウ球菌）が最多

診断基準・鑑別疾患​

  • うっ滞性: 乳房の腫脹・硬結・圧痛、微熱。授乳・搾乳で改善
  • 化膿性: 発赤・熱感・高熱（38.5度以上）、膿瘍形成。穿刺/切開排膿が必要な場合あり
  • 鑑別: 炎症性乳癌（非授乳期、治療に反応しない場合は生検を検討）、乳腺膿瘍

エビデンス・ガイドライン推奨​

  • ABM（Academy of Breastfeeding Medicine）臨床プロトコル #36（2022年改訂）:
    • Stage 1（乳管狭窄/乳汁うっ滞）: 頻回授乳、患側からの授乳開始、冷罨法、NSAIDs（イブプロフェン400mg 8時間ごと）。抗菌薬は不要
    • Stage 2（炎症性乳腺炎）: 上記に加え、24時間経過しても改善しない or 急速に悪化する場合に抗菌薬開始。授乳継続を強く推奨
    • Stage 3（膿瘍形成）: エコーガイド下穿刺排膿または切開排膿。授乳は継続
    • 重要な変更点: 従来の「温罨法で乳管開通を促す」から「冷罨法+生理的排乳（授乳/搾乳）」へシフト。過度な乳房マッサージは組織損傷を悪化させるため非推奨
  • 化膿性乳腺炎: セファレキシン500mg x 3回/日 7-14日間 or アモキシシリン/クラブラン酸。授乳は原則継続可能（WHO推奨）
  • 超音波による膿瘍判定基準:
    • 液体貯留像（低エコー領域）: 径10mm以上で穿刺排膿の適応を検討
    • 後方エコーの増強、辺縁不整の厚い壁
    • 径3cm未満: エコーガイド下穿刺吸引（18G針）で対応可能なことが多い
    • 径3cm以上 or 穿刺後に再貯留: 切開排膿を検討 → 乳腺外科紹介
    • 多房性膿瘍: 穿刺困難なため切開排膿が原則
  • MRSA乳腺炎への対応:
    • 市中MRSA（CA-MRSA）が乳腺炎起因菌の約10-15%を占めるとの報告あり（北米データ）
    • 疑うべき状況: セファレキシンで48-72時間改善なし、膿瘍培養でMRSA検出、再発を繰り返す
    • 治療: ST合剤（トリメトプリム/スルファメトキサゾール）160/800mg 1日2回 10-14日間（授乳との安全性: 生後1ヶ月以降の健康児では使用可能、新生児期はクリンダマイシンを優先）
    • クリンダマイシン 300mg 1日3回 10-14日間: MRSA感受性が高く、授乳中も安全性が確立
    • 培養提出を推奨（膿を綿棒で採取、好気性培養+感受性）
  • 授乳継続: 抗菌薬治療中も授乳は推奨される（児への移行量はごくわずか）。乳汁排出が治療の一部
