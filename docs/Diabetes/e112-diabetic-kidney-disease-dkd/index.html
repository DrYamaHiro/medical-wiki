[E11.2] 糖尿病性腎症 / Diabetic Kidney Disease / DKD

📋 主訴・所見・診察前対応

主訴・ROS

主訴: 検診異常 / 口渇 / 多飲 / 多尿 / 体重減少 / だるさ

代謝・内分泌

口渇・多飲: なし / あり, 多尿・夜間尿: なし / あり ＿回 体重変化: なし / 増加 / 減少 ＿kg

合併症関連 (ROS)

眼: 視力低下 / 霧視 / 飛蚊症 神経: 手足のしびれ / こむら返り / 立ちくらみ / 便通異常 心・腎: むくみ / 息切れ / 胸痛

生活習慣・背景

食事: 規則的 / 間食多い / 糖質過多 / アルコール 運動: なし / 定期的, 喫煙: なし / あり 家族歴: 糖尿病 父 / 母 / 兄弟 妊娠歴: 巨大児出産 / 妊娠糖尿病 他院治療歴: 無 / 有: 薬剤名 ＿

所見・検査

バイタル: BP: ＿/＿, HR: ＿, BMI: ＿ (身長 ＿cm / 体重 ＿kg), 腹囲: ＿cm

神経所見

アキレス腱反射: 消失 / 低下 / 正常 振動覚(内果): ＿秒 / 低下 / 正常 Touch Test: 感覚鈍麻 / 正常

フットチェック

足背動脈: 触知 / 減弱, 爪白癬・鶏眼・胼胝 有 / 無

院内迅速検査

尿: 糖(＿) 蛋白(＿) 潜血(＿) ケトン(＿) 血糖: ＿ mg/dL, HbA1c: ＿ %

外注検査

CPR(インスリン分泌能), 尿中微量アルブミン

診察前対応

（データなし）

💡 Dr.Advice

[1型除外] 「急激な発症」「著明な体重減少」「ケトン体陽性」「若年」「痩せ型」は1型糖尿病（インスリン依存状態）を疑う。見逃すとDKAで死に至るため、必ずCPRと抗体検査を行え。

[眼科受診] 糖尿病網膜症は自覚症状なく進行し、失明原因の上位である。当院では眼底検査ができないため、初診時に必ず眼科への対診依頼 [ID: Doc-Gen-Referral] を行え。

[処方日数] オンライン診療において、基礎疾患情報（お薬手帳、健診結果、紹介状等）がない初診患者の場合は「7日分を上限」とする。情報ありなら通常処方可。

評価

  • 診断根拠: 糖尿病歴、網膜症の合併（一般的）、微量アルブミン尿～顕性蛋白尿。
  • 病期: 第2期:微量Alb / 第3期:顕性Alb / 第4期:腎不全

方針・処方

  • 第2期（微量アルブミン尿）での早期介入が可逆性の鍵。
  • RAAS阻害薬 ＋ SGLT2阻害薬 ＋ MRA（ケレンディア）の多剤併用による強力な腎保護。

処方 (併用推奨)​

腎保護セット

[Rx-DM-SGLT2-Dap] フォシーガ
  • フォシーガ錠10mg 1回1錠 1日1回 朝食後 28日分 [Rx-DM-Nep-Ker] ケレンディア
  • ケレンディア錠10mg 1回1錠 1日1回 朝食後 28日分 — MRA [Rx-HT-ARB-Tel40] テルミサルタン40mg
  • テルミサルタン錠40mg 1回1錠 1日1回 朝食後 28日分

検査オーダー

[Lab-DM-Full] 糖尿病詳細セット
  • HbA1c, 血糖, 尿中微量アルブミン, 尿中ケトン体, CPR (外注)

💡 Dr.Advice

[早期発見] eGFRが下がる前に尿中微量アルブミン（外注）が出る。この時期にSGLT2やARBを開始すれば可逆的であるため、定期的な尿検査を怠るな。

📖 詳細解説​

病態生理​

  • **糖尿病性腎症（DKD）**は糖尿病による慢性腎臓病で、透析導入原因の第1位（約40%）
  • 古典的糖尿病性腎症（典型的DKD）:
    • 糸球体過剰濾過 → メサンギウム増殖・基底膜肥厚 → 結節性糸球体硬化症（Kimmelstiel-Wilson結節）
    • 進行: 微量アルブミン尿 → 顕性蛋白尿 → ネフローゼ → 腎不全
    • 網膜症を高率に合併（腎症があれば網膜症も進行していることが多い）
  • DKD（Diabetic Kidney Disease）の概念拡大:
    • 糖尿病患者にアルブミン尿を伴わないeGFR低下型CKDが多いことが判明
    • 高血圧性腎硬化症、虚血性腎症、加齢性変化が混在
    • 現在は「DKD」として広義に捉える
  • 進行因子: 高血糖、高血圧（最重要の修飾因子）、脂質異常症、喫煙、肥満、高蛋白食

診断基準・鑑別疾患​

  • DKDの病期分類（日本腎臓学会 CKD分類に準拠）:
    • 第1期（腎症前期）: 正常アルブミン尿（UACR 30mg/gCr未満）、eGFR正常
    • 第2期（早期腎症）: 微量アルブミン尿（UACR 30-299mg/gCr）
    • 第3期（顕性腎症）: 顕性蛋白尿（UACR 300mg/gCr以上）
    • 第4期（腎不全期）: eGFR 30mL/min未満
    • 第5期（透析療法期）
  • 糖尿病患者のCKDが全てDKDではない:
    • DKD以外を疑う所見: 急速なeGFR低下、活動性尿沈渣（赤血球円柱）、1型で罹病5年未満、蛋白尿なしの急速な腎機能低下
    • 鑑別: IgA腎症、膜性腎症、ANCA関連腎炎、コレステロール塞栓症
    • 腎生検の適応: 非典型的な経過、急速進行性、ネフローゼ症候群で網膜症なし

エビデンス・ガイドライン推奨​

  • RAS阻害薬（腎保護の基本薬）:
    • ACE阻害薬 or ARB: 微量アルブミン尿以上で投与推奨（推奨度A）
    • RENAAL試験、IDNT試験: ARBが顕性腎症の進行を有意に抑制
    • ACE阻害薬+ARBの併用は推奨されない（高K血症、急性腎障害リスク）
  • SGLT2阻害薬（新たな腎保護薬）:
    • DAPA-CKD試験（2020）: ダパグリフロジンがeGFR低下・腎不全・腎死を39%抑制。糖尿病の有無に関わらず有効
    • CREDENCE試験（2019）: カナグリフロジンが腎複合エンドポイントを30%抑制
    • EMPA-KIDNEY試験（2022）: エンパグリフロジンの腎保護効果を確認
    • eGFR 20以上で開始可能（開始後のeGFR一過性低下は正常な反応で中止不要）
  • フィネレノン（MR拮抗薬）:
    • FIDELIO-DKD/FIGARO-DKD試験: 非ステロイド型MR拮抗薬がDKDの腎・心血管イベントを有意に抑制
    • 2022年日本承認。処方開始条件: eGFR 25以上、血清K 5.0mEq/L未満。高K血症に注意しモニタリング必要
  • 血圧目標: 130/80mmHg未満（蛋白尿陽性例ではさらに低値も考慮）
  • 血糖管理: HbA1c 7.0%未満。DKDの進行抑制には良好な血糖コントロールが不可欠であるが、腎機能低下に伴い低血糖リスクが上昇するため、経口薬の選択とインスリン導入のタイミングが重要となる
    • eGFR 30未満: メトホルミン禁忌、SU薬減量・中止、DPP-4阻害薬は腎排泄型は減量（リナグリプチンは腎機能に関わらず用量調節不要）
    • 経口薬で血糖コントロールが不十分な場合、インスリン分泌能が低下している可能性がある。分泌能が枯渇した状態で高血糖が遷延すると、糸球体過剰濾過・AGEs蓄積・酸化ストレスを介して腎症が加速度的に進行するため、**CPI（C-peptide Index）**による分泌能評価が治療方針の判断に有用である（CPI 1.2以上: 経口薬継続可、0.8未満: インスリン導入が必要）
