[M81.9] 骨粗鬆症 / Osteoporosis

📋 主訴・所見・診察前対応

主訴・ROS

検診異常: 骨密度低下 / YAM値指摘 身長低下: なし / あり: 若い頃より ＿cm 低下 ；2cm以上はリスク 背部痛: なし / あり: いつの間にか骨折疑い

リスク因子(FRAX)

年齢: ＿歳, 性別: 女 / 男, 閉経年齢: ＿歳 早発閉経 / 卵巣摘出 骨折歴: なし / あり: 部位・時期 家族歴: なし / 大腿骨近位部骨折 / 脊椎圧迫骨折 生活歴: ステロイド使用 / 喫煙 / アルコール多飲

所見・検査

バイタル: 身長 ＿cm, 体重 ＿kg, BMI ＿ 姿勢: 正常 / 円背, 壁際直立時の後頭部・壁距離 0cm / >0cm

骨密度 (他施設DEXA法等の結果)

腰椎(L2-4): YAM ＿ %, T-score ＿ 大腿骨頚部: YAM ＿ %, T-score ＿

採血 (外注)

骨代謝マーカー

  • TRACP-5b(骨吸収), P1NP(骨形成), 25(OH)VitD
  • Ca, P, ALP, Cre, eGFR

診察前対応

採血 (外注)

[Lab-Ost-Marker] 骨代謝マーカー

💡 Dr.Advice

[身長低下] 若い頃より「2cm以上」縮んでいれば椎体骨折の可能性が高い。「4cm以上」ならほぼ確実である。痛みがなくても胸腰椎X線を撮像せよ。

[YAM値] 診断基準はYAM 70%未満（または80%未満＋危険因子）である。同年代比較(Age Match)ではなく、常に「若年成人平均(YAM)」を基準に判断せよ。

[設備制約] 当院にはDEXA（骨密度測定装置）がないため、確定診断および詳細な経過評価には近隣のDEXA保有施設へ検査を依頼せよ。

評価

  • 診断根拠: 脆弱性骨折の既往、または骨密度YAM値<70%。
  • 骨代謝回転: 高回転型 / 低回転型
  • 除外: 続発性骨粗鬆症（甲状腺機能亢進症、副甲状腺機能亢進症など）。

方針・処方

  • 治療戦略: 経口薬による治療および管理を中心に行う。自己注射製剤やデノスマブ（プラリア）が必要な場合は専門医へ紹介。

処方・処置​

メイン薬剤 (1つ選択)

[Rx-Ost-Bis-Ale] アレンドロン酸
  • アレンドロン酸錠35mg 1回1錠 週1回 起床時 4週分 — 標準BP製剤 [Rx-Ost-Bis-Min] ボナロン経口ゼリー
  • ボナロン経口ゼリー35mg 1回1包 週1回 起床時 4週分 — 嚥下不安時 [Rx-Ost-SERM-Baz] ビビアント
  • ビビアント錠20mg 1回1錠 1日1回 朝食後 28日分 — 若年閉経後

併用薬 (必要時追加)

[Rx-Ost-VitD-Eld] エディロール
  • エディロールカプセル0.75μg 1回1カプセル 1日1回 朝食後 28日分 — VitD不足・Ca吸収改善

紹介・連携

  • 歯科受診（口腔内チェック依頼）
  • 整形外科（専門的治療・注射製剤検討依頼）

指導・計画​

  • 患者指導: BP製剤は起床直後に服用し、30分間は横にならず飲食も避けること（食道潰瘍予防・吸収確保）。
  • 再診目安: 4週間後。

💡 Dr.Advice

[剤形選択] 錠剤の服用が困難、または起床時のルール遵守が難しい場合は、ゼリー製剤を選択せよ。

[治療期間・出口戦略] BP製剤は一般に3-5年を目安に継続。その後、骨密度と骨折リスクを再評価し、Drug Holiday（休薬）の可否を判断する。骨折歴あり・大腿骨頸部骨密度Tスコア<-2.5の高リスク例は5年以上継続を検討。自己判断での中断は骨折リスクを再上昇させるため、「いつまで飲むか」は必ず医師が判断すると患者に説明せよ。

[プラリア] 当院ではプラリア（デノスマブ）の取り扱いはありませんが、骨折リスクが非常に高い患者や、経口薬の継続が困難な患者には極めて有効な選択肢です。6ヶ月に1回の皮下注射で済むため、経口ビスホスホネート製剤が生活スタイルに合わない患者や、胃腸障害で内服できない患者の治療継続を守るメリットがあります。「内服の飲み忘れが多い」「胃の不快感で続けられない」「重度の骨密度低下（YAM <60%以下）」など、院内での経口薬管理に限界を感じる場合は、治療機会を損失させないよう、速やかにプラリア等の注射製剤が可能な整形外科・専門医へ紹介してバトンタッチしてください。プラリアは、投与を中止すると骨密度が急速に低下し、多発椎体骨折を起こす「リバウンド現象」のリスクがあります。紹介先を検討する際は、長期的な通院が可能か、あるいは中止時にビスホスホネート製剤へスイッチする出口戦略を共有できる施設を選定してください。

病態生理​

  • 骨粗鬆症は骨量減少+骨微細構造の劣化により骨脆弱性が亢進し、骨折リスクが増大した状態
  • 閉経後女性に好発（エストロゲン欠乏→骨吸収亢進）。70歳以上の女性の約50%が罹患
  • 骨折の好発部位: 椎体（最多、無症候性も多い）、大腿骨近位部（最も重篤、1年死亡率約20%）、橈骨遠位端、上腕骨近位部

診断基準・鑑別疾患​

  • 診断基準（日本骨粗鬆症学会 2012）: (1)脆弱性骨折あり→骨粗鬆症 (2)骨折なし+DXA法で腰椎/大腿骨頸部のBMDがYAM 70%以下→骨粗鬆症
  • FRAX: WHO開発の10年間骨折リスク評価ツール。治療介入の閾値判断に使用
  • 二次性骨粗鬆症の除外: 甲状腺機能亢進症、副甲状腺機能亢進症、クッシング症候群、多発性骨髄腫、ステロイド使用

エビデンス・ガイドライン推奨​

  • 薬物療法の第一選択:
    • ビスホスホネート: アレンドロネート35mg/週、リセドロネート75mg/月。破骨細胞を抑制。椎体骨折を約50%、大腿骨骨折を約40%減少
    • デノスマブ（プラリア）60mg 6ヶ月ごと皮下注: RANKL阻害。BP不耐例、腎機能低下例に有用。中止後の急速な骨量減少に注意（中止時にBPへの切り替え推奨）
  • 高リスク例: ロモソズマブ（イベニティ）210mg/月 12ヶ月間。骨形成促進+骨吸収抑制。重症骨粗鬆症に。虚血性心疾患・脳血管障害の既往がある患者では慎重投与（ARCH試験でアレンドロネート対照群と比較し心血管イベントリスクの増加が示唆）
  • テリパラチド（フォルテオ）: PTH製剤。毎日自己注射 or 週2回（テリボン）。骨形成促進。最大24ヶ月。重症例に
  • 基本: ビタミンD（エルデカルシトール0.75μg/日 or アルファカルシドール1μg/日）+カルシウム（食事+補充で1日800mg）
  • 転倒予防: 運動（バランス訓練、筋力強化）、環境整備、視力矯正、薬剤見直し（BZD等）
