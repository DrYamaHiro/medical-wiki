    服薬状況: ( 飲みきった / 中断[理由: ＿] / 副作用なし )
    結石: 排石確認 ( あり / なし ), 疼痛 ( 消失 / 残存 )

<O: 所見・検査>:
    再検尿結果: ( 膿尿消失 / 残存 ), 血尿: ( 消失 / 残存 )
    尿培養結果（提出した場合）: 起炎菌＿, 感受性＿

▶ Dr.Advice [培養結果]: 複雑性膀胱炎で培養を提出した場合、感受性に基づきde-escalationせよ。耐性パターンを確認し、不要に広域な抗菌薬は狭域に変更すること。
▶ Dr.Advice [治療失敗]: 5日間の治療で症状が改善しない場合は、①培養結果の再確認（耐性菌）、②複雑性への格上げ、③腎盂腎炎への進展を検討せよ。
▶ Dr.Advice [再発性]: 年3回以上の再発は予防的抗菌薬投与を検討（250-AP-01参照）。基礎因子の検索も忘れずに。
