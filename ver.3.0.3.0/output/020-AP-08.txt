[A37.0] 百日咳 (Pertussis)

<A: 評価>:
    ・診断根拠: 2週間以上続く発作性咳嗽 ＋ 以下のいずれか（吸気性笛声 whoop ／ 咳嗽後嘔吐 ／ 夜間悪化のスタッカート様連続咳）。 PCR 陽性（発症3週以内）／PT-IgG 抗体価上昇／培養陽性のいずれかで確定。
    ・病期: ( カタル期 1-2週 / 痙咳期 2-6週 / 回復期 ～2ヶ月 )
    ・重症度評価: ( 軽症: 成人で外来管理可 / 中等: 体力消耗・体重減少・睡眠障害 / 重症: 乳児・無呼吸・チアノーゼ・痙攣 → 即入院 )
    ・鑑別: マイコプラズマ／クラミジア肺炎、結核、咳喘息、後鼻漏症候群、GERD、ACE阻害薬関連咳嗽、異物吸引（小児）
    ・疫学: 5類感染症（全数届出、診断後7日以内）。家族内・施設内伝播あり。乳児への感染源は成人・思春期患者が大半（祖父母→孫）。

<P: 方針>:
    ・抗菌薬の主目的は **二次伝播阻止**（本人の症状改善効果は痙咳期以降では限定的）。
    ・抗菌薬適応: 発症3週以内 / 接触者 post-exposure prophylaxis (PEP) / 入院基準を満たす重症例。発症4週以降の慢性咳嗽単独例ではAMS 観点から慎重判断（PCR陽性でも症状改善効果は乏しく、伝播性も低下）。
    ・出席停止: 学校保健安全法 第二種感染症。特殊な咳が消失するまで、または有効抗菌薬投与後5日経過まで。
    ・就業制限: 医療・保育・教育従事者が発症した場合は、有効抗菌薬投与開始後5日経過または特殊咳嗽消失までは就業制限（学校保健安全法に準じる）。
    ・確定診断努力: 経験的マクロライド乱用回避のため、可能な限り PCR/抗体検査で確定後に投与。

    ▼ 処方・アクション (選択) ▼
    【第一選択 マクロライド系（成人）】
    [ID: Rx-Resp-Pert-CAM] クラリスロマイシン
    ・クラリスロマイシン錠200mg 1回1錠 1日2回 朝夕食後 7日分 ；JAID/JSC 推奨。妊婦は原則回避（エリスロマイシン優先）

    [ID: Rx-Resp-Pert-AZM] アジスロマイシン(成人)
    ・ジスロマック錠250mg 1回2錠 1日1回 3日分 ；服薬コンプライアンス良好。マクロライド耐性マイコプラズマ流行地域でも百日咳には有効

    【第一選択 マクロライド系（妊婦・授乳婦・生後1ヶ月未満児）】
    [ID: Rx-Resp-Pert-AZM-Preg] アジスロマイシン(妊婦・授乳婦)
    ・ジスロマック錠250mg 1回2錠 1日1回 3日分 ；CDC 2017 妊婦・授乳婦の第一選択。生後1ヶ月未満児へもAZM推奨（EMは新生児幽門狭窄症リスク）

    【代替 マクロライド系（成人非妊婦・コスト・実績重視時）】
    [ID: Rx-Resp-Pert-EM] エリスロマイシン
    ・エリスロマイシン錠200mg 1回1錠 1日4回 毎食後・就寝前 14日分 ；800mg/日（添付文書: 成人800-1200mg/日 分4-6 範囲内）。非妊婦の代替。妊婦・授乳婦・生後1ヶ月未満児には原則使用しない（cholestatic hepatitis・新生児幽門狭窄症リスク）。消化器症状で脱落多い。estolate塩は妊婦肝毒性で禁忌、日本のエリスロシンはstearate

    【代替 マクロライド不耐／耐性疑い】
    [ID: Rx-Resp-Pert-ST] ST合剤
    ・バクタ配合錠 1回2錠 1日2回 朝夕食後 14日分 ；百日咳は保険適応外（参考処方）。マクロライド不耐・耐性疑い時のみ。妊婦・新生児・G6PD欠損禁忌、葉酸拮抗作用に注意。ワルファリン・経口血糖降下薬と相互作用

    【小児用量（参考、体重別計算）】
    ※ 小児はマスタ Rx-Ped-Pert-* 参照（マスタ未登録 → 04-MASTER-THERAPEUTIC-ITEMS.txt への追加要）。AZM Day1: 10mg/kg, Day2-5: 5mg/kg／CAM 15mg/kg/日 分2 × 7日。乳児は入院適応で原則紹介。

    【症状緩和（補助）】
    [ID: Rx-Resp-Cough-Tulob] ツロブテロールテープ2mg
    ・ツロブテロールテープ2mg 1回1枚 1日1回 胸部または背部に貼付 7日分 ；気管支拡張で咳発作軽減
    [ID: Rx-Gen-Cold-Med] メジコン単剤
    ・メジコン錠15mg 1回2錠 1日3回 毎食後 7日分 ；中枢性鎮咳。発作性咳嗽軽減目的

    【入院適応の判定（即紹介）】
    [ID: Doc-Gen-Referral] 診療情報提供書
    ・紹介先: 小児科入院施設（乳児・新生児）／成人の場合は呼吸不全・脱水・痙攣を伴う重症例
    ・基準: 生後6ヶ月未満／無呼吸・チアノーゼ／経口摂取不能による脱水／痙攣・脳症・肺炎合併

    【検査】
    [ID: Lab-Resp-Pert-PCR] 百日咳 PCR (LAMP法、外注)
    ・発症3-4週以内に最も感度が高い。鼻咽頭スワブで採取
    [ID: Lab-Resp-Pert-IgG] 抗百日咳毒素IgG抗体 (外注)
    ・発症2週以降で上昇。キット・施設により基準値異なる（デンカ生研ELISA 等で抗PT-IgG ≥100 EU/mL を目安、ペア血清で4倍上昇がより確実）。1年以内のDPT/Tdap 接種歴・既感染歴があると解釈困難
    [ID: Lab-Gen-CBC_CRP] CBC + CRP
    ・乳幼児では著明なリンパ球増多が特徴。CRPは正常〜軽度上昇

    【行政対応】
    [ID: Doc-Gen-Notification] 感染症発生届
    ・5類感染症「百日咳」全数届出。診断後 7日以内に保健所へ提出（2018年改正）
    ・医療・保育・教育従事者が発症した患者の場合: 雇用主への診断書発行と就業制限期間（抗菌薬投与5日完了 or 特殊咳消失まで）の明記

    【接触者対応 (Post-Exposure Prophylaxis)】
    ・対象: 同居家族・濃厚接触者で「①生後12ヶ月未満の乳児」「②妊娠後期妊婦」「③乳児に接触機会のある医療・保育従事者」のいずれかに該当する者。一般成人・思春期接触者は症状出現時対応で十分。
    ・薬剤: 確定診断と同じレジメン（CAM/AZM/EM）。用量・期間も同一。
    ・接触後 21 日を超えると PEP 効果は限定的。

▶ Dr.Advice [RedFlag]: 生後6ヶ月未満の乳児は無呼吸・チアノーゼ・突然死リスクあり。咳嗽がなくても無呼吸のみで来院することがある（atypical presentation）。即小児科入院施設へ。

▶ Dr.Advice [鑑別]: 成人の「2週間以上続く咳」では百日咳を常に鑑別に。マイコプラズマ・クラミジア肺炎・咳喘息・GERD・後鼻漏・ACE阻害薬関連咳嗽との鑑別。家族内に百日咳患者・乳児がいる場合は積極的に検査を。

▶ Dr.Advice [AMS / 抗菌薬適正使用]: マクロライドは確定診断（PCR/抗体）または強い臨床的疑い（曝露歴 + 典型症状）に限定。発症4週以降の慢性咳嗽のみで PCR 陰性なら抗菌薬は原則投与しない（症状改善効果なし、耐性誘導リスクのみ）。経験的処方は院内・施設内アウトブレイク時に限定。

▶ Dr.Advice [届出義務]: 5類感染症（全数把握）。診断後 7日以内に保健所へ届出義務（2018年改正）。検査陽性でなくとも臨床診断で届出可。診療情報提供書とは別書類。

▶ Dr.Advice [予防]: 三種混合（DPT-IPV / DTaP）は乳児期4回接種で抗体獲得するが、成人期までに減衰。日本では Tdap (Boostrix®) の成人定期接種は未承認だが、自費で接種可。家族に新生児ができる祖父母世代・周産期妊婦には個別勧奨を検討。妊婦の Tdap 接種（妊娠27-36週）は新生児への移行抗体で重症化予防に有効（米国推奨）。

▶ Dr.Advice [薬剤選択]: マクロライドは CAM 7日 / AZM 3日 / EM 14日 と選択肢あり。コンプライアンス重視・妊婦・授乳婦・生後1ヶ月未満児なら AZM、コスト・実績なら CAM、AZM不耐の非妊婦には EM。マクロライド耐性は百日咳ではまだ稀で、第一選択の信頼性は高い（マイコプラズマ耐性と混同しない）。

▶ Dr.Advice [マクロライド相互作用]: CAM/EM は CYP3A4 阻害により以下と相互作用 — ①スタチン (シンバ・アトルバ) → 横紋筋融解症 (中止または減量), ②ワルファリン → INR上昇 (投与中はINRモニタ), ③カルバマゼピン・テオフィリン・タクロリムス → 血中濃度上昇, ④コルヒチン → 致死的中毒 (腎肝障害例で禁忌), ⑤QT延長薬 (シタロプラム・ジゴキシン・抗不整脈薬) との併用で TdP 増悪, ⑥重症筋無力症で症状増悪 (慎重投与)。AZM は相互作用比較的少ないが QT延長は同様。高齢者・多剤併用例では併用薬の見直しを必ず行う。

▶ Dr.Advice [設備制約]: 当院では PCR は外注（結果まで 3-5日）。臨床的疑いが強ければ検査結果待ちで治療開始可。培養は感度低く臨床利用は限定的。乳児疑いは検査せず即紹介でよい。
