<h3 className="soap-s">主訴・ROS</h3>

**不眠のタイプ**

入眠障害: 30分以上 / 1時間以上 かかる
中途覚醒: 1回 / 2回以上 / その後眠れない
早朝覚醒: 起きたい時間より2時間以上早い
熟眠障害: ぐっすり眠った感じがしない

**精神・身体症状**

気分: 落ち込み / 不安感 / イライラ / 意欲低下
身体: 動悸 / 息苦しさ / 喉のつかえ / 頭痛
食欲: 低下 / 過食, 体重変化: ＿kg

**生活習慣・背景**

就床時刻: ＿時、起床時刻: ＿時
昼寝: なし / あり ＿分
嗜好品: カフェイン＿杯 / エナジードリンク / 寝酒あり
ストレス要因: 仕事 / 家庭 / 介護 / 金銭 / 特になし

<h3 className="soap-o">所見・検査</h3>

表情: 暗い / 不安げ / 緊張 / 涙ぐむ
身体所見: 甲状腺腫大 有 / 無

**除外検査 (外注)**

甲状腺スクリーニング
- TSH, FT3, FT4 ；機能亢進/低下の除外
末梢血一般(CBC)
- Hb ；貧血の除外

**除外検査 (外注)**

- <span className="med-id">[Lab-Endo-Thy-Screen]</span> 甲状腺スクリーニング

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[睡眠衛生]** 薬を出す前に「カフェインは午後控える」「寝酒はやめる（中途覚醒の原因）」「眠くなるまで布団に入らない」といった睡眠衛生指導を行うことが、薬物療法の効果を高める。
>
> **[うつ・双極性除外]** 不眠は「うつ病」の必発症状である。「気分が沈む」「死にたいと思う」などの精神症状がないか必ず確認せよ。また、過去に「異常に元気だった時期（躁）」がないかも確認が必要（抗うつ薬禁忌の可能性）。
>
> **[隠れうつ病 (2質問法)]** 「眠れない」はうつ病の必発症状である。以下の2点を必ず確認せよ（感度96%）。
>
> **[自殺リスク (死ぬ病気)]** 精神疾患は、癌や心筋梗塞と同様に「放置すれば死ぬ病気（自殺）」である。「消えてしまいたい、死にたいと思うことはありますか？」と直球で聞くことを躊躇うな。聞くことが自殺を誘発することはない。計画性がある場合は即座に専門医へ送れ。
>
> **[双極性障害 (躁転注意)]** うつ状態の患者に抗うつ薬を投与して「躁転（躁状態）」させると、人生を破壊する（散財、社会的信用失墜）リスクがある。「過去に異常に元気で、眠らなくても平気だった時期はないか」を必ず確認し、疑わしければ抗うつ薬には手を出さず専門医へ送れ。
>
> **[身体疾患の除外]** 「動悸・不眠」は甲状腺機能亢進症、「だるさ・うつ」は甲状腺機能低下症や貧血、「夜眠れない」は睡眠時無呼吸(SAS)やむずむず脚(RLS)の可能性がある。これらを見逃して向精神薬を出しても治らない。
>
> **[オンライン初診処方制限]** オンライン診療において、お薬手帳、健診結果、紹介状等で基礎疾患が把握できない初診患者の場合、処方は「7日分を上限」とせよ。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 仕事や学業など多数の出来事に対する過剰な不安と心配が6ヶ月以上続く。
- **身体症状:** 落ち着きがない、疲れやすい、集中困難、易怒性、筋肉の緊張、睡眠障害。
- **コントロール不能:** 心配を止めることができない。

<h3 className="soap-p">方針・処方</h3>

- SSRIによるセロトニン調整（第一選択）。
- 抗不安薬（ベンゾジアゼピン系）は即効性があるが、依存リスクのため「ここぞという時」の頓用に留めるか、タンドスピロン（セディール）等の非依存性薬物を併用。
- 漢方薬によるアプローチ。

#### 処方・処置 (選択)

**GAD治療セット**

- <span className="med-id">[Rx-Psych-Dep-Esc]</span> レクサプロ
- レクサプロ錠10mg 1回1錠 1日1回 夕食後 28日分 *— SSRI*
- <span className="med-id">[Rx-Psych-Anx-Sed]</span> セディール
- セディール錠10mg 1回1錠 1日3回 毎食後 28日分 *— 非BZ系抗不安薬*
- <span className="med-id">[Rx-Psych-Anx-Loz]</span> ワイパックス
- ワイパックス錠0.5mg 1回1錠 不安時頓用 10回分
- <span className="med-id">[Rx-Kampo-012]</span> 柴胡加竜骨牡蛎湯(12)
- ツムラ柴胡加竜骨牡蛎湯(12)エキス顆粒 2.5g 1回1包 1日3回 食前 28日分 *— 動悸・不眠*
- <span className="med-id">[Rx-Kampo-137]</span> 加味帰脾湯(137)
- ツムラ加味帰脾湯(137)エキス顆粒 2.5g 1回1包 1日3回 食前 28日分 *— 貧血・不安*

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[BZ系依存]** 「ずっと不安だから」とベンゾジアゼピン（ソラナックス、デパス等）を漫然と定期内服させると、耐性がつき量が増え、止められなくなる（常用量依存）。ベースはSSRIで作るべきである。
>
> **[筋緊張]** GAD患者は常に緊張しており、激しい肩こりや頭痛を伴うことが多い。「肩の力を抜く」リラクゼーション法や、筋弛緩薬・漢方薬の併用が奏功する場合がある。

## 📖 詳細解説

### 病態生理

- **GAD（全般性不安障害）**は多領域にわたる過剰で持続的な心配・不安を特徴とする不安障害
- 生涯有病率: 約5%。中年女性に好発。うつ病の合併率が高い（約60%）
- **病態**: GABA系の機能低下、セロトニン系の異常、扁桃体の過活動。「心配の心配」（メタ認知的な問題）が特徴

### 診断基準・鑑別疾患

- **DSM-5診断基準**: 多数の出来事に対する過剰な不安と心配が6ヶ月以上持続+以下の6症状中3つ以上:
  落ち着きのなさ、疲れやすさ、集中困難、易刺激性、筋緊張、睡眠障害
- **鑑別**: 甲状腺機能亢進症、カフェイン過剰摂取、うつ病（重複多い）、パニック障害、適応障害、身体症状症

### GAD-7スクリーニング

- **[GAD-7](../Calculators/gad7)**は7項目の自記式質問票（各0-3点、計0-21点）。カットオフ10点で感度89%・特異度82%
- **重症度分類:** 0-4点: 正常、5-9点: 軽度、10-14点: 中等度、15-21点: 重度
- **2項目版（GAD-2）:** 最初の2問のみ。カットオフ3点で感度86%・特異度83%。プライマリケアのスクリーニングに最適
- **用途:** 初回スクリーニング、治療効果のモニタリング（2-4週ごとに再評価）

### エビデンス・ガイドライン推奨

- **SSRI/SNRI**が第一選択: エスシタロプラム10-20mg、デュロキセチン30-60mg。効果発現に2-4週間
  - **エスシタロプラム（レクサプロ）RCTデータ:** Baldwinら(2005) 8週RCTでHAM-A改善率がプラセボ比-3.0点（p値 0.001未満）。反応率（HAM-A 50%以上改善）: 10mg群68% vs プラセボ41%
  - **デュロキセチン（サインバルタ）RCTデータ:** Rottaら(2012) メタ解析でHAM-A改善が-3.5点（95%CI: -4.3 to -2.7）。60-120mg/日。NNT=5-6
  - **セルトラリン（ジェイゾロフト）:** 50-200mg/日。GADに対するRCTでHAM-A反応率56% vs プラセボ36%。日本でGADに保険適応あり
  - **パロキセチン（パキシル）:** 20-50mg/日。HAM-A反応率62% vs プラセボ46%（Rickelsら 2003）
  - **ベンラファキシンXR:** 海外でGADに対するエビデンス豊富。75-225mg/日。日本では「イフェクサーSR」としてうつ病適応のみ
- **プレガバリン（リリカ）**: GADに対する有効性のエビデンスあり（日本では適応外）。即効性がある。150-600mg/日でHAM-A改善がプラセボ比-2.8点
- **タンドスピロン（セディール）30-60mg/日**: 5-HT1A部分アゴニスト。日本で使用可能。依存性なし。効果発現に2-4週間
- **ベンゾジアゼピン**: 即効性があるが依存リスクのため短期間（2-4週間）に限定。長期使用時のNNH（依存）=約5
- **認知行動療法**: 心配への対処スキル獲得。効果サイズ（Hedges' g）=1.0-1.3。薬物療法と同等以上の長期効果
- **治療効果判定:** HAM-Aスコア7点以下で寛解、50%以上改善で反応と定義。8-12週で判定し、無効なら変薬を検討
