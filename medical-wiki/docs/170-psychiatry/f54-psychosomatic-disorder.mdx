<h3 className="soap-s">主訴・ROS</h3>

**不眠のタイプ**

入眠障害: 30分以上 / 1時間以上 かかる
中途覚醒: 1回 / 2回以上 / その後眠れない
早朝覚醒: 起きたい時間より2時間以上早い
熟眠障害: ぐっすり眠った感じがしない

**精神・身体症状**

気分: 落ち込み / 不安感 / イライラ / 意欲低下
身体: 動悸 / 息苦しさ / 喉のつかえ / 頭痛
食欲: 低下 / 過食, 体重変化: ＿kg

**生活習慣・背景**

就床時刻: ＿時、起床時刻: ＿時
昼寝: なし / あり ＿分
嗜好品: カフェイン＿杯 / エナジードリンク / 寝酒あり
ストレス要因: 仕事 / 家庭 / 介護 / 金銭 / 特になし

<h3 className="soap-o">所見・検査</h3>

表情: 暗い / 不安げ / 緊張 / 涙ぐむ
身体所見: 甲状腺腫大 有 / 無

**除外検査 (外注)**

甲状腺スクリーニング
- TSH, FT3, FT4 ；機能亢進/低下の除外
末梢血一般(CBC)
- Hb ；貧血の除外

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[睡眠衛生]** 薬を出す前に「カフェインは午後控える」「寝酒はやめる（中途覚醒の原因）」「眠くなるまで布団に入らない」といった睡眠衛生指導を行うことが、薬物療法の効果を高める。
>
> **[うつ・双極性除外]** 不眠は「うつ病」の必発症状である。「気分が沈む」「死にたいと思う」などの精神症状がないか必ず確認せよ。また、過去に「異常に元気だった時期（躁）」がないかも確認が必要（抗うつ薬禁忌の可能性）。
>
> **[隠れうつ病 (2質問法)]** 「眠れない」はうつ病の必発症状である。以下の2点を必ず確認せよ（感度96%）。
>
> **[自殺リスク (死ぬ病気)]** 精神疾患は、癌や心筋梗塞と同様に「放置すれば死ぬ病気（自殺）」である。「消えてしまいたい、死にたいと思うことはありますか？」と直球で聞くことを躊躇うな。聞くことが自殺を誘発することはない。計画性がある場合は即座に専門医へ送れ。
>
> **[双極性障害 (躁転注意)]** うつ状態の患者に抗うつ薬を投与して「躁転（躁状態）」させると、人生を破壊する（散財、社会的信用失墜）リスクがある。「過去に異常に元気で、眠らなくても平気だった時期はないか」を必ず確認し、疑わしければ抗うつ薬には手を出さず専門医へ送れ。
>
> **[身体疾患の除外]** 「動悸・不眠」は甲状腺機能亢進症、「だるさ・うつ」は甲状腺機能低下症や貧血、「夜眠れない」は睡眠時無呼吸(SAS)やむずむず脚(RLS)の可能性がある。これらを見逃して向精神薬を出しても治らない。
>
> **[オンライン初診処方制限]** オンライン診療において、お薬手帳、健診結果、紹介状等で基礎疾患が把握できない初診患者の場合、処方は「7日分を上限」とせよ。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 身体疾患（胃潰瘍、喘息、IBS、頭痛等）の発症・経過に心理社会的ストレスが密接に関与している病態。
- **アレキシサイミア（失感情症）:** 自分のストレスに気づいていないことが多い。

<h3 className="soap-p">方針・処方</h3>

- 身体症状の治療（対症療法）＋ ストレスケア。
- 心療内科的アプローチ（漢方薬、少量の抗うつ薬/抗不安薬）。

## 📖 詳細解説

### 病態生理

- **心身症**は身体疾患の中で、その発症や経過に心理社会的因子が密接に関与するもの（日本心身医学会の定義）
- 心身症は「疾患名」ではなく「病態名」。例: 「心身症としての過敏性腸症候群」のように使用
- **ストレス応答**: ストレス→視床下部-下垂体-副腎系（HPA軸）活性化+自律神経系異常→各臓器の機能障害
- **代表的な心身症**: 過敏性腸症候群、機能性ディスペプシア、気管支喘息、アトピー性皮膚炎、緊張型頭痛、本態性高血圧の一部

### 診断基準・鑑別疾患

- **心身症の診断要件**: (1) 器質的・機能的身体疾患が存在 (2) 心理社会的因子が発症・増悪に密接に関与 (3) 神経症やうつ病などの精神疾患を除外
- **アレキシサイミア（失感情症）**: 自身の感情を認識・表現できない特性。心身症患者に高頻度
- **鑑別**: 身体症状症（旧: 身体表現性障害）、うつ病の身体症状、不安障害の身体症状

### 機能性ディスペプシア（FD）とRome IV基準

- **Rome IV基準（2016年）によるFDの診断:**
  - (1) 以下の1つ以上: 心窩部痛、心窩部灼熱感、食後のもたれ感、早期飽満感
  - (2) 症状を説明できる器質的疾患がない（上部消化管内視鏡で除外）
  - (3) 診断前6ヶ月以上前から症状があり、直近3ヶ月間で基準を満たす
- **サブタイプ分類:**
  - **食後愁訴症候群（PDS）:** 食後のもたれ感、早期飽満感が主体
  - **心窩部痛症候群（EPS）:** 心窩部痛・灼熱感が主体
- **IBSとの重複:** FD患者の約30-50%がIBSを合併

### エビデンス・ガイドライン推奨

- **治療の基本**: 身体疾患の適切な治療+心理社会的アプローチの両輪
- **心理療法**: 自律訓練法（リラクゼーション）、認知行動療法、交流分析
- **自律訓練法の標準手順（Schultzの6段階）:**
  1. 四肢の重感練習:「両腕両脚が重たい」
  2. 四肢の温感練習:「両腕両脚が温かい」
  3. 心臓調整練習:「心臓が規則正しく打っている」
  4. 呼吸調整練習:「楽に呼吸している」
  5. 腹部温感練習:「お腹が温かい」
  6. 額部涼感練習:「額が涼しい」
  - 1日2-3回、各3-5分間。消去動作（手を握り開き→深呼吸→開眼）を必ず行う
  - **効果:** メタ解析で不安・緊張・身体症状に中等度の効果サイズ（d=0.5-0.7）
- **薬物療法**: 身体疾患に対する治療薬+補助的に抗不安薬・抗うつ薬
  - タンドスピロン（セディール）: 不安を伴う心身症に
  - SSRI/SNRI: 慢性疼痛、機能性消化管障害に有効
  - **アコチアミド（アコファイド）100mg 1日3回 食前:** FD（PDS型）に対して日本で承認された初のプロキネティクス。Phase III試験（Matsuedaら 2012, Gut）で食後膨満感・早期飽満感の消失率: アコチアミド群52% vs プラセボ35%（p値 0.001未満）。NNT=6。コリンエステラーゼ阻害による胃運動促進作用
  - 漢方薬: 半夏厚朴湯（のどの違和感・不安）、加味逍遙散（女性の自律神経失調）、補中益気湯（倦怠感）、六君子湯（FDに保険適用あり、グレリン分泌促進）
- **生活指導**: ストレスマネジメント、適度な運動、十分な睡眠
