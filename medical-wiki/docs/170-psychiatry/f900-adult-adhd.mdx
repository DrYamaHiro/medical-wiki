<h3 className="soap-s">主訴・ROS</h3>

**不眠のタイプ**

入眠障害: 30分以上 / 1時間以上 かかる
中途覚醒: 1回 / 2回以上 / その後眠れない
早朝覚醒: 起きたい時間より2時間以上早い
熟眠障害: ぐっすり眠った感じがしない

**精神・身体症状**

気分: 落ち込み / 不安感 / イライラ / 意欲低下
身体: 動悸 / 息苦しさ / 喉のつかえ / 頭痛
食欲: 低下 / 過食, 体重変化: ＿kg

**生活習慣・背景**

就床時刻: ＿時、起床時刻: ＿時
昼寝: なし / あり ＿分
嗜好品: カフェイン＿杯 / エナジードリンク / 寝酒あり
ストレス要因: 仕事 / 家庭 / 介護 / 金銭 / 特になし

<h3 className="soap-o">所見・検査</h3>

表情: 暗い / 不安げ / 緊張 / 涙ぐむ
身体所見: 甲状腺腫大 有 / 無

**除外検査 (外注)**

甲状腺スクリーニング
- TSH, FT3, FT4 ；機能亢進/低下の除外
末梢血一般(CBC)
- Hb ；貧血の除外

**除外検査 (外注)**

<span className="med-id">[Lab-Endo-Thy-Screen] 甲状腺スクリーニング</span>
<span className="med-id">[Lab-Gen-CBC_CRP] 末梢血一般(CBC)</span>

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[睡眠衛生]** 薬を出す前に「カフェインは午後控える」「寝酒はやめる（中途覚醒の原因）」「眠くなるまで布団に入らない」といった睡眠衛生指導を行うことが、薬物療法の効果を高める。
>
> **[うつ・双極性除外]** 不眠は「うつ病」の必発症状である。「気分が沈む」「死にたいと思う」などの精神症状がないか必ず確認せよ。また、過去に「異常に元気だった時期（躁）」がないかも確認が必要（抗うつ薬禁忌の可能性）。
>
> **[隠れうつ病 (2質問法)]** 「眠れない」はうつ病の必発症状である。以下の2点を必ず確認せよ（感度96%）。
>
> **[自殺リスク (死ぬ病気)]** 精神疾患は、癌や心筋梗塞と同様に「放置すれば死ぬ病気（自殺）」である。「消えてしまいたい、死にたいと思うことはありますか？」と直球で聞くことを躊躇うな。聞くことが自殺を誘発することはない。計画性がある場合は即座に専門医へ送れ。
>
> **[双極性障害 (躁転注意)]** うつ状態の患者に抗うつ薬を投与して「躁転（躁状態）」させると、人生を破壊する（散財、社会的信用失墜）リスクがある。「過去に異常に元気で、眠らなくても平気だった時期はないか」を必ず確認し、疑わしければ抗うつ薬には手を出さず専門医へ送れ。
>
> **[身体疾患の除外]** 「動悸・不眠」は甲状腺機能亢進症、「だるさ・うつ」は甲状腺機能低下症や貧血、「夜眠れない」は睡眠時無呼吸(SAS)やむずむず脚(RLS)の可能性がある。これらを見逃して向精神薬を出しても治らない。
>
> **[オンライン初診処方制限]** オンライン診療において、お薬手帳、健診結果、紹介状等で基礎疾患が把握できない初診患者の場合、処方は「7日分を上限」とせよ。

<h3 className="soap-a">評価</h3>

- **主訴:** 不注意（忘れ物、ミス）、多動・衝動性（落ち着きがない）による生活・仕事上の支障。
- **スクリーニング:** ASRS-v1.1 Part A 4点以上で陽性 / 陰性
- **成育歴:** 12歳以前からの症状 有 / 無 / 母子手帳・通知表で確認
- **除外:** うつ病、適応障害、睡眠障害、甲状腺機能異常。

<h3 className="soap-p">方針・処方</h3>

- 【原則紹介】：確定診断および治療導入（コンサータ等）は専門医にて行う。
- 当院ではスクリーニング検査と紹介状作成までを行う。
- 二次障害（うつ・不安）がある場合は、そちらの対症療法を先行させる場合がある。

#### 処方・処置 (選択)

**検査・書類**

<span className="med-id">[Doc-Check-ASRS] ASRS-v1.1 (成人ADHD検査用紙)</span>
<span className="med-id">[Doc-Gen-Referral] 診療情報提供書</span>
- **紹介先:** 精神科・心療内科専門医（ASRS結果添付）

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[診断の限界]** ADHDの診断には、現在の症状だけでなく「幼少期からの持続」の証明や、詳細な除外診断が必須である。プライマリケアの短い診察時間で安易に診断名をつけず、「疑い」として専門医へ委ねるのが安全である。
>
> **[ASRS]** Part Aの6問中4問以上が「頻繁」であればADHDの可能性が高い。あくまでスクリーニングであり診断ではないことを説明せよ。
>
> **[診断の慎重さ]** 「仕事がうまくいかない」＝ADHDとは限らない。うつ病や睡眠不足、適応障害でも不注意は生じる。安易に診断せず、成育歴（子供の頃はどうだったか）を丁寧に聴取せよ。

## 📖 詳細解説

### 病態生理

- **成人ADHD**は小児期から持続する注意欠如・多動性・衝動性を特徴とする神経発達障害
- 成人有病率: 約2-5%。小児ADHDの約60%が成人期にも症状が持続
- **病態**: 前頭前皮質-線条体回路のドパミン/ノルアドレナリン機能障害。実行機能（計画、組織化、時間管理）の障害が中核
- **成人での特徴**: 多動は目立たなくなるが、不注意（物忘れ、期限を守れない）と衝動性（衝動買い、転職を繰り返す）が問題となりやすい

### 診断基準・鑑別疾患

- **DSM-5診断基準（成人 17歳以上）:** 不注意9項目 and/or 多動・衝動性9項目のうち**5つ以上**が6ヶ月以上持続（小児は6つ以上）
- **不注意症状9項目:**
  1. 細部に注意を払えず、不注意なミスをする
  2. 課題や活動中に注意を持続することが困難
  3. 直接話しかけられた時に聞いていないように見える
  4. 指示に従えず業務を完了できない（反抗・理解不能ではなく）
  5. 課題や活動を順序立てることが困難
  6. 精神的努力の持続を要する課題を避ける・嫌がる
  7. 活動に必要なものをしばしばなくす
  8. 外的刺激によってすぐに気が散る
  9. 日常的な活動をしばしば忘れる
- **多動・衝動性症状9項目:**
  1. 手足をそわそわ動かす、座っていてもじもじする
  2. 座っていることが求められる状況で席を離れる
  3. 不適切な状況で走り回ったり高いところに登ったりする（成人では落ち着かない感覚）
  4. 静かに余暇活動に従事することが困難
  5. じっとしていられない、エンジンで動かされているように感じる
  6. しゃべりすぎる
  7. 質問が終わる前に答え始める
  8. 順番を待つことが困難
  9. 他人を妨害し邪魔する（会話や活動に割り込む）
- **追加要件:** 12歳以前に症状が存在 + 2つ以上の場面（職場・家庭等）で障害 + 社会的・職業的機能に臨床的に明確な障害
- **成人での診断の難しさ**: 小児期の情報収集が困難、他の精神疾患との合併が多い
- **成人期の鑑別疾患（重要）:**
  - **うつ病:** 集中困難、意欲低下はADHDと重複。エピソード性（ADHD は持続的）で鑑別
  - **双極性障害:** 躁期の多動・衝動性がADHDに類似。エピソード性で鑑別
  - **不安障害:** 落ち着きのなさ、集中困難が重複。不安の主題の有無で鑑別
  - **ASD（自閉スペクトラム症）:** 注意の偏り、社会的困難が重複。約30-50%が合併
  - **睡眠障害:** 不注意・日中の眠気。OSASやRLSの除外が必要
  - **甲状腺機能亢進症:** 落ち着きのなさ、集中困難。TSHで除外
  - **物質使用障害:** 合併率約25%。薬物の影響を除外後に評価
- **鑑別・合併**: 合併率は約60-80%と極めて高い
- **当院での役割**: 疑い例のスクリーニング（ASRS: Adult ADHD Self-Report Scale）と専門医への紹介

### エビデンス・ガイドライン推奨

- **薬物療法**（専門医による処方が原則）:
  - **メチルフェニデート徐放錠（コンサータ）18-72mg/日:** 中枢刺激薬。登録医制度（流通管理: ADHD適正流通管理システム）。効果サイズ d=0.5-0.7（成人RCTメタ解析）。18mgから開始、1-2週ごとに18mgずつ増量。最大72mg/日。心拍増加・食欲低下に注意
  - **アトモキセチン（ストラテラ）40-120mg/日:** 非刺激薬。NRI。乱用リスクなし。効果サイズ d=0.3-0.5。40mgから開始、最低2週間後に80mg、さらに4週後以降120mgまで増量可。効果発現に4-8週間。肝障害に注意（まれだが重篤）
  - **グアンファシン（インチュニブ）2-6mg/日:** alpha2Aアドレナリン受容体作動薬。多動・衝動性に有効。効果サイズ d=0.2-0.4。2mgから開始、1週間以上あけて1mgずつ増量。眠気・血圧低下に注意。急な中止で血圧上昇リスク
  - **リスデキサンフェタミン（ビバンセ）20-70mg/日:** プロドラッグ型刺激薬。効果サイズ d=0.5-0.8。30mgから開始、1週間ごとに10-20mgずつ増量。1日1回朝投与。登録医制度あり
- **非薬物療法**: 環境調整（タスク管理ツール、メモ活用、タイマー使用）、認知行動療法（成人ADHDに対する効果サイズ d=0.7）、コーチング
- **紹介基準**: ADHDが疑われる場合は精神科・発達外来への紹介が推奨。診断は専門的評価が必要
