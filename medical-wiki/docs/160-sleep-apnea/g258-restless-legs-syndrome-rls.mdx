**睡眠関連**

いびき: 指摘あり / 自分の音で起きる / 動画で確認

中途覚醒: ＿ 回/晩, 起床時の症状: 頭痛 / 口渇 / 熟眠感欠如

脚の不快感: 夕方～夜間に増悪 / じっとしていると悪化 / 動くと楽になる
感覚: ムズムズする / 虫が這うよう / 痛痒い

睡眠時間: ＿時間 (就床 ＿:＿ / 起床 ＿:＿)
体重変化: ＿kg増/＿年
既往歴: 高血圧 / 糖尿病 / 心房細動 / 脳卒中
職業: 運転業務 / 高所作業 / 精密作業 ；事故リスク確認

携帯型睡眠時無呼吸検査（簡易検査）

<h3 className="soap-a">評価</h3>

- **診断根拠:** URGEの4徴候を満たす。
U (Urge): 脚を動かしたい衝動
R (Rest): 安静時に悪化
G (Gyration): 動かすと軽快
E (Evening): 夕方～夜間に増悪
- **検査:** フェリチン値 ＿ ng/mL &lt;50 は鉄欠乏として治療対象
- **原因:** 特発性 / 鉄欠乏性 / 腎不全 / 薬剤性 / 妊娠

<h3 className="soap-p">方針・処方</h3>

- 治療戦略:
- 原因治療（鉄欠乏なら鉄剤、原因薬の中止）。
- 非薬物療法（カフェイン・アルコール制限、マッサージ）。
- 薬物療法（ドパミンアゴニスト、α2δリガンド）。

#### 処方 (選択)

**鉄欠乏治療 (フェリチン&lt;50)**

- <span className="med-id">[Rx-Hem-Fe-Cit]</span> フェロ・グラデュメット
- フェロ・グラデュメット錠105mg 1回1錠 1日1回 朝食後 28日分

**RLS治療薬**

- <span className="med-id">[Rx-Neuro-RLS-Pra]</span> ビ・シフロール
- ビ・シフロール錠0.125mg 1回1錠 1日1回 夕食後 28日分 *— ドパミン作動薬*

- <span className="med-id">[Rx-Neuro-RLS-Gab]</span> ガバペン
- ガバペン錠200mg 1回1錠 1日1回 夕食後 28日分 *— α2δリガンド*

- <span className="med-id">[Rx-Neuro-RLS-Clo]</span> クロナゼパム
- クロナゼパム錠0.5mg 1回1錠 1日1回 就寝前 28日分 *— BZ系・頓用*

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[鉄補充の重要性]** フェリチン&lt;50ng/mLであれば、貧血（Hb低下）がなくても脳内鉄欠乏により症状が出る。鉄剤投与が第一選択となる。
>
> **[Augmentation (症状増悪)]** ドパミン作動薬（ビ・シフロール等）を長期・高用量使用すると、逆に症状が悪化・早期化（Augmentation）することがある。この場合は増量せず、α2δリガンド（ガバペン/レグナイト）への変更を検討せよ。

## 📖 詳細解説

### 病態生理

- **RLS（むずむず脚症候群）**は下肢の不快な異常感覚と動かしたい衝動を特徴とする感覚運動障害
- 有病率: 約2-5%。中年女性に好発。鉄欠乏・腎不全で増加
- **病態**: 中枢ドパミン系の機能障害+脳内鉄欠乏が中核。脊髄レベルでの感覚-運動統合異常
- **二次性RLS**: 鉄欠乏性貧血（フェリチン低下）、腎不全（透析患者の20-30%）、妊娠、薬剤性（抗うつ薬SSRI/SNRI、抗ヒスタミン薬、ドパミン拮抗薬）

### 診断基準・鑑別疾患

- **IRLSSG診断基準（5つの必須基準全てを満たす）**:
  - (1) 下肢の不快な感覚に伴う動かしたいという強い衝動
  - (2) 安静時・不動時に出現または増悪
  - (3) 運動（歩行等）で部分的または完全に改善
  - (4) 夕方〜夜間に増悪（概日リズム性）
  - (5) 他の疾患で説明できない
- **必須検査**: フェリチン（50ng/mL未満で鉄補充を考慮）、腎機能
- **鑑別**: 末梢神経障害、下肢静脈瘤、こむら返り、アカシジア（抗精神病薬による）

### エビデンス・ガイドライン推奨

- **鉄補充**（フェリチン75ng/mL未満の場合）: 鉄剤経口投与（クエン酸第一鉄等）。フェリチン75以上を目標
- **薬物療法**:
  - プラミペキソール（ビ・シフロール）0.125-0.75mg就寝前: ドパミンアゴニスト。有効だが長期使用でaugmentation（症状増悪・拡大）リスク
  - ロチゴチン貼付剤（ニュープロパッチ）: 24時間持続型。augmentationリスクが比較的低い
  - ガバペンチンエナカルビル（レグナイト）600mg 1日1回夕食後: alpha2deltaリガンド。augmentationリスクなし。第一選択として推奨される傾向。※日本ではガバペンチン（ガバペン）のRLSへの使用は適応外。RLSに保険適用があるのはガバペンチンエナカルビル（レグナイト）600mg 1日1回夕食後
  - クロナゼパム0.5-1mg就寝前: 周期性四肢運動障害（PLMD）合併例に
- **augmentation対策**: ドパミンアゴニストの使用は最小有効量で。augmentation出現時はalpha2deltaリガンドへ切り替え
