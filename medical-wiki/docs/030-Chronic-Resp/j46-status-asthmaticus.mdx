<h3 className="soap-a">評価</h3>

- **診断根拠:** 安静時呼吸困難、会話困難、頻脈(&gt;110)、SpO2低下(&lt;90%)。
- **聴診:** 著明な喘鳴 / Silent Chest
- **重症度:** 中発作 / 大発作 / 重篤

<h3 className="soap-p">方針・処方</h3>

- 【緊急】直ちに酸素投与、ネブライザ吸入、ステロイド全身投与を行う。
- 改善なければ救急搬送。

## 📖 詳細解説

### 病態生理

- **定義**: 通常の気管支拡張薬に反応しない重篤な喘息発作。致死的となりうる救急疾患
- **病態**:
  1. 高度な気管支平滑筋攣縮
  2. 気道粘膜浮腫と粘液栓による気道閉塞
  3. 著明な空気トラッピング → 過膨張 → 内因性PEEP
  4. 呼吸筋疲労 → CO2蓄積 → 呼吸性アシドーシス → 心停止
- **死亡リスクの高い患者像**:
  - 過去に挿管・ICU管理歴あり
  - 過去1年に全身ステロイドを要する増悪が2回以上
  - SABA過剰使用（月1本以上）
  - ICS未使用または低アドヒアランス
  - 精神疾患合併、社会的孤立

### 診断基準・鑑別疾患

- **重症度判定（JGL2024準拠）**:
  - 中発作: 呼吸困難で横になれない、SpO2 91-95%、PEF 50-80%
  - 大発作: 起座呼吸、会話困難、SpO2 90%以下、PEF 50%未満、著明なwheezes
  - 重篤: チアノーゼ、意識障害、奇異呼吸、wheezes消失（Silent chest = 超危険）
- **緊急搬送の絶対適応**:
  - SpO2 90%以下が持続
  - 意識障害
  - 会話不能
  - 初期治療（SABA反復吸入）で改善なし
- **鑑別**: 気道異物、アナフィラキシー、気胸、肺塞栓、心不全（cardiac asthma）、声帯機能不全

### エビデンス・ガイドライン推奨

- **クリニックでの初期対応（搬送までの時間稼ぎ）**:
  - SABA反復吸入: サルブタモール（ベネトリン）0.3-0.5mL + 生食2mL ネブライザー、20分間隔で最大3回
  - 酸素投与: SpO2 93-95%を目標（過度の酸素はCO2ナルコーシスに注意）
  - 全身性ステロイド: ヒドロコルチゾン200mg静注 or mPSL 40-125mg静注（施設の規格に応じて。効果発現は4-6時間後だが早期投与が重要）
  - アドレナリン皮下注: 0.3mg（0.1%製剤 0.3mL）重症例で考慮
- **搬送先での標準治療**:
  - 反復ネブライザー + イプラトロピウム（アトロベント）併用
  - MgSO4 2g/20分 点滴（重症例でのエビデンスあり: Cochrane 2014）
  - アミノフィリン点滴（250mg/20分 → 0.6mg/kg/hr）: 日本では使用頻度高い
  - NPPV or 挿管・人工呼吸（意識障害、呼吸筋疲労時）
- **退院後管理**: 発作の原因分析、ICS/LABA定期吸入の確実な導入、アクションプランの作成、1-2週間以内の再診
