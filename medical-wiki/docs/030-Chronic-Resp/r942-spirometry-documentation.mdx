<h3 className="soap-s">主訴・ROS</h3>

主訴: 咳嗽 / 喀痰 / 喘鳴 / 呼吸困難

**呼吸器系**

咳嗽: 乾性 / 湿性, 喀痰: 有 / 無
喘鳴: ヒューヒュー / ゼーゼー / なし
呼吸困難: 労作時 / 安静時 / 夜間 / 明け方
症状の変動: 夜間に悪化 / 季節性あり / 運動・冷気で誘発

**背景**

喫煙歴: ＿ 本/日 × ＿ 年 現在: 喫煙中 / 禁煙済
既往歴: アレルギー性鼻炎、アトピー、小児喘息

<h3 className="soap-o">所見・検査</h3>

バイタル: SpO2: ＿% (Room Air)

**胸部聴診**

呼吸音: 強制呼気時喘鳴 / 呼吸音減弱 / 正常 / 肺胞呼吸音

**呼吸機能検査 (スパイロ)**

呼吸機能検査（スパイロメトリー）
FEV1: ＿L, %FEV1: ＿%
FEV1/FVC: ＿% &lt;70%で閉塞性障害
フローボリューム曲線: 下に凸 / 正常

**画像**

胸部単純X線検査
所見: 異常なし / 透過性亢進 / 浸潤影なし
AI解析結果: 異常なし / 異常所見あり: ＿

<h3 className="soap-a">評価</h3>

- **肺活量(VC):** ＿ L（予測値 ＿ L、%VC: ＿%）
- **努力肺活量(FVC):** ＿ L
- **1秒量(FEV1):** ＿ L（予測値 ＿ L、%FEV1: ＿%）
- **1秒率(FEV1%):** ＿%
- **判定:** 正常 / 閉塞性障害 / 拘束性障害 / 混合性障害
- **閉塞性:** FEV1% 70%未満 → COPD、喘息等を精査
- **拘束性:** %VC 80%未満 → 間質性肺疾患、神経筋疾患等を精査
- **フローボリューム曲線:** 正常型 / 閉塞型（下に凸）/ 拘束型（全体縮小）

<h3 className="soap-p">方針・処方</h3>

- 判定に応じた精査計画を記載。

#### 処方・アクション

**閉塞性障害精査セット**

- <span className="med-id">[Rx-Resp-BDR]</span> 気管支拡張薬吸入後再検（気道可逆性試験）
- サルブタモール200-400μg吸入後15-20分で再検 ；COPD vs 喘息の鑑別
- <span className="med-id">[Rx-Resp-FeNO]</span> 呼気NO検査
- 呼気一酸化窒素(FeNO)測定 ；好酸球性気道炎症の評価

**拘束性障害精査セット**

- <span className="med-id">[Img-Resp-HRCT]</span> 胸部HRCT
- 胸部高分解能CT ；間質性肺疾患の評価

#### 指導・計画

- **再診目安:** 精査結果に応じて1-4週後。
- 閉塞性障害確認時は禁煙指導を併せて実施。
- 拘束性障害確認時は呼吸器専門医への紹介を検討。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[手技]** 最低3回の測定で再現性を確認（FVCとFEV1の最大値の差が150mL以内）。
>
> **[COPD]** FEV1% 70%未満のみではCOPD確定できない。気管支拡張薬吸入後の再検が必要。
>
> **[喘息]** 喘息が疑われる場合は気道可逆性試験（β2刺激薬吸入前後のFEV1 12%以上かつ200mL以上の改善）を実施せよ。
