**排尿症状**

排尿時痛: なし / 排尿終わり / 最初から / 全体
頻尿: なし / あり: ＿回/日, 残尿感: なし / あり, 尿意切迫感: なし / あり
尿の性状: 混濁 / 血尿 / 悪臭

**局所症状**

尿道分泌物: なし / 膿性[ドロっとした黄色] / 漿液性[サラサラ] / 下着の汚れ
疼痛: 下腹部 / 側腹部 / 陰部 / 睾丸 / 咽頭痛

**経過・背景**

症状出現: ＿日前から
性交渉歴: なし / あり: ＿日前・パートナー/風俗
最終月経: ＿ 妊娠の可能性: 有 / 無

<h3 className="soap-o">所見・検査</h3>

バイタル: BT: ＿℃

**腹部・局所**

圧痛: 下腹部 / CVA叩打痛[右・左] / なし
外陰部: 異常なし / 発赤 / 腫脹 / 分泌物 / 水疱 / 潰瘍

**院内迅速検査**

尿検査・尿沈渣
- **定性:** 蛋白(＿) 糖(＿) 潜血(＿) 白血球(＿) 亜硝酸塩(＿)
- **沈渣:** RBC(＿) WBC(＿) 細菌(＿)

**外注検査**

尿培養 (※複雑性・腎盂腎炎疑いのみ)
性感染症(尿) ；淋菌・クラミジアPCR
性感染症(咽頭) ；うがい液PCR

**外注検査**

- <span className="med-id">[Lab-Uro-Culture]</span> 尿培養

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[排尿痛の鑑別]** 排尿終末時痛・残尿感・頻尿なら「膀胱炎」、排尿初期痛・尿道分泌物なら「尿道炎」、発熱・背部叩打痛(CVA)なら「腎盂腎炎」を疑う。
>
> **[設備制約]** 当院には腹部エコーおよびCTがないため、結石のサイズ同定や腎膿瘍の評価はできない。高熱、激痛、背部痛を伴う場合は、診断がつかなくても早期に泌尿器科または総合病院へ紹介せよ。
>
> **[STD検査]** 淋菌・クラミジアは「尿（初尿）」で検査する。膀胱炎疑いの「中間尿」とは採尿タイミングが異なるため、指示出しの際は看護師へ明確に伝えること。
>
> **[梅毒届出]** 梅毒は全数把握疾患（5類感染症）である。診断後7日以内に保健所へ発生届を提出せよ。

<h3 className="soap-a">評価</h3>

- STD一括スクリーニング結果:
- クラミジア（尿/咽頭/膣 NAAT）: 陰性 / 陽性
- 淋菌（尿/咽頭/膣 NAAT）: 陰性 / 陽性
- 梅毒（RPR + TP抗体）: 陰性 / 陽性（RPR定量: ＿倍）
- HIV（第4世代抗原抗体）: 陰性 / 陽性 ※検査前同意取得要
- B型肝炎（HBs抗原）: 陰性 / 陽性
- ウインドウ期:
- HIV: 4週
- 梅毒: 4-6週
- クラミジア/淋菌: 2-3週
- **全項目陰性の場合:** 「現時点でSTDは検出されませんでした。ウインドウ期を考慮し、心配な行為から＿週間後に再検をお勧めします」

<h3 className="soap-p">方針・処方</h3>

- 陽性項目があれば該当疾患のテンプレートへ移行して治療開始。
- 全陰性なら結果説明 + ウインドウ期再検の案内。
- **注:** Z11.3（STDスクリーニング）は保険診療では単独算定不可。保険請求時は『クラミジア感染症の疑い[A56.2]』『淋菌感染症の疑い[A54.9]』等の疑い病名を併記すること。自費診療の場合はZ11.3のみで可。

#### 処方・アクション

**スクリーニング検査セット**

- <span className="med-id">[Rx-Uro-STDScr-CT]</span> クラミジアNAAT
- **尿（男性:** 初尿）/ 膣擦過（女性）/ 咽頭擦過 ；部位は行為内容に応じて選択
- <span className="med-id">[Rx-Uro-STDScr-GC]</span> 淋菌NAAT
- **尿（男性:** 初尿）/ 膣擦過（女性）/ 咽頭擦過 ；部位は行為内容に応じて選択
- <span className="med-id">[Rx-Uro-STDScr-Syp]</span> 梅毒検査
- RPR定量 + TP抗体（TPHA or CLIA）
- <span className="med-id">[Rx-Uro-STDScr-HIV]</span> HIV検査
- 第4世代抗原抗体検査 ※検査前に同意を取得すること
- <span className="med-id">[Rx-Uro-STDScr-HBV]</span> B型肝炎検査
- HBs抗原
- <span className="med-id">[Rx-Uro-STDScr-HCV]</span> C型肝炎検査
- **C型肝炎（HCV抗体）:** 未検 / 陰性 / 陽性 ※特にMSMではHCV同時検査を強く推奨

**陽性時の治療テンプレート参照先**

- クラミジア陽性 → 250-AP-04.txt（性器）/ 250-AP-15.txt（咽頭）
- 淋菌陽性 → 250-AP-05.txt（性器）/ 250-AP-15.txt（咽頭）
- 梅毒陽性 → 250-AP-07.txt〜250-AP-10.txt（病期別）
- HIV陽性 → 専門施設紹介
- HBV陽性 → 消化器内科紹介

#### 指導・計画

- **ウインドウ期の説明:** リスク行為から検査までの期間が短い場合、偽陰性の可能性を説明。
- 全陰性でもウインドウ期を考慮した再検を案内。
- **再診目安:** ウインドウ期経過後（リスク行為から4-6週後）。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[ウインドウ期]** 「昨日リスク行為があった」という患者にすぐ検査しても意味がない。各検査のウインドウ期を説明し、適切な時期に再検を案内せよ。
>
> **[HIV]** HIV検査は検査前に同意を取得すること。結果は対面で伝えることが望ましい。電話での結果通知は避けよ。
>
> **[網羅的に]** 「クラミジアだけ調べて」と言われても、淋菌・梅毒・HIVの同時検査を勧めよ。STDは重複感染が多い。1つ見つかれば他も調べるのが原則。
