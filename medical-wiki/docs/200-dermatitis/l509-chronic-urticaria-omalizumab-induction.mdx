> **[FTU (Finger Tip Unit)]** 外用薬の効果が出ない最大の理由は「塗布量不足」である。チューブから「人差し指の先から第一関節まで（約0.5g）」出した量が、「大人の手のひら2枚分」の面積を塗る適量である。「ティッシュが張り付くくらい」たっぷり塗るよう指導せよ。

<h3 className="soap-a">評価</h3>

- 慢性蕁麻疹（6週間以上持続）で第二世代抗ヒスタミン薬の倍量投与でもコントロール不十分な場合。
- ゾレア（オマリズマブ）300mg 皮下注 4週毎の適応を検討。
- **投与前検査:** 血清総IgE測定（ただし用量調整には使用しない。蕁麻疹では体重・IgEによらず300mg固定）。
- **除外事項:** 寄生虫感染（IgE高値の他原因）。
- 蕁麻疹活動性スコア（UAS7）で効果判定を行う。

<h3 className="soap-p">方針・処方</h3>

- ゾレア300mg 皮下注 4週毎で開始（初回は院内で投与し30分経過観察）。
- 抗ヒスタミン薬は継続（併用）。
- **効果判定:** 3ヶ月（12週）投与後にUAS7で評価。無効なら中止検討。
- **奏効例:** 6ヶ月以上継続後に中止を試みる（中止後再燃することあり）。

**ゾレア導入セット**

- <span className="med-id">[Rx-Der-Urt-Xolair]</span> ゾレア皮下注用150mgシリンジ
- ゾレア皮下注用150mgシリンジ 2本（=300mg）4週毎 皮下注 *— 慢性蕁麻疹*

**併用抗ヒスタミン薬（継続）**

- <span className="med-id">[Rx-Der-Urt-AH2x]</span> 抗ヒスタミン薬（倍量継続）
- 継続中の第二世代抗ヒスタミン薬を倍量で継続 ；ゾレア導入後も併用

#### 指導・計画

- 初回投与は院内で実施し、投与後30分の経過観察を行う。
- 自己注射の導入は3回以上の院内投与後に検討。
- UAS7記録を患者に依頼（毎日の膨疹数・痒みスコアを1週間記録）。
- **再診:** 4週毎（投与日）。3ヶ月後に効果判定。
- **コスト説明:** 3割負担で月約15,000-20,000円。高額療養費制度の案内。

## 📖 詳細解説

慢性蕁麻疹は、膨疹・血管性浮腫が6週間以上にわたり反復出現する疾患であり、成人の有病率は約1%とされる。原因が特定できない慢性特発性蕁麻疹（CSU: chronic spontaneous urticaria）が大半を占める。抗ヒスタミン薬でコントロール不十分な症例に対し、オマリズマブ（ゾレア）が適応となる。

### 病態生理

- **マスト細胞の中心的役割:** 皮膚マスト細胞の脱顆粒によりヒスタミン・ロイコトリエン等のメディエーターが放出され、血管拡張・血漿漏出・神経刺激（掻痒）を引き起こす。
- **自己免疫機序:** CSU患者の約30〜50%に抗IgE受容体（FcepsilonRI）自己抗体または抗IgE自己抗体が検出される。これらがマスト細胞を直接活性化する（I型自己免疫型）。
- **IgEの役割:** IgEはマスト細胞表面のFcepsilonRIに結合し、受容体の発現を維持・増加させる。遊離IgEが多いほどマスト細胞の反応性が亢進する。
- **オマリズマブの作用機序:** 抗IgEモノクローナル抗体（ヒト化IgG1）。遊離IgEに結合してFcepsilonRIへの結合を阻害し、マスト細胞表面のFcepsilonRI発現を低下させる。結果としてマスト細胞の反応性が低下し、膨疹の出現を抑制する。効果発現は投与後1〜2週間と比較的速やかである。

### 診断基準・鑑別疾患

**慢性蕁麻疹の定義**

- 膨疹、血管性浮腫、またはその両方が6週間以上にわたり反復する
- 個々の膨疹は24時間以内に消退（24時間以上持続する場合は蕁麻疹様血管炎を疑う）

**ゾレア導入の適応基準**

1. 慢性蕁麻疹（CSU）の確定診断がある
2. 第二世代抗ヒスタミン薬の常用量で効果不十分
3. 抗ヒスタミン薬の倍量投与（2〜4週間）でも効果不十分
4. 上記にもかかわらずUAS7 16点以上（中等症以上）が持続

**UAS7（Urticaria Activity Score 7）**

- 膨疹数スコア（0〜3点）と掻痒スコア（0〜3点）を毎日記録し、7日間の合計（0〜42点）
- 0〜6: 軽症コントロール良好、7〜15: 軽症、16〜27: 中等症、28〜42: 重症
- ゾレア導入時と投与12週後に評価し、効果判定に用いる

**鑑別疾患**

| 鑑別疾患 | 鑑別ポイント |
|---|---|
| 蕁麻疹様血管炎 | 膨疹が24時間以上持続、消退後に紫斑を残す。皮膚生検で血管炎所見 |
| 物理性蕁麻疹 | 寒冷・日光・圧迫・振動など特定の物理刺激で誘発 |
| アナフィラキシー | 急性発症、呼吸器・循環器症状を伴う |
| 好酸球性皮膚疾患 | 好酸球増多、膨疹様紅斑が持続 |

### エビデンス・ガイドライン推奨

**治療ステップ（日本皮膚科学会蕁麻疹診療ガイドライン2021準拠）**

1. **Step 1:** 第二世代抗ヒスタミン薬（常用量）
2. **Step 2:** 第二世代抗ヒスタミン薬の倍量投与（添付文書上の最大量まで）
3. **Step 3:** 抗ヒスタミン薬倍量 + オマリズマブ（ゾレア）300mg 4週毎 皮下注
4. **Step 4:** シクロスポリン等の追加（専門施設で）

**オマリズマブのエビデンス**

- **ASTERIA I/II試験、GLACIAL試験:** 300mg 4週毎投与でUAS7の有意な改善を確認。プラセボ群と比較して膨疹・掻痒スコアともに有意差あり
- **用量:** 蕁麻疹では体重・IgE値によらず**300mg固定**（花粉症では体重・IgE値に基づき75〜600mgで用量調整する点と異なる）
- **効果判定:** 12週（3回投与）後にUAS7で評価。効果不十分なら中止を検討
- **奏効例の治療期間:** 6ヶ月以上継続後に中止を試みる。中止後に再燃することがあり、再投与で再度有効

**自己注射について**

- 院内投与3回以上で安全性を確認後、自己注射指導を開始できる
- ゾレア皮下注150mgシリンジを2本（=300mg）自己投与
- 初回の自己注射は医療機関で指導のもと実施

**費用（2024年時点）**

- 薬価: ゾレア150mgシリンジ 約24,000円 x 2本 = 約48,000円/回
- 3割負担: 月約15,000〜20,000円（注射手技料等含む）
- 高額療養費制度の適用可能。限度額適用認定証の案内を行う
