> **[KOH即日不可の対応]** 当院ではKOH（真菌検査）が外注となるため、その場での白癬確定診断ができない。典型的な湿疹に見えても、ステロイドを塗って悪化する場合は白癬の可能性がある。「もし薬を塗って赤みや痒みが増したら、すぐに中止して再診してください」と必ず伏線を張れ。疑わしければ、初回は抗真菌薬もステロイドも使わず、保湿剤や非ステロイド系（スタデルム等）で検査結果を待つのも賢明な戦略である。

> **[FTU (Finger Tip Unit)]** 外用薬の効果が出ない最大の理由は「塗布量不足」である。チューブから「人差し指の先から第一関節まで（約0.5g）」出した量が、「大人の手のひら2枚分」の面積を塗る適量である。「ティッシュが張り付くくらい」たっぷり塗るよう指導せよ。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 多汗・高温環境での汗管閉塞によるエクリン汗腺の破綻。好発部位: 頸部、体幹、肘窩、膝窩、乳児は頭部・額。
- **分類:** 紅色汗疹: 赤い点状丘疹+瘙痒 / 水晶様汗疹: 無症候性透明小水疱
- **鑑別:** アトピー性皮膚炎、接触皮膚炎、毛包炎、カンジダ症（乳児の場合）

<h3 className="soap-p">方針・処方</h3>

- **紅色汗疹:** ステロイド外用（ローション剤が使いやすい）短期使用。
- **水晶様汗疹:** 無治療（自然消退）。
- **環境調整:** 通気性のよい衣類、エアコンによる室温管理、こまめなシャワー。
- 二次感染（掻破による膿痂疹化）時は抗菌薬外用を追加。

#### 処方・アクション

**紅色汗疹セット**

- ロコイドクリーム0.1% 1本 1日2回 患部に塗布 7日分 *— 顔面・乳児*

**二次感染時追加**

<span className="med-id">[Rx-Der-Mili-Abx] フシジンレオ軟膏（AMR対策）</span>
- フシジンレオ軟膏2% 1本 1日2-3回 感染部に塗布 *— 膿痂疹化時*
> ※使用は7日以内。改善なければ培養検査検討
<span className="med-id">[Rx-Der-Mili-AbxS] リンデロンVG（二次感染+炎症時）</span>
- リンデロンVGクリーム 1本 1日2回 感染部に塗布 7日分 *— 二次感染を伴う紅色汗疹*

#### 指導・計画

- **患者指導:** 通気性のよい綿素材の衣類、こまめな汗の拭き取り、室温25-28度の管理。
- **再診目安:** 1-2週間で改善なければ再診。

## 📖 詳細解説

汗疹（miliaria）は、エクリン汗管の閉塞により汗が皮膚内に貯留して生じる発疹である。高温多湿環境、発熱、過度の衣類による被覆が誘因となる。乳児は汗腺密度が高くエクリン汗管が未熟であるため特に好発する。日本では夏季に頻度が増加し、軽症例が大半を占める。

### 病態生理

- **エクリン汗管の閉塞:** 高温・多湿環境で大量に産生された汗がエクリン汗管内に貯留する。汗管閉塞の深さにより臨床型が決定される。
- **閉塞部位による分類:**

| 分類 | 閉塞部位 | 臨床像 | 症状 |
|---|---|---|---|
| 水晶様汗疹（miliaria crystallina） | 角層内（最表層） | 1〜2mmの透明な薄壁小水疱 | 無症状。破裂しやすく数時間〜1日で消退 |
| 紅色汗疹（miliaria rubra） | 表皮内（有棘層） | 紅色丘疹、点状紅斑 | 掻痒、刺痛（prickling sensation） |
| 深在性汗疹（miliaria profunda） | 真皮表皮接合部 | 非炎症性の肌色丘疹 | 熱帯環境での長期曝露後。無汗症を伴いうる |

- **紅色汗疹の炎症機序:** 汗管から漏出した汗成分が周囲組織に炎症を惹起する。IL-1alpha等の炎症性サイトカインが関与する。
- **細菌の関与:** 表皮ブドウ球菌（Staphylococcus epidermidis）が産生する多糖体が汗管閉塞に関与するとの報告がある。紅色汗疹が遷延すると二次感染（膿痂疹化）を合併することがある。
- **好発部位:** 頸部、体幹、肘窩、膝窩、腋窩、鼠径部。乳児は頭部・額・背部。衣類や寝具で被覆された部位に多い。

### 診断基準・鑑別疾患

**診断のポイント**

- 高温多湿環境への曝露歴、発熱、過剰な衣類着用の確認
- 好発部位に一致した小水疱・紅色丘疹の分布
- 通常、環境改善（涼しくする）で速やかに改善する点が特徴的
- 特殊な検査は不要。臨床像で診断可能

**鑑別疾患**

| 鑑別疾患 | 鑑別ポイント |
|---|---|
| カンジダ症（間擦疹） | 間擦部（鼠径・腋窩・乳房下）に好発。鮮紅色びらん面、辺縁の鱗屑・衛星病変。KOH陽性 |
| 接触皮膚炎 | 原因物質との接触部位に一致。境界明瞭。パッチテストで同定 |
| 毛包炎 | 毛包一致性の膿疱。細菌培養で起炎菌同定 |
| アトピー性皮膚炎 | 慢性反復性。肘窩・膝窩の苔癬化、乾燥肌。既往・家族歴 |
| 汗疱（異汗性湿疹） | 手指側面・手掌の深在性小水疱。汗管閉塞ではなく湿疹の一型 |
| 多形滲出性紅斑 | ターゲット様紅斑。感染症・薬剤に続発 |

### エビデンス・ガイドライン推奨

汗疹は一般的に自然軽快する疾患であり、大規模RCTは乏しい。治療の基本は環境調整であり、薬物療法は対症的に用いる。

**治療方針**

1. **環境調整（最優先）:**
   - 室温25〜28度、湿度40〜60%の管理
   - 通気性のよい綿素材の衣類（化繊は避ける）
   - こまめなシャワー・汗の拭き取り
   - 乳児では過剰な着衣・布団を避ける

2. **水晶様汗疹:** 無治療で自然消退（数時間〜1日）。環境調整のみで十分

3. **紅色汗疹（掻痒を伴う場合）:**
   - カラミンローション: 収斂・清涼作用。広範囲に使用可。安全性が高い
   - ステロイド外用: ミディアム〜ストロング。短期使用（5〜7日）で十分
   - 顔面・乳児: ロコイドクリーム等のマイルドクラスを使用
   - 体幹: リンデロンVローション等のストロングクラス

4. **二次感染合併時:** 抗菌薬外用（フシジン酸等）を追加。7日以内の使用とする

**予防**

- 高温環境を避ける（特に乳児・高齢者・発熱患者）
- 吸湿性の良い衣類の選択
- 入浴・シャワー後は十分に乾燥させてから衣類を着用
- ベビーパウダーは汗管を閉塞させる可能性があり推奨されない
