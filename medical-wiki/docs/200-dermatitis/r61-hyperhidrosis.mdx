> **[KOH即日不可の対応]** 当院ではKOH（真菌検査）が外注となるため、その場での白癬確定診断ができない。典型的な湿疹に見えても、ステロイドを塗って悪化する場合は白癬の可能性がある。「もし薬を塗って赤みや痒みが増したら、すぐに中止して再診してください」と必ず伏線を張れ。疑わしければ、初回は抗真菌薬もステロイドも使わず、保湿剤や非ステロイド系（スタデルム等）で検査結果を待つのも賢明な戦略である。

<h3 className="soap-a">評価</h3>

- **原発性局所多汗症:** 手掌・腋窩・足底に限局、両側性、25歳以下の発症、家族歴あり、睡眠中は発汗なし。
- HDSS（Hyperhidrosis Disease Severity Scale）: Grade 1（気にならない）〜Grade 4（日常生活に支障）。
- 二次性の除外:
- 甲状腺機能亢進症、褐色細胞腫
- 糖尿病、悪性リンパ腫
- 薬剤性、更年期

<h3 className="soap-p">方針・処方</h3>

- 塩化アルミニウム外用液20%が第一選択（就寝前塗布、起床後洗浄）。
- **腋窩多汗症:** エクロックゲル or ラピフォートワイプ（保険適用）。
- **手掌・足底:** イオントフォレーシス（施設あれば）。
- **腋窩重症例:** ボツリヌス毒素注射（保険適用あり）。
- **重症手掌多汗症:** 胸腔鏡下胸部交感神経遮断術（ETS）→代償性発汗のリスク説明必須。

#### 指導・計画

- 塩化アルミニウム外用: 刺激感が出る場合はワセリンで保護後に塗布。効果発現まで1-2週間。
- エクロック/ラピフォート: 塗布後は必ず手を洗う（眼に入ると散瞳・霧視のリスク）。
- **ETS手術:** 代償性発汗（体幹・下肢の多汗）が高率に出現する旨、不可逆的な手術である旨を十分に説明し同意を得る。
- **再診目安:** 4週間後。HDSS再評価と治療効果判定。

## 📖 詳細解説

多汗症（hyperhidrosis）は、体温調節に必要な量を超える過剰な発汗を特徴とする疾患である。原発性局所多汗症の有病率は日本で約5.8%と報告されており、QOLへの影響が大きいにもかかわらず受診率は低い。近年、保険適用の外用薬が登場し治療の選択肢が広がった。

### 病態生理

- **エクリン汗腺の過剰反応:** 原発性多汗症ではエクリン汗腺の数・形態は正常だが、交感神経（コリン作動性）の過剰興奮により発汗量が増加する。
- **交感神経系の関与:** 視床下部の体温調節中枢から脊髄側角の交感神経節前ニューロンを経て、アセチルコリンを介してエクリン汗腺を刺激する。原発性多汗症ではこの経路の閾値が低下している。
- **部位による特徴:**
  - **手掌・足底:** 精神性発汗（情動発汗）が主体。大脳皮質・辺縁系からの入力が関与
  - **腋窩:** 温熱性発汗+精神性発汗の両方が関与。エクリン汗腺に加えアポクリン汗腺も存在
  - **頭部・顔面:** 温熱性発汗が主体。味覚性発汗（Frey症候群）との鑑別が必要
- **遺伝的背景:** 家族歴を約60〜65%に認める。常染色体優性遺伝パターンが示唆されている。

### 診断基準・鑑別疾患

**原発性局所多汗症の診断基準（日本皮膚科学会ガイドライン）**

局所的に過剰な発汗が6ヶ月以上持続し、以下の6項目中2項目以上を満たす:

1. 発症が25歳以下
2. 左右対称性の発汗
3. 睡眠中は発汗が停止
4. 1週間に1回以上の多汗エピソード
5. 家族歴あり
6. 日常生活に支障をきたしている

**HDSS（Hyperhidrosis Disease Severity Scale）**

| Grade | 重症度 | 内容 |
|---|---|---|
| 1 | 軽微 | 発汗は全く気にならず、日常生活に支障なし |
| 2 | 耐えられる | 発汗は我慢できるが、時に日常生活に支障 |
| 3 | 耐えがたい | 発汗はほとんど我慢できず、頻繁に日常生活に支障 |
| 4 | 耐えられない | 発汗は我慢できず、常に日常生活に支障 |

- Grade 3〜4が積極的治療の適応
- Grade 1〜2は生活指導で経過観察可能

**二次性多汗症の除外（必須）**

| 原因 | 確認事項 |
|---|---|
| 甲状腺機能亢進症 | TSH, FT3, FT4 |
| 褐色細胞腫 | 血圧変動、発作性高血圧 |
| 糖尿病（自律神経障害） | HbA1c, 血糖 |
| 悪性リンパ腫 | 盗汗（night sweats）、体重減少 |
| 更年期障害 | ホットフラッシュとの関連 |
| 薬剤性 | SSRI、三環系抗うつ薬、オピオイド等 |
| 感染症 | 結核等の慢性感染症 |

### エビデンス・ガイドライン推奨

**日本皮膚科学会 原発性局所多汗症診療ガイドライン2023準拠**

**1. 塩化アルミニウム外用（推奨度1B）**

- 20〜50%塩化アルミニウムエタノール/水溶液
- 就寝前に患部に塗布し、起床後に洗浄する
- 効果発現まで1〜2週間。継続使用で効果維持
- 副作用: 刺激性皮膚炎（ワセリンで保護後に塗布すると軽減）
- 保険適用外（院内調剤or市販品）

**2. 抗コリン外用薬（保険適用）**

- **エクロックゲル5%（ソフピロニウム臭化物）:** 2020年承認。原発性腋窩多汗症に保険適用。1日1回腋窩に塗布。抗コリン作用により汗腺分泌を抑制。HDSS改善率は約50〜55%
- **ラピフォートワイプ2.5%（グリコピロニウムトシル酸塩水和物）:** 2022年承認。原発性腋窩多汗症に保険適用。1日1回ワイプで腋窩を拭く。使い切りタイプで利便性が高い
- **注意:** 塗布後は必ず手を洗う。眼に入ると散瞳・霧視のリスクがある。閉塞隅角緑内障・前立腺肥大症には禁忌

**3. イオントフォレーシス（推奨度1B）**

- 水道水に浸した患部に微弱直流電流（15〜20mA）を15〜20分間通電
- 手掌・足底の多汗症に有効。週2〜3回で開始し、改善後は週1回に減量
- 有効率は約80%以上
- 自宅用装置（ドライオニック等）も使用可能だが保険適用外

**4. ボツリヌス毒素注射（推奨度1B）**

- A型ボツリヌス毒素（ボトックス）を皮内注射
- 腋窩多汗症: 片側50単位。2012年から保険適用（重度の原発性腋窩多汗症、HDSS 3以上）
- 効果持続: 4〜9ヶ月（平均6ヶ月）。効果減弱時に再投与
- 手掌への注射は疼痛が強く、神経ブロックが必要な場合がある（保険適用外）
- 3割負担で約25,000〜30,000円/回

**5. 胸腔鏡下胸部交感神経遮断術（ETS）（推奨度2C）**

- 重症手掌多汗症の最終手段。T3〜T4レベルの交感神経を切離
- 手掌多汗症に対する有効率は90%以上と高い
- **代償性発汗:** 術後60〜90%に体幹・下肢の代償性発汗が出現し、約40%が中等度以上の代償性発汗を経験する。「手は乾くが体が汗だくになる」という状況が起こりうる
- 不可逆的な手術であり、十分なインフォームドコンセントが必須
- 近年はクリッピング法（可逆的）も行われるが、完全な可逆性は保証されない
