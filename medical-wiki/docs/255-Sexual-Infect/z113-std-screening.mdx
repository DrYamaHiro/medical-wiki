<h3 className="soap-a">評価</h3>

- STD一括スクリーニング結果:
- クラミジア（尿/咽頭/膣 NAAT）: 陰性 / 陽性
- 淋菌（尿/咽頭/膣 NAAT）: 陰性 / 陽性
- 梅毒（RPR + TP抗体）: 陰性 / 陽性（RPR定量: ＿倍）
- HIV（第4世代抗原抗体）: 陰性 / 陽性 ※検査前同意取得要
- B型肝炎（HBs抗原）: 陰性 / 陽性
- ウインドウ期:
- HIV: 4週
- 梅毒: 4-6週
- クラミジア/淋菌: 2-3週
- **全項目陰性の場合:** 「現時点でSTDは検出されませんでした。ウインドウ期を考慮し、心配な行為から＿週間後に再検をお勧めします」

<h3 className="soap-p">方針・処方</h3>

- 陽性項目があれば該当疾患のテンプレートへ移行して治療開始。
- 全陰性なら結果説明 + ウインドウ期再検の案内。
- **注:** Z11.3（STDスクリーニング）は保険診療では単独算定不可。保険請求時は『クラミジア感染症の疑い[A56.2]』『淋菌感染症の疑い[A54.9]』等の疑い病名を併記すること。自費診療の場合はZ11.3のみで可。

#### 処方・アクション

**スクリーニング検査セット**

<span className="med-id">[Rx-Uro-STDScr-CT] クラミジアNAAT</span>
- **尿（男性:** 初尿）/ 膣擦過（女性）/ 咽頭擦過 ；部位は行為内容に応じて選択
<span className="med-id">[Rx-Uro-STDScr-GC] 淋菌NAAT</span>
- **尿（男性:** 初尿）/ 膣擦過（女性）/ 咽頭擦過 ；部位は行為内容に応じて選択
<span className="med-id">[Rx-Uro-STDScr-Syp] 梅毒検査</span>
- RPR定量 + TP抗体（TPHA or CLIA）
<span className="med-id">[Rx-Uro-STDScr-HIV] HIV検査</span>
- 第4世代抗原抗体検査 ※検査前に同意を取得すること
<span className="med-id">[Rx-Uro-STDScr-HBV] B型肝炎検査</span>
- HBs抗原
<span className="med-id">[Rx-Uro-STDScr-HCV] C型肝炎検査</span>
- **C型肝炎（HCV抗体）:** 未検 / 陰性 / 陽性 ※特にMSMではHCV同時検査を強く推奨

**陽性時の治療テンプレート参照先**

- クラミジア陽性 → 255-AP-02（性器）/ 255-AP-05（咽頭）
- 淋菌陽性 → 255-AP-03（性器）/ 255-AP-05（咽頭）
- 梅毒陽性 → 255-AP-06〜255-AP-09（病期別）
- トリコモナス陽性 → 255-AP-15
- M. genitalium陽性 → 255-AP-16
- HIV陽性 → 専門施設紹介
- HBV陽性 → 消化器内科紹介

:::info NAAT検査の保険請求ルール
STDのNAAT検査は、保険請求上2つのペアに分けて検査する必要があります。

**第1ペア: CT/NG同時核酸検出（D023）**
- 淋菌（GC）+ クラミジア（CT）を同一キットで同時検出
- 1回の検査で2病原体を検出でき、個別検査より低コスト

**第2ペア: TV/MG同時核酸検出**
- トリコモナス（TV）+ マイコプラズマ・ジェニタリウム（MG）を同一キットで検出
- **CT/NG検査が陰性であることが算定の前提条件**

**同日算定で査定されるリスクがある理由:**
MG検査の保険適用通知では「淋菌・クラミジアが陰性の場合に算定可能」と規定されており、同日にCT/NGとTV/MGの両方を提出すると、CT/NG陰性が確認されていない時点でMGを検査したことになり、査定対象となります。

**推奨ワークフロー:** 初回はCT/NGのみ提出 → 結果判明後（陰性時）に別日でTV/MGを検査
:::

#### 指導・計画

- **ウインドウ期の説明:** リスク行為から検査までの期間が短い場合、偽陰性の可能性を説明。
- 全陰性でもウインドウ期を考慮した再検を案内。
- **再診目安:** ウインドウ期経過後（リスク行為から4-6週後）。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[ウインドウ期]** 「昨日リスク行為があった」という患者にすぐ検査しても意味がない。各検査のウインドウ期を説明し、適切な時期に再検を案内せよ。
>
> **[HIV]** HIV検査は検査前に同意を取得すること。結果は対面で伝えることが望ましい。電話での結果通知は避けよ。
>
> **[網羅的に]** 「クラミジアだけ調べて」と言われても、淋菌・梅毒・HIVの同時検査を勧めよ。STDは重複感染が多い。1つ見つかれば他も調べるのが原則。

## 📖 詳細解説

STD（Sexually Transmitted Diseases: 性感染症）スクリーニングとは、リスク行為後に複数の性感染症を一括して検査することである。STDは重複感染が多く（1つのSTDが見つかれば他のSTDの合併率が高い）、単一疾患の検査のみでは不十分である。

### 病態生理

**一括検査の意義**

- STDは無症状で経過することが多い（クラミジアの約50%、淋菌の約10-50%、HIV初期、梅毒の1期-潜伏期）
- 無症状の感染者がパートナーへの感染源（サイレントリザーバー）となる
- 1つのSTDに感染すると粘膜バリアの破綻や局所免疫の変化により、他のSTD（特にHIV）への感受性が2-5倍上昇する
- 梅毒感染者のHIV合併率は約10-15%、淋菌/クラミジア感染者のHIV合併率も一般集団より有意に高い

**各検査のウインドウ期（感染からの検出可能時期）**

| 検査項目 | ウインドウ期 | 検査法 | 備考 |
|---|---|---|---|
| HIV | 約4週間 | 第4世代抗原抗体検査（p24抗原+抗体） | 第3世代（抗体のみ）は約8週間 |
| 梅毒 | 4-6週間 | RPR + TP抗体（TPHA/CLIA） | RPRは治療効果判定にも使用 |
| クラミジア | 2-3週間 | NAAT（核酸増幅検査） | 尿/咽頭/膣を行為内容に応じて選択 |
| 淋菌 | 2-3週間 | NAAT（核酸増幅検査） | 同上 |
| B型肝炎 | 4-12週間 | HBs抗原 | 急性期にはIgM-HBc抗体も有用 |
| C型肝炎 | 3-6ヶ月 | HCV抗体 | 特にMSMでは同時検査を推奨 |

ウインドウ期内の検査は偽陰性となるため、リスク行為直後の検査では感染を否定できない。適切な時期に再検することが重要である。

### 診断基準・鑑別疾患

**リスク行為別の推奨検査**

| リスク行為 | 推奨する検査 |
|---|---|
| 腟性交（コンドームなし） | クラミジア（尿/膣）、淋菌（尿/膣）、梅毒、HIV、HBV |
| オーラルセックス | 上記 + クラミジア（咽頭）、淋菌（咽頭） |
| 肛門性交 | 上記 + 咽頭検査、HCV（特にMSM） |
| 風俗利用後 | フルセット（全項目 + 咽頭検査） |
| パートナーがSTD陽性 | パートナーと同一疾患 + フルセットを推奨 |
| 性暴力被害 | フルセット + 緊急避妊、HIV曝露後予防（PEP）検討 |

**検体の種類と注意点**

- **尿検体（男性）:** 初尿（排尿開始直後の10-20mL）を採取。中間尿では淋菌・クラミジアの検出率が低下する
- **膣擦過（女性）:** 自己採取も可能。子宮頸管擦過より簡便で感度は同等
- **咽頭検体:** うがい液または咽頭擦過。オーラルセックス歴があれば必ず追加
- **採血:** 梅毒、HIV、HBV、HCVの血清検査用

**結果解釈の注意点**

- 全項目陰性でもウインドウ期内であれば偽陰性の可能性がある
- 梅毒のTP抗体は一度陽性化すると治療後も永続的に陽性のため、既往感染との鑑別にはRPR定量の推移が重要
- HIV検査は検査前同意（インフォームドコンセント）の取得が必須

### エビデンス・ガイドライン推奨

**スクリーニングの推奨対象**

- STD症状を有する患者（尿道炎、外陰部潰瘍、異常分泌物等）
- パートナーがSTDと診断された場合
- 不特定多数との性交渉歴がある場合
- 風俗利用歴（提供者・利用者双方）
- MSM（Men who have Sex with Men）: 3-6ヶ月毎の定期スクリーニングを推奨
- 妊婦: 初回妊婦健診で梅毒、HIV、HBV、クラミジアの検査（公費）
- HIV感染者: 年1回以上のSTDスクリーニング

**パートナー検査・治療の重要性**

- STD陽性患者のパートナーには同時に検査・治療を行う（ピンポン感染防止）
- パートナーが未受診の場合、治療が完了しても再感染のリスクが残る
- 治癒確認（TOC: Test of Cure）までの性行為禁止を指導
- クラミジア・淋菌では治療後3-4週でNAAT再検、梅毒ではRPR定量を3ヶ月毎に追跡

**保険診療上の注意**

- Z11.3（STDスクリーニング）は保険診療で単独算定不可
- 保険請求時は「クラミジア感染症[A56.2]」「淋菌感染症[A54.9]」等の疑い病名を併記
- 自費診療であればZ11.3のみで可
