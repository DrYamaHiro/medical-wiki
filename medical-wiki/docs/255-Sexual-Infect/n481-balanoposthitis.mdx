<h3 className="soap-a">評価</h3>

- 亀頭・包皮の発赤・腫脹・疼痛・分泌物。
- 原因鑑別:
1) カンジダ性: 白色粥状の付着物、KOH検査で菌糸・胞子陽性。糖尿病合併が多い。
2) 細菌性: 黄色膿性分泌物。黄色ブドウ球菌、連鎖球菌が主因。
3) 接触性: コンドーム・石鹸・潤滑剤による刺激性/アレルギー性皮膚炎。
- 糖尿病のスクリーニング推奨（特にカンジダ性の反復例）。

<h3 className="soap-p">方針・処方</h3>

- 原因に応じた外用治療を選択。
- 包茎合併の反復例は包茎手術を泌尿器科に相談。

#### 処方・アクション

**カンジダ性**

<span className="med-id">[Rx-Uro-Bal-Clo] エンペシドクリーム（クロトリマゾール）</span>
- エンペシドクリーム1% 1日2-3回 患部に塗布 7-14日間
> ※KOH検査で菌糸・胞子を確認してから処方

**細菌性**

<span className="med-id">[Rx-Uro-Bal-Gen] ゲンタシン軟膏（ゲンタマイシン）</span>
- ゲンタシン軟膏0.1% 1日2-3回 患部に塗布 7日間

**接触性**

<span className="med-id">[Rx-Uro-Bal-Str] リンデロンV軟膏（ベタメタゾン吉草酸エステル）</span>
- リンデロンV軟膏0.12% 1日2回 患部に塗布 短期（5-7日間）
> ※原因物質の回避が最重要

**糖尿病スクリーニング**

- **衛生指導:** 包皮を翻転して微温湯で洗浄する習慣を指導。ただし石鹸の過度な使用は避ける。
- **再診目安:** 1-2週後。改善なければ原因の再検討。

## 📖 詳細解説

亀頭包皮炎（balanoposthitis）は亀頭（glans penis）と包皮（prepuce）の炎症であり、泌尿器科・皮膚科のプライマリケアで頻度の高い疾患である。亀頭のみの炎症をbalanitis、包皮のみをposthitisと呼ぶが、両者は併発することが多い。包茎（特に真性包茎）は最大のリスク因子であり、包皮下の恥垢蓄積が感染の温床となる。

### 病態生理

**カンジダ性亀頭包皮炎**

- 原因菌: Candida albicans（最多）、C. glabrata
- リスク因子: 糖尿病（HbA1c高値で発症リスク上昇）、抗菌薬長期投与、免疫抑制状態、包茎、肥満
- 病態: 包皮下の温暖湿潤環境でカンジダが増殖。菌糸形態への転換により粘膜侵入性が増す。
- 臨床像: 亀頭・包皮内板の発赤、白色粥状（カッテージチーズ様）の付着物、掻痒感。排尿痛は軽度。
- 糖尿病との関連: カンジダ性亀頭包皮炎の反復は未診断糖尿病の初発症状であることがあり、HbA1c測定は必須。SGLT2阻害薬使用者では尿糖排泄増加により発症リスクが2-3倍に上昇する。

**細菌性亀頭包皮炎**

- 原因菌: 黄色ブドウ球菌、A群溶血性連鎖球菌、嫌気性菌
- リスク因子: 包茎、衛生不良、外傷（性交による微小損傷含む）
- 臨床像: 発赤・腫脹が強く、黄色膿性分泌物を伴う。疼痛が主体。進行すると蜂窩織炎に至ることがある。

**接触性（非感染性）亀頭包皮炎**

- 原因: コンドーム（ラテックスアレルギー）、潤滑剤、石鹸、消毒薬
- 刺激性接触皮膚炎とアレルギー性接触皮膚炎に分類
- 臨床像: 原因物質との接触部位に一致した発赤・浮腫、水疱

**その他の原因**

- Zoon亀頭炎（形質細胞性亀頭炎）: 中高年、光沢のある橙赤色斑、慢性経過
- 閉塞性乾燥性亀頭炎（BXO/硬化性苔癬）: 白色硬化局面、包皮の瘢痕性狭窄、前癌状態
- 固定薬疹: 同一部位に繰り返す紅斑、薬剤歴の確認が重要

### 診断基準・鑑別疾患

**診断アプローチ**

1. 視診: 分泌物の性状（白色粥状 vs 黄色膿性 vs なし）、発赤のパターン
2. KOH直接鏡検: 包皮下の白苔を採取し、10% KOH処理後に鏡検。菌糸・胞子を確認すればカンジダ性と確定。
3. 培養検査: KOH陰性で細菌性が疑われる場合
4. 血糖・HbA1c: カンジダ性の場合は必須

**鑑別疾患**

| 疾患 | 鑑別ポイント |
|------|------------|
| カンジダ性 | 白色粥状付着物、KOH陽性、掻痒感主体 |
| 細菌性 | 膿性分泌物、疼痛主体、発赤・腫脹強い |
| 接触性皮膚炎 | 原因物質との時間的関連、境界明瞭な発赤 |
| 性器ヘルペス | 水疱・潰瘍、疼痛、再発性 |
| 梅毒（硬性下疳） | 無痛性潰瘍、硬結、鼠径リンパ節腫脹 |
| 扁平苔癬 | 網状白色線条（Wickham線条）、紫紅色丘疹 |
| ボーエン病/紅色肥厚症 | 治療抵抗性の紅斑、生検で確定 |

### エビデンス・ガイドライン推奨

**カンジダ性の治療**

- 第一選択: クロトリマゾール（エンペシド）クリーム1% 1日2-3回 7-14日間
- 代替: ミコナゾール（フロリード）クリーム 1日2回
- 重症・再発例: フルコナゾール150mg 単回内服（保険適用外だが有効性のエビデンスあり）
- 糖尿病のコントロール改善が再発予防の鍵

**細菌性の治療**

- 軽症: ゲンタマイシン（ゲンタシン）軟膏 1日2-3回 7日間
- 中等症以上（蜂窩織炎傾向）: セファレキシン500mg 1日3回 7日間の内服追加を検討

**清潔保持の指導**

- 包皮を翻転し微温湯で1日1回洗浄
- 石鹸の過度な使用は避ける（皮膚バリア障害・接触性皮膚炎の原因）
- 洗浄後は十分に乾燥させる

**包茎手術（環状切除術）の適応**

- 反復性亀頭包皮炎（年3回以上）
- 真性包茎で包皮翻転不能
- BXO（硬化性苔癬）に伴う包皮狭窄
- 環状切除術により亀頭包皮炎の再発率は大幅に低下する（RR 0.1-0.3）
- 泌尿器科への紹介が必要
