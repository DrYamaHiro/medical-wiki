<h3 className="soap-a">評価</h3>

- クラミジア陰性かつ淋菌陰性の尿道炎/頸管炎。
- **原因微生物:** Mycoplasma genitalium（最重要）、Ureaplasma urealyticum、トリコモナス、アデノウイルス。
- **検査所見:** 初尿WBC陽性、グラム染色でGNDC（グラム陰性双球菌）陰性。
- **STD合併の検索:** HIV・梅毒・B型肝炎のスクリーニングを推奨。

<h3 className="soap-p">方針・処方</h3>

- **第一選択:** アジスロマイシン単回投与 or ドキシサイクリン7日間。
- M. genitalium疑い（治療不応例）: アジスロマイシン extended regimen。
- パートナー同時治療が必須。

#### 処方・アクション

**第一選択A**

<span className="med-id">[Rx-STD-NGU-DOXY] ドキシサイクリン</span>

<span className="med-id">[Rx-STD-NGU-AZMex] アジスロマイシン（延長レジメン）</span>

> ※単回投与で治療失敗した場合に選択

**治療不応例（耐性M. genitalium疑い）**

<span className="med-id">[Rx-STD-NGU-STFX] シタフロキサシン</span>

- **パートナー同時治療:** STDであるため必須。パートナーにも同一レジメンで治療。
- **治癒確認:** 治療終了3週間後にNAAT再検で治癒確認。
- 治療中の性交渉禁止を指導。
- **再診目安:** 治療終了3週間後（治癒確認検査）。

## 📖 詳細解説

非淋菌性尿道炎・頸管炎（NGU/NGC）は、淋菌以外の病原体による尿道・頸管の感染症であり、性感染症（STI）の中で最も頻度が高い疾患群である。男性では尿道炎、女性では頸管炎として発症するが、女性は無症候性のことが多く（最大70-80%）、未治療のまま上行感染し骨盤内炎症性疾患（PID）や不妊の原因となる。

### 病態生理

**原因微生物と頻度**

- **Chlamydia trachomatis（クラミジア）:** NGUの40-50%を占める最多原因。潜伏期間1-3週間。細胞内寄生性のためグラム染色では検出不可。
- **Mycoplasma genitalium:** 15-25%。近年急速に認知が進んだ病原体。マクロライド耐性株が日本では40-50%に達する。
- **Ureaplasma urealyticum:** 5-10%。健常者からも検出されるため、病原性の判定には定量評価が必要。
- **Trichomonas vaginalis:** 1-5%。男性では無症候性が多い。
- **アデノウイルス:** 2-4%。咽頭炎を伴う場合がある。
- **原因不明:** 20-30%。複数菌の関与や未同定病原体の可能性。

**感染経路と病態**

性交渉（膣性交、口腔性交、肛門性交）により粘膜接触で伝播する。病原体は円柱上皮に感染し、局所の炎症反応を惹起する。クラミジアは封入体を形成しながら細胞内で増殖し、細胞破壊後に周囲に拡大する。M. genitaliumは粘膜上皮細胞に接着し、慢性炎症を持続させる。

**合併症**

- 男性: 精巣上体炎、反応性関節炎（Reiter症候群）
- 女性: PID、卵管炎、子宮外妊娠、不妊症
- 新生児: 産道感染による新生児結膜炎・肺炎（クラミジア）

### 診断基準・鑑別疾患

**診断基準**

- 尿道分泌物の存在、または初尿沈渣でWBC 5個/HPF以上
- 淋菌NAAT陰性を確認
- クラミジアNAAT（核酸増幅検査）で原因を同定
- M. genitaliumのNAAT検査は保険適用外だが、治療不応例では考慮

**初尿採取の注意点**

- 最終排尿から2時間以上空けて初尿10-20mLを採取
- 中間尿（膀胱炎検査用）では尿道の病原体が洗い流されるため不適

**鑑別疾患**

| 疾患 | 特徴 |
|------|------|
| 淋菌性尿道炎 | 膿性分泌物（黄色・ドロッと）、潜伏期2-7日と短い |
| 膀胱炎 | 頻尿・残尿感が主体、尿道分泌物なし |
| 前立腺炎 | 会陰部痛、DREで圧痛 |
| 尿道異物・結石 | 血尿、画像で確認 |
| 反応性尿道炎 | 無菌性、全身性疾患に伴う |

**淋菌性 vs 非淋菌性の臨床的鑑別**

- 淋菌性: 潜伏期2-7日、膿性分泌物（黄色）、症状が強い
- 非淋菌性: 潜伏期1-3週、漿液性分泌物（透明〜白色）、症状が軽い
- ただし臨床所見のみでの鑑別は困難であり、NAAT検査による確定が必須

### エビデンス・ガイドライン推奨

**第一選択（日本性感染症学会ガイドライン2020準拠）**

- **アジスロマイシン（AZM）1g 単回投与:** クラミジアに対する治癒率95%以上。服薬コンプライアンスに優れる。ただしM. genitaliumに対しては単回投与での治癒率は低い（耐性株では30%程度）。
- **ドキシサイクリン（DOXY）100mg 1日2回 7日間:** クラミジアに対する治癒率は同等。M. genitaliumに対してはAZMより劣る（治癒率30-40%）が、耐性誘導のリスクが低い。

**M. genitalium耐性問題**

- 日本におけるマクロライド耐性M. genitaliumは40-50%と報告されている
- AZM単回投与後の治療失敗はマクロライド耐性を強く示唆
- 耐性株に対してはAZM extended regimen（初日500mg、2-5日目250mg/日）の治癒率は約60-70%
- シタフロキサシン（STFX）100mg 1日2回 7日間が耐性M. genitaliumに有効（治癒率80-90%）
- 国際的にはモキシフロキサシンが推奨されるが、日本ではSTFXの有効性データが蓄積されている

**治癒確認**

- 治療終了3週間後にNAAT再検を推奨
- 2週間以内の再検はDead DNAによる偽陽性のリスクがある
- クラミジア・M. genitaliumとも治癒確認が望ましい

**パートナー治療**

- 全てのSTIにおいてパートナー同時治療が必須
- 未治療パートナーからのピンポン感染を防止
- パートナーにも同一レジメンを処方
