<h3 className="soap-a">評価</h3>

- **診断根拠:** 他院エコーや検診での指摘。肥満、肝機能障害（ALT優位）。
- **除外:** アルコール摂取量20g/日以下、B/C型肝炎陰性。
- **リスク評価:** FIB-4 Index ＿点 &lt;1.3:低リスク / &gt;2.67:高リスク

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** 食事・運動療法による減量（体重の7%減少を目標）。
- 肝機能障害が持続する場合は薬物療法を検討。
- FIB-4高値例は肝臓専門医へ紹介（肝生検・エラストグラフィ検討）。

## 📖 詳細解説

### 病態生理

- **定義**: 2023年に国際的にNAFLD/NASHからMASLD/MASHへ名称変更。代謝異常関連脂肪性肝疾患
- **MASLD**: 肝細胞の5%以上に脂肪沈着 + 心代謝リスク因子（肥満、糖尿病、脂質異常症、高血圧）1つ以上
- **MASH**: MASLD + 肝細胞障害（風船様変性）+ 炎症。線維化が進行すると肝硬変・肝癌へ
- **二段階仮説**: 1st hit（脂肪蓄積: インスリン抵抗性）→ 2nd hit（酸化ストレス、炎症、線維化）
- **疫学**: 日本の有病率約25-30%。肥満・糖尿病の増加に伴い増加中

### 診断基準・鑑別疾患

- **診断**: 腹部超音波で輝度肝（bright liver）+ アルコール摂取量が少ない（男性30g/日未満、女性20g/日未満）
- **線維化評価**: FIB-4 index（年齢 x AST / 血小板 x ALT平方根）。1.3未満: 低リスク、2.67以上: 高リスク → 肝臓専門医紹介
- **鑑別**: アルコール性肝障害、薬剤性肝障害、自己免疫性肝炎、ウイルス性肝炎

### エビデンス・ガイドライン推奨

- **最も重要な治療**: 体重減少。7-10%の減量でMASH改善のエビデンス
- **運動**: 有酸素運動（週150分以上）。体重減少がなくても肝脂肪を減少
- **食事**: 地中海食パターン。果糖・加工食品の制限
- **薬物療法**: 糖尿病合併時にGLP-1受容体作動薬（セマグルチド: 肝脂肪・炎症改善のエビデンス）、ピオグリタゾン（MASH改善のRCTあり）、SGLT2阻害薬
- **レスメチロム（Resmetirom）**: 2024年FDA承認のMASH治療薬（甲状腺ホルモン受容体beta作動薬）。日本未承認
- **肝癌スクリーニング**: 線維化が進行した患者は6ヶ月ごとの腹部超音波 + AFP
