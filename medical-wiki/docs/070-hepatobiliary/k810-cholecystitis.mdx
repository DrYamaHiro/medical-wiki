## 📖 詳細解説

### 病態生理

- **定義**: 胆嚢の急性炎症。90%以上が胆石嵌頓に起因（結石性胆嚢炎）
- **病態**: 胆嚢管への結石嵌頓 → 胆嚢内圧上昇 → 粘膜障害 → 二次性細菌感染 → 壊疽・穿孔のリスク
- **無石胆嚢炎（10%）**: ICU患者、外傷後、糖尿病、HIV感染など。予後不良

### 診断基準・鑑別疾患

- **Tokyo Guidelines 2024 (TG24)による診断基準**:
  - A: 局所炎症所見（Murphy徴候陽性、右上腹部腫瘤・圧痛）
  - B: 全身炎症所見（発熱、CRP上昇、WBC上昇）
  - C: 画像所見（超音波: 胆嚢壁肥厚4mm以上、胆嚢周囲液貯留、嵌頓結石）
  - A + B + C で確定診断
- **重症度分類（TG24）**: Grade I（軽症）、Grade II（中等症: 局所合併症）、Grade III（重症: 臓器障害）
- **鑑別**: 急性膵炎、消化性潰瘍穿孔、急性虫垂炎（高位）、右腎盂腎炎、Fitz-Hugh-Curtis症候群

### エビデンス・ガイドライン推奨

- **Grade I**: 抗菌薬 + 早期腹腔鏡下胆嚢摘出術（発症72時間以内が望ましい）
- **Grade II**: 抗菌薬 + 発症早期の手術。全身状態不良なら経皮経肝胆嚢ドレナージ（PTGBD）
- **Grade III**: 臓器サポート + 抗菌薬 + PTGBD。全身状態安定後に手術
- **抗菌薬**: SBT/ABPC 1.5-3g 6-8時間ごと、または CMZ + MNZ
- **プライマリケアでの対応**: Murphy徴候陽性 + 発熱 + 超音波異常 → 外科紹介を急ぐ
