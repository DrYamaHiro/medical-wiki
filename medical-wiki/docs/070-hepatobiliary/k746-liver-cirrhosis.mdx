## 📖 詳細解説

### 病態生理

- **定義**: 慢性肝疾患の終末像。びまん性の線維化と再生結節形成による肝構造の破壊
- **原因（日本）**: ウイルス性（B型・C型）が減少傾向、MASLD/アルコール性が増加
- **代償期 vs 非代償期**: 代償期は肝機能が保たれている。非代償期は黄疸、腹水、肝性脳症、食道静脈瘤出血が出現
- **門脈圧亢進**: 肝内血管抵抗上昇 → 門脈圧上昇 → 側副血行路（食道静脈瘤、腹壁静脈拡張）、脾腫、腹水
- **非代償期への移行**: 代償期肝硬変から非代償期への年間移行率は約5-7%

### Child-Pugh分類テーブル

| 項目 | 1点 | 2点 | 3点 |
|---|---|---|---|
| 肝性脳症 | なし | I-II度（軽度） | III-IV度（昏睡） |
| 腹水 | なし | 軽度（利尿薬で制御可能） | 中等度以上（治療抵抗性） |
| 血清ビリルビン (mg/dL) | 2.0未満 | 2.0-3.0 | 3.0超 |
| 血清アルブミン (g/dL) | 3.5超 | 2.8-3.5 | 2.8未満 |
| PT-INR | 1.7未満 | 1.7-2.3 | 2.3超 |

- **Grade A**: 5-6点（代償性。1年生存率 100%、2年生存率 85%）
- **Grade B**: 7-9点（1年生存率 80%、2年生存率 60%）
- **Grade C**: 10-15点（非代償性。1年生存率 45%、2年生存率 35%。肝移植を考慮）

### MELD-Naスコア

肝移植の優先順位決定および3ヶ月以内の死亡リスク予測に使用:

- **MELD計算式**: 9.57 x ln(Cr mg/dL) + 3.78 x ln(T-Bil mg/dL) + 11.2 x ln(INR) + 6.43
- **MELD-Na**: MELD + 1.32 x (137 - Na) - 0.033 x MELD x (137 - Na)（Na値は125-137に制限）
- **解釈**:
  - MELD-Na 15未満: 低リスク（3ヶ月死亡率 6%未満）
  - MELD-Na 15-20: 中等度リスク
  - MELD-Na 21-30: 高リスク（肝移植検討）
  - MELD-Na 30超: 極めて高リスク（3ヶ月死亡率 50%以上）
- **Child-Pughとの使い分け**: Child-Pughは臨床的重症度評価、MELD-Naは移植待機リスト優先順位と短期予後予測に使用

### 診断基準・鑑別疾患

- **検査**: 血小板低下（10万未満が目安）、アルブミン低下、PT延長、ICG R15上昇
- **画像**: 肝表面の不整、脾腫、腹水。エラストグラフィで肝硬度測定
- **FIB-4 index**: 年齢 x AST / (PLT x sqrt(ALT))。3.25以上で肝硬変を強く示唆

### 合併症管理プロトコル

#### 腹水管理

1. **初期治療**: 塩分制限（5-7g/日）+ スピロノラクトン50mg/日（最大400mg）+ フロセミド20mg/日（最大160mg）
2. **難治性腹水**: トルバプタン（サムスカ）3.75-7.5mg/日を追加。大量腹水穿刺（5L超の排液時はアルブミン 6-8g/L排液を補充）
3. **TIPS（経頸静脈肝内門脈大循環短絡術）**: 薬物治療抵抗性で頻回穿刺を要する場合に検討
4. **特発性細菌性腹膜炎（SBP）の管理**:
   - 腹水中の多核白血球 250/mm3以上でSBPと診断（培養結果を待たずに治療開始）
   - **治療**: セフォタキシム 1-2g 8-12時間ごと 静注 5日間（最大4g/日、日本の添付文書準拠）（または SBT/ABPC）
   - **アルブミン補充**: 発症日に1.5g/kg、3日目に1g/kg（腎不全予防、死亡率低下のエビデンス）
   - **二次予防**: ノルフロキサシン400mg/日 内服継続（日本では販売中止のため、代替としてシプロフロキサシン250-500mg/日やST合剤を検討）。SBP既往例の1年再発率は予防なしで70%

#### 食道静脈瘤管理

1. **スクリーニング**: 肝硬変診断時に上部消化管内視鏡。静脈瘤なし→3年ごと、小さい→1-2年ごと再検
2. **一次予防**: F2以上またはRC sign陽性 → 非選択的beta遮断薬（カルベジロール6.25-12.5mg/日）（※日本では門脈圧亢進症に対する保険適用外） or 内視鏡的静脈瘤結紮術（EVL）
3. **出血時**: 緊急EVL + オクトレオチド持続静注 + 予防的抗菌薬（セフトリアキソン1g/日 7日間）
4. **二次予防**: EVL + beta遮断薬の併用。TIPS は再出血のリスクが高い場合

#### 肝性脳症管理

1. **誘因の検索**: 便秘（最多）、感染症、消化管出血、電解質異常、脱水、過量蛋白摂取、薬剤（ベンゾジアゼピン等）
2. **治療**:
   - ラクツロース 30-60mL/日（排便2-3回/日を目標に用量調整）
   - リファキシミン 400mg 1日3回（ラクツロースとの併用で再発を有意に低減）
   - BCAA製剤（リーバクト）: 低アルブミン血症を伴う肝性脳症に有効
3. **便秘の徹底管理**: 酸化マグネシウム、ラクツロースで毎日排便を確保

### HCCサーベイランス

- **対象**: 全ての肝硬変患者（病因を問わず）
- **検査間隔**: 超高リスク群（肝硬変）は3-4ヶ月ごと、高リスク群（慢性肝炎）は6ヶ月ごと
- **検査内容**: 腹部超音波 + AFP + PIVKA-II（+ AFP-L3%を考慮）
- **動的CT/MRI**: 超音波で結節を認めた場合、またはAFP/PIVKA-II上昇時に施行
- **EOB-MRI**: 超音波で描出困難な症例、早期HCCの検出に有用

### エビデンス・ガイドライン推奨

- **原因治療**: HCV-DAA（肝硬変でも使用可能）、B型核酸アナログ、禁酒、MASLD管理
- **栄養療法**: BCAA製剤（リーバクト顆粒: 低アルブミン血症改善）、late evening snack（就寝前捕食 200kcal程度: 早朝の飢餓状態を回避し栄養状態・肝性脳症を改善）
- **サルコペニア対策**: 肝硬変患者の約30-40%にサルコペニア合併。適度な有酸素運動 + BCAA補充 + 十分な蛋白摂取
- **肝移植**: Child-Pugh C、MELD-Na 15以上、難治性腹水、反復性肝性脳症、HCC合併（ミラノ基準内）で検討
