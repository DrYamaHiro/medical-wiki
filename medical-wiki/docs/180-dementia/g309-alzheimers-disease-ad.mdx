<h3 className="soap-s">主訴・ROS</h3>

主訴: 家族の勧め / もの忘れ外来希望 / 区の検診 / 介護保険申請のため

**中核症状 (認知機能)**

- **短期記憶:** 同じことを何度も聞く / 置き忘れ / 約束を忘れる
- **見当識:** 日付が不明 / 道に迷う / 季節感がない
- **実行機能:** 料理の手順が悪くなった / 家電が使えない / 釣銭計算ができない

**周辺症状 (BPSD)**

- **精神系:** 幻視・幻聴 / 物盗られ妄想 / 嫉妬妄想 / 易怒性・暴言 / 徘徊 / 夜間せん妄 / 睡眠障害 / 介護抵抗

**生活機能 (DASC-21等)**

- **ADL:** 自立 / 一部介助 / 全介助
- **IADL:** 買い物 / 服薬管理 / 金銭管理

**背景・ROS**

- **全身症状:** 体重変化 なし / 増加 / 減少 ＿kg, 食欲 良好 / 低下 / 過食 / 異食
- **精神・神経:** 物忘れ 有, 呂律難 有 / 無, 歩行障害 有 / 無, 睡眠 良好 / 不眠
- **学歴・職歴:** ＿
- **嗜好品:** 飲酒 なし / 機会飲酒 / 多飲 ；アルコール性除外
- **家族歴:** 認知症 / 脳卒中

<h3 className="soap-o">所見・検査</h3>

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

**神経学的所見**

- **麻痺:** 有 / 無
- **歩行障害:** 小刻み / すくみ / ワイドベース / なし
- **不随意運動:** 固縮 / 振戦 / ミオクローヌス / なし

**神経心理検査**

- **HDS-R:** ＿/30点, MMSE: ＿/30点
- **時計描画試験(CDT):** 正常 / 異常

**院内迅速**

- **血糖:** ＿ mg/dL, HbA1c: ＿ %

**除外診断用採血 (外注)**

- 甲状腺機能(TSH/FT4), ビタミンB1/B12/葉酸, 電解質, 肝腎機能

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[Treatable Dementiaの除外]** 「治る認知症」を見逃さないこと。1. 慢性硬膜下血腫(CT依頼), 2. 正常圧水頭症(iNPH)(CT依頼), 3. 甲状腺機能低下症, 4. ビタミン欠乏症(B1, B12, 葉酸)の除外はプライマリケア医の責務である。
>
> **[聴取テクニック]** 本人に「今日は何を食べましたか？」と聞き、答えられても安心せず家族に確認せよ。「取り繕い反応」に騙されないことが診断の第一歩。
>
> **[自動車運転]** 診断がついた時点で道路交通法に基づき運転は「禁止」となる。「法律で決まっている」「事故を起こしてからでは遅い」と明確に引導を渡すこと。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 近時記憶障害主体、HDS-R 20点以下、緩徐進行、病識欠如。
- **重症度:** 軽度 / 中等度 / 高度 FAST分類: ＿
- **画像所見:** 海馬萎縮、後部帯状回血流低下（他院連携情報に基づく）。
- **鑑別・除外:** レビー小体型認知症、血管性認知症、Treatable Dementiaを否定。

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** 抗認知症薬による進行抑制。介護保険申請、ケアマネ連携、BPSD対応。

## 📖 詳細解説

### 病態生理

- **アルツハイマー型認知症（AD）**は認知症の約60-70%を占める最多の原因疾患
- **アミロイドカスケード仮説**: アミロイドbeta蛋白の異常蓄積→老人斑形成→タウ蛋白の過リン酸化→神経原線維変化→シナプス障害・神経細胞死→脳萎縮（海馬→側頭頭頂葉）
- **進行**: 記銘力障害（近時記憶）→見当識障害→判断力低下→失語・失行・失認→ADL障害→全介助
- **経過**: 発症から平均8-12年。緩徐進行性

### 診断基準・鑑別疾患

- **NIA-AA診断基準（2011）**: (1) 認知症の存在 (2) 潜行性発症 (3) 明確な認知機能低下の病歴 (4) 初期の顕著な認知障害が記憶障害型（最多）or 非記憶障害型
- **スクリーニング検査**: **[HDS-R（長谷川式）](../810-Calculators/psychiatry/hdsr)**（20点以下で認知症疑い）、MMSE（23点以下）。高齢者のうつ状態の除外には**[GDS-15](../810-Calculators/psychiatry/gds15)**も併用
- **画像所見**: MRIで海馬萎縮（VSRAD 1.0以上）、頭頂側頭葉の萎縮。SPECTで後部帯状回・頭頂側頭葉の血流低下
- **鑑別（treatable dementia）**: 甲状腺機能低下症、ビタミンB12欠乏、正常圧水頭症、慢性硬膜下血腫、うつ病性仮性認知症

### エビデンス・ガイドライン推奨

- **コリンエステラーゼ阻害薬**（軽度〜中等度）:
  - ドネペジル（アリセプト）3mgから開始、5mg維持（中等度以上は10mg）
  - ガランタミン（レミニール）8mgから、16-24mg
  - リバスチグミン貼付剤（リバスタッチ/イクセロン）4.5mgから、18mg
- **NMDA受容体拮抗薬**（中等度〜重度）: メマンチン（メマリー）5mgから開始、20mg。ChEIとの併用可
- **抗アミロイドbeta抗体薬**: レカネマブ（レケンビ）2023年日本承認。早期ADに適応。アミロイドbetaを除去し認知機能低下を27%抑制（Clarity AD試験）。ARIA（脳浮腫・微小出血）のリスクに注意
- **非薬物療法**: 回想法、音楽療法、運動療法、適切な環境整備
- **自動車運転**: 認知症と診断された場合、道路交通法により運転免許の取消・停止の対象
