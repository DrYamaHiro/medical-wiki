<h3 className="soap-s">主訴・ROS</h3>

主訴: 家族の勧め / もの忘れ外来希望 / 区の検診 / 介護保険申請のため

**中核症状 (認知機能)**

- **短期記憶:** 同じことを何度も聞く / 置き忘れ / 約束を忘れる
- **見当識:** 日付が不明 / 道に迷う / 季節感がない
- **実行機能:** 料理の手順が悪くなった / 家電が使えない / 釣銭計算ができない

**周辺症状 (BPSD)**

- **精神系:** 幻視・幻聴 / 物盗られ妄想 / 嫉妬妄想 / 易怒性・暴言 / 徘徊 / 夜間せん妄 / 睡眠障害 / 介護抵抗

**生活機能 (DASC-21等)**

- **ADL:** 自立 / 一部介助 / 全介助
- **IADL:** 買い物 / 服薬管理 / 金銭管理

**背景・ROS**

- **全身症状:** 体重変化 なし / 増加 / 減少 ＿kg, 食欲 良好 / 低下 / 過食 / 異食
- **精神・神経:** 物忘れ 有, 呂律難 有 / 無, 歩行障害 有 / 無, 睡眠 良好 / 不眠
- **学歴・職歴:** ＿
- **嗜好品:** 飲酒 なし / 機会飲酒 / 多飲 ；アルコール性除外
- **家族歴:** 認知症 / 脳卒中

<h3 className="soap-o">所見・検査</h3>

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

**神経学的所見**

- **麻痺:** 有 / 無
- **歩行障害:** 小刻み / すくみ / ワイドベース / なし
- **不随意運動:** 固縮 / 振戦 / ミオクローヌス / なし

**神経心理検査**

- **HDS-R:** ＿/30点, MMSE: ＿/30点
- **時計描画試験(CDT):** 正常 / 異常

**院内迅速**

- **血糖:** ＿ mg/dL, HbA1c: ＿ %

**除外診断用採血 (外注)**

- 甲状腺機能(TSH/FT4), ビタミンB1/B12/葉酸, 電解質, 肝腎機能

> 💡 **Dr.Advice**
>
> **[Treatable Dementiaの除外]** 「治る認知症」を見逃さないこと。1. 慢性硬膜下血腫(CT依頼), 2. 正常圧水頭症(iNPH)(CT依頼), 3. 甲状腺機能低下症, 4. ビタミン欠乏症(B1, B12, 葉酸)の除外はプライマリケア医の責務である。
>
> **[聴取テクニック]** 本人に「今日は何を食べましたか？」と聞き、答えられても安心せず家族に確認せよ。「取り繕い反応」に騙されないことが診断の第一歩。
>
> **[自動車運転]** 診断がついた時点で道路交通法に基づき運転は「禁止」となる。「法律で決まっている」「事故を起こしてからでは遅い」と明確に引導を渡すこと。

<h3 className="soap-a">評価</h3>

- **主症状:** 易怒性 / 暴言・暴力 / 介護抵抗 / 徘徊 / 幻視 / 抑うつ / 夜間不穏
- **誘因分析:** 便秘 / 疼痛 / 薬剤性 / 環境変化 / コミュニケーション不全 / 不明
- **重症度:** 在宅可能 / 介護崩壊の危機 / 入院検討

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** 1.身体的原因(便秘・痛)の除去、2.非薬物的介入、3.薬物療法（抑肝散を第一選択とする）。

- **患者指導:** 興奮の原因が便秘や体の痛みである可能性を説明。否定しない対応を指導。
- **再診目安:** 1-2週間後

## 📖 詳細解説

### 病態生理

- **BPSD（認知症の行動・心理症状）**は認知症に伴う行動障害と心理症状の総称
- **行動症状**: 徘徊、攻撃性、不穏、拒食、異食、収集癖、介護抵抗
- **心理症状**: 妄想（物盗られ妄想が最多）、幻覚、うつ、不安、アパシー、易刺激性
- 認知症患者の約80-90%がいずれかのBPSDを経験。介護負担の最大の原因
- **誘因**: 身体的不調（疼痛、便秘、尿閉、感染症）、環境変化、不適切な対応、薬剤（抗コリン薬）

### 診断基準・鑑別疾患

- **BPSD出現時のチェックリスト**: (1)身体的原因の検索（発熱、脱水、便秘、尿閉、疼痛） (2)薬剤性せん妄の除外 (3)環境要因の評価 (4)うつ病の合併評価
- **NPI（Neuropsychiatric Inventory）**: BPSDの系統的評価スケール

### エビデンス・ガイドライン推奨

- **非薬物療法が第一選択**（推奨度A）:
  - 身体的原因の除去（最優先）
  - 環境調整: 穏やかな対応、日課の安定、適切な照明
  - 回想法、音楽療法、アロマセラピー、動物介在療法
- **薬物療法**（非薬物療法で不十分な場合に限定的に使用）:
  - **抑肝散**: BPSDに対する第一選択漢方。攻撃性、興奮、幻覚に有効。2.5g x 3回/日
  - **リスペリドン**: 0.5-1mg/日。攻撃性・幻覚・妄想に。脳血管障害リスク増大の警告あり（最小量・最短期間で）
  - **クエチアピン**: 12.5-50mg。DLBの場合はリスペリドンより安全。※糖尿病患者には禁忌
  - **トラゾドン（デジレル）**: 25-50mg。不眠・夕暮れ症候群に
  - 全ての抗精神病薬は認知症患者の死亡率を約1.6-1.7倍増加させるため、慎重な適応判断が必要
- **DLBの幻視**: まずChEI増量、次に抑肝散。抗精神病薬は過敏性に注意
