<h3 className="soap-s">主訴・ROS</h3>

主訴: 家族の勧め / もの忘れ外来希望 / 区の検診 / 介護保険申請のため

**中核症状 (認知機能)**

- **短期記憶:** 同じことを何度も聞く / 置き忘れ / 約束を忘れる
- **見当識:** 日付が不明 / 道に迷う / 季節感がない
- **実行機能:** 料理の手順が悪くなった / 家電が使えない / 釣銭計算ができない

**周辺症状 (BPSD)**

- **精神系:** 幻視・幻聴 / 物盗られ妄想 / 嫉妬妄想 / 易怒性・暴言 / 徘徊 / 夜間せん妄 / 睡眠障害 / 介護抵抗

**生活機能 (DASC-21等)**

- **ADL:** 自立 / 一部介助 / 全介助
- **IADL:** 買い物 / 服薬管理 / 金銭管理

**背景・ROS**

- **全身症状:** 体重変化 なし / 増加 / 減少 ＿kg, 食欲 良好 / 低下 / 過食 / 異食
- **精神・神経:** 物忘れ 有, 呂律難 有 / 無, 歩行障害 有 / 無, 睡眠 良好 / 不眠
- **学歴・職歴:** ＿
- **嗜好品:** 飲酒 なし / 機会飲酒 / 多飲 ；アルコール性除外
- **家族歴:** 認知症 / 脳卒中

<h3 className="soap-o">所見・検査</h3>

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃

**神経学的所見**

- **麻痺:** 有 / 無
- **歩行障害:** 小刻み / すくみ / ワイドベース / なし
- **不随意運動:** 固縮 / 振戦 / ミオクローヌス / なし

**神経心理検査**

- **HDS-R:** ＿/30点, MMSE: ＿/30点
- **時計描画試験(CDT):** 正常 / 異常

**院内迅速**

- **血糖:** ＿ mg/dL, HbA1c: ＿ %

**除外診断用採血 (外注)**

- 甲状腺機能(TSH/FT4), ビタミンB1/B12/葉酸, 電解質, 肝腎機能

> 💡 **Dr.Advice**
>
> **[Treatable Dementiaの除外]** 「治る認知症」を見逃さないこと。1. 慢性硬膜下血腫(CT依頼), 2. 正常圧水頭症(iNPH)(CT依頼), 3. 甲状腺機能低下症, 4. ビタミン欠乏症(B1, B12, 葉酸)の除外はプライマリケア医の責務である。
>
> **[聴取テクニック]** 本人に「今日は何を食べましたか？」と聞き、答えられても安心せず家族に確認せよ。「取り繕い反応」に騙されないことが診断の第一歩。
>
> **[自動車運転]** 診断がついた時点で道路交通法に基づき運転は「禁止」となる。「法律で決まっている」「事故を起こしてからでは遅い」と明確に引導を渡すこと。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 認知機能の日内変動、具体的幻視、パーキンソン症状、REM睡眠行動障害。
- **評価尺度:** HDS-RとMMSEの解離（MMSEでの視空間認知低下）。
- **鑑別・除外:** パーキンソン病、アルツハイマー型認知症。

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** 抗認知症薬（ドネペジル）主体の治療。薬剤過敏性に最大限注意。

#### 処方・処置 (選択)

**第一選択**

<span className="med-id">[Rx-Dem-Don3] ドネペジル塩酸塩錠3mg</span>
- ドネペジル塩酸塩錠3mg 1回1錠 1日1回 朝食後 14日分 *— 幻視改善・覚醒*

**BPSD・REM睡眠行動障害**

<span className="med-id">[Rx-Kampo-054] ツムラ抑肝散(54)エキス顆粒 2.5g</span>
- ツムラ抑肝散(54)エキス顆粒 2.5g 1回1包 1日3回 食前 28日分

**パーキンソン症状**

<span className="med-id">[Rx-Neuro-PD-Lev] マドパー配合錠</span>
- マドパー配合錠 1回1錠 1日3回 毎食後 28日分 *— 少量から開始*

#### 指導・計画 (必須)

- **患者指導:** 調子の良し悪し（変動）自体が病気の症状であることを家族へ説明。
- **再診目安:** 2-4週間後

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[薬剤過敏性（禁忌）]** 抗精神病薬に対して極めて過敏であり、少量でも悪性症候群や寝たきりリスクがある。「幻覚があるから」と安易に抗精神病薬を処方せず、ドネペジルと抑肝散で対応せよ。

## 📖 詳細解説

### 病態生理

- **DLB**は認知症の約10-20%を占める第2位の変性性認知症。alpha-シヌクレインの異常蓄積（レビー小体）が脳幹・大脳皮質に広がる
- パーキンソン病と同一スペクトラムの疾患（運動症状が先→PDD、認知症が先→DLB）
- **三大中核症状**: 認知機能の変動（日によって/時間帯によって大きく変動）、繰り返す幻視（具体的で鮮明）、パーキンソニズム

### 診断基準・鑑別疾患

- **DLB臨床診断基準（第4回国際ワークショップ 2017）**:
  - 中核的臨床特徴（2つ以上でprobable）: (1)認知の変動 (2)反復する幻視 (3)REM睡眠行動障害 (4)パーキンソニズム
  - 指標的バイオマーカー: DATスキャンで線条体の取り込み低下、MIBG心筋シンチで取り込み低下、PSGでREM睡眠筋弛緩の消失
- **鑑別**: AD（変動・幻視・パーキンソニズムが乏しい）、パーキンソン病認知症（運動症状が1年以上先行）
- **薬剤過敏性**: 抗精神病薬に対する重篤な過敏反応（悪性症候群リスク）。BPSDへの抗精神病薬使用は極めて慎重に

### エビデンス・ガイドライン推奨

- **認知機能障害**: ドネペジル（アリセプト）3mg→5mg→10mg（DLBへの保険適用あり）。幻視の改善効果も期待
- **パーキンソニズム**: レボドパ少量（100-300mg/日）から開始。幻視増悪に注意
- **REM睡眠行動障害**: クロナゼパム0.25-0.5mg就寝前
- **幻視・妄想**: まず環境調整・安心感の提供。薬物はドネペジル増量、抑肝散。抗精神病薬は原則禁忌（やむを得ない場合はクエチアピン12.5mg等を極少量から）
- **抑うつ**: SSRI（セルトラリン等）。三環系は抗コリン作用で認知機能悪化のリスク
