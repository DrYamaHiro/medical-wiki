<h3 className="soap-s">主訴・ROS</h3>

主訴: 家族の勧め / もの忘れ外来希望 / 区の検診 / 介護保険申請のため

**中核症状 (認知機能)**

- **短期記憶:** 同じことを何度も聞く / 置き忘れ / 約束を忘れる
- **見当識:** 日付が不明 / 道に迷う / 季節感がない
- **実行機能:** 料理の手順が悪くなった / 家電が使えない / 釣銭計算ができない

**周辺症状 (BPSD)**

- **精神系:** 幻視・幻聴 / 物盗られ妄想 / 嫉妬妄想 / 易怒性・暴言 / 徘徊 / 夜間せん妄 / 睡眠障害 / 介護抵抗

**生活機能 (DASC-21等)**

- **ADL:** 自立 / 一部介助 / 全介助
- **IADL:** 買い物 / 服薬管理 / 金銭管理

**背景・ROS**

- **全身症状:** 体重変化 なし / 増加 / 減少 ＿kg, 食欲 良好 / 低下 / 過食 / 異食
- **精神・神経:** 物忘れ 有, 呂律難 有 / 無, 歩行障害 有 / 無, 睡眠 良好 / 不眠
- **学歴・職歴:** ＿
- **嗜好品:** 飲酒 なし / 機会飲酒 / 多飲 ；アルコール性除外
- **家族歴:** 認知症 / 脳卒中

> 💡 **Dr.Advice**
>
> **[Treatable Dementiaの除外]** 「治る認知症」を見逃さないこと。1. 慢性硬膜下血腫(CT依頼), 2. 正常圧水頭症(iNPH)(CT依頼), 3. 甲状腺機能低下症, 4. ビタミン欠乏症(B1, B12, 葉酸)の除外はプライマリケア医の責務である。
>
> **[聴取テクニック]** 本人に「今日は何を食べましたか？」と聞き、答えられても安心せず家族に確認せよ。「取り繕い反応」に騙されないことが診断の第一歩。
>
> **[自動車運転]** 診断がついた時点で道路交通法に基づき運転は「禁止」となる。「法律で決まっている」「事故を起こしてからでは遅い」と明確に引導を渡すこと。

## 📖 詳細解説

### 病態生理

- **介護保険主治医意見書**は要介護認定の審査判定に用いられる医学的意見書。主治医が作成する義務がある
- 65歳以上（第1号被保険者）は原因を問わず申請可能。40-64歳（第2号被保険者）は16の特定疾病に限定
- **特定疾病**: がん末期、関節リウマチ、ALS、骨折を伴う骨粗鬆症、認知症（初老期）、パーキンソン病、脳血管疾患、糖尿病性神経障害・腎症・網膜症、COPD、脊柱管狭窄症、早老症、多系統萎縮症、変形性関節症、閉塞性動脈硬化症、慢性閉塞性肺疾患、後縦靱帯骨化症

### 診断基準・鑑別疾患

- **要介護度の目安**:
  - 要支援1-2: 基本的ADL自立だが手段的ADLに一部支援が必要
  - 要介護1: 部分的介護。立ち上がり・歩行に不安定
  - 要介護2: 軽度の介護。ADLの一部に介助
  - 要介護3: 中等度の介護。排泄・入浴等に全面的介助
  - 要介護4: 重度の介護。日常生活ほぼ全般に介助
  - 要介護5: 最重度。寝たきり、意思疎通困難
- **認知症の日常生活自立度**: I（ほぼ自立）→IIa/IIb（日常生活に支障）→IIIa/IIIb（介護必要）→IV（常に介護必要）→M（専門医療）

### エビデンス・ガイドライン推奨

- **意見書記載のポイント**:
  - 現在の身体・精神状態を具体的に記載。「できない」ことを明確に
  - 認知症がある場合: 日常生活自立度を正確に判定。BPSDの有無・内容を記載
  - 医学的管理の必要性: 内服管理、注射、リハビリ等の必要性を具体的に
  - 特記事項: 審査会への情報提供として最も重要。介護の手間がかかる具体的なエピソードを記載
- **在宅限界点の見極め**: 独居の認知症、頻回の転倒、誤嚥性肺炎の反復、介護者の疲弊・限界
- **サービス調整**: ケアマネージャーとの情報共有が重要。デイサービス、訪問看護、ショートステイ等の活用
