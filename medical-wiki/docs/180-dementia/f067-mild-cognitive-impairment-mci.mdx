<h3 className="soap-s">主訴・ROS</h3>

主訴: 家族の勧め / もの忘れ外来希望 / 区の検診 / 介護保険申請のため

**中核症状 (認知機能)**

- **短期記憶:** 同じことを何度も聞く / 置き忘れ / 約束を忘れる
- **見当識:** 日付が不明 / 道に迷う / 季節感がない
- **実行機能:** 料理の手順が悪くなった / 家電が使えない / 釣銭計算ができない

**周辺症状 (BPSD)**

- **精神系:** 幻視・幻聴 / 物盗られ妄想 / 嫉妬妄想 / 易怒性・暴言 / 徘徊 / 夜間せん妄 / 睡眠障害 / 介護抵抗

**生活機能 (DASC-21等)**

- **ADL:** 自立 / 一部介助 / 全介助
- **IADL:** 買い物 / 服薬管理 / 金銭管理

**背景・ROS**

- **全身症状:** 体重変化 なし / 増加 / 減少 ＿kg, 食欲 良好 / 低下 / 過食 / 異食
- **精神・神経:** 物忘れ 有, 呂律難 有 / 無, 歩行障害 有 / 無, 睡眠 良好 / 不眠
- **学歴・職歴:** ＿
- **嗜好品:** 飲酒 なし / 機会飲酒 / 多飲 ；アルコール性除外
- **家族歴:** 認知症 / 脳卒中

> 💡 **Dr.Advice**
>
> **[Treatable Dementiaの除外]** 「治る認知症」を見逃さないこと。1. 慢性硬膜下血腫(CT依頼), 2. 正常圧水頭症(iNPH)(CT依頼), 3. 甲状腺機能低下症, 4. ビタミン欠乏症(B1, B12, 葉酸)の除外はプライマリケア医の責務である。
>
> **[聴取テクニック]** 本人に「今日は何を食べましたか？」と聞き、答えられても安心せず家族に確認せよ。「取り繕い反応」に騙されないことが診断の第一歩。
>
> **[自動車運転]** 診断がついた時点で道路交通法に基づき運転は「禁止」となる。「法律で決まっている」「事故を起こしてからでは遅い」と明確に引導を渡すこと。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 物忘れの訴えあり、HDS-R 21-26点程度の客観的低下あり、ADLは保たれている。
- **リスク因子:** 高血圧 / 糖尿病 / 難聴 / 社会的孤立

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** 生活習慣病の徹底管理。認知的介入（運動・社会的交流）。現時点で抗認知症薬は適応外。

#### 指導・計画 (必須)

- **患者指導:** 「認知症の予備軍」ではなく「今なら引き返せるチャンス」と動機づけ。社会的交流やデュアルタスク、運動を推奨。
- **生活指導:** 難聴があれば補聴器の早期使用を強く推奨。
- **文書:** [ID: Doc-Gen-Lifestyle] 生活習慣病指導用パンフレット
- **再診目安:** 6-12ヶ月毎の経過観察（認知症への移行チェック）

## 📖 詳細解説

### 病態生理

- **MCI（軽度認知障害）**は正常加齢と認知症の中間段階。認知機能低下はあるがADL自立
- 年間約5-15%が認知症に進行（健常者の進行率は年1-2%）。約20-40%は正常に復帰
- **amnestic MCI**: 記憶障害が主体。ADへの進行リスクが高い
- **non-amnestic MCI**: 記憶以外（実行機能、言語等）の障害。DLB、前頭側頭型認知症への進行リスク

### 診断基準・鑑別疾患

- **Petersen基準**: (1)本人or家族からの認知機能低下の訴え (2)客観的な認知機能低下（年齢・教育に比して） (3)基本的ADLは保持 (4)認知症の診断基準を満たさない
- **NIA-AA基準（2011/2018）による生物学的定義:**
  - **ATNフレームワーク:** A（Amyloid）T（Tau）N（Neurodegeneration）の各バイオマーカーで病態を分類
  - **Amyloid PET:** Florbetapir/Florbetaben/Flutemetamol。陽性はAD病理の存在を示唆。MCI患者の約50-60%がamyloid PET陽性
  - **CSFバイオマーカー:** Aβ42低下（<500 pg/mL）、リン酸化Tau181上昇（>60 pg/mL）、Aβ42/40比低下。感度85-90%、特異度85-90%でAD病理を予測
  - **血漿バイオマーカー（研究段階）:** 血漿Aβ42/40比、血漿p-Tau217。スクリーニングツールとしての実用化が進む
- **スクリーニング**: HDS-R 21-25点程度、MMSE 24-27点程度のグレーゾーン。MoCA（Montreal Cognitive Assessment）がMCIに対する感度90%・特異度87%と高感度
- **除外**: うつ病、甲状腺機能低下症、ビタミンB12欠乏、薬剤性（抗コリン薬、BZD）

### コンバージョン率（MCI→認知症）

- **全体:** MCI患者の年間コンバージョン率は5-15%（メタ解析: Mitchellら 2009）
- **amnestic MCI:** AD への年間コンバージョン率 10-15%。5年で約50%がADに進行
- **amyloid PET陽性MCI:** 年間コンバージョン率 20-25%（amyloid陰性MCIでは5%未満）
- **正常復帰（Reversion）:** MCIから正常認知機能への復帰率は16-40%/年。ただし復帰後も将来の認知症リスクは健常者より高い

### エビデンス・ガイドライン推奨

- **確立された薬物療法はない:**
  - **ChEI MCI試験（いずれもnegative）:**
    - **ドネペジルMCI試験（Petersenら 2005, NEJM）:** 769名、3年間。ドネペジル10mg vs ビタミンE vs プラセボ。主要エンドポイント（AD発症率）に有意差なし（HR 0.80, 95%CI 0.57-1.13）。初期12ヶ月のみ一過性の効果
    - **ガランタミンMCI試験（2008）:** AD移行率に有意差なし。死亡率の上昇傾向あり試験早期中止
    - **リバスチグミンInChi試験（Feldmanら 2007）:** 1018名、4年間。AD移行率に有意差なし
  - **レカネマブ（レケンビ）:** 抗Aβ抗体。早期AD（MCI due to AD含む）に適応。CLARITY-AD試験で認知機能低下を27%抑制。2024年日本承認。Amyloid PET/CSF確認が必須
- **修正可能なリスク因子への介入**（Lancet Commission 2024）: 難聴補正、運動、社会参加、高血圧管理、糖尿病管理、うつ治療、禁煙、肥満管理、過度の飲酒回避。修正可能因子で認知症の約45%を予防可能と推定
- **運動**: 有酸素運動（週150分以上）がMCIの認知機能維持に有効なエビデンスあり（メタ解析: Hedges' g=0.3）
- **フォローアップ**: 6-12ヶ月ごとの認知機能評価。進行が見られた場合に認知症の診断・治療開始
