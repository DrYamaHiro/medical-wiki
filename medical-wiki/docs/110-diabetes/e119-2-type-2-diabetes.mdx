<h3 className="soap-a">評価</h3>

- **診断根拠:** 経口血糖降下薬（2-3剤併用）でもHbA1c目標未達、または高血糖毒性解除が必要。

<h3 className="soap-p">方針・処方</h3>

- インスリン導入前に、SGLT2阻害薬やGLP-1受容体作動薬（リベルサス、マンジャロ）の適応がないか再度検討する。
- BOT（Basal Supported Oral Therapy）の導入。
- 開始用量は原則4〜6単位に固定し、外来で安全にタイトレーションを行う。

## 📖 詳細解説

### 病態生理

- **2型糖尿病**はインスリン分泌低下とインスリン抵抗性を基盤とする慢性高血糖状態
- **日本人の特徴**: 欧米人と比較しインスリン分泌能が低く、非肥満でも発症（BMI 25未満が約50%）
- **インスリン導入の適応**:
  - 経口薬・GLP-1受容体作動薬でHbA1c目標未達成
  - 空腹時血糖 250mg/dL以上の持続
  - 随時血糖 350mg/dL以上
  - 尿ケトン体陽性、口渇・多飲・体重減少
  - 感染症、手術前後、ステロイド使用時
- **BOT（Basal supported Oral Therapy）**: 経口薬に持効型インスリン1日1回を追加する方法。インスリン導入の第一歩として推奨

### 診断基準・鑑別疾患

- **インスリン導入前の確認事項**:
  - 1型糖尿病の除外（抗GAD抗体、CPR測定）
  - 膵性糖尿病の除外（膵炎既往、腫瘍マーカー）
  - 内因性インスリン分泌能の評価: **[CPI（C-peptide Index）](../810-Calculators/physical-renal/cpi)**で分泌能を定量評価。空腹時CPR 0.5ng/mL未満は高度枯渇
  - 経口薬の最適化がなされているか（特にメトホルミンの十分量使用）
- **インスリン導入のタイミング判断**:
  - HbA1c 9%以上で糖毒性が疑われる場合は早期にインスリン導入し、糖毒性解除後に経口薬へ移行も考慮
  - 「インスリンは最後の手段」という患者の誤解を解くことが重要

### エビデンス・ガイドライン推奨

- **BOTのエビデンス**:
  - 持効型インスリン（グラルギンU100/U300、デグルデク）を就寝前または朝に1回注射
  - 開始量: 0.1-0.2単位/kg/日（通常4-8単位程度から開始）
  - 調節: 空腹時血糖 130mg/dL以上が3日続けば2単位増量（treat-to-target法）
  - 目標: 空腹時血糖 80-130mg/dL
- **インスリン製剤の選択**:
  - グラルギンU300（トレシーバと比較し低血糖が少ないとされる）
  - デグルデク（超長時間作用型、半減期25時間、日内変動少ない）
  - いずれも1日1回、注射時刻の多少のずれを許容
- **配合剤の選択肢**:
  - ゾルトファイ配合注（デグルデク+リラグルチド）: BOTで不十分な場合、食後血糖も改善
  - ソリクア配合注（グラルギン+リキシセナチド）: 同様の位置づけ
- **血糖管理目標**: HbA1c 7.0%未満（合併症予防）。低血糖リスクを考慮し個別化

### 日本人2型糖尿病の薬物治療アルゴリズム（日本糖尿病学会）

日本糖尿病学会が日本人の病態に即して提示した4ステップアルゴリズム。

- **ステップ1: 病態に応じた薬剤選択**
  - **肥満型（BMI 25以上）**: インスリン抵抗性が主体 → メトホルミン、SGLT2阻害薬、GLP-1受容体作動薬（セマグルチド/オゼンピック・リベルサス、デュラグルチド、リラグルチド）、チルゼパチド（マンジャロ）が第一選択
  - **非肥満型（BMI 25未満）**: インスリン分泌低下が主体 → DPP-4阻害薬、グリニド、SU薬、メトホルミンを考慮（日本人2型DM患者の約50-55%は非肥満型）
- **ステップ2: 安全性の配慮**
  - 低血糖リスク（高齢、腎機能低下、認知機能低下）→ SU薬・グリニド回避
  - 肝・腎機能障害例 → 用量調整、禁忌薬を避ける
- **ステップ3: 合併症の有無に応じた優先選択**
  - **慢性腎臓病（CKD）合併**: SGLT2阻害薬、GLP-1受容体作動薬を優先
  - **心不全（HF）合併**: SGLT2阻害薬を優先（LVEF不問でエビデンスあり）
  - **動脈硬化性心血管疾患（ASCVD）合併**: SGLT2阻害薬、GLP-1受容体作動薬を優先
- **ステップ4: 患者背景の考慮**: アドヒアランス、服薬負担、費用、患者の希望

### GLP-1受容体作動薬（セマグルチド：オゼンピック・リベルサス）の使い分け

- **オゼンピック（皮下注、週1回）**: 0.25mg/週で開始 → 4週後に0.5mg/週に増量（維持）→ 効果不十分なら1.0mg/週に増量。日本人2型DM患者308例の臨床試験でHbA1c 7.0%未満達成割合・体重減少効果を確認（ベースBMI 25未満が55.8%でも有効）
- **リベルサス（経口、1日1回）**: 3mg/日で開始（4週間） → 7mg/日（維持）→ 効果不十分なら14mg/日に増量。**服用注意**: 起床時、空腹時にコップ半分以下（120mL以下）の水で服用、その後30分は飲食・他薬服用を避ける（吸収率が大きく低下するため）。錠剤の分割は不可（吸収促進剤SNAC配合のため）
- **共通の有害事象**: 胃腸障害（悪心・嘔吐・下痢）が最多。胃排出遅延が機序。低用量から漸増することで軽減
- **腎保護作用**: 腎機能障害合併DM患者でプラセボより腎機能低下を緩徐化（FLOW試験等）
- **選択の指針**: 注射に抵抗のある患者にはリベルサス、確実な効果と1日服用回数を減らしたい場合はオゼンピックを推奨
