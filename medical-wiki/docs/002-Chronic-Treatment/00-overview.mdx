# 📖 Treatment Booster — 使い方と機能ガイド

慢性疾患 9 領域（HT / T2DM / 脂質異常症 / 喘息 / COPD / 痛風 / 不眠症 / 便秘症 / 頭痛）の **治療修正支援ツール** の横断ガイドです。

## 共通の設計思想

1. **現在の治療** + **コントロール状態** + **修飾因子（併存疾患・副作用・年齢層・妊娠など）** を入力
2. 4状態（**controlled / near_target / uncontrolled / overcontrolled**）を判定
3. 状態に応じて **MAINTAIN（現状維持）/ WATCH（経過観察）/ STEP_UP / ADD / SWITCH / TAPER / REFER** を合成して提示
4. 推奨の信頼度・優先度を可視化、医師が最終判断

すべての推奨に **note**（注意点）・**reason**（推奨理由）・**reassess**（再評価タイミング）が付帯します。

## 共通の操作フロー

| Phase | 内容 |
|---|---|
| **Phase 0** | リスク層別化（**脂質異常症のみ**。久山町スコア → LDL目標が即決） |
| **Phase 1** | 現在服用中の薬剤と用量を選択（未治療はスキップ可） |
| **Phase 2** | コントロール指標（HbA1c/家庭BP/LDL等）+ 修飾因子（併存疾患・副作用・年齢層・制約・Red Flag）を選択 |
| **Phase 3** | 適合度順に推奨が表示。Red Flag・MOH・薬物乱用は最優先で警告表示 |

数値入力をスキップして **状態を直接 chip 選択**（controlled/near_target/uncontrolled/overcontrolled）も可能。時短目的の補助UI。

## 各 Booster の特徴的機能

### 🟦 [高血圧 (HT)](./i10-hypertension-treatment) — JSH2025準拠
- **JSH2025 全年齢統一**: 家庭 &lt;125/75（診察室 &lt;130/80）
- **高齢者4カテゴリー**（Table 3）: ADL保持 / フレイル / ADL低下 / エンド・オブ・ライフ
- **白衣HT・仮面HT 自動検出**（診察室+家庭BP 両入力時）
- **Triple Whammy 警告**: ARB/ACEi + 利尿薬 + NSAID → AKI リスク
- **SGLT2i 連携**: DM併存 ARB/ACEi → 心腎保護併用リマインド
- **妊娠時メチルドパ第一選択**（ARB/ACEi 即時禁忌）
- **2次性HT スクリーニングパネル**: PRA/PAC・尿メタネフリン・腎動脈Doppler・TSH
- **ARNI**（サクビトリルバルサルタン）対応
- **就寝前投与提案**: 夜間HT/早朝HT/OSA併存
- 4カテゴリー目標は **chip group 排他選択**（必ず1つ選択）

### 🟧 [2型糖尿病 (T2DM)](./e11-t2dm-treatment) — JDS2024 + JGS/JDS高齢者GL2023準拠
- 17薬剤実装（ビグアナイド・SGLT2i・GLP-1RA・DPP-4i・SU・グリニド・α-GI・TZD・インスリン）
- **高齢者3カテゴリー**（Cat I/II/III、JGS/JDS2023）— **chip group 排他選択**
- **合併症駆動の薬剤選択**:
  - HF/CKD/ASCVD → SGLT2i 第一
  - 肥満+ASCVD → GLP-1RA 第一
  - 高齢・低血糖回避 → DPP-4i 第一
  - CKD G3-G5 で **リナグリプチン明示**
- **症候性高血糖（HbA1c≥10%）**: 紹介待ちブリッジ治療 rec（メトホルミン最大量 + SGLT2i併用検討）
- **GDM 専用パス**: 食事療法+インスリン視野、産科+栄養士+糖尿病内科3者連携
- **T1DM ガード**: 起動時に対象外+専門医継続を明示
- **胃切除後 DM 配慮**: B12/鉄/葉酸スクリーニング、薬剤選択ガイド
- **過降下検出**（下限未満 or 頻回低血糖 with SU/グリニド/インスリン）→ TAPER
- **Sick day ルール** 自動アラート（SGLT2i・メトホルミン）
- **妊娠 + 経口薬** 検出と切替推奨

### 🟨 [脂質異常症 (DLP)](./e78-dyslipidemia-treatment) — JAS2022準拠
- **Phase 0 リスク層別化**（7カテゴリー排他選択）→ LDL目標自動決定
  - FH+ASCVD: &lt;55-70 / 二次予防超高リスク: &lt;70 / 二次予防: &lt;100 / FH一次: &lt;100 / 一次高リスク: &lt;120 / 一次中: &lt;140 / 一次低: &lt;160
- **Phase 0 不整合検出**: cm_fh_suspect なのに risk_primary_low 選択 → 修正提案
- **超高リスク自動 upgrade**: risk_secondary + cm_dm → risk_very_high
- **TG重症度段階**: cm_severe_hypertg (≥500、膵炎リスク) / cm_extreme_hypertg (≥1000、即日精査)
- **二次性脂質異常症 検出**: 甲状腺機能低下・ネフローゼ・閉塞性黄疸・閉経
- **SAMS 再チャレンジ戦略**: drug holiday → 低強度 or 週1-2回投与
- **CYP3A4相互作用**: アトルバ/シンバ + マクロライド/アゾール → 切替推奨
- **スタチン+フィブラート併用警告**（ペマ以外横紋筋融解症）
- **ハイ強度 + LDL&lt;40** → TAPER 検討
- **妊娠/挙児希望で全スタチン・フィブラート即中止**
- **NAFLD/MASH** modifier 対応

### 🟩 [気管支喘息](./j45-asthma-treatment) — JGL2024 + GINA 2024準拠
- 約30薬剤（ICS×6 / ICS-LABA×5 / LAMA / Triple単吸入×4 / LTRA×2 / OCS / テオフィリン徐放 / Th2阻害 / SABA×2 / 生物学的製剤×5）
- **GINA 2024 Track 1（AIR/MART）優先表示**
- **5段階ステップラダー**（Step 1-5）
- **Step up 前の3確認ゲート**: 手技（Teach-back）・アドヒアランス・併存症
- **頻回増悪・OCS依存** 自動警告 → 生物学的製剤検討
- **SABA 過使用 = 喘息死リスク**: 年≥3 canister or 月≥1 警告
- **Type 2表現型ベースの生物学的製剤マッチング**: eos / FeNO / IgE → omalizumab / mepolizumab / dupilumab / tezepelumab
- **AERD（Samter triad）自動認識**: NSAID完全回避 + LTRA + dupilumab
- **ACO（喘息-COPDオーバーラップ）**: ICS必須・Triple化
- **増悪重症度ラダー**: Mild / Moderate / Severe / Life-threatening
- **デバイス/手技対応**: DPI吸気力不足→pMDI、複数→単一
- **妊娠ブデソニド優先**

### 🟫 [COPD](./j44-copd-treatment) — JRS COPD GL 2022 + GOLD 2024準拠
- **GOLD 2024 ABE分類** ベースの自動推奨
- **ICS判断ロジック**: eos≥300 / ACO → 追加、eos&lt;100 / 肺炎既往 → withdrawal
- **mMRC≥2 自動付与**: `co_pulm_rehab_candidate` で肺リハ推奨が見落とされない
- **ACO 未治療 → Triple 直接開始 rec**（ICS必須）
- **増悪 severity 別 pathway**: 軽度/中等度/重度/呼吸不全
- **LAMA 禁忌自動検出**: 狭隅角緑内障・重症BPH
- **非選択性β遮断薬警告**: 気管支攣縮リスク
- **CO2貯留型での酸素投与注意**: SpO2 88-92%目標
- **α1-AT欠損症スクリーニング**: 若年発症・家族歴
- **重症COPDスコープ外明示**: FEV1&lt;30 / 呼吸不全 / HOT適応 → 専門医管理alert
- **気管支拡張症・間質性肺疾患** はスコープ外明示
- **禁煙最優先**: バレニクリン・ニコチンパッチ・禁煙外来
- **ワクチン一式**: インフル/肺炎球菌/RSV/帯状疱疹/COVID

### 🟪 [痛風・高尿酸血症](./m10-gout-treatment) — JP GL第3版2022準拠
- **目標 SUA 層別化**: 結節 &lt;5.0 / 発作既往 &lt;6.0 / 無症候+合併症 &lt;7.0
- **急性発作中（rf_gout_attack_current）は別 pathway**: 新規尿酸降下薬厳禁、既服用継続、NSAID/コルヒチン/PSL
- **HLA-B*5801 陽性でアロプリノール禁忌**（SJS/TEN高リスク、アジア人 ~20%）
- **フェブキソスタット + 心血管高リスク**: CARES試験シグナル警告
- **コルヒチン + CYP3A4阻害薬** （マクロライド/ベラパミル/シクロスポリン）禁忌級
- **コルヒチン + CKD G4-5**: 横紋筋融解・骨髄抑制で禁忌級
- **ベンズブロマロン + 尿酸結石/肝障害**: 絶対禁忌
- **ULT開始時 flare 予防**: コルヒチン 0.5mg/日 × 3-6ヶ月
- **NSAID + CKD**: AKIリスクで PSL へ切替
- **サイアザイド由来高尿酸血症**: HT薬の見直し連携
- **5年以上無発作 + 結節なし**: 減量検討（結節既往あれば抑制）

### 🟦 [不眠症](./f510-insomnia-treatment) — 睡眠薬適正使用GL + 日本睡眠学会GL準拠
- **4分類 chip 排他選択**: 入眠困難 / 中途覚醒 / 早期覚醒（うつ鑑別要）/ 熟眠障害
- **オレキシン受容体拮抗薬を高齢者第一選択**（転倒・認知低下リスク最小）
- **ラメルテオン（メラトニン）を認知症患者に推奨**（依存ゼロ）
- **熟眠障害は二次性鑑別優先**（OSAS/PLMD/うつ/甲状腺/夜間頻尿）
- **3ヶ月以上連用で漸減計画自動アラート**
- **BZ/Z-drug 禁忌級**:
  - OSAS / 認知症 / 妊娠 / 重症肝
  - **アルコール常用** → 呼吸抑制相乗
  - **オピオイド併用** → 呼吸抑制相乗（FDAブラックボックス）
  - **CO2貯留型呼吸不全** → 呼吸抑制増悪
- **トリアゾラム（ハルシオン）高齢禁忌**（≥65歳でBeers基準）
- **ゾルピデム高齢女性 5mg 上限**（FDA勧告）
- **スボレキサント/レンボレキサント + 強CYP3A4阻害薬** 禁忌
- **ラメルテオン + フルボキサミン** 禁忌（CYP1A2阻害）
- **OSAS疑い → 睡眠検査優先**
- **うつ併存ミルタザピン**（PHQ-9閾値 note: 5-9軽度・10-14中等度・≥15重度）
- **CBT-I 併用を慢性不眠で推奨**

### 🟧 [慢性便秘症](./k590-constipation-treatment) — 日本消化管学会GL2023 + Rome IV準拠
- **Red Flag 優先フロー**: 50歳以降初発・血便・体重減少・貧血・家族歴・急激発症 → 大腸内視鏡優先
- **酸化Mg 第一選択**: 高齢者・CKDで Mg高値リスク warning
- **モビコール（PEG）を高齢者・CKDに優先**: 最安全、小児2歳〜
- **IBS-C でリナクロチド**（GC-C作動薬）
- **CIC でルビプロストン/エロビキシバット**（上皮機能変容薬）
- **OIC でナルデメジン**（PAMORA、中枢鎮痛維持）
- **オピオイド使用 + OIC 未対策 → critical alert**
- **刺激性下剤 30日連用警告**（依存・電解質異常・大腸黒皮症）
- **妊娠 + アントラキノン系禁忌**（子宮収縮誘発）
- **薬剤性便秘**（抗コリン・Ca拮抗・抗うつ・鉄剤・制酸薬）見直し提案
- **二次性便秘スクリーニング**: TSH・Ca・K・Cr

### 🟥 [頭痛](./g43-headache-treatment) — 頭痛診療GL2021 + ICHD-3準拠
- **Red Flag SNOOP 自動検出**: Systemic / Neurological / Onset / Older / Pattern change → 二次性精査優先
- **MOH 自動検出 + 離脱優先**: 急性期薬使用日数から自動
  - トリプタン/合剤 月≥10日 → cm_moh_triptan_overuse
  - 単純鎮痛薬 月≥15日 → cm_moh_analgesic_overuse
  - **5段階離脱プロトコル**: 完全中止 → 離脱期対症 → 予防薬導入 → 4週評価
- **表現型別 pathway**:
  - 片頭痛 acute: NSAID/トリプタン/ラスミジタン（CV既往対応）
  - 片頭痛 予防: プロプラノロール/ロメリジン/アミトリプチリン/バルプロ酸/**トピラマート**（β遮断不可で代替、国際GLエビデンスA）
  - 慢性片頭痛 or 難治: CGRP抗体（3ヶ月効果判定+50%減少基準）/ ボトックス
  - 群発: 酸素+スマトリプタンSC、ベラパミル予防
  - 緊張型: アミトリプチリン
- **併存症別 予防薬選択**: うつ→TCA、高血圧→β遮断、喘息/COPD→ロメリジン or トピラマート、てんかん→バルプロ酸
- **CV既往対応**: トリプタン禁忌 → ラスミジタン
- **前兆あり片頭痛 + 経口避妊薬**: 脳卒中リスク警告
- **妊娠中頭痛**: アセトアミノフェン第一、バルプロ酸/トリプタン禁忌
- **オピオイド頭痛治療目的の非推奨**（MOH/依存リスク）

## 共通の安全装置

### Red Flag / 緊急表示
すべての Booster で Red Flag（高血圧緊急症・喘息増悪Severe・痛風結節SJS疑い・MOH・FH強疑い等）は最上部の赤バナーで強制表示。**urgent な推奨は通常の優先度判定をスキップして最優先**で出ます。

### DO_NOT_RULES
各 Booster で禁忌・絶対回避薬を modifier 別に列挙。該当時はカード形式で「【禁忌】〜」と表示。

### MAINTAIN_BLOCKERS
コントロール良好でも MAINTAIN を出さない条件（副作用顕在化・Red Flag・mod未確認等）を Booster ごとに定義。

### 状態 chip の手動指定
数値が未取得・概算で進めたい時に「controlled/near_target/uncontrolled/overcontrolled」を chip で直接指定可能。手動指定時は「✓」表示で識別。

### radioGroup（排他選択）
高齢者カテゴリーや不眠症タイプなど「1つだけ選ぶべき modifier」は破線 border の radio chip として表示。同一グループ内で1つだけ有効。

## 入力のリセット

| ボタン | 用途 |
|---|---|
| **⟳ 入力クリア** | 同じ患者で入力をやり直したい時。本Boosterの薬剤・状態・修飾子をクリア |
| **👤→👤 次の患者へ** | 診療する患者が変わる時に押す。Booster 間で共有される修飾子も全消去（誤って前患者の併存疾患・妊娠が引き継がれることを防ぐ） |

:::warning 患者切替時は必ず「次の患者へ」
ブラウザ内で複数Boosterを跨いで使った修飾子（cm_dm/cm_ckd/co_pregnancy 等）は同じブラウザ内に保持されます。**患者を変える時は必ず「👤→👤 次の患者へ」を押してください**。妊娠/併存疾患情報の引き継ぎは医療事故のリスクがあります。
:::

:::note 横断機能の運用について
複数 Booster 間の修飾子共有機能は試験運用中です。動作の安定性は今後検証予定。確実に避けたい引継ぎがある場合は **ブラウザを閉じる or 「👤→👤 次の患者へ」を確実に押す** ことで完全消去できます。
:::
