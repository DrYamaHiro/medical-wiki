# 高血圧 — Treatment Booster

現在の治療と家庭血圧・修飾因子を入力すると、次の一手（**現状維持・経過観察**・増量・追加・変更・減量・紹介）を提案します。

:::info 使い方
- **Phase 1**: 現在服用中の薬剤と用量を選択（未治療の場合はスキップ可）
- **Phase 2**: 家庭血圧の平均値を入力＋該当する修飾因子（副作用・併存疾患・制約・失敗歴・Red Flag）を選択
- **Phase 3**: 適合度順に推奨が表示されます
:::

:::tip 判定の考え方（臨床上の機微）
家庭血圧は日によって±10mmHg程度の変動が生理的にあります。このツールは以下の4段階で判定します:

- **コントロール良好**（目標達成 or 目標+5以内）: 現状維持
- **目標+5〜+15（様子見ゾーン）**: 経過観察 + 生活指導強化を優先。急な薬物強化は行わない
- **コントロール不良（+15以上）**: 明確な介入推奨
- **Red Flag（緊急）**: 妊娠・重症高血圧・臓器障害等で即時対応

"ちょっと超えてる" くらいでは一旦様子を見る、という実臨床の判断を反映しています。
:::

## 📝 本ツールについて

- JSH2025準拠の治療ラダー + 臨床上の「機微」を実装
- 21薬剤（ARB/ACEi/CCB/利尿薬/β遮断薬/MRA/α遮断薬/合剤）+ 用量別選択
- 46の修飾因子（副作用・併存疾患・制約・失敗歴・Red Flag、「6ヶ月以上安定」等）
- 20の推奨修正パターン + 13の DO NOT 禁忌ルール + MAINTAIN/WATCH の動的生成
- 年齢・合併症に応じた目標設定の自動切替（75歳以上高リスク非合併は &lt;135/85）
- Red Flag（妊娠、重症高血圧、両側腎動脈狭窄等）は独立バナーで即時表示

:::warning 注意
本ツールは治療思考の補助であり、臨床判断を代替するものではありません。薬剤選択・用量・中止の最終判断は主治医が行ってください。
:::
