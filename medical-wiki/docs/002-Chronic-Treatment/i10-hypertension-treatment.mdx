# 高血圧 — Treatment Booster

現在の治療と家庭血圧・修飾因子を入力すると、次の一手（ステップアップ・変更・減量・紹介）を提案します。

:::info 使い方
- **Phase 1**: 現在服用中の薬剤を選択（未治療の場合はスキップ可）
- **Phase 2**: 家庭血圧の平均値を入力＋該当する修飾因子（副作用・併存疾患・制約・失敗歴・Red Flag）を選択
- **Phase 3**: 適合度順に推奨治療修正が表示されます
:::

## 📝 本ツールについて

- JSH2024準拠の治療ラダーを実装
- 21薬剤（ARB/ACEi/CCB/利尿薬/β遮断薬/MRA/α遮断薬/合剤）
- 45の修飾因子（副作用・併存疾患・制約・失敗歴・Red Flag）
- 20の推奨修正パターン + 13の DO NOT 禁忌ルール
- Red Flag（妊娠、重症高血圧、両側腎動脈狭窄等）は独立バナーで即時表示

:::warning 注意
本ツールは治療思考の補助であり、臨床判断を代替するものではありません。薬剤選択・用量・中止の最終判断は主治医が行ってください。
:::
