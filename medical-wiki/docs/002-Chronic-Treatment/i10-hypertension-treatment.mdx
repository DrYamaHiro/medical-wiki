# 高血圧 — Treatment Booster

現在の治療と家庭血圧・修飾因子を入力すると、次の一手（**現状維持・経過観察**・増量・追加・変更・減量・紹介）を提案します。

:::info 使い方
- **Phase 1**: 現在服用中の薬剤と用量を選択（未治療の場合はスキップ可）
- **Phase 2**: 家庭血圧の平均値を入力＋該当する修飾因子（副作用・併存疾患・制約・失敗歴・Red Flag）を選択
- **Phase 3**: 適合度順に推奨が表示されます
:::

:::tip JSH2025 の目標統一 + 臨床上の機微
**JSH2025 最大の改訂点: 全年齢で家庭血圧 &lt;125/75（診察室 &lt;130/80）に統一**（JSH2019の「75歳以上は&lt;135/85」を撤廃）。ただし75歳以上は健康・機能状態に応じた**4カテゴリー分類**で個別判断します。

### 高齢者カテゴリー（JSH2025 Table 3）
- **カテゴリー1**（ADL保持・自力通院）: 非高齢者と同様 &lt;125/75
- **カテゴリー2**（フレイル〜要介護）: 家庭 &lt;135/85
- **カテゴリー3**（基本的ADL低下、通院困難）: 家庭 &lt;145/90、**収縮期&lt;120は回避**
- **カテゴリー4**（エンド・オブ・ライフ）: 個別判断（目安 140-160）

### 4段階判定ロジック
家庭血圧は日間±10mmHg程度の変動が生理的なので:
- **コントロール良好**（目標 or +5以内）: MAINTAIN（現状維持）
- **目標+5〜+15（様子見ゾーン）**: WATCH（経過観察・生活指導強化）
- **目標+15以上**: 介入（DOSE_UP/ADD/STEP_UP）
- **過降圧**（カテゴリー3以上でSBP&lt;120）: TAPER（減量）

"ちょっと超えてる" くらいでは単回値で薬物強化せず、2週間平均で再判断する実臨床の判断を反映しています。
:::
