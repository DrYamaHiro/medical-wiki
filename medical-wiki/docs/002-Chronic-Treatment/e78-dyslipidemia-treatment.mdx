# 脂質異常症 — Treatment Booster

現在の治療・脂質値・リスク因子から、次の一手（現状維持・経過観察・開始・追加・増量・変更・減量・紹介）を提案します。

:::info 使い方
- **Phase 1**: 現在服用中の薬剤と用量を選択（未治療の場合はスキップ可）
- **Phase 2**: LDL-C（必須）＋ HDL-C・TG・non-HDL-C（任意）＋ 該当する修飾因子（副作用・併存疾患・リスク層別・失敗歴・Red Flag）を選択
- **Phase 3**: 適合度順に推奨が表示されます
:::

:::tip JAS2022 リスク層別化（自動判定）
**LDL-C目標（優先順）**:

| 状況 | 目標 |
|---|---|
| **FH + ASCVD既往** | &lt;70 mg/dL（できれば &lt;55） |
| **二次予防・超高リスク**（ASCVD + DM/FH疑い/ACS&lt;12M/非心原性脳梗塞） | &lt;70 mg/dL |
| **二次予防**（ASCVD既往） | &lt;100 mg/dL |
| **FH 一次予防** | &lt;100 mg/dL |
| **一次予防・高リスク**（DM/CKD/PAD/多発病変） | &lt;120 mg/dL |
| **一次予防・中リスク**（複数リスク因子） | &lt;140 mg/dL |
| **一次予防・低リスク** | &lt;160 mg/dL |

**4段階判定ロジック**:
- **コントロール良好**（目標 or +5 mg/dL以内）: MAINTAIN
- **目標+5〜+20**（様子見ゾーン）: WATCH（生活指導+3ヶ月後再評価）
- **目標+20以上**: STEP UP / ADD / SWITCH
- **過降下**（ハイ強度スタチン使用中でLDL&lt;40）: TAPER検討（新規DM・筋症状懸念）

**TG優先**: TG≥500は膵炎予防で最優先（フィブラート先行）。TG≥400ではLDL不正確のためnon-HDL-C代用。
:::

## 📝 本ツールについて（v0.1 JAS2022準拠）

### 実装薬剤（15剤）
- **スタチン**（6剤、強度別）:
  - Low: プラバスタチン・シンバスタチン・フルバスタチン
  - Moderate: アトルバスタチン・ピタバスタチン
  - High: ロスバスタチン
- **エゼチミブ**: ゼチーア（コレステロール吸収阻害）
- **PCSK9阻害薬**: エボロクマブ（レパーサ）・アリロクマブ（プラルエント）
- **フィブラート**: ペマフィブラート（パルモディア）・フェノフィブラート・ベザフィブラート
- **オメガ-3**: イコサペント酸エチル（エパデール）・オメガ-3脂肪酸エチル（ロトリガ）
- **胆汁酸吸着**: コレスチミド（妊娠時選択肢）

### 特徴的機能
- **リスク層別化に応じたLDL目標の動的決定**（FH/ASCVD/DM/CKD等から自動）
- **MAINTAIN/WATCH/TAPER の動的合成**（HT/DM同様）
- **過降下検出**: ハイ強度スタチン + LDL&lt;40 → TAPER
- **TG≥500の膵炎予防最優先**（LDL管理より先行）
- **SAMS 再チャレンジ戦略**: 筋症状軽度 → drug holiday → 低強度 or 週1-2回投与
- **FH 対応**: HeFH即時高強度スタチン、HoFH全例専門医紹介、カスケードスクリーニング
- **続発性原因スクリーニング**: TSH・UACR・肝機能・朝コルチゾール パネル提案
- **CYP3A4相互作用検出**: アトルバ/シンバ + 阻害薬 → 切替推奨
- **スタチン + フィブラート併用警告**: ペマ以外は横紋筋融解症リスク
- **ACS &lt;12ヶ月で高強度スタチン推奨**（LDL &lt;70）
- **妊娠/挙児希望で全スタチン・フィブラート即中止**
- **新規DM発症**: スタチンCV benefit優先で継続 + HbA1c管理

:::warning 注意
本ツールは治療思考の補助であり、臨床判断を代替するものではありません。薬剤選択・用量・中止の最終判断は主治医が行ってください。HoFH・小児FH・ロミタピド・PCSK9阻害薬導入は必ず脂質専門医と連携してください。
:::
