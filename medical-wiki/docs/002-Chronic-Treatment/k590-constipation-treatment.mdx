# 慢性便秘症 — Treatment Booster

現在の治療と Bristol Scale・排便頻度・Rome IV 症状・併存症・Red Flag から、次の一手（生活指導・薬物開始/切替・専門医紹介）を提案します。

:::info 使い方
- **Phase 1**: 現在服用中の便秘薬を選択
- **Phase 2**: Bristol Scale・排便頻度・強い息み/残便感・Red Flag（血便/体重減少/50歳以降初発）・併存症・誘因薬を入力
- **Phase 3**: 推奨表示（Red Flag 検出時は大腸内視鏡優先）
:::

:::tip 目標（Rome IV / GL2023）
- Bristol 3-5（形状正常）
- 排便頻度 ≥3回/週
- Rome IV 症状なし（強い息み・残便感・硬便・指かき出し・閉塞感）
- **Red Flag**（50歳以降初発・血便・体重減少・貧血・家族歴・急激発症）→ **薬物治療前に大腸内視鏡**
:::

## 📝 特徴的機能

- **Red Flag 優先フロー**: 50歳以降初発・血便・体重減少等で**薬物治療前に大腸内視鏡**を強制推奨
- **酸化Mg第一選択**: 安全性高いが高齢者・CKDでMg高値リスク警告
- **モビコール（PEG）を高齢者・CKDに優先**: 最安全、小児2歳〜
- **IBS-C でリナクロチド**: GC-C作動薬
- **CIC でルビプロストン/エロビキシバット**: 上皮機能変容薬
- **OIC（オピオイド誘発便秘）でナルデメジン**: PAMORA、中枢鎮痛維持
- **オピオイド使用 + OIC 未対策 → critical alert**
- **刺激性下剤 30日連用警告**: 依存・電解質異常・大腸黒皮症
- **妊娠 + アントラキノン系禁忌**: 子宮収縮誘発
- **薬剤性便秘（抗コリン・Ca拮抗・抗うつ・鉄剤・制酸薬）** → 誘因薬見直し提案
- **二次性便秘スクリーニング**: TSH・Ca・K・Cr

:::warning 注意
本ツールは治療思考の補助です。Red Flag・骨盤底機能障害疑い・治療抵抗性は必ず専門医と連携してください。
:::
