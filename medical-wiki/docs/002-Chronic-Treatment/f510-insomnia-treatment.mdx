# 不眠症 — Treatment Booster

現在の治療と ISI・睡眠パラメータ・併存症から、次の一手（睡眠衛生/CBT-I・薬物開始/切替・BZ漸減・精神科紹介）を提案します。

:::info 使い方
- **Phase 1**: 現在服用中の睡眠薬（オレキシン/メラトニン/Z-drug/BZ/抗うつ/漢方）を選択
- **Phase 2**: ISIスコア・入眠潜時・中途覚醒・総睡眠時間・日中機能障害・持続期間・併存症（うつ/OSAS疑い/認知症）を入力
- **Phase 3**: 推奨表示（3ヶ月以上連用は漸減計画アラート、OSAS疑いは睡眠検査優先）
:::

:::tip 基本方針（GINA 2024 相当 / 厚労省2014）
- **非薬物療法（CBT-I）が第一選択** — 長期予後で薬物＞CBT-I
- **オレキシン/メラトニン受容体作動薬 優先** — 依存・耐性・転倒リスク最小
- **BZ/Z-drug は短期4週まで、3ヶ月以上は漸減計画必須**
- **高齢者・認知症・OSAS では BZ/Z-drug 回避**
- **目標**: 成人 ISI &lt;8、高齢者 ISI &lt;10、日中機能良好
:::
