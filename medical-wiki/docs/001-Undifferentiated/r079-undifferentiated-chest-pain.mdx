<h3 className="soap-s">主訴・ROS</h3>

主訴: 胸痛 / 胸部不快感 / 胸が締め付けられる / 背中が痛い

**OPQRST分析**

Onset（発症様式）: 突然 / 急性（分単位）/ 徐々に（時間〜日）
Palliative/Provocative（増悪・寛解因子）: 体動 / 食事 / 深呼吸 / 安静で軽快 / 前屈で軽快 / ニトロで軽快
Quality（性状）: 締め付け / 圧迫感 / 裂けるような / 鈍痛 / 刺すような / 灼熱感
Region/Radiation（部位・放散）: 胸骨後部 / 左胸部 / 背部 / 心窩部 / 左肩 / 左腕 / 顎
Severity（強度）: NRS ＿/10
Time（持続時間）: ＿秒 / ＿分 / ＿時間, 持続性 / 間欠性

**随伴症状**

冷汗: なし / あり, 嘔気・嘔吐: なし / あり
呼吸困難: なし / あり, 失神・前失神: なし / あり
咳嗽: なし / あり, 喀血: なし / あり
動悸: なし / あり

**リスク因子**

高血圧: なし / あり, 糖尿病: なし / あり
脂質異常症: なし / あり, 喫煙: なし / あり（＿本/日×＿年）
冠動脈疾患家族歴: なし / あり
肥満: なし / あり（BMI: ＿）
DVT既往: なし / あり, 長期臥床: なし / あり
経口避妊薬: なし / あり

<h3 className="soap-o">所見・検査</h3>

バイタル: BP右: ＿/＿, BP左: ＿/＿（**左右差必須確認**）, HR: ＿, BT: ＿℃, SpO2: ＿% (Room Air), RR: ＿

**心血管系**

心音: 整 / 不整, 雑音: なし / あり（種類: ＿）
奔馬調律（S3/S4）: なし / あり
心膜摩擦音: なし / あり

**呼吸器系**

呼吸音: 清明 / 左右差あり / crackles / wheeze / 減弱・消失（部位: ＿）
気管偏位: なし / あり

**その他**

胸壁圧痛: なし / あり（部位: ＿）
頸静脈怒張: なし / あり
下腿浮腫: なし / あり, 左右差: なし / あり
皮疹（帯状疱疹）: なし / あり

<h3 className="soap-a">評価</h3>

- **Killer Chest Pain 5疾患の系統的除外:**

**1. ACS（急性冠症候群）**
- 胸骨後部の圧迫感・締め付け、左肩・左腕・顎への放散痛
- ST変化（上昇/低下）、新規の陰性T波
- リスク因子集積（高血圧・糖尿病・脂質異常・喫煙・家族歴）

**2. 大動脈解離**
- 突然発症の裂けるような激痛、背部への放散
- **血圧左右差 >20mmHg**
- 痛みが移動する（胸部→背部→腹部）

**3. 肺塞栓**
- 突然の呼吸困難 + 胸痛（胸膜痛）
- DVTリスク因子（長期臥床・手術後・経口避妊薬・悪性腫瘍）
- 頻脈 + SpO2低下

**4. 緊張性気胸**
- 呼吸音消失（患側）
- 気管偏位（健側へ）、頸静脈怒張
- 急速な呼吸循環不全

**5. 食道破裂（Boerhaave症候群）**
- 嘔吐後の激烈な胸痛
- 縦隔気腫（皮下気腫を触知）

- **非致死的鑑別:**
  - GERD / 逆流性食道炎
  - 肋間神経痛
  - 筋骨格性胸痛（胸壁圧痛再現性あり）
  - パニック障害（過換気 + 四肢しびれ + 動悸）
  - 帯状疱疹前駆期（片側性の皮膚違和感）

- **Red Flags:**
  - ⚠ 突然発症 + 裂けるような痛み + 血圧左右差 → 大動脈解離
  - ⚠ 冷汗 + 嘔気 + ST変化 → ACS
  - ⚠ 頻脈 + SpO2低下 + DVTリスク → 肺塞栓
  - ⚠ 呼吸音消失 + 気管偏位 → 緊張性気胸
  - ⚠ ショックバイタル → 即座に救急搬送

<h3 className="soap-p">方針・処方</h3>

- **緊急対応:** Killer Chest Pain疑い → 酸素投与・静脈路確保・救急搬送
  - ACS疑い: アスピリン162-325mg噛砕投与（**ただし大動脈解離疑いでは抗血小板薬禁忌**）
  - 緊張性気胸: 脱気処置（可能であれば）→ 救急搬送

#### 確定診断時の移行先

- ACS → [ACS精査](../Acute-Pain/r074-chest-pain-acs)
- 大動脈解離 → **救急搬送**（CT施設での確定診断が必須）
- 肺塞栓 → **救急搬送**（造影CT・Dダイマー検査が必要）
- 緊張性気胸 → **救急搬送**（脱気後も胸腔ドレナージが必要）
- 食道破裂 → **救急搬送**
- GERD → [GERD](../Gastroenteritis/k210-k219-gerd)
- 肋間神経痛 → [肋間神経痛](../Acute-Pain/g580-intercostal-neuralgia)
- パニック障害 → [パニック障害](../Psychiatry/f410-panic-disorder)
- HEART Score活用 → [HEART Score計算](../Calculators/cardiovascular/heart)

#### 指導・計画

- **再診:** 非緊急胸痛で帰宅の場合、＿日後に再診。
- **安全指導:** 胸痛の再発・増悪、冷汗、呼吸困難、意識朦朧が出現した場合は直ちに救急要請。
- **診断未確定時の対応:**
  - 初期評価でKiller疾患を否定的と判断 → HEART Scoreで層別化
  - HEART Score 4点以上 → 循環器専門医紹介（トロポニン・負荷心電図など精査）
  - 非心臓性と判断しても48時間以内に症状再発なら再評価必須
  - 経過観察中に新たな症状（放散痛・失神・血痰）が出現した場合は即日受診を指示

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[設備制約と判断]** トロポニン迅速検査・CT・Dダイマーがない環境である。「除外できない＝搬送」の原則を貫け。検査結果待ちで搬送が遅れることが最大のリスク。
>
> **[非典型ACS]** 女性・高齢者・糖尿病患者では胸痛がなく、嘔気・倦怠感・息切れのみのことがある。「胸が痛くない＝ACSでない」は誤り。心窩部痛として発症するACSも見逃しやすい。
>
> **[大動脈解離の罠]** 解離がACSに似たST変化を示すことがある。ここで誤ってアスピリンやヘパリンを投与すると致命的。血圧左右差の確認を怠るな。胸痛患者では必ず両上肢の血圧を測定せよ。
