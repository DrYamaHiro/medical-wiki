<h3 className="soap-s">主訴・ROS</h3>

主訴: だるい / 疲れやすい / 倦怠感 / やる気が出ない / 体がしんどい

**倦怠感の性状**

期間: 急性（<1ヶ月）/ 亜急性（1-6ヶ月）/ 慢性（>6ヶ月）
日内変動: 朝に強い / 夕方に強い / 一日中 / 変動なし
労作との関係: 労作後に増悪 / 安静時も持続 / 労作後の回復が遅い
筋力低下 vs 易疲労性: 動けない / 動けるが疲れやすい

**睡眠状況**

入眠障害: なし / あり, 中途覚醒: なし / あり
早朝覚醒: なし / あり, 日中傾眠: なし / あり
睡眠時間: ＿時間, いびき: なし / あり, 無呼吸の指摘: なし / あり

**精神・気分**

興味の低下: なし / あり, 意欲減退: なし / あり
PHQ-2: (1) 気分の落ち込み ＿/3, (2) 興味の喪失 ＿/3 → 合計 ＿/6

**全身症状**

体重変化: なし / 増加 / 減少（＿kg/＿ヶ月）
食欲: 正常 / 低下 / 亢進
発熱: なし / あり, 口渇・多飲・多尿: なし / あり
浮腫: なし / あり, 脱毛: なし / あり
便通異常: なし / 便秘 / 下痢

<h3 className="soap-o">所見・検査</h3>

バイタル: BP: ＿/＿, HR: ＿, BT: ＿℃, SpO2: ＿% (Room Air)
体重: ＿kg（前回: ＿kg, 差: ＿kg）

**頭頸部**

甲状腺触診: 正常 / 腫大 / 結節
リンパ節: 腫脹なし / あり（部位: ＿）
眼瞼結膜: 蒼白なし / あり

**胸部**

心音: 整 / 不整 / 雑音あり
呼吸音: 清明 / 異常（＿）

**腹部**

肝腫大: なし / あり, 脾腫: なし / あり

**四肢・皮膚**

浮腫: なし / あり（部位: ＿）
皮膚: 乾燥 / 色素沈着 / 蒼白 / 黄疸 / 正常

**神経学的所見**

筋力低下: なし / あり（近位筋 / 遠位筋）
握力: 右＿kg / 左＿kg
深部腱反射: 正常 / 低下 / 弛緩相の遅延（甲状腺機能低下示唆）

<h3 className="soap-a">評価</h3>

- **鑑別フレームワーク:**

**1. 器質的疾患（必ず除外）**
- 甲状腺機能低下症（寒がり、便秘、体重増加、皮膚乾燥）
- 糖尿病（口渇、多飲多尿、体重減少）
- 貧血（蒼白、動悸、息切れ）
- 慢性腎臓病（浮腫、夜間尿）
- 心不全（労作時息切れ、浮腫、起座呼吸）
- 悪性腫瘍（体重減少、リンパ節腫脹）
- 副腎不全（低血圧、低Na、色素沈着、ステロイド使用歴）
- 肝疾患（黄疸、肝腫大）

**2. 精神疾患**
- うつ病（PHQ-2≧3 → PHQ-9で詳細評価）
- 不安障害

**3. 睡眠関連**
- 睡眠時無呼吸症候群（いびき、日中傾眠、肥満）
- 不眠症

**4. 機能性**
- 慢性疲労症候群/ME（6ヶ月以上 + 労作後の極端な消耗 + 睡眠で回復しない + 認知障害 or 起立不耐）

- **Red Flags:**
  - ⚠ 進行性の体重減少 → 悪性腫瘍
  - ⚠ 筋力低下（特に近位筋）→ 多発性筋炎/皮膚筋炎 / 甲状腺疾患 / 副腎不全 / 神経筋疾患
  - ⚠ 黄疸 → 肝疾患
  - ⚠ 希死念慮 → 精神科緊急対応

<h3 className="soap-p">方針・処方</h3>

- 最低限のスクリーニング検査で主要な器質的疾患を除外する。
- PHQ-2スクリーニングを並行実施。

#### 確定診断時の移行先

- TSH高値 → [甲状腺機能低下症](../Endocrine/e039-hypothyroidism)
- TSH低値 → [バセドウ病](../Endocrine/e050-graves-disease)
- 貧血（Hb低値）→ [鉄欠乏性貧血](../Hematology/d509-iron-deficiency-anemia)
- HbA1c高値 → [2型糖尿病](../Diabetes/e119-2-type-2-diabetes-glp-1)
- BNP高値 → [慢性心不全](../Cardiovascular/i509-chronic-heart-failure)
- PHQ-9陽性 → [うつ状態](../Psychiatry/f329-depressive-state)
- ESS陽性（日中傾眠）→ [閉塞性睡眠時無呼吸](../Sleep-Apnea/g473-osas)

#### 指導・計画

- **再診:** 検査結果確認のため＿日後再診。
- **安全指導:** 強い筋力低下・歩行困難・呼吸苦・高度の浮腫が出現した場合は直ちに受診。
- **PHQ-2≧3の場合:** PHQ-9を実施し、精神科連携を検討。
- **診断未確定時の対応:**
  - 初期スクリーニング全て正常 → 生活指導（睡眠衛生、運動習慣、ストレス管理）+ 4週間後再評価
  - 4週間後も改善なし → 早朝コルチゾール追加、心エコー検討、睡眠評価（ESS/AHI）
  - 6ヶ月以上持続 + 器質的疾患除外済 → 慢性疲労症候群の診断基準を確認
  - 経過中に新たな症状（体重減少、発熱、リンパ節腫脹）出現時は早期受診を指示

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[倦怠感の鑑別]** 「だるい」は最も非特異的な主訴。最低限のスクリーニング（CBC/TSH/HbA1c/BNP/肝腎機能/フェリチン/尿検査）で主要な器質的疾患の8割は拾える。
>
> **[副腎不全]** 見逃されやすい。ステロイド長期使用歴、低Na、好酸球増多があれば早朝コルチゾールを追加。
>
> **[慢性疲労症候群]** 6ヶ月以上の疲労 + 労作後の極端な消耗 + 睡眠で回復しない + 認知障害 or 起立不耐。「異常なし = 気のせい」ではない。
