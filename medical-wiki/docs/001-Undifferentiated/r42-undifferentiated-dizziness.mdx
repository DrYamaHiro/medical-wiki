<h3 className="soap-s">主訴・ROS</h3>

主訴: めまい / ふらつき / 目が回る / 立ちくらみ / ふわふわする

**めまいの性状分類**

性状: 回転性（vertigo）/ 浮動性（dizziness）/ 前失神（presyncope）/ 平衡障害（disequilibrium）
発症様式: 突発 / 体位変換時 / 起立時 / 安静時
持続時間: 秒単位 / 分単位 / 時間単位 / 日単位
頻度: 単発 / 反復性

**随伴症状**

聴力低下: なし / あり（片側 / 両側）
耳鳴: なし / あり, 耳閉感: なし / あり
頭痛: なし / あり（部位: ＿, 性状: ＿）
複視: なし / あり, 構音障害: なし / あり
嚥下障害: なし / あり
四肢しびれ: なし / あり（部位: ＿）, 麻痺: なし / あり
嘔気・嘔吐: なし / あり

**増悪因子**

頭位変換: なし / あり, 起立: なし / あり
歩行: なし / あり, 暗所: なし / あり

**内服薬**

降圧薬: なし / あり（薬剤名: ＿）
抗てんかん薬: なし / あり, アミノグリコシド系: なし / あり
α遮断薬: なし / あり, 三環系抗うつ薬: なし / あり

<h3 className="soap-o">所見・検査</h3>

バイタル: BP臥位: ＿/＿, BP立位: ＿/＿（**起立性低血圧 = 収縮期≥20mmHg or 拡張期≥10mmHg低下**）, HR: ＿, BT: ＿℃, SpO2: ＿%

**眼振検査**

自発眼振: なし / あり（方向: ＿）
注視眼振: なし / あり（方向: ＿）
頭位眼振: なし / あり

**神経学的検査**

Dix-Hallpike test: 陰性 / 陽性（右 / 左, 眼振方向: ＿, 潜時: ＿秒）
Head Impulse Test (HIT): 陰性 / 陽性（右 / 左）
Skew deviation（交代遮蔽試験）: なし / あり
指鼻試験: 正常 / 異常（右 / 左）
踵膝試験: 正常 / 異常（右 / 左）
Romberg test: 陰性 / 陽性
歩行観察: 正常 / 偏倚あり / 失調性 / 歩行不能

**聴力スクリーニング**

指こすり法: 正常 / 低下（右 / 左）

<h3 className="soap-a">評価</h3>

- **中枢性 vs 末梢性の鑑別（HINTS exam）:**

**末梢性（良性）**

- **BPPV:** 頭位変換で誘発、上眼瞼向き＋回旋性眼振（後半規管型）、潜時あり（数秒）、1分以内に消失、Dix-Hallpike陽性
- **メニエール病:** 回転性めまい + 聴力低下 + 耳鳴（3徴）、反復性、発作は数時間持続
- **前庭神経炎:** 突発性持続性回転性めまい、HIT陽性（末梢障害を示唆）、聴力正常

**中枢性（危険）**

- **小脳梗塞 / 脳幹梗塞:**
  - HINTS中枢パターン: HIT陰性 + 方向交代性眼振 + skew deviation → **中枢性を強く疑う**
  - 小脳失調徴候（指鼻試験異常、失調性歩行）
- **脳腫瘍:** 緩徐進行性、頭痛を伴うことが多い
- **椎骨脳底動脈循環不全:** 高齢者、頸部回旋で誘発

**非前庭性**

- 起立性低血圧（臥位→立位でBP 20mmHg以上低下）
- 貧血、低血糖、不整脈
- 薬剤性（降圧薬・α遮断薬・三環系抗うつ薬・アミノグリコシド）

- **Red Flags:**
  - ⚠ 新規の激しい頭痛 → 脳血管障害
  - ⚠ 神経脱落症状（複視・構音障害・嚥下障害・麻痺）→ 脳幹病変
  - ⚠ HINTS中枢パターン → 小脳/脳幹梗塞
  - ⚠ 小脳失調徴候（指鼻試験異常・失調性歩行）→ 小脳病変
  - ⚠ 「いつものめまいと違う」+ 嘔吐持続 → 中枢性を除外せよ

<h3 className="soap-p">方針・処方</h3>

- **中枢性めまい疑い:** 即日CT/MRI施設へ紹介または救急搬送。
- **末梢性めまい:** 鑑別に応じた治療へ移行。

#### 検査・アクション

<span className="med-id">[Lab-Gen-CBC] CBC（貧血の除外）</span>
<span className="med-id">[Lab-Gen-Biochem] 生化学（血糖・電解質）</span>
<span className="med-id">[Img-CV-ECG] 12誘導心電図（不整脈の除外）</span>

#### 確定診断時の移行先

- BPPV → [BPPV](../Vertigo/h811-bppv)（Epley法実施）
- メニエール病 → [メニエール病](../Vertigo/h810-menieres-disease)
- 前庭神経炎 → [前庭神経炎](../Vertigo/h812-vestibular-neuritis)
- 起立性低血圧 → [起立性低血圧](../Cardiovascular/i951-orthostatic-hypotension-dysautonomia)
- 中枢性めまい疑い → **即日CT/MRI施設へ紹介**

#### 指導・計画

- **再診:** 症状改善しない場合＿日後再診。
- **安全指導:** 新たな神経症状（しびれ・麻痺・ろれつが回らない・物が二重に見える）が出現したら直ちに救急要請。
- **診断未確定時の対応:**
  - 初回評価で中枢性を否定的と判断 → 対症療法で経過観察
  - 1週間以上めまいが持続・悪化する場合は再評価（HINTS再検 + 画像精査紹介）
  - 反復性めまいで聴力低下を伴う場合は耳鼻科紹介（蝸電図等の精査）
  - 起立性低血圧を認めた場合は原因精査（消化管出血・副腎不全・薬剤性の除外）

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[HINTSの威力]** HINTS exam（Head Impulse / Nystagmus / Test of Skew）は急性持続性めまいにおいてMRI拡散強調画像よりも感度が高い（HINTS感度100%・特異度96%（Kattah et al. 2009, Stroke）。初回MRI-DWIは48時間以内で偽陰性あり（Saber Tehrani et al. 2014: DWI感度83%）。HINTS中枢パターン → 脳梗塞を強く疑え。
>
> **[小脳梗塞の落とし穴]** 初期にはBPPVやメニエール病に酷似し、歩行障害も軽微なことがある。「いつものめまいと違う」「嘔吐が止まらない」「まっすぐ歩けない」は即日画像精査。めまい診療で最も怖いのは「よくあるめまい」として帰宅させた小脳梗塞。
>
> **[起立性低血圧の背後]** 単純な脱水だけでなく、消化管出血（黒色便確認）、副腎不全、パーキンソン病、薬剤性（降圧薬・α遮断薬・三環系抗うつ薬）を鑑別。高齢者の「立ちくらみ」は必ず臥位・立位血圧を測定せよ。
