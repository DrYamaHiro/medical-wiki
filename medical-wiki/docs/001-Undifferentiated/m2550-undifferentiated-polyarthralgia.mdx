<h3 className="soap-s">主訴・ROS</h3>

主訴: 関節が痛い / 手がこわばる / 関節が腫れている / あちこち関節が痛い

**罹患関節**

関節数: 単関節（1） / 少数関節（2-4） / 多関節（5以上）
左右対称性: 対称性 / 非対称性
部位: 小関節（手指MP/PIP/MTP）/ 大関節（膝/肩/股/肘/足首）/ DIP

**朝のこわばり**

持続時間: ＿分（<30分 → 非炎症性 / ≥30分 → 炎症性）

**発症様式**

発症: 急性（数時間～日）/ 亜急性（週）/ 慢性（月以上）

**随伴症状**

発熱: なし / あり, 皮疹: なし / あり（＿）
口腔内潰瘍: なし / あり, 眼症状: なし / あり（充血/ドライアイ）
レイノー現象: なし / あり, 筋力低下: なし / あり
腰痛: なし / あり, 下痢: なし / あり, 尿道炎: なし / あり

**既往・家族歴**

既往: 乾癬 / 炎症性腸疾患 / 尿酸値高値 / 外傷 / なし
家族歴: RA / SLE / 乾癬 / なし

<h3 className="soap-o">所見・検査</h3>

バイタル: BP: ＿/＿, HR: ＿bpm, BT: ＿℃, SpO2: ＿% (Room Air)

**全関節の系統的診察**

視診: 腫脹 / 発赤 / 変形（＿関節）
触診: 熱感 / 圧痛 / 関節液貯留（＿関節）
握力低下: なし / あり
Squeeze test（MTP/MCP圧迫）: 陰性 / 陽性（→ 滑膜炎示唆）

**皮膚所見**

リウマトイド結節: なし / あり
蝶形紅斑: なし / あり
乾癬: なし / あり
ゴットロン丘疹: なし / あり

**口腔・眼**

口腔潰瘍: なし / あり, 口腔乾燥: なし / あり
眼充血: なし / あり, ドライアイ: なし / あり

<h3 className="soap-a">評価</h3>

- **炎症性 vs 非炎症性の鑑別が第一歩:**

**炎症性（朝のこわばり≥30分、CRP/ESR上昇、関節腫脹）:**

- RA: 対称性 + 小関節 + 朝のこわばり>60分 + 抗CCP抗体
- SLE: 若年女性 + 蝶形紅斑 + 口腔潰瘍 + 多系統障害
- PMR: 50歳以上 + 肩・腰帯の痛み + ESR著明高値 + 朝のこわばり
- RS3PE: 高齢者 + 手背・足背の圧痕性浮腫 + 急性発症
- 反応性関節炎: 先行感染（尿道炎/腸炎）+ 大関節非対称性
- 乾癬性関節炎: 乾癬 + DIP関節 + 爪変化
- ウイルス性: パルボウイルスB19 / HBV / HCV → 一過性

**非炎症性:**

- 変形性関節症: DIP / 膝 / 股、朝のこわばり<30分

**単関節急性発症 → 緊急除外:**

- 化膿性関節炎 / 痛風 / 偽痛風

- **Red Flags:**
  - ⚠ 単関節急性 + 発熱 → 化膿性関節炎（即日紹介）
  - ⚠ CK上昇 + 近位筋力低下 → 皮膚筋炎（悪性腫瘍合併）
  - ⚠ ESR>50 + 50歳以上 + 頭痛/視力障害/顎跛行 → GCA（失明リスク — ステロイド先行、生検は後追い）

<h3 className="soap-p">方針・処方</h3>

- 炎症性 vs 非炎症性の鑑別のため、CRP/ESR + 朝のこわばり持続時間を重視。
- RF陰性でも抗CCP抗体で早期RAを拾い上げる。

#### 確定診断時の移行先

- RA疑い → [関節リウマチ](../Rheumatology/m069-rheumatoid-arthritis-ra)
- SLE疑い → [SLE](../Rheumatology/m329-sle)
- PMR疑い → [リウマチ性多発筋痛症](../Rheumatology/m353-polymyalgia-rheumatica-pmr)
- 痛風 → [痛風・高尿酸血症](../Dyslipidemia/m109-e790-gout-hyperuricemia)
- 変形性膝関節症 → [変形性膝関節症](../Orthopedics/m179-knee-osteoarthritis)
- 化膿性関節炎疑い → **即日整形外科紹介（関節穿刺）**

#### 指導・計画

- **再診:** 血液検査・X線結果確認のため＿日後再診。
- **安全指導:** 「関節の急な腫れ・発赤に発熱を伴う」場合は直ちに受診。
- **診断未確定時の対応:**
  - CRP/ESR正常 + 朝のこわばり<30分 → 変形性関節症として対症療法、経過観察
  - CRP/ESR上昇 + RF/抗CCP陰性 → 血清反応陰性脊椎関節炎（乾癬/IBD関連）を検討、リウマチ科紹介
  - 多関節痛が4週間以上遷延 + 炎症マーカー上昇 → リウマチ科紹介（早期RA見逃し防止）
  - ANA陽性 + 多系統症状 → SLE精査（抗dsDNA抗体/補体追加）

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[抗CCP抗体]** RF陰性でも抗CCP抗体陽性なら早期RAの可能性が高い（特異度95-99%）。RF陰性=RA否定ではない。両方提出が原則。
>
> **[PMRの背後のGCA]** PMRの15-20%にGCA（巨細胞性動脈炎）が合併。頭痛・視力障害・顎跛行があれば即日眼科+側頭動脈生検。PMR単独でもESR>30+典型的臨床像であればプレドニゾロン15mg/日で劇的改善（通常24-72時間以内、1週間で反応なければPMR診断を再考）。
>
> **[化膿性関節炎は時間勝負]** 単関節の急性発赤・腫脹・発熱 → 可及的速やかに（当日中に）関節穿刺・培養が必要。24-48時間の遅延で関節破壊が進行する。経口抗菌薬で様子を見ている間に関節破壊が進行する。即日整形外科紹介。
