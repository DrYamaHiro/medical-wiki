<h3 className="soap-a">評価</h3>

- **鑑別フレームワーク:**

**1. 反応性（最多）**
- 上気道感染、歯科感染、皮膚感染 → 原発巣を特定

**2. 感染症**
- 伝染性単核球症（若年 + 全身リンパ節 + 咽頭炎 + 肝脾腫）
- HIV、結核性リンパ節炎、猫ひっかき病、梅毒

**3. 悪性腫瘍**
- 悪性リンパ腫（無痛性 + 弾性硬 + 進行性増大 ± B症状）— 若年者（15-35歳）の頸部/縦隔リンパ節腫脹はHodgkinリンパ腫を想起
- 転移性（硬い + 固定 + 鎖骨上窩）

**4. 自己免疫**
- SLE、サルコイドーシス
- 菊池病（若年女性 + 頸部リンパ節 + 発熱）

- **Red Flags:**
  - ⚠ 鎖骨上窩リンパ節 → 悪性腫瘍の確率が最も高い
  - ⚠ 2cm超 + 増大傾向持続 → 生検を積極的に検討
  - ⚠ 硬い + 不動 → 転移性を強く疑う
  - ⚠ B症状（発熱 / 盗汗 / 体重減少）随伴 → 悪性リンパ腫

<h3 className="soap-p">方針・処方</h3>

- リンパ節の性状・分布・随伴症状から系統的に鑑別を進める。
- 鎖骨上窩リンパ節腫脹は悪性腫瘍を第一に疑い速やかに精査紹介。

#### 確定診断時の移行先

- 伝染性単核球症 → [伝染性単核球症](../Acute-URI/b279-infectious-mononucleosis)
- 梅毒 → [梅毒](../Sexual-Infect/a510-primary-syphilis)
- SLE疑い → [SLE](../Rheumatology/m329-sle)
- 悪性リンパ腫疑い → **血液内科紹介**（生検依頼）
- 転移性リンパ節腫脹 → **原発巣検索**（CT施設紹介）

#### 指導・計画

- **再診:** 初回検査結果確認のため＿日後再診。
- **経過観察基準:** 1cm未満 + 柔らかい + 可動性良好 + 感染源明確 → 2-4週間後再評価
- **安全指導:** リンパ節が急速に増大する場合、発熱・盗汗・体重減少が出現した場合は早期受診。
- **診断未確定時の対応:**
  - 感染源明確で2-4週間以内に縮小傾向 → 経過観察継続
  - 4週間以上持続 + 感染源不明 → 生検を検討（経過観察の延長は避ける）
  - 2cm超 + 増大傾向 → 速やかに血液内科紹介

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[鎖骨上窩の法則]** 鎖骨上窩リンパ節腫脹は悪性腫瘍の確率が極めて高い（左=Virchow: 消化器癌（胃癌が典型）/ 胸腔内悪性腫瘍も、右=肺癌/縦隔腫瘍が多いが左右とも悪性の可能性高い）。発見したら速やかに精査紹介。
>
> **[4週間ルール]** 明らかな感染源なくリンパ節腫脹が4週間以上持続する場合、経過観察の延長ではなく生検を検討せよ。特に2cm超+増大傾向。
>
> **[可溶性IL-2R]** 悪性リンパ腫のスクリーニングとして有用（アグレッシブリンパ腫では感度80-90%だが、インドレントリンパ腫では50-60%と低い）。正常値でも悪性リンパ腫は否定できない。ただし自己免疫疾患や感染症でも上昇するため、あくまで補助的指標。
