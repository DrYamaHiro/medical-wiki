<h3 className="soap-a">評価</h3>

- **鑑別フレームワーク:**

**1. 悪性腫瘍（最重要除外）**
- 消化器癌（胃癌、大腸癌、膵癌）— 腹部症状、便潜血、黄疸
- 肺癌 — 喫煙歴、咳嗽、血痰
- 悪性リンパ腫 — リンパ節腫脹、B症状（発熱・盗汗・体重減少）
- 年齢・性別・リスク因子で検索戦略を決定

**2. 内分泌・代謝**
- 甲状腺機能亢進症（食欲亢進 + 体重減少、動悸、振戦）
- 糖尿病悪化（口渇、多飲多尿）
- 副腎不全（低血圧、低Na、色素沈着）

**3. 消化器**
- 吸収不良症候群（脂肪便、下痢）
- 炎症性腸疾患（血便、腹痛、下痢）
- 慢性膵炎（膵外分泌不全）— 飲酒歴、脂肪便、上腹部痛

**4. 感染症**
- 結核（咳嗽、盗汗、発熱）
- HIV

**5. 精神**
- うつ病（意欲低下、食欲低下）
- 摂食障害（若年女性）

**6. 社会的要因**
- フレイル（高齢者、ADL低下）
- 孤立・独居（買い物困難、調理困難）
- 経済的問題
- 義歯不適合

- **Red Flags:**
  - ⚠ 6ヶ月で5%以上の非意図的体重減少 → 悪性腫瘍の確率有意に上昇
  - ⚠ 便潜血陽性 → 消化管悪性腫瘍
  - ⚠ リンパ節腫脹（特に鎖骨上）→ 悪性腫瘍
  - ⚠ 黄疸 → 肝胆膵疾患
  - ⚠ LDH高値 → 悪性リンパ腫・転移性腫瘍

<h3 className="soap-p">方針・処方</h3>

- 非意図的体重減少が確認されたら系統的スクリーニングを実施。
- 6ヶ月で5%以上の減少は積極的な精査適応。

#### 確定診断時の移行先

- 便潜血陽性 → **消化器内科紹介**（下部消化管内視鏡）
- TSH低値 → [バセドウ病](../Endocrine/e050-graves-disease)
- HbA1c高値 → [2型糖尿病](../Diabetes/e119-2-type-2-diabetes-glp-1)
- LDH高値 → **血液内科紹介**（sIL-2R含む二次精査）
- PHQ-9陽性 → [うつ状態](../Psychiatry/f329-depressive-state)
- 胸部X線異常 → **CT施設紹介**
- 上部消化器症状 → **消化器内科紹介**（上部消化管内視鏡）

#### 指導・計画

- **再診:** 検査結果確認のため＿日後再診。
- **体重モニタリング:** 自宅で週1回同条件（起床時・排尿後）で体重測定し記録。
- **栄養指導:** 摂取量低下がある場合は補助栄養（経口栄養補助食品）を検討。
- **安全指導:** 黄疸・血便・強い腹痛・嚥下困難が出現した場合は直ちに受診。
- **診断未確定時の対応:**
  - 初期スクリーニング正常 → 4週間後に体重再測定 + 血液検査再検
  - 体重減少が進行 → 腹部エコー追加、消化器内科紹介（上下部内視鏡検討）
  - 50歳以上で初期検査正常でも体重減少持続 → CT施設紹介を積極的に検討
  - 社会的要因が疑われる場合 → ケースワーカー / 地域包括支援センター連携

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[6ヶ月5%ルール]** 6ヶ月で体重の5%以上の非意図的減少は、悪性腫瘍の確率が有意に上昇（Lancet 2018）。この閾値を超えたら必ず系統的な精査を開始。
>
> **[食欲保持の体重減少]** 食欲があるのに痩せる場合、甲状腺機能亢進症・糖尿病悪化・吸収不良を優先的に鑑別。食欲低下を伴う場合は悪性腫瘍・うつ病を優先。
>
> **[高齢者の落とし穴]** 高齢者では社会的要因（独居・買い物困難・義歯不適合・経済的問題）が体重減少の原因であることが少なくない。検査の前に生活状況を確認せよ。
