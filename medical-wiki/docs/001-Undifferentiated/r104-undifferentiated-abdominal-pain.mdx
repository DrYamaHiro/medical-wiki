<h3 className="soap-a">評価</h3>

- **Killer Abdominal Pain — 外科的緊急症の除外:**

**1. 腹部大動脈瘤破裂**
- 高齢者 + 突然の腹痛・腰背部痛 + ショック + 拍動性腫瘤

**2. 上腸間膜動脈（SMA）閉塞**
- 高齢者 + Af + 腹痛の割に所見が乏しい（**pain out of proportion**）
- 血管系イベントは「所見が追いつかない」のが特徴

**3. 消化管穿孔**
- 板状硬（腹壁全体の筋性防御）+ 腹部X線でfree air

**4. 異所性妊娠破裂**
- 妊娠可能年齢女性 + 腹痛 + ショック → **妊娠反応必須**

**5. 絞扼性腸閉塞**
- 嘔吐 + 腹部膨満 + 排ガス停止 + 腸蠕動音異常（初期亢進・金属音→後期消失）

- **部位別鑑別:**

| 部位 | 主な鑑別 |
|------|---------|
| 右季肋部 | 胆石/胆嚢炎、肝膿瘍 |
| 心窩部 | 胃・十二指腸潰瘍穿孔、急性膵炎、**ACS（心窩部痛として発症）** |
| 右下腹部 | 虫垂炎、卵巣茎捻転、回盲部腫瘍 |
| 左下腹部 | 憩室炎、S状結腸捻転 |
| 臍周囲 | SMA閉塞（初期）、腸炎 |
| 左季肋部 | 脾梗塞、膵尾部病変、左腎結石 |
| 下腹部 | 膀胱炎、異所性妊娠、卵巣嚢腫茎捻転 |

- **Red Flags:**
  - ⚠ ショックバイタル（頻脈&gt;100, BP&lt;90）→ 即座に救急搬送
  - ⚠ 板状硬・腹膜刺激徴候 → 外科的緊急症
  - ⚠ 拍動性腫瘤 + 腹痛 → AAA破裂
  - ⚠ 妊娠可能年齢女性の腹痛 → 妊娠反応確認必須
  - ⚠ Pain out of proportion → 腸間膜虚血

<h3 className="soap-p">方針・処方</h3>

- **外科的緊急症疑い:** 酸素投与・静脈路確保・救急搬送。
- **系統的検査で鑑別を絞り込む。**

#### 確定診断時の移行先

- 急性腹症 → [急性腹症](../Acute-Pain/r100-acute-abdomen)

- 急性膵炎 → **CT施設紹介**（重症度判定にCTが必須）
- 尿管結石 → [尿管結石](../Urinary-Tract/n201-ureterolithiasis)

- 外科的緊急症 → **救急搬送**

#### 指導・計画

- **再診:** 軽症腹痛で帰宅の場合、＿日後に再診。
- **安全指導:** 腹痛の増悪、嘔吐が止まらない、血便・黒色便、発熱38.5℃以上、意識朦朧が出現した場合は直ちに受診。
- **診断未確定時の対応:**
  - 初期検査で緊急性を否定 → 対症療法（鎮痙薬・制酸薬等）で経過観察
  - 48時間以内に症状改善なし or 増悪 → CT施設への紹介を検討
  - 反復性腹痛で器質的疾患が除外できない場合 → 上部/下部消化管内視鏡を検討
  - 女性の反復性下腹部痛 → 婦人科精査（経腟エコー）への紹介

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[妊娠反応は必須]** 妊娠可能年齢の女性の腹痛では、問診で「妊娠の可能性なし」と言われても妊娠反応を確認せよ。異所性妊娠の見逃しは致命的。これはルーティンとして組み込め。
>
> **[Pain out of proportion]** 腹痛の訴えの割に腹部所見が乏しい（触っても柔らかい）場合、腸間膜虚血を疑え。特にAf患者、動脈硬化リスクの高い高齢者。血管系イベントは「所見が追いつかない」のが特徴。乳酸値が測定できれば有用だが、臨床的疑いだけで紹介の閾値を下げよ。
>
> **[高齢者の腹痛]** 高齢者は腹膜刺激徴候が出にくい（腹壁筋萎縮のため）。痛みの訴えが軽くても、頻脈・CRP上昇があれば外科的疾患を強く疑え。CTなしでの判断は限界があり、閾値を低くして紹介/搬送。
