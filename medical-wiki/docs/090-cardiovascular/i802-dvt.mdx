## 📖 詳細解説

### 病態生理

- **定義**: 下肢深部静脈（大腿静脈、膝窩静脈、腸骨静脈等）に血栓が形成される疾患
- **Virchowの三徴**: 血流うっ滞（長期臥床、長時間座位）、血管内皮傷害（手術、外傷）、凝固能亢進（悪性腫瘍、経口避妊薬、妊娠）
- **肺塞栓症（PE）**: DVTの最も重篤な合併症。致死的となりうる
- **近位 vs 遠位**: 膝窩静脈より中枢側を近位DVT、下腿静脈のみを遠位（末梢）DVTと分類

### [Wellsスコア](../Calculators/wells-dvt)全項目テーブル

| 臨床的特徴 | 点数 |
|---|---|
| 活動性の癌（治療中、6ヶ月以内の治療歴、または緩和ケア中） | +1 |
| 麻痺・不全麻痺、または下肢の最近のギプス固定 | +1 |
| 最近の臥床3日以上、または12週以内の全身/局所麻酔手術 | +1 |
| 深部静脈走行に沿った限局性圧痛 | +1 |
| 下肢全体の腫脹 | +1 |
| 症状のある側の下腿腫脹（健側比 3cm以上の左右差: 脛骨粗面下10cmで計測） | +1 |
| 症状のある側の圧痕性浮腫（pitting edema） | +1 |
| 表在静脈の側副血行路の発達（静脈瘤ではない） | +1 |
| DVTの既往 | +1 |
| DVT以外の診断が同程度以上に考えられる | **-2** |

**スコア判定**:

| スコア | リスク | DVTの確率 | 推奨される対応 |
|---|---|---|---|
| **0点以下** | 低リスク | 約5% | D-dimer測定。陰性ならDVT除外 |
| **1-2点** | 中等度リスク | 約17% | D-dimer測定。陽性なら下肢静脈超音波 |
| **3点以上** | 高リスク | 約53% | D-dimer省略可。直接下肢静脈超音波 |

### 年齢調整D-dimer

- **従来のカットオフ**: D-dimer 0.5 mcg/mL（500 ng/mL）未満で陰性
- **問題点**: 50歳以上ではD-dimerが加齢とともに上昇し、偽陽性率が増加（特異度が低下）
- **年齢調整カットオフ**: **50歳以上の患者では、カットオフ値 = 年齢 x 10 ng/mL**
  - 60歳 → 600 ng/mL未満で陰性
  - 70歳 → 700 ng/mL未満で陰性
  - 80歳 → 800 ng/mL未満で陰性
- **ADJUST-PE試験**: 年齢調整D-dimerにより、追加画像検査の回避率が30%増加し、偽陰性率の増加はなし（安全性が確認された）
- **適用**: Wells低〜中リスクの患者に適用。高リスク（Wells 3点以上）では画像検査を優先

### 近位DVT vs 遠位DVTの治療差

| | **近位DVT** | **遠位（末梢）DVT** |
|---|---|---|
| **定義** | 膝窩静脈以上（大腿静脈、腸骨静脈等） | 下腿の深部静脈（前/後脛骨静脈、腓骨静脈、ヒラメ筋静脈等） |
| **PE リスク** | **高い**（近位DVTの約50%にPEが合併） | **低い**（PE合併率は数%） |
| **治療** | **全例で抗凝固療法**（DOAC 3ヶ月以上） | 症状が軽度で誘因がある場合は**経過観察（2週間後に超音波再検）**も選択肢 |
| **抗凝固の適応（遠位）** | -- | 症状が強い、血栓が大きい（5cm以上）、D-dimer高値、リスク因子が持続する場合は抗凝固 |
| **治療期間** | 誘因あり: 3ヶ月、誘因なし: 6ヶ月〜無期限 | 誘因あり: 6週-3ヶ月、誘因なし: 3ヶ月 |

### 診断基準・鑑別疾患

- **下肢静脈超音波**: 圧迫法で血栓を確認（確定診断）。感度95%以上（近位DVT）、遠位DVTでは感度がやや低い
- **鑑別**: 蜂窩織炎、Baker嚢胞破裂、筋肉内血腫、リンパ浮腫、表在性血栓性静脈炎

### エビデンス・ガイドライン推奨

- **抗凝固療法**: DOAC（エドキサバン60mg/日、アピキサバン10mg 1日2回x7日→5mg 1日2回、リバーロキサバン15mg 1日2回x3週→15mg 1日1回）が第一選択
- **治療期間**: 誘因あり（手術後、長期臥床等）3ヶ月。誘因なし/再発6ヶ月以上〜無期限。癌関連VTEはDOAC（エドキサバン）or LMWH
- **弾性ストッキング**: 血栓後症候群の予防（ただしSOX試験で予防効果が否定的）。症状緩和には有用
- **IVCフィルター**: 抗凝固禁忌の場合にのみ。回収可能型が推奨
- **PE疑いの場合**: 造影CT（CTPA）で確認。大量PEはショック → 血栓溶解療法またはカテーテル治療
- **予防**: 術後の早期離床、弾性ストッキング、間欠的空気圧迫法、低用量ヘパリン
- **癌スクリーニング**: 誘因のないDVTの約10%に悪性腫瘍が潜在。年齢相応のがん検診を推奨
