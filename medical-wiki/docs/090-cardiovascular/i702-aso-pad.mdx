## 📖 詳細解説

### 病態生理

- **定義**: 下肢動脈の動脈硬化性狭窄・閉塞による慢性虚血
- **動脈硬化の全身疾患**: PAD患者の約50%に冠動脈疾患、約30%に脳血管疾患を合併。PAD患者の5年死亡率は15-30%

### ABI（足関節上腕血圧比）の解釈

| ABI値 | 解釈 | 対応 |
|---|---|---|
| 1.00-1.40 | **正常** | 症状があれば運動負荷ABI |
| **0.91-0.99** | **境界域** | リスク因子がある場合は経過観察 |
| **0.90以下** | **PAD（異常）** | 血管外科紹介、リスク因子管理開始 |
| 0.41-0.90 | 軽度〜中等度虚血 | 間欠性跛行の管理 |
| **0.40以下** | **重症虚血（CLI疑い）** | **緊急血管外科紹介** |
| 1.40超 | **石灰化動脈（偽高値）** | 糖尿病・透析患者に多い。TBI（足趾血圧比）で評価 |

- **ABI測定法**: 仰臥位で両上肢と両下肢（足背動脈 or 後脛骨動脈）の収縮期血圧を測定。ABI = 下肢血圧 / 上肢血圧（高い方）
- **運動負荷ABI**: 安静時ABI正常だが症状がある場合、トレッドミル歩行後にABIを測定。運動後ABI 20%以上低下でPADと診断

### Fontaine分類 / Rutherford分類テーブル

| Fontaine | Rutherford | 臨床像 | 管理方針 |
|---|---|---|---|
| **I度** | Category 0 | **無症状** | リスク因子管理、ABI定期測定 |
| **IIa度** | Category 1-2 | **軽度間欠性跛行**（200m以上歩行可能） | 運動療法 + 薬物療法（シロスタゾール） |
| **IIb度** | Category 3 | **中等度〜重度間欠性跛行**（200m未満で出現） | 運動療法 + 薬物療法。改善なければ血行再建検討 |
| **III度** | Category 4 | **安静時疼痛** | **CLI（重症虚血肢）** → 血行再建が必要 |
| **IV度** | Category 5-6 | **潰瘍・壊疽**（Category 5: 小さな組織欠損、Category 6: 広範な組織欠損） | **CLI** → 緊急血行再建 + 創傷管理。大切断の回避が目標 |

### CLI（重症虚血肢）の定義

- **定義**: 以下のいずれかを2週間以上満たす慢性虚血:
  - 安静時疼痛（夜間に増悪、下垂で軽減）
  - 虚血性潰瘍・壊疽
- **血行動態的基準**: ABI 0.40未満、足関節血圧 50mmHg未満、足趾血圧 30mmHg未満
- **予後**: 血行再建なしでは1年以内の大切断率25%、死亡率25%
- **CLTI（Chronic Limb-Threatening Ischemia）**: 近年はCLIに代わりCLTIの用語が使用される。WIfI分類（Wound, Ischemia, Foot Infection）で重症度を評価

### 血行再建術の適応

- **間欠性跛行**: 運動療法 + 薬物療法で3ヶ月以上改善なく、生活の質が著しく低下している場合
- **CLI/CLTI**: 原則として全例で血行再建を検討
- **EVT（血管内治療: バルーン拡張・ステント）**: 腸骨動脈領域（TASC A-C）、大腿膝窩動脈の短い病変に適応
- **バイパス手術**: 長い閉塞性病変、EVT不成功例、膝下3分枝病変。自家静脈グラフトが開存率で優位
- **BASIL試験**: CLI患者でバイパス vs EVTを比較。2年以降はバイパス群で生存率が良好。ただし最近の薬剤塗布デバイスでEVTの成績が向上

### 診断基準・鑑別疾患

- **間欠性跛行**: 歩行で下肢の痛み → 休息で軽快。神経性跛行（脊柱管狭窄症: 前屈で軽快、自転車は可能）との鑑別が重要
- **検査**: 下肢動脈超音波、CTA/MRA

### エビデンス・ガイドライン推奨

- **リスク因子管理**: 禁煙（最重要。喫煙継続は大切断リスクを数倍に上昇）、LDL 70mg/dL未満、HbA1c 7%未満、降圧（目標130/80未満）
- **抗血小板薬**: クロピドグレル75mg/日（CAPRIE試験でアスピリンよりPADでやや有効）or アスピリン100mg/日
- **COMPASS試験**: リバーロキサバン2.5mg 1日2回 + アスピリン100mgの併用がアスピリン単独より主要心血管イベント + 下肢イベントを減少（ただし出血リスク上昇）
- **間欠性跛行**: 運動療法（監視下歩行訓練: 週3回、30-45分。エビデンスA）、シロスタゾール100mg 1日2回（歩行距離を50-100%延長。心不全には禁忌）
- **CLI（重症虚血肢）**: 血行再建術（バイパス or EVT）が必要。フットケア・潰瘍管理。多職種チーム（血管外科、形成外科、皮膚科、リハビリ）での管理
