<h3 className="soap-a">評価</h3>

- **診断根拠:** ワーファリン内服中の抗凝固管理。目標PT-INR: NVAF 70歳未満2.0-3.0/70歳以上1.6-2.6。VTE 1.5-2.5(肺血栓塞栓症/DVTガイドライン2017年改訂版)。機械弁: 大動脈弁位(二葉弁) 2.0-3.0、僧帽弁位 2.5-3.5。
- **重症度:** TTR（Time in Therapeutic Range）65%以上が良好なコントロールの指標。
- **鑑別:** 機械弁置換後、抗リン脂質抗体症候群等のDOAC非適応例であることを確認。

<h3 className="soap-p">方針・処方</h3>

- PT-INRに基づきワーファリン用量を微調整（0.5mg単位）。
- VitK含有食品（納豆・クロレラ・青汁）の摂取制限を指導。
- **相互作用チェック:** 抗菌薬（特にST合剤、フラジール）、NSAIDs、抗真菌薬、アミオダロン、フィブラート系、SSRI、セントジョーンズワート、リファンピシン、フェニトイン、カルバマゼピン。
- TTR 65%以上を目標に管理。達成困難な場合はDOAC切替を再検討。

## 📖 詳細解説

### 病態生理

- **ワーファリン（ワルファリン）の薬理:**
  - ビタミンK依存性凝固因子（II、VII、IX、X）およびプロテインC/Sの肝合成を阻害
  - ビタミンKエポキシド還元酵素（VKORC1）を阻害 → ビタミンKのリサイクルを遮断
  - 効果発現まで3-5日（既存の凝固因子が消費されるまで）。第VII因子の半減期が最短（6時間）のためPTが最初に延長
- **心房細動における血栓形成:**
  - 心房収縮の欠如 → 左心耳での血液うっ滞 → 血栓形成
  - Virchowの三徴: 血流停滞、内皮障害、凝固能亢進
  - 左心耳血栓が遊離 → 脳塞栓（心原性脳塞栓症）。AF関連脳梗塞は重症化しやすい

### 診断基準・鑑別疾患

**PT-INR目標値（日本のガイドライン）**

| 適応 | 目標PT-INR |
|------|-----------|
| NVAF 70歳未満 | 2.0-3.0 |
| NVAF 70歳以上 | 1.6-2.6 |
| 機械弁（大動脈弁位・二葉弁） | 2.0-3.0 |
| 機械弁（僧帽弁位） | 2.5-3.5 |
| VTE（肺塞栓/DVT） | 1.5-2.5（JCS 2017） |
| 抗リン脂質抗体症候群 | 2.0-3.0 |

- **TTR（Time in Therapeutic Range）:** 目標INR域内の時間割合。65%以上が良好な管理の指標。TTR 65%未満が持続する場合はDOACへの切替を検討（DOAC適応例のみ）

**ワーファリンが必須の病態（DOAC非適応）**
- 機械弁置換後（RE-ALIGN試験でダビガトランの有害性が証明）
- 抗リン脂質抗体症候群（TRAPS試験でリバーロキサバンの劣性が証明）
- 重度腎機能障害（CrCl 15mL/min未満）
- 僧帽弁狭窄症（中等症以上）

**食事・薬物相互作用**

**ビタミンK含有食品（摂取制限）:**
- **禁止:** 納豆（納豆菌が腸内でVitKを産生し続けるため少量でも禁忌）、クロレラ、青汁
- **大量摂取を避ける:** ブロッコリー、ほうれん草、小松菜、春菊、モロヘイヤ等の緑黄色野菜（通常量の摂取は問題ないが、大量・偏食を避ける）
- **サプリメント:** VitK含有サプリ、セントジョーンズワート（CYP誘導でワーファリン効果減弱）

**INR増強（出血リスク上昇）する薬物:**
- 抗菌薬: ST合剤（最も危険）、メトロニダゾール、フルコナゾール、マクロライド系
- NSAIDs（COX阻害+消化管出血リスク加算）
- アミオダロン（CYP2C9阻害、数週間持続）
- SSRI/SNRI（血小板機能抑制）
- フィブラート系（アルブミン結合部位からの遊離）

**INR減弱する薬物:**
- リファンピシン（CYP誘導、最も強力）
- フェニトイン、カルバマゼピン
- セントジョーンズワート

### エビデンス・ガイドライン推奨

**INR高値時の対応（日本循環器学会GL準拠）**

| INR | 出血 | 対応 |
|-----|------|------|
| 3.0-4.0 | なし | 減量または1回休薬、1週間以内に再検 |
| 4.0-9.0 | なし | 休薬 + VitK 1-2.5mg経口を考慮 |
| 9.0超 | なし | VitK 2.5-5mg経口、翌日再検、必要に応じ追加 |
| 任意 | 重大出血 | VitK 5-10mg緩徐静注 + 4F-PCC（乾燥人血液凝固因子複合体）優先またはFFP → 救急搬送 |

**周術期管理**
- **ワーファリン休薬:** 術前3-5日前に中止。術前日にPT-INR 1.5以下を確認
- **ヘパリンブリッジ:** 高リスク例（機械弁、6ヶ月以内のVTE、CHADS2 5-6点）で検討。ただしBRIDGE試験（2015）で待機手術では非ブリッジ群が出血減少・塞栓差なしと示されており、適応は厳選する
- **術後再開:** 十分な止血確認後、通常術後1-2日で再開（術前用量で）
- **抜歯:** 低リスク手技ではINR安定例（3.0以下）は休薬不要（ワーファリン継続下で抜歯のエビデンスあり）

**CHA2DS2-VAScスコアと抗凝固適応**
- 0点（男性）/1点（女性）: 抗凝固療法なし
- 1点（男性）/2点（女性）: 抗凝固療法を考慮
- 2点以上（男性）/3点以上（女性）: 抗凝固療法を推奨
- 日本ではCHADS2スコア1点以上で推奨（JCS 2020 AF GL）
