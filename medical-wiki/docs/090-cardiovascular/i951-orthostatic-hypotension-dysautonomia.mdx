<h3 className="soap-s">主訴・ROS</h3>

主訴: 労作時息切れ / 動悸 / 胸痛 / 浮腫 / 下肢痛

**心臓症状**

動悸: 脈が飛ぶ / 突然始まる / 常に速い / ドンとする
胸痛: 圧迫感 / 絞扼感 / 鋭痛 / 放散痛:肩・顎
呼吸困難: 労作時 / 安静時 / 夜間発作性 / 起坐呼吸

**末梢血管・下肢**

間欠性跛行: なし / あり: ＿mで出現
下肢症状: 冷感 / 色調変化 / 血管怒張 / 左右差あり
浮腫: なし / 下肢 / 顔面 / 片側 / 両側 / 急激

**リスク・背景**

既往歴: 心筋梗塞 / 弁膜症 / 高血圧 / 糖尿病 / 喫煙
内服薬: 抗凝固薬 / 抗血小板薬 / 利尿薬

<h3 className="soap-o">所見・検査</h3>

バイタル: BP ＿/＿ (左右差: 有 / 無), HR ＿ (整/不整), SpO2 ＿%

**胸部**

頸静脈怒張: 有 / 無
心音: 整 / 不整 / 雑音: 収縮期・拡張期 / III音・IV音
呼吸音: 清明 / 湿性ラ音 / 喘鳴

**末梢・下肢**

下肢浮腫: なし / Pitting / Non-pitting
動脈拍動(足背・後脛骨): 良好 / 減弱 / 消失
Homan's徴候: 陰性 / 陽性、皮膚: 色素沈着 / 潰瘍 / 静脈瘤

**検査**

心電図: 正常洞調律 / ST変化 / 異常Q波 / 不整脈 / LVH
胸部X線: CTR ＿%, 肺鬱血 / 胸水 / 異常なし
採血(外注): BNP, Dダイマー, 电解質, 腎機能

<h3 className="soap-a">評価</h3>

- 起立3分以内に収縮期血圧20mmHg以上または拡張期10mmHg以上の低下。
- Schellong test（簡易起立試験）で診断。Head-up tilt testは精密検査。
- 二次性の除外:
- 薬剤性（降圧薬、α遮断薬、三環系抗うつ薬、抗パーキンソン病薬）
- 糖尿病性自律神経障害
- パーキンソン病 / MSA / DLB
- 副腎不全、脱水、甲状腺機能異常
- **不定愁訴が主訴の場合:** めまい、倦怠感、立ちくらみ、動悸、失神。

<h3 className="soap-p">方針・処方</h3>

- 被疑薬の減量・中止が最優先。
- **非薬物療法:** 起立時のゆっくり動作、弾性ストッキング、塩分・水分摂取増加（心不全なければ）、ヘッドアップチルト睡眠。
- **薬物療法:** 非薬物療法で改善不十分な場合に追加。

#### 処方・アクション

**起立性低血圧治療セット**

- <span className="med-id">[Rx-CV-OH-Mid]</span> ミドドリン（メトリジン）
- メトリジン錠2mg 1回1錠 1日2回 朝昼食後 28日分 *— α1刺激薬・末梢血管収縮*
- <span className="med-id">[Rx-CV-OH-Dro]</span> ドロキシドパ（ドプス）
- ドプスカプセル200mg 1回1カプセル 1日3回 毎食後 28日分 *— ノルアドレナリン前駆体（100mgから開始も可）*

#### 指導・計画

- **生活指導:** 急な起立を避ける。起床時はベッド上で足踏みしてから立つ。
- **弾性ストッキング:** 下肢の静脈還流を促進。日中の着用を推奨。
- **塩分摂取:** 心不全・腎不全がなければ食塩10g/日程度まで許容。水分1.5-2L/日。
- **転倒予防:** 手すり設置、夜間照明、段差解消。
- **再診目安:** 2-4週間後。起立試験の再検と症状評価。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[薬剤性]** 降圧薬・α遮断薬（ハルナール等）が原因であることが非常に多い。処方歴を必ず確認し、被疑薬の減量・変更を最初に検討せよ。
>
> **[夜間高血圧]** 起立性低血圧の患者はしばしば臥位高血圧を合併する。就寝前のミドドリンは避け、夜間の血圧上昇に注意せよ。
>
> **[転倒リスク]** 高齢者では転倒→骨折→寝たきりの原因となる。環境整備（手すり、夜間照明）と家族指導を徹底せよ。
