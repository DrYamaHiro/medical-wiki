<h3 className="soap-a">評価</h3>

- 起立3分以内に収縮期血圧20mmHg以上または拡張期10mmHg以上の低下。
- Schellong test（簡易起立試験）で診断。Head-up tilt testは精密検査。
- 二次性の除外:
- 薬剤性（降圧薬、α遮断薬、三環系抗うつ薬、抗パーキンソン病薬）
- 糖尿病性自律神経障害
- パーキンソン病 / MSA / DLB
- 副腎不全、脱水、甲状腺機能異常
- **不定愁訴が主訴の場合:** めまい、倦怠感、立ちくらみ、動悸、失神。

<h3 className="soap-p">方針・処方</h3>

- 被疑薬の減量・中止が最優先。
- **非薬物療法:** 起立時のゆっくり動作、弾性ストッキング、塩分・水分摂取増加（心不全なければ）、ヘッドアップチルト睡眠。
- **薬物療法:** 非薬物療法で改善不十分な場合に追加。

#### 処方・アクション

**起立性低血圧治療セット**

<span className="med-id">[Rx-CV-OH-Mid] ミドドリン（メトリジン）</span>
- メトリジン錠2mg 1回1錠 1日2回 朝昼食後 28日分 *— α1刺激薬・末梢血管収縮*
<span className="med-id">[Rx-CV-OH-Dro] ドロキシドパ（ドプス）</span>
- ドプスカプセル200mg 1回1カプセル 1日3回 毎食後 28日分 *— ノルアドレナリン前駆体（100mgから開始も可）*

#### 指導・計画

- **生活指導:** 急な起立を避ける。起床時はベッド上で足踏みしてから立つ。
- **弾性ストッキング:** 下肢の静脈還流を促進。日中の着用を推奨。
- **塩分摂取:** 心不全・腎不全がなければ食塩10g/日程度まで許容。水分1.5-2L/日。
- **転倒予防:** 手すり設置、夜間照明、段差解消。
- **再診目安:** 2-4週間後。起立試験の再検と症状評価。

> 💡 **Dr.Advice**
>
> **[薬剤性]** 降圧薬・α遮断薬（ハルナール等）が原因であることが非常に多い。処方歴を必ず確認し、被疑薬の減量・変更を最初に検討せよ。

>
> **[転倒リスク]** 高齢者では転倒→骨折→寝たきりの原因となる。環境整備（手すり、夜間照明）と家族指導を徹底せよ。

## 📖 詳細解説

### 病態生理

- **正常の起立反応:** 起立時に約500-1000mLの血液が下肢・腹腔に移動 → 静脈還流減少 → 心拍出量低下 → 頸動脈洞・大動脈弓の圧受容器が感知 → 交感神経活性化・副交感神経抑制 → 末梢血管収縮+心拍数増加で血圧維持
- **起立性低血圧の病態:** 上記の代償機序のいずれかが破綻 → 起立時の血圧低下が持続
  - 求心路障害: 圧受容器の感受性低下（加齢、糖尿病性自律神経障害）
  - 中枢処理障害: 延髄の血管運動中枢の変性（MSA、パーキンソン病、DLB）
  - 遠心路障害: 交感神経節後線維の変性（純粋自律神経不全症/PAF）
  - 効果器障害: 血管平滑筋の反応性低下
  - 循環血液量減少: 脱水、副腎不全、出血

- **夜間臥位高血圧（supine hypertension）との共存:**
  - 起立性低血圧患者の約50%に合併
  - 臥位で末梢から心臓への血液還流が増加 + 圧受容器反射の障害により血圧を下げられない
  - 夜間高血圧は臓器障害（左室肥大、腎障害）のリスクとなる
  - 治療のジレンマ: 降圧薬で夜間血圧を下げると起立性低血圧が悪化

### 診断基準・鑑別疾患

**定義（2011年 AAS/AAN/AHA コンセンサスステートメント）**
- **起立性低血圧:** 起立後3分以内に以下のいずれかを満たす
  - 収縮期血圧 20mmHg以上の低下
  - 拡張期血圧 10mmHg以上の低下
  - （高血圧患者では収縮期30mmHg以上の低下を基準とする意見もある）

**Schellong test（簡易起立試験、外来で実施可能）**
- 10分間仰臥位安静後の血圧・脈拍を測定
- 起立後1分、3分、5分、（10分）に血圧・脈拍を測定
- 判定: 上記基準を満たせば陽性
- 脈拍変化も重要: 起立後の心拍増加が15bpm未満 → 神経原性を示唆（交感神経障害）

**Head-up tilt test（HUTT）**
- 60-70度で20-45分間傾斜。より感度が高い
- 神経調節性失神（VVS）との鑑別に有用

**二次性の原因（薬剤性が最多 -- 全体の約30-40%）**

| カテゴリ | 代表的原因 |
|----------|-----------|
| 薬剤性 | 降圧薬（Ca拮抗薬、ACE-I/ARB）、α遮断薬（タムスロシン）、三環系抗うつ薬、フェノチアジン系抗精神病薬、L-dopa、利尿薬、硝酸薬 |
| 神経変性 | パーキンソン病、MSA（Shy-Drager症候群）、DLB、PAF |
| 代謝性 | 糖尿病性自律神経障害（長期罹患のDM）、アミロイドーシス、ビタミンB12欠乏 |
| 内分泌 | 副腎不全、甲状腺機能低下症、褐色細胞腫（術後低血圧） |
| 循環血液量低下 | 脱水、出血、過度の利尿 |
| その他 | 長期臥床（デコンディショニング）、加齢 |

### エビデンス・ガイドライン推奨

**非薬物療法（まず実施）**
- **被疑薬の減量・中止:** 最優先。降圧薬・α遮断薬が原因であることが非常に多い
- **身体的対策:**
  - 弾性ストッキング（腰まで）: 下肢の静脈プーリングを20-25mmHg程度で圧迫。腹部バインダーとの併用が効果的
  - 急な起立を避ける。起床時はベッド端に1-2分座ってから立つ
  - 起立直後のcountermaneuver: 下肢の交差、つま先立ち、しゃがみ込み
- **塩分・水分摂取:** 心不全・腎不全がなければ食塩10g/日程度、水分1.5-2L/日
- **ヘッドアップチルト睡眠:** ベッドの頭側を10-15cm挙上。夜間のRAA系活性化を促し循環血液量を維持
- **食後低血圧:** 食後1-2時間の安静、少量頻回食、食前のカフェイン摂取（150-250mg）

**薬物療法**
- **ミドドリン（メトリジン）:** 選択的α1アゴニスト。2-10mg/日 分2-3（朝昼）。就寝前の投与は避ける（臥位高血圧悪化）。日本での第一選択
- **ドロキシドパ（ドプス）:** ノルアドレナリン前駆体。200-600mg/日 分3。パーキンソン病・MSAに伴う起立性低血圧に特に有効。日本で開発された薬剤
- **フルドロコルチゾン:** 鉱質コルチコイド。0.1-0.3mg/日。Na貯留による循環血液量増加。低K血症と臥位高血圧に注意。日本では保険適応外（適応外使用）
- **ピリドスチグミン:** コリンエステラーゼ阻害薬。60mg 分3。交感神経節を介した血管収縮促進。臥位高血圧を悪化させにくい利点がある

**夜間臥位高血圧への対応**
- 就寝前のミドドリン・ドロキシドパ投与を避ける（最終投与は夕方まで）
- ヘッドアップチルト睡眠
- 必要に応じて就寝前の短時間作用型降圧薬（ロサルタン50mg、ニトログリセリンパッチ等）を少量使用
