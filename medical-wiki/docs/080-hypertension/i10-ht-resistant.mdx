<h3 className="soap-a">評価</h3>

- **定義:** 利尿薬を含む3剤以上を使用しても目標血圧未達。
- 阻害要因チェック:
1. 塩分摂取: 過剰 / 適正
2. 服薬状況: 飲み忘れあり / 良好
3. 薬剤性: NSAIDs / 甘草 / ステロイド
4. 二次性/合併症: SAS / 原発性アルドステロン症 / 腎血管性

<h3 className="soap-p">方針・処方</h3>

- 阻害要因（特に減塩不足とNSAIDs）の除去。
- **Step 3:** サイアザイド系利尿薬の追加（必須）。
- **Step 4:** MRA（ミネラルコルチコイド受容体拮抗薬）の追加。
- 二次性高血圧スクリーニング（ARR測定等）。

## 📖 詳細解説

### 病態生理

- **定義**: 利尿薬を含む3剤以上の降圧薬を適切な用量で使用しても、140/90mmHg以上が持続する高血圧
- **有病率**: 治療中の高血圧患者の10-15%
- **真の難治性の原因**: 食塩過剰摂取、肥満、過度の飲酒、二次性高血圧の見逃し、薬剤性（NSAIDs、エリスロポエチン、ステロイド）
- **病態**: 多くの症例でアルドステロン過剰（原発性アルドステロン症の潜在例を含む）や体液貯留が関与

### 偽性治療抵抗性高血圧の除外

真の治療抵抗性高血圧の診断前に、以下を系統的に除外する:

| 除外項目 | 確認方法 | 頻度 |
|---|---|---|
| **アドヒアランス不良** | 処方日数と受診間隔の照合、残薬チェック、血中薬物濃度測定（研究的） | **最多（約50%）** |
| **白衣高血圧** | 家庭血圧測定（135/85未満なら白衣効果）、ABPM | 20-30% |
| **不適切な血圧測定** | カフサイズ（上腕周囲に応じた選択）、測定手技の確認 | 見落とされやすい |
| **食塩過剰摂取** | 随時尿Na/Cr比（推定塩分摂取量）、24時間尿中Na排泄量 | 非常に多い |
| **薬剤性高血圧** | NSAIDs、甘草含有漢方薬、経口避妊薬、ステロイド、エリスロポエチン、免疫抑制薬 | 見落とされやすい |
| **過度の飲酒** | AUDIT-Cスコア、飲酒歴の詳細聴取 | |

### 診断基準・鑑別疾患

- **確認事項**: 服薬アドヒアランス（処方日数の確認、残薬チェック）、減塩の遵守度（随時尿Na/Cr比）、家庭血圧と診察室血圧の乖離
- **二次性高血圧の精査**: 原発性アルドステロン症（ARR: PAC/PRA 200以上）、腎動脈狭窄（腹部超音波ドップラー）、褐色細胞腫（血中・尿中カテコラミン）、クッシング症候群、甲状腺機能異常、睡眠時無呼吸症候群
- **ABPMの役割**: 24時間自由行動下血圧測定で白衣高血圧の除外、夜間血圧パターン（non-dipper/riser）の評価

### PATHWAY-2試験のエビデンス

治療抵抗性高血圧における4剤目の最適な薬剤を比較した二重盲検クロスオーバーRCT:

- **デザイン**: スピロノラクトン25-50mg vs ドキサゾシン4-8mg vs ビソプロロール5-10mg vs プラセボを各12週間投与
- **主要結果**:
  - スピロノラクトンは家庭収縮期血圧を**プラセボ比 -8.7mmHg**低下（p < 0.001）
  - ドキサゾシン比 -4.3mmHg、ビソプロロール比 -4.5mmHg いずれも有意に優越
- **臨床的意義**: 治療抵抗性高血圧の4剤目として**スピロノラクトンが第一選択**であることを確立
- **実臨床での注意**: 高K血症（特にeGFR 45未満、K 4.5以上で注意）、女性化乳房（エサキセレノンで回避可能）

### 腎デナベーション（RDN）

- **SPYRAL HTN-ON MED試験**: 降圧薬服用中の治療抵抗性高血圧患者を対象。RDN群は6ヶ月時点で24時間収縮期血圧をsham対照比 -7.0mmHg有意に低下
- **RADIANCE-HTN TRIO試験**: 3剤併用の治療抵抗性高血圧でRDNの有効性を確認
- **日本での位置づけ**: 2024年に保険適用。薬物治療抵抗性で偽性抵抗性・二次性高血圧を除外した症例が適応
- **手技**: 大腿動脈アプローチでカテーテルを腎動脈に挿入し、超音波またはラジオ波で腎交感神経を焼灼
- **効果の持続**: 3年間の長期フォローアップで降圧効果の持続が確認されている

### エビデンス・ガイドライン推奨

- **4剤目の選択**: スピロノラクトン25-50mg/日の追加が最も有効（PATHWAY-2試験）。高K血症に注意
- **スピロノラクトン不耐例**: エサキセレノン（ミネブロ）2.5-5mg/日（高血圧用量。女性化乳房なし）、ドキサゾシン2-4mg/日、ビソプロロール2.5-5mg/日
- **腎デナベーション**: 上記の通り。4剤以上でもコントロール不良な真の治療抵抗性高血圧が適応
- **専門医紹介**: 4剤でもコントロール不良、二次性高血圧疑い、臓器障害進行
- **減塩の強化**: 食塩6g/日未満を目標。管理栄養士との連携。随時尿Na/Cr比で定期的にモニタリング
