<h3 className="soap-a">評価</h3>

- **診断根拠:** 収縮期血圧&lt;100mmHg。立ちくらみ、めまい、全身倦怠感。
- **分類:** 本態性 / 起立性 / 食後
- **除外:** 貧血、脱水、心疾患、薬剤性（降圧薬過量、前立腺薬等）。

<h3 className="soap-p">方針・処方</h3>

- 原因薬剤の中止・減量。
- 生活指導（水分摂取、弾性ストッキング、昇圧動作）。
- 症状が強い場合は昇圧剤投与。

## 📖 詳細解説

### 病態生理

- **定義**: 収縮期血圧100mmHg未満（WHOでは男性100/60未満、女性90/60未満）
- **分類**:
  - 本態性低血圧: 体質性。若年女性に多い。多くは無症状
  - 起立性低血圧: 立位3分以内に収縮期20mmHg以上または拡張期10mmHg以上の低下
  - 食後低血圧: 食後2時間以内に収縮期血圧が20mmHg以上低下。高齢者に多い
  - 症候性低血圧: 心疾患、内分泌疾患（Addison病、甲状腺機能低下）、脱水、出血、薬剤性

### 起立性低血圧の定義と診断

- **定義（コンセンサスステートメント）**: 臥位から立位への体位変換後3分以内に以下のいずれかを認める:
  - 収縮期血圧 **20mmHg以上の低下**
  - 拡張期血圧 **10mmHg以上の低下**
  - 高血圧患者では収縮期血圧 **30mmHg以上の低下**を基準とする場合もある
- **初期起立性低血圧**: 立位後15秒以内の一過性血圧低下（40mmHg以上）。若年者に多い
- **遅延型起立性低血圧**: 3分以降に発症。高齢者、自律神経障害の初期に多い
- **Schellong試験**: 臥位10分安静後に立位とし、立位後1, 3, 5, 7, 10分で血圧・脈拍を測定。脈拍変動も評価（脈拍代償の有無で原因推定）

### 起立性低血圧の原因薬剤リスト

| 薬剤分類 | 具体的薬剤例 | 機序 |
|---|---|---|
| **降圧薬** | Ca拮抗薬、ACE-I/ARB、利尿薬、beta遮断薬 | 血管拡張、循環血液量低下 |
| **alpha遮断薬** | ドキサゾシン、タムスロシン、シロドシン | 末梢血管抵抗低下 |
| **三環系抗うつ薬** | アミトリプチリン、ノルトリプチリン | alpha遮断作用 |
| **抗パーキンソン病薬** | レボドパ、ドパミンアゴニスト | 末梢血管拡張 |
| **抗精神病薬** | クエチアピン、リスペリドン、オランザピン | alpha遮断作用 |
| **PDE5阻害薬** | シルデナフィル、タダラフィル | 血管拡張（硝酸薬併用は禁忌） |
| **利尿薬** | フロセミド、サイアザイド | 循環血液量低下 |
| **硝酸薬** | ニトログリセリン、ISDN | 静脈拡張による前負荷低下 |
| **オピオイド** | トラマドール、モルヒネ | 血管拡張、自律神経抑制 |

### 診断基準・鑑別疾患

- **評価**: 臥位→立位の血圧変化測定（Schellong試験）、薬剤歴の確認、二次性原因の除外
- **自律神経機能検査**: Valsalva試験、深呼吸時心拍変動（CVRR）
- **鑑別**: 不整脈（失神を伴う場合）、大動脈弁狭窄症、副腎不全、脱水、貧血
- **神経原性起立性低血圧**: パーキンソン病、多系統萎縮症（MSA）、純粋自律神経不全症（PAF）、糖尿病性自律神経障害

### エビデンス・ガイドライン推奨

- **薬剤性の場合**: 原因薬の減量・変更が最優先。特に高齢者のポリファーマシーを見直す
- **生活指導**: 急に立ち上がらない（段階的起立）、弾性ストッキング着用（20-30mmHg）、腹帯の使用、塩分摂取（低血圧では制限不要、1日10g程度まで）、水分摂取（1.5-2L/日）、運動（下肢筋力強化）、食後すぐに立ち上がらない
- **Physical counter-maneuvers**: 立位時の下肢交差、つま先立ち、スクワット姿勢で血圧低下を軽減

### 薬物療法の具体的用量

| 薬剤 | 用法・用量 | 作用機序 | 注意点 |
|---|---|---|---|
| **ミドドリン（メトリジン）** | 2mg 1日2回（朝・昼）。最大 4mg 1日3回 | alpha1受容体刺激 → 末梢血管収縮 | 臥位高血圧に注意。就寝4時間前までに最終投与 |
| **ドロキシドパ（ドプス）** | 100mg 1日3回から開始。200-300mg 1日3回まで増量 | ノルアドレナリン前駆体 → 交感神経終末でNA合成 | 神経原性起立性低血圧に特に有効。保険適用あり |
| **フルドロコルチゾン** | 0.05-0.2mg 1日1回 | ミネラルコルチコイド → Na・水再吸収増加 → 循環血液量増加 | 低K血症、臥位高血圧、心不全増悪に注意 |

- **ミドドリンとドロキシドパの併用**: 単剤で効果不十分な場合に併用可能
- **臥位高血圧の管理**: 昇圧薬投与中は就寝時にヘッドアップ（10-15度）。臥位血圧が180/100以上なら昇圧薬の減量を検討
