<h3 className="soap-a">評価</h3>

- **診断根拠:** 長期間の高血圧。心電図での左室肥大(LVH)。心不全徴候（BNP上昇、息切れ）。
- **重症度:** 心機能保たれている / 拡張不全あり / 収縮不全あり

<h3 className="soap-p">方針・処方</h3>

- 厳格な降圧（目標130/80未満）。
- レニン・アンジオテンシン系阻害薬（ARB/ACE）の推奨。
- 心不全合併時はβ遮断薬、利尿薬等の追加。

## 📖 詳細解説

### 病態生理

- **定義**: 長期間の高血圧による左室肥大・拡張障害 → 心不全に至る病態
- **進行**: 高血圧 → 圧負荷 → 求心性左室肥大 → 拡張障害（HFpEF）→ 遠心性肥大 → 収縮障害（HFrEF）
- **左室肥大（LVH）**: 心血管イベントの独立したリスク因子。脳卒中リスク2-3倍、心筋梗塞リスク2倍
- **心筋線維化**: 持続的な圧負荷により間質の線維化が進行 → 不整脈基質にもなる

### LVH心電図診断基準

| 基準 | 判定方法 | カットオフ | 感度 / 特異度 |
|---|---|---|---|
| **Sokolow-Lyon電位基準** | SV1 + RV5（またはRV6）の和 | **35mm以上** | 感度 22% / 特異度 100% |
| **Cornell電位基準** | RaVL + SV3 | 男性 **28mm以上**、女性 **20mm以上** | 感度 42% / 特異度 96% |
| **Cornell積（duration product）** | (RaVL + SV3) x QRS幅(ms) | **2,440mm・ms以上** | 感度・特異度ともに電位基準より優れる |
| **Romhilt-Estes点数法** | 5項目のスコア合計 | 5点以上で確定、4点で疑い | 感度 33-54% / 特異度 94-97% |

- **ST-T変化（strain pattern）**: LVHに伴うST低下・T波陰転（V5-V6、I、aVL）。心筋虚血やリモデリングの進行を示唆し予後不良因子
- **限界**: 心電図LVHの感度は低い（見逃しが多い）。心エコーの方が感度・特異度ともに優れるが、当院では施行不可

### 心エコーによるLVH評価基準

| 指標 | カットオフ（男性） | カットオフ（女性） | 臨床的意義 |
|---|---|---|---|
| **IVSTd（心室中隔壁厚）** | **11mm以上** | **11mm以上** | スクリーニングに有用 |
| **LVPWd（後壁厚）** | 11mm以上 | 11mm以上 | IVSTdと合わせて評価 |
| **LVMI（左室重量係数）** | **115 g/m2以上** | **95 g/m2以上** | LVH確定診断の標準指標 |
| **RWT（相対的壁厚）** | 0.42以上: 求心性肥大 | 0.42未満: 遠心性肥大 | リモデリングパターンの分類 |
| **E/e'比** | 15以上: 拡張障害示唆 | 同左 | 左室充満圧上昇の指標 |

- **リモデリング分類**:
  - 正常: LVMI正常 + RWT正常
  - 求心性リモデリング: LVMI正常 + RWT上昇（早期段階）
  - 求心性肥大: LVMI上昇 + RWT上昇（圧負荷型、最も典型的）
  - 遠心性肥大: LVMI上昇 + RWT正常（容量負荷型、進行期）

### 診断基準・鑑別疾患

- **BNP/NT-proBNP**: 心不全の程度を反映。BNP 40pg/mL以上でスクリーニング陽性
- **鑑別**: 肥大型心筋症（非対称性中隔肥大、家族歴）、大動脈弁狭窄症（駆出性収縮期雑音）、心アミロイドーシス（granular sparkling、低電位）、Fabry病（若年男性のLVH）

### LVH退縮のエビデンス

- **LIFE試験**: ロサルタン vs アテノロールを高血圧性LVH患者で比較。ロサルタン群で心電図LVHの退縮率が有意に高く、複合心血管エンドポイントを13%低減。特に脳卒中リスクを25%低減
- **メタアナリシス（Klingbeil et al.）**: 降圧薬クラス別のLVH退縮効果
  - ARB: **-13%**（最も有効）
  - ACE-I: **-10%**
  - Ca拮抗薬: **-11%**
  - 利尿薬: **-8%**
  - beta遮断薬: **-6%**（最も弱い）
- **臨床的意義**: LVHの退縮は降圧効果と独立して心血管イベントを低減する。ARB/ACE-Iが最も有効であり、高血圧性心疾患の第一選択となる根拠
- **SGLT2阻害薬**: 近年、LVMI低減効果のエビデンスが蓄積（EMPA-HEART trial等）

### エビデンス・ガイドライン推奨

- **降圧**: 左室肥大退縮のためにRAS阻害薬（ARB/ACE-I）が最も有効（LIFE試験）
- **目標血圧**: 130/80mmHg未満（心不全合併時はさらに低い目標も）
- **心不全合併時**: ARB/ACE-I + beta遮断薬 + MRA（標準的心不全治療）+ SGLT2阻害薬（HFpEFにもHFrEFにもエビデンス）
- **利尿薬**: 体液貯留がある場合に追加
- **フォローアップ**: 心電図は年1回以上。BNP/NT-proBNPで心不全進行をモニタリング。心エコーは可能な施設で1-2年ごと
