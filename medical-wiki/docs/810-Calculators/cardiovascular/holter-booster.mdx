# ホルター心電図判読支援ツール

Philips DigiTrak XT / Zymed 等の自動解析レポートを開きながら、要所を押さえた項目（陽性所見・陰性所見・要数値）を入力すると、コピペ用サマリと臨床的示唆（PVC 心筋症リスク・AF 検出・ペースメーカー適応・QTc 延長 torsades リスク等）を自動抽出します。電子カルテへの貼付を想定。

<HolterBooster />

## 使い方

1. **患者背景・依頼理由** を入力（年齢・性別・主訴・症状日誌との相関・基礎疾患・薬剤・デバイス有無）— 診断補助の精度に影響します。
2. **基本情報** → **心室性** → **上室性** → **徐脈・伝導障害** → **ST 変化** → **HRV** → **QT** → **ペースメーカー機能** の順に、レポート上の該当項目を入力。
3. **陰性所見**（「なし」等）も明示的にクリックしておくと、記載漏れが減ります。
4. 各セクションは折り畳み可能（デバイスなしなら「ペースメーカー機能」を閉じるなど）。
5. **診断補助** 欄には入力値から自動抽出した臨床的示唆を提示。
6. **全文コピー** ボタンで電子カルテへ貼り付け。

## 診断補助の主なルール（一例）

- **PVC 出現率 ≥10%** → PVC 誘発性心筋症リスク、心エコー LV 評価推奨
- **PVC 出現率 ≥20%** → 循環器紹介・アブレーション検討
- **NSVT** → 心筋症・虚血の精査、器質的心疾患合併で ICD 適応評価
- **持続性 VT** → 緊急循環器コンサルト・ICD 適応・原因精査
- **心房細動検出** → CHA₂DS₂-VASc に基づく抗凝固検討、心エコー・甲状腺評価
- **AF burden ≥5%** → 臨床的 AF として抗凝固をより積極的に検討
- **ポーズ ≥3秒（覚醒 or 症状伴）** → ペースメーカー適応（JCS クラス I）
- **2度AVブロック モビッツII型 / 3度AVブロック** → ペースメーカー適応（クラス I）
- **QTc >500 ms** → torsades リスク、原因薬剤中止・K/Mg 補正
- **SDNN &lt;50 ms** → 予後不良指標（心不全・DM 心血管神経障害）
- **V ペーシング率 >40%（CRT 以外）** → ペーシング誘発性心機能低下リスク、CRT アップグレード検討

## 注意

- 本ツールは **判読サポート** です。最終的な診断・治療方針は臨床医が行ってください。
- ホルター記録の解釈で最重要なのは **症状日誌との照合** です。相関の有無は必ず入力してください。
- 数値の「正常範囲」表示は一般的な参考値です。年齢・基礎疾患・薬剤で解釈は変わります。
- 診断補助のガイドライン準拠事項（ペースメーカー適応等）は JCS 各種ガイドラインを都度参照してください。
