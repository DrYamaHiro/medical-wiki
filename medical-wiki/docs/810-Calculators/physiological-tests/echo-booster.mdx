# エコー所見入力ツール

部位を選択 → 臓器別チェックリストで所見を入力 → コピペ用テキストと簡易アセスメントを自動生成します。電子カルテへの貼り付けを想定。

<EchoBooster />

## 使い方

1. **検査部位を選択** (腹部・頸動脈・甲状腺・心臓・下肢静脈)
2. **所見入力**: 各臓器の項目をクリック or 数値入力
   - 選択肢は「正常」と「異常」で色分け (青=正常、赤=異常所見)
   - 異常所見は未選択でも赤縁で識別可能
3. **コピペ用所見**: 入力に応じて自動でテキスト生成
4. **自動アセスメント**: 主要所見に対する次のアクションを提示 (推奨にすぎないため最終判断はカルテで上書き)
5. **全文コピー** ボタンで電子カルテへ貼り付け

## 部位別の対象項目

### 腹部エコー
肝臓（サイズ・輝度・表面・腫瘤・門脈）／胆嚢（結石・壁厚・ポリープ）／膵臓（腫大・膵管・腫瘤）／脾臓／腎臓（サイズ・結石・水腎症・嚢胞・腫瘤）／腹部大動脈／膀胱（壁厚・残尿）

### 頸動脈エコー
両側 CCA の max IMT、頸動脈洞・内頸動脈の狭窄度・PSV、プラーク性状、椎骨動脈血流。狭窄度の測定方法 (NASCET / ECST / エリア法) は各動脈ごとに選択可

### 甲状腺エコー
全体（サイズ・実質・血流）／右葉・左葉（結節数・最大径・TI-RADS）／頸部リンパ節

### 心エコー
左室形態 (IVS/PW/LVDd/LVDs/LAD/上行AoD)、左室収縮能 (LVEF Teich/Simpson・LV%FS・LVEDV/LVESV・局所壁運動)、左室拡張機能 (E/A/E-A比/DcT/e'/E/e'・グレード)、弁膜 (AV/MV/TV/PV・AV Vmax・TRPG)、右心系 (RV基部径/RV壁厚/TAPSE/S'・右房)、下大静脈・心嚢液。性別選択で正常値の性差を反映、拡張機能グレードの自動候補提示あり

### 下肢静脈エコー (DVT)
両側下肢の総大腿/浅大腿/膝窩/下腿静脈の圧迫所見、皮下浮腫、Wells スコア

## 注意

- 出力テキストは編集の出発点として活用してください。最終的な所見・アセスメントは医師の判断で記載してください。
- 数値の hint は一般的な参照値で、年齢・体格・既往により目標値は異なります。
- TI-RADS・NASCET・Wells 等のスコアリングは個別の計算ツール（[CHA₂DS₂-VASc](../cardiovascular/chads) 等）も併用してください。
