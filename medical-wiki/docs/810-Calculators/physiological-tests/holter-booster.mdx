# ホルター心電図判読支援ツール

Philips **ePatch** / DigiTrak XT / Zymed 等の自動解析レポートを開きながら、レポートの並びに沿って数値・所見を入力すると、コピペ用サマリと **【緊急】/【要精査】/【参考】3段階の診断補助コメント** を自動生成します。電子カルテへの貼付を想定。

<HolterBooster />

## 使い方

1. **患者背景・依頼理由** を入力（性別・主訴・症状日誌との相関）— 症状連動の診断補助に影響します
2. **サマリー → 異所性 → エピソード → 心室形態 → 陽性所見チェック → ST → CVHRI → HRV → QT → PM 機能** の順に、ePatch レポートの該当項目を入力
3. **陰性所見** (「なし」等) も明示的にクリックしておくと、記載漏れが減ります
4. 各セクションは折り畳み可能、入力済み件数バッジで進捗が見える
5. 診断補助の「対応欄へ ▸」ボタンで該当セクションへスクロール
6. **全文コピー** ボタンで電子カルテへ貼り付け

## プリセットで時短

- **洞調律・有意所見なし（要確認）**: 陽性所見32項目 + AF/AVB/ST を一括「なし」、数値項目は変更しない
- **AF検出目的で今回未検出** / **動悸精査で PVC/SVPC のみ** / **PM 定期評価で機能正常** — 典型シナリオ別プリセット
- プリセット適用後は全般所見に「※プリセット適用済み — 個別項目を確認してください」の注記が自動追記されます

## 診断補助 3段階分類

- **【緊急】** ePatch メール連絡項目相当（Mobitz II / 完全AVB / VT / RonT / Pause≥3s / 新規AF / PM機能不全 / >190bpm / <35bpm / 失神主訴 / QTc>500ms 等）
- **【要精査】** CVHRI≥15 (OSA疑い)、PVC≥10%、NSVT頻回、AF検出、SVPC≥300、ST低下、SVT長連発、QTc境界域、Δ波、単一形態PVC≥80%、夜間QT延長、日次負荷変動大 等
- **【参考】** ノイズ>30%、平均HR異常、SDNN<50、V ペーシング>40%、症状-不整脈相関パターン、T波陰転化 等

## Phase 別対応 ePatch レポート要素

| ePatch ページ要素 | 本ツール対応 |
|---|---|
| p2-3 サマリー / エピソード | 全セクション |
| p9 日次負荷サマリー | 独立セクション (行追加/削除) |
| p11 心室形態解析 | 主要3+全9形態 |
| p12 患者症状 vs 不整脈 | 症状×不整脈マトリクス |
| p14 QT時間帯別 | 昼夜QTc |
| p15 CVHRI詳細 | 独立セクション |
| p19 メール連絡項目 | 【緊急】判定 |

## 注意

- 本ツールは **判読サポート** です。最終的な診断・治療方針は臨床医が行ってください
- ホルター記録の解釈で最重要なのは **症状日誌との照合** です。相関の有無は必ず入力してください
- 数値の「正常範囲」表示は一般的な参考値です。年齢・基礎疾患・薬剤で解釈は変わります
- 診断補助のガイドライン準拠事項（PM 適応等）は JCS 各種ガイドラインを都度参照してください
