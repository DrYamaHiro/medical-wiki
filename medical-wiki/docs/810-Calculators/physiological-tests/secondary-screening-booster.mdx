# 二次健診 Booster

労災二次健康診断（一次健診で血圧・脂質・血糖・肥満度の4項目すべて異常、または産業医がリスクありと判断した労働者が対象）の医師診察で、**一次健診値のカットオフ**と**技師が口頭で伝える心エコー・頸部エコーの所見**をクリックで入力すると、検診チームのマニュアルに沿って **紹介状の要否・紹介先の種別・ラベル・患者説明トークスクリプト・保健師への申し送り・診療情報提供書の下書き** を提案します。基本操作はクリックのみで、数値・医療機関名の入力は任意です。

## 使い方（受診者ひとりあたりの流れ）

1. **受診者背景**: 導入の問診で確認する「かかりつけ医の有無」「治療中の疾患」「自覚症状」をクリック。かかりつけ医の有無は判定の分岐に直結するので最初に入れる
2. **一次健診結果**: 保健指導表を見ながら、血圧・LDL・HDL・TG・血糖・肥満度の **カットオフ帯域をクリック**（例: LDL「140-179」）。人間ドック協会の判定（A〜D）と JSH2025 の血圧分類、労災二次健診の対象基準（4/4）が自動表示される。「4項目とも軽度該当」「全て基準内」の一括ボタンあり。数値を入れたい場合は「数値入力（任意）」を開くと、入力値から帯域が自動選択される。後日の結果表作成時は「二次健診の採血値」に切り替えて同じ欄を使う
3. **心エコー・頸部エコー**: 技師のインカム伝達を **カットオフの選択肢でクリック**（例: 壁厚「13mm以上16mm未満」、狭窄率「50%以上70%未満」）。弁膜症は AS・AR・MS・MR・TR・PR の弁ごとに「なし / 軽症 / 中等症 / 重症」を選び、最も重い弁で判定する。頸動脈は模式図の部位（左右の CCA・BIF・ICA・ECA）を押してプラークと狭窄率を入れると、最大値がチャート項目に自動反映され、カルテ要点・患者説明・紹介状に部位が付く。「全て正常」を押してから異常項目だけ変えると速い。異常所見にはかかりつけ医がいる場合のみ「未知 / 既知（通院中）」のトグルが出る。既定は「未知」（オーバートリアージ許容）。数値入力は任意
4. **提案**: チャート（所見 x 既知/未知 → 対応）の最大レベルと、かかりつけ医の有無、採血の要治療水準から紹介状の要否を提案する。病院紹介レベルでは自覚症状（胸痛・安静時息切れ・失神・一過性の神経症状・強い頭痛や視覚障害）があれば当日紹介を提案。エコーが正常でもこれらの症状や III度高血圧（180/110 以上）があれば赤い警告を出し、当日対応の要否を医師に促す。医師は「発行タイミング」「最終判断」で上書きできる。紹介先の診療科もクリックで選ぶ
5. **出力**: 各ブロックの「コピー」でカルテ・ラベル・保健師申し送り・トークスクリプト・診療情報提供書の下書きに貼り付ける

## 判定ロジック（マニュアルのチャート）

紹介状は (1) 早期の病院受診が必要で当日発行する場合 (2) 治療やフォローが必要だがかかりつけ医がいない場合 (3) かかりつけ医がいても、異常を指摘されたことのない（未知の）中等症以上の場合に作成する。かかりつけ医への報告のための紹介状は省略する（特別に報告・連絡が必要な場合を除く）。

### チャート外の所見（本ツール独自の目安）

マニュアルのチャートにない所見は、以下の目安で分類する。マニュアルの基準ではないので、最終判断は医師が行う。

| 項目 | 個別判断 | 病院紹介相当 | 根拠の目安 |
|---|---|---|---|
| 心嚢液 | 少量 | 中等量以上（タンポナーデ徴候があれば当日対応） | 中等量以上は原因精査が必要 |
| 上行大動脈径 | 40mm 以上 45mm 未満 | 45mm 以上（50mm 以上や解離疑いは当日対応を検討） | 径が大きいほど緊急性が上がる |
| 肺高血圧（TRPG） | 34-46 mmHg | 46 mmHg 超 | ESC/ERS 2022 の TRV 2.9-3.4 m/s（中等度）、3.4 m/s 超（高い可能性）に相当 |
| 大動脈弁石灰化・左房拡大 | 個別判断 | | 弁通過血流速度などを技師に確認 |
| 甲状腺（結節・びまん性腫大） | 個別判断 | | 径や性状（微細石灰化・境界不整・縦長）で精査を検討。TSH/FT4 の確認 |
| 椎骨動脈逆流 | 個別判断 | | 完全/部分逆流を確認し、両上肢の血圧差を測定 |

エコー結果に異常がない場合でも、一次健診の採血結果で治療・フォローが必要な場合は紹介状を作成する。本ツールでは、採血・血圧が要治療水準（判定 D、または II度以上の高血圧）でかかりつけ医がいなければ「後日紹介状（クリニック）」、要再検査水準（判定 C、または I度高血圧）でかかりつけ医がいなければ「採血結果次第（紹介先を決めてカルテに記載）」を提案する。III度高血圧（180/110 以上）は安静後の再測定と早期受診勧奨を警告として出し、緊急性を示唆する症状があれば当日受診を提案する。

### 技師の判断基準との関係

技師はエコー実施後、チャートの「病院紹介」に当てはまると判断した場合、保健師へ「病院紹介の可能性がある方なので、運動の指導はしないでください」と申し送る（オーバートリアージ許容）。本ツールの「保健師への申し送り」ブロックも同じ基準で文言を出す。

## 患者説明トークスクリプト

マニュアルの導入・結果説明・締めをそのまま収載し、結果説明はエコー所見の平易な表現を差し込んで、判定に応じて次の型を選ぶ。

- (1) かかりつけ医あり・紹介状なし: 結果をかかりつけ医と共有。1ヶ月後くらいに郵送される結果を次回受診時に渡す
- (2) かかりつけ医なし・紹介状あり: かかりつけ医を作る必要を説明。行ったことのあるクリニックを聞いて紹介先を決め、結果の封筒に紹介状を同封
- (3) かかりつけ医なし・紹介状なし または 採血結果次第: 今すぐの受診は不要だが、後日の採血結果次第で紹介状を同封する。念のため紹介先を決めてカルテに記載
- (4) 当日紹介状: 緊急性を踏まえて当日中の受診を前提に紹介状を作成。悪化時は救急要請。受付で手続き・書類、移動手段と到着予定を確認
- マニュアル外・後日の病院紹介（かかりつけ医なし）: 専用の型がないため (2)(4) を基に「病院での精密検査が必要」「精密検査の後はかかりつけ医を作る」という文面を出す
- マニュアル外・かかりつけ医あり・紹介状あり（未知の中等症以上）: (1)(2) を組み合わせた文面を出す

## ラベル運用（カルテの「+」）

- 000: 【当日】紹介状 ／ 【後日】紹介状 ／ 紹介状無し のいずれかを必ず選択
- 000: 宛先検索依頼: 紹介先を受付に探してほしい場合。カルテに紹介依頼する診療科を記載し、一旦保存した後に宛名無しの紹介状を作成
- 01: ③医師診察: 診察終了時に消す
- 「採血結果次第」の場合は特別なラベルは不要（検診チーム回答 2026-09-14）。ツールは「紹介状無し」を出し、紹介先候補をカルテに記載するよう促す
- 混雑時は紹介状の作成を後回しにしてよい。ラベルの実施と「診察終了」のステータス変更を先に行い、後から紹介状を作成する（STEP5 ポイント）

## 保健指導の運動制限基準（保健師への申し送り）

| 項目 | 基準 | 対応 |
|---|---|---|
| 血圧 | III度高血圧（診察時 180/110、家庭血圧 160/110 以上） | 血圧コントロール必須、降圧後に実施。運動前 180/110 以上は運動を控えて休養 |
| 血圧 | II度高血圧以下（診察時 160-179/100-109） | 運動療法の対象（脳心血管病のない高血圧患者）。運動前 160/100 以上は散歩程度にとどめる |
| 心疾患 | 心血管疾患・骨関節疾患・低体力者 | 3メッツ以下の生活活動（掃除・洗車・こどもと遊ぶ・自転車で買い物）から身体活動量を増やす |
| 血糖 | 空腹時血糖 180 以上、HbA1c 9% 以上、尿ケトン体中等度以上 | 運動禁忌。医師相談の上で実施 |
| 肥満 | | 初歩的なものから開始。3〜6メッツ程度（ウォーキング・自転車エルゴメーター・水中歩行） |

## 後日: 結果表の医師所見テンプレート

結果表（カルテ【書類】の「結果作成」から Excel をダウンロード）の「二次健康診断等の結果における医師の所見（就業上の措置又は配慮すべき事項）」欄は、プルダウンからテンプレートを選ぶと所見文が自動入力される。ツールは判定と就業状況から候補を提示する。

| テンプレート | 自動入力される所見 |
|---|---|
| 1 休職中 | 就労については、引き続きかかりつけ医や産業医との面談を続けて決める必要があります。 |
| 2 就業制限の可能性あり（当日紹介状作成） | 就業制限がある可能性があるため、精密検査の上、就業上の制限等があるか再度指示を受けてください。 |
| 3 就業制限なし（かかりつけ有）かかりつけフォロー（紹介状なし） | 就業上の制限はありませんが、かかりつけ医を受診して結果を共有し、指示を受けてください。 |
| 4 就業制限なし（かかりつけ無）後日新規クリニック（紹介状あり） | 就業上の制限はありませんが、紹介状に記載された医療機関を予約して結果を共有し、指示を受けてください。 |
| 5 就業制限なし（かかりつけ無）紹介状なし | 就業制限なし。 |

## マニュアル原文の不明点と検診チームの回答（2026-09-14）

受領した PDF 版マニュアルの不明点を確認した結果。最新版マニュアルは印刷物のみで共有されていないため、本ツールは PDF 版と以下の回答に基づく。

1. 不整脈の備考「気になって座ったら紹介」: 最新版では「自覚症状を踏まえて紹介検討」。ツールもこの文言に更新済み
2. 壁厚「肥厚なし」行の「問診なし」: 最新版では肥厚なしの行自体が削除されている。ツールは「肥厚なし」を正常の選択肢として残し、患者向け文（血圧による影響かもしれないが他の可能性もありフォローが必要）は 13mm 以上の行の内容として扱う
3. 「未治療の場合は紹介」の主語: 当院（二次検診チーム）からかかりつけ等へ紹介する。ツールは脂質・血圧が未治療の IMT 肥厚・プラークを「後日紹介状（クリニック）」に格上げ済み
4. 「採血結果次第」のときの 000 ラベル: 特別な扱いは不要。ツールは「紹介状無し」を出す
5. カルテ「●紹介状」欄の値: 現状のまま（有り / 無し のみ。採血結果次第の場合は「無し」と紹介先候補の記載を組み合わせる）

## 注意

- 本ツールは **判定の提案と入力補助** です。診断・紹介・就業判定の最終決定は担当医師が行ってください
- 受診者の氏名・ID などの個人情報は入力しないでください（ブラウザ内で完結し保存はしませんが、運用ルールとして）
- 心エコーの所見はカルテの「03: 心エコーテンプレート」に技師が記載し、医師が確認・手直しします。本ツールのエコー要点はその補助であり、技師所見の代替ではありません
- 紹介先は「土曜AM診療している」ことを条件とし、Google Map の共有で通えるかを受診者と確認する
- 当日受診が必要な場合は、医師または看護師から病院へ連絡調整を行う
- 紹介状の作成: カルテ【書類】→【文書雛形】→ 当日・後日診療情報提供書雛形をダウンロード → 内容記載 → 書類フォルダにアップロードして保存
- 血圧分類は JSH2025 の診察室血圧分類（降圧目標は全年齢で 130/80 未満）。帯域クリックでは収縮期・拡張期の高い方の度数を選ぶ
- 採血の判定は人間ドック協会基準（A〜D）を転記。E（治療中）は実装していないので、治療中の受診者は「治療中の疾患」に登録して読み替える
- 出典: 検診チーム作成の医師用マニュアル（2026-09 受領版）。マニュアル改訂時は本ページとツールの基準も更新すること
