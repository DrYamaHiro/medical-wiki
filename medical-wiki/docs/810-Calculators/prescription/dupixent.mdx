# デュピクセント 投与量・評価ツール

投与量計算（5適応対応）と適応別の評価ツールを統合しています。適応症を選ぶと、対応する評価スケールに自動で切り替わります。

| 適応症 | 評価ツール |
|--------|-----------|
| アトピー性皮膚炎 | IGA・EASI・BSA |
| 気管支喘息 | ACT |
| 鼻茸を伴う慢性副鼻腔炎 | NPS |
| COPD | mMRC |
| 結節性痒疹 | WI-NRS |
