<h3 className="soap-a">評価</h3>

- 二次健診・産業医面談後の就業判定。
- **判定結果:** 就業上の問題なし / 就業上の制限あり / 要休業
- 判定理由（該当項目を記載）:
- 血圧管理: 良好 / 要改善（現在＿/＿ mmHg、降圧薬 調整中 / 未治療）
- 血糖管理: 良好 / 要改善（HbA1c ＿%）
- 肝機能: 正常 / 異常（AST/ALT/γGTP ＿）
- 腎機能: 正常 / 異常（eGFR ＿）
- 心電図: 正常 / 異常（所見: ＿ → 510-AP-07参照）
- 胸部X線: 正常 / 異常（所見: ＿ → 510-AP-08参照）
- 就業制限の内容（該当時）:
- 残業制限（＿時間/月以内）
- 深夜業務制限
- 出張制限
- 重筋作業制限
- 高所作業制限
- 運転業務制限

<h3 className="soap-p">方針・処方</h3>

- コメント（該当するものを選択・編集）:
「現時点では就業上の問題点は確認されませんでした。引き続き経過観察とします。」
または
「上記理由により就業上の制限が必要と判断します。＿ヶ月後の再評価を推奨します。」
- 意見書を事業者へ提出（健診実施日から30日以内）。
- **制限ありの場合:** 再評価時期を明記し、次回面談を予約。

#### 処方・アクション

**意見書・書類作成**

- <span className="med-id">[Rx-HC-FitWork-Opinion]</span> 就業上の措置に関する医師の意見書
- **判定区分:** 通常勤務可 / 就業制限 / 要休業
- **制限内容（該当時）:** 残業制限・深夜業務制限・出張制限・重筋作業制限・高所作業制限・運転業務制限
- **再評価時期:** ＿ヶ月後

**関連検査参照**

- <span className="med-id">[Ref-HC-FitWork-ECG]</span> 心電図所見 → 510-AP-07.txt参照
- <span className="med-id">[Ref-HC-FitWork-CXR]</span> 胸部X線所見 → 510-AP-08.txt参照

#### 指導・計画

- 就業制限の内容と期間を本人に説明し、理解を確認。
- 治療中の疾患がある場合、主治医との連携を確認。
- **再診目安:** 制限ありの場合＿ヶ月後に再評価。問題なしの場合は次回定期健診時。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[法的根拠]** 就業判定は労働安全衛生法第66条の4-5に基づく。意見書は30日以内に事業者へ提出。
>
> **[過重労働]** 月80時間超の時間外労働者への面接指導は医師の義務（労安法第66条の8）。
>
> **[守秘義務]** 健診結果の取り扱いは個人情報保護に最大限の注意。事業者への意見書には最低限必要な情報のみ記載せよ。
