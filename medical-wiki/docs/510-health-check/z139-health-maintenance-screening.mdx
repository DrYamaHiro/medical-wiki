<h3 className="soap-a">評価</h3>

- 慢性疾患管理中の患者に対する包括的予防医療チェックリスト。

#### がん検診

- 大腸がん: 便潜血（年1回、40歳以上）→ 実施済 / 未 / 該当なし
- 胃がん: 内視鏡 or X線（2年に1回、50歳以上）→ 実施済 / 未
- 肺がん: 胸部X線（年1回）± 喀痰細胞診（BI 600以上）→ 実施済 / 未
- 乳がん（女性）: マンモグラフィ（2年に1回、40歳以上）→ 実施済 / 未
- 子宮頸がん（女性）: 細胞診（2年に1回、20歳以上）→ 実施済 / 未

#### 骨密度

- **骨密度検査:** 閉経後女性、ステロイド使用者、骨折リスク因子あり → 実施済 / 未

#### 感染症スクリーニング

- **B型肝炎（HBs抗原）:** 未検 / 陰性 / 陽性
- **C型肝炎（HCV抗体）:** 未検 / 陰性 / 陽性
- **梅毒（RPR/TP）:** 未検 / 陰性 / 陽性
- **HIV（同意取得の上）:** 未検 / 陰性 / 陽性

#### ワクチン接種状況

- **インフルエンザ:** 本年度 接種済 / 未
- **肺炎球菌（65歳以上）:** ニューモバックス 接種済 / 未
- 帯状疱疹（50歳以上）: シングリックス 1回目 / 2回目 / 未
- **COVID-19:** 最終接種 ＿年＿月

#### 生活習慣

- **喫煙:** 現喫煙 / 禁煙済 / 非喫煙 → TDS 5点以上なら禁煙治療推奨
- **飲酒:** AUDIT-C ＿点 → 高リスクなら減酒指導

<h3 className="soap-p">方針・処方</h3>

- チェックリストで不足分を抽出し、次回以降の検査計画を立てる。

#### 処方・アクション

**がん検診オーダー**

<span className="med-id">[Rx-HC-HM-FOBT] 便潜血検査</span>
- 便潜血2日法 *— 大腸がん検診（年1回、40歳以上）*
<span className="med-id">[Rx-HC-HM-CXR] 胸部X線</span>
- 胸部X線（正面） *— 肺がん検診（年1回）*
<span className="med-id">[Rx-HC-HM-Sputum] 喀痰細胞診</span>
- 喀痰細胞診 ；BI 600以上の喫煙者

**感染症スクリーニング**

<span className="med-id">[Rx-HC-HM-HBsAg] HBs抗原</span>
- HBs抗原（定性）；B型肝炎スクリーニング
<span className="med-id">[Rx-HC-HM-HCV] HCV抗体</span>
- HCV抗体（定性）；C型肝炎スクリーニング
<span className="med-id">[Rx-HC-HM-Syphilis] 梅毒検査</span>
- RPR定量, TP抗体 ；梅毒スクリーニング
<span className="med-id">[Rx-HC-HM-HIV] HIV検査</span>
- HIV-1/2抗体（同意取得後）；HIVスクリーニング

#### 指導・計画

- 不足している検診項目を患者に説明し、受診勧奨。
- がん検診は自治体の助成制度を利用可能な場合がある旨を説明。
- ワクチン接種歴を確認し、未接種のものは接種計画を立てる。
- **喫煙者:** TDS 5点以上なら禁煙外来の適応。禁煙治療の説明を行う。
- **飲酒:** AUDIT-C高リスクなら減酒指導。必要に応じて肝機能検査を追加。
- **再診目安:** 次回定期受診時にチェックリストを更新。

> 💡 **Dr.Advice**
>
> **[便潜血]** 大腸がん検診で最もエビデンスレベルの高い検診。受診率が低いため積極的に勧奨せよ。
>
> **[骨密度]** ステロイド5mg/日以上を3ヶ月以上使用する患者は必ず骨密度を測定せよ。
>
> **[B/C肝]** 一生に一度はスクリーニングを受けるべきとされている。特にC型肝炎はDAA治療でSVR 97%以上が見込める。

## 📖 詳細解説

### 概要

ヘルスメンテナンス（健康維持・予防医療）は、無症候の個人に対してエビデンスに基づくスクリーニングと予防介入を行い、疾患の早期発見・発症予防を図るものである。日本では厚生労働省の指針に基づく対策型がん検診と、個人の判断で受ける任意型検診がある。

### 評価基準

**厚労省推奨 がん検診5種の推奨年齢・頻度**

| がん種 | 対象年齢 | 検査方法 | 頻度 | エビデンスレベル |
|--------|---------|---------|------|----------------|
| 胃がん | 50歳以上 | 胃内視鏡検査 or 胃X線検査（バリウム） | 2年に1回 | 死亡率減少効果あり |
| 大腸がん | 40歳以上 | 便潜血検査（免疫法2日法） | 年1回 | 死亡率減少効果あり（RCTで確認） |
| 肺がん | 40歳以上 | 胸部X線（＋喀痰細胞診: BI 600以上） | 年1回 | 死亡率減少効果あり |
| 乳がん | 40歳以上（女性） | マンモグラフィ | 2年に1回 | 死亡率減少効果あり |
| 子宮頸がん | 20歳以上（女性） | 子宮頸部細胞診 | 2年に1回 | 死亡率減少効果あり |

注: 前立腺がん（PSA検診）は対策型検診として推奨されていない（過剰診断のリスク）。

**骨密度スクリーニング**

- **対象:** 閉経後女性（特に65歳以上）、ステロイド長期使用者（プレドニゾロン換算5mg/日以上を3ヶ月以上）、骨折既往、低体重（BMI 18.5未満）
- **検査:** DXA法（腰椎・大腿骨頸部）が標準
- **診断基準（骨粗鬆症）:** YAM（若年成人平均値）の70%以下、またはYAM 80%以下＋脆弱性骨折あり
- **FRAX:** 10年間の主要骨折リスクが15%以上で薬物治療を考慮（日本骨粗鬆症学会）

**感染症スクリーニング**

| 検査項目 | 対象 | 頻度 | 備考 |
|---------|------|------|------|
| HBs抗原 | 一般成人（一生に1回） | 1回 | 陽性の場合はHBe抗原/抗体、HBV-DNA定量で活動性評価 |
| HCV抗体 | 一般成人（一生に1回） | 1回 | 陽性ならHCV-RNA定量。DAA治療でSVR 97%以上 |
| 梅毒（RPR+TP抗体） | リスク因子あり | 適宜 | 近年日本で急増（2023年報告数14,906件） |
| HIV抗体 | リスク因子あり（同意取得後） | 適宜 | 早期診断・早期治療（U=U: Undetectable = Untransmittable） |

**ワクチン推奨（成人）**

| ワクチン | 対象 | スケジュール | 備考 |
|---------|------|-------------|------|
| インフルエンザ | 全年齢（特に65歳以上・基礎疾患あり） | 年1回（10-12月） | 定期接種（65歳以上） |
| 肺炎球菌（PPSV23） | 65歳以上 | 1回（定期接種） | 5年間隔で再接種を考慮 |
| 肺炎球菌（PCV15/PCV20） | 65歳以上、免疫不全者 | PCV15→PPSV23、またはPCV20単独 | 2024年より定期接種にPCV追加 |
| 帯状疱疹（シングリックス） | 50歳以上 | 2回（2ヶ月間隔） | 予防効果90%以上。任意接種 |
| HPV（シルガード9） | 9-45歳（女性: 定期接種対象あり） | 3回（0-2-6ヶ月） | 公費キャッチアップ接種は2025年3月に終了した。以降は任意接種（自費） |
| B型肝炎 | 医療従事者、HBVキャリアの家族等 | 3回（0-1-6ヶ月） | 抗体価10 mIU/mL以上で免疫獲得 |
| 破傷風 | 全成人（10年ごと追加接種） | 基礎3回後10年ごと | 1968年以前出生者は基礎免疫なしの可能性 |

### エビデンス・ガイドライン推奨

**厚生労働省「がん予防重点健康教育及びがん検診実施のための指針」（令和5年改正）**

- 上記5種のがん検診が対策型検診として推奨されている
- 精密検査受診率の目標: 90%以上
- 便潜血検査は大腸がんによる死亡率を約33%低下させる（Cochrane Review）

**有効性評価に基づくがん検診ガイドライン（国立がん研究センター）**

- 推奨グレードA（十分なエビデンスあり）: 便潜血（大腸がん）、マンモグラフィ（乳がん）、子宮頸部細胞診
- 推奨グレードB（相応のエビデンスあり）: 胃内視鏡、胸部X線+喀痰細胞診
- 推奨なし: PSA単独検診（前立腺がん）、腹部エコー単独（肝臓がん）

**日本骨粗鬆症学会 骨粗鬆症の予防と治療ガイドライン2015年版**

- 閉経後女性は65歳以上でDXAによる骨密度測定を推奨
- ステロイド性骨粗鬆症: 経口ステロイド3ヶ月以上使用予定の場合、骨密度測定と薬物治療（ビスホスホネート等）を検討
- FRAXスコアに基づく薬物介入閾値は国ごとに異なる

**USPSTF（米国予防サービスタスクフォース）との比較**

- 大腸がん: USPSTF は45歳からのスクリーニングを推奨（日本は40歳）
- 乳がん: USPSTF は40歳からの隔年マンモグラフィ推奨（2024年改定で引き下げ）
- 子宮頸がん: USPSTF は21歳から3年ごとの細胞診（日本は20歳から2年ごと）
- 肺がん: USPSTF はLDCTを50-80歳、20 pack-year以上の喫煙者に推奨（日本では対策型として未推奨）

**予防医療のエビデンスレベル**

| 介入 | エビデンスレベル | 推奨度 |
|------|----------------|--------|
| 便潜血による大腸がん検診 | I（RCT） | A |
| マンモグラフィ乳がん検診 | I（RCT） | A（40歳以上） |
| 子宮頸部細胞診 | II（観察研究） | A |
| 禁煙 | I（RCT） | A |
| 高血圧スクリーニング | I | A |
| 脂質スクリーニング（40歳以上） | I | A |
| 糖尿病スクリーニング（40歳以上/リスク因子あり） | I | B |
| 骨密度スクリーニング（65歳以上女性） | I | B |
| HCV抗体スクリーニング | I | B |
