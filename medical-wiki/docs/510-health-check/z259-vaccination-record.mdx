<h3 className="soap-a">評価</h3>

- **ワクチン名:** インフルエンザ / 肺炎球菌(ニューモバックス) / 肺炎球菌(プレベナー) / 帯状疱疹(シングリックス) / HPV(シルガード9) / COVID-19 / B型肝炎 / 破傷風トキソイド / MR / 水痘 / おたふく / その他
- **ロット番号:** ＿
- **接種部位:** 左上腕三角筋 / 右上腕三角筋 / 左大腿外側 / 右大腿外側
- **接種量:** 0.25mL / 0.5mL / 1.0mL
- **体温:** ＿℃（37.5℃未満を確認）
- **問診確認:** 副反応・アナフィラキシーの既往なし、体調良好、妊娠なし
- **同意:** 予診票に基づき問診を行い、接種の効果と副反応について十分説明の上、書面による同意を得て接種を実施した。
- **接種後観察:** 接種後15分（アナフィラキシー既往者は30分）院内で経過観察し、異常なきことを確認。

<h3 className="soap-p">方針・処方</h3>

- 次回接種予定があれば予約。接種証明書の発行。

#### 処方・アクション

**接種実施**

- <span className="med-id">[Rx-Vac-Influenza]</span> インフルエンザワクチン
- インフルエンザHAワクチン 0.5mL 皮下注射
- <span className="med-id">[Rx-Vac-PPSV23]</span> 肺炎球菌ワクチン（ニューモバックス）
- ニューモバックスNP 0.5mL 皮下注射
- <span className="med-id">[Rx-Vac-PCV13]</span> 肺炎球菌ワクチン（プレベナー）
- プレベナー13 0.5mL 筋肉注射
- <span className="med-id">[Rx-Vac-Shingrix]</span> 帯状疱疹ワクチン（シングリックス）
- シングリックス筋注用 0.5mL 筋肉注射 ；2回接種（2ヶ月間隔）
- <span className="med-id">[Rx-Vac-HPV9]</span> HPVワクチン（シルガード9）
- シルガード9 0.5mL 筋肉注射 ；3回接種（0-2-6ヶ月）
- <span className="med-id">[Rx-Vac-COVID]</span> COVID-19ワクチン
- COVID-19ワクチン 最新推奨に準拠
- <span className="med-id">[Rx-Vac-HepB]</span> B型肝炎ワクチン
- ビームゲン 0.5mL 皮下注射 *— 3回接種（0-1-6ヶ月）*
- <span className="med-id">[Rx-Vac-Tetanus]</span> 破傷風トキソイド
- 沈降破傷風トキソイド 0.5mL 皮下注射

**緊急時対応**

- <span className="med-id">[Rx-Emerg-Epi]</span> アドレナリン筋注（アナフィラキシー対応）
- アドレナリン0.3mg 大腿外側に筋注 ；接種前に必ず準備

#### 指導・計画

- **再診目安:** 次回接種スケジュールに応じて予約。
- 接種記録をお薬手帳・接種記録カードに記載。
- 接種後の副反応（発熱、局所腫脹等）について説明。重篤な副反応出現時は速やかに受診するよう指導。
- 接種証明書が必要な場合は発行する。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[アナフィラキシー準備]** ワクチン接種時はアドレナリン0.3mg筋注の準備を必ず行え。
>
> **[シングリックス]** 50歳以上に推奨。2回接種（2ヶ月間隔）。帯状疱疹予防効果90%以上。
>
> **[肺炎球菌]** 65歳以上にニューモバックス。PCV13→PPSV23の連続接種も検討（免疫不全者）。
