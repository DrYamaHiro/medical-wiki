<h3 className="soap-a">評価</h3>

- 健診で指摘された心電図異常の二次精査。
- **所見:** ST変化 / T波異常 / 不整脈 / QT延長 / 左室肥大 / 右脚ブロック / 左脚ブロック / WPW / Brugada型 / その他
- **精査内容:** 安静時12誘導心電図（再検）、心エコー、Holter心電図、運動負荷心電図（必要時）
- **判定:** 異常なし（経過観察）/ 要精査 / 要治療

<h3 className="soap-p">方針・処方</h3>

- 右脚ブロック単独は多くの場合良性だが、左脚ブロック・ST変化・Brugada型は循環器紹介。
- QTc 500ms以上は薬剤性の除外と循環器紹介。

#### 処方・アクション

**精査セット**

- <span className="med-id">[Exam-ECG-12lead]</span> 安静時12誘導心電図（再検）
- 健診心電図との比較読影
- <span className="med-id">[Exam-Echo-TTE]</span> 心エコー検査
- 心機能・壁運動・弁膜症・心室肥大の評価
- <span className="med-id">[Exam-ECG-Holter]</span> Holter心電図

- <span className="med-id">[Exam-ECG-ExTol]</span> 運動負荷心電図
- ST変化の再現性・虚血評価（必要時）

**循環器紹介**

- <span className="med-id">[Ref-Cardio-ECG]</span> 循環器専門医紹介
- 左脚ブロック、ST変化、Brugada型、QTc 500ms以上 → 循環器紹介

#### 指導・計画

- **再診目安:** 精査結果に応じて1-4週後。
- 右脚ブロック単独で心エコー正常であれば年1回の心電図フォローで可。
- QT延長を認めた場合は内服薬リストを確認し、被疑薬（抗精神病薬、マクロライド等）の中止を検討。
- Brugada型心電図を認めた場合は必ず循環器専門医へ紹介。家族歴（突然死）の聴取を行う。

## 📖 詳細解説

### 病態生理

**健診で検出される主要な心電図異常**

健診心電図は安静時12誘導心電図で行われ、有所見率は約30%に達する。多くは臨床的意義が乏しい軽微な所見であるが、中には致死性不整脈や器質的心疾患のサインが含まれる。

- **ST-T変化:** 心筋虚血、左室肥大に伴うストレイン型変化、電解質異常、薬剤性など多因子。健診では非特異的ST-T変化が最も多い
- **左室肥大（LVH）:** 高電位差（Sokolow-Lyon: SV1+RV5/V6 35mm以上、Cornell: RaVL+SV3 28mm以上（男性）/20mm以上（女性））。高血圧性心疾患、肥大型心筋症を示唆
- **心房細動（AF）:** 絶対性不整脈。RR間隔不整+P波消失+f波。脳梗塞リスク評価（CHADS2/CHA2DS2-VASc）が必要
- **WPW症候群:** デルタ波+PQ短縮（0.12秒未満）+QRS延長。副伝導路による房室回帰性頻拍（AVRT）のリスク。頻拍発作歴がなくても循環器コンサルトが望ましい
- **QT延長:** QTc（Bazett補正）440ms以上で延長、500ms以上で致死性不整脈（TdP）のリスクが有意に上昇。先天性（LQTS: Romano-Ward症候群等）と後天性（薬剤性、電解質異常）に分類
- **Brugada型心電図:** V1-V3でcoved型（タイプ1）またはsaddleback型（タイプ2/3）のST上昇。タイプ1は突然死リスクがあり循環器紹介必須

**脚ブロック**

- **完全右脚ブロック（CRBBB）:** QRS 0.12秒以上+V1でrSR'パターン。若年者では正常変異が多いが、ASD（心房中隔欠損症）や右心負荷の除外が必要
- **完全左脚ブロック（CLBBB）:** QRS 0.12秒以上+V5/V6でRR'パターン。器質的心疾患（虚血性心疾患、拡張型心筋症）の合併率が高く、心エコーが必須

### 診断基準・鑑別疾患

**心電図所見別の対応一覧**

| 心電図所見 | 臨床的意義 | 対応 |
|-----------|-----------|------|
| 非特異的ST-T変化 | 多くは良性 | 症状なければ経過観察。高血圧合併なら心エコー |
| 左室高電位 | LVH（高血圧、HCM） | 心エコーで壁厚・心機能評価 |
| 完全右脚ブロック | 多くは正常変異 | 心エコーでASD除外。異常なければ年1回フォロー |
| 完全左脚ブロック | 器質的心疾患を示唆 | 心エコー必須。循環器紹介 |
| 心房細動 | 脳梗塞リスク | CHADS2スコア評価。抗凝固療法の適応判断。循環器紹介 |
| 心房粗動 | 2:1伝導で心拍150/分 | 循環器紹介（アブレーション適応の評価） |
| WPW症候群 | AVRT/偽性心室頻拍 | 循環器紹介。頻拍発作歴を聴取 |
| QTc 440-499ms | 軽度延長 | 被疑薬確認、電解質（K, Mg, Ca）測定、経過観察 |
| QTc 500ms以上 | TdPリスク高い | 被疑薬中止、電解質補正、循環器紹介 |
| Brugada タイプ1 | 突然死リスク | 循環器紹介必須。家族歴（突然死）聴取 |
| Brugada タイプ2/3 | リスクは低い | 薬物負荷試験の適応を循環器と相談 |
| 1度房室ブロック | 多くは良性 | PQ 0.30秒以上なら循環器紹介検討 |
| 2度房室ブロック Wenckebach | 若年者・夜間は正常 | 症状ありなら循環器紹介 |
| 2度房室ブロック Mobitz II | ペースメーカー適応の可能性 | 循環器紹介 |
| 期外収縮（上室性・心室性） | 多くは良性 | 頻発・連発・多源性ならHolter心電図 |

**循環器紹介基準（健診心電図）**

以下のいずれかを認めた場合は循環器専門医へ紹介する:

- 完全左脚ブロック
- 心房細動・心房粗動（新規発見）
- Brugada型タイプ1心電図
- QTc 500ms以上
- Mobitz II型以上の房室ブロック
- 心室頻拍（3連発以上）
- ST低下 1mm以上（水平型・下降型）
- 異常Q波（幅0.04秒以上かつ深さR波の1/4以上）

### エビデンス・ガイドライン推奨

**不整脈薬物治療ガイドライン2020年改訂版（日本循環器学会）**

- 心房細動の脳梗塞予防: CHA2DS2-VAScスコア2点以上（男性）/3点以上（女性）でDOAC推奨
- 心房細動の初回検出でもCHADS2スコア1点以上であれば抗凝固療法を考慮
- WPW症候群: 無症候性であってもハイリスク群（デルタ波消失試験で持続する場合等）ではカテーテルアブレーションを考慮

**QT延長症候群（LQTS）に関する推奨**

- QTc 500ms以上の薬剤性QT延長: 被疑薬の即座の中止が最優先
- QT延長を引き起こす代表的薬剤: 抗精神病薬（ハロペリドール、クエチアピン）、マクロライド系（エリスロマイシン、クラリスロマイシン）、抗不整脈薬（ソタロール、アミオダロン）、フルコナゾール、メサドン
- 先天性LQTS: beta遮断薬が第一選択。LQT1/LQT2に有効

**Brugadaガイドライン（ESC 2022/日本循環器学会）**

- タイプ1（coved型）ST上昇: 自然発生的または薬物誘発性のいずれでも致死性不整脈リスクの評価が必要
- 失神歴・VF既往がある場合はICD適応
- 無症候性タイプ1: リスク層別化のため電気生理学的検査（EPS）を考慮

**健診心電図判定マニュアル（日本人間ドック学会）**

- A（異常なし）、B（軽度異常・経過観察）、C（要再検・生活改善）、D（要精密検査・要治療）、E（治療中）の5段階判定
- 完全右脚ブロック単独はB判定（経過観察）が一般的
- 左脚ブロック、心房細動、Brugadaタイプ1はD判定（要精密検査）
