## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **法的根拠:** 労働安全衛生規則第43条（雇入時の健康診断）
- **対象:** 常時使用する労働者を雇い入れる際に実施
- **必須項目（11項目）:** 既往歴・業務歴、自覚症状・他覚症状、身長・体重・BMI・腹囲、視力・聴力、胸部X線、血圧、尿検査（蛋白・糖）、血液検査（貧血、肝機能、脂質、血糖）、心電図

### 雇用時健診 vs 定期健診の比較表

| 項目 | 雇用時健診（安衛則43条） | 定期健診（安衛則44条） |
|---|---|---|
| **対象** | 雇入れ時（常時使用する労働者） | 常時使用する労働者（年1回） |
| **身長・体重・BMI** | 必須 | 必須（20歳以上で身長は省略可） |
| **腹囲** | 必須 | 必須（40歳未満の一部で省略可） |
| **視力** | 必須 | 必須 |
| **聴力** | 必須（1000Hz・4000Hz） | 必須（35歳・40歳以外はスクリーニング可） |
| **胸部X線** | 必須 | 必須（条件により省略可） |
| **血液検査（貧血）** | 必須 | 35歳・40歳以上は必須、他は省略可 |
| **血液検査（肝機能）** | 必須 | 35歳・40歳以上は必須、他は省略可 |
| **血液検査（脂質）** | 必須 | 35歳・40歳以上は必須、他は省略可 |
| **血液検査（血糖）** | 必須 | 35歳・40歳以上は必須、他は省略可 |
| **心電図** | 必須 | 35歳・40歳以上は必須、他は省略可 |
| **尿検査** | 必須 | 必須 |
| **省略の可否** | **一切省略不可** | 医師判断で年齢に応じ省略可 |
| **費用負担** | 事業者 | 事業者 |
| **結果保存** | 5年間 | 5年間 |

### 異常値判定基準（労働安全衛生法に基づく判定区分）

| 判定区分 | 意味 | 対応 |
|---|---|---|
| **A（異常なし）** | 全項目正常範囲内 | 次回定期健診まで経過観察 |
| **B（軽度異常）** | 正常範囲をわずかに逸脱 | 生活習慣改善の指導。次回定期健診でフォロー |
| **C（要経過観察）** | 生活習慣改善+経過観察が必要 | 6ヶ月-1年後の再検査を推奨 |
| **D1（要治療）** | 医療機関での治療が必要 | 速やかに受診勧奨。就業上の措置を検討 |
| **D2（要精密検査）** | 精密検査が必要 | 二次検査の受診勧奨 |
| **E（治療中）** | 既に治療中 | 主治医と連携し就業上の配慮を検討 |

- **就業上の措置が必要な場合:** 産業医（嘱託含む）の意見を聴取し、就業制限（残業制限、配置転換等）を事業者に意見具申

### エビデンス・ガイドライン推奨

- **実務上の注意:**
  - 3ヶ月以内の健診結果を提出可能（同等の項目がある場合）
  - 結果は5年間保存義務
  - 異常所見がある場合、医師の意見を聴取し就業上の措置を検討
- **費用負担:** 事業者負担が原則
