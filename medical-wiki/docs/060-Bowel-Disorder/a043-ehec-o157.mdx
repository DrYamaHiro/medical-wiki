<h3 className="soap-a">評価</h3>

- **診断根拠:** 激しい腹痛と水様便に続く、鮮血便（出血性大腸炎）。発熱は軽度なことが多い。
- **リスク:** 生肉（レバ刺し、ユッケ、加熱不十分なハンバーグ）摂取歴。
- **Red Flag:** 乏尿、浮腫、意識障害、顔色不良（HUSの兆候）。

<h3 className="soap-p">方針・処方</h3>

- **【原則紹介】:** HUS（溶血性尿毒症症候群）発症のリスクがあるため、入院管理可能な施設へ紹介。
- **【禁忌】:** 止痢薬（ロペミン等）は絶対禁忌。抗菌薬（特にニューキノロン）の使用は慎重に（HUS誘発説あり）。
- 当院では補液と整腸剤のみとし、重症化の兆候を厳重に監視する。

## 📖 詳細解説

### 病態生理

- **病原体**: 腸管出血性大腸菌（EHEC: O157:H7が最多、他にO26、O111等）。志賀毒素（Stx: ベロ毒素VT1/VT2）を産生
- **潜伏期間**: 3-8日。感染量は極めて少量（100個以下）
- **志賀毒素の機序**: 志賀毒素はABトキシン構造。Bサブユニットが標的細胞の糖脂質受容体（Gb3）に結合 → Aサブユニットが細胞内に侵入 → リボソーム28S rRNAのN-グリコシダーゼ活性でタンパク合成を阻害 → 血管内皮細胞のアポトーシス → 腎臓糸球体や脳の微小血管障害 → 血栓性微小血管障害（TMA）→ HUS
- **HUS発症率**: EHEC感染者の約5-10%にHUSが発症。小児（特に5歳未満）と高齢者でリスクが高い。VT2産生株でHUS発症率がより高い
- **病態**: EHEC定着 → 志賀毒素産生 → 血管内皮細胞傷害 → 出血性大腸炎。毒素が血中に入ると → HUS

### 診断基準・鑑別疾患

- **症状**: 水様便 → 血性下痢（鮮血〜粘血便: 「ほぼ血液のみ」の下痢が特徴的）、腹痛（激しい）、発熱は軽度（37-38度C程度）
- **HUS（溶血性尿毒症症候群）の診断三徴**: 発症5-13日後に出現
  - 1. 微小血管障害性溶血性貧血（MAHA）: 破砕赤血球出現、Hb低下、LDH上昇、間接ビリルビン上昇、ハプトグロビン低下
  - 2. 血小板減少: 10万/uL未満（消費性）
  - 3. 急性腎障害: 乏尿（尿量 0.5mL/kg/時未満）、BUN・Cr上昇
  - その他: 中枢神経症状（けいれん、意識障害）を約20-30%に合併。致死率は約1-5%
- **検査**: 便培養（ソルビトール非分解大腸菌を検出）、ベロ毒素検査（EIA法で迅速診断可）
- **鑑別**: 他の出血性腸炎、虚血性腸炎、炎症性腸疾患

### エビデンス・ガイドライン推奨

- **抗菌薬のpros/cons**:
  - Cons: 細菌の溶菌により毒素放出が増加しHUSリスクが上昇する可能性（特にキノロン系、ST合剤で報告あり）
  - Pros: 日本のガイドラインではホスホマイシン（FOM）2-3g/日は毒素産生を抑制する可能性があり、発症早期（水様便の段階）での投与が検討される。メタアナリシスでは抗菌薬とHUS発症の因果関係は確定的ではない
  - 結論: ホスホマイシンは比較的安全とされるが、エビデンスは限定的。専門医判断が望ましい
- **止瀉薬**: 禁忌（毒素排泄を遅延しHUSリスク上昇）
- **支持療法**: 十分な補液による脱水補正が基本（適切な補液がHUS予防に最も重要）
- **HUS発症時**: 入院管理。輸血（赤血球・血小板）、透析、血漿交換の検討（専門施設へ）
- **届出**: 三類感染症 → 直ちに保健所に届出（全数把握）。接触者調査が必要
