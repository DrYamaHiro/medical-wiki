<h3 className="soap-a">評価</h3>

- 診断根拠：パターン化した脱毛、軟毛化。
- 性別：男性 / 女性

<h3 className="soap-p">方針・処方</h3>

- 男性(AGA)：フィナステリドまたはデュタステリド（5α還元酵素阻害薬）。
- 女性(FAGA)：スピロノラクトン（抗男性ホルモン作用）。
- 女性への男性用薬（フィナステリド/デュタステリド）処方は絶対禁忌（胎児毒性）。

**AGA治療薬 (男性専用・自費)**

<span className="med-id">[Rx-Private-AGA-Fin] フィナステリド錠1mg 1回1錠 1日1回 28日分</span>
- **効能:** 5α還元酵素(II型)阻害。ヘアサイクルの正常化、抜け毛の抑制（進行遅延）。
<span className="med-id">[Rx-Private-AGA-Dut] デュタステリドカプセル0.5mg 1回1カプセル 1日1回 28日分</span>
- **効能:** 5α還元酵素(I型・II型)阻害。フィナステリドより強力な発毛効果・抜け毛抑制。

**FAGA治療薬 (女性用・自費)**

<span className="med-id">[Rx-Private-FAGA-Spi] スピロノラクトン(FAGA)</span>
- スピロノラクトン25mg 1回1錠 1日1回 28日分 *— 開始量。効果不十分時50-100mgに増量*
- **効能:** 抗アルドステロン作用・抗アンドロゲン作用により、抜け毛の原因となる男性ホルモンの働きを抑える。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[推奨頻度・期間]**
> - 服用頻度: 1日1回内服。最低6ヶ月の継続後に効果判定（写真比較・抜け毛変化）。3ヶ月未満での中止は初期脱落期と重なるため不適切。効果不十分の場合、12ヶ月まで継続を検討。
> - **効果判定:** AGA進行の「抑制」が主目的であり「元の髪が戻る」わけではない。
>
> **[副作用・安全性]**
> - **フィナステリド/デュタステリド:** 性機能障害（リビドー減退）、肝機能障害。投与開始前および開始後3-6ヶ月毎にAST/ALT測定を推奨。
> - **PSA:** 5α還元酵素阻害薬はPSAを約50%低下させる。PSA検査時は服用中であることを必ず申告させよ。50歳以上は処方前にPSA測定を推奨。
> - **スピロノラクトン:** 利尿作用による頻尿・血圧低下、高カリウム血症に注意。投与開始後1ヶ月、その後3-6ヶ月毎に血清K・Cr測定。ACE阻害薬・ARB併用時は高K血症リスク増大。
> - ⚠ 妊娠可能年齢の女性へのスピロノラクトン処方: 確実な避妊を確認の上で処方。妊娠中・妊娠の可能性がある場合は禁忌（男児外性器の女性化）。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **AGA（男性型脱毛症）:** テストステロン → 5α還元酵素 → DHT → 毛包のミニチュア化 → 軟毛化・脱毛
  - パターン: 前頭部（M字）・頭頂部から進行（Hamilton-Norwood分類）
  - 有病率: 日本人男性の約30%（20代で10%、50代で40%）
- **FAGA（女性男性型脱毛症）:** びまん性に頭頂部の菲薄化（Ludwig分類）、更年期以降に増加

### 診断基準・鑑別疾患

- **診断:** 特徴的な脱毛パターン + 家族歴 + 進行性の経過
- **鑑別:** 円形脱毛症（境界明瞭な脱毛斑）、休止期脱毛（全頭性、ストレス後3-6ヶ月）、甲状腺疾患、鉄欠乏、膠原病

### エビデンス・ガイドライン推奨

- **男性型および女性型脱毛症診療ガイドライン2017（日本皮膚科学会）:**
  - **男性AGA:**
    - フィナステリド（プロペシア）1mg/日: 5α還元酵素II型阻害薬（推奨度A）
    - デュタステリド（ザガーロ）0.5mg/日: I型+II型阻害薬（推奨度A）
    - ミノキシジル外用（5%）: 血管拡張による毛包への血流増加（推奨度A）
  - **女性FAGA:** ミノキシジル外用（1%）が推奨、フィナステリド/デュタステリドは女性には禁忌（妊娠中の男児への影響）
- **注意事項:** 内服薬は献血制限あり（フィナステリド1ヶ月、デュタステリド6ヶ月）、効果判定は6ヶ月以上の継続後
