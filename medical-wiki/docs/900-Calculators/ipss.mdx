# IPSS 計算ツール

国際前立腺症状スコア（IPSS）は、前立腺肥大症をはじめとする下部尿路症状（LUTS）の重症度を7問で評価するスコアリングツールです。QOLスコアによる生活の質への影響度も併せて評価します。
