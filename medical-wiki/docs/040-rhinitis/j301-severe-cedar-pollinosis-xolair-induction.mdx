<h3 className="soap-a">評価</h3>

- **診断根拠:** 既存治療（抗ヒスタミン薬+鼻噴霧ステロイド+抗ロイコトリエン薬）で効果不十分な重症季節性アレルギー性鼻炎。
- **適応基準:** 12歳以上、体重20-150kg、総IgE 30-1500 IU/mL、スギ特異的IgE陽性（クラス2以上）、既存治療1週間以上で効果不十分。
- **鑑別:** 血管運動性鼻炎、鼻茸合併の好酸球性副鼻腔炎（ゾレア適応外ではないが別病態）

<h3 className="soap-p">方針・処方</h3>

- 既存治療をスギ花粉飛散シーズン中に1週間以上使用し効果不十分であることを確認してから開始。
- ゾレア（オマリズマブ）皮下注を開始。
- 投与量・間隔は総IgE値と体重で決定（投与量換算表参照）。
- 投与後30分間の院内観察（アナフィラキシー対応準備）。
- 花粉飛散期（概ね2-4月）のみ投与。

## 📖 詳細解説

### 病態生理

- **IgE介在性アレルギー反応:** スギ花粉曝露 → 抗原提示細胞がTh2細胞を活性化 → IL-4/IL-13産生 → B細胞がIgE産生 → 肥満細胞表面のFcεRIにIgE結合（感作成立）
- **再曝露時:** スギ花粉が架橋結合 → 肥満細胞脱顆粒 → ヒスタミン・ロイコトリエン・PGD2放出 → くしゃみ・鼻汁・鼻閉
- **オマリズマブ（ゾレア）の作用機序:**
  - 遊離IgEのCε3ドメインに結合 → IgEとFcεRIの結合を阻害
  - 遊離IgE濃度が低下 → 肥満細胞・好塩基球表面のFcεRI発現が減少（ダウンレギュレーション）
  - 結果としてアレルゲン刺激に対する肥満細胞の反応性が著明に低下
- 効果発現: 投与後1-2週間で鼻症状スコアの有意な改善が認められる

### 診断基準・鑑別疾患

**ゾレア投与の適応基準（季節性アレルギー性鼻炎）**
- 12歳以上
- 体重20-150kg
- 投与開始前の血清中総IgE: 30-1500 IU/mL
- スギ花粉特異的IgE陽性（CAP-RAST クラス2以上）
- 既存治療（抗ヒスタミン薬+鼻噴霧用ステロイド を1週間以上使用）で効果不十分
- 鼻症状が「重症」または「最重症」（鼻アレルギー診療ガイドライン重症度分類）

**投与量の決定（体重・総IgE換算表）**
- 投与量は75-600mg/回、投与間隔は2週間または4週間
- 例: 体重60kg、総IgE 200 IU/mLの場合 → 300mg/4週毎
- 総IgEと体重の組み合わせで添付文書の換算表を参照（必須）
- 換算表の範囲外（総IgE 30未満または1500超）は適応外

**鑑別疾患**
- 血管運動性鼻炎（非アレルギー性）: IgE陰性、温度変化で誘発
- 好酸球性副鼻腔炎: 鼻茸を伴う、嗅覚障害が強い
- 薬剤性鼻炎（点鼻薬性鼻炎）: 市販血管収縮薬の長期連用
- 感染性鼻炎: 膿性鼻汁、発熱

### エビデンス・ガイドライン推奨

**有効性のエビデンス**
- **国内第III相試験（2019年承認根拠）:** オマリズマブ群は鼻症状スコア（くしゃみ・鼻汁・鼻閉の合計）がプラセボ群に比べ有意に改善（p=0.0001）
- 鼻症状スコアの改善率: 約25-30%の低減（既存治療との併用下）
- QOL（JRQLQ）スコアも有意に改善
- 効果発現は早く、投与後1-2週で効果を自覚する症例が多い

**花粉症用ゾレアと喘息用ゾレアの違い**
- **適応:** 花粉症用は「季節性アレルギー性鼻炎」、喘息用は「気管支喘息」
- **投与期間:** 花粉症用はスギ花粉飛散期のみ（概ね2-4月）。喘息用は通年
- **投与開始条件:** 花粉症用は既存治療1週間以上で効果不十分を確認後。喘息用はステップ4以上で効果不十分
- **用量設定:** 同一の換算表を使用するが、花粉症では投与回数が少なく総コストは喘息より低い

**コスト（薬価ベース）**
- ゾレア皮下注75mgシリンジ: 約14,812円
- ゾレア皮下注150mgシリンジ: 約29,147円
- 3割負担での月額自己負担: 約4,500-45,000円（投与量により大幅に異なる）
- 投与量が多い場合は高額療養費制度の利用を案内
- ※薬価は改定により変動するため最新の薬価を確認のこと

**安全性**
- 主な副作用: 注射部位反応（45%）、頭痛、倦怠感
- アナフィラキシー: 0.1-0.2%。初回投与後30分は院内観察必須
- 長期安全性: 喘息領域での20年以上の使用実績あり
