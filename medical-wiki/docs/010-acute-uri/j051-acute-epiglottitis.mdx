## 📖 詳細解説

:::danger 緊急疾患
急性喉頭蓋炎は**数時間以内に完全気道閉塞から窒息死に至りうる耳鼻咽喉科最大の緊急疾患**である。「咽頭痛」を主訴とする患者の中に潜む本疾患を見逃さないことが、プライマリケア医に求められる最重要スキルの一つである。
:::

### 病態生理

急性喉頭蓋炎は、喉頭蓋およびその周囲の声門上構造（披裂喉頭蓋ヒダ、披裂部、仮声帯）に生じる急性の蜂窩織炎・膿瘍である。喉頭蓋は喉頭入口部の「蓋」として機能するが、粘膜下組織が疎であるため炎症性浮腫が急速に進行し、気道内腔が狭窄・閉塞する。

**疫学の変遷（小児 vs 成人）**

- **小児:** かつてはインフルエンザ菌b型（Hib）による小児の急性喉頭蓋炎が代表的であった。しかし1990年代以降のHibワクチン定期接種化により、小児症例は劇的に減少した（発症率は約90%低下）。
- **成人:** 現在は**成人が主たる罹患者**である。成人では喉頭蓋膿瘍を形成することも多く、糖尿病・免疫不全が危険因子となる。年間発症率は10万人あたり約1〜3人と推定される。

**主な起因菌（成人）**

| 菌種 | 特徴 |
|---|---|
| **A群溶血性連鎖球菌（GAS）** | 成人で最多の一つ。急速進行型が多い |
| **インフルエンザ菌（H. influenzae）** | 型別不能株（NTHi）が成人でも検出される |
| **黄色ブドウ球菌（S. aureus）** | MRSA を含む。膿瘍形成例で多い |
| **肺炎球菌（S. pneumoniae）** | 高齢者・免疫不全で |
| **Klebsiella pneumoniae** | 糖尿病患者で報告あり |

血液培養の陽性率は約25%とされ、培養陰性例も多い。ウイルス（単純ヘルペス等）や真菌（免疫不全者）が原因となることもまれにある。

**病態進行の機序:**
感染 → 粘膜下浮腫 → 声門上狭窄 → 吸気性喘鳴 → 完全閉塞 → 窒息。この過程は**数時間〜半日**で進行しうる。患者は気道を最大限確保するため、自然に**sniffing position（前傾座位・頸部前屈・下顎突出）**をとる。これは典型的な"tripod position"として知られる。

### 診断基準・鑑別疾患

**臨床診断（4D signs + 2S signs）**

急性喉頭蓋炎に特徴的な症候群として以下が知られる:

- **Dysphagia（嚥下困難）** -- 最も高頻度の症状
- **Drooling（流涎）** -- 唾液を飲み込めない
- **Dysphonia（含み声 / hot potato voice）** -- 嗄声ではなく「もごもご声」
- **Dyspnea（呼吸困難）** -- 出現時は重症
- **Stridor（吸気性喘鳴）** -- 気道狭窄の直接徴候。出現時は気道径50%以下を示唆
- **Sore throat（咽頭痛）** -- 咽頭所見に比して痛みが強い（"sore throat out of proportion to pharyngeal findings"）

:::warning プライマリケア医のためのRed Flags
以下のいずれかを認めたら**急性喉頭蓋炎を疑い、直ちに高次医療機関へ搬送**せよ:
1. **咽頭所見が軽微なのに嚥下痛が著明**（"喉は赤くないのに飲めない"）
2. **流涎**（唾液を飲み込めず溢れ出す）
3. **含み声**（嗄声ではなく、口に物を含んだような声）
4. **吸気性喘鳴**（呼気性喘鳴との違いに注意）
5. **前傾座位を好む**（仰臥位を嫌がる・拒否する）
6. **急速な症状進行**（数時間単位で悪化）
7. **舌圧子での診察に強い抵抗**（咽頭反射で喉頭痙攣→窒息誘発リスク）
:::

**画像診断**

- **頸部側面X線:** 喉頭蓋の腫大による**thumbprint sign（母指サイン）**が特徴的。正常な喉頭蓋は薄い葉状（vallecular sign陽性）だが、炎症により丸く肥厚し母指様に見える。感度は約80%。
- **頸部CT（造影）:** 喉頭蓋・披裂部の浮腫、膿瘍形成の評価に有用。感度・特異度ともに高い。**ただし、CT撮影中（仰臥位）に急変するリスクがあるため、気道不安定な患者では撮影より気道確保を優先する。** CT室への移動は必ず気道管理可能な医師が同伴すべきである。
- **喉頭ファイバースコープ:** 確定診断のゴールドスタンダード。喉頭蓋の発赤・腫脹を直接確認できる。ただし施行時の喉頭痙攣に注意が必要。

**鑑別疾患**

| 疾患 | 鑑別ポイント |
|---|---|
| **扁桃周囲膿瘍** | 片側性腫脹、開口障害、口蓋垂偏位 |
| **急性喉頭炎（クループ）** | 犬吠様咳嗽が特徴。小児に多い。喉頭蓋炎では咳嗽は目立たない |
| **咽後膿瘍** | 頸部硬直、後咽頭壁膨隆 |
| **アナフィラキシー** | 暴露歴、蕁麻疹、低血圧 |
| **気道異物** | 突然発症、誤嚥エピソード |
| **喉頭癌・声門上癌** | 慢性経過、嗄声、体重減少 |
| **Ludwig's angina** | 口腔底の硬い腫脹、開口障害 |
| **血管性浮腫** | ACE阻害薬歴、遺伝性（C1-INH欠損） |

### エビデンス・ガイドライン推奨

**1. 気道管理（最優先）**

気道確保のタイミングと方法は重症度に応じて判断する:

| 重症度 | 状態 | 気道管理 |
|---|---|---|
| **軽症** | 嚥下痛のみ、気道症状なし | ICU/HCUでの厳重な経過観察（最低24〜48時間）。保存的管理可能 |
| **中等症** | 含み声、軽度喘鳴、流涎 | 麻酔科・耳鼻科スタンバイ下で経鼻挿管の準備。急変時は緊急気道確保 |
| **重症** | 著明な喘鳴、チアノーゼ、意識変容 | **直ちに気道確保**。経口挿管困難な場合は外科的気道確保（輪状甲状靱帯切開/気管切開） |

- **経鼻挿管**が成人の急性喉頭蓋炎における第一選択とされることが多い（声門の視認性が不良なため経口挿管は困難）。
- ビデオ喉頭鏡（McGRATH, AirWay Scope等）の使用が推奨される。
- **"cannot intubate, cannot oxygenate"（CICO）**の状況に備え、外科的気道確保の準備を常にしておく。
- 小児では歴史的に全例気道確保（手術室での吸入麻酔下経口挿管）が推奨されていたが、Hib vaccine後の軽症例では保存的管理も選択肢となりつつある。

**2. 抗菌薬治療**

**推奨レジメン（成人）:**

| 薬剤 | 用法・用量 | 備考 |
|---|---|---|
| **セフトリアキソン（CTRX）** | 2g IV q24h（または1g IV q12h） | 第一選択。GAS, H. influenzae, 肺炎球菌をカバー |
| **アンピシリン/スルバクタム（ABPC/SBT）** | 3g IV q6h | 代替薬。嫌気性菌カバーが必要な場合 |
| **バンコマイシン（VCM）追加** | 15〜20mg/kg IV q8〜12h（AUC/MIC 400-600を目標; TDMガイドライン2022参照） | MRSAリスク（膿瘍形成、過去のMRSA歴、重症例）がある場合 |

- 治療期間: 通常**7〜10日間**（IV → PO スイッチ含む）。
- 経口スイッチ: 臨床的改善後、オーグメンチン配合錠250RS 1回1錠 + AMPC 250mg 1回1錠 1日3回（オグサワ処方）などへ。

**3. ステロイド**

- **デキサメタゾン 0.5mg/kg IV（最大10mg）** またはメチルプレドニゾロン 1〜2mg/kg IVを初期投与し、以後デキサメタゾン 0.25mg/kg q6〜8h で24〜48時間継続。
- RCTによる強いエビデンスは限定的だが、観察研究およびエキスパートオピニオンにより、浮腫軽減・気道確保回避率の改善が報告されており、**広く使用が推奨されている**。
- Suzuki S et al. (J Laryngol Otol, 2021) のシステマティックレビューでは、ステロイド投与群で気管挿管率が有意に低かったと報告されている。

**4. アドレナリン吸入**

- ボスミン（0.1%アドレナリン）0.5mL + 生食2.5mL ネブライザー吸入。
- 粘膜浮腫の一時的軽減に有効だが、効果は一過性（リバウンドあり）。搬送までの時間稼ぎとして使用。

**5. プライマリケアセッティングでの初期対応**

1. **座位を保持**（絶対に仰臥位にしない）
2. **舌圧子は使用しない**（喉頭痙攣→窒息誘発）
3. **不要な処置で患者を刺激しない**（静脈確保も搬送後でよい場合あり）
4. SpO2モニタリング、酸素投与（ただし気道閉塞には無効）
5. **直ちに救急要請**（耳鼻咽喉科・麻酔科が常駐する施設へ）
6. 可能であればアドレナリン吸入、ステロイドIV
