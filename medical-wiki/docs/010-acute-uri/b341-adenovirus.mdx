## 📖 詳細解説

### 病態生理

**ウイルス学的特徴**

ヒトアデノウイルス（Human adenovirus; HAdV）はアデノウイルス科に属するエンベロープを持たない二本鎖DNAウイルスである。現在A〜Gの7種（species）、100以上の遺伝子型（genotype）に分類される。エンベロープがないため環境中で安定しており、アルコール消毒への抵抗性が高い点が臨床上重要である。

**血清型と臨床像の対応**

| 血清型（代表） | 臨床病型 | 特徴 |
|---|---|---|
| 3型, 4型, 7型 | **咽頭結膜熱（プール熱）** | 高熱（39〜40℃）、咽頭炎、結膜炎の3主徴。夏季に流行。7型は重症肺炎を起こしうる |
| 8型, 19型, 37型 | **流行性角結膜炎（EKC）** | 強い結膜充血、眼脂、耳前リンパ節腫脹。角膜混濁を残すことあり |
| 40型, 41型（Species F） | **胃腸炎** | 乳幼児の水様性下痢。ロタウイルスに次ぐ小児ウイルス性腸炎の原因 |
| 11型, 21型 | **出血性膀胱炎** | 血尿を主徴。学童期男児に多い。自然軽快する |
| 1型, 2型, 5型 | **上気道炎・扁桃炎** | 乳幼児期の発熱性上気道炎の主要な原因 |

**感染経路と疫学**

- 飛沫感染、接触感染、糞口感染で伝播する。
- 咽頭結膜熱は夏季（6〜9月）に流行のピークがあり、プールの水を介した集団感染から「プール熱」と呼ばれる。ただし、プール以外の日常的な接触でも感染する。
- 潜伏期間は5〜7日。症状消退後も咽頭から7〜14日間、便から数週間にわたりウイルスが排泄される。

### 診断基準・鑑別疾患

**臨床診断**

咽頭結膜熱の3主徴は**高熱（38.5℃以上、3〜7日間持続）**、**滲出性咽頭炎**、**結膜炎（片側から始まり両側へ進展）**である。3主徴が揃わない不全型も多く、発熱＋咽頭炎のみの症例が半数以上を占める。

**迅速抗原検査**

- 咽頭または結膜ぬぐい液を検体とするイムノクロマト法が保険適用で使用可能。
- 感度: 約50〜80%、特異度: 約90〜95%（検体採取の質に依存）。
- **偽陰性が少なくない**ため、臨床像が典型的であれば陰性でもアデノウイルス感染を否定できない。
- 咽頭結膜熱は**感染症法5類（定点報告）**の対象疾患であり、臨床診断のみでも届出可能。

**鑑別疾患**

| 鑑別疾患 | 鑑別のポイント |
|---|---|
| **A群溶血性レンサ球菌咽頭炎** | 咳・鼻汁がない、苺舌、結膜炎を伴わない。迅速検査で鑑別。Centor Criteria 3点以上で疑う |
| **EBウイルス感染症（伝染性単核球症）** | 後頸部リンパ節腫脹が目立つ、脾腫、肝機能異常、異型リンパ球増多。発熱が1〜2週間と長い |
| **インフルエンザ** | 冬季流行、全身症状（筋肉痛・関節痛）が強い。迅速検査で鑑別 |
| **川崎病** | 5日以上の発熱＋結膜充血は共通するが、眼脂を伴わない非滲出性充血、四肢末端の変化、BCG接種痕の発赤など多臓器の所見。乳幼児は特に注意 |
| **ヘルパンギーナ** | 口蓋弓の小水疱が特徴的。結膜炎は伴わない |

**川崎病との鑑別に関する注意**: 乳幼児で高熱＋結膜充血＋頸部リンパ節腫脹を認める場合、アデノウイルスと川崎病の鑑別は初期には困難なことがある。アデノウイルス迅速検査陰性かつ発熱が5日以上持続する場合は、川崎病を積極的に疑い心エコーを含めた精査を行う。

### エビデンス・ガイドライン推奨

**治療方針**

- **抗菌薬は不要**: アデノウイルスはウイルス感染症であり、抗菌薬は無効である。二次性細菌感染の明確なエビデンスがない限り、抗菌薬の投与は推奨されない。
- **対症療法が基本**: 解熱鎮痛薬（アセトアミノフェン）、十分な水分摂取、安静。小児では脱水に注意し、経口補水液を推奨する。
- **結膜炎合併時**: 細菌の混合感染予防として抗菌点眼薬（レボフロキサシン等）を使用することがある。ステロイド点眼は角膜上皮障害を遷延させる可能性があり、眼科専門医の判断なく使用しない。
- **重症例（7型肺炎等）**: 乳児や免疫不全患者では重症肺炎に至ることがある。入院管理、輸液、呼吸管理が必要となる。現時点で承認された抗ウイルス薬はないが、免疫不全患者にはcidofovirが海外で使用される場合がある（国内未承認）。

**感染対策**

- 標準予防策＋接触予防策。エンベロープがないため、アルコール消毒の効果は限定的であり、**次亜塩素酸ナトリウム**（0.02〜0.1%）や**流水と石鹸による手洗い**が推奨される。
- タオル・洗面器の共用を避ける。

**学校保健安全法における出席停止基準**

- 咽頭結膜熱は**学校保健安全法 第二種感染症**に指定されている。
- 出席停止期間: **主要症状が消退した後2日を経過するまで**。
- 流行性角結膜炎は**第三種感染症**に指定されており、**医師が感染のおそれがないと認めるまで**出席停止。
