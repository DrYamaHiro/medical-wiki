<h3 className="soap-a">評価</h3>

- **診断根拠:** 咽頭痛、扁桃白苔、苺舌、頸部リンパ節圧痛。迅速抗原検査陽性。咳は認めない。
- **鑑別:** ウイルス性扁桃炎、伝染性単核球症。

<h3 className="soap-p">方針・処方</h3>

- リウマチ熱予防・化膿性合併症予防・感染拡大防止のため、抗菌薬を確実に内服させる。

## 📖 詳細解説

### 病態生理

- 原因菌：A群β溶血性連鎖球菌（GAS, *Streptococcus pyogenes*）
- 咽頭炎の細菌性原因として最多（小児の15〜30%、成人の5〜15%）
- 飛沫感染・接触感染、潜伏期間2〜5日

**主要な病原性因子**
- Mタンパク：好中球の貪食に抵抗する最重要毒力因子（80種以上の血清型）
- 発赤毒素（SpeA/B/C）：猩紅熱の発疹を惹起するスーパー抗原
- ストレプトリジンO（SLO）：溶血毒素、ASO値は感染の指標

**非化膿性合併症**
- **急性リウマチ熱（ARF）**：咽頭炎後2〜4週。Mタンパクと心筋ミオシンの分子相同性（molecular mimicry）による自己免疫。抗菌薬治療により予防可能
- **溶連菌感染後糸球体腎炎（PSAGN）**：咽頭炎後1〜3週。免疫複合体の糸球体沈着。抗菌薬による予防効果は確立されていない

### 診断基準・鑑別疾患

**[Centor Criteria / McIsaac Score](../Calculators/centor)**

| 項目 | 点数 |
|------|------|
| 扁桃の白苔・滲出物 | +1 |
| 前頸部リンパ節の圧痛・腫脹 | +1 |
| 発熱 38℃以上 | +1 |
| 咳嗽がない | +1 |
| 年齢 3〜14歳 / 15〜44歳 / 45歳以上 | +1 / 0 / −1 |

| スコア | GAS陽性確率 | 対応 |
|--------|-----------|------|
| 0〜1点 | 1〜10% | 検査・抗菌薬不要 |
| 2〜3点 | 10〜35% | 迅速検査→陽性なら治療 |
| 4〜5点 | 50〜65% | 迅速検査（経験的治療も考慮可） |

**迅速抗原検査**：感度70〜90%、特異度95〜99%。成人は陰性なら培養不要、小児は培養バックアップ推奨

**鑑別疾患**
- ウイルス性咽頭炎（鼻汁・咳嗽・嗄声の合併はウイルス性示唆）
- 伝染性単核球症（EBV）：著明リンパ節腫脹、肝脾腫、AMPCで薬疹
- 急性喉頭蓋炎：吸気性喘鳴、嚥下困難、流涎 — 緊急疾患
- 扁桃周囲膿瘍：片側扁桃腫大、開口障害、口蓋垂偏位

### エビデンス・ガイドライン推奨

**第一選択：アモキシシリン（AMPC）**
- 添付文書標準用量は750mg/日（250mg x 3回）。JAID/JSCガイドラインは確実な除菌のため1500mg/日（500mg x 3回、または250mg x 2Cap x 3回）を推奨している。なお、GASのペニシリン耐性は報告されていないため、高用量推奨の理由は「耐性菌対策」ではなく、扁桃組織への十分な移行濃度確保による確実な除菌が目的である。当院では添付文書標準用量750mg/日を第一選択とし、高用量はオプションとして用意している
- 小児：AMPC 40〜50mg/kg/日 分2〜3、10日間
- GASはペニシリン系に対し耐性率0%（感受性100%維持）
- **10日間の投与期間はリウマチ熱予防に必須**（短縮は除菌率低下）

**ペニシリンアレルギー時**
- 非アナフィラキシー型：セファレキシン 500mg 1日2回、10日間（IDSA推奨。日本の添付文書では250mg 1日4回であり、処方部は添付文書準拠で記載）
- アナフィラキシー型：アジスロマイシン 500mg 1日1回 3日間、またはクラリスロマイシン 200mg 1日2回 10日間
- 日本のGASマクロライド耐性率は地域により15〜30%、感受性確認が望ましい

**治療後の除菌判定**
- 原則不要（無症候性保菌は治療対象外）
- 除菌確認が考慮される場合：リウマチ熱既往、施設内アウトブレイク、頻回再発例

**登校・登園基準**
- 抗菌薬開始後24時間経過し、全身状態良好であれば可
