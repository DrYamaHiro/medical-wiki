## 📖 詳細解説

### 病態生理

- **ウイルス性が約70〜80%**：ライノウイルス（最多）、コロナウイルス、アデノウイルス、インフルエンザ、パラインフルエンザ、EBウイルス、コクサッキーウイルス等
- **細菌性は約20〜30%**：GASが最多（成人の10〜15%、小児の15〜30%）。その他 C群・G群溶連菌、*Fusobacterium necrophorum*（若年成人）
- 飛沫・接触感染により咽頭粘膜に炎症反応（血管拡張・浮腫・好中球浸潤）

### 診断基準・鑑別疾患

**Centor / McIsaac Score によるGAS層別化**

| 項目 | 点数 |
|------|------|
| 発熱 38℃以上 | +1 |
| 咳嗽がない | +1 |
| 前頸部リンパ節の圧痛・腫脹 | +1 |
| 扁桃の腫脹または滲出物 | +1 |
| 年齢 3〜14歳 / 15〜44歳 / 45歳以上 | +1 / 0 / −1 |

- 0〜1点：検査・抗菌薬不要
- 2〜3点：迅速検査→陽性なら抗菌薬
- 4〜5点：迅速検査（経験的治療も考慮）

**Red Flags（緊急鑑別）**
- **急性喉頭蓋炎**：嚥下痛が所見に比し不釣り合いに強い、含み声、流涎、吸気性喘鳴 — 気道緊急
- **扁桃周囲膿瘍**：片側性咽頭痛、開口障害、口蓋垂偏位 — 穿刺排膿が必要
- **深頸部膿瘍**：頸部腫脹・可動制限、高熱遷延 — 造影CTで評価
- **Lemierre症候群**：若年成人の咽頭炎後に敗血症症状 — 造影CTで内頸静脈血栓確認

### エビデンス・ガイドライン推奨

**抗菌薬適正使用（厚労省「手引き」準拠）**
- 急性咽頭炎の大半はウイルス性であり抗菌薬は不要
- 抗菌薬はGAS感染が確認または強く疑われる場合に限定
- 迅速検査なしの経験的処方は推奨されない

**GAS陽性時の治療**
- AMPC 500mg 1日3回 10日間（第一選択）
- ペニシリンアレルギー：セファレキシン250mg 1日4回 10日間（添付文書準拠。IDSA推奨は500mg 1日2回）、またはマクロライド系

**対症療法（全例）**
- アセトアミノフェン 400〜500mg 頓用またはNSAIDs
- 含嗽（アズレン含嗽液）、十分な水分摂取・安静

**専門科紹介基準**
- Red flagsに該当する場合、経口摂取不能による脱水、48〜72時間で改善なし
