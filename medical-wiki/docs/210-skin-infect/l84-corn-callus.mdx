<h3 className="soap-a">評価</h3>

- **診断根拠:** 圧迫部位の角質肥厚。鶏眼は中心に芯あり（圧痛+）、胼胝は芯なし（びまん性肥厚）。
- **重症度:** 疼痛の程度、歩行障害の有無。
- **鑑別:** 足底疣贅（皮紋が消失し点状出血あり）との鑑別が重要。ミルメシア、悪性黒色腫も除外。

<h3 className="soap-p">方針・処方</h3>

- スピール膏貼付→2-3日後に軟化した角質をメスまたは鶏眼カッターで削る。
- 原因となる靴・歩行パターンの是正、インソール作成の検討。
- **再発予防:** 適切な靴の選択、除圧パッドの使用。

#### 処方・処置 (選択)

**角質軟化セット**

- <span className="med-id">[Rx-Skin-Sp-SAc]</span> スピール膏
- スピール膏Mサイズ 患部に貼付 2-3日毎に交換 *— 鶏眼・胼胝*
- <span className="med-id">[Rx-Skin-SAc-Ext]</span> サリチル酸ワセリン
- サリチル酸ワセリン10% 1日1-2回 患部塗布 *— 角質軟化*

#### 処置・アクション

**削り処置**

- 鶏眼・胼胝削り処置（メスまたは鶏眼カッター使用）
- **算定:** J057-3 鶏眼・胼胝処置 170点

#### 指導・計画

- **再診目安:** 2-4週後に削り処置の効果判定。再発例は定期的処置（4-8週毎）。

## 📖 詳細解説

### 病態生理

鶏眼（corn / clavus）および胼胝（callus / tylosis）は、皮膚への反復的な機械的圧迫・摩擦に対する防御反応として角質が過剰に増殖した状態である。

**角質増殖のメカニズム**

- 持続的な圧迫・摩擦により表皮基底層の角化細胞の分裂が亢進し、角質層が肥厚する
- 正常の角質層は約10-20層だが、鶏眼・胼胝では数十層以上に達する
- 不適合な靴、歩行異常（外反母趾、扁平足、開張足）、骨の突出部位に好発

**鶏眼と胼胝の違い**

| | 鶏眼（corn） | 胼胝（callus） |
|---|---|---|
| 芯（角質柱） | あり（円錐状に真皮方向へ楔入） | なし |
| 形状 | 小型（直径5-8mm程度）、円形 | びまん性、広範囲の角質肥厚 |
| 疼痛 | あり（芯が真皮の神経終末を圧迫） | 通常なし（圧迫感のみ） |
| 好発部位 | 足趾背側（第5趾）、趾間、足底中足骨頭部 | 足底全体、踵、中足骨頭部 |

**鶏眼の分類**

- **硬性鶏眼（hard corn）:** 足趾背側・足底の骨突出部に好発。最も一般的
- **軟性鶏眼（soft corn）:** 趾間（特に第4-5趾間）に発生。湿潤環境で白色軟化
- **粒状鶏眼（seed corn）:** 足底に多発する点状の小型鶏眼。荷重部以外にも出現

### 診断基準・鑑別疾患

**臨床診断のポイント**

- 圧迫部位に一致した限局性の角質肥厚
- 鶏眼: 中心に半透明の芯（角質柱）を認め、圧迫で鋭い疼痛
- 胼胝: 広範囲のびまん性角質肥厚、皮紋（指紋様の皮膚紋理）は保たれる

**ウイルス性疣贅（尋常性疣贅）との鑑別 -- 最重要**

| 所見 | 鶏眼・胼胝 | ウイルス性疣贅 |
|---|---|---|
| 皮紋 | 保たれている（角質を通して皮紋が連続） | 消失（皮紋が途絶する） |
| 点状出血 | なし | あり（削ると点状の黒色点・出血） |
| ダーモスコピー | 均一な角質肥厚 | 乳頭腫構造、点状血管（red/black dots） |
| 圧痛の方向 | 垂直圧迫で疼痛 | 側方からの把握痛が特徴的 |
| 数 | 通常単発、圧迫部位に一致 | 多発しうる、圧迫部位と無関係な分布も |

ダーモスコピーは疣贅との鑑別に有用であり、疣贅では「frog spawn pattern（カエルの卵状パターン）」と呼ばれる点状血管の集簇が認められる。

**その他の鑑別疾患**

- **ミルメシア:** HPV-1による足底の深在性疣贅。中心に向かう角質増殖、疼痛が強い
- **悪性黒色腫（足底型）:** 色素を伴う結節、ABCDEルールで評価
- **異物肉芽腫:** 外傷歴、異物迷入の既往

### エビデンス・ガイドライン推奨

**治療**

- **削り処置:** メスまたは鶏眼カッターで肥厚した角質を削除。鶏眼は芯を完全に除去することが重要。算定: J057-3 鶏眼・胼胝処置 170点
- **サリチル酸絆創膏（スピール膏）:** サリチル酸50%含有。患部に2-3日間貼付し、軟化した角質を削る。周囲の正常皮膚を保護するためワセリンを塗布してから貼付する
- **サリチル酸ワセリン（5-10%）:** スピール膏より緩徐な角質軟化作用。広範囲の胼胝に適する
- **再発予防が治療の本質:** 原因となる機械的刺激を除去しない限り再発は必至

**靴指導・除圧**

- 足長・足幅に合った靴の選択（つま先に1cm程度の余裕）
- 足底板（インソール）の作成による圧力分散
- 除圧パッド（ドーナツ型パッド）による局所の圧力軽減
- 外反母趾・開張足がある場合は整形外科的評価を検討

**糖尿病患者への注意**

- 糖尿病性神経障害がある場合、疼痛を感じにくく病変が進行しやすい
- 自己処置（カミソリ等での削り）は感染・壊疽のリスクがあるため禁止
- フットケア外来への紹介を積極的に検討する
