<h3 className="soap-a">評価</h3>

- **診断根拠:** HSV-2（70%）またはHSV-1（30%）による。Tzanck試験（巨細胞、核内封入体）、HSV抗原検査で確認。
- **重症度:** 初感染は重症（広範囲の水疱・びらん、発熱、鼠径リンパ節腫脹、排尿痛）。再発型は軽症で前駆症状（ピリピリ感）から小水疱。
- **鑑別:** 梅毒（硬性下疳: 無痛性潰瘍）、軟性下疳、ベーチェット病、固定薬疹、接触皮膚炎。

<h3 className="soap-p">方針・処方</h3>

- 初感染: バラシクロビル500mg 1日2回 5-10日間。重症例（歩行困難、尿閉）は入院しアシクロビル点滴を検討。
- 再発型（通常）: バラシクロビル500mg 1日2回 5日間。
- 再発型PIT（Patient Initiated Therapy）: ファムシクロビル1000mg 頓用2回（前駆症状出現時に1回目、12時間後に2回目）。
- 再発抑制療法（年6回以上再発）: バラシクロビル500mg 1日1回 長期継続（保険適用あり）。
- **パートナーへの説明:** 無症状でもウイルス排泄（shedding）あり。コンドーム使用を推奨。

- **再診目安:** 初感染は5-7日後に症状評価。再発抑制療法は1-3ヶ月毎に再発頻度を評価し継続の要否を判断。
- **パートナーへの説明:** 無症状でもウイルス排泄があること、コンドーム使用で感染リスクを低減できること（完全な予防は困難）を説明。
- **STIスクリーニング:** 他のSTI（梅毒、HIV、クラミジア、淋菌）の併存検査を推奨。

## 📖 詳細解説

### 病態生理

性器ヘルペスは単純ヘルペスウイルス（HSV）による性感染症である。原因ウイルスはHSV-2が約70%、HSV-1が約30%を占める。近年、オーラルセックスの普及によりHSV-1による性器ヘルペスの割合が増加傾向にある。

**感染・潜伏機序**

- HSVは皮膚・粘膜の微小な傷から侵入し、局所で増殖して水疱・びらんを形成する
- 初感染後、ウイルスは知覚神経を逆行性に上行し、仙骨神経節（S2-S4）に潜伏感染する
- ストレス、疲労、免疫低下、月経、紫外線曝露などを契機に再活性化し、神経を順行性に下降して皮膚病変を再発させる

**初感染と再発の臨床差**

| | 初感染 | 再発 |
|---|---|---|
| 潜伏期 | 2-12日（平均4日） | 前駆症状から数時間-1日 |
| 症状 | 広範囲の水疱・びらん、発熱、鼠径リンパ節腫脹、排尿痛 | 限局性の小水疱、軽度の不快感 |
| 持続期間 | 2-4週間 | 5-10日間 |
| 全身症状 | あり（発熱、倦怠感） | まれ |
| ウイルス排泄期間 | 約12日間 | 約4日間 |

**無症候性ウイルス排泄（Asymptomatic shedding）**

- 症状がなくてもウイルスが性器粘膜から排泄される現象
- HSV-2感染者の約10-20%の日数で無症候性排泄が起こる
- 性器ヘルペス感染の50-70%はパートナーの無症候性排泄時に生じるとされる
- 再発抑制療法（バラシクロビル500mg/日）により無症候性排泄を約50%減少させることが可能

### 診断基準・鑑別疾患

**臨床診断**

- 外陰部の集簇性小水疱、びらん、浅い潰瘍が典型的所見
- 初感染では両側性・広範囲、再発では片側性・限局性の傾向

**検査**

- **HSV抗原迅速検査:** 水疱底の擦過検体を用いる。感度80-90%。水疱期が最も検出率が高い
- **Tzanck試験:** 水疱底の擦過標本で巨細胞・核内封入体を確認。感度60-70%。HSVとVZVの鑑別は不可
- **PCR法:** 最も感度が高い（感度95%以上）。びらん・潰瘍期でも検出可能
- **血清抗体検査:** 型特異的IgG抗体（HSV-1, HSV-2）。既感染の確認に有用だが急性期診断には不適

**鑑別疾患**

| 疾患 | 特徴 |
|---|---|
| 梅毒（硬性下疳） | 無痛性の硬い潰瘍、単発が多い |
| 軟性下疳 | 有痛性潰瘍、辺縁不整、国内ではまれ |
| ベーチェット病 | 有痛性潰瘍が反復、口腔内アフタ合併 |
| 固定薬疹 | 薬剤投与後に同一部位に出現、円形紅斑 |
| 接触皮膚炎 | 外用薬・ラテックスなどの接触歴 |

### エビデンス・ガイドライン推奨

**治療レジメン（日本性感染症学会ガイドライン2020準拠）**

- **初感染:** バラシクロビル500mg 1日2回 5-10日間（重症例は10日間）
- **再発治療:** バラシクロビル500mg 1日2回 5日間
- **PIT療法（Patient Initiated Therapy）:** ファムシクロビル1000mg頓用 x 2回（前駆症状出現時に1回目、12時間後に2回目）。2019年より保険適用。患者自身が前駆症状を認識し早期に服用開始することで、再発の重症化・持続期間を短縮する
- **再発抑制療法:** バラシクロビル500mg 1日1回 長期継続。年6回以上再発する場合に保険適用。再発頻度を70-80%減少させ、無症候性排泄も約50%抑制する。QOL改善効果が大きい

**重症例・特殊状況**

- **入院適応:** 歩行困難、尿閉、髄膜炎合併 → アシクロビル5mg/kg 8時間毎 点滴静注 7-10日間
- **免疫不全者:** 重症化・遷延化しやすい。アシクロビル点滴を第一選択とし、治療期間の延長を考慮

**妊婦・新生児ヘルペス**

- **妊娠中の初感染:** 特に妊娠後期（分娩前6週間以内）の初感染では新生児ヘルペスのリスクが30-50%と高い
- **分娩時の活動性病変:** 帝王切開の適応。活動性病変がある経腟分娩での新生児感染率は約30-50%
- **新生児ヘルペス:** 全身型（播種性）、中枢神経型、皮膚眼口型の3病型。全身型の死亡率は30%と高い
- **再発抑制療法:** 妊娠36週以降、アシクロビル200mg 1日4回またはバラシクロビル500mg 1日2回の投与で分娩時の活動性病変を減少させる
