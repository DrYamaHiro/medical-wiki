## 📖 詳細解説

ネフローゼ症候群は高度蛋白尿・低アルブミン血症・浮腫を呈する症候群で、原因により一次性と二次性に分類される。

### 病態生理

- **定義（厚生労働省診断基準）:**
  - 蛋白尿: 3.5g/日以上（必須）
  - 低アルブミン血症: 血清Alb 3.0g/dL以下（必須）
  - 浮腫、脂質異常症は補助項目
- **病態:**
  - 糸球体基底膜の透過性亢進 → 大量蛋白尿
  - 低アルブミン血症 → 膠質浸透圧低下 → 浮腫
  - 肝臓での代償的蛋白合成亢進 → 脂質合成も亢進 → 高脂血症
  - 凝固因子の変動 → 血栓傾向（深部静脈血栓症、腎静脈血栓症）
- **一次性（原発性糸球体疾患）:**
  - 微小変化型（MCD）: 小児で最多、成人でも多い
  - 膜性腎症: 高齢者で最多、PLA2R抗体
  - 巣状分節性糸球体硬化症（FSGS）
- **二次性:** ループス腎炎（SLE）、糖尿病性腎症、アミロイドーシス

### 診断基準・鑑別疾患

- **検査:**
  - 随時尿蛋白/Cr比 3.5g/gCr以上
  - 血清アルブミン、総蛋白、脂質、腎機能（**[eGFR](../Calculators/egfr)**で評価）
  - 補体（C3, C4, CH50）、抗核抗体、抗PLA2R抗体
- **腎生検:** 原則として施行（病型診断・治療方針決定に必須）
- **鑑別:** 一次性 vs 二次性の鑑別が重要、悪性腫瘍の合併検索（膜性腎症の10-20%に合併）

### エビデンス・ガイドライン推奨

- **ネフローゼ症候群診療ガイドライン2020（日本腎臓学会）:**
  - **MCD:** プレドニゾロン 0.8-1.0mg/kg/日から開始、4週後に漸減 → 寛解率90%以上
  - **膜性腎症:** 支持療法で6ヶ月経過観察、改善なければ免疫抑制療法（リツキシマブが台頭。ただし日本では膜性腎症に対するリツキシマブは保険適用外（適応外使用））
  - **FSGS:** ステロイド + シクロスポリン
- **支持療法（全病型共通）:**
  - 塩分制限（6g/日未満）、利尿薬
  - RAS阻害薬（蛋白尿減少目的）
  - 抗凝固療法（Alb 2.0g/dL以下で血栓予防を考慮）
- **紹介:** ネフローゼ症候群が疑われた場合は腎臓専門医へ紹介
