# 糖尿病治療薬

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>スイニー（後発品なし）/ アナグリプチン（anagliptin）</strong></summary>

商品名: スイニー
カテゴリ: RX-09 糖尿病治療薬
剤型・規格: 錠 100mg
薬価: 33.00円
薬品区分: 普通薬


**薬理**

- DPP-4阻害薬
- ジペプチジルペプチダーゼ-4を阻害し、活性型インクレチン（GLP-1・GIP）の分解を抑制
- 血糖依存的にインスリン分泌を促進する
- 単独で低血糖リスクが低い
- 肝代謝・腎排泄、T1/2: 添付文書を参照


**適応**

- 2型糖尿病


**用法用量**

- 成人: 1回100mg 1日2回 朝夕に経口投与。効果不十分時は1回200mgまで増量可
- 小児: 適応なし
- 腎機能低下時: 添付文書を参照（腎排泄あり、重度では減量を考慮）
- 肝機能低下時: 慎重投与


**禁忌・注意**

- 禁忌: 1型糖尿病、糖尿病性ケトアシドーシス、重症感染症、手術前後、重篤な外傷
- 慎重投与: 腎機能障害、肝機能障害
- 相互作用:
  - SU薬・インスリン併用 → 低血糖リスク増大（SU薬の減量を検討）
- 授乳婦: 投与しないことが望ましい（動物実験で乳汁移行）
- 副作用:
  - 重大: 低血糖（他の血糖降下薬併用時）、腸閉塞、急性膵炎（稀）、類天疱瘡
  - 頻度高: 便秘、腹部膨満感


**処方のポイント**

- DPP-4阻害薬の中では1日2回投与（多くのDPP-4iは1日1回）
- LDL-C低下作用も報告されている（REASON試験）
- メトホルミンとの配合剤（メトアナ配合錠LD）が利用可能
- 比較的安価なDPP-4阻害薬


**CureStation テンプレートとの関連**

- 110-AP-01（2型糖尿病）: Rx-DM-DPP4i-Ana


**調剤薬局での採用状況**

- 採用: あり（スイニー錠100mg）
- 備考: なし


**採用がない場合の代替案**

- 同一成分別規格: 該当なし（100mgのみ）
- 同効代替薬: シタグリプチン錠、リナグリプチン錠、テネリグリプチン錠

<summary><strong>ジャヌビア（後発品なし）/ シタグリプチン（sitagliptin）</strong></summary>

商品名: ジャヌビア、グラクティブ
カテゴリ: RX-09 糖尿病治療薬
剤型・規格: 錠 25mg / 50mg
薬価: 44.00円（25mg）、82.10円（50mg）
薬品区分: 普通薬


**薬理**

- DPP-4阻害薬
- インクレチン（GLP-1、GIP）の分解を阻害し、血糖依存的にインスリン分泌を促進する
- 単独で低血糖リスクが低い
- 主に腎排泄（未変化体約80%）→ 腎機能低下時は減量が必要
- T1/2 約12時間


**適応**

- 2型糖尿病


**用法用量**

- 成人: 1回50mg 1日1回 経口投与
- 効果不十分時は100mgまで増量可
- 腎機能低下時: 中等度（CCr 30-50 / eGFR 30-50）: 25mg/日、重度（CCr &lt; 30 / eGFR &lt; 30）: 12.5mg/日
- 肝機能低下時: 通常用量で使用可
- 小児: 適応なし


**禁忌・注意**

- 禁忌: 1型糖尿病、糖尿病性ケトアシドーシス
- 慎重投与: 腎機能障害（減量が必要）
- 相互作用:
  - SU薬・インスリン併用 → 低血糖リスク増大
  - ジゴキシン → 血中濃度わずかに上昇（臨床的に問題になることは稀）
- 授乳婦: 投与しないことが望ましい（動物実験で乳汁移行）
- 副作用:
  - 重大: 低血糖（併用時）、急性膵炎、腸閉塞、類天疱瘡
  - 頻度高: 上気道感染、頭痛、消化器症状


**処方のポイント**

- 世界で最初に発売されたDPP-4阻害薬で使用実績が豊富
- 腎機能に応じた減量基準が明確で、CKD合併例でも使いやすい（ただし減量が必要）
- SGLT2阻害薬イプラグリフロジンとの配合剤（スージャヌ配合錠）が利用可能
- DPP-4阻害薬の中で最も処方数が多い（日本）


**CureStation テンプレートとの関連**

- 110-AP-01（2型糖尿病）: Rx-DM-DPP4i-Sita


**調剤薬局での採用状況**

- 採用: あり（ジャヌビア錠25mg / 50mg）
- 備考: 先発品のみ


**採用がない場合の代替案**

- 同効代替薬: リナグリプチン錠
