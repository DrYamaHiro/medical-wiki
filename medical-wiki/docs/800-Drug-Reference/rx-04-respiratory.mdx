# 🫁 呼吸器系

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>フルチカゾンプロピオン酸エステル吸入剤（fluticasone propionate inhaler）</strong></summary>

</details>


<details>
<summary><strong>商品名: フルタイドディスカス</strong></summary>

カテゴリ: RX-04 呼吸器系（吸入ステロイド・ICS単剤）
剤型・規格: ディスカス（DPI）100μg 60ブリスター / 200μg 60ブリスター（※50μg規格も存在するが調剤薬局では採用なし）
薬価: 950.00円（100μg 60ブリスター）/ 1,247.60円（200μg 60ブリスター）
薬品区分: 普通薬


**薬理**

- 吸入ステロイド薬（ICS）
- 気道の炎症を強力に抑制（好酸球浸潤、サイトカイン産生、粘液分泌を抑制）
- 全身バイオアベイラビリティが低い → 全身性副作用が少ない
- DPI（ドライパウダー吸入器）タイプ


**適応**

- 気管支喘息の長期管理（コントローラー）


**用法用量**

- 成人: 1回100-200μg 1日2回吸入。症状に応じて適宜増減（最大800μg/日）
- 小児: 1回50-100μg 1日2回吸入（添付文書を参照）
- 腎機能低下時: 調整不要（全身吸収は少ない）
- 高齢者: 通常量で使用可。吸入手技の確認が重要


**禁忌・注意**

- 禁忌: 本剤成分に過敏症の既往
- 注意: 急性喘息発作には無効（発作時はSABAを使用）
- 副作用:
  - 頻度高: 口腔カンジダ症、嗄声（吸入後のうがいで予防）
  - 重大: アナフィラキシー（極めて稀）


**処方のポイント**

- ICS単剤はGINA Step 1-2の軽症喘息に使用
- ステップアップ時はICS/LABA配合剤（アドエア、レルベア等）へ変更
- 吸入後の含嗽（うがい）を必ず指導 → 口腔カンジダ症・嗄声の予防
- ディスカスは吸入手技が比較的簡単（カウンター付き）


**CureStation テンプレートとの関連**

- 030-AP-01〜02（気管支喘息）


**調剤薬局での採用状況**

- 採用:
  - フルタイド100ディスカス 60ブリスター: 在庫1
  - フルタイド200ディスカス 60ブリスター: 在庫1
- 備考: 在庫数が少ない。処方前に在庫確認が望ましい


**採用がない場合の代替案**

- 同効代替薬: アニュイティ100μgエリプタ（フルチカゾンフランカルボン酸、在庫あり）。1日1回吸入で利便性が高い


</details>

<details>
<summary><strong>商品名: アドエアディスカス</strong></summary>

カテゴリ: RX-04 呼吸器系（ICS/LABA配合）
剤型・規格:
  - ディスカス 100（サルメテロール50μg/フルチカゾン100μg）60ブリスター
  - ディスカス 250（サルメテロール50μg/フルチカゾン250μg）28ブリスター / 60ブリスター
  - ディスカス 500（サルメテロール50μg/フルチカゾン500μg）60ブリスター
薬価: 3,111.10円（100/60）/ 1,865.80円（250/28）/ 3,625.30円（250/60）/ 3,952.10円（500/60）
薬品区分: 普通薬


**薬理**

- ICS（フルチカゾンプロピオン酸）+ LABA（サルメテロール）配合吸入剤
- フルチカゾン: 気道の炎症を抑制
- サルメテロール: 気管支平滑筋のβ2受容体を刺激し長時間（12時間以上）気管支を拡張
- ICSとLABAの相乗効果（ICSがβ2受容体発現を維持、LABAがGR核内移行を促進）


**適応**

- 気管支喘息
- COPD（250ディスカス60ブリスターのみ）


**用法用量**

- 成人: 1回1吸入 1日2回（朝・夕）
- 用量選択:
  - 100ディスカス: 低用量ICS相当
  - 250ディスカス: 中用量ICS相当（最も汎用）
  - 500ディスカス: 高用量ICS相当（重症例）
- 小児: 100ディスカスを使用（添付文書を参照）
- 腎機能低下時: 調整不要
- 高齢者: 通常量で使用可。吸入手技の確認が重要


**禁忌・注意**

- 禁忌: 本剤成分に過敏症の既往、有効な抗菌薬のない感染症
- 注意: 急性喘息発作には無効。発作時はSABAを使用
- 相互作用:
  - CYP3A4阻害薬（リトナビル等）→ フルチカゾン血中濃度上昇 → 副腎抑制リスク
  - β遮断薬 → サルメテロールの気管支拡張効果を減弱
- 副作用:
  - 頻度高: 口腔カンジダ症、嗄声（うがいで予防）
  - 重大: アナフィラキシー（稀）、心房細動（稀）


**処方のポイント**

- GINA Step 3-4の喘息管理の標準治療
- ディスカスは吸入手技が比較的簡単（DPI）
- 28ブリスター製剤は約2週間分、60ブリスターは約1ヶ月分
- SMART療法（維持+頓用）には使用不可（サルメテロールの効果発現が遅い → ホルモテロール含有製剤を使用）


**CureStation テンプレートとの関連**

- 030-AP-01〜02（気管支喘息）


**調剤薬局での採用状況**

- 採用:
  - アドエア100ディスカス 60ブリスター: 在庫1
  - アドエア250ディスカス 28ブリスター: 在庫1
  - アドエア250ディスカス 60ブリスター: 在庫1
  - アドエア500ディスカス 60ブリスター: 在庫1
- 備考: 各規格在庫1のみ。処方前に在庫確認が望ましい


**採用がない場合の代替案**

- 同効代替薬: レルベアエリプタ（在庫あり）。1日1回吸入でアドヒアランス向上。またはブデホル（後発、在庫あり）
