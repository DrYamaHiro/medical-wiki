<details>
<summary><strong>アレグラ（フェキソフェナジン塩酸塩錠「杏林」等）/ フェキソフェナジン塩酸塩（fexofenadine）</strong></summary>

商品名: アレグラ / 後発: フェキソフェナジン塩酸塩錠「杏林」他
カテゴリ: RX-03 アレルギー・免疫
剤型・規格:
  - 錠 30mg / 60mg
  - シロップ用（DS）5%（0.6g/包）
薬価: 10.40円（後発錠30mg・60mg）/ 29.10円（後発DS5%）/ 26.10円（先発アレグラ60mg）
薬品区分: 普通薬


**薬理**

- 第2世代抗ヒスタミン薬
- H1受容体を選択的に遮断し、アレルギー反応を抑制
- 脳内H1受容体占拠率が極めて低い → 眠気が少ない（自動車運転制限なし）
- ケミカルメディエーター遊離抑制作用も有する
- T1/2 約14時間
- 肝代謝はほぼなし（未変化体のまま主に糞便中排泄）→ CYP相互作用が少ない


**適応**

- アレルギー性鼻炎
- 蕁麻疹
- 皮膚疾患に伴うそう痒（湿疹・皮膚炎、アトピー性皮膚炎等）


**用法用量**

- 成人: 1回60mg 1日2回 投与
- 小児（7-11歳）: 1回30mg 1日2回
- 小児（12歳以上）: 成人量
- 小児（2-6歳）: DS使用。1回30mg 1日2回
- 腎機能低下時: 重度腎障害では1回60mg 1日1回に減量（添付文書を参照）
- 高齢者: 腎機能に応じて減量を考慮


**禁忌・注意**

- 禁忌: 本剤成分に過敏症の既往
- 相互作用:
  - エリスロマイシン → フェキソフェナジン血中濃度上昇（P-gp阻害）
  - 制酸薬（Al・Mg含有）→ フェキソフェナジン吸収低下（同時服用を避ける）
  - グレープフルーツジュース → OATP阻害による吸収低下
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 添付文書を参照
- 副作用:
  - 頻度高: 頭痛（稀）、眠気（プラセボと同等）
  - 重大: ショック・アナフィラキシー（極めて稀）、肝機能障害、無顆粒球症


**処方のポイント**

- 眠気が最も少ない抗ヒスタミン薬の一つ（ビラスチンと並ぶ）
- 運転制限なし → ドライバー、精密作業者に適する
- 効果が穏やかなため、重症例にはオロパタジンやレボセチリジンが適する場合あり
- 花粉症シーズン前からの予防的投与が有効
- OTC版（アレグラFX）との重複に注意
- DS製剤は小児への用量調整に有用


**CureStation テンプレートとの関連**

- 040-AP-01（花粉症）
- 040-AP-02（通年性アレルギー性鼻炎）


**調剤薬局での採用状況**

- 採用:


**採用がない場合の代替案**

- 同効代替薬: ビラスチン錠20mg。同様に眠気が少ない

<summary><strong>ザイザル（レボセチリジン塩酸塩錠「サワイ」等）/ レボセチリジン塩酸塩（levocetirizine）</strong></summary>

**適応**

- 小児（2歳以上7歳未満）: シロップ 1回2.5mL（1.25mg）1日2回（朝食後・就寝前）
- 小児（6ヶ月以上1歳未満）: シロップ 1回2.5mL（1.25mg）1日1回 就寝前（導入量）

- 相互作用: 臨床上問題となるものは少ない。腎排泄型のためCYP相互作用は少ない

  - 頻度高: 眠気（フェキソフェナジンより多いがオロパタジンより少ない）、口渇、倦怠感

- 効果と眠気のバランスが良い抗ヒスタミン薬

- 蕁麻疹には増量処方（5mg 1日2回、保険適応外）が有効な場合あり
- 小児用剤型（シロップ、DS）が充実 → 小児のアレルギー管理に有用
- 腎機能低下患者では減量が必要（腎排泄型）

<summary><strong>ポララミン / d-クロルフェニラミンマレイン酸塩（d-chlorpheniramine）</strong></summary>

商品名: ポララミン
カテゴリ: RX-03 アレルギー・免疫
剤型・規格: 錠 2mg
薬価: 5.90円
薬品区分: 普通薬


**薬理**

- 第一世代抗ヒスタミン薬
- H1受容体を拮抗しアレルギー反応を抑制
- 脳内H1受容体占拠率が高い → 強い眠気・鎮静作用
- 抗コリン作用あり → 鼻汁・くしゃみの抑制に寄与するが、口渇・排尿困難等の副作用
- T1/2 約12-43時間（添付文書参照、個人差が大きい）


**適応**

- 蕁麻疹
- アレルギー性鼻炎
- 皮膚疾患に伴う掻痒


**用法用量**

- 成人: 1回2mg 1日1-4回 投与
- 小児: 年齢に応じて減量（添付文書を参照）
- 腎機能低下時: 添付文書を参照
- 高齢者: 抗コリン作用による認知機能低下・せん妄のリスク。Beers criteriaで不適切薬に該当


**禁忌・注意**

- 禁忌: 本剤成分に過敏症、緑内障、前立腺肥大による排尿障害、低出生体重児・新生児
- 注意: 強い眠気 → 自動車運転禁止（添付文書に記載）
- 相互作用:
  - 中枢抑制薬、アルコール → 鎮静増強
  - 抗コリン薬 → 抗コリン作用増強（口渇、便秘、排尿困難）
  - MAO阻害薬 → 作用増強
- 妊婦: 治療上の有益性が危険性を上回る場合に投与
- 授乳婦: 有益性投与（乳汁移行の報告あり）
- 副作用:
  - 頻度高: 眠気（高頻度）、口渇、便秘、排尿困難
  - 重大: 痙攣（小児、過量投与時）


**処方のポイント**

- 第一世代のため原則として第二世代抗ヒスタミン薬を優先
- 主な使用場面:
  - 重症蕁麻疹のレスキュー（注射剤がない外来で経口追加）
  - 鎮静が必要な場面（掻痒による不眠時の就寝前投与）
  - 急性上気道炎の鼻漏（抗コリン作用で鼻汁を抑制）
- 高齢者への漫然とした投与は避ける（Beers criteria該当）
