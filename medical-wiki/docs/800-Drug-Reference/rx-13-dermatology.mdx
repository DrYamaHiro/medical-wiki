# 皮膚科

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>ベタメタゾン吉草酸エステル（betamethasone valerate）</strong></summary>

商品名: リンデロン-V軟膏/クリーム/ローション / 後発: ベタメタゾン吉草酸エステル軟膏「イワキ」他
カテゴリ: RX-13 皮膚科
剤型・規格: 軟膏 0.12% / クリーム 0.12% / ローション 0.12%（各5g/本, 10mL/瓶等）
薬価: 8.50円/g（後発軟膏）〜16.90円/g（先発）
薬品区分: 普通薬


**薬理**

- ストロング（strong/III群）クラスの副腎皮質ステロイド外用薬
- 炎症細胞浸潤の抑制、血管透過性亢進・浮腫の改善
- 全身吸収はほぼなし（広範囲・長期使用・密封法では注意）


**適応**

- 湿疹・皮膚炎群（接触皮膚炎、アトピー性皮膚炎等）
- 乾癬、痒疹群
- 虫さされ


**用法用量**

- 成人: 1日1〜数回、患部に適量を塗布
- 小児: 同様（ただし長期・広範囲の使用は避ける）
- 軟膏: 乾燥・苔癬化した病変に適する。クリーム: 浸出液を伴う病変に。ローション: 頭皮等の有毛部に


**禁忌・注意**

- 禁忌: 細菌・真菌・ウイルス性皮膚感染症（単独使用）、潰瘍面、本剤過敏症
- 注意: 顔面への長期使用は避ける（酒さ様皮膚炎）、眼周囲（緑内障リスク）
- 相互作用: 外用薬のため臨床上問題となるものはない
- 妊婦・授乳婦: 大量・長期使用を避ける。有益性が危険性を上回る場合に使用
- 副作用: 皮膚萎縮、毛細血管拡張、ステロイド座瘡、接触性皮膚炎（稀）


**処方のポイント**

- ステロイド外用薬ランク分類: ストロング（strong/III群）
- 皮膚科外用ステロイドの中で最も汎用されるランクの一つ
- 体幹・四肢の中等症湿疹に適する
- 顔面・陰部にはミディアム以下（ロコイド等）を選択
- VG（ゲンタマイシン配合）は感染を伴う場合に使用するが、長期連用は耐性菌の懸念あり


**CureStation テンプレートとの関連**

- 200-AP-01（アトピー性皮膚炎）
- 200-AP-02（接触皮膚炎）
- 200-AP-03（湿疹・皮膚炎群 一般）


**調剤薬局での採用状況**

- 採用: あり（後発 軟膏0.12%「イワキ」5g/本・調剤用500g、クリーム0.12%「YDJ」10g/本、ローション0.12%「イワキ」10mL/瓶）
- 備考: 先発リンデロン-V軟膏/ローションも在庫あり


**採用がない場合の代替案**

- 同一成分別剤形: 軟膏・クリーム・ローションいずれも在庫あり → 剤形変更で対応可
- 同効代替薬: プレドニゾロン吉草酸エステル軟膏（リドメックス/スピラゾン、ミディアム、在庫あり）。ランク差に注意

<summary><strong>ベタメタゾン吉草酸エステル・ゲンタマイシン配合（betamethasone/gentamicin）</strong></summary>

カテゴリ: RX-13 皮膚科

薬価: 27.70円/g
薬品区分: 普通薬


**薬理**

- ストロングクラスのステロイド（ベタメタゾン吉草酸エステル）＋アミノグリコシド系抗菌薬（ゲンタマイシン）の配合外用剤
- 抗炎症作用と抗菌作用を併せ持つ
- 全身吸収はほぼなし


**適応**

- 細菌感染を伴う又はそのおそれのある湿疹・皮膚炎群


**用法用量**

- 成人: 1日1〜数回、患部に適量を塗布
- 小児: 同様


**禁忌・注意**

- 禁忌: 真菌・ウイルス性皮膚感染症（単独使用）、鼓膜穿孔のある湿疹性外耳道炎、潰瘍面
- 注意: 長期連用でゲンタマイシン耐性菌の発現に注意
- 相互作用: 外用薬のため臨床上問題となるものはない
- 妊婦・授乳婦: 大量・長期使用を避ける。有益性が危険性を上回る場合に使用
- 副作用: 皮膚萎縮、毛細血管拡張、ステロイド座瘡


**処方のポイント**

- ステロイド外用薬ランク分類: ストロング（strong/III群）＋抗菌薬配合
- 二次感染の合併（又はリスク）がある湿疹に短期間使用
- 漫然と長期使用しない（感染が落ち着いたらステロイド単剤に切替）
- 耳鼻科領域ではネオメドロールEE軟膏が使い分けの候補


**CureStation テンプレートとの関連**

- 200-AP-02（接触皮膚炎）
- 200-AP-03（湿疹・皮膚炎群 一般）


**調剤薬局での採用状況**

- 採用: あり（先発 リンデロン-VG軟膏5g/本・調剤用200g、クリーム5g/本、ローション10mL/瓶）
- 備考: 後発品は非採用


**採用がない場合の代替案**

- 同一成分別剤形: 軟膏・クリーム・ローションいずれも在庫あり
- 同効代替薬: ベタメタゾン吉草酸エステル（リンデロン-V、ストロング、在庫あり）＋ゲンタシン軟膏の重ね塗りで代用可
