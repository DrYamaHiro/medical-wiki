# 💉 ワクチン・生物学的製剤

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::

該当薬剤なし（院内接種のため薬局経由ではない）
ワクチン製剤は院内接種のため調剤薬局経由ではない。
ワクチンは医療機関で直接管理・接種されるため、調剤薬局の採用品目に含まれない。
※参考: 舌下免疫療法薬（シダキュア、ミティキュア）は薬局で調剤されるが、
アレルゲン免疫療法薬として RX-04（呼吸器・アレルギー系）に分類。
