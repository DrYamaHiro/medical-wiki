# 💉 ワクチン・生物学的製剤

:::info CS Drug Reference
イオン薬局リーフシティ市川の採用薬を中心とした薬剤リファレンスです。各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・連携薬局での調剤情報を収録しています。
:::

該当薬剤なし（院内接種のため薬局経由ではない）
ソースデータ（イオン薬局 市川 採用薬リスト）にワクチン製剤の記載はなし。
ワクチンは医療機関で直接管理・接種されるため、連携薬局の採用品目に含まれない。
※参考: 舌下免疫療法薬（シダキュア、ミティキュア）は薬局で調剤されるが、
アレルゲン免疫療法薬として RX-04（呼吸器・アレルギー系）に分類。
