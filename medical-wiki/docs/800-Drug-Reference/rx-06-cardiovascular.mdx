# 循環器系

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>アジルバ（アジルサルタン錠「トーワ」等）/ アジルサルタン（azilsartan）</strong></summary>

商品名: アジルバ / 後発: アジルサルタン錠「トーワ」他
カテゴリ: RX-06 循環器系
剤型・規格: 錠 10mg / 20mg
薬価: 18.20円（後発錠10mg）、27.40円（後発錠20mg）、76.30円（先発アジルバ錠20mg）
薬品区分: 普通薬


**薬理**

- アンジオテンシンII受容体拮抗薬（ARB）
- AT1受容体を選択的に遮断し、強力かつ持続的な降圧効果を発揮
- ARBの中で最も高い受容体結合親和性（insurmountable antagonism）
- T1/2 約11〜13時間 → 1日1回投与
- 肝代謝（CYP2C9主体）、腎排泄は少ない


**適応**

- 高血圧症


**用法用量**

- 成人: 1回20mg 1日1回
- 効果不十分時は最大40mgまで増量可
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 慎重投与
- 高齢者: 低用量（10mg）から開始を考慮


**禁忌・注意**

- 禁忌: 妊婦、アリスキレン併用（糖尿病患者）
- 慎重投与: 両側腎動脈狭窄、高K血症、重篤な腎障害
- 相互作用:
  - ACE阻害薬との併用: 原則併用しない（腎機能悪化・高K血症リスク）
  - K保持性利尿薬・K補充剤 → 高K血症リスク
  - NSAIDs → 降圧効果減弱、腎機能悪化
  - リチウム → 血中濃度上昇
- 妊婦: 禁忌（胎児毒性）。授乳婦: 投与を避ける
- 副作用:
  - 頻度高: めまい、頭痛
  - 重大: 血管浮腫、腎機能障害、高K血症


**処方のポイント**

- ARBの中で最も強力な降圧効果が期待できる
- CCB（アムロジピン）との併用が最も一般的 → ジルムロ配合錠（ARB/CCB合剤）あり
- カンデサルタンと異なり心不全への適応はない


**CureStation テンプレートとの関連**

- 080-AP-01（高血圧）


**調剤薬局での採用状況**

- 採用: あり（後発 アジルサルタン錠10mg・20mg「トーワ」、先発 アジルバ錠20mg）
- 備考: なし


**採用がない場合の代替案**

- 同効代替薬: テルミサルタン、カンデサルタン、オルメサルタン
- 配合剤: ジルムロ配合錠LD/HD（アジルサルタン+アムロジピン）


</details>

<summary><strong>ミカルディス（テルミサルタン錠「サワイ」等）/ テルミサルタン（telmisartan）</strong></summary>

商品名: ミカルディス / 後発: テルミサルタン錠「サワイ」他
カテゴリ: RX-06 循環器系
剤型・規格: 錠 20mg / 40mg
薬価: 10.40円（後発錠20mg / 40mg）
薬品区分: 普通薬


**薬理**

- アンジオテンシンII受容体拮抗薬（ARB）
- AT1受容体を選択的に遮断し降圧
- T1/2 約24時間と長い → 安定した24時間降圧効果
- 肝代謝（グルクロン酸抱合主体）。CYP系の関与が少ない
- 腎排泄はほぼなし → 腎機能低下時でも用量調整不要
- PPARγ部分作動作用 → インスリン感受性改善の可能性


**適応**

- 高血圧症


**用法用量**

- 成人: 1回40mg 1日1回
- 1日20mgから開始し最大80mgまで増量可
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 慎重投与（肝胆道排泄が主のため）


**禁忌・注意**

- 禁忌: 妊婦、アリスキレン併用（糖尿病患者）、胆汁の生成・排泄に重篤な障害
- 授乳婦: 投与を避けることが望ましい（乳汁移行の可能性）
- 相互作用:
  - ACE阻害薬との併用: 原則併用しない（腎機能悪化・高K血症リスク）
  - その他: アジルサルタンと同様（K保持性利尿薬、NSAIDs、リチウム）
- 副作用: めまい、血管浮腫（稀）、高K血症


**処方のポイント**

- T1/2が最も長いARB → 服薬タイミングのずれに対する許容度が高い
- 腎排泄がほぼない → 腎機能低下例に使いやすい
- PPARγ作用により糖・脂質代謝への好影響が期待される
- 後発品が非常に安価（10.40円）


**CureStation テンプレートとの関連**

- 080-AP-01（高血圧）


**調剤薬局での採用状況**

- 採用: あり（後発 テルミサルタン錠20mg・40mg「サワイ」）
- 備考: なし


**採用がない場合の代替案**

- 同効代替薬: アジルサルタン、カンデサルタン


</details>

<summary><strong>ノルバスク（アムロジピンOD錠「日医工」等）/ アムロジピン（amlodipine）</strong></summary>

商品名: ノルバスク, アムロジン / 後発: アムロジピンOD錠「日医工」他
カテゴリ: RX-06 循環器系
剤型・規格: OD錠 2.5mg / 5mg / 10mg
薬価: 10.40円（後発OD錠5mg）
薬品区分: 劇薬


**薬理**

- ジヒドロピリジン系Ca拮抗薬（長時間作用型）
- 血管平滑筋のL型Caチャネルを選択的に遮断し、末梢血管を拡張させて降圧
- 心筋抑制作用が弱く、反射性頻脈を起こしにくい
- T1/2 約36時間（長い）→ 1日1回投与で24時間安定した降圧効果
- 肝代謝（CYP3A4）、腎排泄は少ない → 腎機能低下時の用量調整不要


**適応**

- 高血圧症
- 狭心症
- 適応外（参考）: レイノー現象


**用法用量**

- 成人: 1回2.5〜5mg 1日1回。効果不十分時は10mgまで増量可
- 小児（6歳以上）: 1回2.5mg 1日1回
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 低用量（2.5mg）から開始。肝硬変ではAUC上昇
- 高齢者: 2.5mgから開始


**禁忌・注意**

- 禁忌: 妊婦（動物で催奇形性）、ジヒドロピリジン系過敏症
- 慎重投与: 重篤な肝障害、大動脈弁狭窄症
- 相互作用:
  - CYP3A4阻害薬（イトラコナゾール、クラリスロマイシン等）→ 血中濃度上昇
  - グレープフルーツジュース → 血中濃度上昇（患者指導で言及）
  - シンバスタチン → 併用でスタチン血中濃度上昇（横紋筋融解症リスク）
- 副作用:
  - 頻度高: 浮腫（足首、用量依存性、5-10%）、ほてり、頭痛、めまい
  - 重大: 肝機能障害・黄疸（稀）、血小板減少（稀）
  - 歯肉肥厚（長期投与、1-3%）→ 口腔ケア指導


**処方のポイント**

- ARBとの併用が最も一般的な降圧レジメン（ARB/CCB合剤も多数あり）
- 浮腫が問題の場合 → ARBとの併用で軽減、またはシルニジピンへ変更を検討
