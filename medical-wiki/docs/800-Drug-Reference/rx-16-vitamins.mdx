# ビタミン・栄養素

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>シナール（シーピー配合顆粒「東和」）/ アスコルビン酸・パントテン酸Ca配合錠/顆粒（ascorbic acid/calcium pantothenate）</strong></summary>

商品名: シナール配合錠 / 後発: シーピー配合顆粒「東和」
カテゴリ: RX-16 ビタミン・栄養素
剤型・規格: 錠剤 / 顆粒 1g/包
薬価: 6.40〜6.50円
薬品区分: 普通薬


**薬理**

- ビタミンC（アスコルビン酸）＋ビタミンB5（パントテン酸Ca）配合剤
- アスコルビン酸: コラーゲン合成促進・抗酸化・メラニン生成抑制
- パントテン酸Ca: 補酵素CoAの構成成分、糖・脂質・蛋白質代謝に関与


**適応**

- ビタミンC欠乏症の予防・治療
- 炎症後色素沈着
- 適応外: しみ・そばかすの改善


**用法用量**

- 成人: 錠剤: 1回1〜3錠、1日1〜3回経口投与
- 顆粒: 1回1包（1g）、1日1〜3回経口投与


**禁忌・注意**

- 禁忌: 特になし
- 副作用: 稀に胃部不快感、下痢（大量投与時）


**処方のポイント**

- 色素沈着やしみに対して広く処方される
- トラネキサム酸との併用が美白目的で一般的
- ビタミンCは大量投与しても余剰分は尿中排泄される


**CureStation テンプレートとの関連**

- 該当テンプレートなし（しみ・色素沈着の補助療法として使用）


**調剤薬局での採用状況**

- 採用: あり（先発 シナール配合錠 + 後発 シーピー配合顆粒「東和」1g/包）
- 備考: なし


**採用がない場合の代替案**

- 汎用品のため在庫切れの可能性は低い。薬局での取り寄せ: 翌日入荷可能


</details>

<summary><strong>フェロミア（クエン酸第一鉄Na錠「サワイ」）/ クエン酸第一鉄ナトリウム錠（sodium ferrous citrate）</strong></summary>
