# 消化器系

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>タケプロン（ランソプラゾールOD錠「トーワ」等）/ ランソプラゾール（lansoprazole）</strong></summary>

商品名: タケプロン / 後発: ランソプラゾールOD錠「トーワ」他
カテゴリ: RX-05 消化器系
剤型・規格: OD錠 15mg / 30mg
薬価: 添付文書を参照（後発品）
薬品区分: 普通薬


**薬理**

- プロトンポンプ阻害薬（PPI）
- 胃壁細胞のH+/K+-ATPaseを不可逆的に阻害し、強力に胃酸分泌を抑制
- T1/2 約1.5時間だが、酵素への結合は不可逆的のため酸分泌抑制は24時間以上持続
- 肝代謝（CYP2C19, CYP3A4）。CYP2C19の遺伝子多型により代謝速度に個人差あり


**適応**

- 胃潰瘍、十二指腸潰瘍
- 逆流性食道炎
- Zollinger-Ellison症候群
- NSAIDs潰瘍の治療・予防（低用量アスピリン投与時の潰瘍再発抑制、NSAIDs投与時の潰瘍再発抑制）
- H. pylori除菌補助（アモキシシリン+クラリスロマイシンと3剤併用）


**用法用量**

- 胃潰瘍: 1回30mg 1日1回（8週間まで）
- 十二指腸潰瘍: 1回30mg 1日1回（6週間まで）
- 逆流性食道炎: 1回30mg 1日1回（治療）、1回15mg 1日1回（維持療法）
- 低用量アスピリン投与時の潰瘍予防: 1回15mg 1日1回
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 慎重投与（代謝遅延の可能性）


**禁忌・注意**

- 禁忌: アタザナビル・リルピビリン投与中（吸収低下）、本剤過敏症
- 慎重投与: 肝障害
- 相互作用:
  - CYP2C19基質（ジアゼパム、フェニトイン等）の代謝を阻害 → 血中濃度上昇
  - クロピドグレルの活性化を阻害する可能性（臨床的意義は議論あり）
  - タクロリムス → 血中濃度上昇
- 妊婦: 有益性投与。授乳婦: 動物で乳汁移行あり
- 副作用:
  - 頻度高: 下痢、腹部膨満感
  - 重大: 汎血球減少、間質性肺炎、肝機能障害（稀）
  - 長期投与: 骨折リスク上昇、低Mg血症、Clostridioides difficile感染症リスク、腎障害（間質性腎炎）、ビタミンB12吸収低下


**処方のポイント**

- タケルダ配合錠（アスピリン100mg+ランソプラゾール15mg）として低用量アスピリンとの配合剤あり
- PPIの中ではCYP2C19多型の影響を比較的受けやすい
- 長期投与時は漫然投与を避け、適宜PPIの必要性を再評価
- OD錠は経管投与にも対応


**CureStation テンプレートとの関連**

- 050-AP-05（GERD）
- 050-AP-09（胃十二指腸潰瘍）
- 050-AP-10（H.pylori）


**調剤薬局での採用状況**

- 採用: なし（単剤としては非採用
- 備考: ランソプラゾール単剤が必要な場合はエソメプラゾールまたはラベプラゾールで代替


**採用がない場合の代替案**

- 同効代替薬: エソメプラゾールカプセル、ラベプラゾールNa錠
- 配合剤: タケルダ配合錠（アスピリン併用患者に限る）


</details>

<summary><strong>ネキシウム（エソメプラゾールカプセル「サワイ」等）/ エソメプラゾール（esomeprazole）</strong></summary>

商品名: ネキシウム / 後発: エソメプラゾールカプセル「サワイ」「トーワ」他
カテゴリ: RX-05 消化器系
剤型・規格: カプセル 10mg / 20mg
薬価: 21.70円（後発カプセル10mg）、37.80円（後発カプセル20mg）
薬品区分: 普通薬


**薬理**

- プロトンポンプ阻害薬（PPI）
- オメプラゾールのS-エナンチオマー。安定したバイオアベイラビリティ
- 胃壁細胞のH+/K+-ATPaseを不可逆的に阻害し、強力に胃酸分泌を抑制
- 肝代謝（CYP2C19, CYP3A4）。R体と比べCYP2C19多型の影響を受けにくい


**適応**

- 胃潰瘍、十二指腸潰瘍
- 逆流性食道炎（治療・維持療法）
- NSAIDs潰瘍の予防（再発抑制）
- H. pylori除菌補助


**用法用量**

- 逆流性食道炎治療: 1回20mg 1日1回（8週間まで）
- 逆流性食道炎維持療法: 1回10〜20mg 1日1回
- NSAIDs潰瘍予防: 1回20mg 1日1回
- H. pylori除菌: 1回20mg 1日2回（7日間、抗菌薬と併用）
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 重度肝障害では20mg/日を超えない


**禁忌・注意**

- 禁忌: アタザナビル・リルピビリン投与中、本剤過敏症
- 相互作用:
  - クロピドグレルの活性化を阻害する可能性（ランソプラゾールと同様）
  - ジアゼパム、フェニトイン等のCYP2C19基質 → 血中濃度上昇
- 妊婦: 有益性投与。授乳婦: 乳汁移行あり
- 副作用:
  - 頻度高: 下痢、頭痛
  - 重大: アナフィラキシー、汎血球減少（稀）
  - 長期投与: 骨折リスク上昇、低Mg血症、Clostridioides difficile感染症リスク、腎障害、ビタミンB12吸収低下


**処方のポイント**

- CYP2C19多型の影響がランソプラゾールより少なく、安定した効果が期待できる
- 10mgカプセルは維持療法に適した低用量
- PPIの第一選択として使いやすい


**CureStation テンプレートとの関連**

- 050-AP-05（GERD）
- 050-AP-09（胃十二指腸潰瘍）


**調剤薬局での採用状況**

- 採用: あり（後発 エソメプラゾールカプセル10mg「サワイ」、20mg「トーワ」）
- 備考: なし


**採用がない場合の代替案**

- 同効代替薬: ラベプラゾールNa錠10mg、ボノプラザン（P-CAB）

<details>
<summary><strong>パリエット（ラベプラゾールNa錠「トーワ」）/ ラベプラゾール（rabeprazole）</strong></summary>

商品名: パリエット / 後発: ラベプラゾールNa錠「トーワ」他
カテゴリ: RX-05 消化器系
剤型・規格: 錠 10mg（※20mg規格も存在するが調剤薬局では採用なし。逆流性食道炎で20mg/日が必要な場合は10mg×2錠で対応）
薬価: 24.00円（後発錠10mg）、35.80円（先発パリエット錠10mg）
薬品区分: 普通薬


**薬理**

- プロトンポンプ阻害薬（PPI）
- H+/K+-ATPaseを不可逆的に阻害し胃酸分泌を抑制
- PPIの中で最もpKaが高く（約5.0）、活性化が速い → 速やかな酸分泌抑制効果
- 肝代謝（CYP2C19の関与が他のPPIより小さく、CYP2C19多型の影響を受けにくい）
- 非酵素的代謝経路（チオエーテル化）も有する


**適応**

- 胃潰瘍、十二指腸潰瘍
- 逆流性食道炎
- Zollinger-Ellison症候群
- NSAIDs潰瘍
- H. pylori除菌補助


**用法用量**

- 胃潰瘍: 1回10mg 1日1回（8週間まで）
- 十二指腸潰瘍: 1回10mg 1日1回（6週間まで）
- 逆流性食道炎: 1回10〜20mg 1日1回
- H. pylori除菌: 1回10mg 1日2回（7日間）
- 腎機能低下時: 用量調整不要


**禁忌・注意**

- 禁忌: アタザナビル・リルピビリン投与中、本剤過敏症
- 相互作用: CYP2C19への影響が他のPPIより小さい → クロピドグレルとの併用時に選択しやすい
- 妊婦: 有益性投与
- 副作用:
  - 頻度高: 下痢、肝機能障害（稀）
  - 長期投与: 骨折リスク上昇、低Mg血症、Clostridioides difficile感染症リスク、腎障害、ビタミンB12吸収低下


**処方のポイント**

- CYP2C19多型の影響を最も受けにくいPPI
- クロピドグレル併用時のPPI選択としてラベプラゾールが好まれることがある


**CureStation テンプレートとの関連**

- 050-AP-05（GERD）
- 050-AP-09（胃十二指腸潰瘍）


**調剤薬局での採用状況**

- 採用: あり（先発 パリエット錠10mg、後発 ラベプラゾールNa錠10mg「トーワ」）
- 備考: なし


**採用がない場合の代替案**

- 同効代替薬: エソメプラゾールカプセル、ボノプラザン

<details>
<summary><strong>タケキャブ / ボノプラザン（vonoprazan）</strong></summary>

商品名: タケキャブ
カテゴリ: RX-05 消化器系
剤型・規格: 錠 10mg / 20mg
薬価: 94.30円（10mg）、141.00円（20mg）
薬品区分: 普通薬


**薬理**

- カリウムイオン競合型アシッドブロッカー（P-CAB）
- 壁細胞のH+,K+-ATPaseをK+と競合的に阻害
- PPIと異なり酸による活性化が不要 → 投与初日から強力かつ速やかな酸分泌抑制
- PPIと異なり可逆的阻害だが、解離が遅いため持続的な効果
- 肝代謝（CYP3A4主体）。CYP2C19多型の影響をほとんど受けない
- T1/2 約7.7時間


**適応**

- 逆流性食道炎（治療・維持療法）
- 胃潰瘍、十二指腸潰瘍
- H. pylori除菌補助（ボノサップパックとして3剤パック製剤あり）
- NSAIDs潰瘍
- 低用量アスピリン投与時の潰瘍予防


**用法用量**

- 逆流性食道炎治療: 1回20mg 1日1回（4週間まで。重症は8週間）
- 逆流性食道炎維持療法: 1回10mg 1日1回
- 胃潰瘍: 1回20mg 1日1回
- H. pylori除菌: 1回20mg 1日2回（7日間、抗菌薬と併用）
- 低用量アスピリン投与時: 1回10mg 1日1回
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 慎重投与


**禁忌・注意**

- 禁忌: アタザナビル・リルピビリン投与中、本剤過敏症
- 相互作用:
  - CYP3A4阻害薬（クラリスロマイシン等）→ 血中濃度上昇の可能性
  - pH上昇により吸収が低下する薬剤（イトラコナゾール等）
- 妊婦: 有益性投与
- 副作用:
  - 頻度高: 下痢、便秘
  - 重大: 肝機能障害（稀）
  - 高ガストリン血症（胃酸抑制が強力なため）
  - 長期投与: 胃底腺ポリープ、骨折リスク、Clostridioides difficile感染症リスク


**処方のポイント**

- PPIで効果不十分な逆流性食道炎に有効（初日からの強力な酸分泌抑制）
- H. pylori除菌成功率がPPIベースの除菌より高い（P-CABベースの除菌率90%以上）
- 除菌療法に便利
- 薬価がPPIより高いため、維持療法ではコスト面も考慮
- CYP2C19多型の影響を受けない → 遺伝子型に関わらず安定した効果


**CureStation テンプレートとの関連**

- 050-AP-05（GERD）
- 050-AP-10（H.pylori）


**調剤薬局での採用状況**

- 採用: あり（タケキャブ錠10mg、20mg）


**採用がない場合の代替案**

- 同効代替薬: エソメプラゾール、ラベプラゾール。ただしP-CABの酸分泌抑制力には劣る


</details>

- 他の下剤との併用も可能


**CureStation テンプレートとの関連**

**調剤薬局での採用状況**
