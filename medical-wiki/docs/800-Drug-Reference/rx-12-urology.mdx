# 泌尿器・腎臓

:::info CS Drug Reference
各薬剤の薬理・適応・用法用量・禁忌・処方のポイント・調剤薬局での採用状況を収録しています。
:::


<details>
<summary><strong>ハルナール（タムスロシン塩酸塩OD錠「サワイ」等）/ タムスロシン（tamsulosin）</strong></summary>

商品名: ハルナール / 後発: タムスロシン塩酸塩OD錠「サワイ」
カテゴリ: RX-12 泌尿器・腎臓（α1遮断薬）
剤型・規格: OD錠 0.1mg / 0.2mg
薬価: 18.50円（後発OD錠0.2mg）, 25.30円（先発D錠0.2mg）
薬品区分: 劇薬


**薬理**

- 選択的α1A受容体遮断薬
- 前立腺・尿道平滑筋のα1A受容体を選択的に遮断し、尿道内圧を低下させて排尿障害を改善
- α1A選択性が高く、血管平滑筋のα1B受容体への影響が少ない → 起立性低血圧が比較的少ない
- 肝代謝（CYP3A4, CYP2D6）
- T1/2 添付文書を参照（OD錠で持続的な薬効）


**適応**

- 前立腺肥大症に伴う排尿障害


**用法用量**

- 成人: 1回0.2mgを1日1回 食後に経口投与
- 小児: 適応なし
- 腎機能低下時: 軽度-中等度では用量調整不要。重度腎障害では添付文書を参照
- 肝機能低下時: 重篤な肝障害では慎重投与（血中濃度上昇の可能性）
- 高齢者: 通常量で開始可


**禁忌・注意**

- 禁忌: 本剤成分に過敏症
- 慎重投与: 起立性低血圧のある患者、重篤な肝障害
- 相互作用:
  - 他のα遮断薬（降圧薬として使用）→ 過度の血圧低下
  - PDE5阻害薬（シルデナフィル等）→ 降圧作用の増強
  - CYP3A4阻害薬 → 血中濃度上昇の可能性
- 妊婦・授乳婦: 該当なし（男性への投与）
- 副作用:
  - 頻度高: めまい・立ちくらみ、射精障害（逆行性射精）、鼻閉
  - 重大: 起立性低血圧、失神（稀）、肝機能障害
  - 眼科関連: 術中虹彩緊張低下症候群（IFIS）→ 白内障手術前に眼科医に服用歴を申告


**処方のポイント**

- 前立腺肥大症に伴う排尿障害の第一選択薬（α1遮断薬の中で最も使用実績が豊富）
- シロドシンに比べ起立性低血圧が少ないが、射精障害はいずれも起こりうる
- 白内障手術予定がある場合は事前に休薬を検討（眼科医と相談）
- OD錠は嚥下困難な高齢者に有用
- 効果発現は比較的速い（数日〜1週間で排尿症状の改善）
- デュタステリドとの併用（α遮断薬+5ARI）は大きな前立腺肥大に有効


**CureStation テンプレートとの関連**

- 260-AP-01（BPH）


**調剤薬局での採用状況**

- 採用: あり（後発 タムスロシン塩酸塩OD錠0.2mg「サワイ」、先発 ハルナールD錠0.2mg）
- 備考: なし


**採用がない場合の代替案**

- 同一成分: 後発・先発いずれも在庫あり
- 同効代替薬: シロドシン（在庫あり）。α1A選択性がより高いが射精障害がやや多い

<summary><strong>ユリーフ（シロドシンOD錠「サワイ」等）/ シロドシン（silodosin）</strong></summary>

商品名: ユリーフ / 後発: シロドシンOD錠「サワイ」, シロドシン錠「ニプロ」
カテゴリ: RX-12 泌尿器・腎臓（α1遮断薬）
剤型・規格: OD錠 4mg, 錠 4mg
薬価: 10.40円（後発OD錠4mg）, 10.40円（後発錠4mg）
薬品区分: 劇薬


**薬理**

- 選択的α1A受容体遮断薬（タムスロシンよりもα1A選択性が高い）
- 前立腺・尿道平滑筋のα1A受容体を高選択的に遮断し排尿障害を改善
- 血管平滑筋への影響がさらに少ない
- 肝代謝（CYP3A4, UGT2B7）
- T1/2 添付文書を参照


**適応**

- 前立腺肥大症に伴う排尿障害


**用法用量**

- 成人: 1回4mgを1日2回、朝夕食後に経口投与
- 小児: 適応なし
- 腎機能低下時: 重度腎障害（CLcr&lt;30）では慎重投与。血中濃度上昇の可能性
- 肝機能低下時: 重篤な肝機能障害は禁忌
- 高齢者: 通常量で開始可


**禁忌・注意**

- 禁忌: 本剤成分に過敏症、重篤な肝機能障害
- 慎重投与: 起立性低血圧、肝障害
- 相互作用:
  - CYP3A4阻害薬 → 血中濃度上昇
  - 他のα遮断薬 → 過度の血圧低下
  - PDE5阻害薬 → 降圧作用の増強
- 妊婦・授乳婦: 該当なし（男性への投与）
- 副作用:
  - 頻度高: 射精障害（逆行性射精、20-30%と高頻度 → タムスロシンより多い）、口渇、鼻閉
  - 重大: 肝機能障害、起立性低血圧
  - 術中虹彩緊張低下症候群（IFIS）→ 白内障手術前に申告


**処方のポイント**

- α1A選択性がα遮断薬中最も高く、排尿障害改善効果が強い
- 射精障害が高頻度（20-30%）→ 性活動を重視する患者にはタムスロシンを優先
- 1日2回投与が必要（タムスロシンは1日1回）→ アドヒアランス面でやや不利
- OD錠は嚥下困難な高齢者に有用
- 白内障手術前のIFISリスクはタムスロシンと同様に注意


**CureStation テンプレートとの関連**

- 260-AP-01（BPH）


**調剤薬局での採用状況**

- 採用: あり（後発 シロドシンOD錠4mg「サワイ」、後発 シロドシン錠4mg「ニプロ」）
- 備考: なし


**採用がない場合の代替案**

- 同効代替薬: タムスロシン（在庫あり）。射精障害がやや少ない

<summary><strong>フリバス（後発品なし）/ ナフトピジル（naftopidil）</strong></summary>

商品名: フリバス
カテゴリ: RX-12 泌尿器・腎臓（α1遮断薬）
剤型・規格: 錠 25mg / 50mg / 75mg, OD錠
薬価: 添付文書を参照
薬品区分: 普通薬


**薬理**

- 膀胱三角部・膀胱頸部のα1D受容体を遮断し、蓄尿症状（頻尿、尿意切迫感）の改善に寄与
- タムスロシン・シロドシンのα1A選択性とは異なるサブタイプ選択性
- 肝代謝（CYP3A4, CYP2C9）
- T1/2 添付文書を参照


**適応**

- 前立腺肥大症に伴う排尿障害

- 成人: 1日25mgから開始、1-2週後に50-75mgへ増量。1日1回 食後に経口投与
- 小児: 適応なし
- 腎機能低下時: 添付文書を参照
- 肝機能低下時: 慎重投与
- 高齢者: 低用量から開始


**禁忌・注意**

- 禁忌: 本剤成分に過敏症
- 慎重投与: 起立性低血圧、肝障害
- 相互作用:
  - 降圧薬 → 降圧作用の増強
  - PDE5阻害薬 → 血圧低下リスク
- 妊婦・授乳婦: 該当なし（男性への投与）
- 副作用:
  - 頻度高: めまい、立ちくらみ、胃腸障害
  - 重大: 起立性低血圧、肝機能障害（稀）
  - 射精障害はタムスロシン・シロドシンより少ない


**処方のポイント**

- 蓄尿症状（頻尿・尿意切迫感）が主訴の場合に選択されることがある
- 射精障害がα1A遮断薬より少ない → 性活動を重視する患者に有利
- 排尿症状（尿勢低下等）への効果はタムスロシン・シロドシンにやや劣るとの報告
- 降圧作用がやや強い → 高血圧合併例には一石二鳥、低血圧例には注意


**CureStation テンプレートとの関連**

- 260-AP-01（BPH）


**調剤薬局での採用状況**

- 採用: なし
- 備考: 取り寄せ対応


**採用がない場合の代替案**

- 同効代替薬: タムスロシン（在庫あり）、シロドシン（在庫あり）。排尿症状にはこれらが第一選択

<summary><strong>アボルブ（デュタステリドカプセル「日医工」等）/ デュタステリド（dutasteride）</strong></summary>

商品名: アボルブ / 後発: デュタステリドカプセル「日医工」
カテゴリ: RX-12 泌尿器・腎臓（5α還元酵素阻害薬 / 5ARI）
剤型・規格: カプセル 0.5mg
薬価: 22.90円（後発0.5mg AV）
薬品区分: 劇薬


**薬理**

- 5α還元酵素阻害薬（Ⅰ型・Ⅱ型のデュアル阻害）
- テストステロンからジヒドロテストステロン（DHT）への変換を阻害
- 前立腺を縮小させ、排尿障害を改善
- フィナステリド（Ⅱ型のみ阻害）よりDHT抑制が強力
- T1/2 約3-5週間（非常に長い）→ 効果持続が長いが中止後も長期間影響が残る
- 肝代謝（CYP3A4）


**適応**

- 前立腺肥大症


**用法用量**

- 成人: 1回0.5mgを1日1回経口投与
- 食事の影響: 食事に関係なく投与可
- 小児: 禁忌
- 腎機能低下時: 用量調整不要
- 肝機能低下時: 重篤な肝機能障害は禁忌。軽度-中等度では慎重投与
- 高齢者: 用量調整不要


**禁忌・注意**

- 禁忌: 女性（特に妊婦・妊娠している可能性のある女性 → カプセルに触れることも禁忌。皮膚からDHTが吸収され男性胎児の外性器異常を起こす可能性）、小児、重篤な肝機能障害
- 慎重投与: 肝機能障害
- 相互作用:
  - CYP3A4阻害薬 → 血中濃度上昇の可能性（臨床的に問題になることは稀）
- 副作用:
  - 頻度高: 性機能障害（リビドー低下、勃起不全、射精障害）、乳房障害（女性化乳房、乳房圧痛）
  - 重大: 肝機能障害
  - PSA値を約50%低下させる → 前立腺癌スクリーニング時にPSA値を2倍して評価する必要がある


**処方のポイント**

- 前立腺体積が30mL以上の大きな前立腺肥大に特に有効
- 効果発現に3-6ヶ月かかる → 患者に説明し早期の中止を防ぐ
- α遮断薬との併用（タムスロシン+デュタステリド）が大きな前立腺肥大の標準治療
- PSA低下作用に注意: 前立腺癌スクリーニング時はPSA値を2倍にして解釈
- T1/2が非常に長い → 中止後も6ヶ月間は効果・副作用が持続する可能性
- 女性・小児が触れないよう患者指導（カプセルが破損した場合の皮膚吸収リスク）
- 献血制限: 投与中止後6ヶ月間は献血不可


**CureStation テンプレートとの関連**

- 260-AP-01（BPH）


**調剤薬局での採用状況**

- 採用: あり（後発 デュタステリドカプセル0.5mgAV「日医工」）
- 備考: 先発アボルブは非採用


**採用がない場合の代替案**

- 同効代替薬: フィナステリド（在庫確認が必要）。Ⅱ型のみ阻害でDHT抑制がやや弱い
- 取り寄せ: 翌日入荷可能

<summary><strong>ザルティア（後発品なし）/ タダラフィル（tadalafil）</strong></summary>

商品名: ザルティア（前立腺肥大症用）
カテゴリ: RX-12 泌尿器・腎臓（PDE5阻害薬）
剤型・規格: 錠 2.5mg / 5mg
薬価: 添付文書を参照
薬品区分: 劇薬


**薬理**

- ホスホジエステラーゼ5（PDE5）阻害薬
- PDE5を阻害しcGMP分解を抑制 → 前立腺・尿道・膀胱頸部の平滑筋弛緩
- 前立腺・膀胱の血流改善効果も関与
- T1/2 約17.5時間（長い）→ 1日1回投与で24時間効果持続
- 肝代謝（CYP3A4）


**適応**

- 前立腺肥大症に伴う排尿障害（ザルティア）
- ※EDに対するシアリスとは製剤名・適応が異なる


**用法用量**

- 成人: 1回2.5mgを1日1回から開始。1-2週後に5mgへ増量。1日1回経口投与
- 腎機能低下時: CLcr&lt;30では2.5mgから開始し慎重に
- 肝機能低下時: 軽度-中等度では慎重投与。重度では使用回避
- 高齢者: 通常量で開始可


**禁忌・注意**

- 禁忌: 硝酸剤またはNO供与剤投与中（致死的低血圧のリスク）、可溶性グアニル酸シクラーゼ（sGC）刺激剤投与中、重度の肝障害
- 最重要注意: 硝酸剤との併用禁忌 → 狭心症患者の確認が必須
- 慎重投与: 重度の腎障害（CLcr&lt;30で投与経験が限られる → 2.5mgから開始し慎重に）、陰茎の構造的欠損、出血性疾患、活動性消化性潰瘍
- 相互作用:
  - 硝酸剤（ニトログリセリン、硝酸イソソルビド等）→ 併用禁忌（重篤な低血圧）
  - α遮断薬 → 降圧作用の増強（起立性低血圧に注意）
  - CYP3A4阻害薬（ケトコナゾール等）→ 血中濃度上昇
  - CYP3A4誘導薬 → 効果減弱
- 副作用:
  - 頻度高: 頭痛、ほてり、消化不良、背部痛
  - 重大: 低血圧（硝酸剤併用時）、視力障害（非動脈炎性前部虚血性視神経症: NAION、稀）、持続勃起症（稀）


**処方のポイント**

- α遮断薬との異なるメカニズムで排尿障害を改善 → 併用で相加的効果
- 硝酸剤併用禁忌の確認が処方前に必須（狭心症の既往・ニトロ製剤の使用有無）
- α遮断薬との併用は可能だが、起立性低血圧に注意（特に開始時）
- 勃起不全（ED）の改善効果も期待できる（前立腺肥大症+ED合併例に一石二鳥）
- シアリス（ED適応）とザルティア（BPH適応）は同一成分だが適応・薬価が異なる


**CureStation テンプレートとの関連**

- 260-AP-01（BPH）


**調剤薬局での採用状況**

- 採用: なし
- 備考: 取り寄せ対応


**採用がない場合の代替案**

- 同効代替薬: タムスロシン（在庫あり）、シロドシン（在庫あり）。作用機序が異なるため厳密な代替ではない
- 取り寄せ: 翌日入荷可能

<details>
<summary><strong>ベタニス（後発品なし）/ ミラベグロン（mirabegron）</strong></summary>

商品名: ベタニス
カテゴリ: RX-12 泌尿器・腎臓（OAB治療薬 / β3作動薬）
剤型・規格: 錠 25mg / 50mg
薬価: 添付文書を参照
薬品区分: 普通薬


**薬理**

- 選択的β3アドレナリン受容体作動薬
- 膀胱平滑筋のβ3受容体を刺激し膀胱弛緩作用を示す
- 蓄尿期に膀胱の異常収縮を抑制し、膀胱容量を増大
- 抗コリン作用がない → 口渇・便秘・認知機能低下が少ない
- 肝代謝（CYP3A4, CYP2D6）
- T1/2 約50時間


**適応**

- 過活動膀胱における尿意切迫感、頻尿および切迫性尿失禁


**用法用量**

- 成人: 1回25mgを1日1回から開始、効果不十分時は50mgに増量。経口投与（食事に関係なく投与可）
- 腎機能低下時: 重度腎障害（CLcr 15-29）では25mg。CLcr&lt;15では使用経験なし
- 肝機能低下時: 中等度（Child-Pugh B）では25mg。重度では使用回避
- 高齢者: 通常量で開始可


**禁忌・注意**

- 禁忌: 重篤な心疾患、重篤な肝障害
- 妊婦: 有益性が危険性を上回る場合にのみ投与（動物試験で胎児への影響報告あり）
- 慎重投与: QT延長、高血圧、肝障害、腎障害、尿閉
- 相互作用:
  - CYP2D6基質（フレカイニド、プロパフェノン等）→ 血中濃度上昇（ミラベグロンのCYP2D6阻害作用）
  - ジゴキシン → ジゴキシン血中濃度上昇（P-gp阻害）
- 副作用:
  - 頻度高: 口渇（少ない）、便秘（少ない）、高血圧、尿路感染
  - 重大: 尿閉、高血圧の悪化


**処方のポイント**

- 抗コリン薬（ソリフェナシン等）の代替として、口渇・便秘・認知機能低下が問題となる患者に有用
- 高齢者のOABに推奨される（抗コリン作用による認知機能低下リスクがない）
- 血圧上昇の可能性 → 高血圧合併患者では血圧モニタリング
