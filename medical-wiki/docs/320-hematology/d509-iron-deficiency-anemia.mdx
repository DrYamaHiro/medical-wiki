消化管: なし / 黒色便 / 血便 / 胃切除歴
食事・嗜好: 偏食 / ベジタリアン / アルコール多飲

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[貧血は症状]** 「貧血」は病名ではなく「状態」である。鉄剤を出して終わりにしてはならない。閉経後女性や男性の貧血は、消化管癌（胃癌・大腸癌）のサインである可能性が極めて高いため、必ず内視鏡検査を強く推奨せよ。
>
> **[異食症]** 「氷をガリガリ食べるのが止められない」は鉄欠乏性貧血に特異的な症状である。鉄剤投与で劇的に消失する。
>
> **[MCVの鑑別]**
> - 小球性低色素性貧血 (MCV&lt;80): ①鉄欠乏性貧血（最多）②サラセミア③慢性疾患（ただし正球性が多い）の順で考えよ。「フェリチン低値」が鉄欠乏の決め手となる。
> - 正球性正色素性貧血 (MCV 80-100): ①急性出血②慢性疾患性貧血③溶血性貧血④再生不良性貧血を考える。
> - **大球性貧血 (MCV&gt;100):** ①ビタミンB12欠乏②葉酸欠乏③アルコール性が三大原因。神経症状（サブコンバイン）はB12欠乏に特異的。

<h3 className="soap-a">評価</h3>

- **診断根拠:** Hb低値、MCV低値(&lt;80)、MCHC低値。フェリチン低値(&lt;12ng/mL)。
- **原因:** 月経過多 / 消化管出血 / 成長期・妊娠 / 偏食 / 術後吸収障害
- **除外:** 慢性疾患に伴う貧血（フェリチン正常～高値）、サラセミア。

<h3 className="soap-p">方針・処方</h3>

- 治療戦略: 鉄剤内服（フェリチン正常化まで継続）。副作用（嘔気・便秘）対策。原因検索（内視鏡・婦人科エコー）の実施・紹介。静注が必要な場合は他院へ紹介。

#### 処方・処置

**鉄剤 (1つ選択)**

<span className="med-id">[Rx-Hem-Fe-Cit] フェロ・グラデュメット</span>
- フェロ・グラデュメット錠105mg 1回1錠 1日1回 朝食後 28日分 *— 徐放性・第一選択効果不十分時は1日2-3錠に増量可（鉄として100mg/日を目標）*
<span className="med-id">[Rx-Hem-Fe-Syr] インクレミン</span>
- インクレミンシロップ5% 10mL 1回1包 1日1回 朝食後 28日分 *— 小児・錠剤困難時*
<span className="med-id">[Rx-Hem-Fe-Cit2] クエン酸第一鉄Na</span>
- クエン酸第一鉄Na錠50mg 1回1錠 1日1-2回 食後 28日分 *— 低用量から開始したい時*

**副作用対策 (併用)**

<span className="med-id">[Rx-GI-Const-Mag] 酸化マグネシウム</span>
- 酸化マグネシウム錠330mg 1回1錠 1日3回 毎食後 28日分 *— 便秘対策*
<span className="med-id">[Rx-GI-Sym-Nau] ナウゼリン</span>
- ナウゼリン錠10mg 1回1錠 1日3回 食前 5日分 *— 悪心時*

**紹介**

<span className="med-id">[Doc-Gen-Referral] 診療情報提供書 (消化器内科：内視鏡 / 婦人科：過多月経 / 総合病院：鉄剤静注)</span>

#### 指導・計画

- **患者指導:** 便が黒くなることを説明。お茶での服用も臨床上は問題ない。
- **再診目安:** 1ヶ月後（Hb上昇確認）。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[原因検索]** 「貧血は病名ではなく状態」である。鉄剤で数値が良くなっても、背後に胃癌や大腸癌が隠れている可能性がある。閉経後女性や男性の貧血は、必ず消化管精査を行え。
>
> **[高齢者の貧血]** 高齢者の鉄欠乏性貧血は「消化管癌」と同義と考えよ。便潜血が陰性でも、貧血があるなら内視鏡（上部・下部）を行う正当な理由になる。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **最も多い貧血:** 世界人口の約25%が罹患
- **鉄の体内動態:** 総鉄量 3-4g、うち2/3がヘモグロビン、残りはフェリチン・ヘモジデリンとして貯蔵
- **原因:** 慢性出血（消化管出血 - 男性・閉経後女性で最重要、月経過多 - 閉経前女性）、摂取不足、吸収障害（胃切除後、ピロリ菌感染）、需要増大（妊娠、成長期）
- **進行:** 貯蔵鉄減少 → 血清鉄低下 → 小球性低色素性貧血

### 診断基準・鑑別疾患

- **検査所見:** 小球性低色素性貧血（MCV低下）、血清鉄低下、TIBC上昇、フェリチン低下（12ng/mL未満で確定）
- **鑑別:** 慢性疾患に伴う貧血（フェリチン正常～上昇、TIBC低下）、サラセミア（家族歴、HbA2上昇）、鉄芽球性貧血
- **原因検索:** 男性・閉経後女性の鉄欠乏性貧血 = 消化管悪性腫瘍の除外が必須 → 上下部内視鏡

### エビデンス・ガイドライン推奨

- **鉄剤補充:**
  - 経口鉄剤: クエン酸第一鉄Na（フェロミア）100-200mg/日、食後、ビタミンC併用で吸収促進
  - 消化器症状（嘔気、便秘）が高頻度 → 隔日投与でも有効（RCT 2020）
  - 静注鉄剤: 経口不耐容、吸収障害例に適応（含糖酸化鉄/フェジン、カルボキシマルトース鉄/フェインジェクト）。**当院では注射鉄剤の在庫を置いていないため、経口鉄剤不耐容で静注が必要な場合は総合病院へ紹介する方針**
  - **経口不耐容の場合の当院での対応:** まずリオナ錠（クエン酸第二鉄）への変更を検討（消化器症状が少ない）。それでも改善しない場合は、本当に出血等のout > inがないか精査（消化管出血、婦人科的出血）。その上でなお静注が必要と判断される場合に紹介
  - **ビタミンB12欠乏症（胃切除後等）:** 当院にはビタメジン等のB12注射剤の在庫がないため、B12補充が必要な場合は総合病院での短期フォローを依頼する
- **治療期間:** Hb正常化後もフェリチン正常化まで3-6ヶ月継続（貯蔵鉄の補充）
- **原因治療:** 月経過多（婦人科紹介）、消化管出血（原因精査・治療）
