<h3 className="soap-s">主訴・ROS</h3>

**貧血症状**

自覚症状: 労作時息切れ / 動悸 / めまい / 立ちくらみ / 易疲労感 / 耳鳴り
特異的症状: 氷食症[Pica] / 爪の変形 / 舌痛 / 味覚障害
神経症状: なし / 手足のしびれ / 歩行時のふらつき ；B12欠乏疑い

**出血・栄養歴**

月経: 順調 / 過多月経 / 凝血塊あり / 期間延長
消化管: なし / 黒色便 / 血便 / 胃切除歴
食事・嗜好: 偏食 / ベジタリアン / アルコール多飲

<h3 className="soap-o">所見・検査</h3>

眼瞼結膜: 正常 / 蒼白
口腔: 舌乳頭萎縮 / 平滑舌 / 口角炎
爪: 正常 / 扁平 / 匙状爪[Koilonychia]

**循環器・神経**

脈拍: ＿ bpm, 心雑音: なし / 収縮期駆出性雑音
神経所見: 異常なし / 振動覚低下 / Romberg徴候陽性

**院内迅速検査**

末梢血一般(CBC)
- Hb ＿ g/dL, MCV ＿ fL, Plt ＿ x10^4/μL
- **判定:** 小球性&lt;80 / 正球性80-100 / 大球性&gt;100

**外注検査**

貧血・鉄代謝
- 血清鉄(Fe), UIBC, フェリチン
ビタミン欠乏性貧血
- ビタミンB12, 葉酸 ；大球性の場合
網状赤血球数

<h3 className="soap-ns">診察前対応</h3>

**院内迅速検査**

- <span className="med-id">[Lab-Gen-CBC_CRP]</span> 末梢血一般(CBC)

**外注検査**

- <span className="med-id">[Lab-Hem-Iron]</span> 貧血・鉄代謝
- <span className="med-id">[Lab-Hem-Vit]</span> ビタミン欠乏性貧血

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[貧血は症状]** 「貧血」は病名ではなく「状態」である。鉄剤を出して終わりにしてはならない。閉経後女性や男性の貧血は、消化管癌（胃癌・大腸癌）のサインである可能性が極めて高いため、必ず内視鏡検査を強く推奨せよ。
>
> **[異食症]** 「氷をガリガリ食べるのが止められない」は鉄欠乏性貧血に特異的な症状である。鉄剤投与で劇的に消失する。
>
> **[MCVの鑑別]**
> - 小球性低色素性貧血 (MCV&lt;80): ①鉄欠乏性貧血（最多）②サラセミア③慢性疾患（ただし正球性が多い）の順で考えよ。「フェリチン低値」が鉄欠乏の決め手となる。
> - 正球性正色素性貧血 (MCV 80-100): ①急性出血②慢性疾患性貧血③溶血性貧血④再生不良性貧血を考える。
> - **大球性貧血 (MCV&gt;100):** ①ビタミンB12欠乏②葉酸欠乏③アルコール性が三大原因。神経症状（サブコンバイン）はB12欠乏に特異的。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 診断3要素 — (1)臨床症状（味覚障害・皮膚炎・貧血・食欲不振等）+(2)血清亜鉛値（60μg/dL未満で確定、60-80μg/dLで潜在性欠乏）+(3)亜鉛補充による改善。
- **重症度:** 味覚障害・皮膚症状（口囲や四肢末端の皮膚炎）・食欲不振・貧血の有無で評価。
- **鑑別:** 味覚障害・皮膚炎・貧血・食欲不振の原因として亜鉛欠乏を鑑別に挙げる。ペラグラ（ナイアシン欠乏）、ビオチン欠乏、腸性肢端皮膚炎も除外。

<h3 className="soap-p">方針・処方</h3>

- 亜鉛補充療法を開始し、3ヶ月で効果判定。
- 血清亜鉛・ALP・血清銅を定期フォロー（銅欠乏に注意）。
- **原因検索:** PPI長期内服、利尿薬、肝硬変、炎症性腸疾患、腎不全等。

#### 処方・アクション

**亜鉛補充セット**

- <span className="med-id">[Rx-Hem-Zn-Nov]</span> ノベルジン
- ノベルジン錠25mg 1回1錠 1日2回 朝夕食後 28日分 *— 低亜鉛血症*
- <span className="med-id">[Rx-Hem-Zn-Ace]</span> 酢酸亜鉛（増量時）
- 酢酸亜鉛錠25mg 1回1錠 1日3回 毎食後 28日分 *— 低亜鉛血症*
> ※初期は25mg 1日2回で開始。効果不十分時に25mg 1日3回へ増量（最大150mg/日）。
> ※ポラプレジンク（プロマック）は亜鉛欠乏症に対し適応外使用となるため注意。

#### 検査・アクション

**フォローアップ検査**

- <span className="med-id">[Lab-Hem-Zn]</span> 血清亜鉛
- <span className="med-id">[Lab-Hem-Cu]</span> 血清銅
- <span className="med-id">[Lab-Hem-ALP]</span> ALP

#### 指導・計画

- **再診目安:** 4週後に血清亜鉛再検。3ヶ月で症状改善を評価。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[見落とし注意]** 亜鉛欠乏は非特異的症状のため見落とされやすい。原因不明の味覚障害・貧血・皮膚炎では必ず血清亜鉛を測定すること。
>
> **[原因検索]** PPI長期内服、サイアザイド系利尿薬、肝硬変、腎不全、炎症性腸疾患が主な原因。原因除去が根本治療となる。
>
> **[銅欠乏]** 亜鉛長期補充により銅の吸収が阻害される。血清銅を定期的にモニタリングすること。
