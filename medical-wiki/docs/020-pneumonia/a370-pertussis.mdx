<summary className="so-summary">📋 主訴・所見・診察前対応</summary>

<h3 className="soap-s">主訴・ROS</h3>

主訴: 長引く咳嗽 / 発作性咳嗽 / 咳嗽後嘔吐 / 吸気性笛声 (whoop) / 夜間咳悪化 / 体力消耗 / (乳児) 無呼吸・チアノーゼ

**呼吸器系**

咳嗽: 発作性 / 連続性 (スタッカート様) / 通常, 咳嗽後嘔吐: 有 / 無
吸気性笛声 (whoop): 有 / 無, 夜間悪化: 有 / 無
痰: 粘稠 / なし, 喀血・血痰: 有 / 無

**経過・背景**

発症からの期間: ＿週 (カタル期 1-2週 / 痙咳期 2-6週 / 回復期 ～2ヶ月)
ワクチン接種歴: DPT-IPV 4回完了 / 不完全 / 不明 / 未接種
家族内・職場・施設での同様症例: 有 / 無
生後6ヶ月未満児への接触機会: 有 (祖父母・親族・保育) / 無
妊娠中: 有 / 無 (有: 妊娠週数 ＿週)

<h3 className="soap-o">所見・検査</h3>

バイタル: BT: ＿℃, SpO2: ＿% (Room Air), RR: ＿ /min

**身体所見**

発作性咳嗽の観察: 連続咳嗽 → whoop → 顔面紅潮・チアノーゼ
胸部聴診: 通常は清明 (合併症なければ副雑音乏しい)
眼瞼・顔面: 結膜下出血 / 顔面浮腫 (強い咳発作後)

**胸部X線** (鑑別目的)

胸部単純X線検査
所見: 異常なし / 浸潤影 (合併肺炎疑い) / 過膨張

**血液検査**

末梢血一般(CBC), CRP
WBC: ＿ (乳幼児では著明なリンパ球増多が特徴), CRP: ＿ (正常〜軽度上昇)

**確定検査** (外注)

百日咳 PCR (LAMP法): 陽性 / 陰性 / 提出
抗百日咳毒素IgG (PT-IgG): ＿ EU/mL / 提出 / ペア血清予定

<h3 className="soap-a">評価</h3>

- **診断根拠:** 2週間以上続く発作性咳嗽 ＋ 以下のいずれか (吸気性笛声 whoop / 咳嗽後嘔吐 / 夜間悪化のスタッカート様連続咳)。 PCR 陽性 (発症3週以内)／PT-IgG 抗体価上昇／培養陽性のいずれかで確定。
- **病期:** カタル期 1-2週 / 痙咳期 2-6週 / 回復期 ～2ヶ月
- **重症度:** 軽症 (成人外来管理可) / 中等 (体力消耗・睡眠障害) / 重症 (乳児・無呼吸・チアノーゼ → 即入院)

<h3 className="soap-p">方針・処方</h3>

- 抗菌薬の主目的は **二次伝播阻止** (本人の症状改善効果は痙咳期以降では限定的)。
- 適応: 発症3週以内 / PEP / 重症例。発症4週以降の慢性咳嗽単独例ではAMS観点から慎重判断。
- 出席停止: 学校保健安全法 第二種感染症。特殊な咳が消失するまで、または有効抗菌薬投与後5日経過まで。
- 就業制限: 医療・保育・教育従事者は同基準。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[AMS / 抗菌薬適正使用]** マクロライドは確定診断 (PCR/抗体) または強い臨床的疑い (曝露歴 + 典型症状) に限定。発症4週以降の慢性咳嗽のみで PCR 陰性なら抗菌薬は原則投与しない (症状改善効果なし、耐性誘導リスクのみ)。
>
> **[マクロライド相互作用]** CAM/EMはCYP3A4阻害により以下と相互作用 — ①スタチン (シンバ・アトルバ) → 横紋筋融解症, ②ワルファリン → INR上昇, ③カルバマゼピン・テオフィリン・タクロリムス → 血中濃度上昇, ④コルヒチン → 致死的中毒, ⑤QT延長薬との併用でTdP増悪, ⑥重症筋無力症で症状増悪。AZMは相互作用比較的少ないがQT延長は同様。
>
> **[薬剤選択]** コンプライアンス重視・妊婦・授乳婦・生後1ヶ月未満児ならAZM、コスト・実績ならCAM、AZM不耐の非妊婦にはEM。マクロライド耐性は百日咳ではまだ稀。
>
> **[予防 / 接触者対応]** 妊婦Tdap接種 (米国推奨27-36週、日本未承認・自費可) は新生児への移行抗体で重症化予防。同居家族で乳児・妊婦・乳児接触医療従事者に該当する濃厚接触者にはPEP (確定治療と同レジメン)。一般成人接触者は症状出現時対応で十分。
>
> **[設備制約]** 当院では PCR は外注 (結果まで 3-5日)。臨床的疑いが強ければ検査結果待ちで治療開始可。乳児疑いは検査せず即紹介でよい。

## 📖 詳細解説

### 病態生理

- **起炎菌**: *Bordetella pertussis* (グラム陰性桿菌、莢膜・線毛・各種毒素を産生)
- **感染経路**: 飛沫感染。潜伏期間は7-10日 (最長21日)
- **感染力**: R0 = 12-17 (麻疹に次ぐ高感染力)
- **病態**:
  1. 線毛・百日咳毒素 (PT) ・線維状血球凝集素 (FHA) で気道上皮に付着
  2. PT・気管細胞毒素 (TCT) ・アデニル酸シクラーゼ毒素 (ACT) で線毛運動障害・上皮障害・好中球機能抑制
  3. 痙攣性咳嗽は気道粘膜の炎症と神経学的機序による
- **疫学**:
  - 2018年から5類全数届出疾患 (届出基準改正)
  - 成人・思春期患者からの **乳児への家庭内伝播** が主問題 (祖父母 → 孫)
  - 日本では DPT-IPV (4回) 接種で乳児期感染は減少したが、成人期に抗体減衰

### 病期と症状

- **カタル期 (1-2週間)**: 普通感冒様の鼻汁・微熱・軽い咳。**この時期が最も感染力高い**
- **痙咳期 (2-6週間)**: 発作性連続咳嗽 (スタッカート) → 吸気性笛声 (whoop) → 咳嗽後嘔吐の triad。夜間悪化。乳児では whoop なく無呼吸発作のみのことあり
- **回復期 (2ヶ月以上)**: 発作頻度・強度が漸減。「100日咳」の名の由来

### 合併症

- **乳児・新生児**: 無呼吸・徐脈・低酸素脳症・百日咳脳症 (痙攣・意識障害)・致死性肺高血圧症
- **乳児・小児**: 細菌性二次性肺炎・無気肺・気胸・直腸脱・尿失禁・結膜下出血
- **成人**: 肋骨骨折 (強い咳発作)・尿失禁・睡眠障害・体重減少

### 診断基準・鑑別疾患

- **臨床診断 (CDC定義準拠)**: 2週間以上続く咳嗽 + 以下のいずれか
  1. 発作性咳嗽
  2. 吸気性笛声 (whoop)
  3. 咳嗽後嘔吐
- **確定検査**:
  - **PCR (LAMP法)**: 鼻咽頭スワブ。発症3-4週以内が最高感度。第一選択
  - **抗PT-IgG**: 単血清で診断可。キット・施設依存 (例: ≥100 EU/mL を目安)。ペア血清で4倍上昇がより確実。1年以内のDPT/Tdap接種歴・既感染歴があると解釈困難
  - **培養 (Bordet-Gengou / Regan-Lowe培地)**: 感度低く臨床利用は限定的
- **鑑別疾患**:
  - マイコプラズマ・クラミジア肺炎 (頑固な乾性咳嗽が共通)
  - 結核 (慢性咳嗽 + 体重減少 + 盗汗)
  - 咳喘息・アトピー咳嗽 (夜間悪化)
  - 後鼻漏症候群 (副鼻腔炎・アレルギー性鼻炎)
  - GERD関連咳嗽
  - ACE阻害薬関連咳嗽
  - 異物吸引 (小児)

### エビデンス・ガイドライン推奨

- **抗菌薬の主目的**: **二次伝播阻止** (本人の症状改善は痙咳期以降では限定的)
- **第一選択 (CDC 2017 / JAID-JSC)**:
  - **成人**: AZM 500mg/日 3日間 OR CAM 200mg×2 7日間
  - **妊婦・授乳婦・生後1ヶ月未満児**: AZM 第一選択 (EMは新生児幽門狭窄症リスクで回避)
  - **小児**: AZM Day1: 10mg/kg, Day2-5: 5mg/kg OR CAM 15mg/kg/日 分2 × 7日
- **代替**: EM (成人 800mg/日 14日。estolate塩は妊婦肝毒性で禁忌) / ST合剤 (適応外、マクロライド不耐時)
- **抗菌薬投与時期**: 発症3週以内が伝播阻止に有効。4週以降は効果限定的 → AMS観点で投与回避
- **AMS推奨**: 経験的処方は院内・施設内アウトブレイク時 + 濃厚接触者PEPに限定
- **PEP (Post-Exposure Prophylaxis) 対象** (CDC 2017):
  - 同居家族で①生後12ヶ月未満の乳児 ②妊娠後期妊婦 ③乳児に接触機会のある医療・保育従事者
  - 一般成人・思春期接触者は症状出現時対応で十分
- **入院基準**: 生後6ヶ月未満／無呼吸・チアノーゼ／脱水／痙攣・脳症・肺炎合併
- **届出**: 5類感染症 (全数)。診断後7日以内に保健所へ
- **就学・就業制限**: 学校保健安全法 第二種感染症。特殊咳嗽消失 or 有効抗菌薬投与後5日経過まで。医療・保育・教育従事者にも同基準準用
- **予防**:
  - DPT-IPV (定期): 生後3・4・5・12-23ヶ月の4回
  - Tdap (成人): 日本未承認 (自費可)。米国は全成人・妊婦27-36週・60歳以上推奨
  - **祖父母世代・周産期妊婦への個別勧奨** が新生児防御に重要
