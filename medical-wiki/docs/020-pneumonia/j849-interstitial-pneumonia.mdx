## 📖 詳細解説

### 病態生理

- **定義**: 肺の間質（肺胞壁、肺胞間の結合組織）を主座とするびまん性肺疾患の総称
- **分類（ATS/ERS 2013 + 2024改訂）**:
  - **特発性肺線維症（IPF/UIP）**: 最多・最重要。進行性線維化、予後不良（診断後中央生存期間3-5年）
  - **特発性非特異性間質性肺炎（NSIP）**: ステロイド反応性、予後比較的良好
  - **特発性器質化肺炎（COP）**: ステロイドに良好に反応
  - **急性間質性肺炎（AIP）**: 急速進行、びまん性肺胞傷害、致死率高い
  - 膠原病関連間質性肺疾患（CTD-ILD）、薬剤性、過敏性肺炎なども含む
- **IPFの病態**:
  1. 肺胞上皮の反復性微小傷害
  2. 異常な創傷治癒反応 → 線維芽細胞巣（fibroblastic foci）の形成
  3. 細胞外マトリックスの過剰蓄積 → 蜂巣肺（honeycomb lung）
  4. 不可逆的な肺構造の破壊 → 拘束性換気障害 → 呼吸不全
- **リスク因子**: 喫煙（IPFの最大リスク）、粉塵曝露、GERD、遺伝的素因（TERT/TERC変異、MUC5B）

### 診断基準・鑑別疾患

- **IPFの診断基準（ATS/ERS/JRS/ALAT 2024更新）**:
  - 既知の原因（膠原病、薬剤、環境曝露）の除外
  - HRCT所見でUIPパターン:
    - 蜂巣肺（必須所見）
    - 牽引性気管支拡張
    - 胸膜直下・基底部優位の網状影
    - すりガラス影は軽微
  - HRCTでUIP確実なら生検不要
- **クリニックレベルで疑うべき所見**:
  - 慢性の乾性咳嗽 + 労作時呼吸困難（進行性）
  - 聴診: 両側背下部のfine crackles（Velcro rales）
  - ばち指（clubbing）: IPFの30-50%に認める
  - SpO2低下（特に労作時）
- **スクリーニング検査**:
  - KL-6: 1,000 U/mL以上で間質性肺炎を強く示唆（感度70-80%）
  - SP-D: 上昇（肺胞上皮傷害のマーカー）
  - LDH: 上昇（組織傷害の非特異的指標）
- **鑑別疾患**:
  - 心不全（BNP上昇、起座呼吸、下腿浮腫）
  - びまん性肺胞出血（血痰、貧血）
  - 肺胞蛋白症（両側すりガラス影、BALで乳白色）
  - 癌性リンパ管症（原発巣の検索）
  - サルコイドーシス（BHL、ACE上昇）

### エビデンス・ガイドライン推奨

- **IPFの薬物療法**:
  - 抗線維化薬が標準治療（進行を遅らせる。治癒はしない）
  - ニンテダニブ（オフェブ）150mg 1日2回: FVC低下を年間約50%抑制（INPULSIS試験）
  - ピルフェニドン（ピレスパ）1日1,800mg（漸増）: FVC低下を抑制（ASCEND試験）
  - 両剤とも専門医での導入が必要（肝機能障害、消化器症状の管理）
- **IPF以外の間質性肺炎**:
  - NSIP、COP: ステロイド（PSL 0.5-1mg/kg）+ 免疫抑制薬
  - 膠原病関連ILD: 原疾患の治療 + 抗線維化薬（progressive fibrosing ILD）
- **急性増悪**: IPF患者の5-15%/年。致死率50%以上。感冒後などに急激なSpO2低下があれば緊急紹介
- **プライマリケアでの役割**:
  - 早期発見（聴診でVelcro rales → KL-6測定 → 専門医紹介）
  - 安定期のフォロー（3-6ヶ月ごとのKL-6、SpO2、胸部X線）
  - ワクチン接種（肺炎球菌、インフルエンザ: 急性増悪予防）
  - 在宅酸素療法（HOT）の管理
