<h3 className="soap-a">評価</h3>

- **診断根拠:** 眼瞼の局所的な発赤・腫脹・疼痛（ものもらい）。
- **所見:** 睫毛根部（外麦粒腫）または瞼板腺（内麦粒腫）の化膿。
- **原因菌:** 黄色ブドウ球菌主体。

<h3 className="soap-p">方針・処方</h3>

- 治療戦略: 抗菌点眼薬および眼軟膏。腫脹・疼痛が強い場合は抗菌薬内服併用。膿点が見えれば自然排膿を待つ。切開が必要なら眼科紹介。

#### 処方・処置

**外用セット (併用推奨)**

<span className="med-id">[Rx-Gen-Eye-Cravit] クラビット点眼</span>
- クラビット点眼液1.5% 1本 1日4回 両眼
<span className="med-id">[Rx-Gen-Eye-Oin] タリビット眼軟膏</span>
- タリビット眼軟膏0.3% 1本 1日2回 患部に塗布 *— 寝る前など*

<span className="med-id">[Rx-Der-Cel-Cef] ケフレックス</span>

- レバミピド錠100mg 1回1錠 (疼痛時) 10回分

**紹介**

<span className="med-id">[Doc-Gen-Referral] 診療情報提供書 (眼科へ紹介：切開排膿依頼・難治例)</span>

- **患者指導:** 汚い手で触ると周囲に広がるため、「気になっても絶対に触らない」こと。
- **再診目安:** 1週間後。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **定義:** 眼瞼の腺組織の急性細菌感染症
  - 外麦粒腫: Zeis腺またはMoll腺の感染（眼瞼縁外側）
  - 内麦粒腫: マイボーム腺の感染（眼瞼縁内側）
- **起炎菌:** 黄色ブドウ球菌が最多（約90%）
- **症状:** 眼瞼の限局性発赤・腫脹・圧痛、膿点形成
- **自然経過:** 多くは1-2週間で自然排膿・治癒

### 診断基準・鑑別疾患

- **診断:** 臨床所見で診断（眼瞼の有痛性限局性腫脹）
- **鑑別:**
  - 霰粒腫: 無痛性の慢性肉芽腫（感染を伴わない）
  - 眼瞼蜂窩織炎: びまん性腫脹、発熱
  - 眼瞼腫瘍（脂腺癌）: 再発する霰粒腫様病変は要注意

### 内麦粒腫 vs 外麦粒腫の治療差

| | 外麦粒腫 | 内麦粒腫 |
|---|---|---|
| 感染腺 | Zeis腺/Moll腺 | マイボーム腺 |
| 位置 | 眼瞼縁の外側（皮膚面） | 眼瞼縁の内側（結膜面） |
| 排膿方向 | 皮膚面から自然排膿しやすい | 結膜面から排膿、または内方に膿瘍形成 |
| 治療 | 温罨法+抗菌点眼で多くは自然治癒 | 内方に膿瘍形成しやすく、切開排膿を要する頻度が高い |
| 合併リスク | 低い | 霰粒腫への移行リスクあり |
| 眼科紹介閾値 | 2週間改善なし | 早期に紹介を検討（1週間改善なし） |

### エビデンス・ガイドライン推奨

- **温罨法のエビデンス:**
  - Cochrane Review（Lindsley 2012）: 温罨法は麦粒腫の標準治療として推奨されるが、高質のRCTは限定的
  - **推奨手技:** 清潔な温タオル or ホットアイマスク、40-45℃、1日2-4回、各10-15分間
  - **効果の機序:** 脂質の融解促進、局所血流増加による免疫応答の促進、排膿促進
  - 温罨法のみで約90%の外麦粒腫は1-2週間で自然治癒
- **抗菌薬の推奨度:**
  - **抗菌点眼薬:** 排膿促進・周囲への感染拡大予防として併用推奨（エビデンスレベルは高くないが実臨床では標準的）
  - **抗菌眼軟膏:** 就寝前塗布で薬剤の眼表面滞留時間を延長。オフロキサシン眼軟膏が汎用
  - **内服抗菌薬:** 蜂窩織炎への進展時のみ適応（AAO推奨）。ルーチンの内服抗菌薬は不要（過剰治療）
  - **ステロイド:** 急性期には使用しない（感染増悪リスク）
- **切開排膿:** 膿点が明瞭で2週間以上自然排膿しない場合に考慮。内麦粒腫は結膜面からの切開が原則
- **眼科紹介:** 2週間以上改善しない場合、再発を繰り返す場合、眼瞼蜂窩織炎への進展
