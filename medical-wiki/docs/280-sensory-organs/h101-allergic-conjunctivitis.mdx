<h3 className="soap-s">主訴・ROS</h3>

**眼症状**

充血: 右 / 左 / 両眼, 眼脂: 膿性 / 水様 / 粘液性
自覚症状: 掻痒感 / 異物感 / 乾燥感 / 流涙
視力・視野: 低下なし / 急激な視力低下 / 霧視 / 視野欠損
眼痛: なし / 表面 / 奥 / 動かすと痛い

**耳症状**

耳痛: なし / あり, 耳漏: なし / 膿性 / 血性
難聴: なし / 急激 / 徐々 / 低音が聞こえにくい
その他: 耳閉感 / 耳鳴り

**経過・背景**

発症時期: ＿
コンタクトレンズ使用: 有 / 無
既往歴: 緑内障 / 白内障 / 中耳炎 / アレルギー

<h3 className="soap-o">所見・検査</h3>

**眼**

結膜充血: 有 / 無, 眼瞼腫脹: 有 / 無
角膜・瞳孔: 角膜混濁 / 瞳孔不同 / 対光反射迅速 / 対光反射消失

**耳**

外耳道: 発赤 / 耳垢栓塞 / 異常なし
鼓膜所見: 正常 / 発赤 / 混濁 / 液貯留 / 穿孔
耳介牽引痛: 有 / 無 ；外耳炎サイン

**検査**

標準純音聴力検査
- **結果:** 実施せず / 正常 / 感音難聴 / 伝音難聴

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[RedFlag - 眼]** 「急激な視力低下」「激しい眼痛（緑内障発作疑い）」「視野欠損」「眼球打撲」は専門医による緊急対応が必要。処方で粘らず即日紹介せよ。
>
> **[RedFlag - 耳]** 「突然聞こえなくなった（突発性難聴）」は時間との勝負（Time is Hearing）。ステロイド治療のゴールデンタイムを逃さないため、即座に聴力検査を行い、異常があれば直ちに専門医へ送れ。
>
> **[ステロイド点眼の禁忌]** 角膜ヘルペスや真菌感染にステロイドを点眼すると、劇的に悪化し失明のリスクがある。細隙灯で角膜を確認できない環境では、安易にステロイド点眼処方は避けるべきである。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 眼の掻痒感、充血、眼脂（水様～粘液性）。アレルギー性鼻炎の合併。
- **重症度:** 軽症 / 中等症 / 重症

<h3 className="soap-p">方針・処方</h3>

- 治療戦略: 抗アレルギー点眼薬（第一選択）。痒みが強く我慢できない場合のみ弱ステロイド点眼を短期間併用（緑内障除外必須）。コンタクトレンズ一時中止。

#### 処方・処置

**点眼薬 (1つ選択)**

<span className="med-id">[Rx-Gen-Eye-Ale] アレジオンLX</span>
- アレジオンLX点眼液0.1% 1本 1日2回 両眼 *— 1日2回で便利・高用量*
<span className="med-id">[Rx-Gen-Eye-Olo] パタノール</span>
- パタノール点眼液0.1% 1本 1日4回 両眼 *— 標準的*

**二次感染予防 (目やにが多い時)**

<span className="med-id">[Rx-Gen-Eye-Cravit] レボフロキサシン点眼</span>
- レボフロキサシン点眼液1.5% 1本 1日3-4回 両眼

#### 指導・計画

- **患者指導:** 複数の目薬を差す場合は、「5分以上」間隔を空けないと先に差した薬が洗い流されてしまうことを指導。
- **再診目安:** 2週間後。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **機序:** I型アレルギー反応（IgE介在）。結膜肥満細胞からのヒスタミン等放出
- **病型:** 季節性（花粉症）が最多、通年性（ダニ・ハウスダスト）、春季カタル（重症型、小児男児）、アトピー性角結膜炎
- **症状:** 眼掻痒感（最重要）、流涙、結膜充血、眼脂（漿液性～粘液性）、結膜浮腫

### 診断基準・鑑別疾患

- **診断:** 眼掻痒感 + 結膜充血 + アレルギー歴（花粉症、アトピー等）
- **鑑別:**
  - 細菌性結膜炎: 膿性眼脂、掻痒感なし
  - ウイルス性結膜炎（流行性角結膜炎）: 耳前リンパ節腫脹、流涙主体
  - ドライアイ: 異物感主体、BUT短縮

### エビデンス・ガイドライン推奨

- **アレルギー性結膜疾患診療ガイドライン（第3版、2021）:**
  - **第一選択:** 抗アレルギー点眼薬（オロパタジン点眼、エピナスチン点眼）: 軽症～中等症
  - **効果不十分時:** ステロイド点眼（フルオロメトロン0.1%）短期追加 → 眼圧上昇に注意
  - **初期療法:** 花粉飛散2週間前から点眼開始でシーズン中の症状軽減
- **重症（春季カタル）:** シクロスポリン点眼、タクロリムス点眼 → 眼科専門管理
- **コンタクトレンズ:** アレルギー期間中は装用制限を指導
