**眼症状**

充血: 右 / 左 / 両眼, 眼脂: 膿性 / 水様 / 粘液性

眼痛: なし / 表面 / 奥 / 動かすと痛い

**耳症状**

耳痛: なし / あり, 耳漏: なし / 膿性 / 血性
難聴: なし / 急激 / 徐々 / 低音が聞こえにくい
その他: 耳閉感 / 耳鳴り

**経過・背景**

発症時期: ＿
コンタクトレンズ使用: 有 / 無
既往歴: 緑内障 / 白内障 / 中耳炎 / アレルギー

**眼**

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[RedFlag - 眼]** 「急激な視力低下」「激しい眼痛（緑内障発作疑い）」「視野欠損」「眼球打撲」は専門医による緊急対応が必要。処方で粘らず即日紹介せよ。
>
> **[RedFlag - 耳]** 「突然聞こえなくなった（突発性難聴）」は時間との勝負（Time is Hearing）。ステロイド治療のゴールデンタイムを逃さないため、即座に聴力検査を行い、異常があれば直ちに専門医へ送れ。
>
> **[ステロイド点眼の禁忌]** 角膜ヘルペスや真菌感染にステロイドを点眼すると、劇的に悪化し失明のリスクがある。細隙灯で角膜を確認できない環境では、安易にステロイド点眼処方は避けるべきである。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 眼の乾き、異物感、疲れ目（眼精疲労）。結膜充血。
- **原因:** スマホ・PC作業 / コンタクト / エアコン / 加齢

<h3 className="soap-p">方針・処方</h3>

- 治療戦略: 点眼薬による角膜保護・涙液保持。環境調整。改善なければシェーグレン症候群等の鑑別含め眼科紹介。

#### 処方・処置

**点眼薬 (選択)**

<span className="med-id">[Rx-Gen-Eye-Hyalein] ヒアルロン酸点眼</span>
- ヒアルロン酸Na点眼液0.1% 1本 1日4回～ 両眼 *— 保水・角膜修復*
<span className="med-id">[Rx-Gen-Eye-Diq] ジクアス</span>
- ジクアス点眼液3% 1本 1日4-6回 両眼 *— 涙液分泌促進(ムチン産生)*
<span className="med-id">[Rx-Gen-Eye-ArtTear] 人工涙液マイティア</span>
- 人工涙液マイティア点眼液5mL 1本 1日5-6回 両眼 *— 防腐剤フリー・頻回点眼可*
<span className="med-id">[Rx-Gen-Eye-Mucosta] ムコスタ点眼液</span>
- ムコスタ点眼液UD2% 1日4回 両眼 *— ムチン産生促進・白濁あり*

#### 指導・計画

- **患者指導:** ジクアスは「しみる」「目やにが出る」ことがあるが、続けると慣れて涙が増えることを説明。
- **再診目安:** 4週間後。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **定義（2016年改訂）:** 涙液層の不安定性を主体とする眼表面の多因子疾患で、眼不快感や視機能異常を伴う
- **涙液の3層構造:** 油層（マイボーム腺）/ 水層（涙腺）/ ムチン層（結膜杯細胞）のいずれかの異常
- **病型:** 涙液減少型（Sjogren症候群等）、蒸発亢進型（MGD、VDT作業）、短時間BUT型（最多）
- **リスク因子:** VDT作業、コンタクトレンズ、加齢、女性、抗ヒスタミン薬・抗コリン薬、空調環境

### 診断基準・鑑別疾患

- **診断基準（日本ドライアイ研究会2016）:** 自覚症状 + BUT 5秒以下
- **検査:** BUT（涙液層破壊時間）、Schirmer試験（涙液分泌量）、フルオレセイン染色、ローズベンガル染色
- **鑑別:** アレルギー性結膜炎（掻痒感主体）、感染性結膜炎（充血・眼脂）、Sjogren症候群（口渇合併）

### エビデンス・ガイドライン推奨

- **ドライアイ診療ガイドライン（日本眼科学会2019）:**
  - **第一選択:** ヒアルロン酸点眼（0.1%、0.3%）: 涙液保持
  - **ジクアホソルNa点眼（ジクアス）:** 水分・ムチン分泌促進
  - **レバミピド点眼（ムコスタ）:** ムチン産生促進（白濁するが有効）
  - **人工涙液:** 補助的使用
- **生活指導:** VDT作業時の意識的な瞬目、加湿、コンタクトレンズ適正使用
- **重症例:** 涙点プラグ、自己血清点眼 → 眼科専門医紹介
