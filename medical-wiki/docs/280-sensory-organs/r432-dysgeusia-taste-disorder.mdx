<h3 className="soap-s">主訴・ROS</h3>

**眼症状**

充血: 右 / 左 / 両眼, 眼脂: 膿性 / 水様 / 粘液性
自覚症状: 掻痒感 / 異物感 / 乾燥感 / 流涙
視力・視野: 低下なし / 急激な視力低下 / 霧視 / 視野欠損
眼痛: なし / 表面 / 奥 / 動かすと痛い

**耳症状**

耳痛: なし / あり, 耳漏: なし / 膿性 / 血性
難聴: なし / 急激 / 徐々 / 低音が聞こえにくい
その他: 耳閉感 / 耳鳴り

**経過・背景**

発症時期: ＿
コンタクトレンズ使用: 有 / 無
既往歴: 緑内障 / 白内障 / 中耳炎 / アレルギー

<h3 className="soap-o">所見・検査</h3>

**眼**

結膜充血: 有 / 無, 眼瞼腫脹: 有 / 無
角膜・瞳孔: 角膜混濁 / 瞳孔不同 / 対光反射迅速 / 対光反射消失

**耳**

外耳道: 発赤 / 耳垢栓塞 / 異常なし
鼓膜所見: 正常 / 発赤 / 混濁 / 液貯留 / 穿孔
耳介牽引痛: 有 / 無 ；外耳炎サイン

**検査**

標準純音聴力検査
- **結果:** 実施せず / 正常 / 感音難聴 / 伝音難聴

<h3 className="soap-ns">診察前対応</h3>

**検査**

- <span className="med-id">[Phy-Ent-Audio]</span> 標準純音聴力検査

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[RedFlag - 眼]** 「急激な視力低下」「激しい眼痛（緑内障発作疑い）」「視野欠損」「眼球打撲」は専門医による緊急対応が必要。処方で粘らず即日紹介せよ。
>
> **[RedFlag - 耳]** 「突然聞こえなくなった（突発性難聴）」は時間との勝負（Time is Hearing）。ステロイド治療のゴールデンタイムを逃さないため、即座に聴力検査を行い、異常があれば直ちに専門医へ送れ。
>
> **[ステロイド点眼の禁忌]** 角膜ヘルペスや真菌感染にステロイドを点眼すると、劇的に悪化し失明のリスクがある。細隙灯で角膜を確認できない環境では、安易にステロイド点眼処方は避けるべきである。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 味覚減退・消失・異味症の訴え。電気味覚検査やろ紙ディスク法で客観的評価。
- **重症度:** 全味質障害 vs 特定味質障害。食事摂取量低下・体重減少の有無。
- **鑑別:** 亜鉛欠乏、薬剤性（PPI、ACE阻害薬、ARB、抗菌薬、抗がん剤、テルビナフィン、D-ペニシラミン、抗甲状腺薬、メトホルミン）、口腔乾燥（シェーグレン）、神経障害（顔面神経麻痺後）、COVID-19後遺症、ビタミンB12欠乏、鉄欠乏。

<h3 className="soap-p">方針・処方</h3>

- 血清亜鉛を測定し、欠乏時はノベルジン25mg 1回1錠 1日2回（亜鉛として50mg/日）で開始。
- 薬剤性が疑われる場合は原因薬の変更・中止を検討。
- 口腔乾燥にはサリベートまたは人工唾液を処方。

#### 処方・アクション

**亜鉛補充セット**

- <span className="med-id">[Rx-Sens-Zn-Nov]</span> ノベルジン
- ノベルジン錠25mg 1回1錠 1日2回 朝夕食後 28日分 *— 低亜鉛血症*
> ※レセプト病名: 低亜鉛血症の併記が必須

**口腔乾燥対応セット**

- <span className="med-id">[Rx-Sens-Sal-Srv]</span> サリベート
- サリベートエアゾール 1回2-3噴霧 1日4-5回 口腔内 *— 口腔乾燥症*
> ※レセプト病名: 口腔乾燥症[R68.2]を併記

#### 検査・アクション

**原因検索**

- <span className="med-id">[Lab-Sens-Zn]</span> 血清亜鉛
- <span className="med-id">[Lab-Sens-Fe]</span> 血清鉄・フェリチン
- <span className="med-id">[Lab-Sens-Cu]</span> 血清銅
- <span className="med-id">[Lab-Sens-B12]</span> ビタミンB12

#### 指導・計画

- **再診目安:** 4週後に症状評価・血清亜鉛再検。改善まで3-6ヶ月を要する場合あり。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[COVID-19後遺症]** COVID-19後遺症としての味覚障害が増加している。自然回復が多いが、遷延例には亜鉛補充が有効な場合がある。
>
> **[亜鉛正常例]** 血清亜鉛が正常範囲でも、試験的亜鉛投与が奏功する場合がある（特発性味覚障害）。3ヶ月は継続して判定すること。
