<h3 className="soap-a">評価</h3>

- **診断根拠:** 味覚減退・消失・異味症の訴え。電気味覚検査やろ紙ディスク法で客観的評価。
- **重症度:** 全味質障害 vs 特定味質障害。食事摂取量低下・体重減少の有無。
- **鑑別:** 亜鉛欠乏、薬剤性（PPI、ACE阻害薬、ARB、抗菌薬、抗がん剤、テルビナフィン、D-ペニシラミン、抗甲状腺薬、メトホルミン）、口腔乾燥（シェーグレン）、神経障害（顔面神経麻痺後）、COVID-19後遺症、ビタミンB12欠乏、鉄欠乏。

<h3 className="soap-p">方針・処方</h3>

- 血清亜鉛を測定し、欠乏時はノベルジン25mg 1回1錠 1日2回（亜鉛として50mg/日）で開始。
- 薬剤性が疑われる場合は原因薬の変更・中止を検討。
- 口腔乾燥にはサリベートまたは人工唾液を処方。

## 📖 詳細解説

味覚障害は味覚の減退（hypogeusia）、消失（ageusia）、異味症（dysgeusia: 本来と異なる味に感じる）、自発性異常味覚（phantogeusia: 何も食べていないのに味がする）の総称である。日本における受診患者数は年間約24万人と推計され、高齢化・多剤内服の増加に伴い増加傾向にある。最多原因は亜鉛欠乏であり、次いで薬剤性が多い。

### 病態生理

**味覚のメカニズム**

- 味蕾（taste bud）は舌の有郭乳頭・葉状乳頭・茸状乳頭に存在し、成人で約5,000-10,000個
- 味蕾細胞のターンオーバーは約10日間と速く、亜鉛を多量に消費する
- 5基本味: 甘味・塩味・酸味・苦味・旨味
- 味覚神経: 舌前2/3は鼓索神経（顔面神経の枝）、舌後1/3は舌咽神経、喉頭蓋は迷走神経

**亜鉛欠乏と味覚障害**

- 亜鉛は味蕾細胞のターンオーバーに必須の微量元素
- 亜鉛欠乏により味蕾細胞の再生が障害され、味覚閾値が上昇
- 血清亜鉛の基準値: 80-130 mcg/dL
- 60-80 mcg/dL: 潜在性亜鉛欠乏（味覚障害を来しうる）
- 60 mcg/dL未満: 亜鉛欠乏症
- 亜鉛欠乏の原因: 偏食・低栄養（高齢者）、薬剤によるキレート作用、消化管疾患（吸収障害）、慢性肝疾患、腎不全（透析）

**薬剤性味覚障害の主な原因薬**

| 薬剤カテゴリ | 代表的薬剤 | 機序 |
|------------|----------|------|
| ACE阻害薬 | エナラプリル、リシノプリル | 亜鉛キレート作用 |
| 抗癌剤 | シスプラチン、5-FU、S-1 | 味蕾細胞の直接障害 |
| 抗菌薬 | クラリスロマイシン、メトロニダゾール | 苦味受容体への作用 |
| 抗真菌薬 | テルビナフィン | 味蕾細胞障害（回復に数ヶ月） |
| 抗甲状腺薬 | チアマゾール | 亜鉛キレート作用 |
| D-ペニシラミン | -- | 亜鉛・銅のキレート |
| PPI | オメプラゾール、ランソプラゾール | 亜鉛吸収阻害 |
| メトホルミン | -- | ビタミンB12吸収阻害を介する |
| 抗パーキンソン病薬 | レボドパ | 味覚神経への影響 |

**その他の原因**

- 口腔乾燥（シェーグレン症候群、薬剤性、放射線治療後）: 味物質の溶解・運搬障害
- 神経障害: 顔面神経麻痺後（鼓索神経障害）、脳血管障害、頭部外傷
- 全身疾患: 鉄欠乏性貧血、ビタミンB12欠乏、腎不全、肝硬変、糖尿病
- COVID-19後遺症: 嗅覚障害に伴う風味障害が多いが、味覚そのものの障害もある
- 心因性: うつ病、不安障害に伴う味覚異常

### 診断基準・鑑別疾患

**味覚検査法**

- **電気味覚検査（EGM: Electrogustometry）:** 舌の各部位に微弱電流を与え味覚閾値を測定。神経障害の局在診断に有用。正常値: -6〜2 dB（機器により異なる）。8 dB以上で味覚低下と判定。
- **濾紙ディスク法:** 4基本味（甘味・塩味・酸味・苦味）の5段階濃度溶液を浸した濾紙を舌に置き、識別能を評価。全口腔法と局所法がある。各味質の認知閾値を定量的に評価可能。

**原因検索のための検査**

| 検査 | 目的 |
|------|------|
| 血清亜鉛 | 亜鉛欠乏の確認（最重要） |
| 血清鉄・フェリチン | 鉄欠乏の評価 |
| 血清銅 | 亜鉛過剰投与時の銅欠乏モニタリング |
| ビタミンB12 | 悪性貧血の除外 |
| 薬剤歴の詳細確認 | 薬剤性の除外 |
| 口腔内診察 | 舌苔、口腔カンジダ症、舌炎の確認 |
| 唾液分泌量測定 | 口腔乾燥の評価（ガム試験: 10分間で10mL未満は低下） |

**鑑別のフローチャート**

1. 薬剤歴の確認 → 薬剤性が疑われれば変更・中止を検討
2. 血清亜鉛測定 → 80 mcg/dL未満なら亜鉛補充開始
3. 口腔内診察 → 口腔乾燥・カンジダ・舌炎の評価
4. 神経学的診察 → 顔面神経麻痺、頭蓋内病変の除外
5. 全身疾患の評価 → 貧血、肝腎機能、甲状腺機能

### エビデンス・ガイドライン推奨

**亜鉛補充療法（日本臨床栄養学会 亜鉛欠乏症の診療指針2018準拠）**

- **第一選択: 酢酸亜鉛（ノベルジン錠25mg）** 1回1錠 1日2回（亜鉛として50mg/日）
- 適応病名: 低亜鉛血症（2017年に保険適用拡大）
- 効果発現まで: 2週間〜3ヶ月。平均的な改善率は約60-70%。
- 投与期間: 最低3ヶ月は継続して効果を判定。改善後も3-6ヶ月は継続が望ましい。
- **ポラプレジンク（プロマック顆粒15%）:** 胃潰瘍の適応で亜鉛を含有（亜鉛として約17mg/包）。適応外使用だが亜鉛補充に用いられてきた歴史がある。レセプト上はノベルジンが推奨。

**亜鉛補充時の注意点**

- 銅欠乏: 亜鉛は腸管での銅吸収を競合阻害するため、長期投与時は血清銅をモニタリング（3-6ヶ月ごと）
- 消化器症状（嘔気）: 食後投与で軽減
- 血清亜鉛の目標: 80 mcg/dL以上を維持

**薬剤性味覚障害の対応**

- 原因薬の中止・変更が最も効果的（中止後2-4週間で改善開始が多い）
- 中止困難な場合は亜鉛補充を並行して実施
- テルビナフィンによる味覚障害は回復に数ヶ月を要することがある

**血清亜鉛正常例（特発性味覚障害）**

- 血清亜鉛が正常範囲でも、亜鉛の試験的投与が奏功する場合がある
- 組織レベルでの亜鉛欠乏（血清値では反映されない）の可能性
- 3ヶ月間の試験的亜鉛投与で効果判定

**味覚リハビリテーション**

- 味の濃い食品を意識的に摂取し味覚刺激を維持
- 口腔ケア（舌苔除去、保湿）の徹底
- 亜鉛を多く含む食品の摂取指導: 牡蠣（100gあたり亜鉛13mg）、牛赤身肉、ナッツ類、チーズ
