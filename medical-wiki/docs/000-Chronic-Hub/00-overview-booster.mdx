# 📖 Overview Booster — 慢性疾患統合俯瞰ツール

クリニックで生活習慣病・慢性心不全・慢性腎臓病・心房細動・COPD など、相互に密接した慢性疾患を **網羅的に把握** するためのツールです。

:::info このツールの位置づけ
- **Overview Booster (本ページ)** — 多疾患の俯瞰・治療台帳・フォローコード生成 (鳥瞰図)
- **個別 Treatment Booster** — 1疾患の細かい治療修正・推奨ロジック (拡大鏡)
- 両者は連動: Overview から「個別 Booster で詳細編集 →」リンクで深掘り可能
:::

:::tip 4ステップフロー
1. **入口**: フォローコード入力 (再診で前回再現) or 新規セッション開始
2. **STEP 0**: 患者の慢性疾患を chip で選択 (複数可)。患者の処方薬から逆引き提案も
3. **STEP 0.5**: 5疾患 (DLP/HT/CKD/AF/COPD) でリスクスコア層別 (任意スキップ可、自動計算)
4. **STEP 1**: 各疾患の主要薬剤クラス + 食事運動を toggle で選択。禁忌違反を自動警告
5. **まとめ**: フォローコード発行 (紙カルテ書込み可) + 選択一覧 + 個別 Booster へ deep link
:::

:::warning 設計境界 — 必ず読んでください
- Overview Booster は **俯瞰用ツール**で、推奨ロジックは持ちません
- 細かい用量・修飾子・禁忌チェックは **個別 Treatment Booster** で行ってください
- 「→ 個別 Booster で詳細編集」リンクから飛ぶと、選択済み薬剤が引き継がれます
- フォローコードに **患者識別情報 (氏名・生年月日・カルテ番号) は一切含まれません**。疾患・薬剤・lifestyle 選択のみ
- **次の患者を診る時は「👤→👤 次の患者へ」を必ず押してください** (前患者の情報汚染防止)
:::
