<h3 className="soap-s">主訴・ROS</h3>

**痛みの分析 (OPQRST)**

Onset (発症様式): 突然 / 急性 / 徐々 / ある動作で
Palliative/Provocative (増悪・寛解): 体動 / 食事 / 深呼吸 / 安静時
Quality (性状): 締め付けられる / 裂けるよう / 鈍痛 / 差し込む
Region (部位): 胸部 / 心窩部 / 右季肋部 / 右下腹部 / 背部
Severity (強度): 冷や汗をかく激痛 / 会話可能 / 波がある
Time (経過): ＿分/時間 前から持続

**随伴症状**

冷汗 / 嘔気・嘔吐 / 呼吸困難 / 意識消失 / 下血 / なし

**リスク因子**

高血圧 / 糖尿病 / 脂質異常症 / 喫煙 / 心疾患の既往 / なし

<h3 className="soap-o">所見・検査</h3>

バイタル: BP ＿/＿ (左右差: 有 / 無), HR ＿, SpO2 ＿%, BT ＿℃
顔貌: 苦悶様 / 蒼白 / 冷汗 / 安定

**身体所見**

胸部: 異常なし / 心雑音 / 呼吸音異常 / 頸静脈怒張
腹部: 平坦 / 膨満, 腹膜刺激症状 なし / 筋性防御 / 反跳痛
圧痛点: なし / McBurney / Murphy / 全体
CVA叩打痛: なし / 右 / 左

**院内迅速検査**

心電図（12誘導）
- **所見:** 正常 / ST変化 / 異常Q波
末梢血一般(CBC), CRP
- WBC ＿, CRP ＿, 血糖 ＿
尿検査
- 潜血(＿) ；結石・解離の鑑別
胸部単純X線検査
腹部単純X線検査
- **所見:** Free air / 結石影 / 縦隔拡大 / 異常なし

**除外項目(Negative ROS)**

頭痛時: 項部硬直なし / 麻痺・しびれなし / 雷鳴頭痛否定
胸背部痛時: 圧痛なし / 皮疹なし / 血圧左右差なし
腹痛時: 板状硬なし / 反跳痛なし / 拍動性腫瘤なし

<div className="so-dr-advice">

> 💡 **Dr.Advice**
>
> **[Killer Chest Pain]** 胸痛・背部痛で絶対に見逃してはならない5大疾患（ACS、大動脈解離、肺塞栓、緊張性気胸、食道破裂）。当院にはCT/Echoがないため、少しでも疑わしければ「帰宅させない」覚悟が必要。
>
> **[Killer Abdominal Pain]** 腹部大動脈瘤破裂、上腸間膜動脈閉塞症、消化管穿孔、異所性妊娠。特に高齢者の「腹痛＋ショックバイタル」は血管系イベントを強く疑え。
>
> **[設備制約]** トロポニンTやDダイマーの迅速検査、およびエコー・CTがない。心電図とX線で異常がなくても、症状が強ければ「見逃し」を避けるために救急搬送を選択せよ。

<h3 className="soap-a">評価</h3>

- **診断根拠:** 背部の急激な疼痛。
- 鑑別疾患（整形以外）:
- 大動脈解離（裂ける痛み、移動痛）
- 尿管結石（側腹部～鼡径部への放散、血尿）
- 急性膵炎（アルコール歴、前屈位で軽減）
- 圧迫骨折（体動時痛、叩打痛）

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** Red Flags（解離・膵炎・化膿性脊椎炎）の除外。尿検査（血尿）、X線（結石・骨折）。整形疾患または尿路結石と断定できれば鎮痛剤で経過観察。

#### 処方・処置

**鎮痛 (頓用・選択)**

- <span className="med-id">[Rx-Uro-Sto-Dic]</span> ボルタレンサポ
- ボルタレンサポ50mg 1回1個 激痛時頓用 5回分 *— 結石・整形痛に有効*
- <span className="med-id">[Rx-Gen-Pain-Lox-T-Set]</span> ロキソプロフェン・レバミピドセット(頓用)
- ロキソプロフェンNa錠60mg 1回1錠 (疼痛時) 10回分
- レバミピド錠100mg 1回1錠 (疼痛時) 10回分

**結石排石 (併用)**

- <span className="med-id">[Rx-Uro-Sto-Tam]</span> ハルナール
- ハルナールD錠0.2mg 1回1錠 1日1回 朝食後 14日分 *— 尿管拡張(適応外)*
- <span className="med-id">[Rx-Uro-Sto-Uro]</span> ウロカルン
- ウロカルン錠225mg 1回2錠 1日3回 毎食後 14日分

**紹介**

- <span className="med-id">[Doc-Gen-Referral]</span> 診療情報提供書 (救急外来へ紹介：解離・膵炎疑い)

#### 指導・計画

- **再診目安:** 疼痛持続時。

<div className="ap-dr-advice">

> 💡 **Dr.Advice**
>
> **[叩打痛]** 肋骨脊柱角(CVA)の叩打痛があれば、尿路結石や腎盂腎炎を強く示唆する。脊椎自体の叩打痛は圧迫骨折や脊椎炎を示唆する。叩く場所を意識して鑑別せよ。
>
> **[D-dimerなし]** 当院ではD-dimerが即日出ないため、解離や肺塞栓の除外には使えない。疑わしければ画像診断ができる施設へ送るのが鉄則である。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **非特異的腰背部痛が約85%:** 筋筋膜性、椎間関節性、椎間板性など（画像で特定困難）
- **特異的原因（約15%）:** 椎間板ヘルニア、脊柱管狭窄症、圧迫骨折、感染、腫瘍
- **自然経過:** 急性腰痛の約90%は6週間以内に改善

### 診断基準・鑑別疾患

- **Red Flags（要緊急評価）:**
  - 馬尾症候群: 膀胱直腸障害、サドル麻酔、両下肢筋力低下 → 緊急MRI + 外科紹介
  - 悪性腫瘍: 癌の既往、安静時痛、体重減少、50歳以上の初発
  - 感染（化膿性脊椎炎）: 発熱、免疫低下、IV drug use
  - 骨折: 外傷、ステロイド使用、骨粗鬆症
  - 大動脈疾患: 拍動性腫瘤、背部痛（解離・瘤破裂）
- **Yellow Flags（慢性化リスク）:** 破局的思考、恐怖回避行動、職場不満、うつ

### エビデンス・ガイドライン推奨

- **腰痛診療ガイドライン2019（日本整形外科学会）:**
  - **初診時:** Red Flagsの除外 → なければ画像検査は不要（推奨グレードA）
  - **NSAIDs:** 短期使用が有効（推奨グレードA）
  - **アセトアミノフェン:** 効果はプラセボと差がないとのエビデンスもあるが実臨床では使用
  - **筋弛緩薬:** チザニジン（テルネリン）の短期追加は有効
  - **安静は推奨しない:** 可能な限り日常活動を維持（推奨グレードA）
  - **慢性化予防:** 早期の活動再開、患者教育、心理社会的要因への対応
