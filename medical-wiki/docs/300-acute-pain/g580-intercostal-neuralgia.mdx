<h3 className="soap-s">主訴・ROS</h3>

**痛みの分析 (OPQRST)**

Onset (発症様式): 突然 / 急性 / 徐々 / ある動作で
Palliative/Provocative (増悪・寛解): 体動 / 食事 / 深呼吸 / 安静時
Quality (性状): 締め付けられる / 裂けるよう / 鈍痛 / 差し込む
Region (部位): 胸部 / 心窩部 / 右季肋部 / 右下腹部 / 背部
Severity (強度): 冷や汗をかく激痛 / 会話可能 / 波がある
Time (経過): ＿分/時間 前から持続

**随伴症状**

冷汗 / 嘔気・嘔吐 / 呼吸困難 / 意識消失 / 下血 / なし

**リスク因子**

高血圧 / 糖尿病 / 脂質異常症 / 喫煙 / 心疾患の既往 / なし

<h3 className="soap-o">所見・検査</h3>

バイタル: BP ＿/＿ (左右差: 有 / 無), HR ＿, SpO2 ＿%, BT ＿℃
顔貌: 苦悶様 / 蒼白 / 冷汗 / 安定

**身体所見**

胸部: 異常なし / 心雑音 / 呼吸音異常 / 頸静脈怒張
腹部: 平坦 / 膨満, 腹膜刺激症状 なし / 筋性防御 / 反跳痛
圧痛点: なし / McBurney / Murphy / 全体
CVA叩打痛: なし / 右 / 左

**院内迅速検査**

心電図（12誘導）
- **所見:** 正常 / ST変化 / 異常Q波
末梢血一般(CBC), CRP
- WBC ＿, CRP ＿, 血糖 ＿
尿検査
- 潜血(＿) ；結石・解離の鑑別
胸部単純X線検査
腹部単純X線検査
- **所見:** Free air / 結石影 / 縦隔拡大 / 異常なし

**除外項目(Negative ROS)**

頭痛時: 項部硬直なし / 麻痺・しびれなし / 雷鳴頭痛否定
胸背部痛時: 圧痛なし / 皮疹なし / 血圧左右差なし
腹痛時: 板状硬なし / 反跳痛なし / 拍動性腫瘤なし

<h3 className="soap-a">評価</h3>

- **診断根拠:** 肋骨に沿った片側性の発作性疼痛。姿勢や咳で誘発されることがある。圧痛点（Valleix点）。
- **除外診断:** 帯状疱疹（皮疹なし）、胸膜炎（深呼吸で増悪）、心疾患、骨折。

<h3 className="soap-p">方針・処方</h3>

- **治療戦略:** 対症療法（NSAIDs、ビタミンB12）。帯状疱疹の前駆痛の可能性を説明し、発疹が出たら再診するよう指導。

#### 処方・処置

**内服治療セット**

#### 指導・計画

- **患者指導:** 後から発疹が出る可能性があるため、出現時は直ちに受診するよう指導。

## 📖 詳細解説

*最新のガイドラインや病態生理、エビデンスをここに追記できます。ページ下部の「このページを編集」からGitHubで直接編集できます。*

### 病態生理

- **定義:** 肋間神経（胸髄神経前枝T1-T12）の支配領域に沿った痛み
- **原因:** 帯状疱疹（最重要）、脊椎変性疾患、肋骨骨折、外傷、筋筋膜性疼痛、特発性
- **症状:** 片側性の肋間に沿った鋭い痛み、深呼吸・咳嗽・体動で増悪
- **帯状疱疹関連:** 水疱出現前のprodromal painとして出現することがある（3-5日先行）

### 診断基準・鑑別疾患

- **鑑別（胸痛のred flags除外が最優先）:**
  - ACS: 胸部絞扼感、冷汗、心電図異常 → 即時評価
  - 大動脈解離: 突然の裂けるような背部痛
  - 肺塞栓: 呼吸困難、頻脈、DVTリスク
  - 気胸: 突然の胸痛 + 呼吸困難
- **診断:** 除外診断。肋間に沿ったデルマトーム分布の疼痛 + 重篤疾患の除外
- **帯状疱疹の確認:** 3-5日後に水疱が出現しないか経過観察を指導

### エビデンス・ガイドライン推奨

- **治療:**
  - NSAIDs（ロキソプロフェン等）: 第一選択
  - アセトアミノフェン: NSAIDs使用困難時
  - 神経障害性疼痛が疑われる場合: プレガバリン（リリカ）75mg 1日2回から
- **帯状疱疹が判明した場合:** 発症72時間以内に抗ウイルス薬（バラシクロビル等）開始
- **患者指導:** 数日後に皮疹が出たら直ちに再診するよう指導
