<h3 className="soap-a">評価</h3>

- 小児気管支喘息。
- **発作強度分類:** 小発作（会話可、横になれる）/ 中発作（会話は文節、起坐呼吸）/ 大発作（会話困難、チアノーゼなし）/ 呼吸不全（会話不能、チアノーゼ、意識低下）。
- 長期管理ステップ（JPGL2020）: ステップ1〜4で管理薬を段階的に増減。
- **乳幼児喘息の診断:** 3回以上の喘鳴エピソード+アトピー素因（本人の湿疹、親の喘息、IgE高値）で臨床的に診断。
- 修正Asthma Predictive Index（mAPI）: 主要基準（親の喘息、本人のアトピー性皮膚炎）+ 副基準（アレルギー性鼻炎、食物アレルギー、末梢血好酸球≧4%、感冒と無関係の喘鳴）で将来の喘息リスクを評価。

<h3 className="soap-p">方針・処方</h3>

- 【発作時】β2刺激薬吸入（メプチン吸入液0.3mL+生食2mL ネブライザー）、20分間隔で最大3回。
- 中発作以上: プレドニゾロン1-2mg/kg（最大60mg）経口、またはヒドロコルチゾン5mg/kg点滴。
- 【長期管理】
ステップ1: LTRA単独（モンテルカスト等）
ステップ2: 低用量ICS（フルチカゾン50-100μg/日等）
ステップ3: 中用量ICS + LTRA
ステップ4: 高用量ICS + LTRA ± LABA
- 【吸入デバイス選択】
0-2歳: pMDI + スペーサー + マスク
3-5歳: pMDI + スペーサー（マウスピース）
6歳以上: DPI可

#### 指導・計画

- 保護者へ吸入デバイスの使い方を実演指導。スペーサーの洗浄・管理方法も説明。
- 発作時の対応（β2吸入→改善なければ受診）をアクションプランとして書面で渡す。
- **再診目安:** コントロール良好なら1-3ヶ月ごと。ステップダウンは3ヶ月以上安定後に検討。

## 📖 詳細解説

小児気管支喘息は小児期で最も頻度の高い慢性呼吸器疾患であり、日本の小児有病率は約10-15%（学童期のピーク）。気道の慢性炎症と可逆性の気流制限を本態とし、適切な長期管理により大多数の児で良好なコントロールが得られる。日本では小児気管支喘息治療・管理ガイドライン（JPGL2020）が標準指針である。

### 病態生理

**気道炎症のメカニズム**

- **アレルギー性炎症:** ダニ、ペット、カビ等のアレルゲン曝露によりTh2リンパ球が活性化。IL-4、IL-5、IL-13を介して好酸球浸潤、IgE産生、杯細胞過形成（粘液過分泌）が生じる。
- **気道リモデリング:** 慢性炎症が持続すると、基底膜肥厚、平滑筋肥大、粘膜下線維化が進行し、不可逆的な気流制限に至る。早期からの抗炎症治療（ICS）がリモデリング予防に重要。
- **気道過敏性:** 炎症により気道平滑筋の閾値が低下し、運動、冷気、ウイルス感染等の非特異的刺激でも気管支収縮が誘発される。

**発作の3要素**

1. 気管支平滑筋の攣縮（β2刺激薬で可逆的）
2. 粘膜浮腫（ステロイドで改善）
3. 粘液栓（排痰困難 → 無気肺の原因）

### 診断基準・鑑別疾患

**JPGL2020の診断基準**

小児喘息の診断は臨床的に行う（確定的な単一検査はない）:

- **反復する喘鳴（3回以上）** + 呼気性喘鳴の聴取
- β2刺激薬吸入で症状が改善する（可逆性の証明）
- アトピー素因（本人の湿疹・アレルギー性鼻炎、親の喘息、IgE高値）

**発作強度分類（JPGL2020）**

| 強度 | 呼吸状態 | SpO2 | 会話 | 対応 |
|------|---------|------|------|------|
| 小発作 | 軽度喘鳴、陥没呼吸なし | 96%以上 | 文で可能 | 外来でSABA吸入 |
| 中発作 | 明らかな喘鳴、陥没呼吸あり | 92-95% | 句で可能、横になれない | SABA反復+全身ステロイド |
| 大発作 | 著明な喘鳴、起坐呼吸 | 91%以下 | 単語のみ | 入院、酸素、SABA反復+ステロイド点滴 |
| 呼吸不全 | 喘鳴減弱/消失（silent chest）、チアノーゼ | 91%未満 | 不能 | ICU、挿管準備 |

**修正Asthma Predictive Index（mAPI）**

乳幼児の喘鳴が将来の喘息に移行するかを予測するツール:

- **主要基準（1つ以上）:** 親の喘息、本人のアトピー性皮膚炎
- **副基準（2つ以上）:** アレルギー性鼻炎、感冒と無関係の喘鳴、末梢血好酸球 4%以上、食物アレルギー

主要基準1つ以上 または 副基準2つ以上 で陽性。陽性の場合、学童期に喘息を発症するリスクは約77%（陽性的中率）。陰性的中率は約85%。

**鑑別疾患**

- **乳児期:** 細気管支炎（RSウイルス等）、先天性気道狭窄、血管輪、胃食道逆流症、喉頭軟化症
- **幼児期:** クループ、気道異物、先天性心疾患
- **学童期:** 声帯機能不全、心因性過呼吸、運動誘発性喉頭閉塞

### エビデンス・ガイドライン推奨

**長期管理ステップ（JPGL2020、5歳以下）**

| ステップ | 基本治療 | 追加治療 |
|---------|---------|---------|
| ステップ1 | LTRA単独（モンテルカスト4mg 1日1回就寝前） | -- |
| ステップ2 | 低用量ICS（フルチカゾン100 mcg/日等） | またはLTRA+低用量ICS |
| ステップ3 | 中用量ICS + LTRA | SFC（サルメテロール/フルチカゾン）も選択肢 |
| ステップ4 | 高用量ICS + LTRA + LABA | 専門医紹介。生物学的製剤も検討 |

**長期管理ステップ（JPGL2020、6-15歳）**

| ステップ | 基本治療 |
|---------|---------|
| ステップ1 | 低用量ICS（フルチカゾン100 mcg/日等）またはLTRA |
| ステップ2 | 低-中用量ICS + LTRA（またはLABA） |
| ステップ3 | 中-高用量ICS + LTRA + LABA |
| ステップ4 | 高用量ICS + LTRA + LABA。専門医紹介 |

**吸入デバイスの年齢別選択**

| 年齢 | 推奨デバイス | 備考 |
|------|------------|------|
| 0-2歳 | pMDI + スペーサー + フェイスマスク | マスクを顔に密着させる。泣いている時も吸入可 |
| 3-5歳 | pMDI + スペーサー（マウスピース） | マウスピースで口呼吸ができれば移行 |
| 6歳以上 | DPI（タービュヘイラー、ディスクヘラー等） | 十分な吸気流速（30 L/min以上）が必要 |

**ICS副作用と保護者説明**

ICSに対する保護者の忌避感は極めて強い。以下のエビデンスに基づいて丁寧に説明する:

- **成長への影響:** 低-中用量ICSでは成長への影響は最小限（最終身長で平均-1.2cm程度、CAMP trial, NEJM 2012）。高用量ICSでは定期的な身長測定が必要。
- **全身性副作用:** 低-中用量ICSの全身バイオアベイラビリティは極めて低い（フルチカゾンは経口バイオアベイラビリティ1%未満）。副腎抑制は高用量長期使用時のみ問題。
- **局所副作用:** 口腔カンジダ、嗄声。スペーサー使用+吸入後うがいで予防可能。
- **コントロール不良のリスクの方が大きい:** 喘息のコントロール不良は気道リモデリング、成長障害、QOL低下、致死的発作のリスクがある。ICSのメリットはリスクを大きく上回る。

**ステップダウンの基準**

- 3ヶ月以上のコントロール良好（発作なし、夜間症状なし、日常活動制限なし、SABA使用なし）を確認後、1段階ずつ減量。
- ICSの完全中止は慎重に（再燃率が高い）。LTRAのみで維持できる症例もある。
